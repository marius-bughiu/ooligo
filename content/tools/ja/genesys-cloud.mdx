## 概要

Genesys Cloud はエンタープライズ向けのコンタクトセンター・アズ・ア・サービス(CCaaS)プラットフォームです。電話、ルーティング、デジタルチャネル、ワークフォースエンゲージメント(WFM、品質管理、音声分析)、そしてネイティブの AI レイヤーを備え、エージェント席単位で販売され、AI はその上に従量課金で上乗せされます。Genesys のオンプレミス製品ラインである PureConnect と Engage のクラウド後継にあたり、同社はこれらから集約を進めています。Pointillist のジャーニー分析は2026年7月31日にサポートを終了し、Genesys Decisions は2026年12月31日に提供終了を迎えます。CCaaS カテゴリで最も近いのは NICE CXone で、大規模な規制業種のコンタクトセンターをめぐる最大の競合です。

重要なのは規模です。Genesys は2026年4月30日に終わる四半期で Genesys Cloud の年間経常収益が $2.8B に達し、前年比でほぼ35%成長、売上継続率(NRR)は120%超と報告しました。2026年1月時点で、Genesys Cloud 顧客の70%超が AI 機能を利用しています。2025年7月31日に発表された $1.5B の投資のうち、Salesforce と ServiceNow がそれぞれ $750M を拠出しました。両 CRM が単なる連携先ではなく、第一級のエージェントパートナーとして登場するのはこのためです。

## CX・サポートのスタックに入ってくる理由

- **自らを AI エージェントの上位レイヤーとして売り込んでいます。** 2026年9月2日の Xperience で、Genesys は4つの製品を発表しました。AI Control Plane と Contextual Intelligence(提供中)、IVR メニューを置き換える AI の入口である Navigator(GA 予定時期は2026年11月1日〜2027年1月31日)、そして AI エージェント、人、バックオフィスシステムをまたいでジャーニーの状態を保持する Orchestrator(GA 予定時期は2027年2月1日〜4月30日)です。主張は、Salesforce、ServiceNow、Microsoft、専門ベンダーのエージェントを並行して運用することになり、誰かがそれらをルーティングし統制しなければならない、というものです。
- **Agentic Virtual Agent がネイティブの実行面です。** 2025年3月にローンチし、Scaled Cognition の APT-2 アクションモデル、Deepgram の音声認識、ElevenLabs の音声(2026年10月末予定)、そして Salesforce と ServiceNow のエージェントとのエージェント間相互運用性が加わりました。Genesys は APT-2 が前世代より25%精度が高いとしていますが、これはベンダー自身のベンチマークであり、独立したものではありません。
- **Pinkfish がバックオフィス操作のためのツールをもたらしました。** Genesys は2026年6月30日に Pinkfish を買収しました。500超の連携を通じて、CRM、ERP、請求、受注システムにまたがる約25,000の MCP ツールを公開しており、まず AppFoundry 経由で、2027年1月の会計年度末までにネイティブで提供されます。Genesys Cloud 自体は顧客向けの MCP サーバーを公開していません。MCP ツール群は、同社のエージェントが外部を呼び出すためのものです。

## 価格の実態

定価は公開されています。CX 1 はエージェント1人あたり月 $75(音声)、CX 2 は $115(デジタルと品質管理を追加)、CX 3 は $155(フル WFM とワークフォースエンゲージメントを追加)、CX 4 は $240(Agent Copilot とエージェント単位の AI 割当を追加)で、いずれも年間請求です。

AI の請求は別建てで、AI Experience トークンで計測されます。すべての組織に月250トークン(指名ライセンス)または350トークン(同時接続ライセンス)が付与され、CX 4 ではエージェント1人あたり指名で30、同時接続で39が加算されます。Genesys 自身の請求ドキュメントでは、米国での超過単価は1トークンあたり $1 とされ、消費レートも記載されています。Agentic Virtual Agent の1インタラクションは1.2トークン、従来型 Virtual Agent の1インタラクションは0.5、ボイスボットは17分ごとに1トークン、Agent Copilot は指名ユーザー1人あたり月40トークンです。署名前に計算してください。月100,000件のエージェント型インタラクションは120,000トークンで、無料枠を超えた分は定価で月およそ $120K になります。これは CX 3 で300席のセンターの席料(約 $46.5K)より大きい額です。

実際に支払われる席料は定価より低くなります。第三者のベンチマーク(VendorBenchmark、推計)によると、200席未満で15〜22%引き、500席以上で28〜35%引き、1,500席超では最大38〜45%引きで、いずれも3年契約かつ年5〜8%のエスカレーター付きです。これに加えてプロフェッショナルサービスが、シンプルな音声導入でおよそ $150K から、複雑な移行では $2M 超までかかります。

## 適している相手

200席から数千席規模で、音声中心、複数リージョンのコンタクトセンターを運営するコンタクトセンター責任者や CX オペレーション責任者で、ルーティング、ワークフォースマネジメント、AI エージェントを1つの契約にまとめたい組織です。Salesforce や ServiceNow が記録システムであり、複数ベンダーのエージェントを1つの入口の背後で運用する見込みなら、なおさら該当します。

見送るべきなのは、Zendesk や Intercom のようなヘルプデスクで約50席未満を運用している場合です。ヘルプデスク自身の AI のほうが安く、CCaaS レイヤーはオーバーヘッドになります。また、AI のロードマップが Navigator と Orchestrator に依存している場合も見送ってください。これらが一般提供に達するのは2027年初頭です。

## 代替製品との比較

**NICE CXone** はエンタープライズ複占のもう一方で、Gartner の2025年 CCaaS Magic Quadrant では実行能力で最上位に置かれました。ワークフォースエンゲージメントと品質管理が決め手になる場合(WEM の系譜がより深いため)、あるいは WFM チームがすでに NICE を運用している場合は NICE を選んでください。複数ベンダーのエージェントオーケストレーションと CRM パートナーシップがより重要なら Genesys を選んでください。**Five9** は上場企業の選択肢(FIVN)です。中堅市場でインバウンドとアウトバウンドを併用するセンターなら Five9 を選んでください。同社の AI は2026年第2四半期にサブスクリプション売上の約15%に達しています。**Amazon Connect** は、AWS ネイティブで分単位課金のプリミティブの上に構築することに抵抗がない場合に勝ちます。**Talkdesk** はその2025年の Quadrant で Visionary から Leader に移り、最も大きく順位を上げました。中堅市場での迅速な導入や業種別エディションが必要なら Talkdesk を選んでください。

2026年の本当の問いは、その上に専門エージェントを買い足すかどうかです。[Sierra](/ja/tools/sierra/)、[Parloa](/ja/tools/parloa/)、[PolyAI](/ja/tools/polyai/) はいずれも Genesys と接続できます。ルール:まず上位5つの意図でネイティブの Agentic Virtual Agent をパイロットしてください。専門製品を追加するのは、その自己完結率がネイティブを上回り、2つ目の契約を賄えるだけの差がある場合に限ります。

## 注意点

- **自動化の比重が高いプランでは、トークン消費が席料を上回ります。** 無料枠で賄えるのはパイロットであり、本番運用ではありません。ガード:署名前に Genesys が公開しているレートから意図別の月間トークン消費をモデル化し、$1 の超過単価より安い事前購入トークンブロックを交渉し、月間割当の80%でアラートを設定してください。
- **主力のオーケストレーション製品は発表済みであって、出荷済みではありません。** Navigator と Orchestrator にあるのは GA の予定時期であり、日付ではありません。ガード:現時点で一般提供されているものを基準に契約し、Navigator や Orchestrator に関する値上げは、自社リージョンでの GA を条件にしてください。
- **プラットフォームの集約は、計画していなかった移行を意味します。** Pointillist、Decisions、BYOC-Premises のハードウェアサポートはいずれも2026年に終了します。ガード:運用しているすべての Genesys コンポーネントを help.genesys.cloud の廃止予定リストと突き合わせて棚卸しし、移行クレジットを更新契約に書き込ませてください。
- **WEM と AI を追加するほどロックインが深まります。** ルーティングフロー、Architect のロジック、WFM のスケジュールは Genesys ネイティブです。ガード:意図の定義とナレッジコンテンツは自社が所有するシステム(CRM やナレッジベース)に置き、Architect のフローを四半期ごとにエクスポートしてください。そうすれば将来のベンダー切り替えは、リバースエンジニアリングではなくドキュメントから始められます。
