## 概要

Sim は AI エージェントとその周辺のワークフローを作るビジュアルビルダーで、コアは `github.com/simstudioai/sim` で Apache-2.0 ライセンスです。キャンバス上にエージェントブロック、ツール呼び出し、条件分岐、ループを配置し、完成したものを API、チャット、スケジュール、Webhook としてデプロイし、すべての実行のトレースをログで確認できます。2026 年 3 月 17 日の v0.6 以降、製品には Mothership も搭載されています。これは 1 つの会話からワークフロー、テーブル、ファイル、ナレッジベースを構築・編集する自然言語のコントロールプレーンです。このリリースを境に、Sim は自らをワークフロービルダーではなく AI ワークスペースと呼ぶようになりました。

MCP は双方向で動きます。エージェントはワークスペースに登録した任意の外部 MCP サーバーを呼び出せ、デプロイ済みのワークフローは MCP ツールとして公開でき、[Claude](/ja/tools/claude/) Code、Claude Desktop、[Cursor](/ja/tools/cursor/)、Codex から直接呼び出せます。リポジトリの README は、[Slack](/ja/tools/slack/)、[HubSpot](/ja/tools/hubspot/)、[Salesforce](/ja/tools/salesforce/)、[Notion](/ja/tools/notion/) を含む 1,000 以上のインテグレーションをうたっています。ローカルモデルは Ollama または vLLM 経由で動きます。

同社は 2025 年に UC Berkeley の卒業生 2 名が設立し、Y Combinator を経て、Standard Capital が主導し Perplexity Fund と SV Angel が参加するシリーズ A で $7M を調達しました。リポジトリの GitHub スターは 30,000 前後で、週に複数回リリースしています。2026 年 9 月下旬には v0.9.1 から v0.9.3 までが 2 日以内に出ました。

## 解決する分岐点

このページが答える問いは、「[n8n](/ja/tools/n8n/) のライセンスが問題になる。セルフホストできる、本当にオープンソースの自動化エンジンは何か」です。

n8n は Sustainable Use License で提供され、用途を社内業務または非商用に限定します。ほとんどの ops チームには問題ありませんが、有償の顧客向けにワークフローを動かす人にとっては壁です。「Show HN: Sim – Apache-2.0 n8n alternative」は 2025 年 12 月 11 日に 240 ポイント、61 コメントを集め、スレッドの主な論点はライセンスでした。Apache-2.0 なら、コアを改変し、組み込み、再販売できます。

分岐点のもう半分は、何を自動化するかです。n8n と [Zapier](/ja/tools/zapier/) はインテグレーションの配管から始まり、後からエージェントを追加しました。Sim はエージェントブロックから始まっています。ステップの大半がモデル呼び出し、たとえば受信した契約書の分類、アカウントの調査、候補者への返信の下書きであれば、Sim のキャンバス、実行ごとのトークントレース、ナレッジベースブロックのほうが作業に直接合います。

## 価格の実際

Cloud Free は $0 で、1 回限りの 1,000 クレジットとワークスペース 1 つです。Pro はユーザーあたり月 $25 で、月 6,000 クレジットに加えて毎週 2,000 クレジットが補充されます。Max はユーザーあたり月 $100 で、月 25,000 クレジットに加えて週 4,000 クレジット、さらにサンドボックスと Slack Connect が付きます。SSO、セルフホストのサポート、専任サポートは Enterprise 限定で、個別見積もりです。

1 クレジットは $0.005 です。すべての実行に基本料金として 1 クレジットがかかります。Sim のホスト型キーでのモデル呼び出しは、プロバイダーの定価の 1.1 倍でクレジットに換算して請求されます。自前のキーを持ち込めば 10% の上乗せはなくなり、プロバイダーへ直接支払い、残るのは基本料金だけです。超過利用はデフォルトでオフです。オンデマンド課金を有効にすると追加クレジットは $0.005 で、未請求の利用額が $100 に達するたびに請求されます。

1 つのフローで計算してみます。モデル呼び出しが定価で $0.02 のエージェント実行は、モデル分 4.4 クレジットと基本料金 1 で 5.4 クレジットです。Pro の月 6,000 クレジットでこの実行を約 1,100 回まかなえます。自前のキーなら同じ枠で 6,000 実行をまかなえ、$120 のトークン代はプロバイダーに支払われます。両者の差は 10% の上乗せであって、何倍もの差ではありません。どちらにしても実際のコストはモデルの請求額です。

コアのセルフホストはライセンス料 $0 です。文書化された最低要件は、1-5 ユーザーで 2 CPU コアと 12 GB RAM、5-50 ユーザーで 4 コアと 16 GB です。一般的なクラウドで 16 GB の VM とマネージド PostgreSQL を使う場合の当社の見積もりは月 $80-130 で、[Activepieces](/ja/tools/activepieces/) のおよそ 2 倍のフットプリントです。

## 最適な相手

エージェント中心のワークフローを構築し、コードを自社の境界内に置く必要がある、あるいはそのワークフローを顧客に提供する必要がある、20〜200 名規模の企業の ops エンジニアです。Sim が明確に勝つ限定条件はこうです。Legal Ops または CS チームがドキュメントパイプラインを運用し、契約書やチケットをナレッジベースに取り込み、エージェントブロックで分類し、結果をテーブルに書き込み、チームが Claude から呼び出す MCP ツールとしてワークフローを公開する、それを自前のキーでセルフホストする、という構成です。

## 向かない相手

自動化の大半がループ内にモデルのない SaaS 間の配管であるチームです。Zapier や n8n のほうが、より深く歴史のあるコネクタでそれをこなします。バランスシートの規模を持つベンダーを必要とする購買者にも向きません。$7M のシリーズ A は、n8n の $180M のシリーズ C や、2026 年の SAP によるセカンダリー取引での $5.2B の評価額と比べると小規模です。

## 代替候補との比較

- **[n8n](/ja/tools/n8n/)** — 技術系チーム向けのカテゴリーリーダーで、クラウドは月 $23 から。用途が社内向けでライセンスのコストが実質ゼロになり、最大のテンプレートライブラリ、コミュニティ、採用市場を求める場合に選んでください。
- **[Zapier](/ja/tools/zapier/)** — 最大の導入基盤を持ち、月 $19.99 から。フローが短く、誰もインフラを運用したくなく、エージェントの深さよりコネクタの幅が重要な場合に選んでください。
- **[Gumloop](/ja/tools/gumloop/)** — 最も成長が速い AI ネイティブの参入者で、2026 年 3 月に Benchmark 主導のシリーズ B で $50M を調達しました。Pro は月 $37 です。セルフホストすることのない非エンジニアが、モデル中心のパイプラインを動かす場合に選んでください。
- **[Activepieces](/ja/tools/activepieces/)** — もう一つの寛容なライセンスの選択肢で、コアは MIT、月 $16 から。作業がエージェント中心ではなくインテグレーション中心の場合、または手持ちのマシンに 12 GB RAM の最低要件が重すぎる場合は、Sim より Activepieces を選んでください。

どれも合わず、チームがコードを書けるなら、LangGraph や Claude Agent SDK のようなコードファーストのフレームワークでエージェントを構築し、すでに運用しているスケジューラーで動かしてください。2025 年 8 月に Workday が買収した Flowise は 2026 年夏にサービス終了を発表しました。ビジュアルレイヤーは失われうる部分だということを示しています。

## 注意点

- **Apache-2.0 が対象とするのはコアであり、エンタープライズ機能ではありません。** SSO、SCIM、監査ログ、アクセス制御、データ保持、セッションポリシー、ホワイトラベルは `apps/sim/ee/` にあり、Sim Enterprise License の下で評価目的と非本番利用のみが許可されています。防御策：パイロット前に、セキュリティレビューが必須とする統制を洗い出してください。SSO や監査ログが含まれるなら、ワークフローを本番投入した後ではなく、その時点で Enterprise の見積もりを取ってください。
- **セルフホストでも、Mothership と Copilot には sim.ai のキーが必要です。** チャットモジュールには sim.ai が発行する `COPILOT_API_KEY` が必要で、自然言語レイヤーは Sim のクラウドを呼び出します。防御策：データを自社の境界内にとどめる必要があるなら、チャットモジュールを無効にしてキャンバスで構築し、エージェントブロックは自前のプロバイダーキーまたは Ollama に向けてください。
- **1.0 未満で、リリースが速いです。** 週に複数回のリリースは機能面では良いことですが、自動更新する本番マシンにとっては悪いことです。防御策：Docker イメージを特定のバージョンタグに固定し、まずステージング環境でアップグレードし、各アップグレードの前にデプロイ済みワークフローをエクスポートしてください。
- **「1,000 以上のインテグレーション」は 1,000 のネイティブコネクタではありません。** 2025 年 12 月の HN でのローンチ時には 138 のインテグレーションとされ、現在の README は 1,000 以上とうたっていますが、数え方の定義は示されていません。防御策：フローを確定する前に、必要なトリガーとアクションが自社の CRM や ATS 向けのネイティブブロックとして存在するかを確認し、存在しない箇所では MCP または HTTP 呼び出しを構築する時間を見込んでください。
