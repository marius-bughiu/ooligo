## What it is

Mastra is an open-source TypeScript framework for building AI agents, plus a hosted platform for running them. It comes from the team that built Gatsby.js, went through Y Combinator, shipped 1.0 in January 2026, and raised a $22M Series A led by Spark Capital in April 2026 ($35M in total). The GitHub repo sits around 30K stars.

The framework gives you agents with tools, graph-style workflows with branching and suspend/resume, memory, RAG, evals and tracing, all as npm packages under `@mastra/*`. Mastra Studio is the local UI where you chat with an agent, step through a workflow run and read its traces. Agents deploy to anything that runs Node.js, including Vercel, Cloudflare and Netlify, or to Mastra Platform.

The ops question it answers: your team already writes TypeScript (a RevOps engineer maintaining CRM integrations, a legal-ops developer who built the intake portal) and you want internal agents in the same language and repo as the rest of your code, rather than a Python service or a no-code canvas nobody can review in a pull request.

## What you are actually buying

**The framework is free.** Most of the code is Apache 2.0 since July 2025. Code under any `ee/` directory sits under a separate enterprise licence: RBAC, fine-grained authorisation, Agent Builder and third-party sign-in for Studio are free in development and need a paid key in production.

**Mastra Platform** hosts the server, Studio, observability and Connect (managed integrations). November 2026 added a built-in MCP server (2026-11-17), Mastra Gateway for 500+ models on one key with failover (2026-11-19), observability alerts and encrypted secrets.

**Mastra Factory** is a separate product, launched July 2026 and posted as a Show HN on 2026-11-18: a kanban-style board where agents triage GitHub or Linear issues, write the PR and run review. Mastra reports it writes more than 25% of its own PRs. Useful as a reference design; it is a software-engineering tool, not an ops tool.

## Pricing

Published at mastra.ai/pricing, checked 2026-11-27. Prices are per workspace per month.

- **Free — $0.** Unlimited agents, users and deployments; 100K observability events, 40 vCPU-hours, 360 GB-hours of memory, 10 GB egress, 5 connections. Serverless projects only (scale to zero).
- **Starter — $25.** One always-on Small project (2 GB, 1 vCPU), 250K events, 25 GB egress, 10 connections. Repriced on 2026-11-10; the old free "Starter" is now Free.
- **Team — $250.** One Small and two Medium projects, 10M events, 400 vCPU-hours, 50 connections, and the SOC 2 report.
- **Enterprise — custom.** RBAC, SSO, audit logs, static IP, OIDC.

Overage: $10 per 100K events, $0.25 per vCPU-hour, $0.25 per GB-hour, $0.10 per GB egress, $0.50 per extra connection. Extra projects cost $25 (Small), $100 (Medium) or $200 (Large) a month.

The real band: one internal agent on a schedule fits Starter at $25 a month plus model spend. Three production agents with a staging environment land on Team at $250. SSO forces Enterprise, and there is no published number for it. Self-hosting the framework on your own Vercel or AWS account costs nothing in licences unless you need the `ee/` features in production.

## Best for

A TypeScript-first ops engineering team (one to five developers) building two to ten internal agents, such as a lead-enrichment agent in RevOps, an NDA-intake triage agent in legal ops or a candidate-screening summariser in recruiting, that need durable multi-step workflows, human approval steps and traces, and that want the code reviewed in the same repo as everything else.

## Not for

A team without a developer: use [Dify](/en/tools/dify/), [Sim](/en/tools/sim/) or [n8n](/en/tools/n8n/). A Python shop: the framework is TypeScript only. A company that needs SSO on day one and cannot run an Enterprise procurement: Team at $250 does not include it.

## Versus the alternatives

- **LangGraph with [LangSmith](/en/tools/langsmith/)** — the most-adopted code-first agent framework, in Python and JS. Pick it when you need explicit state-machine control and the most mature eval tooling, or the team works in Python.
- **[CrewAI](/en/tools/crewai/)** — Python, role-based multi-agent crews. Pick it when the job maps to roles handing work to each other and the team writes Python.
- **Vercel AI SDK** — the lighter TypeScript option. Pick it when you need streaming model calls and tool use inside a web app and nothing durable; move to Mastra when you need workflows with suspend/resume, memory and traces.
- **[Claude Managed Agents](/en/tools/claude-managed-agents/)** — pick it when you want Anthropic to run the agent loop and sandbox and you only use Claude models.

Is the paid platform worth it? For one or two agents, Starter at $25 is cheaper than the hours spent wiring hosting, secrets and tracing yourself. Past that, compare Team at $250 against running the framework on infrastructure you already pay for and sending traces to [Langfuse](/en/tools/langfuse/).

## Watch-outs

- **The June 2026 npm compromise.** On 2026-06-17 an attacker used a former contributor's npm account to republish 140+ `@mastra` packages with a malicious dependency (`easy-day-js`) carrying a credential stealer and remote-access trojan; Microsoft attributed it to the North Korean group Sapphire Sleet. Mastra says the source code was not modified. Guard: pin exact versions in a committed lockfile, install with `npm ci`, block install scripts in CI where you can, and run a dependency scanner (Socket, Snyk) on every `@mastra` upgrade.
- **Fast release cadence.** Mastra posted more than 15 product announcements on its blog in November 2026 alone, and the July 2026 pricing post was out of date four months later. Guard: upgrade on a monthly schedule against the changelog, not on every release, and re-check plan allowances before each renewal.
- **Enterprise features hide in `ee/`.** Teams discover the RBAC or Studio sign-in licence requirement at go-live. Guard: list the access controls your security review needs before you build, and get an Enterprise quote in the same week.
- **Platform reliability is young.** Mastra published an incident report for a platform incident on 2026-10-21. Guard: keep the deploy target portable (the same code runs on Vercel or Cloudflare) and do not put a revenue-critical agent on a single hosted project without a fallback.
