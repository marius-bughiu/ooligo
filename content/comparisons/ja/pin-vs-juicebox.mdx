[Pin](/ja/tools/pin/) と [Juicebox](/ja/tools/juicebox/) は同じ買い手に売られています。ソーシング専任チームを置くには小さすぎる企業の、社内 TA リードや自ら採用する創業者です。しかも両方とも $99 という入口価格を掲げているため、同じ買い物に見えます。ただし、止まる場所が違います。Pin はカレンダーまでループを回します。求人票を読み、公称 850M 以上のプロフィールから候補者をランク付けし、メール・LinkedIn・SMS でシーケンスを走らせ、面接を予約します。Juicebox はショートリストまでループを回します。PeopleGPT が30以上のソースから集めた 800M 以上のプロフィールを検索し、エージェントがあなたの基準で候補者を評価してパーソナライズしたメールを送り、そこでリストを渡してきます。判断すべきは、どちらのソーシングが優れているかではありません。自社のプロセスで漏れている工程が「人を見つけること」なのか「その人をカレンダーに載せること」なのか、です。

## Pin が勝つところ

**カレンダーへの引き継ぎを自社で握っています。** Pin のスケジューリングは空き時間を調整し、リクルーターがスレッドに入らないまま会議を予約します。つまりシーケンスは、まだ追いかけが必要な返信ではなく、招待で終わります。Juicebox にはスケジューリング工程がまったくありません。自社のエージェントページ自体が、検索のキャリブレーション、候補者分析、パーソナライズしたメール、パフォーマンス追跡までを説明し、そこで止まっています。返信率がすでに許容範囲で、実際に日数を食っているのが三者間の日程調整であるなら、この差が比較のすべてであり、検索精度では埋まりません。

**MCP サーバーは自社製で、一般提供されており、追加課金もありません。** Pin は4つのフェーズにわたって10個のツールを公開しています。セットアップ用に `list_jobs`、`scrape_job_description`、`create_job`。レビュー用に `get_candidates`、`accept_candidate`、`reject_candidate`。チューニング用に `modify_search` と `recalibrate_search`。永続化用に `read_job_memory` と `update_job_memory`。認証は WorkOS 経由の OAuth 2.1 で、ベンダーは全有料プランに含まれ、呼び出し数の従量上限もシートあたりの MCP 料金もないと明示しています。Juicebox は MCP サーバーを提供していません。ブラウザのタブではなく [Claude Code](/ja/tools/claude/) や [Cursor](/ja/tools/cursor/) からショートリストを回すつもりなら、今日その運用ができるのは2製品のうち片方だけです。

**エージェントはシート価格に含まれています。** Pin の無料プランには1エージェントが含まれ、すべての有料プランで AI ソーシングとエージェントが込みだと明記されています。Juicebox はエージェントを別 SKU として、どの有料プランにも上乗せで1エージェントあたり月 $199 で販売します。この1行が2製品間の最大の構造的コスト差であり、1シート目から効いてきます。

**ATS の到達範囲はおよそ3倍広いです。** Pin は120以上の ATS 連携を掲げ、[Greenhouse](/ja/tools/greenhouse/)、[Lever](/ja/tools/lever/)、[Ashby](/ja/tools/ashby/)、[Bullhorn](/ja/tools/bullhorn/)、iCIMS、Jobvite を名指ししています。Juicebox は41の ATS と21の CRM としています。どちらも ATS を記録システムとして残す設計です。単に、あなたの ATS とすでに話せる確率が Pin のほうが高いということです。

## Juicebox が勝つところ

**本当のソーシング上の優位はデータベースの大きさではなく、ソースの多様性です。** Juicebox は 800M 以上のプロフィールを、単一のビジネス SNS を再インデックスするのではなく、30以上のソース——GitHub、特許や論文の著者情報、カンファレンス登壇者リスト——から組み立てています。ML リサーチャーやインフラエンジニアなど、購買シグナルが役職名ではなくコミット履歴や発表論文である職種では、この到達範囲は、役職名とキーワードの索引が構造的に見つけられない人を見つけます。Pin の 850M はより狭い問いに対する大きな数字です。差別化はフィット順のランク付けと承認・却下のフィードバックループにあり、プロフィールの出所ではありません。

**Pin の予算を壊すのは従量課金のクレジットで、Juicebox のエージェントはそれを取り除きます。** Pin は連絡先ルックアップを従量計測します。Solo は月500、Professional はシートあたり 1,000、Business はシートあたり 2,000 です。超過分は500クレジットあたり約 $50 のパックで販売されます。Juicebox Agents アドオンは、どの有料プランでも無制限の連絡先クレジットと無制限のメールクレジットを持ち込みます。開示件数が多い運用ではこれが価格比較を逆転させ、その交差点は理屈ではなく計算で出せます。

**送信面は量に耐えるように作られています。** Growth はユーザーあたり3メールボックス、Business は6です。単一送信元のレピュテーションを焼かずに、アウトバウンドを複数ドメインに分散させる方法がこれです。Pin は Professional 以上でチーム共有の受信箱を使います。エージェンシー規模で送るなら、メールボックス数は利便性ではなく到達率のコントロールです。

**企業規模は明確に大きいです。** Juicebox は2026年3月10日に $80M のシリーズ B を評価額 $850M で調達しました。リードは DST Global、参加は Sequoia、Coatue、Y Combinator、NFDG、Verified Capital です。2025年7月のシリーズ A 以降 ARR は3倍、顧客は 5,000 社としています。Pin は Expa からの $3M シードで約25人です。どちらも動く製品を出していますが、悪い年を生き延びる資本を持つのは片方だけであり、この非対称性は複数年契約の判断材料に入ります。

**自律性はダイヤルです。** Juicebox は、エージェントを完全放任で走らせることも、ショートリストやシーケンス送信の手前に人の確認ポイントを置くこともできるとしています。自社ドメインから実際のメールを送るエージェントの導入としては、これが正しいやり方です。

## 価格の実際

両社とも年払いのシート単価を公開しており、月払いに対しておよそ20〜25%割り引いています。

Pin は、Free が $0（週5ルックアップクレジット、求人1件、エージェント1体、メールのみのシーケンス）、Solo がユーザーあたり月 $99（求人無制限、500クレジット）、Professional が $135（月払いは $179、シートあたり 1,000 クレジット、共有受信箱、メールと LinkedIn と SMS）、Business が $225（月払いは $299、シートあたり 2,000 クレジット、プレミアム ATS コネクタ、SOC 2 ドキュメント）です。SSO/SAML と SCIM はそれぞれ月 +$150 で、Professional と Business のみが購入できます。

Juicebox は、Free が $0（一度きりの連絡先クレジット5件）、Starter が年払いでシートあたり月 $99（検索無制限、連絡先クレジット500とエクスポートクレジット500）、Growth が年払いでシートあたり月 $159（シートあたり連絡先 1,500 とエクスポート 1,500、最大5シート、ユーザーあたり3メールボックス）、Business は個別見積もり（連絡先クレジット無制限、採用マネージャー用シート、ユーザーあたり6メールボックス、データアナリストエージェント）です。エージェントは1体あたり月 $199 で、年払いの2エージェントバンドルは月 $300 で決済されます。

共通の $99 という見出しは、2つの別々のものを指しています。各ベンダーが実際にデモするもの——Pin は稼働中の求人を回すエージェント付き、Juicebox は常設検索を回すエージェント付き——で見積もると、リクルーター1人あたり Pin は月 $99〜$135、Juicebox は月 $298（Starter に1エージェント）です。1シートで 2.2 倍の差になります。

リクルーター3人・年払い1年で見ると、Pin Professional は $4,860、Juicebox Growth に2エージェントバンドルを足すと $9,324 で、Pin は48%安い——クレジットが尽きるまでは。Pin はその3シートで月 3,000 ルックアップを同梱し、超過は1クレジットあたり約 $0.10 なので、月 $372 の差額はおよそ 3,700 ルックアップ分を買えます。つまりチーム全体で月 6,700 件前後の連絡先開示、リクルーター1人あたり約 2,200 件までは Pin のほうが安いということです。その線を超えると、クレジット無制限のエージェントが価格で勝ちます。パイロット期間に採用1件あたりの開示件数を数え、年間の求人件数を掛けてください。価格論争を決めるのはその1つの数字であり、表示価格ではありません。

## 双方の注意点

**Pin：エビデンスの土台が薄いです。** 候補者承諾率83%、平均充足日数14日、アウトリーチ返信 5 倍という数字はすべて「Pin の2026年ユーザー調査」に由来しますが、サンプルサイズも選定基準も公開されていません。4.8/5 という評価も27件の認証レビューに乗っているだけです。*ガード：* 稼働中の求人2件で30日間の有料パイロットを回し、自社の返信率と初回面接までの日数を現在のベースラインと比べてください。それらの数字がビジネスケースに入るのはその後です。

**Pin：ID 系アドオンがプラン1段分の価格です。** SSO/SAML と SCIM がそれぞれ月 $150、つまりシート費用の上に年 $3,600 が乗り、しかも購入できるのは Professional と Business だけです。*ガード：* セキュリティレビューが両方を求めるなら、見積もり時点で発注書に入れ、シート単価ではなく総額で比較してください。

**Pin：統合が進む市場で、25人・調達 $3M です。** Workday は [Paradox](/ja/tools/paradox/) を、SAP は SmartRecruiters を買収しました。吸収されるのは、まさにこの規模の単独ベンダーツールです。*ガード：* 契約前に ATS への書き戻しが動いていることを確認してください。ベンダーに何が起きても、候補者とアウトリーチの履歴が自社が保有するシステムに残るようにするためです。

**Juicebox：シート価格は製品の価格ではありません。** ピッチの主役はエージェントであり、それは $199 の別行です。*ガード：* シートとエージェントを1つの数字として見積もってください。エージェントなしの Starter で試すのは検索窓を試しているだけで、実際に買う対象を試してはいない、と理解した上で進めることです。

**Juicebox：ATS と CRM の同期は上位プランにあります。** ベンダーは、連携は上位プランで利用可能であり、代替手段は CSV エクスポートだとしています。*ガード：* Starter を買う前に、自社の ATS が41のうちに入っているか、どのプランに載っているかを確認してください。さもないと候補者をスプレッドシートで動かすことになります。

**Juicebox：面接を予約するものが何もありません。** *ガード：* プロセスが漏れている場所がカレンダーなら、[GoodTime](/ja/tools/goodtime/) や [Modernloop](/ja/tools/modernloop/) のようなスケジューリング層を予算化するか、コーディネーターの人員を維持してください。そのコストを Juicebox 側に足してから、2つの見積もりを比較することです。

## 結論

**Pin を選ぶ**のは、漏れているのが工程間の引き継ぎである場合です。10〜200人規模の企業で同時に1〜10件の求人を回し、コーディネーターがおらず、シーケンスをショートリストではなくカレンダー招待で終わらせたい社内 TA リードや、自ら採用する創業者が該当します。加えて、MCP クライアントから操作できるのは2つのうちこちらだけです。チームがすでに Claude Code や Cursor の中で働いているなら、この点が効いてきます。

**Juicebox を選ぶ**のは、漏れているのがファネルの上流である場合です。適切な40人を見つけること自体が仕事のすべてで、公開シグナルがビジネス SNS の外にある難易度の高い技術職・研究職。開示件数が多く、従量クレジットが実質的な予算リスクになるチーム。そして、ベンダーの継続性が好みではなく調達要件になっている案件が該当します。

**どちらも選ばない**のは、制約がインバウンドの量である場合です。1求人あたり数百件の応募があり、スクリーニングのスループットがボトルネックになっているなら、それはソーシングではなく会話型のトリアージであり、[Paradox](/ja/tools/paradox/) の領域です。同様に、数千人規模の従業員に対する社内タレントとダイバーシティの分析が必要なら、判断は [SeekOut](/ja/tools/seekout/) と [Gem](/ja/tools/gem/) の間にあります。[SeekOut vs Gem](/ja/vs/seekout-vs-gem/) を参照してください。どちらの製品も ATS ではありません。選んだほうを [Greenhouse](/ja/tools/greenhouse/)、[Ashby](/ja/tools/ashby/)、[Lever](/ja/tools/lever/) と組み合わせ、その境界が曖昧なら [ATS と採用 CRM の違い](/ja/learn/ats-vs-recruiting-crm/) を読んでください。

決めきれないなら、既定は Pin です。どちらの無料プランも単独で決着をつけるには薄すぎるので、判断軸は「どちらの間違いが高くつくか」になります。Pin を既定にすると、高くつく失敗——誰もシーケンスを回さなかった良いショートリストと、誰も予約しなかった面接——を防げます。Juicebox を後から発見層として足すのは加算的な買い物で、検索のリコールが本当の制約だと分かってから実行できます。一方、年度の途中で自社のソーシングツールがショートリストで止まると気づけば、アウトリーチとスケジューリングも買い足すことになります。これらのデータベースにできること・できないことは [AI ソーシング](/ja/learn/ai-sourcing/) で扱っています。
