[Claude](/ja/tools/claude/) と [Perplexity](/ja/tools/perplexity/) は、どちらも $20/月から始まり、どちらもテキストボックスに打ち込んだ質問に答えるという理由で比較されます。その枠組みは2026年に賞味期限を迎えました。Perplexity は自社製の MCP サーバーを提供するようになり、本当の判断はもはや「どちらの製品を契約するか」ではありません。「Perplexity を2つ目のライセンスとして買うのか、Claude の中にツールとして入れるのか」です。この2つは ChatGPT と Perplexity にはできない形で組み合わさり、それに気づいた時点で計算が変わります。

## 前回版からの変更点

**Perplexity は呼び出せる存在になりました。** `@perplexity-ai/mcp-server` パッケージが Perplexity の Search API と Agent API に対して4つのツール — `perplexity_search`、`perplexity_ask`、`perplexity_research`、`perplexity_reason` — を公開します。Claude、Claude Code、あるいは任意の MCP クライアントが、誰も perplexity.ai を開かないまま出典付きの Web リサーチを実行できます。`console.perplexity.ai` の API キーが必要で、Pro ライセンスとは別に課金されます。

**Perplexity の価格帯は上下両方向に伸びました。** Max は $200/月で着地し、Model Council — 1つのクエリを複数のフロンティアモデルに投げて回答を統合する機能 — が付きます。Enterprise Max は $325/ライセンス/月です。反対側の端では、Comet ブラウザが2026年3月に有料の壁を撤廃し、現在は Mac、Windows、iOS、Android で無料で動きます。

**Claude のロングコンテキストの話は、大きくなったのではなく正確になりました。** 1M トークンのウィンドウは Claude 4.6 以降のモデルでデフォルトであり、ベータヘッダーもロングコンテキストの割増料金も不要です。900k トークンのリクエストは 9k のリクエストと同じトークン単価で課金されます。ただしこれは API の性質です。claude.com/pricing は個人向けプランに 200k のウィンドウを表示しています。このページの前回版はチャット製品側に 1M のウィンドウがあるかのように書いていました。それは誤りであり、ここで訂正します。

**Claude は2つ目のエージェント面を得ました。** Cowork — リポジトリではなくあなたのファイルと接続済みアプリを対象に、ファイルシステムのレベルで動くエージェント — が2026年1月にデスクトップで出荷され、7月に Max 契約者向けに Web とモバイルへ届きました。

この非対称性がページの全てです。Perplexity はサーバーです。Claude はクライアントです。ChatGPT との比較ではこれが膠着を生みますが、ここではスタックを生みます。

## Claude が勝つところ

- **他のどこにも収まらない文書。** 標準価格での 1M トークンウィンドウに加え、1リクエストあたり最大600枚の画像または PDF ページ。契約書だらけのデータルームや四半期分のコール文字起こしをカバーします。Perplexity は Web に手を伸ばすために作られており、あなたのコーパスを抱えるためではありません。
- **オーケストレーションする側の部品である。** Claude Code、Cowork、Skills、MCP クライアント、Agent SDK は、あなたがプログラムする runtime です。Perplexity のエージェント面はブラウザと API — どちらも良い製品ですが、あなたはその中ではなく周りに作ることになります。
- **回答ではなく成果物。** レッドライン、初稿、動くコード、下流の誰かが消費するスキーマへの構造化抽出。Perplexity の統合は問いを解決するようにチューニングされており、それは別種の output です。
- **もう一方を呼び出せる。** Perplexity が Claude Code を実行する構成は存在しません。

## Perplexity が勝つところ

- **引用は製品の形そのものであり、切り替えるモードではない。** 法務責任者、規制当局、取締役会に向かうメモにとって、これは転送されても仕事が生き残るかどうかを決めます。
- **Spaces。** ソースをピン留めしたリサーチプロジェクトがセッションをまたいで残り、同僚に引き渡せます。Claude の Project も近いですが、Space は指示ではなくソースを中心に組まれています。
- **ページ上にアシスタントがいる無料ブラウザ。** Comet は4つのプラットフォームで無料です。Claude のラインナップにこの面を占める製品はありません。
- **リクエスト単位で買える retrieval。** Sonar は Web リサーチを従量課金の容量として売ります。そのリサーチを消費するのが人ではなくエージェントなら、ライセンスは単位として間違っており、正しい単位を売っているのは Perplexity です。
- **Internal Knowledge Search。** Enterprise 帯では自社ドキュメントがライブ Web と同じ回答の中に並び、学習に使わない保証が付きます。

## 価格の実際

入口は本物の引き分けで、そこから階段はすぐに分かれます。

- **個人** — Claude Pro は $20/月、または年額請求で $17/月（$200 前払い）。Perplexity Pro は $20/月、$200/年。どちらの請求方式でも引き分けです。
- **欠けている中間段。** Claude Max は Pro の5倍の利用量で $100/月から始まり、20倍で $200/月に達します。Perplexity は $20 から $200 へ直接跳び、間に何もありません。利用量が Pro ライセンス3つ分なら、それに合う段を売っているのは片方だけです。
- **チームライセンス** — Claude Team の標準は $25/ライセンス/月、年額請求で $20。プレミアムライセンスは $125/月、年額で $100。Perplexity Enterprise Pro は $40/ライセンス/月（$400/ライセンス/年）。標準段ではおよそ2倍 Claude 有利で、Perplexity の上乗せが買っているのは Internal Knowledge Search と学習に関する保証です。
- **階段の最上段** — Perplexity Enterprise Max は $325/ライセンス/月（$3,250/ライセンス/年）という固定の大きな数字です。Claude Enterprise は $20/ライセンスに加えてモデル利用分すべてを API 料金で課金します。床は低く、天井はチームの使い込み方が決めます。課金の形が違うので、利用量の見積もりなしにライセンス単価を比べても意味がありません。
- **従量** — Sonar はベース帯でおよそ $1/100万トークン、Sonar Pro は入力 $3 / 出力 $15 per 100万トークン、加えて Web 取得リクエスト1,000件あたり約 $5-12。Claude の API は Opus 5 と Opus 4.8 が $5/$25 per 100万トークン、Sonnet 5 が2026年8月31日まで $2/$10、以降 $3/$15、Haiku 4.5 が $1/$5。Web 検索は1,000検索あたり $10、web fetch はトークン以外の追加費用なし、Batch API は両方を半額にします。Sonar Pro と Sonnet は同じ $3/$15 に着地します。違いは、retrieval を請求してくるのがどちら側かという点です。

個人ライセンス2つで $40/月です。ほとんどの人が見落とす安い構成は、$20 の Claude Pro ライセンス1つに従量課金の Perplexity キーを足すことです。これで出典付きの retrieval が、すでに仕事をしているツールの中に入ります。

## 導入の手間

チャット製品としての Claude には何も要りません。エージェントとしての Claude — MCP サーバー、Skills、サービスアカウント、何に書き込んでよいかのレビュー — は日単位で測る本物のプロジェクトであり、見積もるべき費目はライセンス数ではなくトークン請求です。

アプリとしての Perplexity にも何も要りません。Claude の中の MCP サーバーとしての Perplexity は、API キー1つと設定エントリ1行、1時間未満です。加えて、それまで存在しなかった従量請求が1本増えます。Enterprise の Internal Knowledge Search だけが、ここで本物のコネクタプロジェクトになる部分です。

## 注意点

- **1つの仕事に二重で払う。** Perplexity の MCP サーバーを Claude の中で動かしながら Perplexity Pro のライセンスも維持すると、同じリサーチにライセンスとメーターの両方を払うことになります。*ガード：*1人につき1つの面を割り当て、ライセンス更新の前に初月末の API コンソールの支出を読むこと。
- **ループの中の従量 retrieval。** Web 取得料金はセッション単位ではなく呼び出し単位で発生するため、リトライするエージェントは失敗しながら課金し続けます。*ガード：*無人で動くものに繋ぐ前に、API キーに支出上限を設定すること。
- **1M のウィンドウを 1M の正確さと取り違える。** コンテキストウィンドウが埋まるにつれて recall は劣化します。Anthropic 自身のドキュメントがこれを名指しし、詰め込むより compaction を推奨しています。*ガード：*入れるものを選別し、アーカイブ全体ではなくソース文書を渡すこと。
- **引用の演出。** どちらの製品も、貼り付けられた主張を支えていないページを含むソース一覧を返します。*ガード：*数字を伴う引用はすべて、成果物が手を離れる前にクリックして確認すること。

## 結論

- **Claude を選ぶ** のは、output が成果物 — 草案、レッドライン、抽出、スクリプト — である場合、または input が誰も読みたがらない長さである場合です。
- **Perplexity を選ぶ** のは、output が出所を問われる回答である場合、または技術者でないリサーチャーがチャットウィンドウではなく Spaces と Comet を必要とする場合です。
- **1つだけ選ぶ、予算行は1本という条件なら：$20/月の Claude Pro、そこに従量課金キーで MCP サーバー経由の Perplexity を足す。** これで仕事をしているツールの中に出典付きの retrieval が入り、2つ目のライセンスは丸ごと不要になります。逆にするのは、その人が一日の大半をリサーチに使い、構築には一切使わない場合だけです。
- **$40/月の2ライセンス** は、リサーチする人と構築する人が別人の場合です。
- **どちらでもない** のは、答えがオープンな Web ではなく自社システムの中にある場合です。それはエンタープライズ retrieval の問題であり、候補は [Gemini Enterprise](/ja/tools/gemini/) と [Glean](/ja/tools/glean/) です。オープン Web の検索が仕事のすべてなら、[最良の AI 検索エンジン](/ja/vs/best-ai-search-engines/) が正しいページです。実際に置き換えようとしている相手が OpenAI なら、代わりに [ChatGPT vs Perplexity](/ja/vs/chatgpt-vs-perplexity/) を読んでください。
