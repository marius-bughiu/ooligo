## 概要

Retell AI は、AI 電話エージェントを構築するための開発者向けプラットフォームです。プロンプトを書くか通話フローを描き、LLM と音声を選び、電話番号または自社の SIP トランクを接続し、接続された分数に応じて支払います。位置づけは Vapi と同じ「自分で作る」レイヤーで、PolyAI や Parloa のようなマネージドサービスのレイヤーではありません。Retell が渡すのは音声パイプライン、電話回線、テストツールであり、エージェントを持つのは自社のチームです。2023年に創業し、Y Combinator (2024年冬バッチ) の支援を受け、Palo Alto を拠点に CEO の Bing Wu が率いています。

候補リストに載る理由は成長です。Retell は 2025年12月に月間 4,000万件超の通話を報告し、Brex は 2026年夏のベンチマーク (2026年8月17日) で同社を最も成長が速いスタートアップ Top 25 に選びました。Sacra は 2026年8月時点の年換算売上をおよそ 8,000万ドルと推定しており、2025年末の約 4,500万ドルから増えています。開示済みの調達額は約 510万ドルで、すべて 2024年のシード資金です。これらの売上数値は第三者の推定であり、会社の提出書類ではありません。

## CX・サポートのスタックで採用される理由

- **本物のエージェントを本物の電話回線に載せる最も安い方法。** 音声インフラ、GPT・Claude・Gemini から選べるモデル、Twilio または Telnyx の番号が 1 つのメーターで請求され、従量課金ではプラットフォーム料金も年間契約もありません。サポートチームは営業時間外の回線や予約受付エージェントを、四半期ではなく数日で本番稼働させられます。
- **構築方法は 2 つ、通話の種類ごとに 1 つ。** シングルプロンプトのエージェントは自由な会話を扱います。Conversation Flow はノードベースのビルダーで、本人確認、決済、受付といった構造化された重要度の高い通話向けです。ウォームトランスファー、IVR ナビゲーション、DTMF 入力の取得を標準で備えます。
- **QA はサンプルではなく全通話に。** 2025年12月17日に発表され 2026年1月1日から提供されている Retell Assure は、遅延、割り込み、ハルシネーション、感情について通話の 100% をスコアリングします。人間の QA チームが確認するのは通常 1-2% の通話です。Retell を「デモツール」から「コンタクトセンターのツール」へ押し上げるのはこの機能です。
- **エージェントが自社の MCP サーバーを呼び出せる。** MCP Node (2025年7月) により、音声エージェントは通話中に任意の MCP または HTTP サービスを呼び出せます。すでに MCP で公開している社内の注文照会サービスには、専用コネクタなしで到達できます。向きに注意してください。これはエージェントが自社のツールを使えるという意味で、Claude から通話データを問い合わせるための公式 Retell MCP サーバーがあるという意味ではありません。
- **コンプライアンスはセルフサーブ。** SOC 2 Type 1 と Type 2、HIPAA、GDPR が文書化されており、BAA と DPA は交渉ではなくオンラインで署名できます。そのため、小規模なクリニックグループがエンタープライズ契約なしに PHI を扱う用途で導入できる、数少ないプラットフォームの 1 つです。

## 価格の実態

定価は 1 分あたり $0.07–$0.31 で、この幅の中に判断が隠れています。価格ページの内訳は、音声インフラが $0.055/分、Retell のプラットフォーム音声が $0.015/分 (ElevenLabs の音声は $0.04–$0.10)、Retell が提供する電話回線が $0.015/分 (カスタム SIP は無料)、これに LLM が加わります。GPT 5 mini は $0.008/分、Claude 5 Sonnet または GPT 5.6 Terra は $0.064/分、GPT 5.5 は $0.16/分です。プラットフォーム音声、Retell の番号、中位モデルという標準的な構成では、**すべて込みで 1 分あたり約 $0.15** になります。小型モデルを使う低予算構成では約 $0.09、プレミアム音声とフロンティアモデルの組み合わせでは $0.30 を超えます。

さらにアドオンがあります。ナレッジベースは +$0.005/分、PII 削除は +$0.01/分、AI QA は最初の 100 分の無料枠の後 $0.10/分です。標準的な構成で全分数に QA をかけると、レートはおよそ 3 分の 2 上がります。多くのチームがすべてではなくサンプルをスコアリングするのはこのためです。同時接続は 20 通話まで無料で、それを超えると同時接続 1 通話あたり月 $8 です。

月 100,000 分の場合、標準的な構成で QA 前に月約 $15K、年間でおよそ $180K です。エンタープライズ価格は個別見積もりで、同時接続 50 通話以上から始まり、ボリュームディスカウントと専任の導入支援はここで提供されます。

## こんなチームに向く

エージェントを他のサービスと同じように担当するエンジニアが少なくとも 1 人いるサポート、CX-ops、RevOps チームです。インバウンドのサポート回線、予約スケジューリング、リードの選別、アウトバウンドのリマインダーを、月およそ 5,000 分から 500,000 分の規模で構築するケースで、分単位課金が 6 桁のエンタープライズ契約より有利になります。

チームに webhook を書いたりツール呼び出しをデバッグしたりできる人がいない場合、エージェントの設計と運用をベンダーに任せたい場合、あるいはコンタクトセンターがすでに NICE、Genesys、Five9 で動いており、それらのネイティブ AI が自社の containment 基準を満たす場合は見送ってください。

## 代替候補との比較

**[Vapi](https://vapi.ai)** は開発者向け音声プラットフォームにおけるもう 1 つの定番で、資金力はこちらが上です。2026年5月に 5,000万ドルのシリーズ B を実施し、処理した通話は 10 億件を超えます。$0.05/分がカバーするのはオーケストレーションのみで、音声認識、LLM、音声、電話回線は別請求です。そのため始めるのは安く、予測は難しくなります。HIPAA も自分で署名できるものではなく有料アドオンです。エンジニアがスタックのあらゆる構成要素を入れ替えたいなら Vapi、予測しやすい 1 つのメーターと組み込みの QA が欲しいなら Retell を選んでください。

**ElevenLabs Agents** は最も成長が速い新規参入で、ElevenLabs の ARR 5億ドル超を追い風にしています。音声品質と言語カバレッジがプロジェクトの決め手なら ElevenLabs Agents です。**Synthflow** はノーコードの選択肢で、現在は年間約 3万ドルからのエンタープライズ契約もあります。構築者がエンジニア以外でなければならないなら Synthflow を選んでください。デリバリーをベンダーに任せたいなら、マネージド型を買ってください。医療やホスピタリティの記録システムなら [PolyAI](/ja/tools/polyai/)、EU の金融サービスなら [Parloa](/ja/tools/parloa/)、1 つのエージェントがチャットと音声の両方で取引を実行する必要があるなら [Sierra](/ja/tools/sierra/) です。

どれも合わないなら、何かを買う前に Retell の $10 の無料クレジットを、通話量が最も多い 1 つのインテントに当ててください。1 インテントのパイロットは、どんなベンダー比較よりも多くのことを教えてくれます。

## 注意点

- **見出しのレートは自社のレートではありません。** $0.07 は最も安い音声を前提とし、LLM と電話回線を含みません。ガード: モデル、音声、番号の調達元、アドオンという自社の構成そのものを価格ページで見積もり、推定値ではなくパイロットで計測した平均処理時間を掛けてください。
- **従量課金のサポートはコミュニティとメールです。** レビューでは、対応の遅さや本人確認中のアカウント保留が繰り返し指摘されています。1 週間止まる音声回線は障害そのものです。ガード: ローンチ前に本人確認を完了させ、IVR に人間へのフォールバック番号を残し、その回線が売上に直結する通話を担う前に、担当者付きサポートのあるエンタープライズ契約へ移行してください。
- **遅延の数値は自己申告です。** Retell 自身の 2026年3月のベンチマークでは応答は約 600ms ですが、これを裏付ける独立したベンチマークはなく、フロンティア LLM やプレミアム音声を使えば遅延は増えます。ガード: 選んだモデルと音声でパイロット中にエンドツーエンドの遅延を計測し、モデルのダウングレードを発動させる閾値を設定してください。
- **規模に比べて資本が薄い会社です。** 調達額約 510万ドルに対して推定売上ランレートが 8,000万ドルということは、事業を支えているのは収益性であり、資金調達や買収があれば条件が変わる可能性があります。ガード: エージェントのプロンプト、フロー、ツールスキーマは API 経由で自社のリポジトリにエクスポートしておき、電話回線は自社の Twilio または Telnyx の SIP トランクで運用して、番号を自社と一緒に移せるようにしてください。
