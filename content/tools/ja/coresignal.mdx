## 概要

Coresignal は公開 Web データのプロバイダーで、企業、従業員、求人、SNS 投稿のレコードを、コードを書く人向けに販売しています。料金ページに掲載されている同社自身の数字は、企業レコード 70M 件以上、従業員プロフィール 907M 件以上、求人 482M 件以上です。これらを複数のソース（ビジネス SNS、Glassdoor、Indeed、Owler、Craft など）から統合し、企業 600 項目以上、従業員 300 項目以上の「multi-source」レコードにまとめています。2016 年にフラットファイルの一括提供から始まり、2023 年 7 月にセルフサーブ API を開始しました。現在は従業員 80 名以上、AI 検索、HR テック、セールステック、市場調査の分野で 1,000 社以上の顧客がいるとしています。コンプライアンスページに記載されている契約主体は、デラウェア州法人の Deeptrace Inc. です。

Coresignal は営業担当者向けのプロスペクティングアプリではありません。営業担当者向けのリストビルダー、シーケンサー、Chrome 拡張機能、CRM 同期はありません。ダッシュボードの AI Data Search を使えば技術者でなくてもリストを作成してエクスポートできますが、価格設定もドキュメントもデータパイプライン、データウェアハウス、エージェント向けに作られています。

## 今 RevOps のスタックに登場する理由

- **エージェントから直接呼び出せます。** Coresignal MCP v2 は `https://mcp.coresignal.com/mcp/v2` でホストされ、streamable HTTP と OAuth ログインで接続するため、設定ファイルに API キーを置く必要がありません。[Claude Code](/ja/tools/claude-code/)、Codex、[Cursor](/ja/tools/cursor/)、OpenCode、Antigravity CLI のセットアップページがあります。ツールの料金はドキュメントに明記されています。`entity_search` は検索 1 回 20 クレジット、`entity_fetch` はレコード 1 件 1-20 クレジット、`email_enrich` は見つかったメール 1 件 10 クレジットで、高額な取得の前にはサーバーが確認を求めます。
- **Agentic Search API（2026 年春）。** 従業員、企業、求人を自然言語で検索できます。`/fast` は 1 回 20 クレジット、`/reasoning` は 100 クレジットで 1 時間 10 リクエストが上限です。2026 年 10 月にエンティティの自動判定が加わりました。
- **ネイティブの [n8n](/ja/tools/n8n/) ノード。** 企業検索、Web サイトによるエンリッチ、collect 操作に加え、従業員、求人、従業員投稿の collect と検索に対応し、最大 20 件を返すプレビューモードがあります。Company Posts はまだノードに含まれていません。
- **投稿とシグナル。** Employee Posts データセットが 2025 年、Company Posts が 2026 年 6 月（API は 7 月）、企業 Webhook と Contact Enrichment API が 2026 年 10 月に追加されました。これにより、静的なレコードの保管庫が、トリガーをかけられるフィードに変わります。

## 料金

本日 coresignal.com/pricing と料金ドキュメントで確認しました。すべての API に共通のクレジットが 1 種類あり、フィルターと Elasticsearch DSL のエンドポイントでの検索は無料で、collect または enrich の時点で課金されます。

- **無料トライアル：** 7 日間 2,000 クレジット、企業メールのドメインごとに 1 回。クレジットは有料プランに引き継がれません。
- **月額セルフサーブ：** Mini $49（2,500 クレジット）、Starter $199（12,000）、Pro $499（35,000）、Growth $1,000（150,000）、Premium $1,500（1,000,000）、Scale $3,000（4,000,000）、Elite $5,000（10,000,000）。クレジットは毎月リセットされ、Premium 以上では未使用分が 3 か月繰り越されます。年額払いは Starter 以上で 10% 割引、前払いです。
- **1 レコードあたりのクレジット：** 求人または投稿は 1、multi-source の企業・従業員レコードは基本項目で 10、全バンドルで 20、ヘッドカウント履歴は 10、従業員のリアルタイム取得は 12（Growth 以上のみ）、メールは 10 です。
- **データセット：** JSON、JSONL、Parquet での一括提供で年間契約、月額 $1,000 から。

実際のコスト：CRM の 10,000 アカウントを完全な企業レコードでエンリッチすると 200,000 クレジットになり、Growth を超えて月額 $1,500 の Premium が必要です。キーを基本項目に絞れば同じ作業は 100,000 クレジットで、月額 $1,000 の Growth に収まります。定価で計算すると、完全なレコード 1 件は Mini で約 $0.39、Growth で $0.13、Premium で $0.03 です。比較として、[People Data Labs](/ja/tools/people-data-labs/) は 350 人分のクレジットで $98 から（1 マッチ約 $0.28）、[Crustdata](/ja/tools/crustdata/) はクレジット単価を公開していません。

## 最適なユーザー

データウェアハウス、エンリッチメントパイプライン、エージェントに、ファーモグラフィック、従業員、求人のデータを大量に取り込む必要があり、公開されたレコード単価を求める RevOps エンジニア、データチーム、GTM エンジニア。最も相性が良いのは採用シグナルとヘッドカウントの分析です。求人 1 件 1 クレジット、API でのヘッドカウント履歴により、「どのアカウントがこの職種を採用していて、どれだけの速さで成長しているか」が安価なクエリで済みます。

## 向いていないユーザー

データベースをクリックで探してシーケンスを送りたい営業担当者には [Apollo](/ja/tools/apollo/) を使ってください。携帯電話番号が必要なチームにも向きません。Coresignal のドキュメントにはメールのエンリッチはありますが、電話番号の製品はありません。セキュリティ審査で SOC 2 レポートが必須の購入者にも向きません。

## 代替ツールとの比較

- **[ZoomInfo](/ja/tools/zoominfo/)**：カテゴリーのシェア首位で、営業担当者向け UI、インテントデータ、電話番号を個別の年間契約で提供します。ユーザーが営業担当者なら ZoomInfo を選んでください。データを使うのがコードで、シート単位ではなくレコード単位で払いたいなら Coresignal です。
- **[Apollo](/ja/tools/apollo/)**：もう 1 つのシェア首位で、データベース、シーケンサー、ダイヤラーをシート課金の 1 つのアプリで提供します。人が手作業でプロスペクティングするなら Apollo を選んでください。シート課金が意味をなさない、大量かつプログラムによる企業・求人データには Coresignal です。
- **[Clay](/ja/tools/clay/)**：セグメントで最も急成長しているプラットフォームで、競合というより上に乗るレイヤーです。多数のプロバイダーを[ウォーターフォール](/ja/learn/waterfall-enrichment/)で実行します。オペレーターがテーブル上でエンリッチを設計し CRM 同期を求めるなら Clay を選んでください。1 社のプロバイダーで大半の行をカバーでき、自分でコードを書けるなら Coresignal を直接購入してください。
- **[People Data Labs](/ja/tools/people-data-labs/)**：ID 解決、幅広い人物データのエンリッチ、SOC 2 レポートが必要なら PDL です。求人、投稿、ヘッドカウント履歴の深さを、中位プランでより低いレコード単価で得たいなら Coresignal です。
- **[Crustdata](/ja/tools/crustdata/)**：アウトリーチの瞬間に、エージェントがライブの再取得と転職 Webhook を必要とするなら Crustdata です。公開されたプラン価格と一括データセットを求めるなら Coresignal です。
- **[Sumble](/ja/tools/sumble/)**：どのアカウントが特定の技術を使っているかを求人の本文から答えたい、生のレコードではなく UI が欲しいという場合は Sumble です。

## 注意点

- **プランを決めるのはレコード数ではなくバンドルです。** 完全なレコードは基本レコードの 2 倍のコストがかかり、Growth（150,000 クレジット）から Premium（1,000,000）への移行では、価格 1.5 倍でクレジットが 6.7 倍になります。対策：購入前に API キーのバンドルを、パイプラインが実際に読む項目だけに設定し、レコード数にそのクレジット単価を掛け、合計からプランを選んでください。Growth をわずかに超えるなら、Premium のほうがクレジット単価もレコード単価も安くなります。
- **API での検索は無料ですが、エージェント用ツールでは無料ではありません。** フィルター検索と DSL 検索は無料ですが、MCP の `entity_search` と Search Preview はそれぞれ 20 クレジット、`/reasoning` は 100 クレジットかかります。自由に探索させたエージェントは、Mini プランを半日で使い切ることがあります。対策：探索的なエージェントのセッションは低いプランの別キーで動かし、フィルターが固まったら繰り返しのクエリを無料の DSL エンドポイントに移してください。
- **データの鮮度はエンドポイントによって異なります。** 競合他社のレビューでは、キャッシュされたレコードが転職から数か月遅れていると報告されています。一方 Coresignal は、API のレコードはリアルタイムで更新されタイムスタンプが付くとしています。対策：今四半期に転職したと分かっている連絡先のレコードを 200 件取得し、タイムスタンプと現在の勤務先を確認してください。時間に敏感なトリガーは、Growth 以上が必要な Real-time Employee API に回してください。
- **コンプライアンスは自己申告です。** Coresignal は Ethical Web Data Collection Initiative の認定メンバーであり、ISO 27001 に「正式な認証なしで」準拠しているとしています。サイトには SOC 2 レポートの記載がなく、`email_enrich` は EEA と英国の人物を除外します。対策：契約前にセキュリティ質問票と DPA の依頼を送ってください。欧州に販売するなら、Coresignal のメールを当てにせず、GDPR に準拠した別の連絡先ソースを計画してください。企業項目が何を代替でき何を代替できないかは[ファーモグラフィックデータ](/ja/learn/firmographic-data/)を参照してください。
