## O que é

Cursor é o IDE AI-native que se tornou o ambiente de coding default pra engineers construindo agentes, servidores MCP e o lado técnico da automação de ops. Forkado do VS Code, com integração profunda de IA: tab-completion, modo agente, contexto em nível de codebase e suporte completo a servidores MCP.

## Por que aparece em stacks de RevOps

Essa é pra GTM engineers e o lado técnico de RevOps — não é uma ferramenta pra organização de AE. Mas cada time de RevOps construindo workflows custom, nós de n8n, servidores MCP, apps internas ou código Apex do Salesforce faz esse trabalho cada vez mais no Cursor. A combinação modo agente + MCP significa que você pode plugar o Cursor no Salesforce, HubSpot, Snowflake, no seu data warehouse, e fazer ele escrever código que opera sobre seus dados ao vivo.

- **Modo agente.** Agente de coding multi-step que planeja, edita e roda código com sua supervisão. Mais rápido que Claude Code pra maioria das tarefas; comparável pra refactors complexos.
- **Contexto de codebase.** Indexa seu repo inteiro e usa como contexto. Pra mono-repos de RevOps com integrações custom, scripts e SQL, isso importa.
- **Suporte a servidores MCP.** Plugue qualquer servidor MCP no Cursor — Salesforce, HubSpot, Linear, seu CRM-de-escolha — e a IA pode ler/escrever dados enquanto escreve código que usa eles.
- **Cursor rules.** Convenções por projeto codificadas como arquivos `.cursorrules`. Viram o lugar canônico pra documentar "como construímos automações aqui".

## Pricing

- **Free** — requests de IA diários limitados
- **Pro** — $20/usuário/mês, uso generoso de IA
- **Business** — $40/usuário/mês, inclui controles de admin, SSO, modo privacidade
- **Enterprise** — custom

Acesso à API não é exposto; Cursor é consumido inteiramente via IDE.

## Melhor para

- GTM engineers, RevOps engineers e pessoal técnico de ops escrevendo código custom
- Times adotando MCP — Cursor é o IDE mais polido entre os que são MCP-aware
- Solopreneurs e times pequenos rodando workflows de vibe-coding; o modo agente cuida da maioria das tarefas end-to-end
- Quem já experimentou Copilot, Continue ou Codeium e quer algo notavelmente mais rápido + mais inteligente

## Pontos de atenção

- O modo privacidade é opt-in (tier Business e acima). Pra ambientes regulados, cheque os defaults de retenção de dados antes do rollout.
- Melhor em codebases grandes — pra scripts de um único arquivo, o overhead vs. Claude Code ou claude.ai é real
- A organização de engineering pode já ter uma preferência de tooling (Copilot, Cody, Continue). Não é uma briga que RevOps quer comprar.
