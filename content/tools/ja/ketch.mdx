## 概要

Ketch は、ひとつの仕事を中心に作られたプライバシープラットフォームです。消費者の同意やオプトアウトを一度だけ取得し、その人のデータが流れるすべての場所で執行することです。2020年に Tom Chavez と Vivek Vaidya が自らのスタートアップスタジオ super\{set\} から創業し、2021年に CRV と Acrew Capital がリードした2回のラウンドで合計4,300万ドルを調達しています。中核製品は同意管理プラットフォーム（バナー、プリファレンスセンター、法令別テンプレート、トラッカースキャン、タグのオーケストレーション、同意記録）です。その上に、DSR 自動化、データマッピング、リスク評価、マーケティングのプリファレンス管理を、別料金のモジュールとして販売しています。

現在購入できる内容は、2026年の3つのリリースで決まります。

- **Opt-Out Sync**（2026年1月14日）は、Cookie バナー、オプトアウト用 Web フォーム、ID 解決、バックエンドでの執行をひとつのフローにつなぎます。どちらの入口で行われた「Do Not Sell or Share」の選択も、CRM、CDP、広告プラットフォーム、パートナーのシステムへ送られ、各オプトアウトがどこで適用されたかを ID ベースのログで確認できます。
- **Marketing Preference Management**（2026年3月11日）は、メールやチャネル別の購読設定を同じ同意記録にまとめます。料金は連絡先数に応じて決まります。
- **Ketch Agent Network**（2026年5月下旬発表）は、データマッピング（システムを発見し、ベンダー契約や DPA を読み込んで処理活動の記録を作る）、リスク管理（稼働中の設定を規制や社内ポリシーと照合する）、評価（DPIA、PIA、TIA、AI 影響評価を事前入力し、質問を担当分野の専門家へ回す）のエージェントを追加します。

Ketch は3,500以上の消費者ブランドにサービスを提供し、月に672億件の同意トランザクションを処理していると述べています。どちらの数字もベンダー発表で、第三者による検証はされていません。

## Legal Ops のスタックに入る理由

- **罰金が発生するのはオプトアウトの執行です。** Opt-Out Sync の発表は Honda、Healthline Media、Jam City の和解を挙げ、規制当局が摩擦がなく漏れのないオプトアウトのフローを求めている証拠だとしています。ad tech 全体にわたるカリフォルニア型の Do Not Sell 義務があなたのリスクであれば、Ketch はまさにその問題のために作られており、プライバシープログラム管理の側を担う製品ではありません。
- **[OneTrust](/ja/tools/onetrust/) に対する、より安い2社目の見積もりになります。** Ketch は OneTrust からの移行プログラム「Ketch Switch」を用意しており、誰を置き換えようとしているかは明らかです。
- **マーケティングが主管できます。** 同意、プリファレンス、オプトアウトのフローは、プライバシー責任者だけでなくグロースやマーケティング運用の担当でもあり、Ketch の UX はその共同管理を前提に作られています。

## 実際の料金

Ketch は料金ページを公開している数少ないプライバシーベンダーのひとつです（2026年11月5日に確認）。プランは月間ユニーク訪問者数で決まります。

- **Free：** 0ドル、月5,000訪問者まで、同意管理プラットフォームの全機能、連携2件。
- **Starter：** 月150ドル、月払い、30,000訪問者まで。
- **Plus：** 年払いで月499ドルから（年約6,000ドル）、100,000訪問者まで。DSR の権利対応ワークフローと追加連携はアドオンです。
- **Pro：** 個別見積もり、100,000訪問者以上。DSR 自動化、データマッピング、リスク評価、マーケティングのプリファレンス管理を含む唯一のプランです。

訪問者数の上限を超えると、超過料金ではなく上位プランへ移行します。同意管理以外のモジュールは独自の課金単位を持ち、データマッピングは接続システム数、マーケティングのプリファレンスは連絡先数で課金されます。Pro 契約の価格について信頼できる公開データはなく、Vendr に記録された Ketch の購入は6件だけです。私たちの試算では、同意管理、DSR、データマッピングを含む Pro 契約は年間で5桁ドルの下位から中位に収まり、[TrustArc](/ja/tools/trustarc/) の Vendr 中央値15,120ドルと同じ水準です。どの項目が更新時の値上げを引き起こしているかがわかるよう、モジュール別・課金単位別に分けた見積もりを求めてください。

## 最適な利用者

ad tech のリスクを実際に抱える消費者ブランド（小売、メディア、サブスクリプション、フィンテック）のプライバシー責任者またはマーケティング運用の責任者で、Do Not Sell と同意の選択を CRM、CDP、広告パートナーで執行する必要があり、プライバシー担当が1〜3名のチームです。OneTrust の実際の用途が同意バナーとオプトアウトだけだった企業の乗り換え先にも向いています。

プログラムが評価と規制調査を中心に動いている場合（TrustArc のほうが合います）や、エンジニアリングが本番コードの中で削除と同意を担っている場合（Transcend のほうがその体制に合います）は購入しないでください。ad tech のない小規模な B2B サイトが1つだけなら、無料プランかもっと安い Cookie ツールで足ります。

## 代替製品との比較

**[OneTrust](/ja/tools/onetrust/)** は大差をつけた市場リーダーです。サードパーティリスク、AI ガバナンス、最も幅広いモジュール群をひとつの契約で必要とするなら OneTrust を選んでください。仕事が同意管理とオプトアウトの執行で、エンタープライズ水準より低い公開価格を求めるなら Ketch を選んでください。

**Usercentrics**（Cookiebot）は欧州の大手同意管理専業ベンダーです。多数のサイトに安価で EU 準拠の Cookie バナーを置くなら Usercentrics を選んでください。オプトアウトをタグのブロックだけでなく、バックエンドやパートナーのシステムまで届ける必要があるなら Ketch を選んでください。

**[TrustArc](/ja/tools/trustarc/)** は、評価、Nymity の規制調査、認証がプログラムに必要な場合に勝ちます。

**Transcend と DataGrail** は、ミッドマーケットで最も速く伸びている新興勢力です。エンジニアリングが同意と削除をコードに組み込むなら Transcend、少人数のチームが主に DSR とデータマップを素早く稼働させたいなら DataGrail を選んでください。

**[Vanta](/ja/tools/vanta/)** は、消費者プライバシー法ではなく SOC 2 や ISO 27001 のエビデンスが目的の場合に合います。

## 注意点

- **料金ページがカバーするのは同意管理だけです。** Free、Starter、Plus は同意管理のプランで、DSR、データマッピング、評価が必要になると Pro の個別見積もりになります。*対策：* Plus を契約する前に Pro の全範囲の見積もりを取り、依存する前に上位移行のコストを把握してください。
- **Opt-Out Sync の精度は識別子の質で決まります。** 執行は、ブラウザ、デバイス、システムをまたいで同じ人物を特定できるかにかかっています。G2 のレビューでは、リトライや監視のツールの改善、重複レコードのルールを求める声があります。*対策：* パイロットでテスト用のオプトアウト（ログイン中、ログアウト中、2台のデバイス）を送信し、CRM と主要な広告パートナーのログで1件ずつ適用を確認してください。
- **エージェント機能は新しく、実績がありません。** Agent Network は2026年半ばにリリースされ、発表時に顧客名も利用データもありませんでした。*対策：* エージェントが作ったデータマップや評価は下書きとして扱い、エクスポート前に指名したレビュアーの確認を必須にし、信頼できるまでは人が運用する [DSAR 受付フロー](/ja/workflows/dsar-intake-triage-n8n/) と併用してください。
- **資金調達が古いです。** 最後に公表されたラウンドは2021年で、プライバシーベンダーの統合が進んでいます（Securiti は Veeam へ、TrustArc は Main Capital へ）。*対策：* 支配権変更時の解約権とデータエクスポートの確約を契約に入れ、契約期間は24か月以内にしてください。

G2 での Ketch の評価は200件以上のレビューで4.6/5（Ketch 自身の G2 ウィジェットによる）で、オンボーディングとセットアップの容易さが最もよく挙げられる強みです。同意とオプトアウトの法的な基礎は [法務チームのための GDPR](/ja/learn/gdpr-for-legal-teams/) を参照してください。
