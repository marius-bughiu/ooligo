## Smartlead とは

Smartlead は cold email の送信インフラです。無制限のメールボックスローテーション、組み込みの warmup、返信用の master inbox、そして deliverability ツールを備え、完全な sequencer ではなくアウトバウンドの下に位置するレイヤーとして提供されます。データとコピーは自分で用意し、Smartlead が多数のドメインとメールボックスにまたがって送信を担います。最も近いカテゴリーリーダーは Instantly で、パーソナライズに特化した代替は lemlist です。

## なぜ RevOps スタックに登場するのか

- **すべての tier で無制限のメールアカウント。** 数十のメールボックスとドメインに送信を分散させ、メールボックスあたりの量を低く保てます。lemlist の席課金モデルとは異なり、inbox ごとの料金はありません。
- **API ファーストかつ white-label。** API と webhook が第一級であり、だからこそ代理店や GTM engineer は Smartlead を Clay や n8n のフローに組み込みます。white-label のクライアント workspace（1 つ $29/月）が代理店の標準になっています。
- **deliverability の制御。** SmartDelivery の配信先テスト、カスタムトラッキングドメイン、メールボックスごとのスロットリングが、Apollo や Outreach のような組み込み sequencer が隠す調整つまみを露わにします。

## pricing の実態

リストは $39/月（Base：2,000 件の連絡先、6,000 通の送信）から始まり、$379/月（Unlimited Prime：500K 通の送信、専用 SmartServers）まで上がります。多くのチームは Unlimited Smart（$174/月、年額で $144.50）に落ち着き、無制限の連絡先、150K 通の送信、warmup プールが付きます。年額請求でおよそ 17% 下がります。

プラン料金は請求額の小さい方の半分です。メールボックスは SmartSenders 経由で購入すると 1 つあたり月 $4.50-9（または自前の Google／Outlook を持ち込み）、ドメインは $13-19/年、検証はクレジット課金、SmartDelivery は $49-174/月の別枠です。inbox が 1 桁を超えると、インフラ費用が購読料に並ぶか上回ることがよくあります。プラン価格ではなく、all-in の数字で予算を組んでください。

## こんなチームに最適

- 複数のドメインと数十のメールボックスにまたがって送信する、大量アウトバウンドのチームや代理店（5-25 名の rep、または多数のクライアント workspace を運用する代理店）。
- UI ではなく Clay や n8n からキャンペーンを起動し、送信を API の背後に置きたい GTM engineer。
- すでに別の場所（Apollo、Clay、ZoomInfo）でデータを取得しており、deliverability グレードの送信レイヤーが必要なチーム。

## 代替との比較

Instantly はシェアで首位の代替で、160M 件の連絡先データベースとよりすっきりした UI を同梱します。データ込みで短い ramp を求めるなら Instantly を、API ファーストの制御、white-label の代理店 workspace、半分は無視するであろう同梱データベースなしのメールボックス単位の経済性を求めるなら Smartlead を選んでください。

lemlist はパーソナライズとマルチチャネルの観点で最も成長が速い参入企業です。動的画像、email に加えて LinkedIn のステップがあります。マルチチャネルの sequence と rep レベルのパーソナライズが純粋な送信量より重要なときは lemlist を選んでください。無制限メールボックスの tier がないため、大量送信は月あたり高くつきます。

単一ドメインから月 ~1,000 通未満しか送らないなら、3 つともやめておきましょう。Apollo の組み込み sequencer か既存の engagement ツールですでに足り、インフラレイヤーは無駄な支出になります。

## 注意点

- **公開価格は実コストではありません。** $39-174 のプランは、メールボックス、ドメイン、検証、SmartDelivery が上に積み重なれば請求額の一部にすぎません。対策：コミットする前に、アクティブなメールボックス 1 つあたり月の all-in コストを見積もり、実際にスケールするつもりの inbox 数で計算し直してください。
- **これはインフラであり、データソースではありません。** 組み込みの連絡先データベースはありません。対策：ソーシングには Smartlead を Apollo や Clay と組み合わせ、リードを見つけてくれることは期待しないでください。
- **無制限のメールボックスと warmup だけでは deliverability は直りません。** 共有 warmup プールのレピュテーションは、このカテゴリーのどの vendor でも低下しています。対策：キャンペーンをスケールする前に SmartDelivery の配信先テストを実行し、メールボックスあたりの量を控えめ（1 日あたり 20-30 程度）に保ち、1 つを強く押すのではなくドメインをローテーションしてください。
