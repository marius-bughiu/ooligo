## 概要

Bullhorn は、人材派遣会社、契約リクルーター、サーチファーム向けの ATS 兼 CRM プラットフォームです。自社のために採用するのではなく、クライアント企業のポジションに候補者を紹介する採用セグメントを対象としています。2002年創業で、10,000社以上の採用オペレーションを支え、そのうち 4,500社以上が小規模エージェンシー向けプランを利用しています。コーポレート ATS(iCIMS、Greenhouse、Workable)と分けているのはデータモデルです。単一の採用組織ではなく、多数のクライアント関係、契約ベースの紹介、請求サイクルを前提に設計されています。

2026年に2つの変化がありました。Bullhorn は20年にわたる見積もり専用販売を経て、小規模エージェンシー向けの定価を公開し始めました。そして AI を Amplify という1つの名前に集約しました。2026-05-28 の Engage Boston で、同社は Amplify を9つの名前付きデジタルワーカースキル(Enrich、Match、Screen、Outreach、Present に加えて Prospect、Verify、Audit、Transcribe)へ拡張し、Bullhorn のライブデータに問い合わせて複数ステップのワークフローを起動する自然言語レイヤー Amplify Chat を投入しました。

## なぜ Recruiting スタックに採用されるのか

- **人材派遣会社のワークフロー前提で設計。** レコードモデルは、ユーザーが複数のクライアント企業に候補者を紹介することを前提としています。クライアント管理、契約管理、請求、勤怠管理がファーストクラスのオブジェクトであり、コーポレート ATS に後付けしたモジュールではありません。
- **VMS 連携の深さ。** ベンダー管理システム(VMS)は、大企業が人材派遣ベンダーを管理するためのプラットフォームです。この連携は Fortune 500 クライアントを担当するエージェンシーにとって必須のインフラであり、大手エージェンシーが UI に不満を抱えたまま Bullhorn に留まる理由でもあります。
- **リクルーター CRM の深さ。** 長期サイクルの候補者リレーション追跡、コミュニケーション履歴、紹介履歴、再エンゲージメントのワークフローなど、コーポレート ATS がモデル化する必要のない領域を扱います。
- **AI がレコードの隣ではなくレコード上で動くようになった。** Amplify のエージェント型スキルは Bullhorn 自身のデータに対して実行されます。Engage で公開された数値は個別顧客の自己申告です。Procom は紹介から入社までの成約率が 65% 向上したとし、IDR は週200時間の削減を報告し、初期導入企業はリクルーター1人あたりの紹介成立数が平均 39% 増えたとしています。予算の根拠となる数値ではなく、方向性として読んでください。

## 価格

小規模エージェンシー向けプランは、ユーザー1人あたり月額で公開されています(税別)。

- **Starter — $99/ユーザー/月。** 応募者管理、履歴書パース、クライアント管理、採用サイト付き求人掲載、メール・カレンダー同期、有人サポート。導入支援込み。AI はなし。
- **Core — $165/ユーザー/月。** マーケットプレイス(350社以上の統合済みパートナー)、カスタムフィールドとワークフロー、LinkedIn RSC と Apply Connect、メールサイドバーが加わります。導入支援込み。依然として AI はなし。
- **Pro — 見積もりのみ。** AI が入る最初の階層です。採用 CRM、AI 検索とマッチング、Amplify Chat、AI データエンリッチメント、プロセス自動化、履歴書整形、通話文字起こし、リアルタイム分析、専任アカウントマネージャー。
- **Max — 見積もりのみ。** エージェント型の階層です。エージェント型スクリーニング、マッチング、エンリッチメント、オムニチャネルの候補者エンゲージメント、複数ステップのアウトバウンド、Web サイトチャットボット、面接日程調整。導入支援は込みではなく見積もりの中で個別に見積もられます。

大規模エージェンシーは Front Office Growth、Front Office Enterprise、Bullhorn One を購入し、いずれも見積もりのみです。Onboarding、Middle Office、Messaging、Analytics は規模を問わず別ライセンスです。無料トライアルはありません。

**定価は請求額ではありません。** Bullhorn のページには "No setup fees. No hidden costs" とあり、Starter、Core、Pro の導入支援についてはその通りです。それでもサードパーティの TCO 調査は、10席の初年度を $34,000-$46,100、つまり全部込みでユーザー1人あたり月額およそ $283-$384 と見積もっています。トレーニング(ユーザー1人あたり $100-$500)と別ライセンスのモジュールが乗った後の数字で、更新時の値上げは年 20% 前後、既定では上限なしと報告されています。席数ではなく、モジュールと更新をモデル化してください。

セグメント内の比較では、Loxo が年額請求でユーザー1人あたり月額 $149(Core)と $199(Professional)を公開し、$199 の中にエージェント型ワークフォースと月2,500の共有クレジットを含めています。Recruiterflow はプラットフォームをユーザー1人あたり月額 $149 で公開し、AIRA エージェントは別見積もりです。Bullhorn は3社の中で公開されている入口価格が最も低い一方、AI の価格をまったく公開していない唯一の1社です。

## こんなチームに向く

- **1〜30席の人材派遣会社やサーチファームのオーナー兼実務者、リクルーター。** 初日から既知の金額で動く ATS/CRM が欲しい場合に向きます。Starter は機能制限付きのトライアルではなく、完結した応募者管理システムです。
- **50席以上の人材派遣オペレーション責任者。** VMS 連携とバックオフィスをフロントオフィスと同じシステムに置きたい場合です。それは公開階層ではなく、見積もり制の Front Office および Bullhorn One のラインにあります。
- **RPO プロバイダー。** 多数のクライアント組織にまたがる紹介を管理し、契約・勤怠・請求のデータを紹介レコードに突き合わせる必要がある場合です。

## 注意点

- **公開されている階層に AI は入っていません。** Amplify の機能(検索とマッチング、Amplify Chat、エージェント型スクリーニング)はすべて Pro から始まり、その Pro には公開価格がありません。*対策:* 最初の商談で Pro と Max の見積もりを求め、Core の $165 のラインと並べて評価してください。$99 という見出しの数字で案件を組み立て、後から AI が見積もり制の2階層上にあると気づくのが、このベンダーでの典型的な失敗です。
- **コストを決めるのは席数ではなくモジュールです。** Onboarding、Middle Office、Messaging、Analytics はユーザー単価とは別に見積もられます。*対策:* 使う予定のモジュールをすべて契約時点で見積もらせ、更新時の上限を書面で交渉してください。サードパーティのデータでは、年 20% 前後の値上げが既定では上限なしと報告されています。
- **自社採用には製品カテゴリが合いません。** *対策:* 単一の雇用主のために採用しているなら、[Greenhouse](/ja/tools/greenhouse/)、[Ashby](/ja/tools/ashby/)、[Lever](/ja/tools/lever/)、[Workable](/ja/tools/workable/)、[iCIMS](/ja/tools/icims/)、[SmartRecruiters](/ja/tools/smartrecruiters/) を使ってください。Bullhorn のクライアント・契約・請求のオブジェクトは空のまま残り、それでも課金されます。
- **公式の MCP サーバーはありません。** Bullhorn はドキュメント化された REST API を提供していますが、エージェントからのアクセスは StackOne のようなサードパーティコネクタ、またはその API 上に構築されたコミュニティ製 MCP サーバー経由になります。*対策:* 外部エージェントから Bullhorn のレコードに到達させる必要があるなら、REST API に対する統合プロジェクトとして予算化し、候補者の個人情報に触れる前にコネクタの認証モデルを確認してください。
- **UI は古さが目立ちます。** 人材派遣領域の新興プレイヤー([Loxo](/ja/tools/loxo/)、Vincere)は操作速度で真正面から競合しています。*対策:* 無料トライアルがないため、最も案件量の多いリクルーター2名でデモを回し、紹介1サイクル分の所要時間を計測してから複数年契約に署名してください。
