## 概要

Langfuse は、LLM アプリケーションとエージェントのためのオープンソースのトレーシング、評価、プロンプト管理プラットフォームです。アプリを計装すると、各実行がオブザベーション（生成、スパン、ツール呼び出し）のツリーとして記録され、LLM ジャッジ、コード評価器、人によるアノテーションキューでスコアを付けられます。プロンプトはバージョンとデプロイラベル付きで Langfuse に保存されるため、プロンプトの変更はロールバックできます。コアは MIT ライセンスで、使用量の制限なくセルフホストできます。公式サイトは月間 90B 件以上のオブザベーションと、Fortune 50 のうち 21 社の利用を掲げています。

ClickHouse は 2026-01-16 に Langfuse を買収しました。創業者の投稿によれば、チームは ClickHouse に合流し、ロードマップは変わらず、Cloud は「same endpoints, same contracts」を維持し、ライセンス変更の予定もありません。大規模なクエリを高速化するためにデータモデルをオブザベーション中心に再構築した Langfuse v4 は、2026 年 8 月に Cloud で公開され、セルフホスト版も GA になりました。

オペレーション側の問いに答えるツールです。チームが社内エージェント（RevOps のリード調査エージェント、法務の契約受付アシスタント、サポートの一次振り分けボットなど）を動かしているのに、何をしたのか、1 回の実行にいくらかかるのか、先週のプロンプト修正で悪化していないのかを誰も確認できない、という状況です。

## 実際に買うもの

**トレーシング。** Python と JS/TS の SDK に加えて OpenTelemetry の取り込みに対応しており、フレームワークを選びません。ネイティブ連携は [Dify](/ja/tools/dify/) など一般的なエージェントフレームワークやビルダーをカバーします。v4 ではトレースの全文検索、新しいフィルターバー、アラートが追加されました。

**評価。** LLM-as-a-judge（2026 年 3 月からカテゴリ型スコアにも対応）、コード評価器、人によるレビュー用のアノテーションキュー、実験用のバージョン管理されたデータセットがあります。2026 年 8 月からは画像や音声も評価できます。

**プロンプト管理。** バージョン管理されたプロンプト、デプロイラベル、プロジェクト間での JSON による一括インポートとエクスポートを備えています。

**MCP サーバーと CLI。** すべてのプランに、読み取りと書き込みのツールを備えた認証付き MCP サーバー（`/api/public/mcp`）が含まれます。そのため [Claude Code](/ja/tools/claude-code/) などのエージェントから、プロンプトの一覧取得、オブザベーションの検索、実験結果の取得ができます。CLI 1.0 は 2026-08-28 にリリースされました。

## 料金

langfuse.com/pricing の公開情報で、2026-11-04 に確認しました。**ユニット**とは送信するあらゆるデータポイント、つまりトレース、オブザベーション、スコアのいずれかです。

- **Hobby — $0。** 月 50k ユニット（超過オプションなし）、データ参照期間 30 日、ユーザー 2 人。
- **Core — 月 $29。** 100k ユニット込み、ユーザー無制限、データ参照期間 90 日。
- **Pro — 月 $199。** 100k ユニット込み、データ参照期間 3 年、SOC 2 と ISO 27001 のレポート、HIPAA 向けの BAA に対応。**Teams アドオンは月 $300** で、エンタープライズ SSO、SSO の強制、プロジェクト単位の RBAC が加わります。
- **Enterprise — 月 $2,499。** Pro と Teams のすべてに加え、監査ログ、SCIM、稼働率とサポートの SLA。

有料プランの超過料金は段階制です。1M までは 100k ユニットあたり $8、10M までは $7、50M までは $6.50、それ以上は $6 です。Langfuse 自身の例では、Core で 200k ユニットなら月 $37、Pro で 5M なら月 $551 です。データリージョンは米国、EU、日本です。アーリーステージのスタートアップは初年度 50% 割引を受けられます。

**OSS のセルフホストは無料**で、ユニットとユーザーは無制限、エンタープライズ SSO も含まれます。セルフホスト版 Enterprise には定価がなく、ClickHouse Cloud、BYOC、Private とセットで販売され、ClickHouse の商用プランに上乗せする形で価格が決まります。

実際の価格帯です。SSO が必要な 12 人のチームは、超過分を除いて Pro と Teams で月 $499 になります。LangSmith Plus では 12 人分の席料だけで月 $468、Braintrust Pro は定額で月 $249 です。SSO が不要なら、同じチームは Core で月 $29 です。Langfuse の請求額を動かすのは席数ではなく、ユニットです。

## 向いているチーム

複数のフレームワーク上でエージェントを動かしているプラットフォームまたはオペレーションのエンジニアリングチームで、データレジデンシー、データ量、セキュリティ審査のいずれかによって従量課金の SaaS が既定の選択肢として不適切になり、かつチーム内に Postgres、ClickHouse、Redis、S3 を運用できる人がいる場合です。小規模チームにとっては、本格的なホスト型の選択肢として最も安価でもあります。ユーザー無制限で月 $29 の Core があれば、最初の本番エージェントには十分です。

## 向いていないケース

インフラを運用する人がいないのに、プロジェクト単位の RBAC と監査ログが必要なチームには向きません。セルフホストではこれらに Enterprise のライセンスキーが必要で、Cloud では月 $499 からになります。まだエージェントを本番投入していないチームにも向きません。また、評価そのものを自動化したい場合も別の選択肢があります。失敗からデータセットや修正案を生成する点では、Braintrust の Loop や LangSmith の Engine のほうが先を行っています。

## 代替ツールとの比較

- **[LangSmith](/ja/tools/langsmith/)** — LangChain や LangGraph で構築していて、デプロイと Fleet のエージェントワークスペースを同じベンダーでそろえたい場合、かつ席が必要な人数がおよそ 10 人未満の場合に選びます。
- **[Braintrust](/ja/tools/braintrust/)** — 最も急成長している競合です（2026 年 2 月に評価額 $800M）。トレーシングではなく評価が主な仕事で、レビュー担当者がエンジニアより多い場合に選びます。すべてのプランでユーザー無制限です。
- **Arize Phoenix** — もう一つのオープンソースの選択肢です。従来型の ML モニタリングですでに Arize を使っている場合に選びます。
- **Datadog LLM Observability** — すでに Datadog に費用を払っていて、セキュリティチームがこれ以上ベンダーを増やすことを承認しない場合に選びます。
- 音声エージェントについては、これらのどれもシミュレーションしない部分を [Coval](/ja/tools/coval/) がテストします。

ClickHouse による買収はオープンソースへの賭けを変えるのでしょうか。ライセンスは変わりません。注視すべきは商業面のシグナルです。セルフホスト版 Enterprise は ClickHouse のプランに上乗せして販売されるようになりました。MIT のコアは安心して採用できます。ただし、有料のガバナンス機能は ClickHouse の営業経由で提供されると想定して予算を組んでください。

## 注意点

- **ユニットは実行回数ではなくオブザベーション数で数えられます。** 15 スパンと 3 スコアを含むエージェントの実行は 19 ユニットになるため、Core に含まれる 100k ユニットは約 5,000 回の実行分にしかなりません。対策：Core で 1 週間実際のトラフィックを流し、ユニット数を実行回数で割って自社の倍率を求めます。そのうえで、規模を拡大する前に、高ボリュームで低リスクのエージェントには SDK のサンプリングレート（`LANGFUSE_SAMPLE_RATE`）を設定します。
- **セルフホストとは ClickHouse を運用することです。** 構成は 2 つのコンテナに加え、Postgres、Redis または Valkey、ClickHouse、Blob ストレージで、v4 では内部のデータモデルも変わりました。対策：Helm チャートまたは Terraform モジュールでデプロイし、バージョンを固定し、アップグレードのたびに移行ノートを読み、オンコールの担当者を決めます。
- **無料のセルフホストはコンプライアンス対応の構成ではありません。** プロジェクト単位の RBAC、データ保持ポリシー、監査ログ、サーバー側のデータマスキング、SCIM には Enterprise のライセンスキーが必要です。対策：OSS を選ぶ前にセキュリティ審査で求められる管理項目を洗い出し、Enterprise の価格を Cloud の Pro と Teams の組み合わせと比較します。
- **MCP サーバーは既定で書き込みができます。** プロジェクト単位の API キーで認証し、書き込みツールを公開しているため、そのキーを持つエージェントはプロンプトを変更できます。対策：エージェントには専用プロジェクトのキーを渡し、本番プロンプトは保護されたデプロイラベル（Teams アドオンまたは Enterprise）で守り、キーはデプロイ用の認証情報と同じように扱います。
