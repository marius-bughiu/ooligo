## What it is

MuleSoft is Salesforce's integration and API management platform. Salesforce bought it in 2018 for about $6.5 billion, and it is a Leader in Gartner's 2026 Magic Quadrant for iPaaS alongside [Workato](/en/tools/workato/) and [Boomi](/en/tools/boomi/). The core product, Anypoint Platform, covers API design, the Mule runtime that executes integrations, a connector catalog, Flex Gateway for API policy enforcement, and Anypoint Code Builder, where MuleSoft Vibes (formerly MuleSoft Dev Agent) generates Mule apps, DataWeave transformations and MUnit tests from natural-language prompts.

The thing that separates MuleSoft from its two Leader peers is where it starts. Workato starts from the workflow, Boomi from application-and-data integration. MuleSoft starts from the API: its "API-led connectivity" model has you expose each system of record as a governed, reusable API, then build processes on top of those APIs. That is more upfront design work, and it is why the buyer is usually enterprise architecture rather than an ops team.

## Agent Fabric: the part that changed in 2026

Agent Fabric launched on 25 September 2025 as a control plane for agents built anywhere, not just on Salesforce. It has five capability groups: an Agent Registry that holds agents, APIs and MCP tools in one catalog; Agent Scanners that discover agents and MCP servers on other platforms (Amazon Bedrock and AgentCore and Google Vertex AI are named in the documentation, with Microsoft, Claude, Databricks and Kong listed on the product page); Agent Broker for multi-agent orchestration; a governance layer built on Flex Gateway for MCP and A2A traffic plus Trusted Agent Identity; and Agent Visualizer, which maps the agent network. MCP Bridge exposes existing Anypoint APIs as MCP tools without rewriting them.

On 27 October 2026 Salesforce added production controls. Generally available now: an Agent Kill Switch, open policies for federated API gateways, a FinOps dashboard, Model Wallet spending limits per agent, and cost-optimization policies. Not yet available: Agent Evals and API Evals, which generate pre-deployment test scenarios and score agents, LLMs and MCP servers in production, entered beta in November 2026 with general availability planned for January 2027, as does the triggered kill switch that links an eval failure to automatic shutdown.

## Do you need Agent Fabric if you already run Agentforce?

Only once your agents stop living in one place. [Agentforce](/en/tools/salesforce-agentforce/) already governs agents built inside Salesforce. Agent Fabric earns its cost when there is a second platform — a support agent on [Amazon Bedrock](/en/tools/amazon-bedrock/), an internal assistant in [Microsoft Copilot Studio](/en/tools/microsoft-copilot-studio/), engineers wiring MCP servers into [Claude](/en/tools/claude/) — and someone has to answer "which agents exist, what can they touch, and what are they costing us" across all of them. If every agent you run is an Agentforce agent today, the scanners have nothing to find; revisit when the second platform shows up.

## A use case worth buying it for

Quote-to-cash where [Salesforce](/en/tools/salesforce/) is the system of record and the ERP is [NetSuite](/en/tools/netsuite/) or SAP. MuleSoft's API-led model has you publish a "customer" API and an "order" API once, then reuse them for the CRM-to-ERP sync, the billing portal and, now, the renewal agent that needs to read order history. The second and third consumers are where the upfront design pays back: each new integration or agent calls a governed API with its own policy and audit trail instead of a fresh point-to-point connection.

## Pricing

MuleSoft relaunched its pricing in September 2026. Everything now draws on Mule Credits, a single consumption unit shared across integrations, APIs, automation and agents, with a separate credit rate per usage type that falls as volume rises. Packages start at **$2,000 per month, billed annually**, and come in five shapes — Govern APIs and AI, Manage Agents (the full Agent Fabric), Connect Apps, Process Documents, and Access Everything. There are three ways to buy: Pre-Purchase (credits up front, lowest rate, no minimum), Pre-Commit (a **$50,000 minimum annual commitment**, billed monthly as used) and Unlimited (custom fixed price, uncapped credits). A 30-day free trial covers the full portfolio.

The per-credit rates are not published, so the $2,000 entry point tells you little about a real deal. Third-party transaction data is the better anchor: CostBench puts the median contract at **$55,150 per year** across 74 verified purchases as of April 2026, and Vendr-sourced figures cited by analysts sit near **$69,000**, with deals observed from under $10,000 to above $250,000. Plan for mid-five figures for a first production deployment and six figures once Agent Fabric and multiple business units are in scope.

## Best for

Enterprise architects and integration leads at Salesforce-centric companies who need API management and integration from one vendor, and who now have — or expect — agents on more than one platform that need a shared registry, policy layer and spending cap.

## Alternatives, and when to pick them instead

- **[Workato](/en/tools/workato/)** — pick it when the requirement is cross-system workflow owned by an ops or IT automation team, not an API program, and you want agent tooling (Workato One, Enterprise MCP) without designing an API layer first.
- **[Boomi](/en/tools/boomi/)** — a Leader for the 12th consecutive time in 2026. Pick it when the estate is not Salesforce-centric and the job is application-and-data integration with a lower entry price.
- **[n8n](/en/tools/n8n/)** — the fastest-growing entrant. Pick it when you can self-host, have engineers, and want agent workflows without a five-figure floor.
- **[Zenity](/en/tools/zenity/) or [Runlayer](/en/tools/runlayer/)** — pick one of these when what you need is agent discovery and security governance alone, and you have no reason to buy an integration platform to get it.

## Watch-outs

- **Unpublished credit rates make the first quote hard to check.** Guard: before signing, get the credit rate card for each usage type you will consume written into the order form, then price your five highest-volume integrations and your expected agent and model-call volume against it. Ask what happens at the credit threshold — overage rate, auto-upgrade, or hard stop.
- **Existing vCore customers renew into a different unit.** Guard: ask your account team for a side-by-side translation of your current vCore contract into credits at least two quarters before renewal, and price a Workato or Boomi quote in parallel so the translation is negotiated, not accepted.
- **Model Wallet caps only see traffic that passes through MuleSoft's Model Proxy.** An agent calling a model provider with its own key is invisible to the budget, and the documentation describes caps as approximate. Guard: route every production model key through the proxy and revoke direct provider keys held by agent teams, then reconcile the FinOps dashboard against the provider invoice for the first two months.
- **Agent Evals are beta until January 2027.** Guard: do not design a release gate around automated evals or the triggered kill switch until they are generally available; keep the manual kill switch and a human review step in the runbook until then.
