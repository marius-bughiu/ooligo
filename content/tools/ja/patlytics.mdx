## 何をするツールか

Patlytics は特許のライフサイクル全体をカバーする AI プラットフォームです。発明提案書の受付、明細書のドラフティング、拒絶理由通知の分析、特許・非特許文献の調査、クレーム解釈、無効分析、FTO（実施の自由）、標準必須特許（SEP）分析、ポートフォリオの整理、そして侵害検知までを扱います。Paul Lee と Arthur Jen が2024年に創業しました。製品は各モジュールに加えて Patlytics Agent があり、ベンダーはこれを150以上の Skills で動くチャットインターフェースだと説明しています。

この製品が AI 特許ツール市場の他社と本当に違うのは、重心の置き方です。資金調達済みの競合はほぼすべてドラフティングから始めました。つまり、Word でクレームを書く弁理士が起点です。Patlytics は訴訟とライセンシングの側から始めました。そこでの成果物は実施証拠に裏付けられたクレームチャートであり、そこから権利化業務へと遡って機能を広げてきました。[Anaqua](/ja/tools/anaqua/) がポートフォリオの記録システムだとすれば、Patlytics はそれを読み解く分析レイヤーです。

資金調達は、2025年2月に Next47 がリードした1,400万ドルのシリーズ A、続いて2026年4月8日に発表された4,000万ドルのシリーズ B へと続きます。シリーズ B は SignalFire がリードし、参加投資家に Relativity が含まれます。ベンダー自身の集計で累計は約6,500万ドルです。Patlytics は AmLaw 100 の40%が同プラットフォームを利用していると主張し、Quinn Emanuel、Latham & Watkins、Foley & Lardner、Susman Godfrey の名前を挙げています。企業顧客としては Rivian、Panasonic、Canon、Sanofi、Asahi Kasei などです。これらはいずれもベンダー提供の数字で、独立した監査はありません。規模のシグナルとして読むべきで、測定値としては読まないでください。

## Legal Ops のスタックに入ってくる理由

- **クレームチャートがデモではなく製品そのものです。** 侵害検知は特許と製品を構成要件ごとに突き合わせ、長い構成要件は自動で分割して証拠が正しい文言に紐づくようにし、引用付きの抜粋と各対応箇所の読み取り強度を色分け表示した編集可能なチャートを返します。ポートフォリオスクリーニングでは、同じ処理を数百件の特許と複数の製品に対して一括で走らせます。
- **MCP サーバーが実在し、範囲が明確に切られています。** `https://mcp.patlytics.ai/mcp` は Streamable HTTP で通信し、Patlytics アカウントで認証し、読み取り専用の5つのツールを公開します。類似特許の検索、特許詳細の取得、非特許文献の検索、自分のポートフォリオ一覧、vault 内の特許一覧です。Claude Code ならコマンド1つで済みます。

```bash
claude mcp add --transport http patlytics https://mcp.patlytics.ai/mcp
```

  これで先行技術調査が、アソシエイトがすでに作業している場所で完結します。この線引きは意図的なものです。侵害、無効、FTO、ドラフティングは Web アプリ側に残ります。
- **セキュリティ体制が知財部門の購買を別交渉なしで通ります。** SOC 2 Type 2、ISO 27001、ISO 42001、GDPR に対応し、顧客データは分離され、転送時も保存時も暗号化され、モデルの学習には使われません。履歴の保持期間は90日で、要求すれば削除されます。評価は NCC Group と A-LIGN が実施しています。AI ガバナンスの質問票が来たときに指し示すべきなのは ISO 42001 です。
- **発明提案の受付がエンジニア側のセルフサービスになります。** R&D はパラリーガルの受信箱に届くフォームではなく、プラットフォーム経由で発明を提出します。企業の発明提案パイプラインが詰まるのは、まさにそこです。

## 価格の実態

Patlytics は価格も料金表も無料枠も公開していません。すべての契約がデモ後の個別見積もりです。サードパーティの集約サイトは月額1ユーザーあたり800〜2,000ドル程度としていますが、これは隣接プラットフォームからの外挿による推定であり、ベンダーの数字でも顧客の数字でもありません。この数字で予算を組まないでください。

信頼できるアンカーはセグメント側にあります。Spellbook の2026年リーガル AI 価格調査によれば、法律事務所向けのエンタープライズツールは [Harvey](/ja/tools/harvey/) の水準で月額1ユーザーあたり約1,000〜2,000ドル以上、[Legora](/ja/tools/legora/) で300〜800ドル、[CoCounsel](/ja/tools/thomson-reuters-cocounsel/) や [Lexis+ Protégé](/ja/tools/lexisnexis-protege/) のようなリサーチ AI で225〜650ドルです。Patlytics も同じ購買層に売っており、見積もりはこの近辺に着地します。

金額を動かす要素は2つあり、シート数はそのうちの1つにすぎません。もう1つは分析ボリュームです。検知の実行とポートフォリオスクリーニングが高価な単位であり、四半期に200件の特許をチャート化するライセンシングプログラムと、無効資料を扱う4人の訴訟担当とでは、必要な契約が別物になります。ベンダー自身の ROI の説明は、以前は弁護士の作業時間で3万ドル以上かかっていたクレームチャートが、いまはその一部の費用で済むというものです。自社の数字で検証してください。すでに手作業でチャート化した案件1件を内部原価で計算し、比較するのが早いです。

発注書には3点を入れてください。分析実行の含まれる上限、それを超えた後の超過料金、そして MCP アクセスが各シートに含まれるのか別売りなのかです。

## こんなチームに向いている

社内の知財担当弁理士・弁護士、および法律事務所の特許訴訟担当で、50件以上の有効特許からなるポートフォリオに対して実施証拠、無効分析、FTO の業務を回しているチーム。クレームチャート作成が単発の案件ではなく恒常的なコストセンターになっていて、期限管理と年金の支払いはすでに IPMS が担っている、という状況が前提です。

**向いていないのは**、年間の出願が数件で、ボトルネックがチャートの量ではなくドラフティングの速度である場合です。その業務には DeepIP や Solve Intelligence のほうが近く、見積もりも安く出ます。期限管理、更新、知財費用の管理が必要な場合も対象外です。Patlytics はポートフォリオを分析しますが、運用管理はしません。Anaqua は請求書に残り続けます。購買部門がデモの前に公開価格を要求する場合も対象外です。公開価格は存在しないからです。

## 代替候補と、そちらを選ぶ基準

- **Solve Intelligence** — フルライフサイクルで最も近い競合であり、資金面でも最有力の同格プレイヤーです。ブラウザベースで、2025年12月に M12 と Thomson Reuters Ventures が参加した4,000万ドルのシリーズ B を実施し累計5,500万ドル、同じ月にクレームチャート機能を追加しました。ドラフティングと権利化が業務量の中心で、チャート作成が少ないほうの半分であれば、こちらを選んでください。
- **DeepIP** — 権利化側で最も成長が速い新規参入です。2025年3月に Resonance がリードした1,500万ドルのシリーズ A、2026年3月にさらに2,500万ドル、400を超える法律事務所と企業知財チームが利用しています。Microsoft Word の中でドラフティングし、IPMS や期限管理ツールと連携します。弁理士が Word から離れない場合、または化学・ライフサイエンス分野のドラフティングが主戦場である場合は、こちらを選んでください。
- **PatSnap、Clarivate Derwent、Questel** — 特許データと分析の既存レイヤーであり、市場シェアの点ですでに候補リストに入っているはずの2社を含みます。業務がランドスケープ分析、調査カバレッジ、説明可能なデータライセンスであって、訴訟の成果物ではない場合は、この中から選んでください。
- **[Harvey](/ja/tools/harvey/) または [Legora](/ja/tools/legora/)** — 事務所がすでにライセンスしている可能性が高い汎用リーガル AI です。特許案件が混合案件の一部にすぎず、個別ワークフローでの最適解よりベンダー統合を優先する場合は、こちらを選んでください。
- **XLSCOUT** — 先行技術調査とたまのチャート作成が必要なだけで、訴訟プラットフォームまでは要らないチーム向けの低価格の選択肢です。

- **このページに出てくる実績値はすべてベンダー提供です。** AmLaw 100 の利用率、ポートフォリオマッピングが100時間から20時間になったという事例、「プロジェクト時間を最大90%削減」— いずれも Patlytics のマーケティング資料であり、独立した監査を受けていません。**ガード：** PoC では、すでに手作業でチャート化した案件を処理させ、構成要件ごとに突き合わせて差分を確認してください。ベンダーが選んだ特許でベンダーが回すデモは、自社の技術分野について何も証明しません。
- **確信度の表示は検証ではありません。** 読み取り強度の評価と引用リンクは確認作業の時間を削りますが、弁理士によるレビューをなくすものではありません。誤った対応付けのまま提出したチャートは Rule 11 のリスクであり、それを負うのは署名した弁護士であってツールではありません。**ガード：** ワークフローに弁護士の承認ステップを残し、どの構成要件を AI が対応付けたかを記録してください。そうすればレビューの記録が異議申立てに耐えます。
- **MCP サーバーは読み取り専用で、アカウント単位に限定されています。** MCP 経由で侵害分析や無効分析を起動させるつもりで Claude Code のワークフローを設計すると、そこで行き止まりになります。あの5つのツールは検索と取得だけを行います。**ガード：** 自動化の範囲は先行技術調査と vault へのクエリに限定し、分析の実行は監査証跡が残るアプリ側に置いてください。
- **履歴90日という保持期間は初期設定であって契約条項ではありません。** **ガード：** 署名前に、保持期間、削除の SLA、再委託先リストを DPA に落とし込んでください。トラストページの記載は予告なく変わりますが、DPA は変わりません。
