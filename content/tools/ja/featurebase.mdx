## 概要

Featurebase はフィードバックボードとして始まりました。投票、公開ロードマップ、changelog という Canny と同じ形です。そして2026年を通じて本格的なヘルプデスクへと変わりました。同じ workspace で、ライブチャット、メール、Slack の会話を1つの受信箱で扱い、ヘルプセンター、プロアクティブなメッセージング、そして顧客に回答し解決ごとに課金する AI エージェント Fibi を運用できます。売りは統合です。フィードバックボードと Intercom 型のサポートスタックを別々に持つ代わりに、シート課金のツール1つで済ませます。最初に理解すべき課金メーターは Canny とは正反対です。Featurebase が課金するのは**チームのシートと Fibi の解決件数**であり、投稿や投票をするエンドユーザーではありません。

## Customer Success スタックで採用される理由

- **フィードバックとサポートが1つのレコードを共有します。** Feedback 2.0（2026年9月24日）で投稿は Requests に改称され、各 Request はサポート会話と通話レコーダー（Fathom、tl;dv、Grain、Gong、Fireflies、Granola）から抽出した Insights で裏づけられるようになりました。エージェントは受信箱からチャットを Request に紐づけられ、ステータスの変更は顧客が最初に質問した会話へ返されます。ボードとヘルプデスクが別々なら、連携を介して近づけることしかできないループの閉じ方です。
- **サポート機能が実用水準になりました。** Outbound（7月7日）は changelog、バナー、メール、アンケート、ターゲティングしたチャットを1つのモジュールにまとめました。8月10日には Slack がネイティブのサポートチャネルになり、SLA と Tickets への変換に対応しました。Salesforce の双方向同期と HubSpot のデータ同期は8月20日に提供され、Requests を Opportunity Value で並べ替えられます。
- **AI の課金はシートではなく成果ベースです。** Fibi は会話を解決したときだけ課金され、人間への引き継ぎは無料です。Fibi 3.0（6月18日）以降の Featurebase 自身の全体数値は解決率65%で、以前の50%から上がっています。ただしこれはベンダーの数値であり、独立したベンチマークではありません。
- **エージェント接続は有料の最下位プランにあります。** API、Webhook、MCP は $29/シートの Growth に含まれ、7月の Reports リリースでは MCP サーバー経由でサポートデータを照会できます。

## 料金の実態

4つのプランがあり、シート単位の課金です。エンドユーザー、投稿、コメントは計測されません。

- **Free** — $0、1シート、フィードバックボード1つ、ロードマップ1つ、ライブチャットと受信箱。Fibi はありません。
- **Growth** — 年払いで $29/シート/月、月払いで $37。Fibi、Copilot、API/MCP、レポート。
- **Professional** — 年払いで $59/シート/月、月払いで $75。ワークフロー、SLA、ラウンドロビン割り当て、Salesforce と HubSpot、無料の Lite シート（閲覧専用）20席が加わります。
- **Enterprise** — 年払いで $99/シート/月、月払いで $129。SSO、マルチブランド、Lite シート50席。

シート料金は請求額そのものではありません。上に5つのメーターが積み上がります。Fibi は**1解決あたり $0.49**（2026年7月1日に $0.29 から改定され、新規・既存顧客の両方に適用）。Copilot はシートごとに月10会話まで無料で、それ以降は $19/シート/月。アウトバウンドメールは5,000通まで無料で、それ以降は非公開の料金。Featurebase のブランド表示の削除は $69/月です。試算例として、Growth 3シートに月400件の Fibi 解決を加えると約 $283/月（$87 + $196）です。同じ負荷を Intercom で回すと、$29からの Essential シートに1成果あたり $0.99 の Fin が加わり、約 $483 になります。アーリーステージ企業（設立2年未満、従業員6人未満）は86%の割引を受けられます。

## 最適な用途

サポートシートが2-15席の B2B SaaS 企業の創業者や最初の CS 担当者で、フィードバック投票、公開ロードマップ、ヘルプセンター、AI の一次対応を1つのツールにまとめて月 $300 未満に収めたいチームに向いています。公開ボードが大規模、あるいは一般消費者の比率が高い場合に最も適しています。20,000人のユーザーが投票を始めても、Featurebase のコストは動かないからです。

サポートエージェントが25人以上いる、音声やシフト管理が必要、あるいは自社のマーケティング以外で AI エージェントがベンチマークされたベンダーが必要という場合は、Featurebase を買わないでください。それは [Zendesk](/ja/tools/zendesk/) の領域です。Fin のデフレクション品質とエコシステムが1解決あたり倍の料金に見合うなら [Intercom](/ja/tools/intercom/) です。

## 代替ツールとの比較

- **[Canny](/ja/tools/canny/)** — フィードバックボードだけが必要で、より成熟した製品を求めるなら選んでください。Canny の Autopilot による取り込みはメーター課金されませんが、請求額はトラッキング対象ユーザー数に比例して増えるため、大規模な公開ボードでは計算が Featurebase 有利に傾きます。
- **[Productboard](/ja/tools/productboard/)** — 購入者がサポートの受信箱ではなく、スコア付きの優先順位づけと機能階層を必要とするプロダクト組織であれば選んでください。
- **[Intercom](/ja/tools/intercom/)** と **[Zendesk](/ja/tools/zendesk/)** — サポート分野の市場シェア上位2社です。サポート量、チャネルの幅、コンプライアンス審査が小規模ベンダーの手に余るようになったら、どちらかを選んでください。
- **[Pylon](/ja/tools/pylon/)** — B2B サポートで最も急成長している新興勢力です。エンタープライズ顧客が共有の Slack Connect チャネルにいて、アカウント単位のヘルスビューが必要なら選んでください。[Plain](/ja/tools/plain/) と [Help Scout](/ja/tools/help-scout/) は、それぞれ API ファーストと共有受信箱型の、より軽い選択肢です。

## 注意点

- **AI の料金は13日前の通知で69%上がりました。** $0.29 から $0.49 への変更は6月18日に告知され、7月1日から既存顧客にも適用されました。**対策：** 年間契約では、1解決あたりの料金を上限付きで発注書に明記させ、予算は今日の数字ではなく $0.49 に余裕を上乗せした水準で組んでください。
- **「解決」の定義が公開されていません。** Featurebase は、静止期間、再オープン時のルール、部分的なエスカレーションの課金方法を文書化していません。Zendesk と HubSpot は72時間ルールを公開しています。**対策：** Fibi を有効にする前に定義を書面で入手し、その後1か月分の請求書を会話ログと突き合わせてください。
- **売上順のフィードバック整理には Professional が必要です。** Requests を商談金額で並べ替えられる Salesforce と HubSpot の同期は、Growth ではなく $59 のプランにあります。**対策：** ARR で重みづけしたトリアージが購入理由なら、初日から Professional で見積もってください。
- **Fibi は管理者から見てブラックボックスです。** Featurebase 自身のフィードバックボードには、Fibi がどのツールをなぜ呼び出すのかを見えるようにしてほしいというユーザーの要望が寄せられています。**対策：** 最初の1か月は Fibi の会話記録のサンプルを毎週確認し、機微なテーマはワークフローで人間に回すようにしてください。

このデマンドシグナルをヘルススコアと併せて活用する CS プラットフォームについては、[Gainsight](/ja/tools/gainsight/) と [Vitally](/ja/tools/vitally/) を参照してください。
