## 概要

Wordsmith は、文書ではなく法務部門の「入口」を中心に設計されたインハウス法務向けの AI プラットフォームです。依頼は事業部門が普段使っているチャネル、つまり Slack、Microsoft Teams、Outlook、email、Salesforce から届き、Wordsmith がその一件ごとを受け付け、トリアージし、解決し、記録します。エージェントが自社のプレイブックとテンプレートに基づいて定型的な質問に回答し、商用契約にレッドラインを入れ、判断が必要な依頼は弁護士に引き継ぎます。すべての手順は監査証跡に書き込まれます。2023年にエディンバラで CEO の Ross McNairn、CTO の Volodymyr Giginiak、COO の Robbie Falkenthal が創業し、2026年6月3日に Highland Europe と Index Ventures が主導する 7,000万ドルのシリーズ B を、続いて2026年8月5日に Intact Private Capital 主導・FT Ventures 新規参加による 1,400万ドルの追加ラウンドを調達しました。シード、シリーズ A、シリーズ B を合わせた累計調達額は 1億1,400万ドルです。BT、Financial Times、Canva、Sage、Starling、Trip.com、Deliveroo、Belron、Rakuten を含む500社以上が導入しています。

## Legal Ops スタックに入る理由

- **作業の単位はファイルではなく依頼です。** [Ironclad](/ja/tools/ironclad/) と [Juro](/ja/tools/juro/) は契約レコードを起点にし、[Harvey](/ja/tools/harvey/) と CoCounsel はリサーチの問いを起点にします。Wordsmith の起点は届いた依頼そのものです。調達担当が Slack にベンダーの MSA を貼る、営業担当が相手方のレッドラインを飲めるか尋ねる、人事がオファーレターを確認する、といった依頼です。受付、トリアージ、解決、記録が別々のツール3つに流し込む申請フォームではなく、ひとつの pipeline に収まります。
- **公式の MCP サーバーを提供しています。** `https://mcp.wordsmith.ai` のエンドポイントが `ask_question`、`upload_file`、`list_playbooks`、`list_templates`、`list_assistants` と非同期ジョブのステータス取得を公開し、その下で `https://api.wordsmith.ai/api/v1` の REST API が bearer 認証と webhook コールバックに対応します。法務レビューは誰かが開きに行く到達点のアプリではなく、他チームのエージェントが Claude Code や任意の MCP クライアントから呼び出せる一工程になります。
- **ROI の論点はシート単位の生産性ではなく外部弁護士費用です。** Wordsmith は法律事務所の請求書を相手に売っており、公開されている顧客数値もその線に沿っています。Belron は最初の4週間で10万ドル超の外部弁護士費用を回避し、1タスクあたり平均238分を削減しました。Trustpilot は契約レビュー時間が85%減ったと報告しています。いずれもベンダー公表値です。

## 価格の実態

シート単位の定価はありません。価格ページは3つのプランを掲載していますが、どれにも金額を付けていません。**Free**（セルフサインアップ、カード不要、評価用の利用枠、primitives はすべて開放）、**Production**（従量課金。「エージェントが実際に出した分だけ支払う」という建て付けで、既定の月額予算は200ドル、上限は自分で設定でき、100% に達すると黙って超過するのではなくハード停止します。SSO、RBAC、SCIM に加えて BAA とゼロデータ保持のオプションあり）、そして Wordsmith Black のブランドを冠した **Enterprise**（専用インフラ、保持期間とデータ所在地のカスタム設定、専任のデプロイエンジニア、調達と DPA の支援）です。ベンダー自身の表現は「3プラン、課金面はひとつ、シート税なし」です。

実務上、これは購買プロセスを二つに割ります。月200ドルの上限に対して発注書もデモもなしにパイロットを計測でき、試すコストは実際に安く済みます。一方で、500社という実績が示す部門全体の展開は、いまも30分のデモと、Wordsmith が価格を公開していない年間契約を経由します。パイロットはドル単位で見積もり、見積書が出るまで本番展開は未知数として扱ってください。

## 最適な相手

調達、営業、人事から来る依頼件数が制約になっている200〜5,000人規模の企業の Legal Ops 責任者と法務責任者です。訴訟でも契約書庫でもありません。具体的な引き金は、弁護士2〜6名の部門で Slack の DM と共有の legal@ 受信箱が事実上の受付システムになっており、前四半期に何件の依頼が来たのか誰も答えられず、内部で処理できたはずの仕事を外部弁護士の請求書が吸い続けている状態です。自社チームが作るエージェントから MCP 経由で法務レビューを呼び出したい場合も、カタログ内で最も強い選択肢になります。

## 代替候補との比較

[Ironclad](/ja/tools/ironclad/) は記録の対象が契約そのものである場合の本命です。リポジトリ、義務管理、更新管理が必要で、受付は製品の本体ではなく CLM に流し込むフォームでよい、という場合に選んでください。[Onit](/ja/tools/onit/) は enterprise legal management の極です。実際に買いたいものが案件管理と外部弁護士費用の統制であり、法務がすでに成熟した ops 機能を回している場合に選んでください。Checkbox は入口セグメントで最も成長が速い新規参入で、2026年1月に2,300万ドルのシリーズ A を調達しています。自分で設定するノーコードのキャンバスが欲しく、同じ基盤で法務以外の workflow も動かすつもりなら Checkbox、法務向けの挙動が最初から組まれていて設定に人を張りたくないなら Wordsmith です。[GC AI](/ja/tools/gc-ai/) はシート500ドルの価格を公開しているインハウス向けアシスタントで、弁護士がより良い道具を欲しがっているだけで事業側の受付問題が存在しないなら、こちらが適します。どれも当てはまらないなら、正直な代案はすでに持っているサービスデスクにルーティングフォームを1枚足し、トリアージ当番を回すことです。費用はゼロで、本当の欠落であることが多い「計測」が直ります。

## 注意点

- **効率の数値はすべてベンダー公表値です。** レビュー時間85%削減も、1タスク238分も、4週間で10万ドルも、出所は Wordsmith であり、独立した監査は受けていません。ガード：Free プランを依頼種別ひとつに絞って30日間走らせ、自分で計測した解決率と外部弁護士費用の差分を年間契約の判断条件にしてください。
- **「価格未公開」は「安い」という意味ではありません。** 月200ドルという数字は計測されたプラットフォーム利用に対する既定の支出上限であって、サブスクリプション価格ではなく、enterprise 契約については何も語りません。ガード：パイロットが終わる前に本番展開の見積を書面で取り、エージェントの処理量が3倍になったとき従量課金の請求がどうなるかを名指しで確認してください。
- **受付ツールが失敗する原因は精度ではなく定着です。** 入口は事業部門がそこを通って初めて機能し、典型的な失敗は調達がこれまでどおり法務責任者に直接 DM を送り続けることです。ガード：依頼者グループひとつ、依頼種別ひとつで立ち上げ、旧チャネルは1四半期そのまま並走させ、Wordsmith 経由で届いた依頼の比率を継続判断の指標にしてください。
- **CLM でも案件管理システムでもありません。** Wordsmith は依頼を解決して記録しますが、締結済み契約も法務費用も保持しません。ガード：リポジトリ（[Ironclad](/ja/tools/ironclad/)、[Juro](/ja/tools/juro/)）と費用管理（[Brightflag](/ja/tools/brightflag/)）はそのまま残し、Wordsmith は受付から解決までの層に限定してください。
- **EU のデータ所在地は Enterprise プランの項目です。** 保持期間と所在地のカスタム設定は Wordsmith Black に入っているため、Free と Production のセルフサービス経路では EU 限定という硬い要件を満たせません。ガード：所在地が交渉不可の条件なら、パイロット前に契約で確定させてください。パイロットの経路ではそれを証明できません。
