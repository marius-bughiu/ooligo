Clearbit はもう購入できる製品ではありません。clearbit.com は現在「Clearbit has joined HubSpot」というタイトルのページを表示し、エンリッチメントのエンジンは Breeze Intelligence として [HubSpot](/ja/tools/hubspot/) の中で動いています。単体の Clearbit 顧客だった場合 — API キー、Reveal、無料ツール — 判断すべきなのは Clearbit か他社かではありません。HubSpot の顧客になるか、すべてのエンリッチメント呼び出しを別の場所に向け直すか、です。

ここに至るまでにメーターは 2 回変わり、2 回目の変更は買い手に有利に働きました。撤退の費用を計算する前に、留まる選択肢を計算してください。

## 実際に何が変わったか

2025年6月2日から6月15日にかけて、HubSpot は Breeze Intelligence Credits を HubSpot Credits へ、Breeze Credits 100 に対し HubSpot Credits 3,000 の比率で変換しました。2025年の価格解説記事に載っているクレジット単価は変換前のメーターを引用しており、およそ 30 倍ずれています。

より大きな変更は、**データエンリッチメントがクレジットをまったく消費しなくなった**ことです。HubSpot の公式ドキュメントは、データエンリッチメントは HubSpot Credits を消費しないと明記しており、HubSpot の製品カタログにある Core Seat の定義は、エンリッチされたデータをシートの権利として付与しています。コンタクトと会社のエンリッチメントに必要なのは Starter、Professional、Enterprise のいずれかのサブスクリプションだけで、それ以上は求められません。

引き続き課金対象となるのは以下です。単価はクレジットあたり $0.010、1,000 クレジット $10/月のキャパシティパックで販売されます。

| アクション | クレジット |
|---|---|
| インテントシグナルを有効化し、1 社を 1 か月モニタリングする | 10 |
| Prospecting agent — リード 1 件へのアウトバウンドを提案する | 100 |
| ワークフロー内で Breeze アクションを 1 回実行する | 10 |
| Data agent — レコード 1 件に対しプロンプト 1 件の回答を生成する | 10 |
| Customer agent — テキストベースの会話を 1 件解決する | 50 |

このメーターには落とし穴が 2 つあります。付与されたクレジットは毎月末に失効し、繰り越されません。そして付与枠は製品をまたいで加算されません。Marketing Hub Professional と Sales Hub Enterprise の両方を契約しても、受け取るのは Enterprise の枠であり、2 つの合計ではありません。

残りはシートが決めます。Sales Hub は年間契約の Starter で 1 シートあたり $7/月、Professional で $90、Enterprise で $150、加えて Professional に $1,500、Enterprise に $3,500 の初期オンボーディング費用がかかります。

## Clay

[Clay](/ja/tools/clay/) は、技術力のある RevOps チームにとって Clearbit の API が意味していたものに最も近い代替です。単一ベンダーのデータベースではなく 150 社を超えるデータパートナーを横断するウォーターフォールで、最初のプロバイダーで外れた場合は次へ落ちていきます。

価格はメーターが 2 つあります。Data Credits はデータそのものを購入し、Actions は Clay が代わりに行うプラットフォーム上の処理を計測します。Launch は月額 $185 から、Data Credits 2,500 と Actions 15,000 が付きます。Growth は月額 $495 から、Data Credits 6,000 と Actions 40,000 です。無料プランは Data Credits 100、Actions 500、テーブルあたり 200 行、シート数は無制限です。Data Credits は Launch と Growth で月間付与量の 2 倍まで繰り越せますが、Actions はサイクルごとにリセットされ繰り越せません。

エントリー価格では、この付与量から Data Credit 1 件はおよそ $0.074 になります（$185 ÷ 2,500）。プロバイダーの API キーを自前で持ち込めば Data Credits を完全に回避でき、支払うのは Actions だけです。

この判断を決めるのは 2 つのしきい値で、どちらもエントリー価格より上にあります。CRM の自動同期とエンリッチメントは Growth からなので、CRM をエンリッチされた状態に保つ実質的な下限は月額 $495 です。Clay の API は Enterprise 限定で、年間コミットが前提です。

**Clay に移るのは、**エンリッチメントがプログラム的で、ICP が単一プロバイダーのカバレッジでは足りず、これから学ぶ人ではなく既に Clay で構築できる人がチームにいる場合です。

**移らないのは、**実際に失ったものが Clearbit の API 契約であり、それを公開価格で置き換える必要がある場合です。Clay は Enterprise 未満で API アクセスを販売していません。

## Apollo

[Apollo](/ja/tools/apollo/) はこの中で最も安く、稼働するエンリッチメント API を取り戻す公開価格の経路としても最安です。Basic は年間契約で 1 シートあたり $49/月、シートあたり年間 30,000 クレジット。Professional は $79 で 48,000、Organization は $119 で 72,000、最低 3 シートです。無料プランはシートあたり年間 900 クレジットで、CRM エンリッチメントは月 100 レコードが上限です。

割り算してみてください。シートあたり年間 30,000 クレジットを 1 シート $49/月で割ると、クレジット単価はおよそ $0.02、Clay のエントリー単価のおよそ 4 分の 1 です。CSV、CRM、API でのエンリッチメントはすべて Basic から使え、ウォーターフォールのエンリッチメントも同様です。つまり Clay では Enterprise 契約が必要な機能が、Apollo では 1 シート $49 で手に入ります。データ品質は下がります。

**Apollo に移るのは、**公開されたシート単価で API を取り戻したく、ICP が SMB か下位のミッドマーケットで、さらに別立てのシーケンスツールを同じ SKU に統合できる場合です。

**移らないのは、**ICP が欧州の場合、またはエンリッチメントがスコアリングモデルに流れ込み、ファーモグラフィックの誤りが欠損より高くつく場合です。

## Cognism

[Cognism](/ja/tools/cognism/) は、Clearbit が答えずに済んでいたコンプライアンスの問いに答えます。プロスペクティングのパッケージは Standard と Pro の 2 つで、いずれも 5 シートを含み、どちらも価格を公開していません。

欠けている数字よりも構造が重要です。CRM Enrichment は両パッケージとも有料アドオンで、API アクセスと一括配信は別建ての Data-as-a-Service アドオンです。両方を必要とする Clearbit の置き換えは、ベースパッケージ＋アドオン 2 つであり、請求書 1 行では済みません。

クレジットモデルはこの中で最も寛容です。1 クレジットで 1 コンタクトが開示され、同じクレジットがプロスペクティングのプラットフォーム、Enrich、API のいずれでも追加料金なしで使え、既に開示したコンタクトの再表示は無料です。HubSpot の毎月の失効と比べると、エンリッチメント量に波があるチームにとっては実質的に別物のメーターです。

**Cognism に移るのは、**ICP が EU または英国で、検証済みの携帯番号カバレッジが効き、GDPR への姿勢が好みではなく調達の関門になっている場合です。

**移らないのは、**商談前に数字が必要な場合、または 2 つのアドオンが合計をベースパッケージの見積もりから想定される水準より押し上げる場合です。

## ZoomInfo

[ZoomInfo](/ja/tools/zoominfo/) は価格を公開しておらず、出回っている公開数値はどれもベンダーではなく競合他社のブログ発です。それらの数字はマーケティングとして扱ってください。同社の論拠は北米のエンタープライズカバレッジとインテントであり、Clearbit を巡る経緯はこの論拠を変えません。

**ZoomInfo に移るのは、**北米のエンタープライズカバレッジが購入の実際の理由で、価格を知るために商談プロセスに入る予算がある場合です。

**移らないのは、**月あたり数百ドル規模の Clearbit の費目を置き換えようとしている場合です。入口の水準が一桁違います。ZoomInfo が本当に候補に入っているなら、判断すべき問いは別のものです — [ZoomInfo の代替](/ja/vs/alternatives-to-zoominfo/) を読んでください。

## Breeze Intelligence に留まるべき場合

- HubSpot を Starter 以上で既に運用している。エンリッチメントの限界費用は現在 $0 であり、単体の Clearbit がかつて提示したどの条件よりも有利です。
- エンリッチメントが API 側ではなく CRM 側 — コンタクトと会社のレコードを最新に保つこと — にある。
- フォーム短縮を使っている。HubSpot のフォームにネイティブな機能で、他所で作り直すのは相応の開発工数です。
- 月ごとの量が安定していて、毎月のクレジット失効が実質的な損失にならない。

留まる論拠が最も強いのは、最も打撃を受けたと感じている買い手そのものです。CRM の衛生管理のために Clearbit を買い、既に HubSpot にも払っているチームです。

## 誰も見積もらない移行コスト

エンリッチメントの向け直しは、統合 1 本では終わりません。契約前に以下を棚卸ししてください。

**Logo API は消滅しました。**2025年12月8日に停止し、HubSpot 自身の移行案内は開発者を logo.dev に誘導しています。自社アプリ、マーケティングサイト、顧客向けディレクトリのどこかでロゴを表示しているなら、その呼び出しは既に死んでおり、上記 4 社のどれもそれを代替しません。

**フォーム短縮は付け替えではなく作り直しです。**このリストのどの代替も、そのまま差し替えられる形では提供していません。

**Reveal 方式の IP 識別は別途購入です。**トラフィックの匿名解除は今や独立したカテゴリであり、この 4 社のどれも 1 対 1 の置き換えにはなりません。

**スケジュールが崩れるのはフィールドのマッピングです。**ベンダーごとに返すプロパティの集合も名称も異なります。見積もるべきは API 呼び出しではなく、マッピングとバックフィルです。

## 結論

**決めきれないなら、HubSpot に留まって Breeze Intelligence を使ってください。**エンリッチメントは Core Seat に含まれるようになり、既に HubSpot に払っているチームにとって、かつて Clearbit が課金していたものの限界費用はゼロです。エンリッチメント費用の節約だけを理由に離れるのは、2025年に算術として成り立たなくなった判断です。

- **Clay** はウォーターフォールのカバレッジを伴うプログラム的なエンリッチメント向け — 開始は月額 $185、CRM 同期には $495、API には Enterprise
- **Apollo** は公開価格のエンリッチメント API が必要で、1 シート $49 が基準を満たす場合
- **Cognism** は EU カバレッジと GDPR への姿勢が購入を決める場合
- **ZoomInfo** はこの出発点からはまれで、北米のエンタープライズカバレッジのためだけ

どれも合わない場合 — HubSpot の顧客にならずに、Clearbit の API 契約を旧価格で必要としている場合 — その製品は存在せず、探しても出てきません。仕事を分割してください。CRM のエンリッチメントは自社の CRM が既に最も安く処理している場所に残し、失った具体的な呼び出しだけを、その呼び出し単体で値付けするベンダーから購入することです。
