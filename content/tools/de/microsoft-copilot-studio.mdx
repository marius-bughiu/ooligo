## Was es ist

Microsoft Copilot Studio ist der Low-Code-Builder für Agents und Agent-Workflows auf der Power Platform. Sie beschreiben einen Agent, geben ihm Wissen (SharePoint, Dataverse, Websites, den Microsoft Graph des Tenants), geben ihm Tools (mehr als 1.400 Power-Platform-Konnektoren, MCP-Server, Agent Flows, andere Agents) und veröffentlichen ihn in Teams, in Microsoft 365 Copilot, auf einer Website oder auf einer Telefonleitung. Es ist der Nachfolger von Power Virtual Agents, und es ist das, was [Microsoft Agent 365](/de/tools/microsoft-agent-365/) steuert: Agent 365 ist Registry und Control Plane, Copilot Studio ist der Ort, an dem die Agents gebaut werden.

2026 hat verändert, was das Produkt ist. Computer-Use-Agents — Agents, die einen Browser oder eine Windows-Desktop-App über die Oberfläche bedienen, wenn es keine API gibt — sind seit dem 13. Mai 2026 allgemein verfügbar. Die Delegation zwischen Agents über das A2A-Protokoll wurde im April GA. Eine zweite Laufzeit, der **GitHub Copilot harness**, kam im Juni als produktionsreife Preview und wurde im August GA, mit Skills, Gedächtnis pro Benutzer und einer Planungsschleife, die während der Arbeit neu plant; der ältere **standard harness** läuft parallel weiter. Claude Sonnet 5 und GPT-5.5 Chat sind als primäres Modell wählbar. Und seit Juli 2026 erhält jeder neue Agent automatisch eine Microsoft Entra Agent ID, ohne Opt-out auf Umgebungsebene.

## Warum Ops-Teams hier landen

Die Frage, die eine Ops-Führungskraft auf diese Seite bringt, lautet meist: *Wir sind ein M365-Haus — bauen wir unsere Ops-Agents in Copilot Studio oder kaufen wir n8n, Relevance AI oder Lindy?* Drei Dinge machen Copilot Studio innerhalb eines Microsoft-Tenants zur Standardantwort. Der Agent erscheint dort, wo die Mitarbeitenden ohnehin arbeiten (Teams, Outlook, die Copilot-App), ohne neuen Login. Identität, DLP und Conditional Access greifen pro Agent über Entra Agent ID — etwas, das ein Security-Review sonst von Ihnen per Hand nachbauen lässt. Und für Mitarbeitende mit einer Microsoft-365-Copilot-Lizenz wird die Konversationsnutzung von Agents im standard harness mit null abgerechnet.

Die konkreten Ops-Fälle, in denen es sich rechnet: ein RevOps-Agent in Teams, der „Wie steht die Contoso-Verlängerung?“ beantwortet, indem er Dynamics oder Salesforce plus den SharePoint-Ordner des Accounts liest; ein Legal-Ops-Intake-Agent, der eingehende Anfragen aus einem geteilten Postfach klassifiziert und mit einer Pause für menschliche Freigabe weiterleitet; ein Recruiting-Koordinations-Agent, der per Computer Use Angebotsdaten in ein altes HR-Portal ohne API einträgt.

## Preisrealität

Alles wird in **Copilot Credits** gemessen, gepoolt über den ganzen Tenant:

- **Capacity Pack: 200 USD/Monat für 25.000 Credits** (0,008 USD pro Credit), vorausbezahlt; ungenutzte Credits verfallen.
- **Pay-as-you-go: 0,01 USD pro Credit**, nachträglich über ein Azure-Abonnement abgerechnet.
- **Pre-Purchase-Plan:** bis zu 20 % Rabatt für eine Vorab-Zusage von Credits.
- **Microsoft 365 Copilot (30 USD/Benutzer/Monat; Copilot Business 21 USD, 18 USD als Aktionspreis bis 31. Dezember 2026, bis 300 Plätze)** enthält den standard harness und rechnet die mitarbeiterseitige Nutzung mit null ab, wenn der lizenzierte Benutzer selbst mit dem Agent spricht.

Die Tariftabelle ist das, was zum Budget wird. Klassische (manuell verfasste) Antwort: 1 Credit. Generative Antwort: 2. Agent-Aktion — ein Trigger, ein Tool-Aufruf, ein Reasoning-Schritt: 5. Tenant-Graph-Grounding: 10. Agent-Flow-Aktionen: 13 Credits pro 100. Reasoning-Modelle kosten zusätzlich 10 Credits pro 1.000 Tokens auf den Funktionstarif. Eine einzelne Antwort mit Grounding kostet also 12 Credits, rund 10 Cent im Pay-as-you-go.

Zwei durchgerechnete Spannen:

- **Interner Q&A-Agent, 200 Mitarbeitende ohne Copilot-Lizenz, je 20 Fragen mit Grounding pro Monat:** 200 × 20 × 12 = 48.000 Credits — zwei Packs, **400 USD/Monat, rund 4.800 USD/Jahr**. Derselbe Agent, genutzt von 200 Copilot-lizenzierten Mitarbeitenden, kostet keine zusätzlichen Credits, aber die Lizenzen selbst kosten 72.000 USD/Jahr.
- **Autonomer Pipeline-Hygiene-Agent, 3.000 ausgelöste Läufe pro Monat mit 6 Aktionen plus 1 generativer Antwort:** 32 Credits × 3.000 = 96.000 Credits — **800 USD/Monat in vier Packs oder 960 USD im Pay-as-you-go**. Autonome Trigger und Agent Flows, die durch etwas anderes als die Konversation eines lizenzierten Benutzers gestartet werden, laufen zum Standardtarif — unabhängig davon, ob Ihr Team Copilot-Lizenzen hat.

Computer Use wird zum Agent-Aktionstarif abgerechnet und ist nie durch die Microsoft-365-Copilot-Lizenz abgedeckt; die gehostete Maschine, auf der es läuft (Windows 365 for Agents), ist eine separate Rechnung. Der GitHub Copilot harness ist wieder ein anderer Zähler: Er berechnet Tokens, Tools und den Harness selbst, und er rechnet **ab dem Moment ab, in dem ein Maker mit dem Bauen beginnt** — Previews, Tests und Evaluierungen eingeschlossen —, während der standard harness erst nach der Veröffentlichung abrechnet.

## Am besten für

Eine IT- oder RevOps-Führungskraft in einer **Microsoft-365-E3/E5-Organisation mit 200 bis 5.000 Mitarbeitenden**, die mitarbeiterseitige Agents in Teams braucht, die SharePoint und das CRM lesen, über Konnektoren Aktionen ausführen und ein Security-Review ohne separate Identitätsschicht bestehen. Der Fall, in dem es klar gewinnt: ein interner Agent, dessen Nutzer bereits Microsoft-365-Copilot-Lizenzen haben, weil die Kosten pro Konversation auf null fallen und die Governance mit dem Tenant mitkommt.

## Nicht für

Ein Ops-Team mit 10 bis 50 Personen auf Google Workspace, oder ein Team, dessen Agents hauptsächlich in HubSpot, Salesforce und Slack schreiben statt in Microsoft-Systeme. Sie würden Power-Platform-Umgebungen, Kapazitätszuweisung und Entra-Administration einkaufen, um zu bekommen, was [n8n](/de/tools/n8n/) ab 20 €/Monat oder [Lindy](/de/tools/lindy/) ab 50 USD/Monat liefert. Es ist auch der falsche Kauf für kundenseitige Automatisierung mit hohem Volumen, bei der Sie feste Kosten pro Lösung brauchen: Ein Credit-Zähler, der pro Schritt abrechnet, wird teuer, wenn Agents in langen Schleifen schlussfolgern.

## Im Vergleich zu den Alternativen

- **[Salesforce Agentforce](/de/tools/salesforce-agentforce/)** — der andere Marktanteilsführer unter den Enterprise-Agent-Buildern. Wählen Sie es, wenn die Datensätze, auf die der Agent zugreift, in Salesforce liegen. Agents direkt neben dem CRM-Datensatz schlagen Agents, die über einen Konnektor hineingreifen, und Salesforce-zentrierte Revenue-Teams kommen mit der nativen Trust-Schicht weiter als mit einem Power-Platform-Konnektor.
- **[Google Gemini Enterprise](/de/tools/gemini/)** — das direkte Gegenstück für Google-Workspace-Häuser, pro Platz ab 21 USD/Monat, mit eingebauten No-Code-Agents. Wählen Sie es, wenn E-Mail, Dokumente und Identität bei Google liegen; die Vorteile von Copilot Studio verschwinden außerhalb eines Microsoft-Tenants weitgehend.
- **[n8n](/de/tools/n8n/)** — der am schnellsten wachsende Neueinsteiger in diesem Segment, und die richtige Wahl, wenn die Workflows deterministisch sind, die Systeme überwiegend nicht von Microsoft stammen oder Sie selbst hosten müssen. Abgerechnet wird pro Ausführung, nicht pro Reasoning-Schritt, was bei Flows mit hohem Volumen deutlich planbarer ist. n8n-Agents registrieren sich ebenfalls mit einer Entra Agent ID in Agent 365; die Wahl kostet Sie also nicht die Tenant-Governance.
- **[Relevance AI](/de/tools/relevance-ai/) / [Lindy](/de/tools/lindy/)** — wählen Sie diese für ein GTM-Team, das SDR- oder Research-Agents noch diesen Monat produktiv haben will, ohne einen Power-Platform-Admin dazwischen.
- **[UiPath](/de/tools/uipath/)** — wählen Sie es statt Computer Use in Copilot Studio, wenn UI-Automatisierung die Kernlast ist (Hunderte Läufe pro Tag, SAP- oder Mainframe-Masken, attended Robots) und Sie ausgereiftes Exception-Handling und Orchestrierung brauchen statt eines Agents, der gelegentlich klickt.

## Stolpersteine

- **Die 125-%-Schwelle schaltet Agents ab.** Erreicht ein Tenant mit vorausbezahlter Kapazität 125 % seiner Credits, werden Custom Agents abgeschaltet — Nutzer sehen „This agent is currently unavailable“ —, und neue Agent-Flow-Läufe werden blockiert, sobald die Kapazität aufgebraucht ist. **Absicherung:** Verknüpfen Sie jede Produktionsumgebung mit einem Pay-as-you-go-Abrechnungsplan in Azure, damit Mehrverbrauch abgerechnet statt blockiert wird, und setzen Sie monatliche Credit-Limits pro Agent unter Power Platform admin center → Licensing → Copilot Studio → Manage Agents.
- **„In Copilot enthalten“ ist enger, als es klingt.** Die Null-Abrechnung deckt Konversationen ab, in denen ein Copilot-lizenzierter Mitarbeitender der authentifizierte Benutzer ist. Autonome Trigger, Agent Flows mit anderen Triggern, Computer Use und alle ohne Lizenz laufen zum Standardtarif. **Absicherung:** Lassen Sie vor dem Rollout den Agent Usage Estimator von Copilot Studio pro Agent laufen, trennen Sie lizenzierten Konversationsverkehr von autonomem und unlizenziertem Verkehr, und budgetieren Sie die zweite Gruppe mit 0,01 USD pro Credit.
- **Der GitHub Copilot harness rechnet schon beim Bauen ab.** Maker, die in der Preview iterieren, verbrauchen echte Credits, bevor irgendetwas live geht. **Absicherung:** Geben Sie Maker-Umgebungen eine eigene kleine Credit-Zuweisung, getrennt von der Produktion, damit Experimente nicht die Kapazität aufbrauchen, von der produktive Agents abhängen.
- **Zwei Agent-Identitäten in einem Tenant.** Vor Juli 2026 erstellte Agents laufen noch über klassische App-Registrierungen und warten auf eine von Microsoft geplante Migration; neue erhalten Entra Agent IDs. Conditional Access, das für die einen geschrieben ist, deckt die anderen nicht ab. **Absicherung:** Exportieren Sie das Agent-Inventar (Admin Center, API oder Azure Resource Graph), kennzeichnen Sie jeden Agent nach Identitätstyp und schreiben Sie Richtlinien für beide, bis die älteren Agents migriert oder neu erstellt sind.
- **Premium-Konnektoren und Cloud Flows sind eine separate Lizenz.** Power-Automate-Cloud-Flows nutzen Power-Automate-Lizenzen, keine Copilot Credits; nur Agent Flows laufen auf Credits. **Absicherung:** Bauen Sie agentgesteuerte Automatisierung als Agent Flows innerhalb von Copilot Studio, und kalkulieren Sie jeden eigenständigen Cloud Flow gegen Power Automate Premium, bevor Sie ihn zusagen.
