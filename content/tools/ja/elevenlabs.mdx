## 概要

このページが扱うのは、ElevenLabs の音声・チャットエージェント基盤である ElevenAgents です。同社がよく知られている text-to-speech、吹き替え、音楽の各製品ではありません。ElevenAgents では、ワークフロービルダーまたは API と SDK でエージェントを構築し、ナレッジベースに接地させ、LLM を選び、電話番号または自社の SIP トランクを接続して、電話回線、Web ウィジェット、テキストメッセージに展開できます。[Retell AI](/ja/tools/retell-ai/) や Vapi と同じ「自分で組み立てる」レイヤーに位置しますが、ほとんどの評価を左右する違いが 1 つあります。それらのプラットフォームが再販している音声モデルを作っているのが ElevenLabs だという点です。

同社は音声 AI で最も資金力のある独立系企業です。2026年2月4日に Sequoia 主導、評価額110億ドルで5億ドルのシリーズ D を調達し、5月5日に発表された3回目のクロージングでは BlackRock、Wellington、D.E. Shaw、NVIDIA の NVentures が加わりました。2025年末の ARR は3億3,000万ドル超で、2026年の最初の4か月で ARR 5億ドルを突破したと発表しています。エージェントの導入企業として Revolut、Klarna、Deutsche Telekom、Square の名前が挙がっています。

## CX・サポートのスタックに登場する理由

- **音声品質と言語カバレッジこそが製品であり、追加項目ではありません。** Revolut は2026年1月、英国と欧州の400万人超の顧客向けに、電話の一次サポートへ ElevenLabs のエージェントを導入しました。31以上の言語で稼働し、リアルタイムで言語を切り替えます。ベンダーが公開した事例では、第1フェーズで解決までの時間が8分の1以下になったと報告されています。他のプラットフォームでは ElevenLabs の音声はプレミアムなアドオンで、Retell では基本料金に加えて1分あたり $0.04〜$0.10 かかります。
- **リファレンスとなる導入事例は大規模かつ規制業界です。** Klarna は2026年2月、ElevenAgents の音声エージェントを米国電話サポートの最初の窓口にし、米国の顧客3,500万人全員が利用できるようにしました。支払い状況や製品に関する質問に対応し、複雑な通話や機微な通話は人間に引き継ぎます。Klarna は、エージェントが対応した通話で最大10倍速い解決を報告しています。
- **CRM だけでなくヘルプデスクにもつながります。** ドキュメント化された連携先は Salesforce、HubSpot、Zendesk(チケットの参照・作成・ルーティングに対応するファーストパーティ連携)、ServiceNow、Twilio、Vonage、Genesys で、さらに MCP で公開された任意の API に接続できます。
- **テスト機能が組み込まれています。** 実際の通話を受ける前に、過去のトランスクリプトや新しいシナリオから作ったシミュレーション会話でエージェントを試せます。自前で作る音声プロジェクトの多くが省いてしまう工程です。

## 価格の実態

公開されている料金体系は、Free(通話15分)から、Starter 月額 $6(75分)、Creator $22(275分)、Pro $99(1,238分)、Scale $299(3,738分)、Business $990(12,375分、同時通話40)までです。どのプランも通話1分あたり同じ $0.08 に相当し、追加分も $0.08 で課金されます。電話回線に ElevenLabs の手数料はかかりません。Twilio や SIP トランクを持ち込む場合は、そのキャリアから直接請求されます。

$0.08 は総額ではありません。LLM の利用料は別途かかり、モデルによって変わり、同じクレジット残高から差し引かれます。同時通話の上限を超えた通話はバーストモード(上限の3倍まで)で処理され、料金は2倍の1分あたり $0.16 です。実際の単価は $0.08 に、選んだモデルの1分あたり LLM コストと、キャリア料金を足したものです。プラン価格を信じるのではなく、パイロットで測定してください。Enterprise は個別見積もりで、HIPAA 向けの BAA、カスタム DPA と SLA、米国・EU・インドでのデータレジデンシー、より高い同時通話数はこのプランで提供されます。

## 最適な対象

エージェントを担当できるエンジニアを抱え、通話者が多くの言語を話す mid-market およびエンタープライズ企業の CX・サポートエンジニアリング責任者です。具体的には、情報提供やアカウント状況の通話に対して電話の一次サポートを運用するフィンテック、マーケットプレイス、通信、消費者向けサブスクリプション事業です。音声品質と言語カバレッジがプロジェクトを決める場合、開発者向けレイヤーで最も有力な選択肢です。

チーム内にプロンプト、ツール呼び出し、評価を担当する人がいない場合、導入をベンダーに一括で任せたい場合、またはボリュームの大半がチャットの場合は見送ってください。ElevenLabs のエージェントはテキストも扱えますが、購入する理由は音声です。

## 代替製品との比較

開発者向け音声プラットフォームの2つの定番は [Retell AI](/ja/tools/retell-ai/) と Vapi です。すべて込みの分単価($0.07〜$0.31)と音声ベンダーの選択肢が欲しいなら Retell を選んでください。エンジニアが音声、LLM、電話回線を個別に組み合わせたく、$0.05 のオーケストレーション料金と引き換えに予測の難しさを受け入れられるなら Vapi です。3社の中で最も成長が速いのは ElevenLabs で、顧客が評価するのが音声そのものである場合に選んでください。

導入をベンダーに任せたいなら、マネージド型を購入してください。医療・ホスピタリティの基幹システムなら [PolyAI](/ja/tools/polyai/)、EU の金融サービスや BPO が運営するコンタクトセンターなら [Parloa](/ja/tools/parloa/)、エージェントがチャットと音声の両方で取引を実行し、成果報酬型の課金を受け入れるなら [Sierra](/ja/tools/sierra/) です。[Decagon](/ja/tools/decagon/) は自社の音声チャネルを ElevenLabs 上に構築しているため、チャットでのディフレクションが主な仕事で、音声が2番目のチャネルである場合に選んでください。

どれも合わない場合は、電話には人間を残し、情報提供系の上位3つのインテントの時間外あふれ呼に限って ElevenLabs のエージェントを置いてください。

## 注意点

- **HIPAA またはゼロリテンションのワークスペースでは MCP サーバーを使えません。** ElevenLabs 自身のドキュメントによれば、これはエージェントの MCP 設定にかかわらず適用されます。対策：PHI やゼロリテンションが対象範囲に入る場合は、初日からすべてのツール呼び出しを直接の webhook またはサーバーツールとして設計し、アーキテクチャを承認する前に制限の現状を書面で確認してください。
- **プラン価格には LLM とバーストの費用が見えていません。** 対策：実際のインテント構成で2週間のパイロットを実施し、モデルごとに1分あたりの LLM コストを記録し、ACD のデータからピーク時の同時通話数を見積もってバーストを例外にとどめ、その実測した総額単価を基準に Enterprise を交渉してください。
- **目玉の成果はベンダー発表で、簡単な通話に限られています。** Klarna の10倍と Revolut の8倍はどちらも ElevenLabs の事例紹介によるもので、両社とも複雑な通話は人間に回しています。対策：人間のベースラインに対してインテントごとの自己完結率の目標を設定し、速度ではなく自己完結率と転送率でパイロットを評価してください。
- **ダウングレードや解約をすると、支払い済みのクレジットは失効します。** 対策：パイロットのボリュームが安定するまでは月額払いにとどめ、その後で年間契約または Enterprise に移行してください。
