デューデリジェンスの責任者が、署名まで3週間という状況で仮想データルームから4,000件の契約書を取り出す。[Kira Systems](/ja/tools/kira-systems/) と [Luminance](/ja/tools/luminance/) は、どちらもショートリストに入ります。両者を区別する枠組みとして今も使われているのは、Kira は自分で教え込む必要がある学習済み条項モデルの抽出ツール、Luminance は文書群全体を素の状態で読んでおかしな箇所を指摘するツール、という説明です。この振り分けルールはほぼ10年通用しました。Litera はその半分を2026年1月27日に撤回しました。

Kira の Generative Smart Fields は、Litera 自身のドキュメントによれば「ラベル付き学習データの必要性を取り除く」もので、どの言語でも作成できます。Concept Search はプロジェクト内の全文書から概念を「学習もプロンプトもセットアップも不要で」探し出し、GenAI をオフにした状態でも動作します。期限の短い案件を Luminance へ押しやっていた学習コストは、もう存在しません。

いま判断を分けるのは、その作業がどれだけ長く生き続ける必要があるかです。

## Kira が勝つところ

- **デューデリジェンス業務の全工程が1か所に収まる。** keep-awake 付きの一括取り込み、重複排除、データルーム連携。分類・タグ付け・グルーピング・担当割当・言語/管轄の判定によるトリアージ。Analysis Grid での構造化レビュー。比較とレッドライン。Word、Excel、PDF への書き出し。外に出ていくのは書き出したファイルであり、Kira はそれを作るために設計されています。Litera は、弁護士が学習させた1,400以上のモデル群にもとづく90%超の抽出精度、「10年にわたる AI 開発と45,000時間超の弁護士工数」による改良、レビュー時間の最大50%削減を掲げています。
- **案件単位でオフにできる GenAI。** 管理者はプロジェクトごとに GenAI をオン・オフでき、GenAI を使わない機能はそのまま残ります。クライアントごとに outside counsel guidelines が異なる法律事務所 — ある銀行は生成モデルを禁じ、次の銀行は気にしない — にとって、これはプラットフォーム全体の方針論争ではなく案件単位のスイッチです。Kira は顧客データを学習には決して使わないと明言する一方で、顧客自身のデータで独自モデルを学習させる選択肢を提供し、データ保管地は米国、カナダ、欧州、アジア太平洋から選べます。
- **文書だけでなく取引そのものに接続する。** Intralinks と HighQ の連携により、Kira は取引がすでに動いているデータルームの隣に置かれます。Litera Transact 連携では、レビューの進捗とレビュー担当者数が Transact のダッシュボードに直接表示されます。取引管理がすでに Litera なら、デューデリジェンスの作業ラインは横並びではなくその中に報告されます。
- **Lito に追加費用はかからない。** Litera は Word、Outlook、Web で動く AI リーガルエージェント Lito を、Kira 顧客に追加費用なしで提供します — 新規顧客は購入時、既存顧客は更新時または申請時です。ただし金額に織り込む前に細目を読んでください。

## Luminance が勝つところ

- **モデルそのものが製品であり、ベンチマークを公開している。** 2026年6月19日に発表された Luna Crescent は、Luminance が触れてきた2億2,000万件超の検証済み法務文書から抽出した、約340万件の法的概念にわたる厳選データセットで学習しています。Luminance はこれを、手作業で注釈を付けた189,000件のデータポイントからなる独自ベンチマーク ContractIQ Bench で評価し、契約理解タスクで5%高い精度、生成は毎秒200〜400トークンと報告しています。Kira は精度の数値を公開します。Luminance はベンチマークとその背後にあるコーパスまで公開します。
- **チェックリストに載せなかった異常。** Analyze は取り込み時点で1,000を超える法的概念を提示し、「異常・傾向・逸脱... たとえば欠落した条項や通常と異なる文言」を自動的に特定します。デューデリジェンスで高くつく発見は、誰も探そうと思わなかったものです。Kira のグリッドはあなたが立てた問いに答えます。Luminance は立てなかった問いのほうを差し出します。
- **作業が取引を越えて残る。** Luminance にとって10年で最大となる2026年1月27日の再構築は、マルチエージェント構成 — Negotiation AI、Workflow Orchestration、Contract Intelligence、Ask Lumi — の下に組織的記憶を敷きました。各エージェントは交渉履歴と先例からなる長期記憶を参照します。デューデリジェンスの所見は、クロージング資料の中の表計算ファイルではなく、クロージング後の契約管理の初期状態になります。
- **Agent Lumi は報告ではなく実行する。** 2024年10月以降、受領した契約書を自社基準に照らしてマークアップし、必要な承認を起動し、相手方に渡せる版を返します。Luminance は、再構築によって交渉時間の削減率が70〜80%から90%へ上がり、チームは3割超の時間を取り戻すとしています。これらはベンダー側の数値ですが、自律性は実在し、Kira に同等のものはありません。
- **導入の重み。** 70か国超で1,000社を超える企業、直近12か月で1,800万件の契約分析、Deloitte、Quantinuum、Ingram Micro、Baringa といった design partner。2025年2月には Point72 Private Investments 主導で7,500万ドルのシリーズ C を実施しています。

## Lito という注記

Litera 自身の FAQ が率直に答えています。「Lito と Kira は現在、別個のツールとして動作します。Kira と Lito をつなぐワークフローは製品ロードマップ上にあります」。無償のエージェントは、あなたのデューデリジェンス案件の中では動きません。追加費用のかからない2つ目の製品であり、Word と Outlook では実際に役立ち、Analysis Grid には関与しません。「Kira にはエージェントが付属し、Luminance には付かない」でこの2社を振り分けるベンダー資料は、バンドルされた隣接ツールをプラットフォーム内蔵のものと突き合わせています。2026年7月15日の Litera の「1つのエージェント、1つのデータセット」への再出発は、これが解消されるという約束です。まだ解消されていない以上、済んだものとして支払うべきではありません。

## 価格の実際

どちらも価格を公開していません。Litera の Kira ページは「価格はデモをご依頼ください」で終わり、Luminance は営業相談へ誘導します。したがって有効な比較は、値札ではなく形です。

Kira は Lito を無償同梱したエンタープライズ契約インテリジェンスのサブスクリプションとして売られます。第三者の調査は企業向けの下限を年間5万ドル前後としていますが、これは推計であって Litera の数値ではありません。Luminance はプラットフォームとモジュールを売ります。ミッドマーケットの初年度について第三者は総額15万〜30万ドルと見積もり、導入費用は初年度ライセンスの20〜50%が相場とされます。いずれも桁の目安としてのみ扱ってください。両者が一致しているのは、およそ3倍の開きがあり、Luminance のほうが重い約束だという点です。

この差は、取り損ねている値引きではありません。範囲の違いです。Kira はレビュー能力に値付けし、Luminance はレビューもこなす契約システムに値付けしています。

## 本当に効いてくる判断

クロージング後にその契約書は誰のものかを問うてください。答えが「クライアントのもので、こちらは報告書を返す」なら、業務はそこで終わり、プラットフォームの永続性に払う費用はすべて使われない固定費です。答えが「自社のもので、この先7年動き続ける」なら、デューデリジェンスは契約書の一生における1つの出来事にすぎず、出来事の合間に忘れるシステムは、義務の期限が来るたびに同じ文脈を組み直させます。

## 結論

- **Kira を選ぶ**のは、デューデリジェンスが終了日のあるプロジェクト業務であるとき。GenAI ポリシーの異なるクライアントの案件を扱う法律事務所で、プロジェクト単位のスイッチが要るとき。成果物が生きたリポジトリではなく Word・Excel・PDF の報告書であるとき。取引がすでに Litera Transact、HighQ、Intralinks で動いているとき。あるいは通すべき予算がプラットフォームではなくレビューツールのものであるときです。
- **Luminance を選ぶ**のは、クロージング後も契約書が自社に残るとき。チェックリストなしで逸脱を提示してほしいとき。署名後の交渉と義務追跡を同じプラットフォームで担わせたいとき。買い手が法律事務所ではなく企業の法務・調達部門であるとき。あるいは定型契約の自律的マークアップを本気で任せたい業務であるときです。
- **どちらも選ばない**のは、対象が混在していて問いが開かれているとき — [Harvey](/ja/tools/harvey/) と [Hebbia](/ja/tools/hebbia/) のほうが、費用は上がりますがどちらよりうまく扱います。[harvey-vs-hebbia](/ja/vs/harvey-vs-hebbia/) を参照してください。仕事が読むことではなく起案と交渉なら、[Spellbook](/ja/tools/spellbook/) と [DraftWise](/ja/tools/draftwise/) が適切な規模です。署名後の CLM が主目的でデューデリジェンスが従なら、[Ironclad](/ja/tools/ironclad/) と [SirionLabs](/ja/tools/sirionlabs/) がデータルームではなくリポジトリから始めます。どちらの精度の主張を評価する場合でも、[ai-contract-review-accuracy](/ja/learn/ai-contract-review-accuracy/) が、公開された百分率で何が分かり何が分からないかを説明しています。

デフォルトの選択は **Kira** です。期限の短い案件で Luminance を選ぶ理由は Kira に学習が必要だったことでしたが、それは2026年1月に成り立たなくなりました。プロジェクト単位の GenAI スイッチは、法律事務所がいま書面で問われるガバナンスの質問に答えます。Intralinks と Transact の連携は、取引がすでに存在する場所に製品を置きます。同梱の Lito は、切り離されたままであっても上振れ要素です。契約書が自社のもので取引より長く生きるなら、Luminance を買ってください。それは今日確認できる組織図の事実であり、どちらのロードマップへの賭けでもありません。
