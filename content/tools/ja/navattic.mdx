## 概要

Navattic はノーコードのインタラクティブデモプラットフォームです。Chrome 拡張機能が製品の HTML と CSS をキャプチャし、クリック操作できるアプリのクローンを生成します。見込み客はログインもトライアルアカウントもなしに、Web サイト、メール、共有リンクからそのデモを使えます。有料プランのデモは HTML キャプチャから作成します。無料の Starter プランではアップロードしたメディアによるデモも 1 件作れますが、動画や GIF へのエクスポートはありません。そのため、どの HTML デモも製品の録画ではなく製品そのもののように動作します。Navattic は 1,000 社以上の顧客を公表しており、G2 では約 824 件のレビューで 4.7/5 の評価です。Y Combinator 出身の独立企業のままで、2026 年の買収や資金調達の記録はありません。2026 年の製品ラインは 3 つで構成されます。デモプラットフォーム、Copilot（AI によるデモ作成、ボイスオーバー、アバター）、そして Navattic Agents です。Navattic Agents は Web サイト訪問者を案内・選別し、質問に答えながらキャプチャ済みデモを操作する対話型 AI エージェントで、別製品として販売されています。

## RevOps のスタックに入る理由

- **製品と同じように動く PLG 向け Web サイトデモ。** 各デモが HTML クローンなので、訪問者は入力欄に文字を入力し、メニューを開き、画面間を移動できます。マーケティングは「Book a demo」の隣に「Take a tour」として配置し、フォームには決して記入しないセルフサーブ型の検討者に届けます。
- **デモのエンゲージメントがルーティングデータになる。** アカウント識別（Base 以上）は、デモを閲覧している企業を特定します。連携機能はエンゲージメントを [HubSpot](/ja/tools/hubspot/) の Contacts と Companies、[Salesforce](/ja/tools/salesforce/) の Leads、Contacts、Accounts に同期し、新規作成の前に既存アカウントの有無を確認します。ターゲットアカウントが購買意欲の高いフローを完了すると、プレイブックが [Slack](/ja/tools/slack/) またはメールでアラートを送ります。Default の導入事例によると、Navattic は自社のプロダクト起点のリード（PQL）を [Default](/ja/tools/default/) でこの方法でルーティングしています。
- **$500 のプランで Salesforce が使える。** Navattic の料金ページでは、Base（年払いで月額 $500、5 シート）に Salesforce、Marketo「ほか 25 以上」が含まれています。[Storylane](/ja/tools/storylane/) は 5 シートの Growth プランに同じ $500 を請求しますが、Salesforce は月額 $1,200 の Premium まで提供せず、Arcade はネイティブの Salesforce 連携を Enterprise に限定しています。
- **Growth は営業商談でのデモもカバーするようになった。** Growth にはサンドボックスデモ、デモ翻訳、Gong、Salesloft、Outreach、Seismic、Highspot のコネクタ、そして営業担当者向けの Launchpad 機能（リクエストと承認、個人用の紹介動画、バイヤーサークルの発見）が加わります。Web サイト用に Navattic を導入したチームは、2 社目のベンダーなしで同じキャプチャライブラリを営業に渡せます。
- **書き込み権限を持つ MCP サーバー。** 料金ページでは MCP サーバーは Base に記載されています。Navattic のドキュメントでは「on the Startup plan and above」で利用可能とされています。[Claude](/ja/tools/claude/)、[ChatGPT](/ja/tools/chatgpt/)、Gemini Enterprise、Microsoft Copilot Studio は OAuth で接続し、[Cursor](/ja/tools/cursor/)、VS Code、Codex はスコープを選べる個人アクセストークン（有効期限 7〜180 日）を使います。エージェントは分析データ、訪問者データ、Navattic Agents の会話を読み取り、デモを作成・公開し、Launchpad の共有リンクを管理できます。Growth では「MCP suggested demos」が加わります。

## 料金

Navattic は料金ページで Base と Growth の定価を公開しています（2026-11-23 に確認）。年払いは月払いより約 14〜17% 安くなります。

- **Starter — $0。** 1 シート、デモ 1 件（HTML またはメディア）、Starter Copilot、閲覧数無制限、基本的な分析。
- **Base — 年払いで月額 $500**（月払いは $600）、5 シート。HTML デモ無制限、Salesforce、HubSpot、Marketo ほか 25 以上の連携（プレイブック無制限）、MCP サーバー、アカウント識別、A/B テスト、パイプライン影響レポート、プレミアム AI ボイスオーバー、AI アバター 100 分、専任 CSM。
- **Growth — 年払いで月額 $1,200**（月払いは $1,400）、10 シート。Gong、Salesloft、Outreach、Gmail、Outlook、Seismic、Highspot、サンドボックスデモ、デモ翻訳、カスタムドメイン、SSO とディレクトリ同期、AI アバタークローン、アバター 300 分が加わります。Navattic が 2026 年半ばに公開していた年払い $1,000 から 20% の値上げです。
- **Enterprise — 個別見積もり。** オフラインデモ、HTML キャプチャの翻訳、カスタム権限、監査ログ、プロフェッショナルサービス、優先サポートが加わります。
- **Startup — 見積もりのみ。** 自己資金またはシード段階で 30 名以下のチームが対象です。最後に公開された価格は年払いで月額 $125 でしたが、現在のページには「Contact us for pricing」とあります。
- **Navattic Agents — 見積もりのみ。** 会話数とエージェント数で課金され、Base プランへのアクセスが含まれます。
- **実際の支払額。** Vendr によると、Navattic の契約額の中央値は 99 件の購入で年間 $8,500、範囲は $5,000〜$18,000 で、年間前払いや複数年契約により定価から 15〜30% の値引きが可能です。この中央値は Base（定価で年間 $6,000）と Growth（$14,400）の間にあります。Salesforce を CRM として使うなら Base を、サンドボックスやセールスエンゲージメントツールとの同期が要件に入った時点で Growth を予算に組んでください。

## 最適な利用者

- PLG またはハイブリッド型の B2B SaaS 企業で、HubSpot や Salesforce のルーティングにつながる実際に操作できる HTML デモを Web サイトに置きたい、デモ作成者 5〜10 名規模のプロダクトマーケティング・グロース責任者
- Salesforce 連携を年間 $14,400 ではなく定価 $6,000 の予算で必要とする RevOps・デマンドジェネレーションチーム
- ローンチ投稿や SNS 向けに動画や GIF のツアーが欲しいチーム（Navattic は動画をエクスポートしません）、大規模チームで SE が見込み客ごとにデータを編集したサンドボックスを作るエンタープライズのプリセールス組織（Consensus や [Walnut](/ja/tools/walnut/) を検討してください）、UI が毎週変わる製品（HTML キャプチャは自動更新されません）には向きません

## 代替ツールと選ぶべきケース

- **[Storylane](/ja/tools/storylane/)** — ほぼすべての直接比較で競合となる独立系ツールで、顧客チームは 5,000 以上です。スクリーンショット、動画、HTML のキャプチャを 1 つのライブラリで扱い、年払いで月額 $40 から始まり、月額 $2,000 からの AI SDR（RepX）も販売しています。10 シートでは、Storylane の Premium と Navattic Growth の年払い定価はどちらも月額 $1,200 になりました。マーケティングがスクリーンショットや動画のツアーを、営業がプレゼンター型デモを同じツールで必要とするなら Storylane を選んでください。HTML の Web サイトデモが中心業務で、Salesforce が 5 シートのプランに必要なら Navattic を選んでください。
- **Arcade** — 無料利用の裾野が最も広く（企業プロフィールデータによると 20,000 社以上）、現在は AI 動画生成ツールも別製品として販売しています。デモ向けの Growth プランは 1 シートあたり月額 $50（年払いで 15% 割引）、最大 10 シートで、MP4 と GIF のエクスポートに対応します。HTML キャプチャとネイティブの Salesforce 連携は Enterprise 限定です。デモがパイプライン資産ではなく、ローンチや SNS 向けの洗練されたスクリーンショット・動画ツアーなら Arcade を選んでください。
- **[Supademo](/ja/tools/supademo/)** — 最も急成長している新興ツールで、G2 の急成長製品にも選ばれており、従量課金の AI Demo Agent を備えます。HTML デモは Business（年払いで月額 $199、作成者 1 名）から利用でき、Growth（月額 $350）は作成者 5 名とサンドボックスデモをカバーします。Navattic Base の $500、Navattic Growth の $1,200 と比べて安価です。HTML デモとサンドボックスデモを低価格で使いたく、連携先が少なくても構わないなら Supademo を選んでください。
- **[Consensus](/ja/tools/consensus/)** — プリセールス重視で、動画とインタラクティブデモを購買委員会に送り、どのステークホルダーが何を見たかを分析します。2026 年 4 月に対話型デモエージェントの Peel の買収に合意し、定価の公開をやめています。Vendr での中央値は年間 $53,296 です。買い手がエンタープライズの委員会で、ボトルネックが Web サイトのコンバージョンではなく SE のキャパシティなら Consensus を選んでください。
- **[Walnut](/ja/tools/walnut/)** — 営業主導でエンタープライズ価格です。Ignite は年払いで月額 $575、Vendr での中央値は年間 $17,000 で、無料プランはありません。大規模な営業チームで SE がデータを編集したサンドボックスデモを必要とするなら Walnut を選んでください。

## 注意点

- **Growth は 20% 値上がりしました。** 10 シートのプランは年払いで月額 $1,000 から $1,200 に、月払いでは $1,400 になりました。対策：更新の見積もりが新しい定価を基準にしている場合は、Vendr の中央値 $8,500 と Storylane または Supademo の対抗見積もりを商談に持ち込み、複数年の価格固定を交渉してください。Vendr によると、年間契約や複数年契約では定価から 15〜30% の値引きが得られています。
- **キャプチャ形式は 1 種類で、動画はありません。** 有料プランの出力は HTML クローンのみです。対策：同じツアーを LinkedIn の動画、ローンチメールの GIF、ヘルプセンターのクリップとしても使う必要があるなら、Navattic に無理をさせず、2 つ目のツール（Arcade または Supademo）を予算に入れてください。
- **UI をリリースするとキャプチャは古くなります。** HTML クローンはキャプチャした日の製品の姿を示し、再キャプチャは手作業です。対策：公開中のデモごとに担当者を明確に決め、大きな UI リリースのたびに再キャプチャし、2 四半期更新されていないデモは公開を終了してください。
- **Startup プランは見積もりのみで、30 名で対象外になります。** 公開価格はもうなく、次に価格が公開されているプランは年間 $6,000 の Base です。対策：Startup の料金を書面で確保し、契約期間中に資金調達や従業員 30 名超えが見込まれるなら、契約時に Base の価格を交渉してください。
- **Agents はまだ初期段階で、MCP サーバーは公開操作もできます。** Navattic は会話単位で課金される Navattic Agents の顧客成果を公表しておらず、MCP サーバーの Demo Publishing スコープはデモを公開・アーカイブできます。対策：Agents はまず 1 ページだけで、デモ訪問者 1,000 人あたりの商談予約数をベースラインとして試験し、契約に会話数の上限を設けてください。MCP トークンには、エージェントによる変更を人が確認する体制ができるまで、読み取りスコープ（Analytics、Demo Browsing）だけを付与してください。
