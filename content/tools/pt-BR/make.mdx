## O que é

Make (antigo Integromat) é uma plataforma de workflow automation visual — você arrasta módulos para um canvas, conecta dados entre eles, ramifica por condição e publica. Posiciona-se como a alternativa mais potente e barata ao Zapier para times que querem controle real de flow sem escrever código.

## Por que aparece em stacks de ops

- **Editor de flow visual.** Branching, error handling, iterators e aggregators são first-class — não viraram afterthought como no Zapier.
- **Operações são baratas.** O pricing por "operation" do Make tende a ser mais generoso que o modelo por task do Zapier para cenários de complexidade média.
- **Módulos HTTP e JSON.** Power users batem em qualquer API REST, parseiam respostas e roteiam — fazendo dele uma plataforma de integração de verdade, não só uma cola.

## Pricing

- **Free** — 1.000 ops/mês, 2 cenários ativos
- **Core** — $9/mês, 10K ops
- **Pro** — $16/mês, 10K ops + features avançados
- **Teams** — $29/mês, cenários compartilhados
- **Enterprise** — custom

## Melhor para

- Times de ops que cresceram além do modelo de tasks do Zapier
- Automações de complexidade média com branching e error handling
- Times que preferem flows visuais ao n8n script-heavy

## Pontos de atenção

- O catálogo de integrações é menor que o do Zapier — checa teus apps
- A superfície de IA/agente fica atrás de Zapier e n8n
- O editor visual pode ficar transbordado em cenários complexos; precisa de disciplina
