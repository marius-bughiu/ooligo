## Was es ist

Claude Code ist das agentische Coding-Tool von Anthropic: Sie beschreiben eine Aufgabe in natürlicher Sprache, und es liest das Repository, bearbeitet Dateien darin, führt Shell-Befehle und Tests aus und committet oder öffnet einen Pull Request. Es läuft auf derselben Engine über mehrere Oberflächen — eine Terminal-CLI, eine VS-Code-Extension (die sich auch in Cursor installieren lässt), ein JetBrains-Plugin, den Code-Tab der Claude-Desktop-App, den Browser unter claude.ai/code und die mobilen Claude-Apps —, sodass `CLAUDE.md`, Einstellungen und MCP-Server eines Projekts Ihnen zwischen ihnen folgen. Seit Mai 2025 ist es allgemein verfügbar, und laut Anthropics eigener Finanzierungsankündigung vom Februar 2026 lag sein annualisierter Umsatz (Run-Rate) bereits über 2,5 Mrd. US-Dollar.

Dies ist eine Unterprodukt-Seite. [Claude](/de/tools/claude/) behandelt den Assistenten und die API; [Claude Cowork](/de/tools/claude-cowork/) behandelt die Agent-Oberfläche für Menschen, die keinen Code schreiben. Claude Code ist für die Person im Ops-Team, der der Code gehört.

## Warum es in Ops-Stacks auftaucht

GTM Engineers und RevOps-Entwickler liefern immer mehr Integrationscode aus: CRM-Sync-Skripte, Enrichment-Jobs, eigene MCP-Server, Code-Nodes in [n8n](/de/tools/n8n/), Warehouse-Modelle. Der Großteil davon entsteht heute in Claude Code, aus vier Gründen:

- **MCP in beide Richtungen.** Es verbindet sich mit MCP-Servern für [HubSpot](/de/tools/hubspot/), [Salesforce](/de/tools/salesforce/), [Linear](/de/tools/linear/), [Notion](/de/tools/notion/) und [Slack](/de/tools/slack/), und es ist der schnellste Ort, einen eigenen Server zu schreiben und zu testen. Siehe [was ein MCP-Server ist](/de/learn/mcp-server-explained/) und [wann ein Skill einen Server schlägt](/de/learn/claude-skill-vs-mcp-server/).
- **Headless-Läufe.** `claude -p` führt einen Prompt nicht-interaktiv aus und passt damit in CI, Cron-Jobs und Pipelines von GitHub Actions oder GitLab CI/CD. Das Agent SDK stellt dieselben Werkzeuge bereit, um eigene Agents zu bauen.
- **Routines.** In der Cloud geplante Jobs, angelegt mit `/schedule`, die weiterlaufen, wenn Ihr Laptop aus ist, und durch einen API-Aufruf oder ein GitHub-Event ausgelöst werden können — der nächtliche Datenqualitäts-Check oder das montägliche Dependency-Audit, an das niemand mehr denken muss.
- **Geteilte Repo-Anweisungen.** Seit Version 2.1.277 (18. September 2026) liest Claude Code `AGENTS.md`, wenn ein Ordner keine `CLAUDE.md` hat. Ein Repository, das bereits für Codex oder andere Agents eingerichtet ist, funktioniert also ohne doppelte Anweisungen. Existieren beide Dateien, gilt `CLAUDE.md`.

## Die Preisrealität

Claude Code hat keinen eigenen Preis; es ist in jedem bezahlten Claude-Plan enthalten, nicht aber in Free:

- **Pro** — 20 $/Monat, oder 17 $/Monat bei jährlicher Abrechnung
- **Max** — 100 $/Monat oder 200 $/Monat, mit 5× oder 20× der Pro-Nutzung
- **Team** — Standard-Seat 25 $/Monat (20 $ jährlich); Premium-Seat 125 $/Monat (100 $ jährlich), 2 bis 150 Seats
- **Enterprise** — 20 $ pro Seat plus Nutzung zu API-Preisen

Sie können Seats auch überspringen und es mit einem API-Key aus der Anthropic Console, über Amazon Bedrock, Google Cloud's Agent Platform oder Microsoft Foundry betreiben und pro Token zahlen.

Die Tarifliste ist nicht die echte Zahl. Die Nutzung wird zwischen dem claude.ai-Chat, der Desktop-App, Cowork und Claude Code geteilt und zweifach gedeckelt: ein rollierendes Fünf-Stunden-Fenster und ein Wochenlimit, das Anthropic im Lauf von 2026 mehrfach angepasst hat. Ganztägiges Coden an jedem Tag sprengt einen Pro-Seat; dafür gibt es Max und Premium-Seats. Planen Sie einen Standard-Team-Seat für die Analystin oder den Analysten, die oder der ein Skript pro Woche schreibt, einen Premium-Seat (oder Max für Einzelpersonen) für alle, die es als Hauptwerkzeug nutzen, und 100–200 $ pro Intensivnutzer und Monat als Planungszahl. Das automatische GitHub Code Review, auf Team und Enterprise als Research Preview verfügbar, wird separat über Nutzungsguthaben abgerechnet, im Schnitt mit 15–25 $ pro Review.

## Am besten geeignet für

GTM Engineers, RevOps Engineers und Technologen in Legal Ops oder Recruiting Ops, denen ein Repository gehört — die Person, die den CRM-Warehouse-Sync pflegt, den eigenen MCP-Server für den Deal Desk schreibt oder die ATS-Export-Pipeline baut. Der klar abgegrenzte Fall, in dem es eindeutig gewinnt: Änderungen über mehrere Dateien einer bestehenden Codebasis, die weiterhin ihre Tests bestehen muss, gefolgt von einem geplanten oder CI-ausgelösten Lauf desselben Jobs. Damit ist die Frage nach dem Team-Premium-Seat beantwortet: ja für die ein oder zwei Personen, deren Job es ist, diesen Code zu bauen, nein für alle anderen.

## Nicht geeignet für

Menschen, die keine Diffs lesen. Claude Code schlägt Shell-Befehle vor, führt sie aus und committet Code; wenn niemand auf der Empfängerseite beurteilen kann, ob eine Änderung richtig ist, geben Sie dieser Person [Claude Cowork](/de/tools/claude-cowork/) oder einen No-Code-Builder. Es ersetzt auch kein Flow-Tool für Pipelines mit hohem Volumen und fester Form: Sobald der Job „diese Felder jede Stunde verschieben" lautet, sollte der Code, den Claude Code geschrieben hat, in n8n oder Ihrem Orchestrator laufen, nicht in einer Agent-Session.

## Gegenüber den Alternativen

- **[GitHub Copilot](/de/tools/github-copilot/)** — die größte installierte Basis nach Seat-Zahl. Business kostet 19 $ und Enterprise 39 $ pro Nutzer und Monat, und seit dem 1. Juni 2026 wird Nutzung über die enthaltenen AI Credits hinaus zusätzlich gemessen und abgerechnet. Wählen Sie es, wenn die Organisation bereits GitHub Enterprise kauft und der Hauptbedarf Inline-Vervollständigung im Editor für viele Entwickler ist, nicht delegierte mehrstufige Aufgaben.
- **[Cursor](/de/tools/cursor/)** — der umsatzstärkste coding-spezifische Konkurrent; Bloomberg berichtete, dass es im März 2026 die Marke von 2 Mrd. US-Dollar annualisiertem Umsatz überschritt. Einzelpläne beginnen bei 20 $/Monat, Teams bei 40 $ pro Nutzer. Wählen Sie es, wenn die Person in einer IDE lebt und jede Änderung visuell sehen und steuern will; die vollständige Abwägung steht in [Claude vs Cursor](/de/comparisons/claude-vs-cursor/).
- **OpenAI Codex** — der am schnellsten wachsende Anbieter, von mehr als 2 Millionen wöchentlichen Nutzern im März 2026 auf mehr als 5 Millionen im Juni. Es ist in ChatGPT Go (8 $), Plus (20 $) und Business (20 $ pro Nutzer jährlich, 25 $ monatlich) enthalten. Wählen Sie es, wenn das Unternehmen bereits auf ChatGPT Business standardisiert hat, denn dann kommt der Coding-Seat ohne neuen Anbieter. OpenAI hat im Juni 2026 aufgehört, neue Pay-as-you-go-Seats nur für Codex in Business-Plänen zu verkaufen; tokenbasierte Nutzung läuft jetzt über einen API-Key.

## Fallstricke

- **Auto Mode ist jetzt der Start-Berechtigungsmodus.** Ab Version 2.1.283 starten interaktive Terminal- und VS-Code-Sessions im Auto Mode, in dem ein zweites Modell jede Aktion prüft statt eines Menschen. Anthropics eigene Dokumentation sagt, er „garantiert keine Sicherheit". Absicherung: Setzen Sie auf Team und Enterprise `permissions.defaultMode` oder `permissions.disableAutoMode` auf `"disable"` in den verwalteten Einstellungen für die Gruppen, die Produktivsysteme berühren, ergänzen Sie `ask`-Regeln für jedes MCP-Tool, das ins CRM schreibt, und lassen Sie unbeaufsichtigte Sessions in einem Container oder einer Sandbox laufen.
- **Ein Nutzungspool, viele Verbraucher.** Eine Routine, die Chat-Session eines Kollegen und Ihre Coding-Session ziehen aus demselben Seat-Limit, und dieses Limit setzt sich in einem Fünf-Stunden-Fenster zurück, das Sie nicht steuern. Absicherung: Geben Sie geplanten Routines und CI-Jobs einen eigenen API-Key mit Ausgabenlimit, damit ein außer Kontrolle geratener Job nicht die Person aussperrt, die den Seat um 10 Uhr braucht.
- **Die Kosten von Code Review skalieren mit den Pushes.** Wenn ein Repository „After every push" prüft, multipliziert sich der Durchschnitt von 15–25 $ mit der Zahl der Pushes pro Pull Request. Absicherung: Starten Sie Repositories mit „Once after PR creation" oder Manual, und setzen Sie unter claude.ai/admin-settings/usage ein monatliches Ausgabenlimit für den Dienst Claude Code Review, bevor Sie ihn aktivieren.
