## 概要

Synthflow は、AI 電話エージェントを構築するためのノーコードプラットフォームで、2026年からは SMS と WhatsApp のチャットエージェントにも対応しています。対象はコンタクトセンターと、それを支える BPO や再販事業者です。オペレーションや CX の担当者がビジュアルエディターでエージェントを構築し、カレンダー、CRM、電話システムを接続し、シミュレーションした発信者でテストしてから公開します。webhook を書く必要はありません。そのため立ち位置は、エンジニアがエージェントを持つことを前提とする [Retell AI](/ja/tools/retell-ai/) や [Vapi](/ja/tools/vapi/) とも、エージェントをベンダーが代わりに作る PolyAI や Parloa とも異なります。

同社は 2023年に Berlin で、CEO の Hakob Astabatsyan、CPO の Albert Astabatsyan、CTO の Sassun Mirzakhan-Saky によって創業されました。累計調達額は 3,000万ドルで、うち 2025年6月に Accel が主導した 2,000万ドルのシリーズ A を含み、従業員数は約 70 人とされています。Synthflow は 1 日 100 万件超の通話を処理していると述べており、2026年4月のプレスリリースでは、Freshworks や Thryv を含む 100 社超のエンタープライズ顧客について累計 6,500万件超の通話としています。どちらもベンダー発表の数値です。

## CX・サポートのスタックで採用される理由

- **すでに運用しているコンタクトセンターに組み込める。** Five9 のハンドオフアクション (2026年7月)、8x8 Contact Center との連携 (2026年8月)、Zoom Phone と Zoom Contact Center (2026年6月)、そして SIP 経由の RingCX により、エージェントは既存のプラットフォーム内で電話に応答し、文脈を引き継いだまま発信者を人間のキューに渡せます。Batteries Plus は米国の 700 超の拠点で、Zoom Phone 上で Synthflow を運用しています。
- **チャネルパートナーが販売と導入を担う。** 8x8 は 2026年4月に戦略的パートナーシップを結び、8x8 とそのパートナーが Synthflow を再販できるようになりました。AVANT Communications は 2026年6月23日に独占販売契約を結んでいます。ホワイトラベルはエンタープライズ契約に含まれており、BPO が自社ブランドで運用しているのはこのためです。
- **音声とメッセージングをまたぐ 1 つのエージェント。** エージェントは通話中に SMS や WhatsApp のメッセージを送信でき (2026年4月)、2026年6月からは音声、SMS、WhatsApp の間でメモリーが共有されています。確認のテキストを受け取った発信者がそれに返信すると、文脈を保ったまま同じエージェントにつながります。
- **エンジニア以外でも回せるテスト。** シミュレーションとテストスイートはエージェントエディターから実行でき (2026年9月)、任意の 2 つのエージェントバージョンを並べて比較できます (2026年10月)。プロンプトの編集が予約フローを気づかないうちに壊すことへの防御策です。
- **双方向の MCP。** MCP Connectors (2026年5月) により、稼働中のエージェントが外部 MCP サーバーのツールを呼び出せます。また Synthflow MCP サーバーは Claude の公式コネクタ (2026年7月) および ChatGPT プラグイン (2026年9月) として提供されており、これらのクライアントからエージェントを確認・編集できます。
- **コンプライアンス書類はそろっている。** トラストセンターには SOC 2 Type 2、ISO 27001、GDPR、PCI DSS v4.0.1、HIPAA (自己証明) が掲載されており、2026年5月には EU のホスティングリージョンが開設されました。

## 価格の実態

Synthflow は現在エンタープライズ限定です。セルフサーブのプランは 2026年6月に従量課金に置き換えられ、その従量課金も同じ月に廃止されました。ある価格トラッカーは、6月9日時点で音声エンジンが $0.09/分、これに LLM の費用が $0.02/分から加わる料金を記録し、6月24日には「contracts start at $30,000 annually」とする単一の Enterprise プランを記録しています。現在の価格ページには金額が一切表示されず、無料プランもトライアルもありません。販売されているのは、通話量、電話システム、連携、そして forward-deployed エンジニアによるローンチ支援に応じてスコープが決まる年間契約です。

予算は **年間最低 $30K** を見込み、これは見積もりではなく下限として扱ってください。旧来の音声エンジンのレート $0.09 だけで計算すると、$30K でおよそ 330,000 分をカバーできました (最も安い LLM を加えると約 270,000 分)。つまり、月 5,000 分を処理する営業時間外の回線 1 本だけなら、同じ分数を Retell や ElevenLabs で使う場合よりはるかに高い金額を払うことになります。第三者の価格ガイドでは、含まれる利用分を使い切った後の超過料金は 1 分あたり $0.45–$0.50 程度と報告されています。Synthflow は超過料金を公表していないため、書面で確定させてください。

## こんなチームに向く

Five9、8x8、Zoom、RingCentral の回線で音声エージェントを必要とする CX やコンタクトセンターのオペレーション責任者、そして BPO です。エージェントを構築・調整するのがエンジニアではなくオペレーションのマネージャーであり、通話量が年間 $30K 超の契約を正当化できるケースに向きます。典型的な用途は、予約受付、注文状況の確認、インバウンドの選別、営業時間外のオーバーフロー対応です。

クレジットカードで始めたい場合、どのみちエンジニアがエージェントを持つ場合、あるいは LLM を自分で選んで入れ替える必要がある場合は見送ってください。

## 代替候補との比較

**[Retell AI](/ja/tools/retell-ai/)** と **[Vapi](/ja/tools/vapi/)** は音声エージェントプラットフォームの 2 大定番です。Retell は 1 つのメーターで請求し、標準的な構成で 1 分あたり約 $0.15、QA も組み込まれています。Vapi はオーケストレーションに $0.05/分を課金し、すべての構成要素を自分で選べます。どちらも従量課金で始められます。エンジニアがいて、契約なしでパイロットしたいならどちらかを選んでください。構築者がエンジニアでない場合や、エージェントを Five9、8x8、Zoom の中で動かす必要がある場合は Synthflow を選んでください。

**[ElevenLabs Agents](/ja/tools/elevenlabs/)** は最も成長が速い新規参入で、公開プランでは $0.08/分に LLM 費用が加わります。音声品質と言語カバレッジがプロジェクトの決め手なら ElevenLabs Agents です。エージェントの設計と運用をベンダーに任せたいなら、マネージド型を買ってください。[PolyAI](/ja/tools/polyai/) か [Parloa](/ja/tools/parloa/) です。[Five9](/ja/tools/five9/) を運用していて、そのネイティブ AI がすでに自社の containment 基準を満たしているなら、追加で何も買う必要はありません。

どれも合わないなら、まず通話量が最も多いインテントを Retell か ElevenLabs のセルフサーブ枠でパイロットしてください。そこで得た分数と containment の数値が、Synthflow との契約交渉の材料になります。

## 注意点

- **2026年だけでパッケージが 3 回変わっています。** 定額プランが従量課金に、従量課金がエンタープライズ限定に変わり、パートナー向けの Stripe ベースの再販は 2026年9月15日に終了しました。ガード: 1 分あたりのレート、超過料金、更新時の値上げ上限を契約期間全体について発注書で固定し、エージェントの設定は API 経由でエクスポートしておいてください。
- **モデルを常に自分で管理できるとは限りません。** 2026年8月以降、旧来のセルフサーブプランに残っているエンタープライズ以外のレガシーアカウントは GPT モデルが外され、Synthflow 独自の LLM で動いています。これは、ベンダーが利用者の知らないうちにモデルを変更しうることを示しています。ガード: 使用する LLM と、それを変更する際の通知期間を契約に明記し、モデルが変わるたびにテストスイートを再実行してください。
- **HIPAA は自己証明です。** トラストセンターに第三者による HIPAA の証明はありません。ガード: PHI が通話に関わる前に、署名済みの BAA と SOC 2 Type 2 レポートを求め、その両方がそろうまで機微なインテントは人間のキューに残してください。
- **規模の数値はベンダー発表で、しかも食い違っています。** ニュースルームでは 3,000 社超の企業と 1 日 100 万件超の通話とされている一方、2026年4月のプレスリリースでは 100 社超のエンタープライズ顧客と累計 6,500万件の通話とされています。1 日 100 万件のペースなら、この累計には約 2 か月で達してしまいます。ガード: 自社の電話システム上で自社と同程度の通話量を持つリファレンスを 2 社求め、年間契約に署名する前に、測定可能な containment 目標を設けてパイロットしてください。
