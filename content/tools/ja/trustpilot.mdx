## これは何か

Trustpilot はオープン型のレビュープラットフォームです。誰でもどの企業でもレビューでき、企業側は顧客の招待、返信、評価の表示、そして書かれた内容の分析に対してお金を払います。公開側には 3億6,100万件を超えるレビューがあります（同社発表、2026年6月）。有料側が Trustpilot Business で、CX チームやインサイトチームが実際に購入するのはこちらです。

同社はロンドン証券取引所に上場しており（TRST）、成長を続けています。2026年上半期の売上は $151.4M で前年比 23% 増、bookings は 22% 増の $171.2M、北米の bookings は為替一定ベースで 27% 伸びました（2026年9月15日公表の決算）。契約の途中で消えるリスクのあるベンダーではありません。

2026年4月、同社は AI 検索を軸にポジショニングを変えました。4月7日の発表では、AI Visibility Metrics（AI 主導の発見のどこに信頼シグナルが現れるか）、招待の対象を絞り込むレイヤー、そしてマーケティング・CX・インサイトの各チームが同じ数字を読むための Reputation Insights ダッシュボードが加わりました。2026年6月29日には作り直された Shopify アプリが公開され、Trustpilot は Shopify 内のレビューにおける主要パートナーに位置づけられました。

## Customer Success と VoC のスタックに登場する理由

- **顧客にフォーム入力を頼まなくても顧客自身が書く、唯一の VoC ソースです。** アンケートはこちらが選んだ質問を測りますが、Trustpilot のレビューは顧客が選んだ不満を捉えます。だからこそ [Enterpret](/ja/tools/enterpret/)、[Chattermill](/ja/tools/chattermill/)、[Unwrap](/ja/tools/unwrap/) はいずれもソースとして取り込んでいます。Trustpilot 自身の Review Insights は、レビューをテーマ別にまとめ、テーマごとにセンチメントをスコア化し、テーマ×星評価のヒートマップを描きます。日付、タグ、キーワードで絞り込めます。
- **評価はもはやバッジではなく、流通チャネルです。** AI のショッピングエンジンや回答エンジンは第三者のレビューシグナルに依拠しており、Trustpilot はレビューページのドメインオーソリティを 93 としています。B2C ブランドにとって TrustScore は、購入者がサイトに来る前にアシスタントが引用するものになりつつあります。AI Visibility Metrics は、それを測ろうとする最初の Trustpilot 製品です。
- **API の範囲は広いです。** 招待、サービスレビュー、商品レビュー、ビジネスユニットをそれぞれ別の API が扱い、さらに Trustpilot のより広いレビューデータベースにアクセスする Data Solutions API があります。Zendesk、Salesforce、HubSpot、Zapier との連携により、サポートや CRM のイベントでレビュー招待を自動送信できます。

## 価格の実態

公式のプランページには、Free（月50件の招待、ユーザー1人）、Starter は1ドメインあたり月 $99 から（招待100件、売上 $5M 未満の新規顧客のみ）、Plus は $319 から（招待300件、ユーザー3人）、Premium は $799 から（招待1,000件、ユーザー10人、専任 CSM、競合インサイトのフルアクセス）、そして個別見積もりの Enterprise が並んでいます。有料契約はすべて12か月前払いで、価格はドメイン単位です。国別サイトを3つ運営するブランドなら、おおよそ3倍を払うことになります。

AI による返信支援と招待の絞り込み機能は Premium と Enterprise にあります。API アクセスはアドオン扱いです。インサイトと API アクセスを求めるミッドマーケットの CX チームにとって現実的な価格帯は、定価に API アドオンを足した推計で **1ドメインあたり年 $10K–25K** です。複数ドメインのエンタープライズ契約はこれを大きく超えます。第三者の掲載サイトでは 2026年3月時点でも Plus を $299 としていたので、定価は今年上がっています。

## 最適な用途

公開評価がコンバージョンを左右し、AI 検索がすでに計測可能なトラフィックを送っている B2C・ecommerce の CX リーダー向けです。小売、旅行、金融サービス、サブスクリプション型の消費者ブランドが該当します。チケットやアンケートと並べて Trustpilot を読む Enterpret や Chattermill のような分析レイヤーも運用している場合に、VoC スタックの一角を占める価値があります。

## 買うべきでないケース

B2B ソフトウェアを売っている場合です。ソフトウェアの購入者が読むのは [G2](https://www.g2.com) やピアコミュニティで、Trustpilot ではありません。しかも Trustpilot はオープン型なので、怒ったサポート問い合わせが数件あるだけで公開スコアが決まってしまいます。テーマ分析だけが目的なら Premium は不要です。Trustpilot のレビューをすでに取り込んでいる VoC ツールのほうが、全チャネル横断でより良いテーマを出せますし、無料プランでも返信は続けられます。

## 代替ツールとの比較

- **Google Business Profile**：量で見れば最大のレビュー面で、無料です。実店舗があり、全国規模の ecommerce をしていないなら、これだけを選んでください。
- **Bazaarvoice**：小売各社のサイトにシンジケートされる商品レビューのエンタープライズ向けの選択肢です。自社ドメインではなく、そのシンジケーションネットワーク内の小売サイトの商品ページにレビューを載せる必要があるときに選んでください。
- **Yotpo**：Shopify ブランド向けのレビューとロイヤルティのセットです。商品ページのレビューとリテンション施策が同じ予算のときに選んでください。
- **Judge.me**：Shopify で最も勢いよく伸びている挑戦者で、無料プランがあり、App Store のページには評価 5.0 で 46,000件を超える加盟店レビューがあります。第三者によるブランド評価ではなく、自社サイト上の商品レビューが必要なときに選んでください。
- **[Qualtrics](/ja/tools/qualtrics/)** と **[Medallia](/ja/tools/medallia/)**：代替品ではありません。両社はアンケートプログラムを運用する側で、Trustpilot はそこに入る非要請型のインプットの1つです。

結論：公開された独立のブランド評価が資産であるなら Trustpilot を買ってください。商品ページが資産であるなら商品レビューツールを買ってください。

## 注意点

- **規制当局は「認証済み」ラベルを検証し始めています。** イタリアの競争当局は 2026年3月、Trustpilot に €4M の制裁金を科しました。認証済みと表示されたものを含むレビューの確認が不十分だったこと、そして企業が誰に依頼するかを選べる招待ツールが理由です。Trustpilot は不服を申し立てています。*対策：* 招待は必ず「注文配達済み」「チケット完了」といった自動イベントから全顧客に送り、手作業で選んだリストは使わず、トリガーのロジックを文書化しておいてください。英国の DMCC Act と米国 FTC の偽レビュー規則は、プラットフォームだけでなく企業側にも責任を負わせます。
- **更新は自動で、価格が上がります。** Capterra のレビューでは、大幅な値上げを伴う自動更新が報告されており、12か月前払いのため年の途中で抜けられません。*対策：* 最初の発注書に更新時の値上げ上限と60日前の通知期限を盛り込み、署名時に通知日をカレンダーに入れてください。
- **G2 の評価は約246件のレビューで 5点中3.4** で、サポート品質が最も低い評価です。*対策：* その CSM を理由に Premium を払う前に、担当 CSM の名前と応答時間の約束を書面でもらってください。
- **スコアは公開されており、自社では管理できません。** 解約してもレビューはプロフィールに残ります。*対策：* 星1・星2レビューへの返信時間を CX の KPI として計測し、サポート責任者を担当者に、48時間未満を目標にしてください。
