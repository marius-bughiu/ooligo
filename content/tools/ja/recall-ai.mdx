## 概要

Recall.ai はミーティング録音のインフラストラクチャ層です。単一の統合された API 呼び出しで Zoom、Google Meet、Microsoft Teams、Webex、Slack Huddles、GoTo Meeting、Whereby、BlueJeans にボットをデプロイする Meeting Bot API です。開発者はミーティング URL と Webhook エンドポイントを送るだけで、ボットが参加し、個々の音声ストリームをキャプチャし、200ms のレイテンシで話者帰属付きのトランスクリプトを生成してデータを配信します。Recall.ai は直接使うノートテイカーではなく、ops チームが実際に使うノートテイカー、面接レコーダー、CRM 自動化ツール、セールスコーチングプロダクトの下で動いているエンジンです。顧客には HubSpot、[Calendly](/ja/tools/calendly/)、[Apollo](/ja/tools/apollo/)、ClickUp、Instacart、[Brighthire](/ja/tools/brighthire/)、[Metaview](/ja/tools/metaview/) が含まれます。同社は 2025 年 9 月に Bessemer 主導の $38M シリーズ B を完了し、2026 年 1 月時点で ARR $31M（2024 年末の $8M から成長）に到達し、2,000 社以上にサービスを提供しています。

## RevOps および Recruiting スタックで採用される理由

**RevOps の文脈：** AI セールスコーチング、ディールインテリジェンス、CRM エンリッチメントのあらゆるプロダクトにはミーティングデータが必要です。Gong、Chorus、Fathom は数年前に相当のコストをかけて独自のキャプチャスタックを構築しました。それらのプラットフォームの上または隣に軽量なプロダクトを構築するチームが Recall.ai を選ぶのは、9 つのビデオ会議プラットフォームにわたる 6〜12 か月分のボットエンジニアリングが不要になるからです。Apollo は Recall.ai を使って通話データを CRM エンリッチメントパイプラインに供給しています。代替手段は Zoom、Teams、Meet のプラットフォーム固有のボットを個別に構築・保守し、さらに大半の自家製ソリューションが完全に省略している Webex と Slack Huddles にも対応することです。

**Recruiting の文脈：** 面接インテリジェンスツール ー [Brighthire](/ja/tools/brighthire/)、[Metaview](/ja/tools/metaview/)、そして ATS ネイティブのノートテイカーの波 ー はいずれもミーティングキャプチャのインフラストラクチャ上に構築されています。Recall.ai はその相当数を支えています。リクルーティングテックのビルダーにとって Recall.ai の代替は、ポイントプロダクトから面接録音をライセンス取得する（そのプロダクト自体が独自のロードマップリスクを持つ依存関係になる）か、ゼロから構築するかです。Recall.ai の SOC 2、ISO 27001:2022、GDPR、HIPAA への準拠は、リクルーティングツールのコンプライアンス対応がインフラ層ですでに解決済みであることを意味します。

## 価格の実態

Recall.ai は 2026 年に月額プラットフォーム料金を廃止し、純粋な従量課金制に移行しました。Pay As You Go 料金は Meeting Bot API または Desktop Recording SDK で録音 1 時間あたり $0.50、内蔵トランスクリプションは 1 時間あたり $0.15 です。ストレージは最初の 7 日間は無料で、延長ストレージは録音 1 時間あたり 30 日間で $0.05 です。Calendar Integration API はすべてのティアで無料です。

新規アカウントには 5 時間の無料クレジットが付与されます — 本格的な概念実証には十分です。Launch ティア（カスタム価格、営業に連絡）は専任 Slack サポート、SSO、アップタイム保証、カスタム契約条件を追加します。Enterprise は HIPAA 対応の BAA とホワイトグローブのインフラサポートを追加します。

スケールすると、ユニットエコノミクスは魅力的です。1 日 3 回、平均 45 分の通話をこなす 100 席の営業チームは、月間約 2,250 時間の録音を生成します — $0.50/時間で約 $1,125、トランスクリプションに $337 で合計月 $1,500 未満、年間 $18,000 未満です。これはインフラコストです。その上に乗るプロダクトには独自の価格が付きます。

## 最適な対象

複数のビデオ会議プラットフォームにわたってミーティングデータをプログラム的にキャプチャする必要があり、独自のボットインフラを構築・保守せずに済ませたい、あらゆる規模の企業の開発者チームまたは AI プロダクトビルダー（RevOps エンジニア、TA テックリード、ミーティングインテリジェンス領域の SaaS ビルダー）。理想的なユースケースは、信頼性の高い話者帰属付きトランスクリプトデータを入力として必要とする、ミーティング隣接 AI プロダクト — 面接サマリー生成、ディールコーチング、通話からの CRM 自動入力 — を構築するチームです。

自分のミーティング用のノートテイカーを探しているエンドユーザーは Recall.ai を使ってはいけません。[Fathom](/ja/tools/fathom/) や類似のコンシューマー製品が適切です。ミーティングがすべて 1 つのプラットフォーム（Zoom のみなど）で完結しており、そのプラットフォームのネイティブトランスクリプション API がすでに動作しているなら Recall.ai は不要です — マルチプラットフォーム抽象化が Recall.ai の核心的な価値であり、シングルプラットフォームのチームにはそれが必要ありません。API を統合・保守するエンジニアリングリソースがなければ対象外です。

## 代替案との比較

**MeetingBaaS** はこのカテゴリで最も急成長している新規参入者で、Recall.ai のより低コストな代替として明示的に位置づけています（「同じ機能の 80% をコストの 50% で」）。トークンベースの料金は小ボリュームでは安く見えますが、月額サブスクリプション（最低 ~$299/月）が必須で、トークン切れで使用量上限に達するとボットがセッション途中で停止します。信頼性テストでは、MeetingBaaS のボットはホストが不在の場合に Zoom ミーティングへの参加に成功したのが 20% 未満でした — Recall.ai が確実に処理する障害ケースです。管理されたバジェット上限を持つ素早い概念実証には MeetingBaaS を選び、本番構築で各プラットフォームティアの信頼性が重要な場合は Recall.ai を選んでください。

**Zoom のネイティブデベロッパー API** は録音とトランスクリプションへのアクセスを提供しますが Zoom 専用です。あなたのプロダクトが Zoom に標準化していて Teams や Meet を使わない企業向けなら、ネイティブ API はよりシンプルで安価です。顧客が混在したビデオ会議環境 — エンタープライズアカウントのほとんどが該当 — にいるなら、Zoom API だけでは構築できません。[Gong](/ja/tools/gong/) と [Chorus](/ja/tools/chorus/) は競合ではなく、エンドユーザー向けに類似のデータキャプチャ問題を解決する完成品であり、新プロダクトを構築する開発者向けではありません。

**Nylas Notetaker** と **Attendee.dev**（オープンソース、セルフホスト）がラインナップを完成させます。Nylas はメール・カレンダー API をノートテイカーとバンドルします。Nylas エコシステムにすでにいるなら Nylas を選んでください。Attendee.dev はインフラとデータレジデンシーの完全なコントロールが必要で、それを運用する DevOps キャパシティがある場合の正解です — コストは API 料金でなくエンジニアリング時間です。

## 注意点

- **プラットフォームポリシーが存在論的依存関係です。** Recall.ai のボットは参加者アカウントとしてミーティングに参加するため、Zoom、Google、Microsoft が利用規約の下でサードパーティのボットアカウントを引き続き許可していることに依存しています。Zoom IQ と Microsoft Copilot for Teams は自社でミーティングインテリジェンス領域で直接競合しており、どちらの企業も 90 日前の通知で API アクセスを制限したりサードパーティボットをブロックしたりできます。Guard：他者に販売するプロダクトの基盤として Recall.ai にコミットする前に、主要な 2〜3 プラットフォームの現在の ToS を確認し、コアアプリケーションロジックを書き直さずにトランスクリプションとストレージをバックアッププロバイダーに切り替えられるようにデータパイプラインを設計してください。
- **コストは使用量とほぼ線形にスケールします。** 固定費用の SaaS とは異なり、Recall.ai の請求は録音ボリュームに比例して増加します。使用量を 2 倍にすると Recall.ai の請求も 2 倍になります。低ボリュームでは問題ありませんが、高ボリューム（月に数百万時間の録音）では、独自インフラの運用コストやエンタープライズ契約の交渉価格が Pay As You Go 料金を大幅に下回る可能性があります。Guard：料金ティアにコミットする前に 12 か月・24 か月の使用量予測をモデル化し、年間に月 50,000 時間を超えることが予想される場合は本番稼働前に営業チームからボリューム割引条件を取得してください。
- **MCP サーバーはコーディングエージェント向けであり、ノーコード自動化向けではありません。** Recall.ai には MCP サーバーがありますが、コーディングエージェントが Recall.ai のドキュメントを読んで API 統合をデバッグできるようにするためのものであり、Recall.ai をノーコードワークフローに接続するためではありません。Guard：チームが Claude や AI エージェントを通じてコードを書かずに Recall.ai を使うことを期待していた場合、それは現在の MCP がサポートしていないことです。統合を構築するには開発者が必要です。
