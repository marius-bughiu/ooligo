## 概要

Salesforce はエンタープライズ向け CRM です。2025年10月の Dreamforce で発表された Agentforce 360 の再アーキテクチャ以降、多くのオペレーションチームが日常的には使っていない名前で販売されています。Sales Cloud は Agentforce Sales として売られ、Data Cloud は Data 360 に、そして Agentforce は他のすべてと同じレコードグラフ上に置かれたエージェントランタイムです。オブジェクトモデル、権限システム、エコシステムは動いていません。動いたのは価格ページ上の SKU 名で、更新見積もりを前年の契約と突き合わせるときにこれが効いてきます。本格的な B2B ソフトウェアベンダーはどこよりも先に Salesforce と連携します。ARR 50M ドル以上の組織や上場企業の営業組織にとっては、いまも事実上のデフォルトです。

## RevOps スタックで採用される理由

- **設定の柔軟性。** カスタムオブジェクト、ワークフロー、入力規則、Apex トリガー、Flow オートメーション。代替製品が4つ目の要件あたりで息切れする具体的なケースがこれです。複数の事業部門にまたがるテリトリー割り当てで、部門ごとに承認マトリクスが異なり、フォーキャストカテゴリのマッピングも別々で、しかも共有のアカウント階層がボードデック向けにきれいに集計されなければならない、という条件です。
- **連携エコシステム。** [Outreach](/ja/tools/outreach/)、[Salesloft](/ja/tools/salesloft/)、[Gong](/ja/tools/gong/)、[Clay](/ja/tools/clay/)、[ZoomInfo](/ja/tools/zoominfo/)、Marketo、Pardot — いずれも深いネイティブ連携をまず Salesforce 向けに出し、他はその後です。
- **ホスト型 MCP サーバーが 2026-04-29 に GA。** Enterprise Edition 以上の組織は、Setup → API Catalog → MCP Servers から Agentforce 360 Platform、Tableau Next、Data 360 SQL 向けの既製サーバーを有効化し、OAuth と PKCE で [Claude](/ja/tools/claude/) や Cursor を接続できます。本エントリの前回改訂以降で実務上もっとも大きい変化がこれです。エージェントのために Salesforce からパイプラインを取り出すのに、自前で保守する中間レイヤーはもう要りません。まずはサンドボックスで読み取り専用の `platform/sobject-reads` サーバーから始めてください。エージェント層そのものの詳細は [Salesforce Agentforce](/ja/tools/salesforce-agentforce/) のエントリにあります。
- **レポーティングの深さ。** ネイティブのレポートとダッシュボードは深いところまで届き、データモデルは先に ETL 層を作らなくても外部 BI(Tableau、Looker、Hex)に供給できるだけ成熟しています。

## 価格

ユーザーあたり月額、年間契約。Sales の価格ページで 2026-08-11 に確認しました。

- **Free Suite** — $0、2ユーザーまで、カスタムオブジェクトなし
- **Starter Suite** — $25、月額でも購入できる唯一のエディション
- **Pro Suite** — $100
- **Enterprise** — $175。API、Sales Engagement、Conversation Intelligence が必要な営業組織にとって現実的なベースライン
- **Unlimited** — $350
- **Agentforce 1 Sales** — $550。組織あたり年間 1M Flex Credits と 2.5M Data 360 クレジット、従業員向けエージェント利用の無計測、Slack Enterprise+、Spiff、Sales Planning、Sales Programs、Maps、Tableau Next を含みます

このはしごの外側に2つのコストがあります。Web Services API は Enterprise 未満では $25/ユーザー/月のアドオンです。つまり Clay や ZoomInfo に書き戻させたい Pro Suite の組織は、実際には $125 を払っています。そして顧客向けエージェントの利用はシートとは別に計測され、Flex Credits は 100,000 クレジットあたり $500、または1会話あたり定額 $2 で、組織はどちらか一方のモデルを選びます(併用はできません)。

実勢レンジは、管理者の人員(おおむねユーザー50〜100人あたり1人)、サンドボックス、連携ライセンス、導入パートナーまで数えるとシート単価の2〜4倍です。Enterprise の100シート組織は定価で年間 $210K、実際は $400〜700K に着地します。

## 適しているケース

ARR 50M ドル以上で複数のレベニューモーションを回している B2B 企業の RevOps リーダー。プラットフォーム移行のコストが Salesforce の運用コストを上回り、監査・規制要件によって共有モデルが「あると便利」ではなく構造的な要件になっている組織です。

## 注意点

- **UX が古い。** [HubSpot](/ja/tools/hubspot/) や新しい世代([Attio](/ja/tools/attio/)、Folk)と比べると見劣りします。営業担当者は不満を言い、その不満は後になって未記録の活動とフォーキャストのズレとして現れます。ガード: 営業担当者の接触面を Salesforce の外に移し、Gong や Slack 上のディール更新を API 経由で書き戻す形にしてください。ネイティブ UI を好きになってもらおうとするより確実です。
- **エージェント支出にはシート単位の上限がない。** Flex Credits と会話単位の課金は人数ではなく利用量に連動するため、サポート寄りのエージェントは誰にも気づかれないまま自分の投資対効果を追い越せます。ガード: 最初のエージェントは Pre-Purchase モデルで固定のクレジット残高に対して動かし、Digital Wallet で四半期まるごと消費を観察してから PayGo に移してください。
- **名称変更が証跡を分断する。** Agentforce Sales と書かれた見積もりと Sales Cloud と書かれた契約は同じ製品を指します。一方で $550 の Agentforce 1 Sales と書かれた見積もりは、前年の $500 の Einstein 1 Sales とは別物です。ガード: 購買部門に、製品名ではなく前回の注文書と SKU 単位で突き合わせさせてください。

代替と選び分けの基準。ARR 25M ドル未満なら [HubSpot](/ja/tools/hubspot/) のほうが良い答えです。3つ目のカスタムオブジェクト、あるいは2つ目の事業部門に到達するまでは HubSpot を選んでください。そこで設定の柔軟性という論点が逆転します。Microsoft Dynamics 365 Sales はエンタープライズ規模のもう一方の選択肢で、組織がすでに Microsoft に標準化していて E5 のライセンス計算が CRM の費目を飲み込む場合に選びます。[Attio](/ja/tools/attio/) はこのセグメントで最も成長が速い新規参入で、50人程度までのチームが AI ネイティブなデータモデルを求め、エコシステムの深さと引き換えに立ち上がりの速さを取るなら Attio です。
