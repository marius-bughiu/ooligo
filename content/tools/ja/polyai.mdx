## 概要

PolyAI は、発信者をチャットへ誘導するのではなく、電話そのものに応答するエンタープライズ向け音声 AI プラットフォームです。テーブルの予約、発信者の本人確認、決済の受け付け、予約の変更まで電話上で完結させます。2017年にロンドンで Cambridge の対話システム研究者 3 名 — Nikola Mrkšić (CEO)、Tsung-Hsien Wen、Pei-Hao Su — が創業し、サードパーティの ASR と TTS を繋ぎ合わせるのではなく自社の音声スタック上で動作します。自社対話モデル Raven は 10 億件を超えるエンタープライズ会話で学習されており、推論レイヤーには GPT-5、Claude、Gemini を代替として使えます。

2025年12月15日に 8,600万ドルのシリーズ D を実施し、Georgian、Hedosophia、Khosla Ventures が共同リードを務め、NVIDIA の NVentures、Citi Ventures、Zendesk Ventures、Point72 Ventures、Sands Capital、Squarepoint Ventures、British Business Bank が参加しました。SiliconANGLE はこのラウンドの評価額を 7億5,000万ドルと報じており、2024年5月の 5億ドルから上昇し、累計調達額は 2億ドルを超えています。ラウンド時点で本番稼働 2,000件超、導入企業 100社超を公表し、2026年5月には 25か国・75言語という規模を示しました。公表顧客には Marriott、Caesars Entertainment、PG&E、UniCredit、Foot Locker、FedEx、Fogo de Chão、Howard Brown Health、Quicken が含まれます。

## CX・サポートのスタックで採用される理由

- **その電話が本当に扱っている業務システムと繋がる。** 音声 AI ベンダーはどこでも Salesforce と CCaaS には接続します。PolyAI の公開カタログはそこから先、顧客が電話をかけている理由そのものである業務システムまで届きます。医療では Epic、athenaOne、ModMed、Cerner (Oracle Health)、Raintree、ホスピタリティでは OpenTable、Tripleseat、HotSOS、Cendyn です。診療記録を読めるエージェントや予約を動かせるエージェントは、CRM のメモしか読めないエージェントとは別の仕事をしています。この両方をカバーするリストとしては、カテゴリ内で最も短いものです。
- **マネージドサービスだけが入口ではなくなった。** 2025年まで一貫した批判は「PolyAI のエージェントは自分では作れない、PolyAI のチームが作る」という点でした。これは 2026年に 2 度変わりました。4月22日に公開された Agent Development Kit は CLI と Python パッケージで、Git を前提としたローカル開発と `poly push` によるデプロイを備えます。エージェントは自社のリポジトリに置かれ、自社の CI を通ります。5月18日には最初の 2 か月を無料とするセルフサーブ登録を開放し、自然言語でオーサリングする Poly Agent Builder も同時に提供しました。
- **音声パスを自社で持ち、その理由を示すモデルを出した。** 2026年7月30日にリリースされた Dialog-RSN-1 はオーディオネイティブで、ターンテイキング、音声認識、function calling、応答生成を 4 段のパイプラインではなく単一のモデルで実行します。PolyAI は A100 GPU 上で 300ms 未満の応答、保険会社での遅延 37% 削減、全国展開のレストラングループでの containment 相対 11% 改善を報告しています。
- **コンプライアンスは価格に織り込まれており、後付けではない。** ベンダーによれば SOC 2、HIPAA、GDPR、PCI DSS は標準で、決済経路として PCI Pal と Stripe がマネージドで用意されています。医療や公益事業のロゴが顧客リストに並ぶ理由がここにあります。
- **エージェントは MCP サーバーをツールとして呼び出せる。** 統合ドキュメントは独自ツール向けの MCP をカバーしており、すでに MCP で公開している社内サービスは専用コネクタなしで音声エージェントから到達できます。向きに注意してください。これはエージェントが自社のツールを使えるという意味で、Claude から PolyAI の分析データを問い合わせられるという意味ではありません。

## 価格の実態

公開情報はありません。価格ページが示す事実は 1 つだけ、利用は分単位課金であるという点で、それ以外の質問はすべてデモへ回されます。公開レートも最低額も超過レートもなく、2026年5月に開放された 2 か月のセルフサーブ試用を除けば無料枠もありません。

第三者のバイヤー分析は、年間契約の下限をおよそ 15万ドルとし、通話量、同時接続数、言語数、統合の深さに応じて上がるとしています。これは見積もりではなく推定として扱ってください。同じ分析は、電話回線、CRM 統合、コンプライアンス対応が通常は別請求になると指摘しています。プラットフォームの金額は初年度の金額ではありません。PolyAI 自身が委託した Forrester の Total Economic Impact 調査は ROI 391%、平均 1,030万ドルの削減を主張していますが、これはベンダー資金の調査です。役員会資料には使えますが、自社のモデルには使えません。

運用上重要なのは、分単位のメーターが平均処理時間に連動するという点です。エージェントが 80 秒で解決するインテントは、同じ通話量なら 120 秒かかる同一インテントより 3 分の 1 安くなります。分数 × containment 率としてモデル化し、成果ベースのメーターと比較する前に、分単位レート、年間最低額、超過レート、未消化分の繰り越しを書面で取り付けてください。

## こんなチームに向く

規制があり電話が主体の業界 — 医療、公益事業、金融サービス、ホスピタリティ、多店舗の飲食・小売グループ — のエンタープライズ CX / コンタクトセンター責任者で、発信者が問い合わせている記録が CRM ではなく Epic、athenaOne、OpenTable、HotSOS にあるケースです。ROI が最も良く効くのは年間およそ 50万音声分を超える帯域で、containment が数ポイント改善すれば 6 桁のコミットを回収できます。統合リストがプロジェクトの成否を決めるとき、カテゴリ内で最も強い選択肢になります。

チャットが接点量の大半を占める場合、初年度予算で 6 桁のコミットを吸収できない場合、購買サイクルを経ずに承認できる公開価格が必要な場合、あるいは自社の記録システムが統合カタログに 1 つも載っていない場合は見送ってください。最後のケースでは、エンタープライズ音声 AI の単価でカスタム API 開発を買うことになります。

## 代替候補との比較

すでに支払っているものから始めてください。NICE CXone、Genesys、Five9 を運用しているなら、それらのネイティブ AI が既存勢力であり、オンボードすべきベンダーも増えません。主要インテントでの containment が自社の基準を満たすならそれを採ってください。通話理由が取引ではなくルーティングと FAQ なら、たいていこれが答えになります。AI ネイティブな音声プラットフォームの中では [Parloa](/ja/tools/parloa/) が最も近い比較対象であり、資本力も上です。2026年1月に 3億5,000万ドルのシリーズ D を評価額 30億ドルで実施し、ARR は 5,000万ドル超、PolyAI が掲げていない DORA 準拠も持ちます。EU の金融サービス購買者である場合、あるいはコンタクトセンターを Teleperformance、Concentrix、Foundever に委託している場合は Parloa を選んでください。これらはすでに Parloa を展開しています。決め手が医療やホスピタリティの記録システムであれば PolyAI です。

最も成長が速い新規参入は [Sierra](/ja/tools/sierra/) で、2026年5月時点で ARR はおよそ 2億ドルです。エージェントがチャットと音声の両方で取引を実行する必要があり、そのために成果ベース課金とより大きなベンダーを受け入れるなら Sierra です。チャットのディフレクションが仕事なら [Decagon](/ja/tools/decagon/)、チャネルの広さとエージェント性能から切り離された請求が欲しいなら [Ada](/ja/tools/ada/)、人間のエージェントを残して置き換えではなくコーチングしたいなら [Cresta](/ja/tools/cresta/) です。

どれも合わないなら、セルフサーブ試用を通話量上位 3 インテントに当て、それ以外は人間に残してください。インテントを整理する前に買った音声エージェントが生むのは、解決した通話ではなく待ち行列までの短い道です。

## 注意点

- **見出しの遅延数値は、手元に来ないかもしれないモデルのものです。** Dialog-RSN-1 は限定提供で英語のみです。既存顧客は今日から有効化できますが、新規顧客はアーリーアクセスを申請する形になります。300ms 未満という数値も遅延 37% 削減もこのモデルのもので、多言語の本番環境は従来のパイプライン上で動きます。ガード: 実際に配信されるモデル、その言語カバレッジ、提供開始日を発注書に明記し、パイロットのベンチマークはローンチ記事のモデルではなく自社トラフィックを実際に担うモデルに対して行ってください。
- **分単位課金は遅延と冗長なエージェントの分も請求します。** 何を「解決」と数えるかの議論から守ってくれるメーターは、逆向きのリスクを渡してきます。応答の遅さも長いプロンプトも、どちらも請求書に現れます。ガード: インテント単位の平均処理時間を初週から人間のベースラインと比較して計測し、分単位レートを契約期間中固定し、その時間が明示した閾値を超えたらレビューが走るトリガーを契約に書き込んでください。チューニングは勝手には起きません。
- **セルフサーブ試用はエンタープライズ製品ではなく、費用が消えるのは統合作業です。** メールアドレスだけの 2 か月無料で試せるのは Agent Builder であって、Epic コネクタ、Genesys の SIP 経路、PCI 範囲の決済フローではありません。ガード: プラットフォーム契約に署名する前に、統合とコンプライアンスの作業を別項目として範囲と金額を確定し、どのコネクタが製品でどれがカスタム開発かを書面で確認してください。第三者分析はいずれも、購買側が驚くのはこの請求だと一致しています。
- **提出済みの売上は評価額から大きく離れています。** 英国で提出された会計書類では、2025年1月31日までの年度の売上は 1,500万ドル、前年の 890万ドルから増加し、損失は 2,660万ドルへ拡大しています。同年12月に付いた評価額は 7億5,000万ドルでした。Deloitte は 3 年で 248% の成長をもとに 2025年の英国で最も成長が速い AI 企業と位置づけており、軌跡は本物ですが、成長前提で評価された企業は複数年契約と数量下限を押してきます。ガード: 初回契約期間は 1 年に抑え、PHI が範囲に入るなら契約前に現行の SOC 2 Type II レポートと署名済み BAA を求め、エージェント定義は ADK 経由で自社の Git リポジトリに保持してください。そのリポジトリが唯一の安価な出口であり、自社が保持することを契約で確認しておく価値があります。
