## Claude が担う役割

Claude は Anthropic のアシスタントとモデル API です。この情報補完パイロットでの役割は限定しています。提供された出典テキストから企業情報の候補を抽出し、検証後に書き出し文を作成します。Claude 自体が企業の従業員数の情報源になるわけではありません。流暢な回答は証拠ではありません。

明示した指示に従って非構造化テキストを解釈する場合に Claude を選んでください。固定の採点ルール、日付確認、完全一致の比較には通常のコードを使います。必要な構造化データがすでに CRM にあるなら、コピーのためにモデルを追加してもデータ不足は解消せず、失敗箇所を増やします。

## 実行方法を選ぶ

[Claude Code のスキル](https://code.claude.com/docs/en/skills)は、再利用する指示と補助ファイルをまとめます。[API の構造化出力](https://platform.claude.com/docs/en/build-with-claude/structured-outputs)は回答のスキーマを制約します。それぞれ異なる設定上の問題を解決しますが、返された事実が正しいとは証明しません。

手作業では抽出結果と出典を並べて確認してください。API で繰り返し処理するなら、出力形式を検証し、証拠を保存し、モデルとプロンプトのバージョンを記録します。[Clay](/ja/tools/clay/) では Use AI とモデルのアカウントを別に設定してください。ローカルスキルのインストールで Clay のテーブルは設定されません。

## 契約と API の費用

[Claude の料金](https://claude.com/pricing)は Pro が **$20/月または$200/年**、Max が **$100/月**、Ultra が **$200/月**です。Free とチーム向けプランもあり、使用量の上限が適用されます。

条件を満たす Max、Ultra、Team には[毎月の API クレジット](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-ultra-and-team-plans)が含まれます。受け取るには対象プランで7日間の有効な契約と Console 組織の紐付けが必要です。クレジットは請求サイクルごとに失効し、対話型の Claude Code には使えません。予算に計上する前に、対象条件と紐付けた残高を確認してください。

API ではキャッシュを使わない入力トークン数と入力単価の積に、出力トークン数と出力単価の積を加えて見積もります。[選んだモデルの現在の単価](https://platform.claude.com/docs/en/about-claude/pricing)を使ってください。該当するツール、キャッシュ、再試行の費用も加えます。実際の処理費用と確認費用を採用レコード数で割ります。契約料金だけでは、自動情報補完の実行費用は算出できません。

## ダウンロード例から試す

[Clay と Claude のワークフロー](/ja/workflows/lead-enrichment-clay-claude/)には20件の合成レコード、抽出と書き出し文のプロンプト、スキーマ、ローカルの検証プログラムがあります。展開したパッケージで `python3 pipeline.py demo` を実行してください。付属データと決定的なコードを使うため、Claude や Clay は呼び出さず、API 費用もかかりません。

任意の Claude Code 経路では、補助ファイルを `.claude/skills/lead-enrichment-clay-claude/` に保持し、その直下に `SKILL.md` を置きます。実際のモデルを動かす前にワークフローの設定手順に従ってください。API や Clay に適用するときは、モデル出力を記載された JSONL 項目に変換します。スキルのディレクトリがそのままインポートできる連携だと考えないでください。

## 引き続き必要な確認

- **有効なスキーマでも事実は誤る可能性があります。** 出典 ID と正確な引用を必須にします。採点前に証拠の欠損、古さ、矛盾を確認してください。もっともらしい推測で空欄を埋めるようモデルに頼まないでください。
- **指示は実行制御の代わりになりません。** CRM への書き込みとシーケンス登録を抽出処理から分離します。草稿はアウトリーチに使う前に確認してください。
- **1回の成功した回答は評価ではありません。** 欠損や矛盾を含む固定のテスト集合を保持してください。プロンプトやモデルを変える前に、棄却動作、修正時間、費用を比較します。

比較には[情報補完の評価ガイド](/ja/learn/data-enrichment-strategies/)を使ってください。[Apollo](/ja/tools/apollo/) は営業開拓データとアウトリーチ機能を提供し、テキストモデルとは役割が異なります。周辺の処理を選ぶ際は [Clay vs Apollo](/ja/vs/clay-vs-apollo/)を読んでください。既存のアシスタントが同じ証拠の確認をより低い実測費用で満たすなら、それを維持します。

**証拠の状態：**公式資料を2026年11月1日に確認しました。このプロフィールのために Claude の実環境抽出ベンチマークやモデル比較は実施していません。オフラインの合成データデモはローカルのルールを検証するもので、モデルの正答率のテストではありません。
