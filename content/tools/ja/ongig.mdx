## 何をするツールか

Ongig は、Rob Kelly が創業した独立系企業 Ongig, Inc. の職務記述書（JD）管理ソフトウェアです。すべての職務記述書をクラウド上のライブラリで管理し、排他的な表現や読みにくさを指摘します。検索向けに職種名をスコアリングし、AI で下書きと編集を行い、完成した求人を ATS に戻します。もともとは「Text Analyzer」として始まり（ログインは今も text-analyzer.ongig.com です）、現在はガバナンス層に成長しています。バージョン履歴、承認ワークフロー、給与透明性チェック、そして最上位プランでは翻訳まで備えています。顧客ページには Intel、Disney、GoDaddy、Yelp、Elastic などのロゴが並びます。

このページが答える問いは次のとおりです。300 件、あるいは 3,000 件の職務記述書が ATS、共有ドライブ、hiring manager の受信トレイに散らばっています。それを統制する専用ツールは必要か、そして Ongig の $4,900 の Lite プランで始めるのに十分か。

## Recruiting スタックに入る理由

- **製品の本体はライブラリであり、ライターではありません。** どの LLM でもそれなりの求人票は書けます。Ongig の価値は、職種ごとにバージョン管理された唯一の正本と、どの求人が古いか、給与レンジが抜けているか、ATS と同期していないかを示すコンテンツダッシュボードにあります。良い求人票を 1 本書くのとは別の仕事です。
- **すでに使っている ATS とつながります。** 連携ページには [Greenhouse](/ja/tools/greenhouse/)、[Workday](/ja/tools/workday/)、[iCIMS](/ja/tools/icims/)、[SAP SuccessFactors](/ja/tools/successfactors-recruiting/)、[Lever](/ja/tools/lever/)、[SmartRecruiters](/ja/tools/smartrecruiters/)、[Bullhorn](/ja/tools/bullhorn/)、[BambooHR](/ja/tools/bamboohr/)、[Workable](/ja/tools/workable/)、[Jobvite](/ja/tools/jobvite/)、Oracle Taleo、UKG などが並び、自社開発の ATS 向けには連携 API もあります。
- **翻訳が統制されたライブラリの中で完結します。** Enterprise プランは求人コンテンツを翻訳するため、ドイツ語や日本語の求人も英語の原文と同じ承認とバージョン管理を通ります。翻訳者のメールの中に埋もれることはありません。

## 料金

Ongig は価格を公開しています。このカテゴリでは珍しいことです。プランは 3 つで、いずれも年額です。

- **Lite — $4,900/年。** 最大 3 ユーザー、100 求人。クラウドの求人ライブラリ、Word またはコピー＆ペーストでの取り込み、Word 書き出し、職種名の SEO スコアリング、読みやすさと表現の提案、メールサポート。**ATS からの取り込みと AI 文章作成は含まれません。**
- **Professional — $14,900/年から。** ユーザー数・求人数とも無制限。ATS/HRIS からの一方向取り込み、AI 文章作成とテンプレート、バージョン履歴、PDF と HTML での書き出し、コンテンツダッシュボード、給与透明性コンプライアンス、専任のカスタマーサクセス担当が加わります。
- **Enterprise — $39,900/年から。** ATS/HRIS との双方向同期、カスタムのワークフロー自動化とアラート、カスタムのロールとレポート、SSO、同期ずれアラート、求人の翻訳が加わります。

単発のサービスもあります。ライブラリ全体のバイアス監査が $6,900 から、一括リライトが $9,900 から、採用サイト構築が $12,900 からです。Ongig は中小企業と非営利団体向けの割引があるとしています。

Lite は 1 ユーザーあたり月額約 $136 に相当します。ATS 取り込みも AI 文章作成もないツールとしては割高です。多くのチームにとって実際の入り口は $14,900 の Professional です。これは Textio の中央値契約額 $24,405（Vendr、2026 年 2 月）の約 60% で、[Datapeople](/ja/tools/datapeople/) について当サイトが見ている $10,000〜15,000 の価格帯の上限にあたります。

## 最適な用途

数百から数千の定常的な職種を抱える雇用主の TA オペレーション責任者と人事コンプライアンス担当者です。hiring manager が求人票を手作業で書き直し、複数の法域で給与レンジ開示の法律が適用され、どの版の職務記述書が最新なのか誰も答えられない、という状況に向きます。Enterprise は、複数言語で求人を出し、翻訳した求人も英語版と同じように承認する必要がある多国籍企業に合います。

**向いていないのは**、1〜2 名のリクルーターがすべての求人票を書き、給与レンジ開示法のない 1 つの州だけで採用している場合です。スタイルガイドを入れた Claude のプロンプト（[JD ライター・スキル](/ja/workflows/jd-writer-claude-skill/) を参照）と ATS に内蔵された生成機能で、限界コスト $0 で十分にこなせます。AI 文章作成が主目的なら Lite も誤った買い物です。Lite には含まれていないからです。

## 代替との比較

- **[Textio](/ja/tools/textio/)** — このカテゴリで最も知られた名前です。実際の採用結果をもとに、応募者層の属性の偏りを含めて誰が応募するかを予測するスコアを持ちます。報告する指標が応募者構成で、採用が主に英語で行われるなら Textio を選んでください。大きなライブラリを既知の価格で統制することが課題なら Ongig を選んでください。
- **[Datapeople](/ja/tools/datapeople/)（Payscale）** — 複数の法域にまたがる、監査可能な給与透明性対応の求人掲載に最も強く、Payscale の市場データがレンジを支えます。すでに Payscale を購入しているならこちらです。翻訳が必要な場合や、デモ前に価格を知りたい場合は Ongig を選んでください。
- **ATS のネイティブ AI と LLM の組み合わせ** — 最も急速に伸びている代替手段です。Greenhouse と Workday はエディター内で職務記述書を下書きします。求人数が少ないならこれを選んでください。ただし、どれも職種横断のライブラリ、バージョン履歴、掲載内容の監査証跡は持っていません。

## 注意点

- **プランの段階分けが、目当ての機能を隠しています。** Lite には ATS 取り込みも AI 文章作成もありません。給与透明性チェックは Professional から、双方向同期・SSO・翻訳は Enterprise だけです。*対策：* デモの前に必須要件を書き出し、料金ページを見ながらそれぞれをプランに対応づけ、発注書にプラン名を明記してもらってください。
- **排他的表現のチェックが 2 通りの形で売られています。** トップページでは機能として挙げられている一方、ライブラリ全体のバイアス監査は $6,900 からの別サービスです。*対策：* リアルタイムの指摘が自分のプランに含まれるかを書面で確認し、監査は過去のライブラリを一括で整理するときだけ購入してください。
- **第三者による裏付けが乏しいです。** 執筆時点で Ongig の G2 と TrustRadius のプロフィールはレビュー 0 件で、サポートや連携の安定性について第三者の評価がありません。*対策：* 自社と同じ ATS・同程度の求人数の導入先を 2 社紹介してもらい、年間契約の前に稼働中の 20 求人で 30 日間のパイロットを行ってください。
- **一方向同期はずれていきます。** Professional では ATS 側の編集が Ongig に戻らないため、ライブラリと公開中の求人が食い違っていきます。*対策：* ATS の権限設定で職務記述書の編集を Ongig に限定するか、Enterprise の双方向同期と同期ずれアラートの予算を確保してください。
- **コンプライアンスの警告は法的助言ではありません。** ツールは給与レンジの欠落を指摘しますが、各州の法律や、2026 年 6 月に国内法化の期限を迎えた EU 賃金透明性指令に準拠していることを保証するものではありません。*対策：* ルールがどの法域をカバーし、どの頻度で更新されるかを確認し、求人テンプレートには引き続き法務の承認を取ってください。
