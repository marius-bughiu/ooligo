商談が終わったとき、営業担当者はどこで何を見たいでしょうか。10人が Attio で録画と文字起こしを見られればよいなら、Pro には録画機能があります。チームで Fathom の録画ライブラリを使いたい場合は、その席数を別途見積もります。Fathom Business を検討する理由の1つは、既に使っている HubSpot に10人全員の会議を同期したい場合です。[Attio の録画設定](https://attio.com/help/reference/productivity-collaborating/call-intelligence/set-up-and-manage-call-recording)・[Fathom の CRM 連携](https://www.fathom.ai/integrations-crm)

## 10人分の年間ソフトウェア予算

以下は2026年11月2日に確認した公開価格で試算したものです。USD 建ての4項目は、10人が通年利用し、Clay のワークスペースを1つ契約する前提です。すべて年払いで、n8n の料金は EUR 建てです。

| 共通の契約 | 計算に使う月額 | 年額 |
| --- | --- | --- |
| [Attio Pro](https://attio.com/pricing/usd) | 10人 × 79 USD | 9,480 USD |
| [Clay Launch](https://www.clay.com/pricing) | 1ワークスペース167 USD から | 2,004 USD から |
| [Claude Team Standard](https://claude.com/pricing) | 10人 × 20 USD | 2,400 USD |
| [Slack Pro](https://slack.com/pricing/pro) | 10人 × 7.25 USD | 870 USD |
| [n8n Cloud Starter](https://n8n.io/pricing/) | 月2,500回の実行で20 EUR | 240 EUR |

**A. 10人で録画し、CRM への転記は手動で行う。** Fathom Team は1人月15 USD で、10人分は年間1,800 USD です。合計は **16,554 USD と240 EUR から**。担当者が Fathom で録画し、確認済みの要約を手作業で Attio に保存します。1ドメイン3人までという制限は、対応 CRM との同期にかかります。録画は10人とも利用できます。Attio の録画機能で足りれば Fathom は不要で、共通部分の合計は **14,754 USD と240 EUR から** です。カレンダーを連携し、レコーダーに会議への入室を許可して、誰が録画を閲覧できるか確認してください。[Fathom の料金](https://www.fathom.ai/pricing?plan=teams)・[Attio の録画設定](https://attio.com/help/reference/productivity-collaborating/call-intelligence/set-up-and-manage-call-recording)

**B. 10人全員が HubSpot でも会議の要約を必要とする。** 既に HubSpot を契約しているチームで Fathom Business を追加する場合、1人月25 USD、10人で年間3,000 USD です。合計は **17,754 USD と240 EUR から** で、A との差は年1,200 USD です。Fathom の資料によると、HubSpot 連携は Team で1ドメイン3人まで、Business でそれを超える人数に対応します。HubSpot 自体の料金は別です。Business を契約しても Attio との同期は設定されません。[Fathom の料金](https://www.fathom.ai/pricing?plan=teams)・[対応 CRM と同期の条件](https://www.fathom.ai/integrations-crm)

両方の試算とも、税金、Clay の追加データクレジットやアクション、Attio の追加クレジット、プランの範囲を超えるモデルや API の利用料、n8n Starter の上限を超える実行分は別です。構築と保守の工数も別に見積もります。初期設定の時間に人件費込みの時間単価を掛け、月間の保守時間に同じ単価と12か月を掛けた額を加えます。通貨を統一する場合は、自社の支払いに適用される為替レートを使ってください。

## 見込み客の情報を確認して営業担当者に渡す

アカウントと営業担当者の対応関係は Attio で管理します。Clay Launch では、まず少数の候補を選び、情報を補完してエクスポートします。情報源がその会社のドメインに対応することを確認し、承認した行だけを Attio に取り込みます。Clay は CRM の自動同期と Webhook による自動化を Growth の機能として案内しています。継続的な更新が必要なら、Growth の料金と接続先への対応を確認してください。Claude には承認済みの情報を渡して担当者向けの下書きを作らせます。チームで定めた条件の処理には n8n を使い、Slack には担当者が閲覧できるレコードのリンクを送ります。[Clay と Claude のワークフロー](/ja/workflows/lead-enrichment-clay-claude/)は架空のデータを使うオフラインの例で、各サービスへの接続は行いません。[Clay のプラン比較](https://www.clay.com/pricing)

## Fathom の会議メモを Attio に保存する検証手順

以下は API 仕様を基にした設計案です。顧客のアカウントでこの連携を動かした実績はありません。Fathom が資料で案内する CRM 連携先には Salesforce と HubSpot があります。Attio 向けには、RevOps の担当者が次の受け渡しを構築し、保守する必要があります。[Fathom の CRM 連携](https://www.fathom.ai/integrations-crm)

1. テスト用の環境で、コピーしてよい会議と、Attio 側でメモを閲覧できる人を決めます。Fathom のユーザーキーで取得できるのは、そのユーザーの録画か、所属チームに共有された録画です。対象の録画に署名付き Webhook を設定し、文字起こし全文を含めず要約を要求します。[API のアクセス範囲](https://help.fathom.video/en/articles/8368641)・[Webhook の設定](https://developers.fathom.ai/api-reference/webhooks/create-a-webhook)
2. 架空の録画 `74201` について、外部参加者の確認済みメールアドレスで Attio の人物レコードを1件に特定します。担当者が要約を承認したら、Attio が返したレコード ID を使ってその人物にメモを作成します。メモに録画 ID を記し、作成したメモの ID を保存します。[Attio のメモ API](https://docs.attio.com/rest-api/endpoint-reference/notes/create-a-note)
3. 同じイベントを2回送り、正しい人物のレコードに承認済みメモが1件だけ残ることを確認します。該当レコードがゼロまたは複数なら、書き込まずに確認担当者へ回します。書き込み後にタイムアウトした場合は、再試行の前に録画 ID を Attio で検索します。結果が不明なら人が確認します。閲覧を許可されていない人がコピー先のメモを開けないことも確認してください。

自社環境でこれらのテストに合格するまでは、手動の確認を続けてください。照合失敗や再試行を担当できる人がいなければ、Attio で録画するか、確認したメモを手で保存する方法があります。週次の営業会議には、CRM から書き出した2回分のデータを使う[売上予測会議の準備例](/ja/workflows/forecast-meeting-prep-skill/)が参考になります。

## この構成が向いているチームと、別のシステムで扱う業務

この構成は、顧客レコードを Attio で管理したい営業チームで、インポートや照合失敗の担当者を決められる場合に向いています。既存の CRM で見込み客の振り分けができているなら、移行する前にその CRM から書き出したデータで情報の補完を試してください。開発者が既に連携サービスを運用している場合は、そこに会議メモの処理を加える場合と n8n を導入する場合の費用を比べます。どちらを選んでも、担当者が録画の受信からメモの保存まで追跡できることが条件です。

顧客からの値引き依頼を記したメモは、営業担当者にとって有用です。価格ルールの適用、値引きの承認、請求書の発行は、引き続き見積・請求システムで扱います。商談予測に製品利用状況や請求データも使うなら、それらを結び付けるレポートの設計が別途必要です。いずれの費用も先ほどの10人分の予算には含まれません。
