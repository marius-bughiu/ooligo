## 概要

PandaDoc は、営業提案書、見積書、契約書、フォームを対象とするドキュメント自動化プラットフォームで、電子署名と決済回収を標準で備えています。SMB の営業チーム向け提案書ツールとして始まり、現在は承認ルーティング、検索可能なドキュメント保管、更新通知といった契約フローを十分にカバーしており、営業契約向けの軽量な CLM として機能します。現在も独立企業で、2025年9月時点の自社発表では顧客 56,000 社以上、従業員 700 名以上です。2026年1月から Keith Rabkin が CEO を務め、共同創業者の Mikita Mikado は Chief Product Officer に移っています。最も近い競合は、電子署名では DocuSign、提案書では Proposify と Qwilr です。

## Legal Ops と RevOps のスタックに入る理由

- **提案書、order form、署名、決済を1つのドキュメントで完結します。** 顧客契約が提案書の最終ページである場合、PandaDoc はフロー全体を1つのツールに収めます。Legal Ops は営業契約のために別の CLM を買わずに条件を把握できます。
- **エージェントが契約書を作成・送信できます。** PandaDoc は2025年9月16日に公式のホスト型 MCP サーバーを公開しました（`mcp.pandadoc.com`、EU 向けエンドポイントは `mcp.pandadoc.eu`）。ユーザーごとに OAuth で認可します。テンプレートからのドキュメント作成、送信、受信者、ステータス、検索、テンプレートをカバーし、書き込みも可能です。作成、送信、フィールド更新、支払済み・却下のマーク、期限切れ設定、アーカイブができます。PandaDoc は Claude のコネクタディレクトリにも掲載され（2026年7月）、ChatGPT アプリも公開しています（2026年6月）。ベンダーによれば、どちらも Free を含む全プランで利用でき、有料プランには現時点で利用上限がありません。
- **基本的な電子署名を超えるコンプライアンス機能があります。** eIDAS 対応の QES、21 CFR Part 11 への準拠、KBA と本人確認、PandaDoc Notary によるリモートオンライン公証が同じプラットフォームにあります。order form だけでなく、規制対象の契約を送る法務チームにとって重要です。

## 料金

- **Free — $0。** 年間 60 件（月 5 件）のドキュメントで、法的拘束力のある電子署名、ドラッグ＆ドロップエディター、トラッキングが使えます。
- **Starter — 年間払いで $19/seat/月**（月払いは $35。第三者の料金トラッカーによる。ベンダーのページは年間払いで「最大 46%」節約と記載）。アップロードと電子署名は無制限、テンプレートは最大 5 件です。電子署名とフォームのためのプランで、見積、CRM 連携、content library、カスタムブランディングは含まれません。
- **Business — 年間払いで $49/seat/月**（月払いは $65）。提案書のユースケースに必要なのはこのプランです。見積と価格表、CRM 連携、content library、承認ワークフロー、決済、最大 3 つの deal room が含まれます。Salesforce 連携、一括送信、Web フォーム、SSO はここでは標準ではなくオプションのアドオン扱いです。
- **Enterprise — 個別見積**で、seat 単位またはドキュメント単位です。smart content、チームワークスペース、カスタムロール、webhook、米国または EU のデータレジデンシーが加わります。CPQ、ワークフロー自動化、Notary、API アクセスはアドオンです。seat 無制限のドキュメント単位パッケージ（2025年9月に Launch プランとして開始）は営業経由で販売されています。
- **API は別料金です。** PandaDoc の API ページでは無料枠（年間 60 件）と、月 40 件で $40/月の API Developer プランを販売しています。標準の Business プランには API アクセスが含まれません。
- **実際の支払額。** Vendr の年間契約の中央値は $14,868、レンジは $3,662-$37,580 で、購入者は平均 26% を節約しています。Business 10 seat の定価計算はアドオン前で $5,880/年です。Vendr の中央値からは、多くの購入者がその上に seat やアドオン（典型的には Salesforce、CPQ、Enterprise）を追加していることがわかります。

## 最適な利用者

- 顧客契約が提案書に添付され、口頭合意から相手方署名までの時間短縮が目標となる、5-100 名の営業担当を抱える営業主導型 B2B 企業の RevOps・sales ops リーダー
- CLM を運用せずに営業契約を可視化したい Legal Ops チーム
- Claude や ChatGPT のエージェントに、承認済みテンプレートから起案させて署名依頼まで送らせたいチーム
- 購買、ベンダー MSA、双方向で交渉する契約には向きません。PandaDoc は売り手が管理するドキュメント向けに作られており、redlining と署名後の義務管理は手薄です

## 代替候補と選ぶべき場面

- **[DocuSign](/ja/tools/docusign-iam/)** — 電子署名市場のリーダーです。提案書のデザインよりも署名件数、相手方の慣れ、エンタープライズの契約管理を重視する場合に選んでください。第三者の料金トラッカーによると、eSignature プランは年間払いで Standard が $25、Business Pro が $40（ユーザー/月）で、ユーザーあたり年間 100 エンベロープが上限です。IAM プラットフォームには Iris AI と独自の MCP サーバーがあります。
- **Adobe Acrobat Sign** — もう1つの電子署名の既存大手です。すでに Adobe Acrobat のライセンスがあり、署名だけが要件であれば選んでください。
- **Proposify** — 提案書に特化した最も近い競合です。Basic は年間払いで $19/ユーザー/月（月 10 件送信）、Team は $41（月 30 件）です。担当者1人あたり月 30 件未満の提案書を送る小規模チームで、ドキュメントの幅より提案書の分析を重視するなら選んでください。
- **Qwilr** — PDF ではなく Web ページ形式の提案書で、Starter は年間払いで $35/ユーザー/月です。提案書がマーケティング資産である場合に選んでください。ただし Salesforce 連携には最低 10 ユーザーの $75 の Scale プランが必要です。
- **[Concord](/ja/tools/concord/) または [Ironclad](/ja/tools/ironclad/)** — 営業契約だけでなく全種類の契約を Legal Ops が所管する場合は CLM を選んでください。[PandaDoc vs Concord](/ja/comparisons/pandadoc-vs-concord/) も参照してください。

## 注意点

- **Salesforce 連携は Business の価格に含まれていません。** 料金表では Business と Enterprise の両方でオプション扱いです。対策：PandaDoc と DocuSign や Qwilr を seat 単価で比べる前に、Salesforce アドオンの価格を見積書に明記させてください。
- **ドキュメント上限の記載が2通りに読めます。** プラン表では Starter と Business のドキュメントは無制限ですが、料金 FAQ には今も超過料金として Starter 年間払いで1件 $2、Starter 月払いで $3.50、Business 月払いで $2.60 と記載されています。対策：自社プランの送信枠を order form に明記させてください。
- **エージェントが法的拘束力のあるドキュメントを送信できます。** MCP サーバーとコネクタは1つのプロンプトから作成と署名依頼の送信まで行え、ユーザー本人の権限で動作します。対策：エージェントにはロックしたテンプレートからのみ送信させ、承認ワークフローを有効にし、コネクタで作成したドキュメントが承認で止まることをテスト用ワークスペースで確認してから運用に乗せてください。
- **MCP サーバーは連携基盤ではありません。** 人が開始したチャットの中でしか動かず、トリガーがなく、封印済みの署名済み PDF の取得や webhook の購読もできません。これらは API 専用で、webhook には Enterprise が必要です。対策：「ドキュメント署名完了」で起動すべき処理は、コネクタではなく API か [Zapier](/ja/tools/zapier/) 経由にしてください。
- **CLM ではありません。** Business では更新通知がオプションで、義務管理はありません。対策：ベンダー、購買、交渉を伴う契約は CLM に回し、署名済み PDF をメタデータ付きで毎月エクスポートして、リポジトリが PandaDoc の seat 数に依存しないようにしてください。
- **AI Assistant は一般提供されていません。** 検索、Q&A、要約のためのアプリ内アシスタントは、一部の Business・Enterprise アカウント向けのクローズドベータです。対策：今すぐ有効にできる機能で評価してください。条項レベルの法務レビューには、PandaDoc と [Spellbook](/ja/tools/spellbook/) または [Claude](/ja/tools/claude/) を組み合わせてください。
