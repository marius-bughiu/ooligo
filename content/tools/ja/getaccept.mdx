## 概要

GetAccept は、契約をルームの中で署名まで完結できるデジタルセールスルームです。多くのセールスルームは相互アクションプランで止まり、書類手続きは [PandaDoc](/ja/tools/pandadoc/) や [DocuSign](/ja/tools/docusign-iam/) に引き渡します。GetAccept は電子署名と提案書のツールとして始まり、その周りにルームを構築しました。そのため、提案資料、価格表、見積書、注文書、署名欄が 1 つのリンクと 1 つのエンゲージメント記録を共有します。

同社は 2015 年にスウェーデンのマルメで Samir Smajic、Mathias Thulin、Jonas Blanck、Carl Carell によって創業され、Y Combinator（W16）を経て、2020 年末に Bessemer が主導するシリーズ B を調達しました。2023 年の純売上高は 1 億 2,800 万スウェーデン・クローナ（約 1,100 万ユーロ）で、前年比 18% 増と報告しています。現在は米国法人 GetAccept Inc.（サンフランシスコ）を通じて契約し、マルメ、ストックホルム、ロンドンにオフィスを置き、5,000 以上のレベニューチームが利用していると公表しています。顧客基盤は北欧・欧州のミッドマーケットが中心で、スウェーデン、デンマーク、ノルウェー、フィンランド向けの eID 認証をネイティブに備えているのはそのためです。

## RevOps スタックに登場する理由

- **AI ネイティブ Deal Room が唯一のディールルームになりました。** GetAccept は旧来のルーム体験を廃止し、既存のルームとテンプレートを含むすべてのアカウントを移行しました。AI は会議の文字起こしと、追加したファイル、URL、メモからルームを組み立て、テンプレートを商談のステージに合わせて調整し、招待すべきステークホルダーを提案して招待文を下書きし、相互アクションプランを作成・更新します。その後の会議のあとにはルームの更新案を出し、情報が不足していた箇所も含めた変更サマリーを書きます。バージョン比較と復元も可能です。この最後の点が重要で、AI が何を変えたかを買い手より先に担当者が確認できます。
- **契約、見積もり、署名がルーム内で完結します。** 契約テンプレートは、ディールルームの中から 3 ステップのウィザードで送信できるようになりました。価格表と製品ライブラリは Professional、CPQ は Enterprise にあり、署名済み文書は更新リマインダー付きの契約ストアに保管されます。「口頭での合意」から「署名済み」までの間で商談を失っているチームにとっては、別の電子署名ツールへの受け渡しをなくせることが購入理由になります。
- **本格的な API と MCP サーバー。** REST API は契約（文書、価格表、送信、送信後の編集）とディールルーム（ルーム、参加者、アクションプラン、会議、紐づく契約）の両方をカバーし、文書向けに 19、ルーム向けに 10 の Webhook を備えます。MCP サーバーは 2026 年 10 月に `mcp.getaccept.com/mcp` で公開され、Claude、ChatGPT、Gemini、Le Chat から使え、52 のツールを提供します。内訳は読み取り 40、書き込み 12 で、ルームの作成と公開、ステークホルダーの招待、会議の記録、アクションプランのタスク更新などができます。[Aligned](/ja/tools/aligned/) も MCP サーバーを提供していますが、trumpet は API も MCP サーバーも公開していません。
- **会話インテリジェンスのデータを取り込めます。** [Gong](/ja/tools/gong/)、[Salesloft](/ja/tools/salesloft/)、[Airspeed](/ja/tools/airspeed/)、[Fathom](/ja/tools/fathom/)、Zoom、Google Meet、[Microsoft Teams](/ja/tools/microsoft-teams/) とのネイティブ連携により、ルームを組み立てる AI が使う文字起こしが供給されます。

## 価格

ベンダーの価格ページには 3 つのプランがあり、いずれも 12 か月契約です。

- **eSign** — 1 ユーザーあたり月額 25 ドル、最大 5 ユーザー、月払いまたは年払い。電子署名無制限、テンプレート、更新リマインダー付きの契約保管、動画、チャット。ディールルームはありません。
- **Professional** — 1 ユーザーあたり月額 49 ドル、最低 5 ユーザー、年払いのみ。ディールルーム、利用上限付きの GetAccept AI（エディター、スマートコンテンツ、会議サマリー、ナレッジベース）、相互アクションプラン、最大 3 製品の価格表、HubSpot・Pipedrive・Upsales・Lime Go との連携を含みます。AI の無制限利用、AI による契約データ抽出、CPQ、SSO、API アクセス、Salesforce と Dynamics 365 のネイティブ連携は、このプランでは有料アドオンです。
- **Enterprise** — 個別見積もり。CPQ、無制限の製品ライブラリ、SSO、API の読み取りアクセス、プレミアム CRM 連携（Salesforce、Dynamics 365、SuperOffice）、条件付きコンテンツを含みます。

実際の価格帯：ディールルームを使うための最低額は **年 2,940 ドル**（Professional 5 席）です。Salesforce を使う 10 人の担当者チームは **Salesforce アドオンを除いた定価の座席費だけで年 5,880 ドル** を払い、SSO や CPQ が要件に入った時点で実際には Enterprise の見積もりになります。この定価は PandaDoc Business（年払いで 1 席 49 ドル）や [Aligned](/ja/tools/aligned/) Pro（年払いで 49 ドル）と同じで、[trumpet](/ja/tools/trumpet/) の Scale プラン（1 ユーザーあたり月額 100 ドル）のおよそ半分です。trumpet の電子署名はこの Scale プランから始まります。

## 最適な利用者

AE が 5〜50 人の欧州または北欧の B2B 企業で、契約書や注文書で締めくくる 30〜90 日の商談を扱い、セールスルームと別契約の電子署名サービスを組み合わせるのではなく、ルーム、見積もり、署名を 1 つの記録にまとめたい RevOps リードや営業マネージャー。

重心が違う場合は別のツールを選んでください。2026 年 7 月に 6,000 万ドルのシリーズ B を調達したカテゴリ内で最も急成長している新興勢力 [Aligned](/ja/tools/aligned/) は、ルーム内での署名より買い手との共同作業と顧客ポータルが重要で、無料プランでパイロットしたい場合に選びます。[trumpet](/ja/tools/trumpet/) は、インタラクティブデモ（Walnut、Storylane、Navattic）の深い連携と商談ヘルススコアが目的の場合に選びます。[Dock](/ja/tools/dock/) は、ルームが主に多数の外部担当者を招く受注後のオンボーディングポータルである場合に選びます。[PandaDoc](/ja/tools/pandadoc/) または [DocuSign](/ja/tools/docusign-iam/) は、文書・署名ベンダーとして導入基盤が最も大きい 2 社で、本当に必要なのが大量の提案書と署名であり、ディールルームはあれば便利という程度の場合に選びます。

## 注意点

- **Professional では Salesforce 連携が別料金です。** HubSpot と Pipedrive は含まれますが、Salesforce と Dynamics 365 のネイティブ連携は Enterprise 未満ではアドオンです。**対策：** Salesforce を使っているなら、最初の見積もりにアドオンを含めてもらい、49 ドルではなく Enterprise の金額と比較してください。
- **年払いのみで、最低 5 席です。** Professional は月払いの選択肢がない 12 か月契約です。**対策：** 無料トライアルを 2〜3 人の担当者で実際の商談に使い、買い手の再訪問と署名までのサイクルタイムを測定してから、5 席の最低契約に署名してください。
- **基本プランでは AI の利用に上限があります。** ルーム生成、スマートコンテンツ、会議サマリーには利用上限があり、無制限利用はアドオンです。**対策：** トライアル中に担当者 1 人が週に何件のルームと更新を生成するかを数え、予算化の前に利用上限を書面で確認してください。
- **MCP サーバーからは署名依頼を送れず、API の書き込みは追加料金です。** エージェントはルームの作成・更新やリマインダー送信はできますが、契約書の送付はできません。API の書き込みアクセスはすべてのプランでアドオンです。**対策：** 署名依頼の送付はルーム内の人間の作業として残し、CRM やエージェントから文書を作成する予定なら API の書き込みアクセスを契約に明記してください。

ルームの隣にある quote-to-cash のステップについては [DealHub](/ja/tools/dealhub/) を、ルームのエンゲージメントデータが流れ込む商談インスペクション層については [Gong](/ja/tools/gong/) と [Clari](/ja/tools/clari/) を参照してください。
