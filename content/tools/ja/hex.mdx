## 概要

Hex は、データチームが本格的な分析に使う SQL と Python のノートブックを中心に構築された分析ワークスペースで、その上に3つの AI レイヤーがあります。ノートブックエージェントは、プロジェクト内で SQL、Python、チャートを書き、修正します。Threads はセルフサービスのレイヤーです。席を持つ人なら誰でも自然言語で質問でき、回答はチャートとテーブルで返ってきます。その裏には、アナリストが開いて監査できる完全な Hex プロジェクトがあります。モデリングエージェントはセマンティックモデル定義の作成と検証を支援し、既存の定義を dbt MetricFlow、Cube、Snowflake Semantic Views から取り込むこともできます。Threads は Hex の外からも使えます。Slack チャンネルで @Hex をメンションするか、[Claude](/ja/tools/claude/)、[ChatGPT](/ja/tools/chatgpt/)、[Cursor](/ja/tools/cursor/)、[Codex](/ja/tools/openai-codex/) から Hex の MCP サーバーを呼び出します。2026年9月15日以降、これらのチャットクライアントは Hex プロジェクトの読み取りだけでなく、作成と更新もできるようになりました。

2026年には、アナリスト以外の利用を正当化できるガバナンス機能がそろいました。Context Studio(1月28日)は、エージェントが何を聞かれ、何を使い、どこで誤ったかを示します。8月から新しい Threads のデフォルトになった Endorsed モードは、データチームが信頼できると承認したデータだけに回答を限定します。7月30日にはエージェントを CLI と API から呼び出せるようになり、8月4日には evals が加わりました。これにより、データチームは既知の質問セットを公開し、スケジュールで再実行して回答のずれを検知できます。Hex の直近の公表済み資金調達は、2025年5月の7,000万ドルのシリーズ C です。Avra が主導し、a16z、Sequoia、Snowflake Ventures が参加して、累計調達額は1億7,200万ドルになりました。

## アナリストではない Ops 担当者は Hex でセルフサービスできるか

できます。ただし前提条件が1つあります。誰かが先にデータをモデリングしておく必要があります。「前四半期に定価を下回って更新したアカウントはいくつか」と尋ねる RevOps マネージャーは、更新、定価、割引がセマンティックモデルで定義され、承認されていれば正しい回答を得られます。生の CRM テーブルに対しては、エージェントはもっともらしいものの、誤った金額フィールドを拾う SQL を書きます。役に立つ導入と信頼性の問題との差は、まさにここにあります。Hex 自身のクレジットガイドが作業のコストを示しています。単純なカウントは約1クレジット、基本的なチャートは約2、12か月の ARR 予測は約5、インタラクティブなデータアプリは約10です。

## 価格の実態

Community は無料で、月5 AI クレジットが付きます。Professional はエディター1人あたり月36ドルで、エディターごとに30クレジットです。Team はエディター1人あたり月75ドルで、エディターごとに40クレジット、公開アプリ無制限、スケジュール実行とアラートが付きます。Explorer 席は、何も構築せずに Threads とアプリを使う人のためのロールで、Team では月10クレジットが付きますが、Hex は価格を公開していません。Enterprise は個別見積もりで、OIDC による SSO、監査ログ、OpenAI、Anthropic、AWS Bedrock、Google Gemini の bring-your-own-key に対応します。追加クレジットは50クレジットのパックが25ドルで自動補充され、1クレジットあたり0.50ドルです。Medium コンピュート(8 GB、1 CPU)は含まれており、より大きなプロファイルは1時間0.32ドルからの分単位課金です。

購入者データ:Vendr によると、84件の購入に基づく契約額の中央値は年38,550ドルで、範囲は12,726ドルから122,700ドル、購入者は定価から約41%引きで契約しています。Team エディター5人の定価は年4,500ドルなので、Vendr の中央値は主に SSO と Explorer 席を含む Enterprise 契約を反映しています。予算は、Team ワークスペースで年5,000〜10,000ドル、Enterprise の管理機能と数十人の Explorer が必要になったら年25,000〜40,000ドルを見込んでください。ウェアハウスのコンピュート費用は別です。

## 最適な対象

Snowflake、BigQuery、Databricks、ClickHouse にモデリング済みのウェアハウスを持つ企業のデータ・分析リードで、アナリスト水準のノートブック作業を1か所で行いつつ、ガバナンスの効いたセルフサービスの質問を Slack 上の RevOps と CS のチームに渡したい人。社内に SQL を書ける人がいないなら見送ってください。Hex は、モデリング、承認、監査を担うデータチームの存在を前提にしています。

## 代替ツールとの比較

**Power BI** はインストールベースで BI のトップで、Pro はユーザー1人あたり月14ドルです。Microsoft 中心の企業で、固定のダッシュボードが目的なら選んでください。**Tableau** Cloud Creator の定価はユーザー1人あたり月75ドルです。訓練を受けたアナリストが高度なビジュアル探索を行うなら選んでください。どちらにも Hex のノートブックとエージェントの組み合わせはありません。

**[Sigma](/ja/tools/sigma/)** は最も近い購買判断の相手です。スプレッドシートに慣れたビジネスユーザーが、フォーキャストの提出やクォータ計画のようにガバナンスの効いたデータを編集する必要があるなら Sigma を選んでください。書き戻しができる input tables に相当する機能は Hex にはありません。作業がアナリストの問いから始まる場合、Python が必要な場合、あるいは BI ツールを開かない人が Slack や Claude から答えを得るべき場合は Hex を選んでください。

**Omni** は最も急成長している新興勢力で、2026年4月に評価額15億ドルで1億2,000万ドルのシリーズ C を調達しました。従来型ダッシュボードの下に Looker 風のガバナンスの効いたセマンティックレイヤーが欲しいなら Omni を選んでください。ダッシュボードのカタログより探索的分析と対話型の回答が重要なら Hex を選んでください。

単一のウェアハウスで運用していて text-to-SQL だけが必要なら、まずウェアハウス自身のエージェントを試してください。Databricks Genie と Snowflake の Cortex Analyst は、すでに支払っているプラットフォームの中で動きます。複数ソースにまたがるプロジェクト、ノートブック、監査証跡が必要になり、それらのツールでは足りなくなったら Hex に移行してください。

## 注意点

- **クレジットは席数から想像するより早く尽きます。** Team エディターの40クレジットはデータアプリ構築で月4回程度にしかならず、Slack、MCP、CLI からの実行もすべてここから消費されます。*対策:* Explorer に Threads を開放する前に自動補充の月額上限を設定し、30日後に Context Studio でエージェントの活動内訳を確認してください。
- **モデリングされていないデータは、自信ありげな誤答を生みます。** *対策:* Endorsed モードをオンのままにし、導入前に RevOps が実際に尋ねる10〜20の指標をモデリングして承認し、それらの質問で構成した eval スイートを毎週のスケジュールで公開してください。
- **機密テーブルが外部クライアント経由で漏れる可能性があります。** *対策:* PII を含む接続を sensitive に指定して MCP サーバーと Slack エージェントが使えないようにし、Hex だけに頼らずウェアハウス側の行レベルセキュリティと組み合わせてください。
- **Explorer の価格は見積もりのみです。** *対策:* Explorer はエディターより人数が多くなるため、50人規模の導入を見積もる前に、Explorer 席の価格とクレジット付与量を書面で取得してください。
