## 何をするツールか

PatSnap は特許と R&D のインテリジェンスプラットフォームです。ライセンス取得済みのグローバルな特許・文献コーパスに、検索、分析、そして現在では一連の AI エージェントを載せています。Jeffrey Tiong が2007年にシンガポールで創業し、2021年に SoftBank Vision Fund 2 と Tencent がリードした3億ドルのシリーズ E で評価額10億ドルに到達しました。ベンダーは18,000社以上の顧客、174の法域にわたる2億1,400万件以上の特許、2億5,900万件以上の科学文献レコードを主張しており、ライフサイエンスや素材分野のチーム向けに化学構造と生物配列のデータベースも備えています。

製品ラインは3つのレイヤーに分かれます。**Analytics** は、知財部門が10年来ライセンスしてきた従来型の検索・ランドスケープ分析のワークベンチです。**Eureka** は AI レイヤーで、現在のカタログには23のドメインエージェントがあり、Novelty Search、FTO Search、Design FTO Search、Competitive Landscape、Technology Roadmap、Technical Disclosure、Patent Drafting などが含まれます。**Open Platform** は同じデータとエージェントを、REST API、MCP サーバー、埋め込み可能なウィジェット、パッケージ化された Agent Skills を通じて自社のツールに公開します。その横に業界特化の製品（Bio、Chemical、バイオ医薬向けの Synapse、Hiro LS）が並びます。

この位置づけは、[Patlytics](/ja/tools/patlytics/)、[Solve Intelligence](/ja/tools/solve-intelligence/)、[DeepIP](/ja/tools/deepip/) のページを読む人にとって重要です。これらのツールはクレームチャートや出願書類のドラフトといった成果物を生み出します。PatSnap はその作業の下にあるデータと検索のレイヤーであり、先行技術の集合、ランドスケープ、FTO スクリーニングの出どころです。

## Legal Ops のスタックに入ってくる理由

- **堀になっているのはチャット画面ではなくコーパスです。** 174の法域にわたる全文特許に、正規化された出願人、法的状態、ファミリーのデータが付き、文献、化学構造、配列も同じインデックスに入っています。AI ネイティブのドラフティング系スタートアップには、この規模のライセンス済みデータ資産は再現できません。そして FTO 意見の質は、調査した集合の質で決まります。
- **エージェントは名前のついた知財業務ごとに範囲が切られています。** FTO Search と Novelty Search はキーワードのヒット一覧ではなく、理由付きでランク付けされた文献を返します。Design FTO Search は、AI 系の新規参入の多くが手を出さない意匠特許をカバーします。ベンダーは新規性調査で ChatGPT や Claude を上回る85%のヒット率を主張していますが、これはベンダーが選んだデータセットでのベンダー自身のベンチマークです。検証すべき主張として扱ってください。
- **開発者向けの接点は既存大手としては異例なほど開かれています。** ベンダーは Claude Desktop、Cursor などの MCP クライアント向けに20以上の MCP サーバー、300以上のデータ API、60以上のエージェント API を掲げ、LangChain と CrewAI との連携も用意しています。Legal Ops のエンジニアなら無料の Starter 枠から始めて、別途データライセンスの交渉をすることなく、その日の午後には社内エージェントに特許検索を組み込めます。
- **R&D が知財チームを介さずに使えます。** Eureka は法務担当と同じくらいエンジニアにも売られています。TRIZ による問題解決、技術ロードマップ、発明提案書のドラフティングです。これは利用を広げますが、同時に機密情報の露出面も広げます（注意点を参照）。

## 価格の実態

PatSnap はこのセグメントの大半より多くを公開していますが、それは周辺部分に限られます。Eureka Pro は14日間のトライアル（10,000クレジット付き）の後、月額100ドル（年額1,080ドル）です。Life Sciences Pro は月額400ドル（年額3,600ドル）です。Open Platform はクレジット制で10,000クレジットあたり100ドル（1クレジット＝1セント）、無料の Starter 枠は90日間で10,000クレジット、毎分10リクエストまで、Pro は毎分60クエリ、120を超える分はカスタムの Enterprise です。

知財部門が実際に購入する中核の Analytics ライセンスは見積もりのみです。購入者の報告によれば、少数シートのエントリー契約で年間およそ1万5,000〜3万ドル、Insights、Discovery、あるいは化学・生物モジュールを加えると5万ドル以上に近づき、複数シートのエンタープライズ契約は6桁ドルに達します。これらは報告された範囲であり、公開価格ではありません。金額を動かすと報告されているレバーは2つあります。Clarivate または Questel からの書面での競合見積もりと、たまにしか使わないユーザーにライセンスを配るのではなく、ヘビーユーザー用のシートを1〜2つだけ購入することです。

発注書には3点を入れてください。各シートがどのモジュールにアクセスできるか、自動化する予定の各エージェントのクレジット消費率、そして Open Platform のクレジットが Analytics の契約とプールされるのか別枠なのかです。

## こんなチームに向いている

年間数十件の発明を出願またはクリアランスする企業の知財・R&D チーム、特に化学、素材、ライフサイエンス分野で、説明可能なライセンス済みコーパスに基づくランドスケープ調査、新規性調査、FTO 調査を必要とし、そのコーパスに MCP や API 経由で自社のエージェントからアクセスしたいチームです。

**向いていないのは**、ボトルネックがドラフティングの速度やクレームチャートの量である場合です。PatSnap にも Patent Drafting エージェントはありますが、ドラフティング重視のツールのほうが弁理士の作業に近いところにあります。期限管理、年金、知財費用の管理が必要な場合も対象外です。それは [Anaqua](/ja/tools/anaqua/) の仕事です。四半期に数回の調査しかしない個人の実務家にも向いていません。Lens.org と Google Patents は無料です。

## 代替候補と、そちらを選ぶ基準

- **Clarivate（Derwent Innovation）** — 市場シェアでもう一方の既存大手であり、訴訟担当者が信頼する人手で作成された Derwent の抄録とファミリーデータを持っています。調査記録が訴訟や異議申立てで精査される可能性があり、エージェント機能よりもキュレーションされた抄録が重要な場合は、こちらを選んでください。
- **Questel（Orbit Intelligence）** — 3番目の主要なデータ既存大手で、欧州に強く、知財管理サービスとセットで提供されます。調査、期限管理のサポート、更新手続きを1社のベンダーでまとめたい場合は、こちらを選んでください。
- **[Patlytics](/ja/tools/patlytics/)** — 分析側で最も成長が速い AI ネイティブの新規参入で、2026年4月に4,000万ドルのシリーズ B を実施しました。成果物が調査レポートではなく、実施証拠や無効のクレームチャートである場合は、こちらを選んでください。
- **[Solve Intelligence](/ja/tools/solve-intelligence/) または [DeepIP](/ja/tools/deepip/)** — 業務量の中心がドラフティングと権利化であり、調査が製品ではなくインプットにすぎない場合は、どちらかを選んでください。
- **Lens.org、Google Patents、EPO OPS** — 無料です。ボリュームが小さく、ベンダーによるカバレッジの保証を誰も必要としない場合は、こちらを選んでください。

## 注意点

- **性能に関する主張はすべてベンダー提供です。** 新規性調査のヒット率85%、「75%速く、25%低コスト」、18,000社という顧客数は、いずれも PatSnap のマーケティングです。**ガード：** PoC では、最も近い先行技術をすでに把握している発明を2〜3件使い、各エージェントがそれを上位10件の結果に出せるかを採点してください。
- **SOC 2 は Type 2 ではなく Type 1 です。** トラストページには ISO 27001:2022 と SOC 2 Type 1 が記載されています。これはある時点での設計の証明であり、運用の有効性を確かめる監査ではありません。**ガード：** レポートとブリッジレターを請求し、R&D が未出願の発明提案書を Eureka に貼り付け始める前に、データの保管場所、モデル学習への利用除外、再委託先リストを DPA に盛り込んでください。
- **Agent Skills はまだベータです。** ベンダー自身の2026年4月の投稿で、Agent Skills は2026年第2四半期の時点でまだ展開中だとしています。**ガード：** 本番の自動化は REST API または MCP サーバー上に構築し、依存するエージェントのバージョンを書面で固定してください。
- **クレジット制のため、自動化のコストが伸縮します。** エージェントの呼び出しは基本的な検索取得より多くのクレジットを消費し、エンジニアリングのチケットごとに FTO スクリーニングを走らせる社内ボットは、1年分の割り当てを数週間で使い切りかねません。**ガード：** 無人で動くワークフローにエージェントを接続する前に、キーごとのレート制限と月次のクレジットアラートを設定してください。
- **検索結果は意見書ではありません。** FTO Search の出力はランク付けされた文献の集合であって、クリアランスではありません。**ガード：** すべての FTO の結論に登録実務家の承認を残し、クエリ、コーパスの日付、結果を保存して、調査記録が故意侵害の主張に耐えられるようにしてください。
