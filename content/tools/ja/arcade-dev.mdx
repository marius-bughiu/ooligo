## 何をするツールか

Arcade は自らを、エージェントとその到達先システムとの間に入る「the actions runtime」と称しています。特定のエージェントが特定のアクションを実行してよいか、誰の権限で実行するのかを判断し、実行した事実を記録するレイヤーです。[Composio](/ja/tools/composio/) が1コールあたりの最安値で戦うのに対し、Arcade が戦う問いは別です。この書き込みを認可した人間は誰か、そしてそれを6か月後に証明できるか、という問いです。認可は委任型なので、エージェントはそのユーザーとして動作します。ツールコールが、呼び出したユーザーの付与していない OAuth スコープを必要とした場合、Arcade は実行を中断し、そのユーザーをプロバイダーの同意フローに通してから再開します。使われるトークンは共有のプラットフォームキーではなく、リクエストを出した本人のものです。既存の OAuth フローや ID プロバイダーのフロー(Okta、Entra)を置き換えるのではなく、その上で動作します。

同社は 2026年6月に SYN Ventures がリードする $60M のシリーズ A を調達し、Morgan Stanley と Wipro が戦略投資家として参加しました。$12M のシードを含めた調達総額は $72M です。MCP の URL elicitation フローの基となったツール認可の提案は Arcade が執筆したもので、Anthropic と共同で開発され、2025年11月に仕様へ採択されました。2026年8月5日には、公開 MCP レジストリ兼ホスティングプラットフォームの Smithery を買収しています。トップページに名前が挙がっている本番環境の顧客には、LangChain、Snyk、Relevance AI、Sybill、Duracell、Madrigal Pharmaceuticals が含まれます。

## エージェントスタックで採用される理由

プラットフォーム OAuth クライアントが1つということは、影響範囲も1つということです。Composio は 2026年5月21日、まさにそうした中央保管庫から約 5,241 件の API キーと 5,001 件の GitHub OAuth トークンが攻撃者に持ち出されたと公表しました。Arcade のユーザー単位モデルなら、同じ事故が及ぶのは被害を受けた個々のアカウントの権限だけです。さらに、各書き込みを認可した人間の名前が残るアクションログも残ります。コンプライアンス監査担当者が求めるのはこのログであり、共有サービスアカウントではこれを出せません。

カタログの数字は注意して読んでください。Arcade は「8,000+ permission-aware tools」と宣伝していますが、arcade.dev/tools の公開カタログに名前付きで載っているサーバーは9カテゴリにわたる約 85 件で、Salesforce、HubSpot、Attio から Zendesk、ServiceNow、Microsoft 365 スイート、Workday までを含みます。ツールは個々の関数であり、実際に統合する相手はサーバーです。カードには **Pro** バッジが付くものと **BYOC**(bring your own credentials、自前の認証情報の持ち込み)バッジが付くものがあり、Arcade 自社製のサーバーとは別に、パートナー製サーバーの階層も並んでいます。

## 価格の実態

Arcade は認証イベント課金を廃止しました。現在の料金ページが計量するのはツールコールの1項目だけで、「not per seat」と明記しています。

- **Free**:$0、クレジットカード不要。Arcade Cloud 上で月あたりツールコール 2,000 件、Discord と GitHub でのコミュニティサポート。
- **Team**:月 $25 のプラットフォーム料金に加えて、ツールコール1件 $0.01。Arcade Cloud のみで、サポートは翌営業日のメール対応です。料金ページには Team に含まれるコール枠の記載がありません。
- **Enterprise**:個別見積もり。ツールコールの年間バンドルとして販売され、規模が大きくなるほど超過分が割引されます。SSO、RBAC、監査ログ、プライベートレジストリへのアクセス、自社 VPC 内または完全エアギャップ環境でのデプロイ、24時間365日の SLA 付きサポート、専任のフォワードデプロイドエンジニアが付くのはこの階層だけです。

実際の価格帯は、いまや単純な計算で出せます。300 人の営業担当を支援し、月 25,000 件のツールコールを処理する社内エージェントなら $275(プラットフォーム $25、コール $250)で、そのコールが 30 人のユーザーから来ても 3,000 人から来ても変わりません。月 500,000 コールでは Team の定価が $5,025 になり、ここが定価をやめてバンドルを交渉する量です。大規模展開に対するかつてのペナルティはなくなりました。以前の計量方式では、4プロバイダーにまたがる 5,000 シートの展開で、エージェントが何も仕事をしないうちに 20,000 件の認証イベントが課金されていました。現在は人員数には費用がかからず、費用がかかるのはアクションだけです。

1コールあたりで見ると、$0.01 は Composio の $0.0003 に対してなお 33 倍の開きです。このプレミアムで買えるのは、ユーザー単位のトークンとアクション単位の監査証跡です。どの人間が書き込みを認可したのかを誰も問わないのであれば、使わない性質に1桁以上の上乗せを払っていることになります。

## こんなチームに向く

多数の実名エンドユーザーを代理してシステムオブレコードへ書き込むエージェントを出すプラットフォームエンジニアやセキュリティエンジニアで、監査要件が「このアクションを認可した人間を証明すること」である場合です。文句なしに勝つ限定ケースは、RevOps や Customer Success のチームが数百人の営業担当の前段にエージェントを置き、各担当者として [Salesforce](/ja/tools/salesforce/) や [HubSpot](/ja/tools/hubspot/) を更新し、[Slack](/ja/tools/slack/) に投稿させる構成です。すべての書き込みにユーザー単位の証跡が残り、コンプライアンス監査に耐えます。シート連動の認証課金がなくなったため、請求額はエージェントが支援する営業担当の人数ではなく、エージェントが実行するアクションに連動します。

## 向かないケース

単一サービスアカウントで高頻度にコールを出す、シングルテナントの社内エージェントです。同じ3つのトークンが全リクエストを処理し、どの権限で書き込みが行われたのかを監査担当者が問うこともないなら、1コールあたり 33 倍のプレミアムは何も買っていません。エンジニアでない人にとっても間違ったレイヤーです。これは SDK と CLI と API であって、キャンバスではありません。また、Legal Ops や Recruiting の監査担当者が問うガバナンス機能は、監査ログや SSO から VPC デプロイまで、すべて Enterprise の向こう側にあります。Team は規制対象データを扱えるコンプライアンス準拠の本番階層ではありません。

## 代替候補との比較

- **[Composio](/ja/tools/composio/)**:1コール $0.0003、月 100,000 コールまで無料という、このセグメントで最も安い認証済みツールコールです。コール量が請求額を支配し、単一のプラットフォームキーという保管形態をセキュリティレビューが受け入れるなら、こちらを選んでください。2026年5月の情報漏えいが、その受け入れに対する反論材料です。
- **[Zapier](/ja/tools/zapier/) MCP**:9,000 以上のアプリを持つカテゴリ最大の導入基盤で、Zapier の全プランに含まれます。配線するのが ops のジェネラリストで、月間のコール量が約 1,000 件未満に収まり、Zapier がすでに請求書に載っているなら、こちらを選んでください。タスク課金は1コールあたり約 $0.069 に相当するため、量が増えた時点で優位は逆転します。
- **[Runlayer](/ja/tools/runlayer/)**:エージェントガバナンス領域で最も成長が速い新規参入企業で、2025年11月に $11M のシード、2026年6月に Felicis がリードする $30M のシリーズ A を調達しています。セキュリティプラットフォームとして見積もりのみで販売しています。課題がシャドー MCP サーバーの発見と、自社が作っていないサーバーからのトラフィック検査であるなら、こちらを選んでください。Arcade は ID で勝ち、Runlayer は受信脅威の検査で勝ちます。両方の課題を抱えるチームは両方を買います。
- **[Merge](/ja/tools/merge/) Agent Handler**:マネージド認証に加えて全コールに DLP をかけるもので、月 $1,000 からです。従業員のエージェントトラフィックに対するデータ損失防止が要件で、HRIS、ATS、CRM がすでに Merge の単一 API で接続されているなら、こちらを選んでください。

どれも合わない場合、統合が約5件未満でサービスアカウントが1つなら、正直な代替策は API クライアントを直接書いてこのレイヤーを省くことです。

## 注意点

- **トップページには「SOC 2 compliant」とあるだけでタイプの記載がなく、公開サイトのどこにも ISO 27001 や HIPAA についての立場が示されていません。** ガード:セキュリティレビューを始める前に、SOC 2 レポート、そのタイプ、監査期間、直近のペネトレーションテスト要約を書面で請求してください。文書が手元に届くまでは、マーケティング文言を未検証として扱ってください。契約書や候補者の PII に触れる Legal Ops や Recruiting のデプロイは、トップページの主張ではレビューを通りません。
- **Pro バッジ付きのツールは $0.01 で課金されない可能性があります。** Arcade の 2025年の料金体系では、Pro の実行1回に $0.50、自前の認証情報を持ち込んだ場合は $0.01 が課金されていました。現在の料金ページには Pro の料金が記載されていませんが、カタログにはバッジが残っています。ガード:検索ツールやスクレイピングツールなど Pro バッジ付きのサーバーを前提に構築する前に、1コールあたりの料金を書面で確認し、Team で計量テストを1週間走らせて、実際に請求書に載る額を確かめてください。
- **Free 階層はデモであり、パイロットではありません。** ツールコール 2,000 件は、よく喋るエージェントなら1回の午後で使い切る量で、上限は評価の途中に予告なく来ます。ガード:継続可否の判断がかかるパイロットは、明示的な予算上限を設けたうえで Team で走らせ、評価が枠ではなく根拠で終わるようにしてください。
- **カタログが大きいことと、審査済みであることは別です。** Arcade 自身が 43,400 以上の公開 MCP サーバーと 219,069 のツールを調査したインデックスでは、A 評価を得たのは 0.5% でした。また、Arcade 自身のカタログには Arcade 製、パートナー製、BYOC のサーバーが混在しています。ガード:カタログの記載を信用するのではなく、ワークフローが頼る3つのツールコールをトライアル期間中に実データで検証し、依存する各サーバーを誰が保守しているのかを確認してください。
