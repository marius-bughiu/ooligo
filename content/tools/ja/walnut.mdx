## 概要

Walnut は、Web サイトの訪問者ではなく営業チームのために作られたインタラクティブデモプラットフォームです。製品を HTML または動画でキャプチャし、見込み客が自社のロゴ、数値、ユースケースを目にするようにキャプチャ済みのデータを編集して、ガイド付きデモ、サンドボックス、複数デモのプレイリスト、またはディールルームとして送付します。2020 年に創業し、ニューヨークに本社を置く同社は累計 $56M を調達しており、直近は 2022 年 1 月に Felicis が主導した $35M のシリーズ B です。数百社の B2B ソフトウェア企業にサービスを提供しているとしています。G2 では 151 件のレビューで 4.5/5 を獲得し、SOC 2 Type II 認証を取得しています。

2026-09-02、Walnut は自ら「エンタープライズ向けエージェントプラットフォーム」と呼ぶ機能群をリリースしました。購入者側で質問に答え、見込み客をデモ内で案内するエージェント **Walnut Xpert**、1 つのプロンプトから購入者ごとにパーソナライズされた体験を構築する **AI Mode for Playlists and Deal Rooms**、そしてワークスペース全体での AI の使い方に権限とガードレールを設定する管理レイヤー **AI Center** です。

## RevOps のスタックに入る理由

- **SE が環境を作り直さずに、見込み客ごとのデモを用意できます。** Walnut では、営業担当がキャプチャ済みデモのテキスト、ロゴ、グラフ、数値をアカウントに合わせて変更できます。AI Mode はこのパーソナライズをプロンプトから生成します。Walnut によると、プレイリストやディールルームの作成には、これまで AE や CSM が 1 案件あたり約 3 時間を費やしていました。
- **デモを組み込んだディールルーム。** ディールルームは、デモ、コンテンツ、ステークホルダーの行動を 1 つのリンクにまとめます。すでに [Trumpet](/ja/tools/trumpet/) や [Dock](/ja/tools/dock/) でセールスルームを運用している場合、Trumpet には Walnut とのネイティブ連携があります。Walnut 自身の Digital Sales Rooms は Accelerate ではアドオン、Scale では標準搭載です。
- **Salesforce 内でデモのエンゲージメントを確認できます。** Accelerate 以上で使える [Salesforce](/ja/tools/salesforce/) の高度な連携では、営業担当がレコードからデモを起動し、そこで案件分析や Walnut のカスタムレポートを確認できます。[HubSpot](/ja/tools/hubspot/)、Marketo、Pardot、[Zapier](/ja/tools/zapier/) は全プランで利用できます。
- **AI アシスタントから読み取り専用で分析データを参照できます。** Walnut のヘルプセンターには、Customer Data API をラップした MCP サーバーが記載されており、[Claude](/ja/tools/claude/)、[Cursor](/ja/tools/cursor/)、VS Code からデモセッション、合計値、上位デモを照会できます。読み取るのは分析データのみで、デモの作成や公開はできません。Data API は Scale プランに含まれます。

## 料金

Walnut は [Navattic](/ja/tools/navattic/) と異なり、定価を公開しています。無料プランもセルフサーブのトライアルもありません。

- **Ignite — 年間払いで月額 $575**（年間 $6,900）。エディター 3 席とプレゼンター 3 席、年間 50,000 AI クレジット、デモ無制限、デモ向け AI Mode、プレイリスト、分析、HubSpot と Salesforce の基本連携。サンドボックスデモ、SSO、Xpert はアドオンです。
- **Accelerate — 年間払いで月額 $1,550**（年間 $18,600）。エディター 6 席とプレゼンター 6 席、100,000 AI クレジット、サンドボックスデモ、見込み客ごとのパーソナライズ、動画オーバーレイ、AI アバター、SSO、Salesforce の高度な連携、専任 CSM、10 時間のオンボーディング。ディールルームと Xpert はアドオンです。
- **Scale — 個別見積もり。** 200,000 AI クレジット、Digital Sales Rooms、243 言語への翻訳、Data API、AI モデルの BYOK（bring-your-own-key）。
- **AI クレジットは従量で消費されます。** 追加パックは 50,000 クレジットで $1,000（1 クレジット $0.020）から、200,000 クレジット超では 1 クレジット $0.015 まで下がります。
- **実際の支払額。** Vendr によると、Walnut の契約額の中央値は 36 件の購入で年間 $17,000、範囲は $7,900〜$36,700 で、購入者は定価から 10〜25% の値引きを報告しています。この中央値は Accelerate の定価をわずかに下回る水準で、よくある購入パターンと一致します。Salesforce の高度な連携とサンドボックスが必要なチームは Ignite を飛ばすということです。

## 最適な利用者

- 5 桁〜6 桁ドル規模の案件を扱う B2B SaaS 企業の営業・プリセールス責任者で、初回商談の後に AE や SE が購買委員会へパーソナライズしたデモやディールルームを送るケース
- デモのエンゲージメントを Salesforce の商談に紐づけてレポートしたい RevOps チームで、そのために年間 $15,000〜$20,000 の予算を組めるケース
- Web サイトの「ツアーを見る」ボタンを最小コストで用意したい PLG チームや、無料プランや月額 $100 程度のエントリープランが必要なシード期の企業には向きません

## 代替ツールと選ぶべきケース

- **[Storylane](/ja/tools/storylane/)** — 最も幅広い独立系の競合で、スクリーンショット・動画・HTML のキャプチャ、サンドボックスデモとプレゼンターデモ、AI SDR の RepX を備えています。有料プランは年間払いで月額 $40 からですが、Salesforce は月額 $1,200 の Premium まで使えません。マーケティングと営業で 1 つのデモライブラリを共有し、より安く始めたいなら Storylane を選んでください。
- **[Navattic](/ja/tools/navattic/)** — HTML のみの Web サイト向けデモで、5 席の Base プラン（最後に公開された価格は月額 $500）で Salesforce を利用でき、Vendr の中央値は年間 $8,500 と Walnut の半分です。デモが Web サイト上にあり、リードのルーティングに使うなら Navattic を選んでください。
- **Supademo** — 最も急成長している新興ツールで、G2 の急成長製品に選ばれており、2026 年 6 月から独自の AI Demo Agent を提供しています。HTML デモは Growth プランの月額 $350（クリエイター 5 名）から利用できます。クリエイター単価が決め手で、CRM での詳細なレポートが不要なら Supademo を選んでください。
- **Consensus** — 購買委員会向けに、ステークホルダー単位の分析を備えたプリセールス用の動画デモとインタラクティブデモを提供します。Salesforce、Gong、Outreach は Pro プラン（10 ユーザーで月額 $1,250）から利用できます。見込み客ごとにデモのデータを編集することより、委員会の誰が何を見たかを把握することが課題なら Consensus を選んでください。

## 注意点

- **安いプランは実際に使うプランではありません。** Ignite の Salesforce 連携は基本版のみで、サンドボックスデモと SSO はアドオンです。Vendr の中央値 $17,000 は Accelerate の定価に近い水準です。対策：初回商談の前に Accelerate（または必要なアドオンをすべて付けた Ignite）の価格を算出し、Storylane か Navattic の見積もりを持ち込んで、Vendr が報告する 10〜25% の値引き幅を狙ってください。
- **AI クレジットは 2 つ目のメーターです。** パーソナライズ、Xpert、AI Mode は共有の年間枠を消費し、追加パックは 1 クレジットあたり $0.015〜$0.020 かかります。対策：AI Mode の 1 回の実行と Xpert の 1 セッションあたりのクレジット消費量を Walnut に確認し、発注書で追加購入の上限額を決めておいてください。
- **キャプチャは本番の製品から乖離していきます。** 編集したキャプチャはキャプチャ当日の UI を映しており、データ編集によって保守すべきデモのバージョンが増えていきます。対策：ユースケースごとにマスターデモを 1 つ持ち、再キャプチャではなくそこからパーソナライズし、大きな UI リリースのたびに各マスターデモを確認してください。
- **エージェント機能はリリースから数週間しか経っていません。** Xpert、AI Mode for Playlists and Deal Rooms、AI Center は 2026-09-02 にリリースされたばかりで、現時点での成果は「Xpert のセッションで購入者の滞在時間が 2 倍以上になる」という Walnut 自身の主張だけです。対策：1 つのセグメントで Xpert を試験導入し、標準デモを送る営業担当とのステージ転換率を比較し、営業担当が購入者向けコンテンツを生成できるようになる前に AI Center の権限を設定してください。
