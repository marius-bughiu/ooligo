## Was es ist

Claude ist der Allzweck-KI-Assistent von Anthropic, verfügbar als Chat-Produkt, API, Coding-Agent (Claude Code) und Plattform für das Ausführen von Custom Skills und MCP-basierten Tool-Integrationen. Für Ops-Teams ist es eine horizontale Schicht — Drafting, Zusammenfassung, strukturierte Extraktion, Web-Recherche, agentische Workflows — die sich in jeden vertikalen Stack integriert, den Sie bereits betreiben.

## Warum es in jedem RevOps-Stack auftaucht

- **Skills + MCP.** Definieren Sie wiederverwendbare Workflows einmal und führen Sie sie über Claude.ai, Claude Code und jeden MCP-kompatiblen Client aus. RevOps-Teams nutzen das für Lead-Enrichment, Account-Recherche, Deal-Desk-Pricing, QBR-Vorbereitung und Churn-Analyse.
- **Long Context.** 1M-Token-Fenster bedeuten, dass Sie ein Quartal [Salesforce](/de/tools/salesforce/)-Aktivität, einen Deal-Room voller Verträge oder ein Jahr Support-Tickets in einen einzigen Prompt einspeisen können — ohne Retrieval-Aufwand.
- **Tool-Use, das tatsächlich funktioniert.** Natives Function Calling und Multi-Turn-Agent-Loops sind zuverlässig genug, um über MCP-Server ([HubSpot](/de/tools/hubspot/), Salesforce, Snowflake, BigQuery, [Slack](/de/tools/slack/)) an produktive Systeme angeschlossen zu werden.

## Preise

- **Free** — begrenzte tägliche Nutzung
- **Pro** — 20 USD/Monat, voller täglicher Zugriff, größerer Context, Projects
- **Max** — 100–200 USD/Monat, erweiterte Nutzung und priorisierter Zugriff
- **Team / Enterprise** — Seat-basiert, inklusive Admin-Controls und SSO
- **API** — Pay-per-Token; das Sonnet-Pricing macht Content-Workflows mit hohem Volumen wirtschaftlich

## Am besten geeignet für

- Jedes RevOps-, Legal-Ops- oder Recruiting-Team, das sich auf einen Assistenten für Analyse, Drafting und agentische Workflows standardisiert
- Teams, die MCP einführen, um KI mit ihrem CRM, Data Warehouse oder Document Store zu verbinden
- Engineers, die interne Tools bauen und einen Coding-Agent wollen, der mit langem Context umgehen kann

## Worauf zu achten ist

- Outputs hängen stark von der Prompt-Qualität ab — investieren Sie in Skills/Templates statt in Ad-hoc-Prompts
- Einige Integrationen (z. B. zu Legacy-CRMs) brauchen einen MCP-Server, den Sie entweder aus einem Verzeichnis wählen oder selbst bauen
