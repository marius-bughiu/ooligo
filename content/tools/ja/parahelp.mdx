## 何であるか

Parahelp は、すでに運用しているヘルプデスクの上に乗り、チケットをエンドツーエンドで解決する AI サポートエージェントです。チケットを読み、文書化された手順に従い、社内ツールを API 経由で呼び出し、チケットをクローズするか、コンテキストを添えて人間に引き継ぎます。対象は、チケットが技術的かつアカウント固有であるソフトウェア企業です。失敗したデプロイ、請求をめぐる異議、顧客の実際のアカウントを確認する必要がある利用上限の質問といったもので、ヘルプセンターの記事で答えられる質問ではありません。

同社は 2024 年にデンマーク出身の創業者 Anker Bach Ryhl と Mads Lunau Liechti が設立し、Y Combinator を経て、San Francisco を拠点としています。2025-09-11 に $21.2M の調達を発表しました。内訳は Hidden Capital の Blake Robbins がリードした $3.2M のシードと、Alt Capital の Jack Altman がリードした $18M のシリーズ A で、Hanabi、Y Combinator、Perplexity Fund、ByFounders、Skyfall が参加しています。公表されている顧客リストはほぼすべて AI 企業と開発者ツール企業で、Perplexity、Replit、HeyGen、Framer、Bolt、Photoroom、Cursor が並び、現在のホームページには Kit と Fyxer も掲載されています。

提供されるエージェントは 2 つです。**Customer Agent** はメール、ライブチャット、Slack をまたいで会話を担当します。**Internal Agent** (「AI Manager」として発表) は、チームが Customer Agent を構築・調整するための手段です。手順の変更を自然言語で指示すると、過去のチケットと模擬シナリオに対して変更をテストし、何が変わったかを報告します。

## 開発者ツールのサポートスタックに登場する理由

- **課金は完全に解決したチケットのみ。** エージェントが人間にエスカレーションしたチケットには費用がかかりません。これは [Intercom](/ja/tools/intercom/) Fin や [Lorikeet](/ja/tools/lorikeet/) と同じメーターであり、失敗も成功と同じ単価で課金する会話単位の課金とは逆です。
- **ヘルプデスクを置き換えない。** [Zendesk](/ja/tools/zendesk/)、[Intercom](/ja/tools/intercom/)、[Front](/ja/tools/front/)、[Plain](/ja/tools/plain/)、[Pylon](/ja/tools/pylon/) の上で動作するため、移行プロジェクトは不要で、人間のエージェントはキュー、マクロ、レポートをそのまま使い続けられます。
- **ツール接続に制限がない。** API があるものなら何でも接続できます。返金やプラン変更には Stripe、再現手順付きのバグ起票には [Linear](/ja/tools/linear/)、アカウント照会には社内の管理エンドポイントです。これにより、「なぜ 2 回請求されたのか」というチケットに返金ポリシーを引用するのではなく、チケットをクローズできます。
- **設定はフロービルダーではなく会話で行う。** 手順は自然言語の SOP として書かれ、Internal Agent が編集内容をテスト済みの変更に変えます。Parahelp はエンジニアなしで 1 日でセットアップできると主張していますが、ツールに新しい API スコープが必要な場合はもっと長く見込んでください。
- **セキュリティの基本事項はページに記載されている。** SOC 2 Type II の監査済み、GDPR 準拠で、顧客データでモデルを学習しないことを明言しています。

## 価格の実態

Parahelp は料率を公開しており、その点で Lorikeet や Fin と同じ側に立ち、[Decagon](/ja/tools/decagon/) や [Sierra](/ja/tools/sierra/) とは一線を画します。

- **Start** — $1,000/月。月間 3,000 チケット未満のチーム向けで、解決チケットあたり $1.25。
- **Scale** — $4,000/月。月間 3,000-20,000 チケット向けで、解決チケットあたり $1.00。SSO/SAML、ロールベースのアクセス制御、優先サポートが付きます。
- **Custom** — 月間 20,000 チケット以上。チケット単価は交渉制で、SLA はカスタムです。
- **Internal Agent** — すべてのプランで別途課金され、モデルのトークン使用量に 20% を上乗せした額です。
- **トライアル** — 14 日間、「no-cure-no-pay」。

第三者による価格分析では、月額を前払いのクレジット最低額と解釈しており、解決チケット 1 件につき 1 クレジットです。Start では $1,000 で 800 件、Scale では $4,000 で 4,000 件の解決を購入することになります。この解釈に立つと、Start は月に少なくとも 800 件を解決するチーム向けの価格設定であり、それを下回ると得られなかった解決分まで支払うことになります。

単価ベースの市場と比べると、Parahelp は公開価格帯の上端に位置します。Fin は outcome あたり $0.99 で月 50 件の最低数があり、Lorikeet はチャットとメールで $0.80-$0.95、[eesel AI](/ja/tools/eesel-ai/) は結果にかかわらず対応チケットあたり $0.40 です。一方、コミット量での自動解決あたり約 $1.50 という [Zendesk](/ja/tools/zendesk/) よりは安価です。そしてヘルプデスクのサブスクリプションは請求書に残ります。月 2,000 件の解決では、Parahelp Start は Internal Agent のトークン費用を除いて約 $2,500 かかり、これにすでに Zendesk や Intercom に支払っているシート単位の費用が加わります。

## 最適な対象

開発者ツール、AI、PLG のソフトウェア企業のサポートリーダーで、月間およそ 1,000-20,000 チケットを扱い、チケットの構成が技術的かつアカウント固有で、ユーザーベースに対してサポートチームが小さく、新しいヘルプデスクではなく既存の Zendesk、Intercom、Front、Plain、Pylon のデスクにエージェントを載せたい場合です。チケットの大半がクローズのために Stripe や社内管理ツールでのアクションを必要とする環境で最もよく適合します。

次の場合は見送ってください。チケットの多くがドキュメントで答えられる場合は、より安価なディフレクション型エージェントが同じ量をより少ない費用で解決します。音声が必要な場合、Parahelp は音声を掲載していません。B2C や規制業種のサポート組織である場合は、顧客リファレンスとコンプライアンスの厚みが不足しています。

## 代替候補との比較

市場シェアの首位は、すでに保有しているデスクの AI レイヤーです。Intercom を運用していてチケットの大半が回答で片づくなら、Intercom Fin が選択肢です。outcome あたり $0.99、新しいベンダーは不要で、解決あたりの価格も低くなります。調達部門がベンダーを増やさず、すでに Zendesk Suite に支払っているなら Zendesk AI です。チケットの大きな割合がクローズにツール呼び出しを必要とし、ネイティブのエージェントがそこで止まってしまう場合に、両者より Parahelp を選んでください。

最も成長の速い新規参入は [Sierra](/ja/tools/sierra/) で、2026 年 5 月に評価額 $15.8B で $950M を調達しました。音声とエンタープライズ向けのトランザクションワークフローが必要で、年間 $150K 以上の契約を用意できるなら Sierra を選んでください。[Decagon](/ja/tools/decagon/) は月間およそ 10,000 件の解決を超える領域でのエンタープライズ向け代替で、約 $50,000 のプラットフォーム費用があっても、交渉した料率が $1.00 を上回ります。[Lorikeet](/ja/tools/lorikeet/) は公開された解決単位の価格で最も近い同等品で、チケットあたりはより安価です。fintech や healthtech のワークフローと音声には Lorikeet を、Slack とメールで運用する開発者ツールのサポートには Parahelp を選んでください。解決率が高く、このカテゴリを試している段階なら、コスト面では [eesel AI](/ja/tools/eesel-ai/) が勝ちます。

どれも合わない場合は、技術的なキューには人間を残し、Fin か eesel を FAQ の層だけで運用してください。エージェントがチケットをクローズするには、文書化された手順と API アクセスが必要です。それがなければ、このリストのどのベンダーでもキューの大半がエスカレーションされます。

## 注意点

- **月額とチケット単価が、どう組み合わさるかを示さずに公開されている。** クレジット最低額と読めば、低調な月にはクレジットが無駄になります。プラットフォーム費用と読めば、$1,000 に加えてすべての解決に $1.25 がかかります。ガード: $1,000/$4,000 という数字の定義、クレジットの繰り越し、超過料率を発注書に盛り込み、過去 1 年で最も量の少なかった月で請求額を試算してください。
- **「完全に解決」が商業モデルのすべてなのに、ページでは定義されていない。** エージェントがクローズし、2 日後に再オープンされたチケットも解決として課金されうる状態です。ガード: 課金を無効にする再オープン期間 (7 日間が妥当な要求です) を合意し、再オープン率はベンダーのダッシュボードではなく自社のヘルプデスクから計測してください。
- **Internal Agent は 2 つ目の、上限のないメーターである。** トークン使用量プラス 20% は、チケット量ではなくチームがどれだけ反復するかに比例して増えます。ガード: 自社と同規模の顧客における前四半期の Internal Agent 支出を確認し、契約に月間上限を設定してください。
- **小規模なベンダーで、リファレンスの幅が狭い。** 公開顧客はほぼすべて AI 企業と開発者ツール企業で、Sierra が今年 $950M を調達したカテゴリで、同社の調達額は $21.2M です。ガード: 署名前に SOC 2 Type II レポートを要求し、SOP を Parahelp の中だけでなく自社のリポジトリにも保管し、会話ログと手順のエクスポートを契約で確認して、数か月ではなく数週間で乗り換えられるようにしてください。
