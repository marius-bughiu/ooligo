## 概要

Assembly Neos は、米国の原告側人身傷害（personal injury）事務所向けのクラウド型案件管理ソフトで、Assembly Software が販売しています。前身は Needles で、1985 年に PINS として始まり 1995 年に Needles と改称された Windows 向けの人身傷害システムです。Needles と Trialworks は 2019 年に Assembly Software として統合され、Assembly は現在 Needles の顧客を Neos へ誘導しています。Assembly によると、1,450 以上の人身傷害事務所と 15,000 人以上の弁護士・スタッフが同社製品を使っています。Neos は Microsoft Azure 上で動作し、SOC 2 Type II 認証を取得しています。Wolters Kluwer ELM と LexisNexis の出身である Jonah Paransky が 2026-01-07 に CEO に就任しました。

いま検討する理由は AI です。最上位プランの NeosAI は、記録の要約、案件フィールドへのデータ抽出、文書生成、案件に関する質問への回答を行います。2026-11-10、Assembly は Demands Plus の一般提供を開始しました。案件内にすでにある記録から医療クロノロジーを作成し、新しい記録が届くたびに更新し、治療の空白や欠けている記録を指摘し、事務所自身の書式に倣って損害賠償請求書（demand letter）を起案します。引用をクリックすると Neos 内の元記録が開きます。

## Legal Ops スタックに登場する理由

- **導入済みの顧客基盤があります。** 数千の原告側事務所が Needles で案件管理を覚えました。彼らにとって現実の選択は「人身傷害システム一般のどれにするか」ではなく、「Neos に移るか、Assembly から完全に移行するか」です。
- **請求書作成を内製するか外部に頼むかの答えになります。** 多くの人身傷害事務所は請求書を [EvenUp](/ja/tools/evenup/) か [Supio](/ja/tools/supio/) から購入しています。どちらも Neos 用コネクタを公開していません。EvenUp の連携ページが挙げるのは Litify、[SmartAdvocate](/ja/tools/smartadvocate/)、[CasePeer](/ja/tools/casepeer/) で、Supio は Litify、MyCase、CasePeer です。そのため Neos の事務所は、記録を手作業で外部ツールに移すか、案件ファイル内で Demands Plus を使うかのどちらかになります。さらに Assembly は Demands Plus の費用を事務所の固定費ではなく、回収可能な経費として案件に計上します。
- **インテークと電話の周辺はすでにつながっています。** インテークフォームとインテーク CRM は全プランに含まれ、最上位プランでは [RingCentral](/ja/tools/ringcentral/) と Zoom Phone を通じた通話追跡付きダイヤラーが加わります。決済は [LawPay](/ja/tools/lawpay/) が担い、DocuSign、[Zapier](/ja/tools/zapier/)、Case Status、YoCierge（医療記録）がパートナーとして掲載されています。

## 価格の実態

assemblysoftware.com/pricing（2026-11-15 確認）、ユーザーあたり月額、年払い、最低 3 ユーザー：

- **Essentials：$109。** インテークフォームと CRM、リード追跡、文書作成と保管、メールとカレンダーの同期、レポート、経費と請求。
- **Premium：$139。** OCR、PDF 編集、墨消し、Bates 番号付与が加わります。
- **NeosAI Platinum：見積もり。** NeosAI、自動化されたワークフロー、Intake Pro、Neos Texting、ダイヤラー、電子署名連携が加わります。
- **Demands Plus：** Platinum が前提のアドオンで、案件量に応じた価格です。Assembly は金額を公開していません。
- **アドオン：** 下位プラン向けの双方向テキスト、デジタル支払い、医療記録の取り寄せ。

ディレクトリサイト（TrustRadius）にはまだ $99 / $129 / $179 が載っているため、予算は公式ページの最新価格で組んでください。3 ユーザーの事務所が Essentials を使うと年 $3,924、10 ユーザーの事務所が Premium を使うと年 $16,680 です。Platinum と Demands Plus は営業との交渉になります。請求書あたりまたは案件あたりの単価を書面で受け取り、アドオン前で請求書 1 通あたり約 $300 という EvenUp の目安と比べてください。移行は専任の CSM が担当し、Assembly によるとほとんどが 60〜90 日で完了します。

## 向いている組織

- **最適なのは：** 3〜50 ユーザー規模の原告側人身傷害事務所のマネージングパートナーや業務責任者、特にまだ Needles を使っていて、請求書とクロノロジーを別ベンダーではなく案件ファイル内で作りたい事務所です。
- **向いていないのは：** 個人の弁護士（最低 3 ユーザーのため）、Filevine 並みのワークフローのカスタマイズが必要な大規模集団訴訟（mass tort）事務所、そしていますぐオープンな API や Claude 用 MCP コネクタが欲しい事務所です。Assembly の価格ページにはどちらも記載がありません。

## 代替製品との比較

- **vs [Filevine](/ja/tools/filevine/)。** 2025 年の $400M の資金調達以降、原告側案件管理で最も成長しているプラットフォームです。見積もりのみで、独自の MedChron と DemandsAI を持ちます。集団訴訟や高度にカスタマイズしたワークフローなら Filevine、公開されたユーザー単価と Needles からの移行経路を重視するなら Neos を選んでください。
- **vs [CasePeer](/ja/tools/casepeer/)。** ユーザーあたり月額 $90 からの公開価格で、EvenUp と Supio へのコネクタがあります。請求書作成の AI を外部ベンダーから買うつもりなら CasePeer、システム内に持ちたいなら Neos です。
- **vs [SmartAdvocate](/ja/tools/smartadvocate/)。** 見積もりのみで約 $109 から、SmartIntelligence AI とオンプレミスの選択肢があります。システムを自社サーバーに置く必要があるなら SmartAdvocate です。
- **vs [Litify](/ja/tools/litify/)。** Salesforce ベースで、すべて込みでユーザーあたり月額約 $150〜300 です。事務所がすでに Salesforce を使っている場合に限り選んでください。
- **vs [Clio](/ja/tools/clio/)。** 事務所数では市場トップですが、人身傷害向けには作られていません。人身傷害が業務の一部にすぎない場合に限り選んでください。
- **vs [EvenUp](/ja/tools/evenup/) の追加。** 請求書ごとの評価分析と人によるレビュー層が欲しいなら EvenUp です。Demands Plus は案件の価値を見積もりません。

## 注意点

- **AI は最上位プランにしかありません。** NeosAI のすべての機能と Demands Plus には Platinum が必要で、その価格は公開されていません。**対策：** Neos を CasePeer や Filevine と定価で比べる前に、Platinum の見積もりと Demands Plus の単価を取ってください。
- **Demands Plus は新しく、速度の数字はベンダー自身のものです。** 手作業で 3〜10 時間以上かかるところを請求書 1 通 30 分という数字は、Assembly のベータ報告によるものです。**対策：** トライアル中に終結済みの案件 5 件を通し、起案ではなく弁護士のレビュー時間を計測してください。
- **公開 API がありません。** 価格ページに API アクセスの記載がなく、独自レポートや外部 AI ツールの利用が制限されます。**対策：** どのデータエクスポートが得られ、どう移行できるかを書面で確認してください。
- **移行は 1 週間ではなく 1 四半期かかります。** 60〜90 日は Assembly 自身の見積もりです。**対策：** 移行中は Needles のカスタムフィールドの変更を凍結し、切り替え前に 1 件の案件のライフサイクル全体をテストしてください。
