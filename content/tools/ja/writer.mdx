## 概要

WRITER は、エンジニアリング部門ではなくビジネスチーム向けに販売されているエンタープライズ向けエージェントプラットフォームです。マーケターや RevOps のリーダーがタスクを平易な言葉で説明すると、WRITER はそれを、自社のコンテンツ、データ、ブランドルールに基づいて動くエージェントに変換します。統制は IT が一度設定するだけです。他社のモデルを借りるのではなく WRITER 独自の Palmyra モデルで動作し、2026年9月からは、エンタープライズのマーケティングチームとレベニューチームのためのエージェントプラットフォームであることを明確に打ち出しています。

[ChatGPT](/ja/tools/chatgpt/) のような汎用チャットアシスタントではなく、[Glean](/ja/tools/glean/) のようなエンタープライズ検索エンジンでもありません。最も近いのは、エンジニアではない人が再利用可能なエージェントを構築する、ガバナンスの効いた作業場です。WRITER はサンフランシスコの非上場企業で、2024年11月に評価額 19億ドルで 2億ドルの Series C を調達しました。公表されている顧客には Accenture、Intuit、Qualcomm、Uber、Vanguard が含まれます。

## 2026年の変更点

- **Agent Skills と Playbooks（2026年3月25日）。** ユーザーがワークフローを説明するか、既存のプロセス文書を貼り付けると、WRITER がそれを実行可能な Playbook に変換し、Skills、コネクター、ナレッジ、ブランドボイスを組み込みます。200 を超える構築済みのエンタープライズ向け Skills のライブラリとともにリリースされ、WRITER によれば顧客はすでに 5,000 を超える Playbooks をデプロイしていました。
- **イベントベースのトリガー（2026年4月30日）。** エージェントはプロンプトではなくシグナルを起点に動き出すようになりました。新しい Gong の通話、Gmail のメッセージ、カレンダーの予定、Google Drive や SharePoint へのファイル追加、Slack への投稿などです。
- **Palmyra X6（2026年8月13日）。** オープンウェイトの GLM 5.2 をベースにした新しいフラッグシップモデルで、価格は入力 100万トークンあたり 2ドル、出力 100万トークンあたり 8ドルです。WRITER の自社テストでは、X6 とハーネスの改良により、エージェントタスクの平均コストが 52% 下がり、処理速度が 48% 向上したとしています。
- **Enterprise Brain（2026年9月9日）。** アカウント、商談、キャンペーン、コンテンツ、顧客との会話をマッピングする共有コンテキストレイヤーで、チーム単位の Agent Memory を備えます。あわせて Zoom、Teams、Google Meet 向けの WRITER Meet も提供されます。

コネクターは WRITER が自社開発した MCP ゲートウェイを経由し、アクションごとに ID と権限を確認します。IT は OpenAPI 仕様または MCP サーバー設定から、社内システムをカスタムコネクターとして追加できます。公表されているコネクターには [Salesforce](/ja/tools/salesforce/)、[HubSpot](/ja/tools/hubspot/)、[Gong](/ja/tools/gong/)、[ZoomInfo](/ja/tools/zoominfo/)、[Slack](/ja/tools/slack/)、Snowflake、Databricks、Adobe Experience Manager があります。

## 購入に値するユースケース

エンタープライズ営業チームの商談後フォローアップです。Gong の録音が届くとトリガーが起動し、Playbook が会社の承認済みボイスで要約メールを下書きし、Salesforce からそのアカウントのオープンな商談を取得して次のステップを更新し、承認用の下書きを Slack で担当営業に送ります。プロセスを所有するオペレーション担当者は、エンジニアリングにチケットを起票することなくこれを構築・編集でき、ブランドとコンプライアンスのルールは、担当営業が覚えておかなくてもすべての下書きに適用されます。

## 料金

- **Starter**：年払いで 1ユーザーあたり月額 29ドル、月払いなら 39ドルです。最大 5ユーザー、5 Playbooks、アクティブなコネクター 3つ、スケジュール済みルーティン 3つ、機能制限付きの Knowledge Graph が含まれます。14日間のトライアルがあり、カードは不要です。
- **Enterprise**：個別見積もりです。Playbooks、コネクター、ルーティンが無制限で、SAML SSO、部門別のボイスプロファイル、高度なガードレールが含まれます。
- **API（AI Studio）**：Palmyra X6 は入力/出力 100万トークンあたり 2ドル/8ドル、100万トークンのコンテキストウィンドウを持つ Palmyra X5 は 0.60ドル/6ドルです。

Starter はトライアル用のティアであり、5人を超える規模はすべて Enterprise の見積もりになります。Vendr の取引データによると、WRITER の契約額の中央値は年間約 28,900ドル、100〜500ユーザーの導入では 7.5万〜25万ドル、500ユーザー以上の導入では 50万ドルを超えます。また Vendr は、API の超過料金、サービス、サポートを加えると、総コストがサブスクリプション料金を 20〜40% 上回ると報告しています。

## 最適な対象

従業員 1,000人以上の企業で、コンテンツ、アカウントリサーチ、フォローアップ業務のために、ガバナンスが効きブランドに沿ったエージェントを必要とし、Playbooks の所有者をエンジニアではなくビジネスユーザーにしたい Marketing Ops と RevOps のリーダーです。

## 代替ツールと、それらを選ぶべきケース

- **Microsoft 365 Copilot と [Agent 365](/ja/tools/microsoft-agent-365/)**：市場シェアで見たデフォルトの選択肢です。業務が Microsoft 365 上にあり、1ユーザーあたり月額 30ドルの Copilot がすでに予算に入っている場合に選んでください。
- **[Glean](/ja/tools/glean/)**：エンタープライズ検索のリーダーです。中心的な課題がブランドに沿った成果物の作成ではなく、数十のシステムにまたがって答えを見つけることである場合に選んでください。
- **[Salesforce Agentforce](/ja/tools/salesforce-agentforce/)**：エージェントの仕事が Salesforce のレコード内で始まって終わり、シート単位ではなくアクション単位で支払いたい場合に選んでください。
- **[Dust](/ja/tools/dust/)**：急成長中で価格が透明な代替ツールで、1ユーザーあたり月額約 31ドル、最低シート数はありません。エンタープライズの営業サイクルを経ずにノーコードのエージェントビルダーを求めるミッドマーケットのチームに向いています。
- **[Claude Cowork](/ja/tools/claude-cowork/)**：ブランドガバナンスよりもフロンティアモデルの推論能力が重要で、ガードレールを自分で用意できる場合に選んでください。

## 注意点

- **モデルは WRITER 製で、選択肢は狭くなります。** Palmyra X6 は WRITER 自身の評価では高いスコアを出していますが、それらはベンダーのベンチマークです。対策：トライアル期間中に、実際の業務で最も難しい 10件のタスクを Palmyra と、本来使うはずのフロンティアモデルの両方で実行してください。また、Enterprise ティアの約束である「お客様のシステムおよび LLM との完全な相互運用性」を、サポート対象モデルの明示的なリストとして契約書に書き込んでください。
- **Starter は実質的なエントリー価格ではありません。** 5ユーザーの上限とコネクター 3つの制限があるため、部門単位の展開はすぐに個別見積もりになります。対策：パイロットの前に、Enterprise のシート単価、最低シート数、API の超過料金を書面で入手し、Vendr のようなベンチマークを使って交渉してください。
- **製品のポジショニングが急速に変わっています。** 6か月で 4つの大型リリースがあり、訴求対象もあらゆるビジネス部門からマーケティングチームとレベニューチームへと絞り込まれています。対策：今日テストできる Playbooks とコネクターを基準に購入し、Enterprise Brain と Agent Memory はビジネスケースではなくパイロットに含めてください。
- **トリガーは人間を介さずに動きます。** 誤ったシグナルで顧客にメールを送るイベントベースのエージェントは、機械の速度で損害を与えます。対策：Playbook が 1か月間問題なく動くまでは、顧客に届くものや CRM に書き込むものすべてに承認ステップを残してください。
