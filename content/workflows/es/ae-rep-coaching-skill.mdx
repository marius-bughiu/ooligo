Una skill de Claude que ingiere las últimas diez llamadas de un AE desde Gong y entrega una nota de coaching: tres cosas que están funcionando, dos que apretar y un ejercicio específico para la siguiente semana. Construido para managers que quieren coaching consistente pero no tienen diez horas a la semana para escuchar llamadas.

## Lo que vas a necesitar

- Gong con la API de llamadas habilitada y transcripts disponibles
- Claude.ai o Claude Code
- La rúbrica de llamadas de tu equipo (discovery, demo, negociación) como project knowledge
- Un canal de entrega semanal acordado con el AE: DM, email o en el siguiente uno-a-uno

## Setup

1. **Instala la Skill.** `ae-coaching.skill` expone `pull_recent_calls`, `analyze_against_rubric` y `render_coaching_note`.
2. **Autentica Gong.** API key con acceso de lectura a las llamadas y transcripts del AE. La Skill respeta el modelo de permisos de Gong; si las llamadas del AE están restringidas, la Skill no las puede ver.
3. **Carga la rúbrica de llamada.** Rúbricas distintas para discovery, demo y negociación. La Skill auto-detecta el tipo de llamada desde el stage tag de Gong o le pide a Claude que clasifique si está sin etiquetar.
4. **Configura el rep ID y el rango de fechas.** Default son las últimas diez llamadas o los últimos catorce días, lo que sea más corto.
5. **Decide la cadencia de entrega.** Semanal es realista. Diaria es demasiado. Mensual es muy poco. Agenda para el viernes en la tarde para que el AE tenga el fin de semana de absorber.

## Cómo funciona

La Skill jala transcripts y metadata de llamadas, clasifica cada una por tipo de llamada y corre la rúbrica relevante contra el transcript. Claude evalúa cada criterio de la rúbrica, citando momentos específicos de la llamada. Después agrega entre las diez llamadas en la estructura tres-dos-uno: tres patrones funcionando, dos patrones a apretar, un ejercicio específico.

El ejercicio es el output más importante. "Mejora el discovery" es inútil. "En tus próximas tres llamadas de discovery, haz la pregunta de presupuesto antes del minuto veinte" es accionable. La Skill está prompteada con dureza para hacer el ejercicio concreto y medible.

## Cuídate de

- **Calibración de tono.** Las notas de coaching que se leen como una evaluación de desempeño se ignoran. La Skill está prompteada hacia voz de "peer de confianza". Prueba el tono con uno de tus AEs más fuertes antes del rollout.
- **Calidad de transcripts.** Llamadas de menos de cinco minutos, llamadas con más de cinco asistentes y llamadas con audio malo producen análisis ruidoso. Filtra agresivamente.
- **Alineamiento de rúbrica.** Una rúbrica escrita para discovery outbound aplicada a llamadas de demo inbound produce feedback irrelevante. Asegúrate que la rúbrica coincida con el tipo de llamada.
- **Dependencia del manager-of-record.** Esta es una herramienta para el manager, no un reemplazo. La salida es un draft. El manager edita, contextualiza y entrega.

## Stack

- **Gong** — fuente de llamadas, capa de transcript, clasificación de tipo
- **Claude** — scoring de rúbrica y síntesis
- **Doc de rúbrica de llamada** — el lente que hace específico el feedback
