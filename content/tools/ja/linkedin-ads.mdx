## 概要

LinkedIn Ads は、LinkedIn のフィード、メッセージ受信箱、そして 2026 年からはコネクテッド TV の裏側にあるセルフサーブ型の広告プラットフォームです。購入は Campaign Manager で行います。目的（認知、Web サイト訪問、リード獲得、コンバージョン）を選び、メンバー自身がプロフィールで最新に保っている役職、シニアリティ、職務、企業、業種の項目でターゲティングし、オークションで入札します。「この 800 社の財務担当 VP」と指定して、そのターゲティングが崩れない有料チャネルは他にありません。

RevOps や ABM チームにとって重要な要素は次のとおりです。

- **Matched Audiences。** 企業リストや連絡先リストをアップロードするか、サイト訪問者や動画視聴者をリターゲティングします。企業リストはネイティブな ABM の手段です。LinkedIn 自身のガイダンスでは最良の結果のために 1,000 社以上を推奨しており、各広告セットの配信には一致したメンバーが最低 300 人必要です。
- **Conversions API と CRM 連携。** HubSpot、Salesforce、Dynamics 365 からのサーバーサイドのコンバージョンイベントに加え、広告エンゲージメントを CRM の商談と結び付ける **Revenue Attribution Report** があります。Company Attribution ビューによってアカウント単位の集計が追加されました。
- **Thought Leader Ads。** 2024 年以降、従業員の投稿に加え、許可を得れば顧客、パートナー、クリエイターの投稿も広告として配信できます。代理店が報告するベンチマークでは、CPC はブランドページの広告を大きく下回ります。ただし正確な比率はベンダー側のデータとして扱ってください。
- **Campaign Manager の AI。** キャンペーンタイプ Accelerate がターゲティングとクリエイティブを自動化します。2026-07-01 には、Draft with AI（ランディングページの URL から広告の初稿を作成）、Brand Kit、AI による広告バリエーション、役職・企業・業種別の Ads Personalization が追加されました。
- **CTV と動画。** LinkedIn CTV Ads は 2026 年 5 月から Amazon DSP 経由で購入可能になり、2 つ目のプログラマティック経路として The Trade Desk の展開も進んでいます。BrandLink（旧 Wire Program）は、パブリッシャーやクリエイターのコンテンツの前に自社動画を配信します。
- **BrandWorks。** 2026-06-10 に発表された、ブランド戦略、クリエイティブ、イベントを担う LinkedIn 社内チームです。対象は一部のマネージド顧客のみで、初期ユーザーとして SAP と Webflow の名前が挙がっています。セルフサーブ機能ではなく、サービスの層です。

Lookalike Audiences は 2024-02-29 に廃止され、Predictive Audiences と Audience Expansion が後継となりました。

## 実際の価格

プラットフォーム利用料はありません。クリック（CPC）、インプレッション（CPM）、送信（Message Ads）単位で支払い、プラットフォームの下限は 1 日の予算 $10、新規キャンペーンの総予算 $100、最低入札額 $2 です。

下限額は実際のコストについて何も教えてくれません。2026 年に公開された代理店のベンチマークは一致しませんが、おおむね次の範囲に集まっています。

- **CPC：** シニアリティで絞り込んだ B2B オーディエンスでおよそ $5-15。シニアな購買者や絞り込んだ ABM オーディエンスはこの帯の上限に位置します。
- **CPM：** 幅広い職業ターゲティングでおよそ $27-35、経営層を狙うと $50-65 以上。
- **成立するテスト予算：** 代理店の推奨は、最初の B2B テストで月 $2,000-5,000、評価までに最低 2 週間という水準に収束しています。LinkedIn は公式の数字を公開していません。この範囲を下回ると、クリエイティブを判断できるだけのクリック数がキャンペーンに集まることはまれです。

つまり LinkedIn は、ほとんどの B2B 有料チャネルの組み合わせの中で最も高いクリックであり、Google 検索のクリックの数倍になることもよくあります。選ぶ理由はオーディエンスの精度であって、コスト効率ではありません。

## 最適な対象

**$50 以上の CPM を吸収できる案件規模を持つ B2B 企業のデマンドジェンおよび ABM マーケター**で、役職とアカウントで定義した購買委員会に届く必要があり、ABM スタックの他のツール（6sense、Demandbase、AdRoll ABM）がいずれにせよオーディエンスを送り込むチャネルを使いたい人です。

## 代替ツールとの比較

- **[6sense](/ja/tools/6sense/) と [Demandbase](/ja/tools/demandbase/)** は導入実績が最も大きい 2 つの ABM プラットフォームで、インテントでスコアリングしたアカウントのオーディエンスを LinkedIn に同期し、アカウント単位のエンゲージメントを CRM に戻します。**LinkedIn をネイティブで運用する代わりにどちらかを選ぶべきなのは**、今週*どの*アカウントを狙うかを決めるためにインテントデータが必要なとき、プログラマティックディスプレイも購入しているとき、あるいは取締役会がチャネル横断のアカウント単位の影響レポートを求めるときです。契約は通常、メディア費を除いて年間 $40,000-60,000 前後から始まります。
- **[Vector](/ja/tools/vector/)** はこの領域で最も動きの速い新興勢力で、LinkedIn Ads そのものの上で動作します。特定したサイト訪問者への連絡先単位のリターゲティング、LinkedIn の入札を 15 分ごとに調整する入札エージェント、パフォーマンスを照会する MCP サーバーを備えています。LinkedIn がすでに主要な有料チャネルで、課題がインテントではなく訪問者特定と入札にある場合は **Vector を選んでください**。
- **[AdRoll ABM](/ja/tools/rollworks/)** と **[Influ2](/ja/tools/influ2/)** は、より安価な ABM 広告の選択肢です。AdRoll ABM は中小企業の予算向け、Influ2 は名前の分かっている連絡先への個人単位の広告向けです。
- **LinkedIn をネイティブで運用すべきなのは**、ターゲットアカウントのリストが四半期中固定されており、予算が月およそ $20,000 未満で、Revenue Attribution Report と CRM 連携でレポーティングの問いに答えられるときです。

## 注意点

- **Audience Expansion と LinkedIn Audience Network は、キャンペーン作成時に有効になっていることがよくあります。** どちらも、絞り込んだ ABM オーディエンスを類似メンバーや LinkedIn 外の配信面へと気付かないうちに広げてしまいます。**対策：** 新しい ABM キャンペーンでは毎回両方をオフにし（複製したキャンペーンや新規作成したキャンペーンではデフォルトが戻ることがあります）、最初の週に配信面レポートを確認してください。
- **小さな ABM リストは 300 人の下限を満たせません。** 購買委員会 100 人のリストでは、配信に足るメンバー数が一致することはまれです。代理店は連絡先リストの一致率を 30-60% と報告しています。**対策：** 必要なメンバー数の 3 倍以上をアップロードし、企業名と Company Page の URL を含む企業リストを優先し、企業リストに職務ターゲティングを重ねてください。
- **CSV リストを差し替えるとキャンペーンが一時停止します。** LinkedIn の Marketing API ドキュメントによると、CSV オーディエンスを使うキャンペーンは差し替えリストの評価中、24-48 時間停止します。**対策：** HubSpot や Salesforce のコネクター、または ABM プラットフォームの同期経由でリストを供給し、更新がその場で反映されるようにしてください。
- **ネイティブのアトリビューションはリード中心で、評価が甘めです。** Revenue Attribution Report は LinkedIn 独自のウィンドウ内でエンゲージメントを評価し、ビュースルーコンバージョンは認知施策の費用対効果を実態より良く見せます。**対策：** 予算を説明する前に、[Dreamdata](/ja/tools/dreamdata/)、[HockeyStack](/ja/tools/hockeystack/)、[Factors.ai](/ja/tools/factors-ai/) などのアカウント単位のアトリビューションツールと突き合わせてください。
- **新しい AI 機能は API への反映が遅れます。** 2026 年 7 月のクリエイティブツールは、リリース時点で Marketing API の変更履歴に掲載されていませんでした。**対策：** サードパーティツールでキャンペーンを管理している場合は、その機能に対応しているかを確認してから計画に組み込んでください。

## 結論

定義可能な購買委員会に販売していて、クリック単価を負担できるなら、LinkedIn Ads は計画に入れるべきです。本当の問いは、自社で運用するか ABM プラットフォーム経由で運用するかです。まずは企業リスト、Audience Expansion オフ、CRM 連携ありの状態でネイティブに始めてください。アカウント選定にインテントが必要になったら 6sense か Demandbase を、LinkedIn の支出が大きくなり入札と訪問者特定がボトルネックになったら Vector を追加します。広告で温めているのと同じアカウントに担当者がフォローアップできるよう、[Sales Navigator](/ja/tools/sales-navigator/) と組み合わせてください。
