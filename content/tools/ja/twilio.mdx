## 概要

Twilio は、電話番号、音声、SMS、WhatsApp、email、そしてその背後にある通信キャリアとの関係を提供するコミュニケーション API の会社で、現在は AI エージェント向けの「会話インフラ」として自社を売り出しています。サポートチームから見ると、Twilio は3つの形で登場します。ほぼすべての voice AI ベンダーの下で動く基盤の回線（Vapi、Retell、ElevenLabs はいずれも Twilio の番号に接続します）、自社の音声エージェントを Twilio 上で直接動かしたいチーム向けの ConversationRelay、そして設定するのではなく構築するプログラマブルなコンタクトセンターである Flex です。

大規模で黒字の上場企業です（NYSE: TWLO）。2026年 Q2 の売上高は $1.50B で前年同期比22%増、音声は20%超、セルフサーブの音声は50%超の成長で、Twilio はこの成長を AI ネイティブな開発者と結びつけています。2025年11月には、人間と AI エージェントを同じ仕組みで認証するため、アイデンティティ基盤の Stytch を $104.1M で買収しました。

## 2026年の変化

- **回線の上に会話レイヤー。** 2026年5月6日の SIGNAL で、Twilio は4つの製品を一般提供（GA）しました。Conversation Orchestrator（チャネルをまたいだ1本のスレッドで、AI と人間のエージェント間の引き継ぎを管理）、Conversation Memory（LLM が参照するために設計された、ID 解決済みの顧客プロファイル）、Conversation Intelligence（会話の途中で感情の変化やエスカレーションを検知する LLM ベースの「language operators」）、Enterprise Knowledge（自社の FAQ やポリシーへのグラウンディング）です。オープンソースのツールキット Agent Connect を使えば、任意の LLM やフレームワークで構築したエージェントをこのレイヤーにつなげられます。
- **ConversationRelay が成熟しました。** Twilio の voice AI ブリッジが音声認識、音声合成、ターンテイキングを担い、自社サーバーは WebSocket 経由で LLM を実行します。2026年には HIPAA 対応、PCI 準拠、Deepgram Flux によるターン検出、そして Conversation Relay Insights（2026年5月6日 GA）が加わりました。通話ごとのレイテンシ、割り込み、処理時間を見るダッシュボードです。
- **Flex は刷新と整理が進みました。** Flex SDK は2026年3月26日に GA となり、既存の Twilio アカウント上の Flex 向けに月間アクティブユーザーあたり $35 のプランが登場しました。Flex の Programmable Chat は2026年6月1日にサポート終了（移行先は Flex Conversations）、現場担当者向けモバイルアプリの Frontline は2026年9月30日に提供終了しました。
- **MCP。** `@twilio-alpha/mcp` サーバーは Twilio の公開 API を Claude などのクライアントに公開し、`--services` と `--tags` でサービスごとに絞り込めます。現在も Alpha の扱いです。

## 実際の価格

API レイヤーは従量課金で、プラットフォーム料金はありません。米国の音声は、ローカル番号の着信が $0.0085/分、トールフリーの着信が $0.022/分、発信が $0.014/分、SIP 経由が $0.004/分です。番号はローカルが月額 $1.15、トールフリーが月額 $2.15 です。ConversationRelay は $0.07/分が加算されます。つまり自社構築の音声エージェントは **LLM を除いて約 $0.08/分** です。月10万分の着信なら、Twilio の料金はおよそ $7,850 で、これにモデルプロバイダーの請求が加わります。Vapi や Retell の標準的な構成（全込みで $0.09〜$0.15/分）より安くなるのは、それらのベンダーが販売しているオーケストレーション作業を自社のエンジニアが引き受ける場合に限ります。

会話レイヤーは別メーターです。Memory は1日あたり利用プロファイル1件につき $0.005 と、recall 1回につき $0.007。Intelligence は Twilio 製 operators で 1K 文字あたり $0.005、Orchestrator は取り込み 1K 文字あたり $0.0002、Knowledge は取得1回につき $0.005 です。月10万件の AI 通話で1通話1回の recall、1日あたり約1万件のプロファイル参照なら、Memory だけで月約 $2,200 になります。

Flex には併用できない3つのプランがあります。月間アクティブユーザーあたり $35 に従量課金を加えるプラン、契約ベースで指名ユーザーあたり月額 $150、またはアクティブユーザー1時間あたり $1 です。指名ユーザーで50席の音声チームなら、電話料金を除いて年間 $90K。Five9 Core の下限 $95K に近い水準ですが、構築は自社の責任です。第三者の見積もりでは外部の導入支援に $10,000 以上かかるとされており、基本的なキュー以上のものを作るならこれを下限と考えてください。Agent Copilot（ベータ）は音声1分あたり $0.035 が加算されます。

## 最適な用途

社内に開発者を抱え、音声とメッセージングのスタックを自社で所有したいサポートエンジニアリングおよび CX オペレーションのチームに向いています。自社の LLM で ConversationRelay 上に AI エージェントを動かす場合も、エージェントのデスクトップ、ルーティング、CRM 連携を自社管理のコードとして Flex 上に独自のコンタクトセンターを構築する場合も同様です。また、ベンダーを乗り換えても番号を持ち出せるよう自社アカウントに番号を置きたい場合、Vapi、Retell、ElevenLabs の下で動く標準の電話レイヤーにもなります。

go-live 後に誰も保守しないなら Flex は見送ってください。パッケージ型の CCaaS には、Flex では自前で構築するかパートナーから購入する必要があるワークフォースマネジメント、品質管理、レポートが最初から含まれています。

## 代替ツールとの比較

**[Genesys Cloud](/ja/tools/genesys-cloud/)** と **[Five9](/ja/tools/five9/)** は、パッケージ型 CCaaS の市場シェア上位です。初日から WFM、QA、スーパーバイザー向けレポートが必要で、チームがコードを書くのではなく設定で済ませたいなら、Flex よりこちらを選んでください。ルーティングやエージェントのデスクトップが特殊で、パッケージ型スイートでもどのみち大幅なカスタマイズが必要になるなら Flex を選んでください。

**[Vapi](/ja/tools/vapi/)** と **[Retell AI](/ja/tools/retell-ai/)** は、音声エージェント向けに Twilio の上で動きます。オーケストレーションを自分で書かずに、テスト、通話分析、コンポーネントの差し替えを使いたいなら、素の ConversationRelay よりこちらを選んでください。すでに Twilio アカウントを大量に利用していて、ベンダー、BAA、請求書を1つにまとめたいなら ConversationRelay を選んでください。

**[ElevenLabs Agents](/ja/tools/elevenlabs/)** は音声エージェント分野で最も急成長している新興勢力です。音声品質と対応言語がプロジェクトの決め手なら ElevenLabs を選び、その下のキャリアとして Twilio を残してください。回線だけを安く調達したいなら、Telnyx が安価なキャリアの選択肢です（Vapi の料金計算ツールで着信約 $0.0055/分）。

どれも合わない場合は、高ボリュームのインテントを1つ、Twilio の番号で Vapi 経由で1か月動かし、同じインテントを ConversationRelay で作り直して、解決済み通話1件あたりのコストを比較してください。オーケストレーションベンダーがそのマージンに見合うかどうかが分かります。

## 注意点

- **メーターは1つではなく5〜6つあります。** 電話、ConversationRelay、LLM、Memory、Intelligence、キャリア手数料はそれぞれ独立して変動します。Twilio によれば、2026年 Q2 には米国キャリア手数料の追加分がメッセージングの成長率を約10ポイント押し上げました。対策：自社のログで通話とメッセージごとにコストセンター属性を付け、料金ページではなく Twilio の Usage API と毎月突き合わせてください。
- **Flex は購入ではなく構築です。** G2 のレビューでは、複雑なセットアップと標準レポートの弱さが指摘されています。対策：契約前に WFM、QA、レポートの範囲を決め、そのためのエンジニアリング工数を予算化するか、パートナーのアドオンの見積もりを取り、go-live 後も Flex のコードベースに担当者を明確に割り当ててください。
- **製品は終了します。** 単体の Programmable Chat が非推奨となった後、Flex の Programmable Chat と Frontline が2026年にサポート終了を迎えました。対策：Twilio の changelog を購読し、現在推奨されている仕組み（Flex Conversations、ConversationRelay、Conversations API）の上に構築し、エージェントのロジックは自社サービス側に置いてください。そうすれば非推奨化で変わるのはアダプターだけで、エージェント自体は変わりません。
- **MCP サーバーは Alpha です。** 対策：必要なサービスに限定した API キーを与え、`--services` で公開範囲を絞り、Twilio のセキュリティチーム自身が勧めているとおり、コミュニティ製の Twilio MCP サーバーと併用しないでください。
