## 概要

Papermark は DocSend のオープンソース代替です。ピッチ資料、提案書、契約書をアップロードしてトラッキング付きのリンクを送ると、誰が開いたか、どのページを読んだか、どれだけの時間をかけたかがわかります。同じ製品でバーチャルデータルームも運用できます。1つのリンクの背後にドキュメントのフォルダを置き、メール認証、NDA への同意の要求、動的な透かし、訪問者ごとの分析を備えたものです。コアは GitHub 上で AGPLv3 として公開されており(スター数 9.2K、2026年8月までコミットあり)、ほとんどのチームが購入するのはホスト版です。

RevOps にとって重要な2026年の追加機能は2つです。1つ目は AI エージェントで、データルーム内のすべてのドキュメントを横断して質問に答え、該当ページへの引用を示し、ルームのアクセス制御を守ります。2つ目として、2026年6月以降、Papermark の MCP サーバー(型付きツール57個)、API、CLI によって、Claude や ChatGPT からルームの作成、ファイルのアップロード、共有リンクの発行、ページ単位の分析の取得ができるようになりました。

Papermark は 2026-06-25 に Hacker News のトップページに載りました。共同創業者が、YC 出資のスタートアップ Corgi が前日にローンチした製品に、Papermark のオープンソースおよびエンタープライズライセンスのデータルームのコードをコピーしたと非難したためです。Corgi はこれを否定しました。この件は製品の品質について何も語りませんが、コードがコピーできるほど公開されていることは示しています。それが次のセクションの論点です。

## オープンソースでも、すべてを無料でセルフホストできるわけではありません

リポジトリは分割されています。`ee/` の外側はすべて AGPLv3 です。`ee/` の内側はすべて Papermark Commercial License の対象で、本番環境で動かすには有料の Enterprise Edition のサブスクリプションが必要です。`ee/` の中には、AI 機能、きめ細かな権限設定、データルームの Q&A(「conversations」)、データルームへの招待、ワークフロー、そしていくつかのセキュリティ制御があります。

つまり、セルフホストの無料版でカバーされるのは、リンクのトラッキング、ページ分析、基本的なデータルームです。デューデリジェンスのためにデータルームを使う理由になる機能は、ライセンス対象のコードです。セルフホストには、PostgreSQL、S3 または Vercel Blob のストレージ、分析用の Tinybird、メール用の Resend の運用も伴います。すぐに対応できるエンジニアがいないチームにとって、現実的な選択肢はホスト版の Papermark です。

## 料金の実態

USD、月払い / 年払い(月額換算)です。2026-10-01 に papermark.com/pricing で確認しました。すべてのプランで訪問者数は無制限です。

- **Free — $0。** 1ユーザー、50リンク、50ドキュメント、ページ単位の分析、分析データの保持期間は30日。
- **Pro — $35 / $29。** 1ユーザー、リンク無制限、100ドキュメント、カスタムブランディング、動画およびその他のファイル形式。
- **Business — $90 / $69。** 3ユーザー(追加1ユーザーあたり +$30 / +$23)、1,000ドキュメント、カスタムドメイン、メール認証、スクリーンショット防止、Webhook、MCP/API/CLI。AI エージェントはこのプランから。
- **Data Rooms — $179 / $119。** 3ユーザー(+$60 / +$40)、データルームとストレージは無制限、NDA への同意、動的な透かし、ファイル単位の権限設定。
- **Data Rooms Plus — $399 / $299。** 5ユーザー、訪問者の監査ログ、Q&A モジュール、ファイルの自動インデックス作成。
- **Data Rooms Premium — $799 / $649。** 10ユーザー、AI による墨消し、ワークフロー、SSO は要望に応じて提供。
- **Data Rooms Unlimited — $1,799 / $1,199**、ユーザー無制限。セルフホストの Enterprise は見積のみです。

料金はワークスペースごとの定額に席数を加えたもので、ドキュメント単位やページ単位ではありません。これが DocSend との主な差です。年払いの5人のディールチームの場合、Papermark Data Rooms は年間 $2,388(含まれる3席に加えて $40 の席が2つ)で、DocSend Advanced は $3,960(3ユーザーで $150 に加えて $90 の席が2つ)、DocSend Advanced Data Rooms は $4,320 です。Q&A モジュールと訪問者の監査ログが加わる Papermark Data Rooms Plus は、5席込みで年間 $3,588 になります。

注目すべきプランは Data Rooms Plus です。Q&A と訪問者の監査ログは、デューデリジェンスで買い手側の弁護士が求める2つの機能であり、どちらも $119 ではなく年払いで月額 $299 のプランに含まれています。

## 適した用途

送信者が1〜10人のディールチームに属する RevOps 責任者、創業者、営業責任者で、ピッチ資料、提案書、デューデリジェンス資料を社外に送り、DocSend 型のページトラッキングを求め、送信者単位の課金なしでデータルームを使いたい方に向きます。資金調達ラウンド、セキュリティ質問票と MSA を伴うミッドマーケットの営業サイクル、パートナーやチャネルとのドキュメント共有に適しています。

**次の場合は使わないでください。** 数十社の入札者と正式な Q&A プロセスを伴う、バンカー主導のセルサイド M&A を行う場合です。それは契約形態とサポート体制を含めて Datasite や Intralinks の領域です。また、セルフホストのスタックを担当する人がいて、どの機能が `ee/` にあるかを読んで確認していない限り、オープンソースライセンスだけを理由に選ばないでください。

## 代替候補との比較

- **DocSend (Dropbox)** — 既存の定番で、投資家が見慣れたリンク形式です。Dropbox は 2025-03-31 に無料の Send and Track 機能を終了し、そのユーザーを有料の DocSend に誘導しました。送信者が1人でリンクのトラッキングだけが必要で、受信者が DocSend に慣れていることが重要なら、DocSend Personal(年払いで1ユーザー $10)を選んでください。送信者が3人を超えるか、データルームが必要になった時点で、同じ席数なら Papermark のほうがおよそ40〜45%安くなります。
- **Datasite と Intralinks** — 規制対象でバンカー主導の M&A 向けのエンタープライズ向けバーチャルデータルームです。料金は見積制です。ディールの規模がプロジェクト契約に見合い、セルサイドのアドバイザーがプラットフォームを指定する場合に選んでください。
- **Peony** — 比較的新しいベンチャー出資の参入企業(2021年創業、サンフランシスコ)で、管理者単位の料金です。Peony 自身の料金表によれば、管理者1人あたり月額で Business が $30、Data Room が $52 です。管理者1人がルームを運用するなら Peony を選んでください。Papermark Data Rooms は3席付きで $119 からなので、管理者が3人以上なら Papermark が有利です。
- **[Dock](/ja/tools/dock/)** — 成果物がトラッキング付きのドキュメントではなく、相互アクションプランを備えた買い手向けのデジタルセールスルームである場合に選んでください。Papermark はファイルをトラッキングし、Dock はその周りのディールのワークスペースを運用します。

## 注意点

- **AI と Q&A はオープンソースではなく、ライセンス対象のコードです。** 対策: セルフホストを選ぶ前に、必須機能を列挙し、それぞれがリポジトリの `ee/` 配下にあるかを確認してください。1つでも該当するなら、Enterprise Edition の予算を確保するか、ホスト版を購入してください。
- **CRM とのネイティブ同期がありません。** ネイティブの OAuth 連携は Slack のみです。HubSpot、Notion、Salesforce は、署名付き Webhook と Zapier、Make、n8n の組み合わせで接続します。対策: 展開前に Webhook から CRM へのフィールドマッピング(閲覧者のメールアドレス、ドキュメント、閲覧ページ、完了率)を構築してテストし、自動化ツールのタスク量を予算に含めてください。
- **デューデリジェンス向けの機能は2段階上のプランにあります。** Q&A モジュールと訪問者の監査ログは Data Rooms Plus から、SSO は Premium からで、しかも「要望に応じて」の提供です。対策: ルームを公開した後ではなく契約前に、セキュリティレビューと弁護士のデューデリジェンスのチェックリストをプランに照らし合わせてください。
- **下位プランでは分析履歴が短いです。** Free は分析データを30日間、Pro は1年間保持します。対策: Papermark を記録システムとして頼るのではなく、初日から Webhook を通じてエンゲージメントデータを CRM にエクスポートしてください。
- **改変した場合の AGPL 上の義務。** 改変した Papermark を外部ユーザー向けに運用すると、AGPLv3 のソース開示条項が適用されます。対策: フォークを外部ユーザーに触れさせる前に、法務レビューを通してください。
