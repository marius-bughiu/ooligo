## 概要

Mistral AI は、2023 年に Arthur Mensch、Guillaume Lample、Timothée Lacroix が創業したパリのモデル開発企業です。オペレーションチームが本来 OpenAI や Anthropic から買うはずのフルスタック、つまり自社開発のフロンティアモデル、全社向けアシスタント、開発者プラットフォームをすべて販売している唯一のヨーロッパ企業です。オペレーション部門の購買担当者にとって重要な製品は 2 つあります。

**Vibe** はアシスタントです。2026 年 5 月 28 日までは Le Chat という名前でした。Mistral は名称を変更し、コーディングエージェントを統合しました。その結果、1 つの製品に **Work** 側（リサーチ、ドキュメントやレポートの作成、会議準備、メール・カレンダー・Slack をまたぐ定期タスク）と **Code** 側（CLI、VS Code、JetBrains、Zed、クラウドから動くサンドボックス上のコーディングエージェント）があります。URL、ログイン、サブスクリプションは引き継がれましたが、Mistral のヘルプや法務関連の資料の多くは今も「Le Chat」と表記しています。

**Studio**（旧 La Plateforme）は API とエージェント構築のコンソールです。2026 年 5 月 22 日から、Connectors in Studio が連携機能を再利用可能な MCP エンティティとしてパッケージ化しています。GitHub、Gmail、Web 検索などの組み込みコネクタに加え、自社のリモート MCP サーバーや任意の公開 MCP サーバーを指すカスタムコネクタも登録できます。どのツールにも `requires_confirmation` を設定でき、設定するとツール呼び出しの実行前にエージェントが一時停止し、制御がアプリケーション側に戻ります。この機能はパブリックプレビューです。

2026 年 10 月 28 日時点のモデルラインナップは、Mistral Large 4（v26.10）、Medium 3.5（修正 MIT ライセンス）、Small 4（Apache 2.0）、OCR 4.1 で、汎用モデルの大半はオープンウェイトです。同社は買収される側ではなく買収する側です。2026 年 9 月 8 日に 30 億ユーロのシリーズ D を完了し、ポストマネー評価額は 210 億ユーロを超えました。リードは Samsung Electronics、共同リードは EQT の Scaleup Europe Fund と PSG Equity です。2026 年中に Koyeb、Emmi AI、Pimento を買収しています。

## RevOps・Legal Ops・Recruiting のスタックに登場する理由

- **「秘匿特権のあるデータをどのモデルベンダーなら見せてよいか」に対する EU ソブリンな答えです。** Enterprise の顧客は、Vibe とモデルを Mistral のクラウド、プライベートクラウド、または自社ハードウェアで運用でき、ベンダー、契約当事者、モデルウェイトのすべてがヨーロッパに属します。秘匿特権のある文書を扱う Legal Ops チームや、労使協議会のある法域の人事チームにとって、これは US Cloud Act の問題を緩和するのではなく、問題そのものをなくします。
- **エージェントがチームの既存システムに届きます。** Vibe は 100 以上のコネクタを掲げており、Google Workspace、Outlook、[SharePoint](/ja/tools/microsoft-sharepoint/)、[Slack](/ja/tools/slack/)、Jira、GitHub に加え、カスタム MCP にも対応します。RevOps リーダーは、フォーキャストのシートを読んで Slack に投稿する週次のパイプラインリスクレポートをスケジュールできます。Work モードは実行前に計画を提示して承認を求め、そのルーティンを再利用可能なスキルとして保存します。
- **モデルは、すでに導入済みのツール経由でも使えます。** [Langdock](/ja/tools/langdock/) と [Dust](/ja/tools/dust/) はどちらもワークスペース内で Mistral のモデルを提供しています。また Studio の API は、受信した契約書を分類したり応募書類をスクリーニングしたりする n8n フローの裏側に置けるほど安価です。

## 実際の価格

Vibe のセルフサーブプラン（税抜）は次のとおりです。

- **Free** — $0。メッセージ数、検索数、コーディングセッションに上限があります。
- **Pro** — 1 人あたり月額 $14.99。月 $15 分の API クレジットが含まれます。
- **Team** — 月払いで 1 ユーザーあたり月額 $24.99、年払いで €19.99（The Decoder）。Pro と Team の利用上限は同じで、Team には共有ワークスペース、管理ツール、ドメイン認証、データエクスポート、追加ストレージが付きます。
- **Enterprise** — 個別見積もり。SAML SSO、監査ログ、カスタムエージェント、ホワイトラベル、オンプレミスまたはプライベートクラウドへのデプロイはここに含まれます。

Studio はトークン単位の課金です。Mistral の料金ページでは、Mistral Large は入力 100 万トークンあたり $0.50、出力 100 万トークンあたり $1.50 と記載されており、バッチ処理は半額、キャッシュされた入力は最大 90% 安くなります。OCR は 1,000 ページ単位の課金です（OCR 4 は $4 で提供開始）。

150 人規模のオペレーション組織が Team を年払いで使う場合、年間約 36,000 ユーロを見込んでください（試算：150 × €19.99 × 12）。これは ChatGPT Business の年払い $20 のシートとほぼ同じ水準で、シート単位では Mistral は安い選択肢ではありません。節約効果が出るのは API 側です。Large の $0.50/$1.50 は、大量の分類・抽出処理において Claude Sonnet の入力価格の 6 分の 1、出力価格の 10 分の 1 です。SSO やセルフホスティングが要件に入った時点で、下限価格が公開されていない Enterprise の見積もりになります。

## 最適な利用者

EU に本社を置く、または EU の規制を受ける企業の Legal Ops、人事、RevOps のリーダーで、秘匿特権のあるデータ、個人データ、労使協議会が関わる機微なデータについて調達部門が承認できるアシスタントとモデルベンダーを 1 つに絞りたい人。そして、法域を優先するためにフロンティアでのモデル品質をある程度譲れる人です。

英語の営業業務で Claude や GPT からの単純な品質向上を狙って導入するのは避けてください。そこは Mistral が勝てる領域ではありません。また、IdP ポリシーで SAML SSO が必須なら Team は選ばないでください。SAML SSO は Enterprise 限定です。

## 代替候補との比較

**[ChatGPT](/ja/tools/chatgpt/) Enterprise** と **[Microsoft 365 Copilot](/ja/tools/microsoft-365-copilot/)** が導入済みベースの大半を占めています。米国ベンダーでも問題なく、コネクタと GPT のエコシステムの広さを重視するなら ChatGPT を選んでください。業務が Outlook、Teams、SharePoint の中にあり、すでに Microsoft 365 を契約しているなら Copilot です。契約、ホスティング、モデル開発元のすべてをヨーロッパにそろえる必要があるなら Mistral を選んでください。

**[Claude](/ja/tools/claude/)** は、Menlo Ventures の 2025 年調査でエンタープライズ向け LLM API のシェアで OpenAI を上回った、最も成長の速い挑戦者です。長文ドキュメントの推論やエージェント型コーディングではこちらが強い選択肢です。法域が絶対条件でない限り、Mistral より Claude を選んでください。

**[Langdock](/ja/tools/langdock/)** は、EU に拠点を置くワークスペースが欲しい一方で、Claude や GPT も Mistral と並べて 1 つの請求書で使いたい場合の選択肢です。マルチテナントのクラウドは Azure 上で動き、トラフィックの大半は米国のモデル開発元に流れるため、ソブリンティの答えとしては Mistral 本体より弱くなります。

**[Noxtua](/ja/tools/noxtua/)** は、リーガルリサーチと起案に限れば Mistral より優れています。ライセンス取得済みの法律コンテンツと Word のワークフローを、ヨーロッパのインフラ上で提供しているためです。

データを一切社外に出せず、どのベンダーとも関係を持ちたくないためにどれも合わない場合は、Mistral の Apache 2.0 オープンウェイトモデルを [Onyx](/ja/tools/onyx/) などのセルフホスト型フロントエンドの裏で自社運用してください。

## 注意点

- **製品名がまだ変わり続けています。** 2026 年 5 月に Le Chat は Vibe に、La Plateforme は Studio になり、以前の契約書、DPA、ヘルプ記事は旧名称のままです。*対策：* 発注書と DPA に製品名、プラン、デプロイ形態を明記し、現行の再委託先リストが Vibe をカバーしていることを Mistral に確認してください。
- **モデルの退役サイクルが速いです。** Mistral は後継モデルが一般提供またはパブリックプレビューに達した時点で非推奨を告知します。第三者のトラッカーは、2026 年 10 月中旬までに Mistral のページ上で 43 のモデルが非推奨または退役になったと数えています。*対策：* Studio のすべてのエージェントとワークフローで日付付きのモデルバージョンを固定し、`-latest` エイリアスは使わないでください。非推奨ページを購読し、予定された停止のたびに評価セットを再実行してください。
- **学習へのデータ利用除外はプランによって異なります。** Mistral のヘルプセンターによると、Team と Enterprise のユーザーはデフォルトでモデル学習の対象外です。Free と Pro のユーザーは、プライバシー設定を切り替えない限り対象外になりません。*対策：* 業務に個人の Pro アカウントを経費精算で使うことを禁止して該当ユーザーを Team に移すか、管理コンソールで除外を強制してください。
- **Studio での人による承認はツールごとのオプトインです。** CRM や ATS に書き込むカスタム MCP コネクタは、`requires_confirmation` を設定しない限り一時停止せずに実行されます。*対策：* エージェントが本番データに触れる前に、書き込み可能なツールすべてにフラグを設定してください。また、この機能がパブリックプレビューの間は、Connectors in Studio を無人実行のワークフローに組み込まないでください。
