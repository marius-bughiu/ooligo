O Cursor é um editor de código com um agente que pode pesquisar o repositório, alterar arquivos e executar comandos. Faz sentido quando uma mudança no processo de RevOps exige revisão de código. Peça, por exemplo, que ele encontre a função que mapeia as etapas de venda na importação para o CRM. Forneça uma linha fictícia com uma etapa desconhecida. Antes de aceitar a mudança, exija um teste que encaminhe a linha para revisão sem gravar nada no CRM. [Agente do Cursor](https://cursor.com/docs/agent/overview)

## O que a assinatura cobre

Para novas assinaturas individuais, o Free tem uso limitado do agente. O Plus custa US$ 8 por mês e exclui modelos de terceiros. O Premium custa US$ 30 por mês e inclui agentes na nuvem. Se você escolher um modelo Claude no Premium, o uso é cobrado à parte pelo preço de tabela da API e descontado do saldo pré-pago. São preços mensais da contratação pela web, antes de impostos, consultados em 2 de novembro de 2026. [Preços do Cursor](https://cursor.com/pricing) · [Modelos e cobrança](https://cursor.com/docs/models-and-pricing)

Quem mantém o antigo Pro de US$ 20 por mês pode continuar com as condições de uso desse plano. Segundo o Cursor, a mudança para a nova assinatura é opcional e não pode ser desfeita. Confira o plano da conta antes de estimar a próxima fatura. [Condições dos planos antigos](https://cursor.com/docs/account/pricing/legacy-cursor-plans)

## Como funcionam a API e o MCP

A API Cloud Agents v1 está em beta público. Um programa pode iniciar um agente em um repositório conectado usando `POST /v1/agents` e consultar a execução. O Cursor aceita repositórios no GitHub e no GitLab, entre outros. Você precisa de um repositório autorizado, uma conta com acesso e uma chave de API de usuário ou de conta de serviço. [API Cloud Agents](https://cursor.com/docs/cloud-agent/api/endpoints)

O MCP permite disponibilizar ferramentas externas ao Cursor por meio de um servidor configurado. Se o agente só precisa da definição de um campo do CRM, dê a ele uma conexão de leitura. A chave para iniciar um agente na nuvem não concede, por si só, permissão para gravar no CRM. [Configuração do MCP](https://cursor.com/docs/mcp)

## Antes de compartilhar um repositório

Usuários individuais podem ativar o Privacy Mode nas configurações. Um administrador também pode definir o modo para a equipe. Segundo o Cursor, com esse modo ativo, os dados do cliente ficam fora do treinamento. O fornecedor descreve exceções de retenção para investigações de abuso e determinados modelos. Confira o modo ativo, o modelo e os repositórios permitidos no seu ambiente. [Segurança do Cursor](https://cursor.com/security) · [Uso de dados](https://cursor.com/data-use)

Se você já assina o Claude, use a importação de duas linhas do [comparativo entre Claude e Cursor](/pt-BR/vs/claude-vs-cursor/) para avaliar quanto o editor acrescenta ao seu trabalho.
