## 概要

Kombo は HR データ向けの共通モデル API で、HR チーム自身ではなくソフトウェアベンダー向けに作られています。リクルーティングテックや HR テックの製品は Kombo の共通データモデルに一度統合するだけで、その製品の顧客は埋め込み型の接続フローである Kombo Connect を通じて、自社の ATS、HRIS、給与計算、LMS、アセスメントシステムを接続できます。Kombo は 4 つのカテゴリ別 API（ATS、HRIS と給与計算、アセスメントとバックグラウンドチェック、LMS）を、本人いわく「数百」のシステムに対して提供しています。競合各社の分析では 2026 年 10 月時点で合計 250 以上とされ、ATS への書き込みに関する Kombo 自身の記事は 108 の ATS 連携を対象としています。

Kombo は 2022 年に創業し、ベルリンとニューヨークに拠点を置き、Y Combinator を投資家に持ちます。2026 年 2 月 18 日に Volition Capital がリードする 2,500 万ドルのシリーズ A を調達し、累計調達額は 3,000 万ドルになりました。300 社以上と取引しているとし、Indeed、Paychex、HireVue、Mercor、Juicebox、Gem を顧客として挙げています。[Greenhouse](/ja/tools/greenhouse/)、[Metaview](/ja/tools/metaview/)、[SeekOut](/ja/tools/seekout/)、[TestGorilla](/ja/tools/testgorilla/) もロゴ一覧に掲載されています。SOC 2 Type 2 と ISO 27001 を取得しており、ホスティングは米国、カナダ、EU から選べます。

## リクルーティングのスタックに登場する理由

オペレーション責任者が Kombo を直接購入することはほとんどありません。Kombo が登場するのは、あなたが評価しているツール（[Gem](/ja/tools/gem/)、[Juicebox](/ja/tools/juicebox/)、[HireVue](/ja/tools/hirevue/)、そして多数の小規模な AI リクルーティング製品）が、あなたの ATS に接続するために使っているからです。これは 2 つの立場で意味を持ちます。リクルーティングテックベンダーや社内の TA エンジニアリングチームで連携を担当しているなら、Kombo は「ATS コネクタを自前で作るか、Merge を使うか、Kombo を使うか」という問いにおける購入側の選択肢です。そうしたツールを購入する側なら、Kombo は候補者データのコピーを保持する再委託先であり、セキュリティレビューの対象に含めるべきです。

HR 専業であることが Kombo を選ぶ理由です。共通モデル API は書き込みの深さで手薄になりがちですが、Kombo は数値を公開しています。2026 年 10 月の ATS に関する記事によると、108 の ATS 連携のうち 103 で応募の作成、52 で選考ステージ間の候補者移動、24 で理由付きの不合格処理に対応しています。これらは AI スクリーニングやソーシング製品が、別タブではなく顧客の ATS の中で処理を完結させるために必要な操作です。Kombo はさらに [Workday](/ja/tools/workday/)、SAP SuccessFactors、Oracle との認定パートナーシップを掲げています。これらはコードではなくパートナーアクセスがボトルネックになるシステムです。

## 実際の価格

Kombo は価格を公開していません。3 つのプラン（Start、Scale、Enterprise）はいずれもデモ経由で販売されます。料金体系は年額固定のプラットフォーム料金と、接続されたエンド顧客ごとの定額料金の組み合わせで、後者はボリュームに応じて下がります。API コール単位やデータ量単位の課金はなく、非アクティブな連携には課金されません。サンドボックス付きの無料 PoC が用意されています。

公開されていない価格表よりも、各プランで何が使えるかの方が重要です。

- **Start** は読み取り専用です。このプランには書き込み API がありません。
- **Scale** では読み書きアクセス、より高頻度の同期、Workday や [iCIMS](/ja/tools/icims/) などのエンタープライズシステム、30 日間のログ、専任のアカウントマネージャーが追加されます。ATS に書き戻す製品には最低でも Scale が必要です。
- **Enterprise** ではマルチリージョンのデータレジデンシー、SAML SSO、稼働率とサポートの SLA、90 日以上のログ、SFTP 連携とカスタム連携、SAP と Workday のサンドボックスが追加されます。

公開されている支出データは、Cledara のマーケットプレイスにおける同社顧客の平均額約 5,200 ドルのみで、期間も接続数も示されていません。見積もりではなく、小規模導入の目安として扱ってください。比較の基準として、[Merge](/ja/tools/merge/) は共通モデル API の Launch プランを、連携アカウント 10 件まで月額 650 ドル、それ以降 1 件ごとに 65 ドルと公開しており、接続顧客 20 社なら年額 15,600 ドルになります。2 社の見積もりを比較できるよう、Kombo には同じ 20 社と 100 社のシナリオを Scale で見積もってもらいましょう。

## 最適な利用者

リクルーティングテックや HR テックのベンダーで、シリーズ A からグロース段階にあり、連携やプラットフォームエンジニアリングを率いる責任者です。顧客が Workday、iCIMS、SuccessFactors を含む数十種類の ATS や HRIS を使っていて、製品が候補者、ステージ変更、結果をそれらのシステムに書き戻す必要がある場合に向いています。EU のホスティングとベルリンのチームがあるため、顧客基盤が EU 中心であればさらに適しています。

## 向かないケース

- 社内の TA オペレーションチームが、1 つの ATS と 1 つの HRIS をつなぐだけの場合。ネイティブ連携か iPaaS を使ってください。共通モデル API が元を取れるのは、多数のシステム上の多数の顧客にサービスを提供する場合だけです。
- CRM、会計、チケット管理の連携も必要な製品。Kombo は HR 専業です。
- ライブの HR データへの MCP アクセスが今すぐ必要なエージェント開発チーム。Kombo の 2026 年 9 月のブログは連携を MCP 経由で使えるとしていますが、競合による分析では、2026 年 10 月時点で Kombo の公開ドキュメントにはドキュメント検索用の MCP サーバーしか見つかりませんでした。これを前提に計画する前に、デモで確認してください。

## 代替ツールとの比較

- **[Merge](/ja/tools/merge/)** は共通モデル API の最大手で、HRIS、ATS、CRM、会計、チケット管理、ファイルストレージをカバーし、セルフサーブの価格を公開しています。HR 以外のカテゴリが必要な場合や、営業との商談なしで始めたい場合は Merge を選んでください。
- **自社開発**は、顧客の大半が [Greenhouse](/ja/tools/greenhouse/)、[Lever](/ja/tools/lever/)、[Ashby](/ja/tools/ashby/) のようなオープンな API を持つ少数の ATS に集中している場合に適しています。データ経路とロードマップを自社で握れる代わりに、新しいシステムや API 変更のたびにエンジニアリング工数を払うことになります。
- **Knit** と `Unified.to` は新しい挑戦者です。どちらも保存したコピーではなくパススルー型の読み取りを提供し、エージェント向けの MCP アクセスを打ち出しています。顧客のセキュリティレビューが第三者による候補者 PII の保存を認めない場合や、エージェントが同期サイクルより新しいデータを必要とする場合は、どちらかを選んでください。

どれも合わない場合は、最大手の顧客が必要とする 3〜4 個のコネクタを自社で作り、ATS のロングテールの要望が商談を止め始めた時点で初めて共通モデル API を追加してください。

## 注意点

- **Kombo はデータのコピーを保存します。** 候補者と従業員のレコードを自社データベースにミラーし、デフォルトでは 3 時間ごとに同期します（有料プランではより高頻度で、Kombo によれば最短 5 分）。ソースシステムからの Webhook を受け取れるのは 22 の連携のみです。対策：DPA に Kombo を再委託先として記載し、セットアップ時にホスティングリージョンを選び、候補者の自動不合格処理のような時間に敏感な操作の前には手動同期を実行してください。
- **書き込みの対応範囲にはばらつきがあります。** ステージ移動は 108 の ATS のうち 52、理由付きの不合格処理は 24 でしか動きません。対策：契約前に、顧客の上位 20 の ATS と自社製品が必要とする具体的な書き込み操作のマトリクスを作り、PoC のサンドボックスで 1 つずつテストしてください。
- **エンタープライズのサンドボックスは時間がかかります。** Knit がまとめた G2 のレビューでは、iCIMS のサンドボックスを 3〜6 か月待ったと報告されています。対策：パートナーのサンドボックス申請は初日に出し、Workday や SAP を使う企業に販売するなら、これらのサンドボックスが含まれる Enterprise を予算に入れてください。
- **デフォルト認証情報は乗り換えコストを生みます。** 競合による Kombo ドキュメントの分析によると、Kombo のデフォルト認証情報で接続した顧客は、プロバイダーを乗り換える際に再接続が必要です。対策：ATS が対応している限り自社のパートナー認証情報を使い、トークンとデータのエクスポートを契約に明記してください。
