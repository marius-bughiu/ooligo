## 概要

BuiltWith はオーストラリアのテクノグラフィックデータ企業です。公開 Web サイトをクロールし、各サイトが読み込むコードを識別して、使われている技術を記録します。対象は CMS、ecommerce プラットフォーム、アナリティクス、タグマネージャー、チャットウィジェット、広告ピクセル、決済サービス、CDN などです。プランページによると、4 億 9,190 万ドメインで 128,510 種類の技術を追跡しており、数十年分の履歴があります。いずれもベンダー公表値です。

データの使い方は 3 つあります。

- **リードリスト。** 技術を 1 つ選び（「Shopify Plus を使うすべてのサイト」や「今年 Marketo をやめたすべてのサイト」など）、企業名、トラフィック、支出推定、そして取得できる場合は担当者の氏名・メール・役職を含むリストをエクスポートします。
- **個別検索とアラート。** 1 つのドメインの技術スタックを確認したり、新たにある技術を導入したサイトを Slack で通知させたりできます。
- **API と MCP。** Domain API は 1 ドメインにつき 1 クレジットでサイトの技術プロファイルを返します。2026 年 2 月、BuiltWith は `api.builtwith.com/mcp` のホスト型 MCP サーバー、`llms.txt` ファイル、API キーのクォータを返す WHOAMI エンドポイントを追加しました。これにより Claude や自社のエージェントから直接データを照会できます。2026 年 7 月には「Acquired and Funded Websites」ビューを追加し、買収や資金調達の発表に関連するサイトを、判明している場合は金額・ラウンド・投資家とともに一覧表示できるようになりました。

1 サイト単位の検索は引き続き無料です。

## RevOps スタックに登場する理由

このページが答える問いは、テクノグラフィックデータを BuiltWith から直接買うか、HG Insights、ZoomInfo、Clay に含まれる形で手に入れるか、です。

**BuiltWith に見えるのは Web サイトが読み込むものだけで、それ以外はほぼ見えません。** これが強みであり限界でもあります。競合として狙う技術がサイトのコードに痕跡を残すもの（Shopify、Klaviyo、HubSpot フォーム、Intercom、Google Tag Manager、決済ウィジェットなど）であれば、BuiltWith は検出し、初回検出日と最終検出日を記録し、導入サイトをすべて一覧にできます。競合がバックオフィス系ソフトウェア（ERP、データウェアハウス、HR スイートなど）の場合、通常は Web 上に痕跡が残らず、BuiltWith では見えません。HG Insights や Sumble は求人情報や文書などのシグナルからそれを推定します。

**ルールはシンプルです。** 販売先が ecommerce ブランド、代理店、マーケティングチームなど、ターゲットの技術スタックがサイト上に見える相手なら、BuiltWith を直接買います。インフラやエンタープライズソフトウェアを売るなら、Web サイトの裏側まで見えるベンダーを買い、BuiltWith は補助的なフィルターとして使います。

## 実際の価格

BuiltWith は価格を公開しています。2026 年 11 月 14 日時点のプランページの月額定価は次のとおりです。

- **Basic：月額 295 ドル。** レポート対象は技術 2 つとキーワード 2 つ、ログイン 1 つ、CRM 連携付き。BuiltWith のナレッジベースによると、ドメインのアップロードは月 2,000 件までです。
- **Pro：月額 495 ドル。** 技術、キーワード、リテールレポートが無制限、ログイン 1 つ、アップロードクレジットは月 20,000。
- **Team：月額 995 ドル。** Pro の全機能に加え、ログイン無制限、API クレジットは年間 120 万。
- **Team Ultra：価格非公開。** 専用 API エンドポイントでの検索が無制限、最大 1 億レコードのデータセット付き。見積もりが必要です。

年払いには割引があります。BuiltWith のナレッジベースでは Team が年額 9,950 ドルで、約 2 か月分が無料になる計算です。月額プランの最低契約期間は 1 か月で、いつでも解約できます。無料トライアルはありません。単発のリストが欲しい場合、BuiltWith 自身が Basic を 1 か月だけ購入して解約する方法を勧めています。

**実際の支払額：** 個人の営業担当や代理店なら通常 **月額 295〜495 ドル** です。ログインの共有と API アクセスが必要な営業チームは Team で **年間約 10,000〜12,000 ドル** になります。HG Insights と比べると、Vendr のデータでは HG の契約額の中央値は年間約 90,000 ドルです。

## 最適な利用者

**ecommerce 事業者や Web サイト中心のビジネスに販売する企業**（Shopify アプリ、マーケティング代理店、決済やレビューのベンダーなど）の **RevOps リーダーや自ら営業する創業者** で、特定の技術を使っている・導入した・やめたサイトをすべてリスト化し、HubSpot や Salesforce に送りたい人です。BuiltWith が文句なしに勝つ具体的なケースは、競合のアプリを導入したばかりの新しい Shopify Plus ストアの週次リストを作り、SDR に振り分ける場面です。

## 向いていないケース

購買者の技術スタックが外から見えないチームには向きません。連絡先データベースとして使うのもやめましょう。レビューでは連絡先データの評価が技術検出よりも一貫して低く、G2 の比較ページでは連絡先の正確性スコアが 10 点中 6.0 です。メールや電話番号の補完は別のツールで行う前提にしてください。

## 代替ツールとの比較

- **ZoomInfo**：B2B データで市場シェア首位。テクノグラフィックは連絡先データベース内のフィルターの 1 つです。検証済みの連絡先が最優先なら ZoomInfo を選びます。技術リストそのものが目的で、履歴や初回検出日が欲しいなら BuiltWith を選びます。[ZoomInfo](/ja/tools/zoominfo/) を参照。
- **HG Insights**：エンタープライズ IT 向けテクノグラフィックの首位。導入数、IT 支出、バックオフィス系ソフトウェアのデータが必要なら HG を選びます。費用はおよそ 10 倍です。[HG Insights](/ja/tools/hg-insights/) を参照。
- **Sumble**：当サイトで扱うテクノグラフィックの新興勢力のなかで最も成長が速いツールです。求人情報などの公開シグナルから技術スタックを推定し、無料プランと、1 ユーザーあたり月額 99 ドルの Pro があります。BuiltWith には見えないバックオフィス系やデータ系のツールを把握したいなら Sumble を選びます。[Sumble](/ja/tools/sumble/) を参照。
- **Clay**：BuiltWith をネイティブのエンリッチメントとして提供しています（「Find Technology Stack」。Clay 管理アカウントでは 1 行あたり 2 Clay クレジット、有料プランなら自社の BuiltWith キーも使用可能）。テクノグラフィックが長いエンリッチメントのワークフローの 1 ステップにすぎず、既存アカウントの照会だけで足りるなら Clay を選びます。ある技術の導入企業をすべてリスト化したいなら BuiltWith を直接買います。[Clay](/ja/tools/clay/) を参照。

## 注意点

- **検出は実際の変化より遅れます。** 先月ツールを外した企業が、まだそのツールを使っているように表示されることがあります。**対策：** リプレイス狙いのキャンペーンの前に、BuiltWith の最終検出日でフィルターし、直近 30〜60 日に検出されていないものは除外します。
- **タグが検出されても有料顧客とは限りません。** 消し忘れのスクリプトや無料プランも、エンタープライズ契約と同じようにカウントされます。**対策：** 技術フィルターに支出やトラフィックのしきい値を組み合わせ、競合の顧客としてスコアリングする前に、初回の商談で営業担当に確認させます。
- **Basic は見た目より範囲が狭いです。** 技術 2 つとログイン 1 つは固定のリストには十分ですが、探索には向きません。**対策：** 3 つ以上の技術を試すなら、まず 1 か月 Pro で始め、ターゲットリストが固まったらダウングレードします。
- **API クレジットはドメイン単位で消費されます。** **対策：** 大量のアカウントリストを巡回するエージェントに MCP サーバーを接続する前に、WHOAMI を呼び出してクォータを確認します。
