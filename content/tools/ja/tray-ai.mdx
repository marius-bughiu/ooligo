## 概要

Tray.ai(リブランド前の名称は Tray.io)は、San Francisco に本社を置くローコードの統合・自動化プラットフォームです。2012年に Rich Waldron が共同創業し、現在も同氏が CEO を務めています。市場の中間に位置する製品です。[Zapier](/ja/tools/zapier/) や [Make](/ja/tools/make/) よりガバナンスと深さがあり、[Workato](/ja/tools/workato/) より価格の下限が低く導入も軽く、[n8n](/ja/tools/n8n/) が求めるセルフホスティングの手間もありません。

Gartner は2026年3月18日に公開した Magic Quadrant for iPaaS で、Tray.ai を Visionary に位置付けました。3年連続で、この象限に入った4社のうちの1社です。この意味は正確に読んでください。Visionary はビジョンの完全性による位置付けであり、実行能力による評価ではありません。同じレポートで Workato と Boomi は Leader です。公開されている顧客事例には Life360、Apollo、Yext、Zuora があります。

## 2026年に何が変わったか

2023年に評価したことがあるなら、Tray は3つの点で別の製品になっています。

**Tray Headless** は2026年6月3日にリリースされ、プラットフォームを AI コーディングツールの中に持ち込みます。提供形態は2つです。[Claude Code](/ja/tools/claude/) 向けの `tray-workflows` プラグインと、Cursor、Codex、Windsurf、あるいは自社のエージェントから操作できる `api.tray.io/mcp` のホスト型 MCP サーバーです。「sync new Salesforce leads to Slack」のように自然言語で統合を記述すると、ワークフローの計画、コネクターの選定、認証の設定、ステップの検証を行い、承認を得たうえでテスト実行します。こうして作ったものは移行作業なしでビジュアルビルダーで開けるため、エンジニアがテキストで下書きし、運用担当者がキャンバス上で保守する分担ができます。認証は API トークンの貼り付けではなく、ブラウザでの OAuth サインインです。リリース時点の制約として、Headless は US リージョンのワークスペースに限定されています。

**Agent Gateway** は逆方向の機能です。Tray のワークフローと700以上のコネクターを、外部エージェントが呼び出せるガバナンス付きの MCP ツールとして公開し、アクセス制御、認証オプション、オブザーバビリティを備えます。**Merlin Agent Builder** は Tray 独自のエージェント層で、ガードレール、監査ログ、ナレッジ取り込み、メモリ、複数 LLM への対応、Slack と Teams へのデプロイに加え、ITSM と HR 向けの既製エージェントを備えています。この2つは有料アドオンの Agent Development に含まれます。Headless MCP、Claude Code と Codex 向けプラグイン、API へのフルアクセスは全プランに含まれます。

## 購入に値するユースケース

Zapier のアカウントでは手に負えなくなったリードとアカウントの紐付け・ルーティングです。フォーム送信やエンリッチメントのイベントが届くと、Tray は [Salesforce](/ja/tools/salesforce/) または [HubSpot](/ja/tools/hubspot/) の既存アカウントに照合し、テリトリーとラウンドロビンのルールを適用し、レコードを作成または更新し、[Slack](/ja/tools/slack/) で担当者に割り当てを通知します。重複への分岐、CRM が書き込みを拒否したときの明確なエラーパス、後から誰でも読めるログも備えます。これが Tray の得意な問題の形です。2〜3の基幹システムにまたがる多分岐のロジックを、統合専門の CoE ではなく RevOps やシステムチームが担うケースです。Headless を使えば、RevOps エンジニアが Claude Code から午後のうちにこのワークフローを下書きし、ビジュアルで保守する管理者に引き渡せます。

## 価格

Tray は Pro、Team、Enterprise の3プランを公開していますが、どのプランにも価格は掲載していません。Pro は3ワークスペースと7日間のログ保持、Team は20ワークスペース、30日間のインサイト、ログのマスキング、Enterprise は無制限のワークスペース、180日間のインサイト、SSO、HIPAA、リージョン別ホスティング、オンプレミス機能を追加します。3プランとも、課金単位はタスクひとつです。

基準になるのは Vendr の取引データです。108件の購入で**年間中央値は37,641ドル**、範囲はおよそ18,700ドルから96,300ドル、初回見積もりからの平均値引きは26%です。比較として Vendr は Boomi の中央値を45,147ドルとしており、Workato の公開中央値は約64,500ドルです。同等の範囲なら、Tray は Workato の契約のおおむね半分から3分の2に収まります。

タスクの数え方は次のとおりです。ワークフローの1ステップが1タスクで、そのステップが内部で何回 API を呼んでも変わりません。ループ内のコネクター実行はすべて1タスクずつ数えるため、500件のレコードに対する3ステップのループは少なくとも1,500タスクになります。リトライは課金されません。AI トークンの使用量は顧客ごとに異なる比率でタスクに換算され、その比率は Customer Success に問い合わせる必要があります。割り当てを超えてもアカウントは停止されません。使用量アラートは80%と100%で通知され、超過分は後からオンデマンドのタスク単価で請求されます。

## 最適な対象

従業員200〜2,000人規模の企業で、実際に機能するエラーパスを備えた複数システム間のガバナンス付き自動化を必要とし、プラットフォームチームではなく1〜2人の技術担当者で運用し、Workato 規模の契約なしでエージェントと MCP のツールを使いたい RevOps、システム、ビジネステクノロジーのチームです。

## 代替候補と、それを選ぶべき場合

- **[Workato](/ja/tools/workato/)**:2026年に8回目の Gartner Leader。order-to-cash のような ERP レベルのプロセスを担当者が明確な統合チームが担い、環境間の正式なプロモーションが必要で、予算がすでに6桁ドル規模なら Workato を選んでください。
- **Boomi**:12回連続の Leader で、2026年のレポートでは実行能力の評価が最も高いベンダーです。データとアプリケーションの統合が中心で、エージェント層より最長の実績を重視するなら Boomi を選んでください。
- **[n8n](/ja/tools/n8n/)**:最も急成長している新興勢力で、2026年5月の評価額は52億ドル。セルフホストでき、エンジニアがいて、価格の下限を設けたくないなら n8n を選んでください。
- **[Zapier](/ja/tools/zapier/)**:ワークフローが非技術者の担当する直線的なアプリ間連携で、誰もログを読まないなら Zapier を選んでください。

## 注意点

- **ループがあるとタスクの見積もりが1桁ずれます。** 対策:契約前に、計画中のワークフローのうち処理量の多い上位5つについて、ループの反復をすべて含めた1回あたりのコネクター実行数を数え、想定される月間実行回数を掛け、その数字をもとにタスク量を交渉してください。LLM を呼び出すワークフローがあるなら、トークンとタスクの換算比率を Customer Success から書面で受け取ってください。
- **超過分は上限なしで、後からオンデマンド単価で請求されます。** 対策:オンデマンドのタスク単価を発注書に明記させ、80%の使用量アラートを、暴走したワークフローを当日中に停止できる担当者に届くよう設定してください。
- **更新時の値上げ。** Vendr の購入者は、標準で年7%の値上げがあると報告しています。対策:複数年契約と引き換えに固定料金を確保し、更新時の値上げ幅の上限を契約に明記してください。11か月目になってから交渉するのでは遅すぎます。
- **Headless は現時点で US リージョンのみです。** 対策:データ所在地の要件で EU など他のリージョンにワークスペースをホストしているなら、Headless は使えない前提で、ビジュアルビルダーだけで評価してください。
