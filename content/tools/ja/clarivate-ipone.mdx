## 概要

IPOne は、Clarivate がすでに販売している知財データの上に AI エージェントを載せるための総称です。対象となるデータは、Derwent の特許レコード、Darts-ip の訴訟データ、CompuMark の商標・意匠データです。Clarivate は 2026年5月29日に、3つの構成要素で発表しました。**IPOne Insights** は対話型検索です。**IPOne Workflow Agents** は、クリアランス、特許性、ポートフォリオ・競合分析、訴訟リスク、技術ランドスケープ向けの特許・商標エージェントです。**IPOne AI Ecosystem Access** は、同じデータを Claude、ChatGPT、Microsoft Copilot に流し込む MCP サーバー群です。

本当の資産はデータです。Clarivate の IPOne ページは、109の法域にわたる1億8,000万件の特許公報、188の商標データベースからの1億6,800万件超の商標、1,200万件超の検証済み知財案件を挙げています。Derwent の手書き抄録とファミリー単位のグルーピングがあるからこそ、訴訟弁護士はすでに Derwent の検索レコードを信頼しています。

ただし、発表は注意深く読んでください。Clarivate 自身の製品ページは、IPOne を完成したスイートではなく、特許・商標・訴訟をまたぐ単一の知財インテリジェンス・エコシステムの「ビジョン」として説明しています。今日実際に接続できるものは、プレスリリースが示唆するより狭い範囲です。

- **CompuMark Trademark MCP**：2026年6月7日から Anthropic の公式 Claude コネクタディレクトリに掲載されており、Clarivate はその後 ChatGPT 向けにも提供を発表しました。商標検索、ノックアウト検索、件数カウント、全文、指定商品・役務、登録庁コードなど9つのツールを公開しています。ドキュメントは `https://ipone.clarivate.com/trademarks/mcp/docs` にあり、サインインには既存の CompuMark アカウントが必要です。
- **Darts-ip Litigation MCP**：製品ページでは、判例を照会する接続先として Copilot、Claude、ChatGPT が挙げられています。商標サーバーのようにコネクタディレクトリの公開掲載で確認できるものは見つかりませんでした。
- **Derwent Patent Search**（旧 Derwent Innovation）：Derwent World Patents Index に対する AI 検索に加え、2025年11月24日にリリースされた Derwent Patent Monitor で、特許性、FTO、異議申立の共同レビューができます。Clarivate のメニューには Derwent Patent MCP が載っていますが、公開掲載は見つかりませんでした。

企業としての状況も購買判断に影響します。Clarivate は 2026年10月6日、Life Sciences & Healthcare セグメントを Altaris に6億ドルで売却する取引を完了し、現在は Academia & Government と IP の2セグメント体制です。IPOne は残った IP 事業の旗艦製品です。投資が集まるのは利点です。一方で収益への期待も背負っています。IP の経常オーガニック収益は、2026年 Q2 にようやく横ばいまで戻ったところです。

## 価格の実際

価格は一切公開されていません。IPOne、Derwent、CompuMark はいずれも見積もりのみで、MCP サーバーはセルフサービスの登録ではなく、既存の Clarivate 利用権に対して認証します。実務上、IPOne へのアクセスは、すでに保有しているか、これから交渉するデータ契約の延長です。

外部の手がかりは弱いものしかありません。競合する商標ツールの GleanMark は、CompuMark を SAEGIS のサブスクリプションで年間5,000〜50,000ドル以上、またはフル調査1件あたり約745ドルとしています。これは見積もりではなく、競合の営業トークとして扱ってください。レビューサイトは Derwent を特許調査市場の高価格帯に位置づけていますが、金額は示していません。比較材料として、購入者が報告する PatSnap Analytics のエントリー契約は、数 seats で年間およそ15,000〜30,000ドルです。Derwent の見積もりはそれより下ではなく、上になると考えてください。

発注書には次の3点を入れてください。契約日時点で一般提供されている IPOne の構成要素と早期アクセス段階のものの区別、MCP の呼び出しが seats に含まれるのか従量課金なのか、そして Claude や Copilot などサードパーティの LLM に返される結果のデータ利用条件です。

## 最適なチーム

すでに Derwent または CompuMark をライセンスしている企業の、社内知財弁護士と知財オペレーション責任者です。チームが Claude、ChatGPT、Copilot のいずれかに標準化しており、別の検索 seat ではなくそのアシスタントの中でクリアランスや訴訟リスクの照会をしたいケースです。最も明確な初期ユースケースは、ブランドチームがすでに信頼している CompuMark データを裏付けに、Claude や Copilot のチャットから商標のノックアウト・スクリーニングを行うことです。

**向いていないのは**、現在 Clarivate と契約がない場合です。IPOne のために契約を結ぶのは、一部がまだロードマップ上にあるエージェントにたどり着くために、データ層をエンタープライズ定価で買うことを意味します。出願書類の起案やクレームチャートの作成が目的の場合も向いていません。IPOne は検索と分析を行います。弁護士の成果物を作るものではありません。

## 代替候補と選び分け

- **[PatSnap](/ja/tools/patsnap/)**：特許データ市場でシェア上位のもう一方の既存大手で、エージェントでは先行しています。Eureka はドメイン特化エージェントを提供し、ベンダーは30以上の MCP サーバーと、無料スターター枠付きのクレジット課金制 Open Platform をうたっています。先にエンタープライズ契約を結ばずに、今四半期中にエージェントワークフローを試作したいときに選んでください。
- **Questel**：欧州発の既存大手で、Orbit 検索と AI アシスタント Qthena を備えています。EPO や WIPO での手続きが業務の中心である場合や、Clarivate の見積もりの横に対抗見積もりを並べたい場合に選んでください。
- **[Patlytics](/ja/tools/patlytics/)**：分析領域で最も急成長している AI ネイティブの新興勢力で、2026年4月に4,000万ドルのシリーズ B を調達し、`https://mcp.patlytics.ai/mcp` で公開 MCP サーバーを提供しています。成果物が調査レポートではなく、実施証拠や無効論のクレームチャートである場合に選んでください。
- **[Solve Intelligence](/ja/tools/solve-intelligence/)** または **[DeepIP](/ja/tools/deepip/)**：業務が検索ではなく起案や権利化手続きである場合に選んでください。これらはデータライセンスの下流に位置し、ライセンスの代わりにはなりません。
- **[Anaqua](/ja/tools/anaqua/)**：課題がインテリジェンスではなく、期限管理、年金管理、ポートフォリオ記録である場合に選んでください。その領域に対する Clarivate 自身の答えは IPfolio で、IPOne とは別製品です。

## 注意点

- **発表が製品より先行しています。** Clarivate は IPOne をビジョンとして打ち出しており、ディレクトリへの公開掲載が確認できるのは商標 MCP だけで、顧客の導入数も公表されていません。**対策：** 署名前に、契約日時点で一般提供されている IPOne 構成要素の一覧を書面で求めてください。それ以外は辞退できる無償オプションとし、価格の根拠には決してしないでください。
- **MCP 接続は既存の利用権に従います。** 認証は `ipone.clarivate.com` 経由で CompuMark または Derwent のアカウントに対して行われるため、エージェントが到達できるのはすでにライセンスしているデータだけです。その契約を失えば、上に構築したワークフローも止まります。**対策：** CompuMark Trademark MCP を1つのブランドチームで30日間パイロット運用して呼び出し量を記録し、更新時に MCP アクセスとレート制限を独立した明細項目として交渉してください。
- **結果は Clarivate の環境の外に出ます。** MCP の回答はサードパーティのアシスタントのコンテキストやログに入り、クリアランスの照会から未発表の製品名が漏れる可能性があります。**対策：** 保持期間の管理機能があるエンタープライズテナント経由でのみ接続し、展開前にどの案件をどのアシスタントで照会してよいかを法務に承認してもらってください。
- **企業再編が更新交渉の前提を変えます。** Clarivate は Altaris への売却後に負債削減を進めており、IP 収益はようやく横ばいに戻ったばかりです。**対策：** 署名時に更新時の値上げ幅に上限を設け、IPOne の価格改定はロードマップではなく、すでに一般提供されている機能に結びつけてください。
