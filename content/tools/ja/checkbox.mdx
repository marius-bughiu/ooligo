## 概要

Checkbox は、企業法務部門が自部門の窓口として運用するノーコードプラットフォームです。依頼は Slack、Microsoft Teams、メール、Web フォーム、Salesforce から届き、AI レイヤーが種類・緊急度・リスクで分類し、ルーティングルールが案件種別、弁護士の専門領域、稼働状況、事業部門に応じて割り当てます。その後に続くもの — 関連文書・タスク・承認が紐づいた案件レコード、生成された NDA や書面、そして法務責任者が取締役会に持ち込むダッシュボード — はエンジニアリングではなく、リーガルオペレーションがドラッグ&ドロップのビルダーで組み立てます。2016年にシドニーで Evan Wong (CEO) と James Han が創業し、現在の本社はニューヨークです。2026年1月28日には Touring Capital がリードし、Peak XV、Conductive Ventures、Tidal Ventures、Five V Capital、そして Evisort 創業者の Jerry Ting が参加した2,300万ドルのシリーズ A を調達しました。SAP、PepsiCo、Hitachi、Telstra、Woolworths、Coca-Cola Europacific Partners、Macquarie Group、Xero を含む100社超の企業が導入しています。

## Legal Ops スタックで採用される理由

- **これは設定用のツールキットであり、作り込み済みの法務アプリではありません。** ビルダーは、独自の案件ステータス・フィールド・ビューの上で直列、並列、トリガー起動のフローを扱い、既成テンプレートの上にリスト、棒、折れ線、円、メトリクスの5種類のウィジェットでレポートします。同じテナントに法務と並んでコンプライアンス、人事、財務、調達のインテークが載ることが多いのはそのためです。エンジンはその依頼がどの部門から来たかについて一切の前提を持ちません。そして本番稼働がサインアップではなくプロジェクトになる理由も同じです。
- **AI は2016年製のワークフローエンジンの上に載っており、どのレイヤーを買うかが効いてきます。** 生成 AI によるトリアージ、法務チャットボット、文書生成は、それらより10年近く前から存在する自動化プラットフォームに後から加えられたものです。実務上、AI は届いた依頼の分類とルーティングには強く、その中身に対する判断の代替にはなりません。[Ivo](/ja/tools/ivo/) や [Ironclad](/ja/tools/ironclad/) との連携が存在するのは、まさにそのためです。
- **公開されている成果は、起案ではなく振り分けの数字です。** Hitachi のリーガルオペレーション責任者は、40か国にまたがる体制で定型的な法務・コンプライアンス依頼の83%が部分的または完全に自動化されたと報告しています。Woolworths については案件量が最大80%削減されたとされています。いずれもベンダーが公開した数値で、独立した監査は受けていませんが、Checkbox が実際に最適化している指標 — どれだけが弁護士に届かずに済むか — を名指ししています。背景となるモデルは [legal intake](/ja/learn/legal-intake/) と [matter management](/ja/learn/matter-management/) を参照してください。

## 価格の実態

Checkbox は価格を公開していません。サイトに価格ページは存在せず、当該 URL は認可エラーを返し、サイトマップにもエントリがありません。すべての導線は日程調整されたデモに行き着きます。第三者のソフトウェアディレクトリは年間5,000豪ドル（約3,300米ドル）前後をエントリー価格として掲載していますが、この数字はベンダーの確認が取れておらず、単一チーム導入の下限を示すもので、法務・コンプライアンス・調達にまたがる SAP 規模の展開の費用ではありません。エンタープライズ価格帯より下でも販売されている証拠として読むべきであり、予算枠として読むべきではありません。

実際に買っているのはスコープを切った導入 — 最初のワークフロー、1つのチャネル、レポート一式 — です。シリーズ A 以降、Checkbox はチームの最初の法務インテークエージェントを無償で構築する提供を続けています。契約が存在する前に設定工数を値付けできる、現状もっとも安い手段です。使い、そして所要時間を計測してください。

## 適しているのは

従業員およそ1,000人を超える企業のリーガルオペレーション責任者と法務責任者で、法務が依頼に溺れている複数のサービス部門の1つであり、プロセス設計を実際の職務として担う人がチームにいる場合です。判断のきっかけは、依頼が5つのチャネルに散らばり、事業部門別の需要を誰も報告できず、同じ NDA の質問に四半期で40回答えている状態です。調達、コンプライアンス、人事が同じ窓口を求めている場合にも適切な選択になります。設定済みの1つのエンジンで4部門を回せる点こそ、Checkbox が法務専用ツールに総コストで勝つ場面です。

## 代替製品との比較

[Onit](/ja/tools/onit/) はエンタープライズ法務管理の既存勢力です。実際の購買対象が案件管理と外部弁護士費用の統制であり、インテークはそこに流し込むフォームにすぎない場合はこちらを選んでください。[Ironclad](/ja/tools/ironclad/) は、契約が記録の主体であり、依頼受付が製品そのものではなく CLM の一段階である場合の選択肢です。[Wordsmith](/ja/tools/wordsmith/) はこのセグメントで最も成長が速い新規参入で、自チームで組み立てるキャンバスではなく、作り込み済みの法務挙動と MCP から呼び出せるレビューが欲しい場合はこちらが鋭い選択です。Streamline AI は法務インテーク専用に作られた競合で、Checkbox は同社に対する比較ページを運用しています。そのページの率直な読み方は、Checkbox は稼働までの速さと引き換えに守備範囲を取っている、というものです。[GC AI](/ja/tools/gc-ai/) は、弁護士側がより良いアシスタントを求めていて、事業部門側のインテーク問題が存在しない場合に合います。どれも合わないなら、Checkbox が Jira に対する反論ページも運用している点に注目してください。すでに支払っている Jira か ServiceNow のインスタンス上のサービスデスクプロジェクトとトリアージ当番があれば、2週間程度の事務作業で計測の問題は解決します。今日の時点で上位3つの依頼種別を挙げられないなら、それが正しい答えです。

## 注意点

- **設定負荷がこの製品の最大のリスクです。** どの部門でも回せるキャンバスは、誰かが設計しなければならないキャンバスであり、設定が足りない Checkbox はダッシュボード付きのフォームビルダーにすぎません。ガード: 評価期間中にベンダーへ最も量の多い依頼種別2つを構築させ、時間を計測してください。最初のワークフローに自チームのカレンダーで3週間以上かかるなら、契約前に社内 FTE をビジネスケースに織り込んでください。
- **価格が非公開ということは、下限も非公開ということです。** 法務向けに得た見積もりは、調達と人事を足した後の見積もりとは別物であり、部門横断への拡大こそがベンダーの成長経路です。ガード: 1年目の契約に署名する前に、部門数2倍・依頼量3倍での1年目と3年目の価格を同一文書で提示させてください。
- **入手できる効率化の数値はすべてベンダー公表です。** 83%も80%も、Checkbox が Checkbox の顧客について出した数字です。ガード: 本番稼働前にベースラインを計測し — 種別・チャネル別の四半期依頼件数、初回応答までの時間 — 自ら計測した振り分け率を更新の条件にしてください。
- **認証は強いが、AI のデータ条件は非公開です。** Checkbox は SOC 2 Type II、ISO/IEC 27001:2022、ISO 27017、ISO 27018 を保持し、監査報告書は trust.checkbox.ai 経由で請求できます。公開サイトに記載がないのは、ホスティングリージョン、データレジデンシーの選択肢、そして顧客コンテンツがモデル学習に使われるかどうかです。ガード: 秘匿特権のある資料が窓口を通る前に、サブプロセッサ一覧、モデル提供元、学習に使わない旨のコミットメントを DPA に書面で入れてください。[GDPR](/ja/learn/gdpr-for-legal-teams/) 下の EU 法人にとっては交渉の余地がありません。
- **MCP サーバーがなく、公開 API リファレンスもありません。** Webhook と API は存在し、サイトの連携一覧は網羅的ではないとベンダーは述べていますが、開発者向けドキュメントサイトも MCP から呼び出せるものも存在しないため、現時点の Checkbox を自チームが構築するエージェントの一工程に組み込むことはできません。ガード: そこが重要なら、評価期間中に API リファレンスを請求し、案件作成とステータス変更のイベントについて Webhook の対応範囲を前提にせず確認してください。
