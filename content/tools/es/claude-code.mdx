## Qué es

Claude Code es la herramienta de programación agéntica de Anthropic: le das una tarea en lenguaje natural y lee el repositorio, edita archivos a lo largo de él, ejecuta comandos de shell y tests, y hace commit o abre un pull request. Corre sobre un mismo motor en varias superficies — una CLI de terminal, una extensión de VS Code (que también se instala en Cursor), un plugin de JetBrains, la pestaña Code de la app de escritorio de Claude, el navegador en claude.ai/code y las apps móviles de Claude —, así que el `CLAUDE.md`, la configuración y los servidores MCP de un proyecto te siguen de una a otra. Llegó al público general en mayo de 2025 y, según el anuncio de financiamiento de Anthropic de febrero de 2026, su ingreso anualizado (run-rate) ya superaba los $2.5 mil millones.

Esta es una página de subproducto. [Claude](/es/tools/claude/) cubre el asistente y la API; [Claude Cowork](/es/tools/claude-cowork/) cubre la superficie de agentes para quienes no escriben código. Claude Code es para quien, dentro del equipo de ops, es dueño del código.

## Por qué aparece en los stacks de ops

Los GTM engineers y los desarrolladores de RevOps hoy entregan cada vez más código de integración: scripts de sincronización del CRM, jobs de enriquecimiento, servidores MCP propios, nodos de código de [n8n](/es/tools/n8n/), modelos del data warehouse. La mayor parte de eso hoy se construye en Claude Code, por cuatro razones:

- **MCP en ambos sentidos.** Se conecta a servidores MCP de [HubSpot](/es/tools/hubspot/), [Salesforce](/es/tools/salesforce/), [Linear](/es/tools/linear/), [Notion](/es/tools/notion/) y [Slack](/es/tools/slack/), y es el lugar más rápido para escribir y probar tu propio servidor. Mira [qué es un servidor MCP](/es/learn/mcp-server-explained/) y [cuándo una skill le gana a un servidor](/es/learn/claude-skill-vs-mcp-server/).
- **Ejecuciones headless.** `claude -p` ejecuta un prompt sin interacción, así que encaja en CI, cron jobs y pipelines de GitHub Actions o GitLab CI/CD. El Agent SDK expone las mismas herramientas para construir tus propios agentes.
- **Routines.** Jobs programados en la nube, creados con `/schedule`, que siguen corriendo con tu laptop apagada y pueden dispararse con una llamada a la API o un evento de GitHub — el chequeo nocturno de calidad de datos o la auditoría de dependencias del lunes que nadie tiene que recordar.
- **Instrucciones de repo compartidas.** Desde la versión 2.1.277 (18 de septiembre de 2026), Claude Code lee `AGENTS.md` cuando una carpeta no tiene `CLAUDE.md`, así que un repositorio ya configurado para Codex u otros agentes funciona sin duplicar instrucciones. Si existen ambos archivos, gana `CLAUDE.md`.

## La realidad del precio

Claude Code no tiene precio propio; está incluido en todos los planes pagos de Claude, y no en Free:

- **Pro** — $20/mes, o $17/mes con facturación anual
- **Max** — $100/mes o $200/mes, con 5× o 20× el uso de Pro
- **Team** — asiento estándar $25/mes ($20 anual); asiento premium $125/mes ($100 anual), de 2 a 150 asientos
- **Enterprise** — $20 por asiento más uso facturado a tarifas de API

También puedes saltarte los asientos y usarlo con una API key de Anthropic Console, Amazon Bedrock, Google Cloud's Agent Platform o Microsoft Foundry, pagando por token.

La lista de planes no es el número real. El uso se comparte entre el chat de claude.ai, la app de escritorio, Cowork y Claude Code, y tiene dos topes: una ventana móvil de cinco horas y un límite semanal, que Anthropic ajustó varias veces durante 2026. Programar todo el día, todos los días, supera un asiento Pro; para eso existen Max y los asientos premium. Presupuesta un asiento Team estándar para el analista que escribe un script por semana, un asiento premium (o Max para individuos) para quien lo usa como herramienta principal, y $100–$200 por usuario intensivo al mes como número de planificación. El Code Review automático en GitHub, disponible en Team y Enterprise como research preview, se factura aparte vía créditos de uso, con un promedio de $15–25 por revisión.

## Ideal para

GTM engineers, RevOps engineers y tecnólogos de legal ops o recruiting ops que son dueños de un repositorio — quien mantiene la sincronización CRM-warehouse, escribe el servidor MCP propio para el deal desk o construye el pipeline de exportación del ATS. El caso acotado donde gana sin discusión: cambios en varios archivos de un codebase existente que tiene que seguir pasando sus tests, seguidos de una ejecución programada o disparada por CI del mismo job. Eso responde la pregunta del asiento Team premium: sí para la una o dos personas cuyo trabajo es construir ese código, no para el resto.

## No sirve para

Personas que no leen diffs. Claude Code propone y ejecuta comandos de shell y hace commit de código; si nadie del lado receptor puede juzgar si un cambio es correcto, dale a esa persona [Claude Cowork](/es/tools/claude-cowork/) o un builder no-code. Tampoco reemplaza a una herramienta de flujos en pipelines de alto volumen y forma fija: una vez que el job es «mover estos campos cada hora», el código que escribió Claude Code debe correr en n8n o en tu orquestador, no dentro de una sesión de agente.

## Frente a las alternativas

- **[GitHub Copilot](/es/tools/github-copilot/)** — la mayor base instalada por número de asientos. Business cuesta $19 y Enterprise $39 por usuario al mes, y desde el 1 de junio de 2026 el uso por encima de los AI credits incluidos se mide y cobra aparte. Elígelo cuando la organización ya compra GitHub Enterprise y la necesidad principal es autocompletado dentro del editor para muchos desarrolladores, no tareas de varios pasos delegadas.
- **[Cursor](/es/tools/cursor/)** — el principal rival específico de programación por ingresos; Bloomberg reportó que superó los $2 mil millones de ingreso anualizado en marzo de 2026. Los planes individuales empiezan en $20/mes y Teams en $40 por usuario. Elígelo cuando la persona vive en un IDE y quiere ver y dirigir cada edición de forma visual; el análisis completo está en [Claude vs Cursor](/es/comparisons/claude-vs-cursor/).
- **OpenAI Codex** — el competidor que más rápido crece: de más de 2 millones de usuarios semanales en marzo de 2026 a más de 5 millones en junio. Está incluido en ChatGPT Go ($8), Plus ($20) y Business ($20 por usuario anual, $25 mensual). Elígelo cuando la empresa ya estandarizó en ChatGPT Business, porque el asiento de programación llega sin proveedor nuevo. OpenAI dejó de vender nuevos asientos Codex-only de pago por uso en los planes Business en junio de 2026, así que el uso facturado por token ahora pasa por una API key.

## Puntos de cuidado

- **Auto mode es ahora el modo de permisos inicial.** Desde la versión 2.1.283, las sesiones interactivas de terminal y VS Code arrancan en auto mode, donde un segundo modelo revisa cada acción en lugar de una persona. La propia documentación de Anthropic dice que «no garantiza la seguridad». Protección: en Team y Enterprise, define `permissions.defaultMode` o pon `permissions.disableAutoMode` en `"disable"` en la configuración administrada para los grupos que tocan sistemas de producción, agrega reglas `ask` para cualquier herramienta MCP que escriba en el CRM, y corre las sesiones desatendidas en un contenedor o sandbox.
- **Un solo pool de uso, muchos consumidores.** Una routine, la sesión de chat de un compañero y tu sesión de programación consumen el mismo límite del asiento, y ese límite se reinicia en una ventana de cinco horas que no controlas. Protección: dale a las routines programadas y a los jobs de CI su propia API key con un tope de gasto, para que un job descontrolado no bloquee a quien necesita el asiento a las 10 de la mañana.
- **El costo de Code Review escala con los pushes.** Configurar un repositorio para revisar «después de cada push» multiplica el promedio de $15–25 por la cantidad de pushes por pull request. Protección: empieza los repositorios en «Once after PR creation» o Manual, y define un tope de gasto mensual para el servicio Claude Code Review en claude.ai/admin-settings/usage antes de activarlo.
