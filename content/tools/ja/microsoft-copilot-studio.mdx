## 概要

Microsoft Copilot Studio は、Power Platform 上でエージェントとエージェントのワークフローを作るローコードビルダーです。エージェントを記述し、ナレッジ（SharePoint、Dataverse、Web サイト、テナントの Microsoft Graph）とツール（1,400 を超える Power Platform コネクタ、MCP サーバー、agent flows、他のエージェント）を与え、Teams、Microsoft 365 Copilot、Web サイト、電話回線に公開します。Power Virtual Agents の後継であり、[Microsoft Agent 365](/ja/tools/microsoft-agent-365/) が統制する対象でもあります。Agent 365 はレジストリとコントロールプレーン、Copilot Studio はエージェントを作る場所です。

2026年に製品の中身が変わりました。computer use エージェント（API がないときに、ブラウザや Windows のデスクトップアプリを UI 経由で操作するエージェント）は 2026年5月13日に一般提供になりました。A2A プロトコルによるエージェント間の委任は 4 月に GA になりました。2 つ目のランタイムである **GitHub Copilot harness** は 6 月に本番利用可能なプレビューとして登場し、8 月に GA になりました。skills、ユーザーごとのメモリ、作業しながら計画を立て直すプランニングループを備えています。従来の **standard harness** も並行して動きます。主モデルとして Claude Sonnet 5 と GPT-5.5 Chat を選べます。そして 2026年7月以降、新しいエージェントにはすべて Microsoft Entra Agent ID が自動で付与され、環境単位でのオプトアウトはできません。

## オペレーションチームがここにたどり着く理由

オペレーション責任者がこのページに来るときの問いは、たいてい「うちは M365 の会社だ。オペレーション用のエージェントは Copilot Studio で作るべきか、それとも n8n、Relevance AI、Lindy を買うべきか」です。Microsoft テナントの中では、3 つの理由で Copilot Studio が標準の答えになります。エージェントは従業員がすでに働いている場所（Teams、Outlook、Copilot アプリ）に新しいログインなしで現れます。ID、DLP、Conditional Access が Entra Agent ID を通じてエージェント単位で適用されます。これがなければ、セキュリティレビューで手作業での再構築を求められます。そして Microsoft 365 Copilot のライセンスをすでに持つ従業員については、standard harness のエージェントとの会話利用はゼロ課金です。

元が取れる具体的なオペレーションのケースは次のとおりです。Dynamics または Salesforce とアカウントの SharePoint フォルダを読んで「Contoso の更新はどうなっている？」に答える Teams 上の RevOps エージェント。共有メールボックスに届く依頼を分類し、人による承認の一時停止を挟んでルーティングする Legal Ops のインテークエージェント。API のない古い人事ポータルに computer use でオファー内容を入力する Recruiting のコーディネーターエージェント。

## 価格の実態

すべては **Copilot Credits** で計測され、テナント全体でプールされます。

- **Capacity pack：月額 200 USD で 25,000 クレジット**（1 クレジットあたり 0.008 USD）、前払い。未使用分は繰り越されません。
- **従量課金：1 クレジットあたり 0.01 USD**、Azure サブスクリプションに後払いで請求。
- **事前購入プラン：** クレジットを前もって確約すると最大 20% 割引。
- **Microsoft 365 Copilot（1 ユーザーあたり月額 30 USD。Copilot Business は 21 USD、2026年12月31日まではプロモーション価格 18 USD、300 席まで）** には standard harness が含まれ、ライセンスを持つユーザー本人がエージェントと会話する場合、従業員向けの利用はゼロ課金になります。

予算に直結するのは料金表です。クラシック回答（手作業で作成）：1 クレジット。生成回答：2。エージェントアクション（トリガー、ツール呼び出し、推論ステップ）：5。テナント Graph のグラウンディング：10。agent flow のアクション：100 回あたり 13 クレジット。推論モデルは、機能の料金に加えて 1,000 トークンごとに 10 クレジットかかります。つまりグラウンディング付きの回答 1 件は 12 クレジット、従量課金で約 10 セントです。

2 つの試算です。

- **社内 Q&A エージェント、Copilot ライセンスのない従業員 200 人、各自が月 20 件のグラウンディング付き質問：** 200 × 20 × 12 = 48,000 クレジット。pack 2 つで **月額 400 USD、年間約 4,800 USD** です。同じエージェントを Copilot ライセンスを持つ 200 人が使えばクレジットの追加費用はかかりませんが、ライセンス自体が年間 72,000 USD です。
- **自律型のパイプライン衛生エージェント、月 3,000 回の実行、各回 6 アクションと生成回答 1 件：** 32 クレジット × 3,000 = 96,000 クレジット。**pack 4 つで月額 800 USD、従量課金なら 960 USD** です。自律トリガーや、ライセンスを持つユーザーの会話以外で起動した agent flows は、社員が Copilot ライセンスを持っているかどうかに関係なく標準料金で課金されます。

computer use はエージェントアクションの料金で課金され、Microsoft 365 Copilot ライセンスでカバーされることはありません。実行先のホストマシン（Windows 365 for Agents）も別請求です。GitHub Copilot harness はさらに別の課金体系です。トークン、ツール、harness そのものに課金し、しかも **メーカーが作り始めた瞬間から** 課金されます（プレビュー、テスト、評価の実行を含む）。standard harness は公開後にしか課金されません。

## 最適な用途

**従業員 200〜5,000 人の Microsoft 365 E3/E5 組織** の IT または RevOps の責任者で、SharePoint と CRM を読み、コネクタ経由でアクションを実行し、別の ID レイヤーなしでセキュリティレビューを通る、従業員向けの Teams エージェントが必要な人です。文句なしに勝つケースは、利用者がすでに Microsoft 365 Copilot のライセンスを持っている社内エージェントです。会話ごとのコストがゼロになり、ガバナンスもテナントに付いてくるからです。

## 向いていないケース

Google Workspace を使う 10〜50 人のオペレーションチームや、エージェントの書き込み先が Microsoft のシステムではなく主に HubSpot、Salesforce、Slack であるチームです。[n8n](/ja/tools/n8n/) なら月 20 ユーロから、[Lindy](/ja/tools/lindy/) なら月 50 USD から得られるものを手に入れるために、Power Platform の環境、キャパシティの割り当て、Entra の管理を抱え込むことになります。解決 1 件あたりの固定コストが必要な、大量の顧客向け自動化にも不向きです。ステップごとに課金するクレジット制は、エージェントが長いループで推論すると高くつきます。

## 代替ツールとの比較

- **[Salesforce Agentforce](/ja/tools/salesforce-agentforce/)**：エンタープライズ向けエージェントビルダーのもう 1 つのシェアリーダーです。エージェントが操作するレコードが Salesforce にあるなら、こちらを選んでください。CRM レコードの隣にいるエージェントは、コネクタ経由でレコードに手を伸ばすエージェントに勝ちます。Salesforce 中心のレベニューチームは、Power Platform のコネクタよりネイティブのトラストレイヤーのほうが先まで進めます。
- **[Google Gemini Enterprise](/ja/tools/gemini/)**：Google Workspace の会社にとっての直接の対抗馬で、1 席あたり月額 21 USD から、ノーコードのエージェントが組み込まれています。メール、ドキュメント、ID が Google にあるならこちらです。Microsoft テナントの外では、Copilot Studio の利点はほぼ消えます。
- **[n8n](/ja/tools/n8n/)**：このセグメントで最も急成長している新興勢力です。ワークフローが決定的である場合、システムの大半が Microsoft 以外である場合、セルフホストが必要な場合はこちらを選んでください。課金は推論ステップ単位ではなく実行単位なので、大量のフローでははるかに予測しやすくなります。n8n のエージェントも Entra Agent ID 付きで Agent 365 に登録されるので、n8n を選んでもテナントのガバナンスは失われません。
- **[Relevance AI](/ja/tools/relevance-ai/) / [Lindy](/ja/tools/lindy/)**：Power Platform の管理者を介さずに、SDR やリサーチのエージェントを今月中に動かしたい GTM チームにはこちらです。
- **[UiPath](/ja/tools/uipath/)**：UI 自動化が主な業務（1 日数百回の実行、SAP やメインフレームの画面、attended ロボット）で、たまにクリックするエージェントではなく成熟した例外処理とオーケストレーションが必要なら、Copilot Studio の computer use よりこちらを選んでください。

## 注意点

- **125% の上限でエージェントが止まります。** 前払いキャパシティのテナントがクレジットの 125% に達すると、カスタムエージェントは無効化され（ユーザーには「This agent is currently unavailable」と表示されます）、キャパシティを使い切った時点で新しい agent flow の実行もブロックされます。**対策：** すべての本番環境に Azure の従量課金プランをひも付け、超過分がブロックではなく請求されるようにしてください。さらに Power Platform admin center → Licensing → Copilot Studio → Manage Agents で、エージェントごとの月間クレジット上限を設定してください。
- **「Copilot に含まれる」の範囲は見た目より狭いです。** ゼロ課金の対象は、Copilot ライセンスを持つ従業員が認証済みユーザーとして会話する場合です。自律トリガー、他のトリガーによる agent flows、computer use、ライセンスを持たない人はすべて標準料金です。**対策：** 展開前に Copilot Studio の agent usage estimator をエージェントごとに実行し、ライセンス付きの会話トラフィックと、自律型およびライセンスなしのトラフィックを分けてください。後者は 1 クレジット 0.01 USD で予算化します。
- **GitHub Copilot harness は構築中にも課金されます。** プレビューで試行錯誤するメーカーは、何も公開しないうちから実際のクレジットを消費します。**対策：** メーカー用の環境には本番とは別の小さなクレジット割り当てを与え、実験が本番エージェントの頼るキャパシティを食いつぶさないようにしてください。
- **1 つのテナントに 2 種類のエージェント ID があります。** 2026年7月より前に作られたエージェントは従来のアプリ登録のまま動いており、Microsoft が予定する移行を待っています。新しいエージェントには Entra Agent ID が付きます。一方向けに書いた Conditional Access は、もう一方をカバーしません。**対策：** エージェントのインベントリ（admin center、API、Azure Resource Graph）をエクスポートして各エージェントに ID の種類でタグを付け、古いエージェントの移行または作り直しが終わるまでは両方にポリシーを書いてください。
- **プレミアムコネクタと cloud flows は別ライセンスです。** Power Automate の cloud flows は Copilot Credits ではなく Power Automate のライセンスを使います。クレジットで動くのは agent flows だけです。**対策：** エージェントから呼び出す自動化は Copilot Studio 内の agent flows として作り、単独の cloud flow は約束する前に Power Automate Premium の価格で見積もってください。
