## 概要

SeekOut は、エージェント型 AI を軸に作り直した人材検索・ソーシングのプラットフォームです。中核は依然として、膨大な公開候補者プロフィールのプールを対象とする検索エンジンで、SeekOut は 1B 件超のプロフィールを掲げています（独立系レビューはインデックス済みの実数を 780M 件前後と見ています）。これに GitHub の活動、96M 件超の学術論文、特許、clearance および就労資格のデータが付加されます。このデータ層の上で、現在は 6 つの名前付きエージェント（Rubric Creator、Candidate Finder、Profile Analyst、Outreach Author、Market Researcher、Engagement Tracker）が動き、採用ルーブリックの作成、検索、フィットのスコアリング、アウトリーチの作成を行います。カテゴリ上の最も近い隣人は、ソーシングの深さでは [hireEZ](/tools/hireez)、talent intelligence の位置づけでは [Eightfold](/tools/eightfold) です。

## Recruiting/TA スタックで使われる理由

- **技術職・難充足ポジションでの深さ。** GitHub Coder Score、特許・論文のカバレッジ、スキルによるエンリッチメントが、ATS や LinkedIn Recruiter のタイトル・キーワード検索では取りこぼすエンジニア、研究者、security/clearance 系の候補者を浮かび上がらせます。これが SeekOut が価格に見合う限定的なユースケースです。LinkedIn だけでは sourcer が埋められない、シニア技術職や専門職の req を米国で継続的に充足するチームが対象です。
- **バイアス低減機能付きのダイバーシティ・ソーシング。** 過小評価層の人材に特化したフィルターに加え、レビュー中に人種や性別を示唆するフィールドを隠す「bias reducer」を備えます。役員レベルで DEI のミッションを持つ組織にとって、これは歴史的に SeekOut の軸となる差別化要素でした。
- **ソフトウェアだけでないエージェント型 Spot サービス。** SeekOut Spot はエージェントと人間のリクルーターを組み合わせ、面接可能な slate（ドシエ、スコアカード、スクリーニング録画つき）を約 14 日で提供します。SeekOut はこれを、コンティンジェンシー型エージェンシーより ~70% 安いと位置づけています。運用する seat をもう 1 つ増やすのではなく、成果が欲しいチームへの橋渡しです。
- **SeekOut MCP。** SeekOut は MCP サーバーを公開しており、Claude などのアシスタントが候補者データを直接クエリできます。ソーシングツールの中では珍しく、ここで `mcp_available` が true である理由です。

## 料金

seat あたりの公開定価はなく、すべて営業経由です。第三者の価格トラッカーは、実際のディールを seat あたり $10–30K/年 という広いレンジに置き、年間契約の中央値は約 $20K、team/enterprise プランでは 3 seat が下限です。複数年契約や前払いのコミットでは、seat あたりの数字は ~$4.5–7K まで下がります。導入には別途 ~$2–10K を見込み、年 5–7% の値上げ条項は契約時に上限を設定するよう求めてください。これらの数字は、リセラーや購入者レポートから三角測量した推定値であり、ベンダーが公表した数値ではない点に注意してください。Spot（マネージドサービス）はプラットフォームの seat とは別に、エンゲージメント単位で課金されます。

## 最適な対象

専任のソーシング機能がすでに存在し、ボトルネックがパイプライン管理ではなく候補者の発見にある、enterprise および scale-up の TA チーム（Series C から Fortune 500 を想定）で、**米国/カナダの技術職・エンジニアリング・security clearance・ダイバーシティ目標**の req を継続的に充足する場合です。seat あたりの採算とデータの深さの両方が見合うのが、このセグメントです。

**次の場合は SeekOut を買わないでください。** 採用の大半が非技術職、大量採用、または北米外のグローバルである場合（EMEA と APAC ではデータが急速に薄くなります）、あるいは req を端から端まで回す単一のツールが欲しい場合です。SeekOut はソーシングとスクリーニングを行いますが、ATS ではなく、ATS を持っていることを前提としています。

## 代替候補との比較

- **[hireEZ](/tools/hireez)** — パイプラインがグローバル、特に APAC やアジア言語のソーシングである場合は、SeekOut より hireEZ を選んでください。hireEZ のデータの方が深く、seat あたりのコストも通常は低めです。SeekOut は米国の技術職の深さ、clearance データ、エージェント型 Spot サービスで取り返します。
- **[Gem](/tools/gem)** — 制約が純粋な発見ではなくアウトリーチと CRM のモーション（sequences、ソース別分析、ATS と同期したパイプライン）にある場合は Gem を選んでください。多くのチームは Gem を行動のシステムとして回し、req が本当に難しいときだけ SeekOut に手を伸ばします。
- **[Eightfold](/tools/eightfold)** — ミッションが外部ソーシングではなく、Workday/SAP の上での enterprise talent intelligence と社内モビリティである場合に選んでください。Eightfold はプラットフォーム勝負、SeekOut はより鋭いソーシングツールです。
- **[Juicebox](/tools/juicebox)** — 急成長中の軽量な新規参入。enterprise 契約なしで自然言語の候補者検索だけが欲しい小規模チームには、Juicebox の PeopleGPT が価格と time-to-value で SeekOut を下回ります。引き換えに、clearance データ、エージェント、マネージドサービスは諦めることになります。

どれも合わず、四半期に数件の req しか充足しないなら、正直な答えは LinkedIn Recruiter に難しいポジション向けのコンティンジェンシー型エージェンシーを足すことです。req の量が少なければ、SeekOut の seat あたりの下限は元が取れません。

## 注意点

- **国際カバレッジが急落します。** レビューは一貫して、SeekOut が米国/カナダ志向であることを指摘しています。ガード： 契約前に、実際の難しい req について実際の地域でライブのテスト検索を行い、ヒット率を hireEZ と比較してください。グローバルなプロフィール件数ではなく、自分が実行した検索を信じてください。
- **プロフィールデータがソースに遅れることがあります。** 候補者の GitHub/LinkedIn にある内容と SeekOut が表示する内容との不一致がユーザーから報告されています。ガード： SeekOut は発見の層として扱い、キャッシュされたレコードを信じるのではなく、アウトリーチの時点で連絡先と現職を検証してください。
- **価格は上がり、値上げ条項が積み上がります。** モジュール、seat、年 5–7% の値上げが加算されます。ガード： 契約時に値上げ条項に上限を設け、seat 数を実際の sourcer に合わせ（リクルーターごとではなく seat ごとです）、Spot 対プラットフォームの配分を毎年見直してください。難しい req が数件だけなら、遊休 seat に払うよりマネージドサービスの方が得な場合があります。
- **これはソーシングであって ATS ではありません。** ガード： 記録のシステム（[Greenhouse](/tools/greenhouse)、[Lever](/tools/lever)、Workday）を信頼できる情報源として維持し、パイプラインのレポートを SeekOut に依存する前に、双方向同期がステージ更新をカバーしていることを確認してください。
