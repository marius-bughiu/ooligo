## Qué es

Perplexity es un motor de búsqueda con IA que devuelve respuestas sintetizadas con citas inline, además de un feature Spaces para proyectos de research sostenidos, un browser Comet y un tier Enterprise para equipos. Es la herramienta default para gente de ops que quiere respuestas grounded — no output puro de modelo — al investigar empresas, regulaciones o candidatos.

## Por qué aparece en stacks de ops

- **Grounded por default.** Cada respuesta cita las fuentes, lo cual importa para research de ICP, intel de competidores y cualquier output que vaya al CRO o GC.
- **Spaces para research de proyecto.** Pinea fuentes, corre queries repetidas, comparte con el equipo — mejor que ChatGPT para workstreams de research continuos.
- **Web en tiempo real.** ChatGPT y Claude tienen búsqueda web, pero la UX de Perplexity está construida desde cero para eso.

## Pricing

- **Free** — búsqueda básica, features Pro limitados
- **Pro** — $20/mes, modelos avanzados, búsquedas Pro ilimitadas
- **Enterprise Pro** — $40/usuario/mes, SSO, admin, controles de datos
- Acceso vía API por Perplexity Sonar, basado en uso

## Mejor para

- RevOps construyendo dossieres de research de cuentas
- Recruiters haciendo sourcing de candidatos y validando data de mercado
- Legal-ops escaneando updates regulatorios y resúmenes de casos

## Cosas a vigilar

- Las citas se ven autoritativas; igual verifica antes de citar en un deck de directorio
- Para reasoning y escritura de formato largo, Claude/ChatGPT siguen siendo más fuertes
- El catálogo de integraciones es delgado — combina con Zapier o Make para distribución
