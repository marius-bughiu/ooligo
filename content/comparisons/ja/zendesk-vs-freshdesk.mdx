[Zendesk](/ja/tools/zendesk/) と [Freshdesk](/ja/tools/freshdesk/) は、サポートまたは CS のリーダーが 1 つのチケッティングプラットフォームに標準化する際に実際に候補に挙げる 2 つのデスクです。どちらもオムニチャネルのチケッティングを行い、どちらも席数の上に AI レイヤーを重ね、どちらも更新を自前で管理するのではなく顧客ヘルスのシグナルを CS プラットフォームへ供給します。違いは機能ではありません。機能リストは大きく重なります。違いは、導入実績と規模か、スピードとコストかです。Zendesk は他のすべてのデスクが比較対象とするエンタープライズの標準であり、Freshdesk は導入パートナーなしで今週のうちに立ち上げられる SMB から mid-market 向けのバリュー重視の選択肢です。機能のチェックボックスではなく、その線の上で自社がどこに位置するかで選んでください。

## Zendesk が勝つところ

- **エンタープライズの幅と導入実績。** メール、Web/モバイルのメッセージング、音声 (Talk)、ソーシャルが 1 つの workspace に収まり、プラットフォームは複数の製品ラインを 1 つのデスクで運用する 50 名以上のエージェント組織にまでスケールします。サポートが補助的なツールではなく重要インフラであるなら、ルーティング、WFM、コンタクトセンターのアドオンにおける Zendesk の深さは、より完成された面です。
- **統合エコシステムが堀である。** ヘルススコアリングのツール (Gainsight、Vitally、Catalyst) は Zendesk のチケット量と CSAT を一級の churn シグナルとして扱い、Zendesk のコネクタライブラリ (Salesforce、HubSpot、Slack、Jira、Intercom、Gainsight) は Freshdesk のものより広く、実戦で鍛えられています。デスクが顧客の声の記録システムであるとき、その統合の深さこそがスタックを支える理由です。
- **成果ベースの AI エージェント価格。** Zendesk は AI エージェントを自動解決 1 件ごとに課金し (コミット量で 1 解決あたり約 $1.50、pay-as-you-go で $2.00)、Intercom の Fin と同じようにチケット単位で deflection の ROI をモデル化できます。1 解決あたり 1 セント未満が積み上がる量では有用です。
- **買い手も監査人もすでに想定しているもの。** エンタープライズ規模では「Zendesk を使っている」が調達とセキュリティレビューを通る最も抵抗の少ない道です。これは本来以上に効いてきます。

## Freshdesk が勝つところ

- **SMB と mid-market での価格対価値。** 入口の定価は Zendesk と同じ $19/エージェントですが、本物の Free tier (1-2 エージェント、6 か月の枠) と、マルチプロダクト、カスタムロール、高度な分析を含む $55/エージェントの Pro tier があります。これらは Zendesk が上位 tier に閉じ込めるか、アドオンとして売る機能です。5-100 エージェントのチームでは、同等のスコープで Freshdesk の総コストが明らかに低く収まります。
- **本番までの時間。** Freshdesk はセルフサービスの立ち上げを前提に設計されており、チケッティングは数日で稼働し、導入パートナーは不要です。Copilot、WFM、コンタクトセンターを伴う Zendesk Suite Professional の展開は数週間の設定プロジェクトです。今週デスクを動かす必要があるなら、その差は決定的です。
- **小規模でのアドオン税が低い。** どちらも AI コストを席数の上に積み上げます。Freshdesk の Freddy Copilot はエージェント単位のアドオンで、Freddy AI Agent はセッション課金です (一度限りの 500 セッション分の枠、その後は 100 セッションあたり約 $49)。しかし生産的になるために必要な基本バンドルがより安いため、AI 前の下限が低くなります。
- **エンタープライズの重さなしの洗練されたオムニチャネル。** メール、チャット、電話、ソーシャル、WhatsApp が 1 つのエージェントビューに集約され、成長中のほとんどのチームにとっては、Zendesk のより重いコンタクトセンタースタックを買わなくてもその幅で十分です。

## 価格の実態

入口の定価は $19/エージェント/月で同一ですが、これは誤解を招きます。現実的な mid-market の下限はすぐに分かれます。Zendesk は Suite Professional の $115/エージェント/月で、Copilot (+$50/エージェント)、WFM、コンタクトセンターを加えるチームは、アドオンが積み上がると日常的に $200/エージェント/月を超えます。Freshdesk の実働 tier は Pro の $55/エージェント/月で、Enterprise が $89 です。成長中のほとんどのチームが実際に必要とする tier で、Zendesk より約 2× 安くなります。どちらも AI を別建てで課金します。Zendesk は自動解決ごと、Freshdesk は AI-Agent のセッションごとです。どちらの AI 行も無料ではないため、想定するチケット量でバンドル全体をモデル化してください。エージェント単位の定価は入口のオンランプであり、どちらのプラットフォームでも総コストではありません。

## 実装の労力

Freshdesk: 稼働するデスクまで数日、セルフサービス、パートナー不要です。トレードオフは、最も深いエンタープライズのルーティング、ガバナンス、WFM が Enterprise tier にあるか、Zendesk ほど成熟していないことです。Zendesk: Copilot とコンタクトセンターを伴う Suite Professional/Enterprise の完全な rollout には数週間のプロジェクトが必要で、移行は設計上はがれにくいものです。チケットスキーマ、マクロ、トリガーロジックは独自仕様なので、再設定に数週間を見込み、いつか離脱する計画があるなら過去データを中立的な形式へエクスポートしてください。どちらも MCP を備えていますが、まだ初期です。Zendesk の MCP Client は early-access で Server は 2026 年夏予定、Freshdesk の MCP 統合は early-access (EAP) です。Claude や Cursor 駆動の workflow には使えますが、どちらもまだ本番グレードのガバナンスを前提にしないでください。

## 結論

- **Zendesk を選ぶ** のは、デスクを重要インフラとして扱う 50 名以上のエージェントのサポートまたは CS 組織で、最も広い統合エコシステム (特に Gainsight/Vitally への深いヘルススコアのフィード) が必要、複数の製品ラインを 1 つのプラットフォームで運用する、またはエンタープライズの調達とセキュリティレビューが導入実績ある製品を安全な道にする場合です。その深さの代価として、より高い総コストと数週間の実装を受け入れてください。
- **Freshdesk を選ぶ** のは、SMB から mid-market の B2B SaaS (おおむね 5-100 エージェント) で、オムニチャネルのチケッティングを速く安く稼働させたく、デスクが更新を管理することを期待するのではなく、サポートデータを別の CS プラットフォームへのフィーダーとして扱う場合です。Pro tier が ROI のスイートスポットです。
- **どちらも CS プラットフォームとしては選ばないでください** — どちらもサポートデスクであり、customer success プラットフォームではありません。本当に必要なのがヘルススコア、更新の forecasting、NRR の playbook なら、デスクは完全に間違ったカテゴリです。それは [Gainsight](/ja/tools/gainsight/)、[Totango](/ja/tools/totango/)、[ChurnZero](/ja/tools/churnzero/)、[Vitally](/ja/tools/vitally/) の領域であり、どちらのデスクもそれらのツールを置き換えるのではなく供給します。

上記の規模や調達の条件なしに何もないところで選んでいるなら、Freshdesk を選んでください。より低い総コストと同じ週での立ち上げが、最もリスクの低い default にします。エージェントが約 50 名を超えたとき、その統合の深さが決定的に必要になったとき、またはエンタープライズのコンプライアンスが導入実績ある製品を交渉不可にしたときに、Zendesk へ切り替えてください。
