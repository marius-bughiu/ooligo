## 概要

Twenty は、セルフホストすることも、マネージドのクラウドワークスペースとして利用することもできるオープンソースの CRM です。2023年に Charles Bochet と Félix Malfait が創業し、Y Combinator の S23 バッチを経ています。2026年9月29日時点で GitHub スター数は 57,700 を超えており、ベンダーは GitHub で No.1 のオープンソース CRM と謳っています。データモデルは Attio と同じ考え方で、Settings からカスタムオブジェクト、フィールド、ビュー（テーブル、カンバン、カレンダー、リスト）、ダッシュボードを定義でき、どのプランでもオブジェクト数やレコード数の上限はありません。

コアは AGPLv3 で、アプリ構築ツールキット（`twenty-sdk`、`create-twenty-app`）は MIT、`@license Enterprise` と記された一部のファイルは商用ライセンスです。購入前に理解すべきなのはこの分割です。AGPL のコードだけで完全な CRM を無料で使えますが、SSO と行レベル権限は商用ファイル側にあります。

## RevOps スタックに登場する理由

- **「なぜデータベースにシート単位で払っているのか」という疑問を解消します。** セルフホストのインスタンスにかかるのはサーバー代と運用工数だけで、シート料金も、レコード数の上限も、オブジェクト数の上限もありません。
- **リリースのペースが速く、透明です。** Twenty は twenty.com/releases で公開しながら出荷しています。v2.35（2026年8月26日）では、同期されナビゲート可能なトランスクリプト付きの通話録音が追加されました。v2.39（9月9日）では音声のみの録音と録音ボットの一時停止スイッチが、v2.40（9月15日）ではティア別に AI モデルを選べる単一のスライダーが追加され、各モデルのプロバイダー、価格、コンテキストウィンドウ、データレジデンシーが AI 設定に表示されるようになりました。
- **エージェントがファーストパーティでアクセスできます。** すべての Cloud ワークスペースに OAuth 経由のネイティブ MCP サーバーが付属しており、Claude、ChatGPT、Cursor がミドルウェアなしで CRM レコードを読み書きできます。REST と GraphQL の API、Webhook は全プランで利用でき、ワークフロー、AI チャット、カスタムスキル付きの AI エージェントは Pro から含まれます。
- **開発者は TypeScript で拡張できます。** `npx create-twenty-app` を実行すると、カスタムオブジェクト、サーバーサイドのロジック関数、Twenty 内でレンダリングされる React コンポーネント、AI スキルを含むアプリの雛形が生成されます。Apex 抜きの Salesforce AppExchange という発想です。

## 実際の料金

2026年9月29日に twenty.com/pricing で確認しました。全プランでシート数、レコード数、カスタムオブジェクト数は無制限で、30日間のトライアルにクレジットカードは不要です。

- **Self-hosted Free** — $0。Pro の全機能とコミュニティサポートが付き、Docker または Kubernetes は自社で運用します。AI の呼び出しは自社のプロバイダーキー（`OPENAI_API_KEY` と、Anthropic、Google、Mistral、xAI 用の同等のキー）に送られます。
- **Pro (Cloud)** — 年払いで $9/ユーザー/月、月払いでは約 $12。API は毎分 50 コールが上限です。SSO と行レベル権限はありません。
- **Organization** — 年払いで $19/ユーザー/月、月払いでは約 $25。行レベル権限、SAML/OIDC SSO、監査ログ、暗号鍵のローテーション、カスタムドメイン、優先サポート、毎分 100 API コールが加わります。セルフホスト向けのライセンスキーとしても販売されています。
- **Enterprise** — 年額 $50,000 から。シングルテナントの分離、IP 許可リスト、SCIM、セキュリティレビューと DPA、SLA が付きます。

ワークフローと AI はクレジットで動き、1 クレジット = $1 分の利用量です。ワークスペースには月払いで月 5 クレジット、年払いで年 50 クレジットが付与されます。これはユーザー単位ではなくワークスペース単位で、未使用分は 1 期間分の付与量まで繰り越せます。標準的なワークフローステップは約 $0.0001 なので、単純な自動化は実質無料です。一方、大規模な多段階のエージェントタスクは 1 ドル以上かかることがあります。Organization を年払いで使う 20 シートのチームは、クレジットパックを除いて年 $4,560 を支払います。これに対し、Salesforce Enterprise を定価 $175 で 20 シート契約すると年 $42,000 です。

## 最適な対象

従業員 10〜200 人規模の企業で、社内にエンジニアがいて、CRM を自社インフラや自社の EU リージョンに置きたく、マーケットプレイスのアドオンを買うより TypeScript でアプリを書きたい RevOps 担当者や Ops エンジニアに最適です。

## 向かない対象

技術サポートのない営業チームには向きません。複雑な Salesforce や HubSpot の組織からの移行にはスクリプトかパートナーが必要で、不足を埋める AppExchange 規模のエコシステムもありません。安価なプランでの SSO を購入要件とするチームにも向きません。アウトバウンド目的で購入するチームも同様です。Twenty には組み込みのシーケンス、ダイヤラー、コンタクトデータベースがないため、Apollo、Outreach、または Clay のワークフローに引き続き費用を払うことになります。

## 代替ツールとの比較

- **[Salesforce](/ja/tools/salesforce/)** — 財務、サポート、パートナーがすでにデータモデルを共有している場合や、200 ユーザー超での 3 年目のガバナンスが評価軸の場合に選んでください。コスト（Organization は Enterprise 定価のおよそ 9 分の 1）とコードの所有では Twenty が勝ります。
- **[HubSpot](/ja/tools/hubspot/)** — マーケティングオートメーション、シーケンス、CRM を 1 つの請求にまとめる必要があり、チームにコードを書く人がいない場合に選んでください。Twenty は CRM であり、マーケティングスイートではありません。
- **[Attio](/ja/tools/attio/)** — 柔軟なデータモデルのセグメントで最も急成長している新興勢力で、使用感も最も近い製品です。自前で何も運用せずに、組み込みのエンリッチメント、Sequences、通話インテリジェンスが欲しいなら Attio を選んでください。セルフホスト、オープンソースライセンス、あるいは Attio の $35 の Plus シートに対する $9 が決め手なら Twenty を選んでください。

## 注意点

- **セルフホストが無料なのは SSO が必要になるまでです。** SSO、行レベル権限、監査ログは商用ライセンスのファイルに含まれるため、セキュリティ質問票ひとつで $0 のインストールが Organization ライセンスに変わります。対策：無料の道を選ぶ前にアクセス制御の要件を洗い出し、SSO がリストにあるなら初日から Organization キーの費用を見積もってください。
- **再販するなら AGPL は本気で効いてきます。** 社内利用には制限がありませんが、改変した Twenty をネットワーク経由で顧客に提供すると AGPL のソース開示義務が発生します。対策：コアをフォークするのではなく、顧客向けの拡張は MIT ライセンスの SDK と公開 API を通じた別アプリとして構築してください。これはライセンスのアプリケーション例外でカバーされます。
- **Pro の API 上限は同期の多いスタックには低すぎます。** 毎分 50 コールでは、一括エンリッチメントのバックフィルや双方向のウェアハウス同期が詰まります。対策：GraphQL API で書き込みをバッチ化し、バックフィルは業務時間外にスケジュールしてください。CRM がデータフローの中心にあるなら、Organization の毎分 100 コールを予算に組み込んでください。
- **クレジットは少なく、共有プールです。** ワークスペースあたり月 5 クレジットでは、単純な自動化はまかなえても、AI エージェントを毎日動かすチームには足りません。対策：まず 1 か月を月払いで運用し、Settings → Billing でワークフロー別・モデル別のクレジット内訳を確認してから、パックを購入するか年払いに移行してください。
- **通話録音はまだ新しい機能です。** トランスクリプトは2026年8月下旬にリリースされたばかりで数週間の実績しかなく、会話インテリジェンスツールの代わりにはなりません。対策：ネイティブのレコーダーが本番運用で 1 四半期の実績を積むまでは、通話には [Fathom](/ja/tools/fathom/) か [Granola](/ja/tools/granola/) を使い続けてください。どちらにも Twenty アプリがあります。
