## Ce que c'est

Claude Code est l'outil de programmation agentique d'Anthropic : vous décrivez une tâche en langage naturel, et il lit le dépôt, modifie des fichiers à travers celui-ci, exécute des commandes shell et des tests, puis commit ou ouvre une pull request. Il tourne sur un même moteur à travers plusieurs surfaces — une CLI de terminal, une extension VS Code (qui s'installe aussi dans Cursor), un plugin JetBrains, l'onglet Code de l'application desktop Claude, le navigateur sur claude.ai/code et les applications mobiles Claude —, si bien que le `CLAUDE.md`, les réglages et les serveurs MCP d'un projet vous suivent de l'une à l'autre. Il est ouvert au grand public depuis mai 2025 et, selon l'annonce de levée de fonds d'Anthropic de février 2026, son chiffre d'affaires annualisé (run-rate) dépassait déjà 2,5 milliards de dollars.

Ceci est une page de sous-produit. [Claude](/fr/tools/claude/) couvre l'assistant et l'API ; [Claude Cowork](/fr/tools/claude-cowork/) couvre la surface d'agents pour les personnes qui n'écrivent pas de code. Claude Code s'adresse à la personne de l'équipe ops à qui appartient le code.

## Pourquoi il apparaît dans les stacks ops

Les GTM engineers et les développeurs RevOps livrent de plus en plus de code d'intégration : scripts de synchronisation CRM, jobs d'enrichissement, serveurs MCP maison, nœuds de code [n8n](/fr/tools/n8n/), modèles d'entrepôt de données. L'essentiel de ce code se construit désormais dans Claude Code, pour quatre raisons :

- **MCP dans les deux sens.** Il se connecte aux serveurs MCP de [HubSpot](/fr/tools/hubspot/), [Salesforce](/fr/tools/salesforce/), [Linear](/fr/tools/linear/), [Notion](/fr/tools/notion/) et [Slack](/fr/tools/slack/), et c'est l'endroit le plus rapide pour écrire et tester votre propre serveur. Voir [ce qu'est un serveur MCP](/fr/learn/mcp-server-explained/) et [quand une skill l'emporte sur un serveur](/fr/learn/claude-skill-vs-mcp-server/).
- **Exécutions headless.** `claude -p` exécute un prompt sans interaction, ce qui l'intègre aux CI, aux cron jobs et aux pipelines GitHub Actions ou GitLab CI/CD. L'Agent SDK expose les mêmes outils pour construire vos propres agents.
- **Routines.** Des jobs planifiés dans le cloud, créés avec `/schedule`, qui continuent de tourner quand votre portable est éteint et peuvent se déclencher sur un appel d'API ou un événement GitHub — le contrôle nocturne de qualité des données ou l'audit de dépendances du lundi auquel plus personne n'a à penser.
- **Instructions de dépôt partagées.** Depuis la version 2.1.277 (18 septembre 2026), Claude Code lit `AGENTS.md` quand un dossier n'a pas de `CLAUDE.md` : un dépôt déjà configuré pour Codex ou d'autres agents fonctionne donc sans dupliquer les instructions. Si les deux fichiers existent, `CLAUDE.md` l'emporte.

## La réalité du prix

Claude Code n'a pas de prix propre ; il est inclus dans toutes les offres payantes de Claude, mais pas dans Free :

- **Pro** — 20 $/mois, ou 17 $/mois en facturation annuelle
- **Max** — 100 $/mois ou 200 $/mois, pour 5× ou 20× l'usage de Pro
- **Team** — siège standard 25 $/mois (20 $ en annuel) ; siège premium 125 $/mois (100 $ en annuel), de 2 à 150 sièges
- **Enterprise** — 20 $ par siège plus l'usage facturé au tarif API

Vous pouvez aussi vous passer de sièges et l'utiliser avec une clé API de l'Anthropic Console, Amazon Bedrock, Google Cloud's Agent Platform ou Microsoft Foundry, en payant au token.

La grille tarifaire n'est pas le vrai chiffre. L'usage est mutualisé entre le chat de claude.ai, l'application desktop, Cowork et Claude Code, et il est plafonné deux fois : une fenêtre glissante de cinq heures et une limite hebdomadaire, qu'Anthropic a ajustée plusieurs fois en 2026. Coder toute la journée, tous les jours, dépasse un siège Pro ; c'est à cela que servent Max et les sièges premium. Prévoyez un siège Team standard pour l'analyste qui écrit un script par semaine, un siège premium (ou Max pour un particulier) pour quiconque en fait son outil principal, et 100–200 $ par utilisateur intensif et par mois comme chiffre de planification. Le Code Review automatique sur GitHub, disponible sur Team et Enterprise en research preview, est facturé à part via des crédits d'usage, en moyenne 15–25 $ par revue.

## Idéal pour

Les GTM engineers, RevOps engineers et technologues legal ops ou recruiting ops qui possèdent un dépôt — la personne qui maintient la synchronisation CRM-entrepôt, écrit le serveur MCP maison du deal desk ou construit le pipeline d'export de l'ATS. Le cas précis où il gagne sans conteste : des modifications sur plusieurs fichiers d'une base de code existante qui doit continuer à passer ses tests, suivies d'une exécution planifiée ou déclenchée par la CI du même job. Voilà la réponse à la question du siège Team premium : oui pour la ou les deux personnes dont le métier est de construire ce code, non pour tous les autres.

## Ne convient pas pour

Les personnes qui ne lisent pas de diffs. Claude Code propose et exécute des commandes shell et commit du code ; si personne côté destinataire ne peut juger si une modification est correcte, donnez plutôt à cette personne [Claude Cowork](/fr/tools/claude-cowork/) ou un outil no-code. Il ne remplace pas non plus un outil de flux pour des pipelines à fort volume et à forme fixe : dès que le job devient « déplacer ces champs toutes les heures », le code écrit par Claude Code doit tourner dans n8n ou votre orchestrateur, pas dans une session d'agent.

## Face aux alternatives

- **[GitHub Copilot](/fr/tools/github-copilot/)** — la plus grande base installée en nombre de sièges. Business coûte 19 $ et Enterprise 39 $ par utilisateur et par mois, et depuis le 1er juin 2026 l'usage au-delà des AI credits inclus est mesuré et facturé en plus. Choisissez-le quand l'organisation achète déjà GitHub Enterprise et que le besoin principal est la complétion dans l'éditeur pour de nombreux développeurs, pas des tâches en plusieurs étapes déléguées.
- **[Cursor](/fr/tools/cursor/)** — le premier rival spécialisé code en chiffre d'affaires ; Bloomberg a rapporté qu'il a franchi 2 milliards de dollars de chiffre d'affaires annualisé en mars 2026. Les offres individuelles commencent à 20 $/mois et Teams à 40 $ par utilisateur. Choisissez-le quand la personne vit dans un IDE et veut voir et piloter chaque modification visuellement ; l'arbitrage complet est dans [Claude vs Cursor](/fr/comparisons/claude-vs-cursor/).
- **OpenAI Codex** — le concurrent à la croissance la plus rapide, passé de plus de 2 millions d'utilisateurs hebdomadaires en mars 2026 à plus de 5 millions en juin. Il est inclus dans ChatGPT Go (8 $), Plus (20 $) et Business (20 $ par utilisateur en annuel, 25 $ en mensuel). Choisissez-le quand l'entreprise a déjà standardisé sur ChatGPT Business : le siège de code arrive alors sans nouveau fournisseur. OpenAI a cessé de vendre de nouveaux sièges Codex-only en pay-as-you-go sur les offres Business en juin 2026 ; l'usage facturé au token passe désormais par une clé API.

## Points de vigilance

- **Auto mode est désormais le mode de permission de départ.** Depuis la version 2.1.283, les sessions interactives en terminal et dans VS Code démarrent en auto mode, où un second modèle examine chaque action à la place d'un humain. La documentation d'Anthropic elle-même indique qu'il « ne garantit pas la sécurité ». Garde-fou : sur Team et Enterprise, définissez `permissions.defaultMode` ou passez `permissions.disableAutoMode` à `"disable"` dans les réglages gérés pour les groupes qui touchent aux systèmes de production, ajoutez des règles `ask` pour tout outil MCP qui écrit dans le CRM, et faites tourner les sessions sans surveillance dans un conteneur ou un sandbox.
- **Un seul pool d'usage, de nombreux consommateurs.** Une routine, la session de chat d'un collègue et votre session de code puisent dans la même limite de siège, et cette limite se réinitialise sur une fenêtre de cinq heures que vous ne contrôlez pas. Garde-fou : donnez aux routines planifiées et aux jobs de CI leur propre clé API avec un plafond de dépense, pour qu'un job qui s'emballe ne bloque pas la personne qui a besoin du siège à 10 h.
- **Le coût du Code Review augmente avec les pushes.** Régler un dépôt sur une revue « After every push » multiplie la moyenne de 15–25 $ par le nombre de pushes par pull request. Garde-fou : démarrez les dépôts en « Once after PR creation » ou en Manual, et fixez un plafond de dépense mensuel pour le service Claude Code Review sur claude.ai/admin-settings/usage avant de l'activer.
