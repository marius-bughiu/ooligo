## 概要

Dots は [ChatGPT](/ja/tools/chatgpt/) 内で動く OpenAI の常時稼働エージェントで、2026年9月29日の DevDay で Sam Altman が発表しました。Dot はチャットを閉じた後も作業を続けます。各 Dot は専用のクラウドコンピューター（Chrome ブラウザ付きの Linux 環境で、ユーザーごとに分離）を持ち、タスクをまたいでコンテキストを保持し、予定された作業や定期的な作業を実行し、会話と会話の間も目標に向けて作業を進めます。ChatGPT や [Codex](/ja/tools/openai-codex/) と同じプラグイン権限を通じて 4,000 以上のアプリにアクセスするため、すでに接続済みのアプリはそのまま Dot からも使えます。やり取りは Web、デスクトップ、モバイルの ChatGPT か、デスクトップから設定する [Slack](/ja/tools/slack/) と [Microsoft Teams](/ja/tools/microsoft-teams/) で行います。Dot の作成はデスクトップでしかできません。

制御の中心は Custom Rules です。サポートされている各アクションは、「確認せずに実行」「事前承認があれば実行」（プロンプトでそのアクションを依頼した場合）「先に確認する」「あなたに引き継ぐ」の4つのモードのいずれかに設定されます。緩められない制限もあり、パスワード変更と送金は必ずあなたに戻されます。別系統の auto-review システムが、メール送信などの予定されたステップをあなたの指示とルールに照らしてチェックし、このシステムは Dot が変更できる環境の外で動きます。Dot が自発的に調査を行うとき、アプリ用ツールは読み取り専用になります。

オペレーションチームにとって有用なのは、単発の作業ではなく継続的な定型業務です。たとえば毎週月曜に未署名の更新契約を追いかけてリマインドの文面を下書きする、次のステップが決まっていない deal をパイプラインから洗い出してチームの Slack チャンネルに一覧を投稿する、面接フィードバックを残していない hiring manager にフォローアップする、といった使い方です。

## 実際の価格

Dots 単体では購入できません。最初の Dot は、現在月額 100 ドル、200 ドル、500 ドルの3段階がある ChatGPT Pro と、Business Premium シートに含まれます。Business Premium シートは OpenAI のヘルプセンターで、年払いなら1ユーザーあたり月額 100 ドル、月払いなら 125 ドルと案内されています。Business ワークスペースには有料シートが最低2つ必要なため、Dot を含む最小の法人構成は Premium シート1つと Standard シート1つです。リリース時点では、Pro 経由の Dots は EEA、スイス、英国では利用できませんでした。Enterprise、Edu、Healthcare は、管理者が有効化するベータを個別契約で利用します。

追加の Dot や、Dot ごとの速度・月間キャパシティの拡張は、将来の有料オプションとして予告されていますが価格は未公表です。Dot とのチャットは ChatGPT の利用上限にカウントされませんが、Dot が開始した Codex や ChatGPT Work のタスクはカウントされます。上限の引き上げは最初の1か月だけです。現実的な予算は Dot を担当する1人あたり 100〜125 ドルとし、OpenAI が追加 Dot の価格を出した時点で2つ目の費用項目が発生すると見込んでください。

## ベータ期間中に Enterprise 管理者が管理できること

Enterprise ワークスペースでは、Dots はデフォルトでオフです。管理者がワークスペースの機能設定で「Use dots (Beta)」を有効にし、ローカルコンピューターへのアクセス、Custom Rules、Slack と Teams、クラウドブラウザ、ネットワーク、デスクトップ、パスワードマネージャーの利用可否を個別に制御します。Enterprise のモデル設定は Dots には適用されません。ベータ期間中はデータレジデンシーも推論レジデンシーもなく、FedRAMP ワークスペースや EKM を使うワークスペースでは Dots を利用できません。OpenAI は Dot 単位の監査ログのエクスポートを公表していません。独立系のハードニングガイドは、Compliance API でできるのはアクセスの取り消しであり、Dot が何をしたかの再構成ではないと説明しています。専用の ID と認証情報を持ち [Microsoft Agent 365](/ja/tools/microsoft-agent-365/) で管理する専門 Dot は、OpenAI 主導の企業向けパイロットとして始まり、提供時期は示されていません。

## 最適な用途

ChatGPT Pro または Business Premium を使っている RevOps マネージャー、CS リード、recruiting コーディネーターで、いくつかの定例フォローアップを抱えており、workflow を組まずにメール、CRM、Slack をまたいで1つのエージェントに任せたい人に向いています。個人のタスクリスト向けであり、チーム全体のプロセス向けではありません。

データレジデンシー、完全な監査証跡、あるいは 40 人の rep に同じロジックを適用する必要があるなら見送ってください。それは個人のエージェントではなく、ガバナンスの効いた workflow の仕事です。

## 代替ツールとの比較

[Microsoft 365 Copilot](/ja/tools/microsoft-365-copilot/) と [Claude Cowork](/ja/tools/claude-cowork/) は、企業がすでに契約している AI シートの中でエージェント的な作業を行う定番の選択肢です。[Manus](/ja/tools/manus/) は汎用クラウドエージェントで最も急成長している新興勢力です。作業が Outlook、Teams、SharePoint 中心で、Purview とレジデンシーが今すぐ必要なら Copilot を選んでください。ファイルとコネクター中心の作業で、100 ドルのシートではなく 20 ドルの Pro シートで回したいなら Cowork です。プロセスごとに専用のアシスタントを用意し、月額 50 ドルからの従量課金にしたいなら [Lindy](/ja/tools/lindy/) です。フォローアップをすべての rep に同一の内容で実行し、実行ログを自社で保持する必要があるなら [n8n](/ja/tools/n8n/) です。チームがすでに ChatGPT 中心で仕事をしていて、作業がルールより判断に依存し、担当者が1人に決まっているなら Dots を選んでください。

## 注意点

- **編集できないメモリ。** Dot は ChatGPT と接続アプリからメモリを作りますが、個々のメモリを閲覧・削除することはできません。アプリの接続を外しても新規アクセスが止まるだけで、学習済みの内容は残ります。対策：各 Dot には範囲を絞った仕事を1つだけ任せ、その仕事に必要なアプリだけを接続し、担当範囲が変わったら Dot を削除して作り直してください。
- **承認疲れが一括承認につながる。** アクションごとに4つのモードがあるため、1週間確認依頼が続くと、すべてを「確認せずに実行」にしたくなります。対策：最初の1か月は顧客宛ての送信メールと CRM のステージ変更を「先に確認する」のままにし、どのアクションも緩いモードに移す前に Activity View を毎週確認してください。
- **ベータはコンプライアンス対応が整っていない。** レジデンシーなし、公開された監査エクスポートなし、モデル設定も適用されません。対策：Enterprise では名前を決めたパイロットグループだけに Dots を有効化し、OpenAI がログ記録を文書化するまで規制対象データ（候補者の PII、契約条件）を接続アプリから外し、そうしたプロセスはガバナンスの効いた workflow ツールで処理してください。
- **プロンプトインジェクションは軽減されるだけで解決はしていない。** OpenAI 自身が防御策ではリスクを排除できないと述べており、受信メールを読む Dot は信頼できないテキストを読んでいることになります。対策：送信を「先に確認する」にしないまま、Dot に受信箱の読み取り権限と送信権限を同時に与えないでください。
