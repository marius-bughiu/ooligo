## 何であるか

Monaco は、CRM、シーケンサー、エンリッチメント層、パイプラインインテリジェンスツールを1つのシステムオブレコードに統合した製品です。誰もやりたがらないデータ入力はエージェントが担います。答えているのはシリーズ B 前の具体的な問いです。[Salesforce](/ja/tools/salesforce/) と5つのポイントツールを買い、それを回すためにオペレーション担当を採用するのか。それとも、TAM を構築し、アウトバウンドを実行し、すべてのやり取りを記録し、案件を前に進める1つのプラットフォームを買うのか。後者には、設定を代行するフォワードデプロイドの営業専門家が付いてきます。

創業したのは Sam Blond です。Brex の CRO を務め、その前は Zenefits にいました。アーリーステージ B2B の営業リーダーシップにおいて、彼はもっとも名の知れた存在と言えます。共同創業者は [Clari](/ja/tools/clari/) の元 CTO である Malay Desai と、[Apollo](/ja/tools/apollo/) および Qualtrics の元 CPO である Shek Viswanathan です。これは豆知識ではなく製品の論拠として読むべきです。フォーキャスト層、プロスペクティングのデータベース、アンケート基盤を作ったのはこの3人であり、Monaco はいまそれらを継ぎ合わせるのをやめろと主張しています。

Monaco は 2026-02 に3,500万ドル超を調達してステルスを抜け、2026-05-12 に Benchmark がリードする5,000万ドルのシリーズ B を実施しました。Founders Fund と Human Capital が継続出資し、Alt Cap、Mantis、Saga VC、Garry Tan、Neil Mehta、John Collison、Patrick Collison も名を連ねます。累計は8,500万ドルを超えました。Jack Altman は Benchmark のパートナーとして初の投資先に選び、取締役会に加わっています。Monaco 初の買収は 2026-09-05 に完了しました。対象は Overlayy、IIT Kanpur 出身者が創業したバンガロールの営業コパイロットで、B2B の商談会話を大規模に分析していた企業です。

## 実際に買うもの

現時点で名前の付いた6つの構成要素が提供されています。乗り換えの決め手になるのは最初の2つです。

**Pre-built TAM と Custom Signals。** オンボーディングは、あなたが初回ログインする前に総アドレス可能市場を構築してスコアリングし、ターゲットアカウントを順位付けします。推奨される購買担当者は、Monaco が代わりに監視するシグナルから浮かび上がります。チームの既存人脈、転職、そして自分で定義した Web シグナルです。AI Semantic Search は、フィルタビルダーではなく自然文でそのデータベースを絞り込みます。

**Autopilot Sequences と Self-Managing Pipeline。** シーケンスは、担当者がリストを組むのを待たず、シグナルが発火した時点でアカウントを自動的に登録します。パイプラインは記録されたやり取り、つまりメール、通話、会議、メッセージから自動更新されます。5人規模の営業チームに耐えられる CRM かどうかは、ここで決まります。CRO Copilot はその上に乗り、レベニュー責任者が金曜日に投げる質問に答えます。

**会話の記録。** Monaco は通話メモを取り、メールを下書きし、指示がなくてもレコードに書き戻します。ただし発信はしません。ダイヤラーがないため、これは記録と分析であって、アウトバウンドの電話業務ではありません。Overlayy の会話分析は、この方向の明白な強化です。

Monaco はベータ期間中に数百社のスタートアップを導入したと述べ、平均的な顧客は前月比のレベニュー成長率を16ポイント上乗せし、月間の商談数を3倍にしたとしています。いずれもベンダー申告の数字で、自己選択されたベータ群のものです。G2 の蓄積も第三者の事例もまだ背後にありません。ベンチマークではなく、商談を設定する理由として扱ってください。

## 価格

公開価格ページも、セルフサーブの試用も、公表されたプランもありません。Blond はローンチ時に金額の明示を断り、Monaco は 2026-09-21 時点でも公開していません。確定しているのは *形* です。席数課金ではない定額で、フォワードデプロイドのオンボーディングが含まれます。

第三者のディレクトリは、組み込み AE のコスト構造から月額500〜2,000ドル超と見積もっています。これは見積もりであって、正式な提示ではありません。金額より形のほうが重要です。定額課金は採用が進むほど担当者あたりの単価が下がり、席数課金の競合に対する損得は10〜15ユーザーあたりで逆転します。最初の商談で2つ聞いてください。現在の人員での金額と、人員が3倍になったときの金額です。2つ目の答えが「御社に合わせて変わります」であれば、その定額は1年間だけの定額です。

## 最適な対象

シードからシリーズ A の B2B 企業、従業員5〜30人で、ICP を検証済み、メール中心のアウトバウンドを回しており、移行する価値のある CRM を持っていない創業者または営業1人目です。レガシーデータがないことが判断材料になります。Monaco の価値が最大化するのは、代替案が「Salesforce を置き換える」ではなく「パイプラインはスプレッドシートと Apollo にあり、どちらも誰も更新していない」ときです。

## 向かない対象

Monaco をスタックの他の部分と連携させる必要がある組織です。Monaco は AI 連携向けに MCP サーバーを公開していますが、連携の話はそこで終わります。公開 API もなく、Webhook もなく、文書化されたコネクタもありません。案件を BI ツールへ送ることも、プロダクトのイベントからシーケンスを起動することも、既存の Salesforce 環境と同期することもできません。12人規模なら許容範囲です。データウェアハウスがあるなら失格要件です。

インバウンドや電話が主体のチームにも向きません。Web サイト訪問者の特定機能がないため、自社サイト上でもっとも見込みの高いアカウントは匿名のままです。そこは [Warmly](/ja/tools/warmly/) の領域です。ライブチャットもダイヤラーもありません。そしてシリーズ B 以降にも向きません。Monaco は1人がレベニューを回す規模帯のために作られており、ロードマップはあなたではなくその規模帯を追いかけます。

## 代替製品との比較

- **[Salesforce](/ja/tools/salesforce/)** — 実際の意思決定者が取締役会、セキュリティ審査、あるいはすでにそれを前提にモデリングしている財務チームである場合の既定解です。オブジェクトモデルが10年と3人のレベニュー責任者を越えて生き残る必要があるなら Salesforce を選んでください。チームの誰も管理者をやらないなら Monaco です。
- **[HubSpot](/ja/tools/hubspot/)** — 誠実な中間解であり、Monaco が価格面で狙っている既存勢力です。Sales Hub は Monaco に欠けているインバウンド側を担い、本物の API を持ちます。マーケティングと営業が1つのシステムを共有するなら HubSpot を選び、マーケティングチームがまだ存在せずアウトバウンドがすべてなら Monaco を選んでください。
- **[Attio](/ja/tools/attio/)** — もっとも成長の速い AI ネイティブ CRM であり、この一覧でもっとも鋭い比較対象です。Attio は自分で制御できるデータモデル、MCP、文書化された API、そして35ドルからの公開された席数価格を提供します。ただし TAM を構築してくれるわけでも、シーケンスを走らせてくれるわけでもありません。システムを自分で所有して周辺を組み上げたいなら Attio、すでに組み上がった状態がほしいなら Monaco です。
- **自前で組み上げる道** — [Attio](/ja/tools/attio/) と [Clay](/ja/tools/clay/) と [Apollo](/ja/tools/apollo/) と [Gong](/ja/tools/gong/) を合わせれば、Monaco の守備範囲はおおむね埋まります。ただしベンダー4社、請求書4通、そして担当者1人の注意力を丸ごと使います。この道は可搬性で勝ち、初回商談までの時間で負けます。その組み上げ作業を引き受ける人がチームにいないなら、4ベンダー構成はシステムではなく計画にすぎません。

## 注意点

- **API も Webhook もないため、Monaco は片道の扉になります。** 作成したレコードはすべて、連絡先、企業、案件、活動履歴の CSV エクスポートでしか外に出せないシステムに置かれます。ガード: 契約前、試用期間中に完全エクスポートを実行し、活動履歴がオブジェクトのレコードと一緒に出てくることを確認してください。別々に出る場合や出ない場合があります。エクスポートしたスキーマは初月のうちに中立フォーマットへ対応付け、四半期ごとに再取得してください。検証していない可搬性は可搬性ではありません。
- **価格は見積もり制で、割引されたベータ料金は更新料金ではありません。** Blond は、製品がベータの間は初期価格が割引されていると説明していました。その製品はいま GA です。ガード: 1年目に署名する前に2年目の金額を書面で取得し、上昇幅に上限を設けてください。更新に上限のない定額は、手順が増えただけの席数課金契約です。
- **ホワイトグローブ型の提供モデルは製品そのものであり、同時に天井でもあります。** フォワードデプロイドの営業専門家がいるからオンボーディングは四半期ではなく数日で着地しますが、彼らはソフトウェアのようにはスケールしない人件費でもあります。Monaco の従業員数はおよそ40人と報じられています。ガード: 指名されたオンボーディング担当者が何社を抱えているか、そしてその担当者が離れた4か月目のサポートがどうなるかを聞いてください。4か月目の答えは通話記録ではなく契約書に入れてください。
- **トラクションの数字はすべてベンダー申告で、対象は7か月のコホートです。** 16ポイントの成長率、3倍の商談数、月あたり7桁の ARR 積み上げは、いずれも Monaco が 2026-02 に始まったベータを計測したものです。独立した蓄積はまだ存在しません。ガード: 実証はパイロットで取ってください。名前の付いた対照群、つまり現行のアウトバウンド、同じセグメント、同じ担当者に対して60日間走らせ、創出パイプラインではなく担当者あたりの獲得商談数を測ってください。パイプラインは Monaco 自身のスコアリングが左右する数字ですが、商談数はそうではありません。
