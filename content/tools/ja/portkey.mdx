## 概要

Portkey は AI ゲートウェイです。アプリやエージェントと、その背後にあるモデルプロバイダーの間に置く、OpenAI 互換の単一エンドポイントです。各チームは Portkey を呼び出し、Portkey がプロバイダーキーを保持し、モデル間のルーティングとフォールバックを行い、レスポンスをキャッシュし、ガードレールを適用し、チームごとに予算とレート制限を課し、すべてのリクエストを費用とレイテンシとともに記録します。トップページでは 1,600+ の LLM にアクセスできるとうたっていますが、ドキュメントの概要ではまだ 250+ と記載しているため、大きいほうの数字はマーケティング上の表現と考えてください。MCP ゲートウェイは同じ認証、アクセス制御、ログ記録を MCP サーバーの前段に置きます。また、[Claude Code](/ja/tools/claude-code/) 向けの専用ゲートウェイ構成もあります。

コアのゲートウェイは GitHub 上で MIT ライセンスのオープンソースとして公開されています（スター数は約 13.4k）。ホスト型のコントロールプレーンでは、オブザーバビリティ UI、プロンプト管理、セマンティックキャッシュ、RBAC、SSO、監査ログが追加されます。

解決する運用上の課題はこうです。RevOps、サポート、法務にまたがるエージェントや自動化が 3〜4 社のモデルプロバイダーを呼び出しており、財務は費用を1つの画面で把握したく、セキュリティ部門は PII マスキングと1つのキルスイッチを求めていて、誰もゲートウェイを自前で運用したくない、という状況です。

## Palo Alto による買収で何が変わったか

Palo Alto Networks は 2026年4月30日に買収を発表し、2026年5月29日に完了しました。買収額は公表されていません。7月16日、Palo Alto はこの製品を **Prisma AIRS AI Gateway** として一般提供（GA）を開始しました。LLM、MCP、エージェント間（A2A）のトラフィックを扱う単一のゲートウェイと説明されており、Prisma AIRS のランタイムセキュリティやレッドチーミングと連携します。

2026年11月22日時点で確認した、実務上の意味は次のとおりです。

- **料金ページはなくなりました。** portkey.ai/pricing は現在、Palo Alto の営業問い合わせフォームにリダイレクトされます。portkey.ai 上の Contact と Demo のボタンもすべてそこへ飛びます。
- **約束は薄いものです。** Palo Alto が顧客に対して公に示している約束は、「will continue to support existing and new Portkey customers」（既存および新規の Portkey 顧客を引き続きサポートする）という一文だけです。単体製品が独自のロードマップや料金を維持すると明記した公開情報はありません。
- **エアギャップ環境での導入は新規顧客には提供されなくなりました。** これは Portkey 自身の機能比較ページに記載されています。既存のエアギャップ環境は引き続きサポートされます。マネージド SaaS と、ハイブリッド構成（ゲートウェイは自社 VPC 内、コントロールプレーンは Portkey がホスト）は引き続き利用できます。
- **オープンソースのリポジトリは更新が鈍っています。** GitHub 上の最新のタグ付きリリースは 1月の v1.15.2 です。エンタープライズ版ゲートウェイをオープンソースに統合する Gateway 2.0 は、README で今もプレリリース扱いです。

## 料金

Portkey のドキュメントにある機能比較ページより（2026-11-22 確認）：

- **Open source：** 無料、セルフホスト、リクエスト数の上限なし、ホスト型ログなし。
- **Dev：** 無料、月 10,000 リクエスト、超過利用不可、ログ保持期間 3 日。
- **Pro：** 月 $49 で 100,000 リクエスト、以降は 300 万リクエストまで 100,000 リクエストごとに $9 追加。保持期間 30 日、セマンティックキャッシュ付き。トップページには 0.5M に対して「59.99$」と表示された矛盾するタイルがあるため、予算化の前に金額を確認してください。
- **Enterprise：** 個別見積もり。BAA の締結、VPC ホスティング、プライベートテナンシー、SCIM、高度な RBAC はこのプランに含まれ、「Book Call」のリンクは現在 Palo Alto の営業窓口につながります。

実際の価格帯：月に数十万リクエストを記録する1つの運用チームなら、Pro で月 $100 未満に収まります。SSO、BAA、VPC ホスティングが必要な場合は、Prisma AIRS と合わせて価格が決まるエンタープライズのセキュリティ案件になります。クレジットカードでの申し込みではなく、Palo Alto の調達サイクルを見込んで予算を組んでください。

## 最適な利用者

セキュリティ部門がすでに Palo Alto（Prisma、Strata、Cortex）を購入している企業のプラットフォームチームまたは AI 推進チームで、ガードレール、PII マスキング、MCP ガバナンスを備えたマネージド型ゲートウェイを求め、モデルとエージェントのトラフィックを同じセキュリティコンソールに集約したい場合です。

## 向いていないケース

エンドツーエンドで自社が管理する完全セルフホスト型、またはエアギャップ型のゲートウェイが必要なチームには向きません。新規のエアギャップ導入はもう選択肢にありません。1年後も透明なセルフサービス料金を求める小規模チームにも向きません。公開価格表はすでに料金ページではなくドキュメントにしか残っていません。また、単一プロバイダーのみを使う組織にも向きません。すべてが [Amazon Bedrock](/ja/tools/amazon-bedrock/) や [Microsoft Foundry](/ja/tools/microsoft-foundry/) 上で動いているなら、ネイティブのクォータと IAM でほとんどをカバーできます。

## 代替製品との比較

- **[LiteLLM](/ja/tools/litellm/)** は、Portkey と最もよく比較検討されるオープンソースのゲートウェイです。ゲートウェイ全体を自社ネットワーク内で運用する必要があり、アップグレードを担うエンジニアがいる場合に選んでください。先に 2026年のサプライチェーン侵害の経緯を確認してください。
- **[OpenRouter](/ja/tools/openrouter/)** は最も急成長しているホスト型ルーターで、現在は Stripe の傘下です。数百のモデルを1つの請求書にまとめたく、キーと上限設定以上のゲートウェイポリシー層が不要な場合に選んでください。
- **Cloudflare AI Gateway** または **Kong AI Gateway**。そのベンダーがすでに自社 API の前段にある場合に選んでください。
- ルーティングではなくトレースや評価が目的なら、どのゲートウェイにも [Langfuse](/ja/tools/langfuse/) か [LangSmith](/ja/tools/langsmith/) を組み合わせてください。

では、Portkey は今も正しいゲートウェイでしょうか。Palo Alto を導入済みの組織なら、答えは「はい」です。成熟したゲートウェイが、すでに費用を払っているセキュリティスタックに組み込まれます。そうでなければ、より安全な既定の選択肢は LiteLLM（セルフホスト）か OpenRouter（ホスト型）です。Portkey の単体での料金とロードマップは、Prisma AIRS を優先する親会社に左右されるようになったためです。

## 注意点

- **更新時に料金が変わる可能性があります。** セルフサービスの価格表はドキュメントにしか残っておらず、営業は Palo Alto 経由になりました。対策：本番トラフィックを流す前に、リクエスト単価とログ保持期間を契約期間全体について書面で固定し、更新時の値上げ上限を取り付けてください。
- **プロンプトと設定によるゲートウェイへのロックイン。** プロンプトテンプレート、ルーティング設定、仮想キーは Portkey のコントロールプレーンに保存されます。対策：プロンプトは自社リポジトリで管理し、ベース URL を差し替えられるよう OpenAI 互換 API 経由で Portkey を呼び出し、ログは自社のデータウェアハウスか OpenTelemetry のシンクにエクスポートしてください。
- **ログにはプロンプトとレスポンスが残ります。** エージェントを通過する顧客データや候補者データも含まれます。対策：リクエストとレスポンス本文の保存を無効化するよう Portkey に依頼し（ドキュメントでは依頼に応じて可能とされています）、本番稼働前に PII マスキングのガードレールを有効にしてください。
- **オープンソースのゲートウェイをセルフホストしても、製品と同じものにはなりません。** プロンプト管理とセマンティックキャッシュはホスト型またはエンタープライズ限定で、リリースは 1月以降止まっています。対策：セルフホストが必須条件なら、Gateway 2.0 のリリースを当てにせず、LiteLLM を並行して評価してください。
