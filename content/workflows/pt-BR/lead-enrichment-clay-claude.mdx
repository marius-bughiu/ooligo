Um Claude Skill que aumenta uma tabela do Clay com três colunas de IA: resumo de empresa, score de fit de ICP com justificativa, e um opener personalizado para cold email. Plugue em qualquer tabela do Clay que tenha uma coluna `domain`, rode, empurra pro HubSpot.

## O que você precisa

- Conta no Clay (plano Starter ou superior)
- API key do Claude (ou Claude.ai com o Skill importado)
- Uma tabela do Clay com uma coluna `domain` preenchida
- Um documento de rubrica de ICP (opcional mas altamente recomendado)
- HubSpot (ou qualquer CRM com o qual o Clay sincroniza) como destino

## Setup

1. **Adicione o Skill.** Coloque `lead-enrichment.skill` no seu projeto do Claude.ai, ou em `~/.claude/skills/` para o Claude Code. O Skill expõe três funções chamáveis: `summarize_company`, `score_icp_fit`, `write_opener`.
2. **Plugue três colunas de IA no Clay** referenciando o Skill:
   - `summary` — input: `domain`. Output: resumo de empresa em 2 frases.
   - `icp_fit_score` — input: `domain` + rubrica de ICP. Output: score 1-10 + justificativa de 1 linha.
   - `opener` — input: `domain` + `summary` + notícias recentes. Output: opener de cold email em um parágrafo, menos de 50 palavras.
3. **Configure o destino.** No Clay, configure a tabela para empurrar linhas enriquecidas pro HubSpot via integração nativa. Mapeie `summary` → propriedade custom, `icp_fit_score` → propriedade custom, `opener` → variável de sequence de first-touch.
4. **Rode em uma amostra de 20 linhas.** Confira a precisão. Ajuste a rubrica de ICP se os scores não baterem.
5. **Rode em escala.** Cadência recomendada: semanal para leads recém-importados, diária para segmentos de alta prioridade.

## Como funciona

O Skill pega um domain e roda três sub-tarefas em sequência:

1. Busca a homepage + página about da empresa (Claude com tool de web fetch, ou coluna HTTP do Clay upstream).
2. Extrai: indústria, sinais de tamanho (employee count de fontes públicas), value proposition, notícias recentes.
3. Gera os três outputs em uma única resposta estruturada.

Para o scoring de fit de ICP, o Skill aceita uma rubrica opcional — passe os critérios de "cliente ideal" do seu time como texto — e retorna tanto um score 1-10 quanto a justificativa, pra que os reps possam verificar ou sobrescrever.

## Pontos de atenção

- **Qualidade dos dados de origem.** Domains que não resolvem, parked domains ou sites com pouco conteúdo produzem outputs mais fracos. Rode a coluna de validação de domain do Clay upstream.
- **Custo.** Cada linha dispara ~3 chamadas pro Claude. Com o pricing do Sonnet, menos de um centavo por linha, mas em 100K linhas o orçamento importa. Use a Anthropic Batch API para runs de enriquecimento não-urgentes (~50% de desconto).
- **A rubrica de ICP é o ponto de alavancagem.** Uma rubrica vaga ("bom fit B2B SaaS") produz scores vagos. Rubrica apertada → scores apertados. Itere a rubrica mensalmente.
- **Variabilidade do opener.** A coluna de opener precisa de guardrails — defina um comprimento máximo, exija uma referência a algo específico (um lançamento de produto recente, uma contratação pública), e proíba superlativos. Sem guardrails, openers derivam pra bajulação genérica.

## Stack

- **Clay** — enriquecimento + substrato de orquestração
- **Claude** — inferência das colunas de IA; o Skill é a interface reutilizável
- **HubSpot** — CRM destino (Salesforce, Attio, etc. funcionam igual)
