## Was es ist

Cursor ist die KI-native IDE, die zur Standard-Coding-Umgebung für Engineers geworden ist, die Agents, MCP-Server und das technische Ende der Ops-Automatisierung bauen. Geforkt von VS Code, mit tiefer KI-Integration überlagert: Tab-Completion, Agent-Modus, Codebase-weiter Kontext und volle MCP-Server-Unterstützung.

## Warum es in RevOps-Stacks auftaucht

Das ist eines für GTM-Engineers und das technische Ende von RevOps — kein Tool für die AE-Organisation. Aber jedes RevOps-Team, das individuelle Workflows, [n8n](/de/tools/n8n/)-Nodes, MCP-Server, interne Apps oder Salesforce-Apex-Code baut, erledigt diese Arbeit zunehmend in Cursor. Die Kombination aus Agent-Modus + MCP bedeutet: Sie können Cursor an Salesforce, HubSpot, Snowflake oder Ihr Data Warehouse anbinden und Code schreiben lassen, der auf Ihren Live-Daten operiert.

- **Agent-Modus.** Mehrstufiger Coding-Agent, der unter Ihrer Aufsicht plant, editiert und Code ausführt. Schneller als [Claude](/de/tools/claude/) Code für die meisten Aufgaben; vergleichbar bei komplexen Refactorings.
- **Codebase-Kontext.** Indiziert Ihr gesamtes Repo und nutzt es als Kontext. Für RevOps-Monorepos mit individuellen Integrationen, Skripten und SQL macht das einen Unterschied.
- **MCP-Server-Unterstützung.** Schließen Sie einen beliebigen MCP-Server an Cursor an — Salesforce, HubSpot, [Linear](/de/tools/linear/), Ihr CRM der Wahl — und die KI kann Daten lesen/schreiben, während sie Code schreibt, der diese nutzt.
- **Cursor Rules.** Pro-Projekt-Konventionen, kodiert als `.cursorrules`-Dateien. Werden zum kanonischen Ort, um zu dokumentieren, „wie wir hier Automatisierungen bauen".

## Pricing

- **Free** — begrenzte tägliche KI-Anfragen
- **Pro** — 20 $/Nutzer/Monat, großzügige KI-Nutzung
- **Business** — 40 $/Nutzer/Monat, inkl. Admin-Kontrollen, SSO, Privacy-Mode
- **Enterprise** — auf Anfrage

API-Zugang wird nicht angeboten; Cursor wird ausschließlich über die IDE genutzt.

## Am besten geeignet für

- GTM-Engineers, RevOps-Engineers und technische Ops-Leute, die individuellen Code schreiben
- Teams, die MCP einführen — Cursor ist die ausgereifteste MCP-fähige IDE
- Solopreneure und kleine Teams, die Vibe-Coding-Workflows fahren; der Agent-Modus erledigt die meisten Aufgaben Ende-zu-Ende
- Alle, die Copilot, Continue oder Codeium ausprobiert haben und etwas spürbar Schnelleres und Schlaueres wollen

## Worauf zu achten ist

- Privacy-Mode ist Opt-in (ab Business-Stufe). In regulierten Umgebungen prüfen Sie die Standardeinstellungen zur Datenaufbewahrung vor dem Rollout.
- Am besten bei großen Codebases — für Ein-Datei-Skripte ist der Overhead gegenüber Claude Code oder claude.ai real
- Die Engineering-Organisation hat möglicherweise bereits eine Tooling-Präferenz (Copilot, Cody, Continue). Kein Kampf, den RevOps führen sollte.
