## 概要

Celonis はプロセスマイニングのプラットフォームです。SAP、Oracle、[Salesforce](/ja/tools/salesforce/)、ServiceNow で作成された受注、ブロックされた請求書、変更された価格、承認といった、システムがすでに書き出しているイベントログを読み込み、プロセスが実際にどう流れているかを、バリアントごとに、各ステップ間の所要時間とともに再構成します。得られるのは規程文書にあるフローチャートではありません。受注が実際にたどっている数十通りの経路、そのうちどれが遅いのか、どれに人が手作業で介入したのか、です。

自動化ツールではなく、[UiPath](/ja/tools/uipath/) や [n8n](/ja/tools/n8n/) の代わりにもなりません。時間がどこで消えているかを示して最初に何を自動化すべきかを判断させ、その後、自動化で何かが変わったかを測定します。Celonis はミュンヘンとニューヨークに本社を置く非上場企業で、2022年8月に $1B を調達した際の評価額はおよそ $13B でした。Gartner は2026年5月5日に公開した Magic Quadrant for Process Intelligence で Celonis を Leader に位置づけました。このレポートは Celonis が3年連続でリーダーだったプロセスマイニングのレポートの後継で、Celonis は13社の中で実行能力が最も高く、ビジョンの完全性が最も先行する位置に置かれています。

## エージェント時代に向けて変わったこと

Celonis は現在、エージェントに欠けているコンテキスト層として自らを売り込んでいます。「遅延している受注を解消せよ」と指示されたエージェントは、どの受注が遅れているのか、なぜなのか、前四半期にどの対策が効いたのかを知りません。Celonis はそのデータを持っています。Celosphere 2025 では Process Intelligence 向けの MCP サーバーを発表しました。これにより [Claude](/ja/tools/claude/) のような MCP クライアントが、プロセス指標や KPI を照会し、データモデルを検索し、判断結果を書き戻せます。レート制限は asset ごとに毎分500コールです。

2026年5月12日には、プロセスデータと業務知識から構築したオペレーションのライブなデジタルツインである Celonis Context Model を発表し、あわせて MIT 発の予測・シミュレーション企業 Ikigai Labs の買収契約を締結しました。共同創業者の Devavrat Shah は chief scientist として参画します。このコンテキストを利用できるエージェント基盤として名前が挙がっているのは、[Claude Cowork](/ja/tools/claude-cowork/)、Microsoft Copilot と [Agent 365](/ja/tools/microsoft-agent-365/)、Amazon Bedrock、IBM watsonx Orchestrate、Databricks Agent Bricks です。

## 購入に値するユースケース

CRM と ERP をまたぐ order-to-cash です。見積は Salesforce でクローズし、受注は SAP に入り、その間のどこかで与信ブロック、価格の不一致、手作業による再入力のせいで案件が止まります。Celonis は両方のイベントログを受注ごとに1つのケースへつなぎ、たとえば受注の3分の1が手作業の価格変更を経ていることを示し、各バリアントを売上債権回転日数（DSO）と結びつけ、今週リスクのある未処理受注にフラグを立てます。これが次に構築するエージェントやボットのブリーフになり、効果を測る基準線にもなります。Celonis が委託した Forrester の調査（2025年7月）は、モデル企業で人の介入なしに処理される受注の割合が33%から86%に上がったとしています。ベンダーにとっての最良のケースとして扱い、予測値とはみなさないでください。

## 料金

公開価格はありません。Celonis 自身の料金ページへのリンクは営業問い合わせフォームにリダイレクトされます。唯一の公開リスティングである AWS Marketplace では、12か月契約で「platform units」を単位に課金し、36か月契約なら最大33%の割引があります。ユニット数はプライベートオファーの中でデータ量とプロセスの範囲に応じて決まるため、分かるのは課金モデルであって請求額ではありません。調達ベンチマークでは、エンタープライズ向けのエントリーパッケージは導入前で年間約 $150K–$250K、導入サービスは別途一度きりで $120K–$500K と見積もられています。同じ Forrester の調査は3年間で $44.1M の効果、ROI 383% と報告しており、そこからモデル企業の3年間のコストはおよそ $9M と逆算できます。最初は6桁ドルの予算を見込み、プロセスを追加するたびに増えると考えてください。

比較として、Microsoft は Power Automate の中でプロセスマイニングを販売しています。ユーザーあたり月額 $15 の Premium には 50 MB のプロセスマイニング用ストレージが含まれ、テナントあたり月額 $5,000 のアドオンでこれが 100 GB に増えます。

## 最適な対象

従業員2,000人以上の企業で、SAP または Oracle 上で order-to-cash、procure-to-pay、サービスのプロセスを運用し、エージェントやボットをプロセスに投入する前に時間がどこで消えているかの証拠を求めているオペレーション、finance-ops、変革推進のリーダー。さらに、コネクタを担当するデータエンジニアがいることが条件です。

## 代替ツールと、それを選ぶべきとき

- **SAP Signavio** — SAP 自身のプロセスインテリジェンス製品で、同じ2026年の Magic Quadrant で Leader です。SAP S/4HANA または RISE の顧客で、マイニング、モデリング、SAP 自身のデータアクセスを1つの契約にまとめたいときに選んでください。
- **Microsoft Power Automate Process Mining** — プロセスが Microsoft 365 と Dynamics 上にあり、データ量が 100 GB 未満に収まり、年間 $60K が上限のときに選んでください。
- **Pega Process Mining** — こちらも2026年の Leader です。すでに Pega でケース管理を運用していて、同じワークフローにマイニングをつなげたいときに選んでください。
- **[UiPath](/ja/tools/uipath/)** — その後の自動化をどのみち UiPath のボットで行うなら、同社のプロセスマイニングとタスクマイニングを選んでください。
- **Mimica** — 2025年9月に $26.2M のシリーズBを調達した新興企業で、システムログではなくデスクトップ上の操作を分析します。業務がスプレッドシートやメールで行われていて、Celonis が読めるイベントログが存在しない場合に選んでください。
- **[Scribe](/ja/tools/scribe/)** — システムをまたぐプロセスを測定するのではなく、1つのチームがタスクをどう行っているかを文書化したいときに選んでください。

## 注意点

- **SAP データへのアクセスが訴訟の対象になっています。** Celonis は SAP データ抽出の技術的・費用的な障壁をめぐり、米国連邦裁判所で SAP を提訴しています。SAP は2025年6月、訴訟が決着するまで Celonis の抽出ツールを妨害せず追加料金も課さないことに合意しており、公判は2026年12月7日に予定されています。対策：Celonis との契約にデータアクセスの継続性と価格上限を盛り込み、訴訟後の抽出コストを SAP に書面で確認してください。
- **プラットフォームの価値はコネクタで決まります。** 最初の数か月はほとんどがデータエンジニアリングに費やされます。テーブルのマッピング、タイムスタンプのクレンジング、CRM のケースと ERP のケースの結合です。対策：最初のプロジェクトは1つのプロセス、1〜2つのソースシステムに絞り、複数プロセスへの拡張契約に署名する前にコネクタを稼働させてください。
- **オーナー不在のインサイトは使われずに終わります。** 数十の受注バリアントを示すダッシュボードも、それを減らす責任者がいなければ何も変えません。対策：本番稼働前にプロセスオーナーと、タッチレス受注率や DSO などの目標指標を1つ決め、毎月レビューしてください。
- **Context Model はまだ新しい製品です。** 2026年5月に発表されたばかりで、Ikigai の予測機能はまだ統合の途中です。対策：今日テストできるプロセスマイニングの実力で購入を判断し、エージェント向けコンテキストはビジネスケースの前提にせず、パイロットで実証する上積みとして扱ってください。
