## 概要

Webex Contact Center は Cisco のクラウド型コンタクトセンター（CCaaS）です。音声、チャット、メール、SMS、ソーシャルのルーティング、通話フローを作る Flow Designer、レポート用の Analyzer、スーパーバイザーとエージェント向けのデスクトップを備えています。Cisco のオンプレミス製品である UCCE（オンプレミス版 Contact Center Enterprise）、Packaged CCE、Contact Center Express、そしてホスト型の Webex Contact Center Enterprise と並ぶ位置づけです。実際の購買層はここにあります。すでに Cisco の電話システムやコールセンターを使っていて、ベンダーを変えずにクラウドへ移りたい組織です。

AI 層は **Webex AI Agent** で、AI Agent Studio 上で2つのモードで構築します。scripted（インテントとフローによるボット）と autonomous（アクションを実行する LLM エージェント）です。2026年6月の Cisco Live で、Cisco は Webex AI Agent をオンプレミスの UCCE と PCCE 環境向けに一般提供しました。さらに2026年10月のリリースノートでは autonomous エージェントに MCP の fulfillment アクションが追加され、エージェントがライブの会話中にサードパーティのツールを呼び出せるようになりました。Cisco は継続的に製品を出し続けている大手ベンダーであり、この製品が終了する懸念はありません。終了したのは管理まわりです。旧テナント管理ポータル（2026年半ばに Control Hub へ移行）と、Flex プランの旧コンタクトセンター SKU（最終受注日は2026年8月1日）です。

## サポートのスタックに登場する理由

- **Cisco の環境の中で完結します。** 電話、会議、デバイス、コンタクトセンターを1社でまかない、Control Hub を唯一の管理コンソールにできます。UCCE で500席を運用するセンターにとって、Webex Contact Center への移行は最も摩擦の少ないクラウド化の道です。
- **ホスト型 MCP サーバーは実在し、ドキュメントも整っています。** developer.webex.com の Webex Contact Center MCP Server は、外部の AI エージェントに対して管理設定（エントリポイント、営業時間、ダイヤルプラン）、リアルタイムのテレメトリ、Search API への読み取り専用クエリツールを公開します。組織の管理者が Control Hub の Agentic Apps で有効化します。WebexOne 2026（10月、オースティン）で Cisco は、すべてを Webex AI Agent 経由にするのではなく、プラットフォームを外部エージェントに開放する動きとしてこれを打ち出しました。
- **ServiceNow と Salesforce のネイティブ連携。** Webex Contact Center for ServiceNow は2026年3月にベータとなり、2026年第3四半期の一般提供を予定していました。既存の Salesforce、Microsoft Teams 連携もあります。

AI まわりの多くはまだロードマップ段階です。今回の確認時点で、**AI Concierge**（メモリとマルチエージェントのオーケストレーションを備えた既製の窓口エージェント）は2026年第4四半期の一般提供予定、Splunk ベースのエージェント可観測性は2026年12月予定、**Dialog**（1人の顧客をすべてのチャネルで追跡し、案件が解決するまで対応し続けるエージェント用ハーネス）は2027年第1四半期にベータ予定、人と AI のやり取りを100%評価する **AI Quality Management** は当初の2026年第1四半期から延びて2027年第3四半期予定、AI WEM の予測とシフト作成は2027年第3四半期に限定提供の予定です。Cisco は AI Agent の自己解決率（containment）を公表していません。WebexOne で示された唯一の公開顧客数値である GetixHealth の後処理時間86%削減は Cisco 提供の数字で、測っているのは通話後の作業であり、自動化ではありません。

## 実際の価格

Cisco は価格表を公開しておらず、席は Collaboration Flex Plan を通じてパートナー経由で販売されます。最も確かな公開数値は、Cisco が2024年に英国 G-Cloud に提出した資料で、同時接続エージェント1人あたり月額 Standard が £94.44、Premium が £139.61 です。第三者の調査では、米国の指名ユーザー席は Standard が約 $70-110、Premium が約 $110-180 で、同時接続ライセンスはそれより高くなります。Webex AI Agent は従量課金で席には含まれません。Cisco はその単価を公開しておらず、AI が処理した1分あたり $0.06-0.12 という第三者の推定は検証されていません。WFM と QM、通信事業者の通話料、Flow Designer への移行に伴うパートナーのプロフェッショナルサービスは別途予算化してください。

## 最適な対象

Cisco に標準化した組織（およそ100-2,000席、規制業種やグローバル企業が多い）のコンタクトセンター運用責任者で、現在 UCCE、PCCE、Webex Calling を使っており、ベンダーと管理コンソールを1つにまとめたく、AI ロードマップの実現を12-18か月待てる方。

まだ Cisco を使っていない場合、今年中に実証済みの AI 自己解決が必要な場合、WFM と QM を2027年ではなく今すぐプラットフォームベンダーから入手したい場合は選ばないでください。

## 代替製品との比較

**[NICE CXone](/ja/tools/nice-cxone/)** と **[Genesys Cloud](/ja/tools/genesys-cloud/)** はエンタープライズ向け CCaaS の2大プラットフォームで、どちらも Gartner の2025年版 CCaaS Magic Quadrant で Leader に位置づけられました。同じレポートで Cisco は Challenger から Niche Player に後退しています。WFM と QM が決め手なら NICE、複数の AI エージェントを1つのオーケストレーション層で束ねたいなら Genesys を選んでください。**[Talkdesk](/ja/tools/talkdesk/)** は最も勢いのある製品（同レポートで Visionary から Leader へ）で、ミッドマーケットで速く展開したい場合に向きます。アウトバウンド重視なら **[Five9](/ja/tools/five9/)**、AWS ネイティブのチームなら **[Amazon Connect](/ja/tools/amazon-connect/)**、Webex ではなく Zoom に標準化しているなら同等の選択肢は **[Zoom Contact Center](/ja/tools/zoom-contact-center/)** です。

Cisco 中心の企業向けのルールはこうです。Webex Contact Center をルーティングと電話の層として維持しつつ、主要な問い合わせ理由の自動化を Dialog や AI Concierge の登場まで待たないでください。音声なら [Parloa](/ja/tools/parloa/) や [PolyAI](/ja/tools/polyai/)、チャットとメールなら [Decagon](/ja/tools/decagon/) や [Sierra](/ja/tools/sierra/) といった専門の AI エージェントを追加し、Webex のキューへ引き継ぐ構成にします。AI QM がリリースされ、両者を並べて測定できるようになったら、ネイティブの Webex AI Agent を改めて検証してください。引き継ぎのパターンは[音声サポートエージェントのスタック](/ja/stacks/voice-support-agent-stack/)で解説しています。

## 注意点

- **ロードマップの日程はずれます。** AI QM は2026年第1四半期から2027年第3四半期に延びました。対策：契約時点で一般提供されているものだけを価格に含めて契約し、ロードマップ項目は名前を明記した納品物として契約に入れ、2四半期遅れた場合のクレジットまたは解約条項を付けてください。
- **AI の利用は従量制で、単価が公開されていません。** 対策：パイロットをラボの外に出す前に、AI Agent の1分あたりまたは1セッションあたりの単価を書面で取り付け、月額上限とアラートを設定してください。
- **MCP サーバーはサインインしたユーザーとして動作します。** `wxcc-admin-config` などのツールはエントリポイントやダイヤルプランを変更できます。対策：外部エージェントは最小権限の専用サービスユーザーで接続し、本番エージェントには管理設定ツールを持たせず、すべての MCP 呼び出しをログに残してください。
- **導入はパートナー次第です。** ほとんどの導入は Cisco パートナー経由で行われ、UCCE のスクリプトから Flow Designer のフローへの自動変換はありません。対策：フローの棚卸しと切り替え前の並行稼働期間を含む、範囲固定の移行 statement of work を求めてください。
