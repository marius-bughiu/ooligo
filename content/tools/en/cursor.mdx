Cursor is a code editor with an agent that can search your repository, change files and run commands. Use it when a RevOps change needs a code review. For example, ask it to find where a CRM importer maps sales stages. Give it a fictional row with an unknown stage. Require a test that puts the row aside for review and makes zero CRM writes before you accept the change. [Cursor Agent](https://cursor.com/docs/agent/overview)

## What the subscription covers

For new individual subscriptions, Free has limited Agent usage. Plus costs US$8 per month and excludes third-party models. Premium costs US$30 per month and adds cloud agents. If you select a Claude model on Premium, model usage comes out of prepaid credit at the API list price, in addition to the subscription. These are monthly web prices before tax, checked November 2, 2026. [Cursor pricing](https://cursor.com/pricing) · [Models and billing](https://cursor.com/docs/models-and-pricing)

Existing subscribers can keep the legacy US$20 Pro plan and its usage terms. Cursor documents switching to the new subscription as optional and permanent. Check the plan in your account before using new-customer prices to estimate next month's bill. [Legacy plan terms](https://cursor.com/docs/account/pricing/legacy-cursor-plans)

## What the API and MCP connect

The Cloud Agents API v1 is in public beta. It lets a script start an agent on a connected repository with `POST /v1/agents` and inspect its run. Cursor supports repositories hosted on GitHub and GitLab, among others. This requires an authorized repository, an eligible account and a user or service-account API key. [Cloud Agents API](https://cursor.com/docs/cloud-agent/api/endpoints)

MCP serves a different purpose. Configure an MCP server to expose specific external tools to Cursor. If the agent needs a CRM field definition, give it a read-only connection to those definitions. Credentials for launching a cloud agent alone do not authorize CRM writes. [Cursor MCP setup](https://cursor.com/docs/mcp)

## What to check before sharing a repository

Individuals can enable Privacy Mode in settings, and an administrator can set it for a team. Cursor says it excludes customer data from training when enabled, and describes separate retention exceptions for abuse investigations and certain models. Check the mode, selected model and allowed repositories for your workspace. [Cursor security](https://cursor.com/security) · [Data use](https://cursor.com/data-use)
