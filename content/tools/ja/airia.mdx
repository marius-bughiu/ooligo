## 何をするツールか

Airia はエンタープライズ向けの AI コントロールプラットフォームです。エージェントを構築し、そのモデルトラフィックをルーティングし、ツールコールにゲートをかけ、そのすべてについてコンプライアンス記録を残す、という機能を1つの製品で提供します。ベンダーはプラットフォームを4つのモジュールに分けています。**Discover** は AI ディスカバリー、セキュリティポスチャ、インベントリ、リスク分類を担います。**Secure** はレッドチーミング、MCP ゲートウェイ、エージェントの制約、ガードレールを担います。**Govern** はガバナンスレジストリ、コンプライアンスレポート、システムコントロールを担います。**Optimize** はエージェントビルダー、モデルルーティング、AI FinOps、プロトタイピングスタジオ、モデルライフサイクル、データ連携を担います。

会社は若く、その社歴にしては異例なほど資金が潤沢です。2025年9月16日の Business Wire のリリースは創業を2024年としており、**総額 $100M、うち $50M は投資済み、さらに $50M の追加コミットメント** を発表しました。いずれもベンチャーファンドではなく、共同創業者で会長の John Marshall 自身の資本によるものです。Marshall は AirWatch の共同創業者で、同社は VMware に $1.54B で買収されました。また2023年まで OneTrust の共同会長を務めていました。CEO の Kevin Kiley をはじめ経営陣の多くも OneTrust 出身です。このリリースの時点で Airia は、エンタープライズ顧客300社超、従業員150人、拠点は Atlanta、London、Singapore、Dubai、Melbourne、Bangalore と公表していました。

ops の候補リストに載るようになったのは、2026年の製品リリースのペースによるものです。AI Governance は **2026年1月14日** に提供が始まりました。担当者、リスク分類、コンプライアンス状況を持つエージェントとモデルのレジストリで、EU AI Act、NIST AI フレームワーク、ISO 42001 に準拠しています。続いて **2月12日** に、MCP のインタラクティブ UI 拡張である MCP Apps への対応が加わりました。Microsoft Foundry の評価器を本番トラフィックに対してスケジュールまたはイベント駆動で実行する Model Risk Management は **5月26日** に登場しました。Model Change Management は **7月14日** に提供が始まりました。モデルが廃止される最大90日前から段階的に強まるアラートを出し、そのモデルに依存するすべてのエージェントを一覧にし、承認済みの後継モデルへ一括で移行させ、監査用のバージョン履歴を残します。Forrester は *The Agentic Control Plane Solutions Landscape, Q2 2026* で Airia を注目ベンダーに挙げています。

## これが答える問い

「Copilot、Claude、内製エージェントを横断する1つのコントロールプレーンが必要なのか、それとも単機能のガバナンスツールで足りるのか」。Airia の答えは、ガバナンスはエージェントが構築され、そのトラフィックがルーティングされる場所で適用するほうが容易だ、というものです。競合の多くは、別の場所にあるエージェントを監視します。Airia は、エージェントが住む場所そのものになろうとしています。それが強みであり、同時にコストでもあります。モデルルーティング(機密データは承認済みモデルにだけ送り、プロバイダー間でフェイルオーバーする)、ツールアクセス(ベンダーによれば 2,000件超の設定済み連携を備える MCP ゲートウェイ)、監査ファイルについて、1つのポリシーレイヤーが手に入ります。ただし、その価値が完全に発揮されるのは、チームがエージェントの構築を Airia に移したときだけです。

2つ目の差別化要因はデプロイ形態です。Airia はマルチテナント SaaS、GovCloud を含む自社 AWS アカウント内のプライベートクラウド、VMware、Kubernetes、ベアメタル上のオンプレミス、そしてハイブリッドを販売しています。SOC 2 Type II と ISO 27001 の取得を公表しています。データレジデンシーの要件でベンダーのクラウドが使えない Legal Ops や規制業種の Customer Success チームにとっては、どの機能よりもこの一覧のほうが評価期間を短くします。

## 価格の実態

Airia はもう公開の価格ページを出していません。airia.com/pricing は現在、ログインが必要なドキュメントにリダイレクトされます。2026年7月にこのページを記録していた第三者のトラッカーは、4つのプランで一致しています。**Free**、**Individual が月 $50**、**Team が月 $250**、**Enterprise は見積もり** です。各プランの実行回数とユーザー数の上限については食い違っているので、公表されている上限は自社アカウントで確認するまで未確定として扱ってください。Enterprise は AWS Marketplace 経由でも販売されており、プライベートオファーは既存の AWS 利用コミットメントに算入できます。Marketplace の年間および複数年のサブスクリプションは返金不可です。

ops チームにとっての実際の価格帯は Enterprise です。買っているのはガバナンスレジストリ、プライベートデプロイ、組織全体の MCP ゲートウェイであり、どれも $250 の Team プランでは意味を持たないからです。予算は [Zenity](/ja/tools/zenity/) と同じように組んでください。つまり、エージェント数とデプロイ形態を基準に交渉する、年5桁から6桁ドルのプラットフォーム契約としてです。Team プランは、調達部門が関与する前に少数のエージェントを構築・ルーティングしてみたい単一部門向けのパイロット手段です。

## 向いているのは

中堅以上の企業で、**エージェントをどこで構築するかを標準化しようとしている** CIO 配下のスタッフ、あるいは RevOps / Legal Ops のプラットフォームオーナーで、モデルルーティング、ツールガバナンス、コンプライアンス記録を同じ製品で持ちたい場合です。Airia が明確に勝つ限定条件はこれです。エージェントをオンプレミスまたは自社 AWS アカウントで動かす必要があり、それを EU AI Act と ISO 42001 に対応付け、本番で複数のモデルプロバイダーを使っている規制業種の企業です。

## 向いていないのは

エージェントがすでに [Copilot Studio](/ja/tools/microsoft-copilot-studio/) と [Foundry](/ja/tools/microsoft-foundry/) にある、Microsoft 中心のテナントです。その場合は、月 $15/ユーザーの [Microsoft Agent 365](/ja/tools/microsoft-agent-365/) が、すでに運用している Entra と Purview を使ってテナント内を統治します。また、エージェントが数体しかない約200人未満のチームにとっても買い間違いです。その規模なら、[AI エージェント運用スタック](/ja/stacks/ai-agent-ops-stack/)とエージェントごとの担当者名で、はるかに安く賄えます。

## 代替案との比較

- **[Microsoft Agent 365](/ja/tools/microsoft-agent-365/)**: Microsoft テナント内のガバナンスで、市場シェア上の既定解です。重要なエージェントが Copilot Studio、Foundry、Teams にあるならこれを選んでください。エージェントが Microsoft、Claude、ChatGPT、自社コードにまたがる場合、あるいは Microsoft のクラウドの外で動かす必要がある場合は Airia を選んでください。
- **[Zenity](/ja/tools/zenity/)**: 業務部門の人が Copilot Studio や Agentforce で作ったエージェントを取り締まる独立系の筆頭で、ツールコールの段階でのランタイムブロックを備えます。エージェントがすでにそれらのプラットフォーム上にあり、必要なのがガバナンスだけなら Zenity を選んでください。構築とルーティングも欲しいなら Airia です。
- **[Runlayer](/ja/tools/runlayer/)**: MCP に特化して急成長している新規参入で、SSO 同期のアクセス制御とセッション記録を備えたマネージド MCP ゲートウェイです。課題が、社員が Claude や Cursor を MCP サーバーにつないでいることなら、これを選んでください。MCP ゲートウェイがより広いモデル・エージェントポリシーの一部にすぎないなら Airia です。
- **[LiteLLM](/ja/tools/litellm/)** または **[Portkey](/ja/tools/portkey/)**: ガバナンスレジストリは不要で、モデルルーティングと支出管理だけが必要なら、このどちらかを選んでください。

どれも当てはまらないなら、つまりプラットフォームが1つで監査人からの要求もないなら、正しい支出はゼロです。プラットフォーム標準の監査ログと、書き込みの前の人間による承認以外には何も要りません。

## 注意点

- **プラットフォームの範囲が広いため、評価がエージェントビルダーのデモに流れがちです。** 契約を正当化するのはガバナンスのほうです。ガード: 価値検証は自社の監査上の問い(稼働中の3体のエージェントについて、レジストリのエントリ、リスク分類、担当者、モデル履歴を出す)を軸に設計し、ビルダーは別枠で採点してください。
- **価値はエージェントが Airia に移ることを前提にしています。** Copilot Studio や Agentforce に残るエージェントが得られるのはディスカバリーとポスチャのカバーであって、ルーティングとゲートウェイによる強制ではありません。ガード: 契約前に、12か月後にどこで構築されているかでエージェントを一覧にし、実際に Airia 上に載る分についてだけ Airia の価格を評価してください。
- **資金の出どころが1つです。** 創業者資本 $100M はベンチャーからの圧力をなくしますが、同時に会社のランウェイを1人の出資者のコミットメントに集中させます。ガード: 最初の契約期間は12か月にとどめ、レジストリと監査ログをオープンな形式でエクスポートできることを必須とし、MCP ゲートウェイについて書面の撤退計画を用意しておいてください。
- **公表されている上限は当てになりません。** 第三者の掲載情報は、プランごとの実行回数とシート数で食い違っています。ガード: 実行回数の上限、超過料金、そして「実行」の定義は、価格トラッカーからではなく発注書で確認してください。
