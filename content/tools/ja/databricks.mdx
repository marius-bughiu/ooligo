## 概要

このページが扱うのは Databricks の業務ユーザー向けエージェント層であり、レイクハウス本体ではありません。対象は Genie One と、その下で動く Genie Agents です。Genie One はチャット型の入り口で、Web、モバイル、Slack、Microsoft Teams から利用できます。営業、財務、CS の担当者が自然言語で質問すると、グラフ、その根拠となる SQL、引用元へのリンク付きで回答が返ります。製品名は 2026年6月9日に Genie から Genie One に変更され、Genie One のチャットは 2026年6月15日に一般提供（GA）となりました。Genie Agents は 7月9日に Genie Spaces から改称されたもので、アナリストが 1 つの業務（たとえばパイプラインとブッキング）向けに整備する範囲限定のエージェントです。Unity Catalog のテーブル、ビュー、metric view を最大 50 個、サンプル SQL、記述した指示を組み込めます。その下にあるのが Genie Ontology で、Databricks がダッシュボード、ノートブック、クエリ、データパイプラインから推定するビジネス文脈のマップです。デフォルトで有効ですが、まだ public preview です。2026年9月24日、Databricks はシアトルのクラウド表計算スタートアップ Row Zero を買収し、Genie にガバナンスの効いた表計算グリッドを持たせる計画です。提供開始日は発表されていません。

## RevOps と CS のスタックに登場する理由

- **すべての回答が 1 つのアイデンティティモデルに従います。** Genie Agent は作成者の埋め込みコンピュート認証情報で warehouse 上の SQL を実行しますが、データアクセスは常にエンドユーザー本人として評価されます。Unity Catalog の row filter と column mask は人ごとに適用され、各クエリはクエリ履歴で質問者に紐づきます。CSM は自分の担当顧客だけを、地域 VP は自分の地域だけを見ます。
- **CRM データをサードパーティのパイプラインなしで取り込めます。** Lakeflow Connect には Salesforce と HubSpot のマネージドコネクタがあり、Unity Catalog に直接書き込みます。RevOps チームは CRM 連携のためだけに [Fivetran](/ja/tools/fivetran/) を買わずに、商談、請求、プロダクト利用データを結合できます。
- **チームがすでに使っているエージェントから呼び出せます。** Genie One の MCP サーバーは 2026年9月22日に GA となりました。[Claude](/ja/tools/claude/)、[ChatGPT](/ja/tools/chatgpt/)、[Cursor](/ja/tools/cursor/) から OAuth 経由で Genie に質問でき、MCP Apps 対応クライアントでは Genie のグラフがインライン表示されます。逆方向では、Google Drive、Gmail、Microsoft 365、Atlassian、Slack、GitHub 向けの Databricks マネージドコネクタが 9月10日に GA となり、それぞれユーザー単位で認証されます。

## 価格の実態

シート課金はなく、現時点では Genie 層そのものはほぼ無料です。Databricks の課金ドキュメントによると、人間のユーザーによる Genie One と Genie Agents の利用は 2027年1月31日まで無料です。service principal（自動化や API 経由の呼び出し全般）は 2026年9月24日から標準価格で課金され、無料枠はありません。データチーム向けエージェントの Genie Code は、ユーザーごとに月 150 DBU の無料枠があり、超過分は Serverless Real-Time Inference SKU で課金されます。同じ期間は 25% のプロモーション割引が適用されます。2027年1月以降の Genie One の価格を Databricks は公表していません。

今実際に支払うのは warehouse の費用です。Genie Agents には pro または serverless の SQL warehouse が必要で、サードパーティの価格ガイドでは serverless SQL は AWS Premium の定価で 1 DBU あたり約 $0.70 とされています。私たちの試算では、1 時間 4 DBU の 2X-Small serverless warehouse を 1 日 10 時間、22 営業日稼働させると定価で月約 $620、1 時間 12 DBU の Small なら約 $1,850 です。すでに Databricks を運用しているなら、オペレーション部門 20〜100 人への展開で年間 $7,500〜$25,000 の warehouse コンピュート追加を見込み、さらに将来の Genie One 価格に備えた予備枠を確保してください。Databricks を運用していないなら、これはツール購入ではなくプラットフォームの意思決定です。

## 最適な対象

データチームがすでに Unity Catalog 付きの Databricks レイクハウスを運用している企業の RevOps および CS オペレーション責任者で、20〜200 人の業務ユーザーにパイプライン、更新、利用状況に関する質問を自分で解決してもらいたい（Slack、Teams、ブラウザで）、しかも 1 人ずつ BI シートを買いたくない、というケースです。

warehouse が Snowflake や BigQuery なら見送ってください。エージェントのためにデータを移す価値はほとんどありません。ユーザーが数値を編集する必要がある場合も見送りです。フォーキャストの提出やクォータ調整には writeback 対応ツールが必要です。そして、データチームの誰も整備済みエージェントの担当にならないなら見送ってください。整備されていない Genie は、もっともらしい誤答を返します。

## 代替ツールとの比較

**Microsoft Power BI Copilot** はインストールベースで最大の既存勢力で、F2 以上の有償 Fabric キャパシティならどれでも使えます。会社が Microsoft 365 中心で、ダッシュボードが主な成果物なら Power BI Copilot を選んでください。データがすでに Databricks にあり、別のセマンティックモデルではなく Unity Catalog でガバナンスされた回答が欲しいなら Genie One です。

**[Snowflake CoWork](/ja/tools/snowflake/)** は warehouse ネイティブの直接の競合で、トークン単位の AI Credits で課金されます。warehouse が Snowflake ならこちらを選んでください。両者は互換ではありません。

**[Hex](/ja/tools/hex/)** Threads は最も勢いのある新興勢力で、シート課金（Team は編集者 1 人あたり月 $75）です。AI の回答をアナリストが監査できるノートブックへ引き継げます。業務ユーザーが頼る前に、AI の回答をデータチームがレビューしたいなら Hex を選んでください。

**[Sigma](/ja/tools/sigma/)** は、同じ Databricks テーブル上で writeback アプリ（フォーキャスト提出、テリトリープラン）を作るのが目的なら勝ちます。Genie が特定したセグメントを定期的に CRM へ送るなら、[Hightouch](/ja/tools/hightouch/) と組み合わせてください。

営業と財務で「アクティブアカウント」の定義が一致しないせいでどれも合わないなら、先にモデルを直してください。[data warehouse vs CDP](/ja/learn/data-warehouse-vs-cdp/) を参照してください。

## 注意点

- **無料期間は 2027年1月31日に終わり、その後の価格は未公表です。** *対策:* 毎月 `system.billing.usage` を `sku_name = 'GENIE_FREE_USAGE'` で照会し、Genie Code の料金で換算したコストを把握してください。展開が日常業務に定着する前に、プロモーション終了後の価格を更新契約に明記させてください。
- **ベータ版の MCP エンドポイントは 2026年10月31日に廃止されます。** まだ `/api/2.0/mcp/genie` を呼んでいる連携は動かなくなります。*対策:* `/ai-gateway/mcp-services/system.ai.genie_one_mcp` へ移行し、OAuth スコープ `ai-gateway` を追加してください。旧スコープ `genie` だけの認可では新サービスに届きません。
- **自動化は最初の呼び出しから課金されます。** service principal で動く Slack ボット、スケジュールジョブ、Claude エージェントには無料枠がありません。*対策:* 対話的な利用は on-behalf-of-user で実行し、Genie の予算を設定し、service principal のワークロードにタグを付けて課金上で分けて見えるようにしてください。
- **Ontology は合意ではなく推定です。** 人がこれまでデータをどう照会してきたか（誤りも含めて）からビジネス上の意味を学習します。*対策:* 中核となる 20〜30 の指標を metric view として定義し、各エージェントにはそれだけを紐づけ、指示を変えるたびに固定のベンチマーク質問セットで精度を確認してください。
- **スケジュールタスクは最大でも 1 日 1 回です。** 2026年6月25日以降、1 時間ごとのスケジュールはサポートされていません。*対策:* 日中のアラート（たとえば $100,000 を超える商談がステージを後退した場合）は、Genie のスケジュールではなく warehouse のジョブか [Hightouch](/ja/tools/hightouch/) の同期で処理してください。
