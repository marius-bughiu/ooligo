Claude vs Perplexity é uma incompatibilidade de categoria que aparece comparada porque os dois são ferramentas de IA. Claude é um assistente de uso geral para raciocínio, escrita, código e análise de contexto longo. Perplexity é um search engine com um front-end LLM — feito para responder perguntas com fontes web ao vivo citadas. Eles se sobrepõem em "fazer uma pergunta e obter uma resposta", e divergem em todo o resto. A maioria dos knowledge workers deveria usar os dois para trabalhos diferentes.

## Onde Claude ganha

- **Raciocínio e análise de contexto longo.** Jogue um contrato de 200 páginas ou um trimestre de transcrições de call no Claude com janela de contexto de 1M e faça perguntas profundas. Perplexity não foi feito para isso.
- **Escrita, código e output estruturado.** Claude é ferramenta de escrita e engenharia primeiro. O LLM do Perplexity é bom mas otimizado para sintetizar resultados de busca, não para entregar deliverables.
- **Workflows agênticos e Skills.** Claude Code, MCP, Skills e tool use orquestrado te dão um agente programável. As capacidades agênticas do Perplexity são incipientes.

## Onde Perplexity ganha

- **Busca web ao vivo com citações.** O trabalho central do Perplexity é buscar a web ao vivo, citar fontes e devolver uma resposta sintetizada limpa. A busca web do Claude é boa mas o Perplexity vem otimizando exatamente esse workflow há mais tempo.
- **Velocidade para fact-finding.** Perguntas rápidas ("últimas notícias sobre os resultados de X", "preço atual do ZoomInfo") são 10x mais rápidas no Perplexity que no Claude.
- **Transparência de fontes.** Perplexity mostra suas fontes com destaque e inline. Claude cita mas o workflow é menos parecido com search engine.

## Quando usar os dois / Realidade de preço

A maioria dos knowledge workers modernos roda os dois diariamente. Perplexity para pesquisa "o que está acontecendo agora". Claude para "me ajude a pensar, escrever ou construir". Preços: Perplexity Pro é US$ 20 por mês. Claude Pro é US$ 20 por mês. Os dois têm tiers grátis utilizáveis; os dois têm tiers de potência (Perplexity Enterprise; Claude Max) para necessidades mais pesadas.

## Veredito

- **Escolha Claude** se o seu trabalho é raciocínio, escrita, código ou análise de documentos longos. Isso é a maior parte do knowledge work.
- **Escolha Perplexity** se o seu trabalho é pesado em pesquisa e se beneficia diariamente de fontes web ao vivo citadas — analistas, pesquisadores, jornalistas, sales reps fazendo pesquisa de account.
- **Use os dois** se você faz os dois tipos de trabalho, o que descreve a maioria dos cargos de ops e exec.

O único erro a evitar: usar Perplexity para tarefas em que Claude é melhor (escrita, código, análise long-form) só porque ele cita fontes. Citações não são o mesmo que raciocínio de qualidade.
