## 概要

GitHub Copilot は GitHub の AI コーディングアシスタントで、2026 年時点では 1 つのライセンスに 4 つの製品が入っています。VS Code、JetBrains、Visual Studio、Xcode でのインライン補完と次の編集候補、エディタ内のチャットとエージェントモード、issue を割り当てるとプルリクエストを返してくるクラウドのコーディングエージェント、そしてプルリクエスト上の Copilot code review と Copilot CLI です。市場の既存王者であり、Microsoft は 2026 年 1 月に Copilot の有料サブスクライバーが 470 万人、前年比 75% 増と発表しました。ほとんどのエンジニアリング組織では、オペレーション側の誰かが尋ねる前にすでに購入済みです。

6 月より前に書かれた比較記事を読む前に理解しておくべきことがあります。Copilot は課金モデルを変更しました。2026 年 6 月 1 日以降、すべてのプランは **GitHub AI Credits**（1 クレジット = 0.01 ドル）で計測され、各モデルの API 料金で入力・出力・キャッシュのトークンに応じて課金されます。補完と次の編集候補は有料プランでは引き続き無制限で、クレジットを消費しません。チャット、エージェントモード、クラウドエージェント、CLI、Spaces、code review はクレジットを消費します。

## オペレーションチームが行き当たる理由

GTM エンジニア、RevOps エンジニア、そして Python を書くリーガルオペレーションやリクルーティングオペレーションの担当者 1 人は、たいてい会社の GitHub 組織がすでに Copilot を持っているから使うことになります。彼らが持ち込む問いは 9 月の請求書の問いです。19 ドルの Business シートで、エージェント作業 — [n8n](/ja/tools/n8n/) のノード構築、Salesforce 同期スクリプト、MCP サーバー — にまだ足りるのか。それとも ops-dev グループは [Cursor](/ja/tools/cursor/) や Claude Code に移るべきか。

答えはエージェント作業の量次第です。クレジット削減が直撃したのはまさにそこだからです。6 月、7 月、8 月の間、GitHub は Business シートあたり 30 ドル、Enterprise シートあたり 70 ドルのプロモーション付き利用枠を提供しました。9 月 1 日にそれが標準の 19 ドル（1,900 クレジット）と 39 ドル（3,900 クレジット）に下がりました。夏の利用枠に合わせて使い方を決めていたチームは、9 月にプールの上限に達しました。

## 価格の実態

本日 GitHub のプランページとドキュメントで確認した定価です。

- **Free** — 月 2,000 回の補完と限定的なチャット。
- **Pro** — 月 10 ドル。10 ドルのベースクレジットに、GitHub が現在 5 ドルと表示している変動制の「flex」枠が付きます。
- **Pro+** — 月 39 ドル。flex 込みで 70 ドル分のクレジットと表示。
- **Max** — 月 100 ドル。flex 込みで 200 ドル分と表示。4 月 20 日に始まった個人向け新規登録の停止が 6 月に解除された際に追加されました。
- **Business** — 1 ユーザーあたり月 19 ドル、1,900 クレジットを請求単位全体でプール。
- **Enterprise** — 1 ユーザーあたり月 39 ドル、3,900 クレジットをプール。組織のコードベースをインデックスした GitHub.com 上のチャットが加わります。GitHub Enterprise Cloud が前提で、その分のユーザー単価が別途かかります。

実際の金額を決めるのは 3 つの課金ルールです。クレジットは**プール**されます。Business 10 シートで 19,000 クレジットを共有するため、エージェントを多用する 2 人が、補完しか使わない 8 人の分までプールを使い切ることがあります。組織では**有料の超過利用がデフォルトで有効**で、安いモデルへの自動フォールバックはありません。さらに 6 月 1 日以降、プライベートリポジトリでの Copilot code review は **GitHub Actions の実行時間（分）**も消費します。

Business を使う 10 人の ops-dev グループでの試算です。シート代は月 190 ドル。夏の使い方 — 1 人あたり 30 ドル分のクレジット — を続けると超過分は月 110 ドルで、実質 1 シート 30 ドルになります。それでも 40 ドルの Cursor Teams より安く、年払い 100 ドルの Claude Team プレミアムシートよりはるかに安いです。価格だけを理由に Copilot から離れる判断はほとんど成り立ちません。新規の組織はもう 1 点に注意してください。GitHub は 4 月 22 日、Free プランと Team プランの組織に対する Copilot Business のセルフサービス申し込みを停止し、新規の購入者を営業経由に回しています。私たちが確認した時点では再開は発表されていませんでした。

## 最適な対象

**コードがすでに GitHub 上にある会社**の RevOps エンジニア、GTM エンジニア、またはオペレーション寄りの開発者で、補完は一日中、エージェントの支援は週に数回ほしい人。そしてセキュリティチームが契約済みのベンダーを好む場合です。強みは守備範囲の広さで、1 シートで IDE、ターミナル、プルリクエスト、issue トラッカーをカバーし、許可するモデルを組織ポリシーで管理できます。

## 不向きな対象

「このリポジトリを読んで、統合を設計し、書いてテストして」といった長時間のエージェントセッションを毎日の主な作業スタイルにしているオペレーションのビルダーです。クレジットモデルが最も厳しく課金するのがこの使い方で、Claude Code と Cursor はまさにここでトークンを使うように作られています。安定したモデル一覧を求めるチームにも向きません。GitHub は 9 月 1 日に 6 つのモデルを廃止し、10 月 19 日にもさらに 6 つの廃止を予定しています。

## 代替ツールとの比較

- **[Cursor](/ja/tools/cursor/)** — IDE で最も強力な挑戦者。個人 20 ドル、Teams は 1 ユーザーあたり 40 ドル。作業がエディタ内で完結し、より高性能なエージェント体験がほしく、シート単価がおよそ 2 倍になってもよい場合に選びます。
- **Claude Code** — [Claude](/ja/tools/claude/) Team のシートに含まれます（年払いで標準 20 ドル、プレミアム 100 ドル）。このセグメントで最も急成長しているツールです。作業がターミナル中心で、リポジトリ全体や MCP で接続したシステムに対して長時間のエージェントセッションを回す場合に選びます。
- **OpenAI Codex** — [ChatGPT](/ja/tools/chatgpt/) Business に含まれます。会社が OpenAI に標準化していて、ベンダーを増やしたくない場合に選びます。

補完には Copilot を使い、エージェント作業には Claude Code を追加する組み合わせは一般的で、理にかなった分担です。[Claude vs Cursor](/ja/comparisons/claude-vs-cursor/) と [AI コーディングアシスタントのベスト](/ja/comparisons/best-ai-coding-assistants/) も参照してください。

## 注意点

- **プールは静かに減り、その後に請求書が届きます。** 超過利用はデフォルトで有効で、午後いっぱいクラウドエージェントを動かした 1 人が全員分のクレジットを使い切ります。**対策:** 最初の丸 1 か月が始まる前に、エージェントを多用するユーザーにはユーザー単位の予算を、AI Controls には組織の予算を設定します。上限で確実に止めたい場合は「AI credits paid usage」ポリシーを無効にします。
- **モデルの入れ替えが固定したワークフローを壊します。** 廃止は数週間ごとにやってきて、あるモデルに合わせて調整したプロンプトやカスタムエージェントは、後継モデルで挙動が変わります。**対策:** GitHub Copilot の changelog を購読し、依存しているエージェントごとに小さな回帰テスト用プロンプトのセットを用意し、許可するモデルは各ユーザーの選択ではなくグローバルモデルポリシーで設定します。
- **AI レビューはセキュリティレビューではありません。** 8 月に広まった Wiz のレポートは、同社の Red Agent が Snowflake の公開リポジトリ `snowflake-connector-net` の GitHub Actions ワークフローでコマンドインジェクションを見つけ、それが Jira の認証情報を露出させていたことを示しました。Snowflake は同日中に修正し、認証情報をローテーションしました。脆弱な行を Copilot が書いたかどうかは争いがあり、Wiz は主張を「Copilot がプルリクエストをレビューしたのに問題を指摘しなかった」に絞っています。**対策:** すべてのワークフローファイルについて、CodeQL などの静的スキャナーと人間の承認者を必須チェックとして残し、Copilot のレビューは判断材料の 1 つとして扱い、決して最終関門にしないでください。
