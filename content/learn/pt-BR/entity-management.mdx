Gestão de entidades é a disciplina de manter a estrutura organizacional corporativa de uma empresa — cada entidade jurídica, sua jurisdição de constituição, seus diretores e conselheiros, suas obrigações de arquivamento anual, suas contas bancárias, suas subsidiárias, seus acordos intercompany e a cap table quando aplicável. Para uma startup com uma única entidade, isso é uma planilha de cinco linhas. Para uma multinacional com mais de 200 subsidiárias, é uma equipe em tempo integral usando software especializado.

## O que a gestão de entidades rastreia

Para cada entidade jurídica, os dados operacionais incluem:

- **Identidade.** Nome legal, data de constituição, jurisdição, tipo de entidade (Inc, LLC, GmbH, BV, Pty Ltd), CNPJ/tax ID
- **Governança.** Diretores, conselheiros, agente registrado, escritório registrado, composição do conselho
- **Arquivamentos.** Relatórios anuais, imposto de franquia, renovações do agente registrado, arquivamentos de beneficiários finais (CTA nos EUA, equivalente em outras jurisdições)
- **Bancário.** Signatários autorizados por conta, limites de autoridade de assinatura
- **Capitalização.** Detentores de equity, classes de ações, opções pendentes (quando aplicável)
- **Estrutura de subsidiárias.** Relações controladora-subsidiária, percentuais de participação, fluxos de dividendos
- **Contratos materiais.** Acordos de serviços intercompany, licenciamento de PI, documentação de preços de transferência

O sistema de gestão de entidades é a fonte da verdade sobre quem pode assinar o quê em nome de qual entidade — diretamente relevante para toda execução de contrato.

## Por que a gestão de entidades importa mais do que as empresas percebem

Falhas na gestão de entidades são silenciosas até que não são mais:

- O arquivamento anual de uma subsidiária é perdido, a entidade é administrativamente dissolvida e um contrato executado em nome dessa entidade se torna inexequível
- Uma mudança de autoridade de assinatura não é refletida nos registros da entidade, e o contrato é assinado por alguém sem autoridade
- Uma solicitação de due diligence em M&A pede o organograma e a estrutura de beneficiários finais; produzi-lo leva três semanas
- Uma nova lei tributária (CTA, Pillar 2, reporting país a país) exige dados que o sistema de gestão de entidades nunca foi configurado para rastrear

Cada um desses cenários é evitável com uma gestão de entidades disciplinada; cada um fica caro quando negligenciado.

## Quando você precisa de software de gestão de entidades

O limite é a quantidade de entidades mais o espalhamento jurisdicional:

- **1-3 entidades, jurisdição única:** Uma planilha mais um calendário. O rastreamento de datas de renovação é o essencial.
- **4-15 entidades, único país:** Ferramentas leves (Carta para startups ancoradas em cap table, Diligent Entities para empresas estabelecidas).
- **15-50 entidades, múltiplos países:** Plataformas especializadas (Diligent Entities, GlobalScape, Athennian, hubsync) com workflow para arquivamentos, rastreamento de autoridade de assinatura e relatórios consolidados.
- **50+ entidades, global:** Plataformas enterprise com integração profunda com fiscal e tesouraria. Frequentemente combinadas com um provedor de serviços de gestão de entidades (CSC, Wolters Kluwer CT) para os arquivamentos efetivos.

## Como operacionalizar

1. **Uma fonte da verdade.** Todos os dados de entidades vivem em uma plataforma; em todos os outros lugares (CLM, bancário, contabilidade) se puxa via API. Múltiplas fontes da verdade produzem registros divergentes e arquivamentos perdidos.
2. **Calendário de arquivamentos com alertas automáticos.** Todo arquivamento anual, imposto de franquia, renovação de agente registrado, atualização de beneficiários finais — calendário com lembretes de 90/60/30 dias para o responsável.
3. **Matriz de autoridade de assinatura integrada com o [CLM](/pt-BR/learn/contract-lifecycle-management/).** Quando um contrato entra no CLM, o sistema verifica os dados de gestão de entidades para identificar quem pode efetivamente assinar por aquela entidade naquele limite de valor.
4. **Trilha de auditoria para cada mudança.** Mudança de diretor, mudança de conselheiro, mudança de autoridade de assinatura — tudo registrado com data, documento fonte, aprovador. Crucial para due diligence e defesa em disputas.
5. **Revisão anual de higiene de entidades.** Uma vez por ano, reconcilie os registros de entidades com os registros estaduais/regulatórios. Identifique e dissolva entidades dormentes; consolide onde a estrutura não faz mais sentido.
