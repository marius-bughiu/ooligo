## 概要

Entegrata は、法律事務所向けにあらかじめ構築されたデータレイクハウスです。大規模事務所がすでに運用しているタイムキーピング・請求、財務、人事、CRM、インテーク、文書管理などのシステムからデータを取り出し、1つの法務データスキーマにマッピングします。このスキーマには約5,000のフィールドがあり、2025年3月のシードラウンド時点の3,500から増えています。その結果、クライアント、案件、タイムキーパーごとに整理された単一のレコードができ、レポーティング、他のシステム、AI ツールのすべてがそこからデータを読み取れます。基盤は Microsoft Azure で、その下で Databricks が動いており、Entegrata がホストする形か、事務所自身の Azure テナントにデプロイする形のどちらかで運用します。法律事務所の業務向けに作られた Power BI レポートのライブラリも提供しています。

同社は2023年に Tom Baldwin が創業し、New York を拠点としています。Baldwin は Cadwalader、Reed Smith、Sheppard Mullin で CIO 兼チーフナレッジオフィサーを務めていました。2025年3月には、Chicago Ventures がリードし、OnDean Forward と The LegalTech Fund が参加する450万ドルのシードラウンドを実施しました。SOC 2 Type II を取得しており、Drata による継続的なコンプライアンス監視を行っています。

## Legal Ops のスタックに登場する理由

- **多くの大規模事務所が行き詰まっている「自社構築か購入か」の問いに答えを出します。** 2026年8月25日、ILTACON に合わせて、Entegrata は12か月で顧客を2倍以上の20事務所に増やしたと発表しました。最近加わった顧客には Cleary Gottlieb、Wilson Sonsini、Kilpatrick Townsend があり、以前からの顧客には Mayer Brown、Vinson & Elkins、Pillsbury がいます。Baker Botts は、自社構築か購入かを検討する正式なコンサルティング契約を経て、2026年7月に Entegrata を選びました。同事務所の CIO である Rick Boulin は、社内で構築するパイプラインはすべて「新しい機能の提供から奪われる時間と人材」だと述べています。
- **コネクタの数こそが製品です。** コネクタは2025年3月の15以上から、2026年3月には33、2026年8月には50以上に増え、このとき [iManage](/ja/tools/imanage/) との連携が追加されました。サイトには Elite 3E、[Aderant](/ja/tools/aderant/)、[Intapp](/ja/tools/intapp/) の Intake、Deal、Walls、Terms、[NetDocuments](/ja/tools/netdocuments/)、[Litera](/ja/tools/litera/)、[Salesforce](/ja/tools/salesforce/)、[Workday](/ja/tools/workday/)、Dayforce、ADP、Microsoft Graph が掲載されています。そのひとつひとつが、自社のデータチームが書いて保守する必要のないパイプラインです。
- **Metrics により、財務チームは1つの数値に1つの定義を持てます。** 2026年8月24日にリリースされた Metrics は、ガバナンスの効いたセマンティックレイヤーで、実現率（realization）、稼働率（utilization）、WIP、弁護士1人あたり売上など、100以上の収益指標があらかじめ用意されています。バージョン履歴と監査証跡を保持し、同じ計算を Power BI、SSRS、Excel、基幹業務システム、AI ツールに配信します。Databricks 上で動くため、更新は夜間バッチではなく数分で終わります。3つのレポートが3つの異なる実現率を示すパートナー会議の問題は、これで解決します。
- **AI プロジェクトに必要となるデータレイヤーです。** Entegrata によると、顧客のレイクハウス全体で1日あたり10億行近くを取り込んでおり、AI クライアントがガバナンスの効いたデータを直接照会できる MCP サーバーを開発中です。[MCP サーバーとは何か](/ja/learn/mcp-server-explained/)も参照してください。

## 実際の価格

**見積もりのみです。2026年9月15日に見積もりのみであることを確認しました。** Entegrata は料金表を公開しておらず、私たちが確認したサードパーティのディレクトリにも価格は掲載されていません。予算は1項目ではなく2項目で組んでください。Entegrata のサブスクリプションと、レイクハウスが稼働する Azure と Databricks のリソースです。自社テナントにデプロイする場合、これらのリソースは自社の Azure サブスクリプションに置かれるため、最初の打ち合わせでコンピュートとストレージの費用を誰が負担するのかを確認してください。

見積もりと比較すべき数字は、自社で構築した場合のコストです。2026年のあるエンタープライズ向けレイクハウスのガイドでは、3人のデータエンジニアリングチームに年間60万ドル、アーキテクト、ガバナンス担当者、トレーニングを加えると120万ドル以上の予算を見込んでいます。DataWarrant のようなコンサルティング会社を通じて Microsoft Fabric 上に法律事務所向けの基盤を構築しても、稼働開始後のパイプラインは自社で抱えることになります。実務上の判断基準はこうです。Entegrata の見積もりとコンピュート費用の合計が、10以上のソースのパイプラインを保守するために代わりに雇うことになる1〜2人のデータエンジニアの費用より少ないなら、購入してください。

## 最適な利用者

弁護士100人以上の法律事務所の CIO、CFO、プライシング・分析部門の責任者に向いています（Legaltech Hub は Entegrata の顧客を100–499人と500人以上の規模帯に分類しています）。Microsoft と Azure の環境を運用し、Elite 3E または Aderant、Intapp、iManage または NetDocuments、そして一度も突き合わせたことのない HRIS が混在している事務所に合います。求めているのが、今は Power BI に、将来は AI ツールにデータを供給する、ガバナンスの効いた事務所全体のデータセット1つであり、その代替案がデータエンジニアリングチームの採用である場合には、正しい選択です。

弁護士がおおむね100人未満で、事務所管理システムから財務ダッシュボードを作れれば十分なら、見送ってください。パッケージ型の BI ツールのほうが安く実現できます。事務所が Snowflake や AWS に標準化している場合も見送ってください。Entegrata は Azure 専用だからです。

## 代替製品との比較

**BigHand Business Intelligence (powered by Iridium)** は、定評のあるパッケージ型 BI の選択肢です。BigHand は2022年に Iridium Technology を買収しており、Iridium BI は Aderant Expert、Elite 3E、Elite Enterprise に対応しています。1つの事務所管理システムを基にした財務レポーティング（売上、収益性、案件予算）が目的なら、こちらを選んでください。人事、DMS、CRM、インテークのデータにもまたがる場合は、Entegrata を選んでください。

**Litera Foundation** は、大規模事務所でクライアント、案件、実績データの管理にすでに導入されている既存製品です。タイムキーピング・請求、docketing、CRM からデータを集め、ナレッジ管理、実績管理、リレーションシップ管理に活用します。実績の検索やピッチ支援が目的なら、こちらを選んでください。財務、IT、AI の各チームがその上に構築する汎用のデータレイヤーが目的なら、Entegrata を選んでください。

**事務所管理システムのベンダー自身のデータ連携**が最も速く進んでいます。Elite の Data Connect はガバナンスの効いた 3E Cloud のデータを Microsoft Fabric に取り込み、Intapp は2025年6月から Snowflake と提携して、事務所全体のデータを DealCloud と合わせて分析できるようにしています。1つのベンダーのデータがレポート対象の80%を占めるなら、これらのいずれかを選んでください。データの大半を持つベンダーが1社もないなら、Entegrata を選んでください。

どれも合わない場合、つまり社内に強力なデータチームがあり、すでに Fabric や Snowflake を標準としているなら、自社で構築してください。その場合でも Metrics の考え方は取り入れてください。ダッシュボードを1つでも作る前に、実現率と稼働率を、ガバナンスの効いた1か所で一度だけ定義しておくことです。

## 注意点

- **設立間もないベンダーで、参照顧客の基盤が小さいです。** Entegrata は2023年の創業で、顧客は20事務所、開示されている資金調達はシードラウンドのみです。*対策：*自社と同じ事務所管理システムを使っている参照顧客を2社紹介してもらい、データのポータビリティを注文書に明記してください。テナントにデプロイする場合は、解約時にもレイクハウスのテーブルが自社の Azure サブスクリプションに残ることを確認してください。
- **請求が2つあります。** サブスクリプションはコストの一部にすぎず、Databricks のコンピュート費用は取り込む行数と更新頻度に応じて増えます。*対策：*自社のデータ量でのコンピュート費用の見積もりを書面で受け取り、初日から Azure の予算アラートを設定してください。
- **Metrics はリリースされたばかりです。** 2026年8月24日のリリースのため、会計年度を丸1年運用した事務所はまだほとんどありません。*対策：*5〜10個の収益指標でパイロットを行い、既存のレポートを廃止する前に、事務所管理システムの月末の数値と突き合わせてください。
- **MCP サーバーは製品ではなくロードマップです。** 2026年8月時点で開発中と発表されており、リリース日は示されていませんでした。*対策：*ビジネスケースは現在提供されている Power BI と Metrics のアウトプットに基づいて組み立て、AI クライアントからのアクセスは上振れ要素として扱ってください。
- **Azure 専用です。** データチームが Snowflake や AWS を運用している事務所では、管理するクラウドが2つになります。*対策：*データウェアハウスの標準が Snowflake なら、Entegrata のデモを受ける前に、Intapp–Snowflake のルートや自社構築の費用を見積もってください。
