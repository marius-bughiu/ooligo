## これは何か

HackerRank は技術アセスメントのプラットフォームで、2026 年を別の問いに沿った作り直しに費やしました。候補者がアルゴリズムを暗記から書けるかではなく、AI コーディングアシスタントをどう指示し、確認し、修正するかを見る、という問いです。2009 年に InterviewStreet として創業し、現在も独立企業のままで、直近の調達は 2022 年 3 月、累計はおよそ $110M、顧客数 2,500 社、開発者コミュニティは 26M 人超と公表しています。

3 つのプロダクトが 1 つのプラットフォームに載っています。Screen は非同期アセスメント、Interview はライブのペアプログラミング、そして 2026 年 1 月に投入された AI 面接官の Chakra は、追加質問で候補者の思考を掘り下げる対話型スクリーニングを行い、現在は面接の途中でインラインのコードエディタを開きます。

2026 年 7 月のリリースはアセスメントの実行環境そのものを変えました。候補者はエージェント型 IDE で作業し、モデルを Claude、Gemini、GPT から選びます。スコアリングはチャットログではなく IDE の操作を読み取り、候補者が AI の提案をどれを受け入れ、どれを却下し、どれを書き直したかを、初期コードと最終コードの Diff View で提示します。Plan Mode では、何かを書き始める前に AI と一緒に方針を設計させます。新規の plan-build-review リポジトリ課題 159 件は、MERN、Spring Boot、Django、Go、.NET といった本番相当のコードベースに候補者を置き、サポートチケットを解決させます。

## Recruiting スタックで採用される理由

- **AI の使用を止めにいくのではなく、使い方を採点します。** guarded と unguarded のアシスト モードは設問ごとに設定し、AI Fluency スコアは候補者がモデルの出力をどう扱ったかから算出されます。もう一方の道、つまりアシスタントを禁止して剽窃検知をいたちごっこで回す運用は、実務では現れない行動を測っていることになります。
- **エントリー階層に公開価格が付きました。** HackerRank は 2026 年まで見積もり販売のみでしたが、2026 年 9 月時点でセルフサーブ 2 階層が価格ページに載っており、最初の技術職採用を進めるチームから調達サイクルを 1 つ取り除きます。
- **どの階層でもプラットフォームユーザーは無制限です。** HackerRank の課金単位はシートではなく候補者の受験回数なので、面接パネルのエンジニア全員にアカウントを配っても請求額は動きません。シート課金のベンダーでは、候補者と実際に働く人たちに提出物を読ませること自体が高くつきます。

## 価格

[hackerrank.com/work/pricing](https://www.hackerrank.com/work/pricing) を 2026-09-03 に確認しました。

- **Starter — 年額請求で $79/月**（$948/年、候補者の受験 60 回）、または**月額請求で $99/月**（5 回/月）。ユーザー無制限、ライブラリ設問 2,000 問超、Chakra、Screen、Interview、剽窃検知、セッションリプレイ、デバイス検知。ATS なし、カレンダーなし、API なし、SSO なし。
- **Pro — 年額請求で $419/月**（$5,028/年、受験 360 回）、または**月額請求で $529/月**（30 回/月）。[Greenhouse](/ja/tools/greenhouse/)、[Lever](/ja/tools/lever/)、[Ashby](/ja/tools/ashby/) との ATS 連携、Gmail と Outlook のカレンダー同期、4,000 問超のライブラリが加わります。
- **Enterprise — 見積もり。** API アクセス、HackerRank の MCP サーバー、流出設問への保護、80 職種向けの認定アセスメント、SSO/SCIM、監査ログ、プロクタリング用デスクトップアプリ、22 種超の ATS 連携を持つ唯一の階層です。
- **超過分は 1 受験あたり $20** で、公開されている 2 階層に共通です。Pro の年額請求では受験を $15 で事前購入できます。
- 年額請求は両階層とも月額請求のおよそ 20% 下に収まります。

実際の価格帯: SpendHound が HackerRank の顧客 160 社から匿名化した契約データでは、SMB の平均支出が $4,860/年（17 社、従業員 50〜1,000 人）、エンタープライズの平均支出が $84,947/年（35 社、従業員 1,000 人超）です。

**階層を決める受験回数の計算。** Pro は Starter より $4,080/年 高く、受験を 300 回追加します。超過単価 $20 では、同じ受験を Starter に積み増して買うと 204 回でちょうど同じ $4,080 に達します。つまり受験コストだけで見れば、年 264 回あたりまでは Starter と超過購入の方が安く付きます。その手前で Pro に移るのは、Starter がどの価格でも持たない ATS 連携が必要なとき、という理由に限ります。

## 向いている相手

- Pro で年 25〜60 人のエンジニアを採用する開発組織 — 1 採用あたり 6 回のアセスメントなら、360 回で採用ファネルを賄えます
- 候補者が AI を使う前提でループを組んでおり、それを取り締まるのではなく評価に反映させたいチーム
- 最初の技術職採用に取り組む小規模チーム。Starter の $948/年 とシート無制限は、見積もりを待つより有利です

プログラマティックなアクセスが要件なら選択肢から外れます。ここでは API と MCP が Enterprise 専用である一方、[Codility](/ja/tools/codility/) は $6,000/年 の Scale 階層で MCP による課題作成を販売しています。

## 注意点

- **MCP と API は Enterprise の見積もりの向こう側にあります。** HackerRank の MCP サーバーは 2026 年 7 月に読み取り専用かつ提供限定で登場しました。ガード: アセスメント結果を社内ダッシュボードやエージェントに流すことが必須要件なら、Pro を確定する前に Enterprise の見積もりを取り、自社アカウントでの MCP 提供可否を書面で確認してください。
- **流出設問への保護は Enterprise 専用ですが、設問ライブラリはどの階層でもスクリーニングの信号そのものです。** ガード: Starter と Pro では、年 20 回を超えてスクリーニングする職種ごとに自社設問を書き、四半期ごとに入れ替えてください。
- **エントリー階層はコモディティ化しており、表示価格で選ぶのはコイン投げです。** [CodeSignal](/ja/tools/codesignal/) の Build プランは同じ 60 クレジット、同じ超過単価 $20 で $948/年。CoderPad の Starter は 60 回で $960/年。Codility の Starter は 120 招待で $1,200/年 — 1 招待 $10 で、HackerRank の $15.80 より安いものの、プラットフォームユーザーは 1 人に制限されます。ガード: 各ベンダーがエントリー線の上に何を残しているか、そして自社の実際の量における 1 受験あたり単価で判断し、表示価格を見るのはその後にしてください。
- **AI Fluency スコアは guarded と unguarded の間で比較できません。** ガード: 展開前に職種ごとにモードを固定し、変更する場合はコホートの基準値を取り直してください。guarded のコホートに対して unguarded で採点された候補者は、同一条件の読み取りにはなりません。
- **コーディング課題の成績は、入社後のエンジニアとしての有効性との相関が弱いままです。** ガード: アセスメントは[構造化面接](/ja/learn/structured-interviewing/)と設計課題と組み合わせ、スコアは順位付けではなく足切りフィルタとして扱ってください。
