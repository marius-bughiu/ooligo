## 概要

Vapi は、AI 電話エージェントを構築する開発者向けのインフラです。音声認識、LLM、音声合成、ターンテイキング、割り込み、電話回線というリアルタイムのループをオーケストレーションし、そのループの各コンポーネントを自分で選べるようにします。ダッシュボードまたは API でアシスタントを設定し、ツールを追加し、電話番号か SIP トランクに接続すると、Vapi にはホスティング料として1分あたり $0.05 を支払い、モデル・音声・文字起こしの各プロバイダーはそれぞれの原価で課金します。位置づけは [Retell AI](/ja/tools/retell-ai/) と同じ「自社で構築する」レイヤーであり、PolyAI や Parloa のようなマネージドサービスのレイヤーではありません。

サンフランシスコに拠点を置く同社は、YC 出資の会議メモアプリ Superpowered として始まり、2023年末に CEO Jordan Dearsley のもとで音声 API へピボットしました。2026年5月12日には、Peak XV 主導、M12、Kleiner Perkins、Bessemer が参加する $50M のシリーズ B を発表しました。報道ベースの評価額は約 $500M、累計調達額は $72M です。Vapi は通話数が10億件、開発者数が100万人を超え、エンタープライズ ARR が前回ラウンドから10倍に伸びたとしています。代表的な顧客は Amazon Ring で、40社以上の音声ベンダーを評価したうえで、現在はインバウンドのサポート通話をすべて Vapi 経由でルーティングしています。Ring のソフトウェア開発担当 VP は、ゼロから本番稼働まで2週間だったと述べています。

## CX・サポートのスタックに選ばれる理由

- **すべてのコンポーネントを差し替えられます。** Deepgram などの文字起こし、OpenAI・Anthropic・Google のモデル、ElevenLabs または Vapi 独自の音声、Twilio・Telnyx・Vonage または自社の SIP トランク。より安いモデルや優れた音声が出たら、プラットフォームを移行せず設定を1つ変えるだけです。モデルはプロバイダー原価で、上乗せなしに課金されます。
- **Squads によるマルチエージェント通話。** ハンドオフツールが、コンテキストと抽出済みの変数を保ったまま通話中の会話を別のアシスタントへ引き継ぎます。認証、請求、エスカレーションの各エージェントをそれぞれ小さく、テストしやすく保てます。
- **Composer が最初のドラフトを作ります。** 2026年初めにアルファ版として公開され、8月に改良されたダッシュボード内アシスタントで、自然言語の説明から番号・ツール・連携を備えたアシスタントを作成します。Vapi によれば、Composer 利用者は通話時間100分に到達する確率が約3倍高いとのことです。ベンダー発表の数字ですが、オンボーディングデータで通常見られる傾向と一致しています。
- **双方向の MCP。** `https://mcp.vapi.ai/mcp` の公式 MCP サーバーにより、Claude などのクライアントからアシスタントの一覧表示・作成、通話の発信・予約、通話記録の取得ができます。これとは別に、MCP ツールを使えば、稼働中の音声エージェントが通話の途中で自社の MCP サーバーを呼び出せます。
- **テスト機能が標準装備です。** シミュレーションスイート（2026年8月）で、デプロイ前にスクリプト化した発信者をアシスタントに当てられます。全プランで利用できます。

## 実際の価格

$0.05 のホスティング料は、請求書で最も小さい項目です。Vapi 自身の計算ツールでは、1,000分で月額 $82〜$129 となります。内訳はホスティング $50、文字起こし約 $10、LLM $8〜$45、ElevenLabs の音声 $15〜$24 です。これに電話回線が加わります。Twilio は着信 $0.008/分、発信 $0.014/分、Telnyx は $0.0055/分、Vapi 独自の SIP は無料です。一般的な構成で、**すべて込みで1分あたり約 $0.09〜$0.14** になります。最先端モデルやプレミアム音声を使えば、これを上回ります。

次にプランの層があります。従量課金では同時通話4件、番号1つ、データ保持14日、SLA なしの Discord またはメールサポートに制限されます。Core は月額 $29 で同時通話10件、サポート SLA は2営業日です。Pro はホスティング料の10%（最低月額 $999）で、同時通話30件、Slack サポート、99% の稼働率 SLA が付きます。Premier は個別見積もりで、99.9% の SLA と P0 インシデントへの1時間以内の対応が付きます。追加の同時通話枠は1回線あたり月額 $10 です。HIPAA は BAA を含む**月額 $2,000 のアドオン**です。

一般的な構成で月10万分を処理する場合、利用料は約 $9K〜$14K に Pro の最低額 $999 が加わり、年間でおよそ $120K〜$180K（HIPAA を除く）になります。大量利用時の Retell と同じ価格帯で、Vapi は小規模な構築では安く、大規模になるほど予測しにくくなります。

## 最適な用途

音声エージェントを他の本番サービスと同じように運用できるエンジニアを抱える CX-ops・サポートエンジニアリングのチームで、インバウンドのサポート回線、トリアージ、予約受付、アウトバウンドのリマインダーを月約1万分から数百万分の規模で構築し、パッケージを受け入れるのではなくモデル・音声・通信キャリアを自分たちで選びたい場合に最適です。

チームに Webhook を書ける人がいない場合、ベンダーにエージェントの設計と運用を任せたい場合、または限られた予算で HIPAA が必要な小規模クリニックの場合は見送ってください。月額 $2,000 あれば、他社で相当な分数を購入できます。

## 代替ツールとの比較

**[Retell AI](/ja/tools/retell-ai/)** はこのレイヤーのもう1つの定番です。音声インフラ、プラットフォーム音声、電話回線を1つのメーターにまとめ（一般的な構成で約 $0.15/分）、BAA をオンラインで締結でき、組み込みの QA で通話を評価します。予測しやすい単一料金と、月額 $2,000 のアドオンなしの HIPAA を求めるなら Retell を選んでください。エンジニアがすべてのコンポーネントを自分で選び、差し替えたい場合や、より広い連携範囲と MCP サーバーが必要な場合は Vapi を選んでください。

**[ElevenLabs Agents](/ja/tools/elevenlabs/)** は最も急成長している新規参入者で、ElevenLabs 独自の音声を基盤としています。音声品質と対応言語数がプロジェクトの決め手になるなら選んでください。**Synthflow** はノーコードの選択肢で、構築担当者がエンジニアでないチーム向けです。導入までベンダーに任せたいなら、マネージド型を購入してください。[PolyAI](/ja/tools/polyai/)、[Parloa](/ja/tools/parloa/)、[Sierra](/ja/tools/sierra/) が候補です。

どれも合わない場合は、Vapi の無料クレジット $5 を最も件数の多い問い合わせ種別に使い、解決1件あたりの実測コストを現在の有人対応の1件あたりコストと比較してから契約してください。

## 注意点

- **請求には4〜5種類のメーターがあります。** ホスティング、文字起こし、モデル、音声、電話回線はそれぞれ独立して変動します。対策：料金計算ツールで実際の構成をそのまま組み、パイロットを実施し、見出しの $0.05 ではなく、通話ログで実測した平均処理時間と1通話あたりのコストから予測してください。
- **固定料金が予告なく変わります。** Vapi のサポートフォーラムで、ある顧客が HIPAA アドオンが予告なく月額 $2,000 に倍増したこと、そして異議を申し立てた $1,000 の請求に8日間回答がなかったことを報告しています。対策：本番トラフィックが依存する前に、HIPAA、同時通話枠、サクセスパッケージの価格を、通知期間付きの発注書に明記させてください。
- **従量課金プランのサポートは手薄です。** コミュニティの投稿では返信の間隔が2〜3日空くと報告されており、デフォルトのプランには SLA がありません。対策：回線が売上に直結する通話を担う前に Pro か Premier へ移行し、2026年4月14日に発生した1時間55分の SIP 障害のような事態に備えて、IVR に有人対応のフォールバック番号を用意してください。
- **デフォルトの同時通話数が少なすぎます。** 従量課金の同時通話4件では、最初のピーク時にトラフィックを取りこぼします。対策：ピーク時間帯をシミュレーションで負荷テストし、最初の話し中が発生する前、つまりローンチ前に1回線 $10 で同時通話枠を購入してください。
