O ATS (Applicant Tracking System) e o Recruiting CRM são duas ferramentas relacionadas, mas diferentes, no stack de recruiting moderno. O ATS rastreia candidatos *que se candidataram* pelo funil de contratação — candidatura → triagem → entrevista → oferta → contratação. O recruiting CRM gerencia o relacionamento mais amplo com candidatos — incluindo todos com quem a equipe já interagiu, contatou, conversou ou rejeitou, independentemente de terem se candidatado. A maioria das equipes em growth-stage e enterprise precisa de ambos; PMEs geralmente começam apenas com um ATS e adicionam o CRM depois.

## A diferença substancial

| Capacidade | ATS | Recruiting CRM |
|---|---|---|
| Rastreia candidatos ativos | ✓ | ✓ (às vezes) |
| Rastreia candidatos passivos (sourced, nunca se candidataram) | Não | ✓ |
| Rastreia candidatos rejeitados para re-engajamento | Limitado | ✓ |
| Postagem de vagas + distribuição multi-board | ✓ | Não |
| Agendamento de entrevistas e scorecards | ✓ | Não |
| Gestão de ofertas | ✓ | Não |
| Sequências de e-mail outbound para candidatos | Limitado | ✓ |
| Pipelining e nurture de talentos | Não | ✓ |
| Workspace diário do sourcer / recruiter | Não | ✓ |
| Relatórios de métricas de time-to-hire | ✓ | Limitado |

Um ATS é o sistema de rastreamento do funil. Um recruiting CRM é o sistema de rastreamento de relacionamentos. Eles se sobrepõem no "banco de dados de candidatos", mas divergem muito no workflow.

## Quando você precisa de ambos

A progressão natural:

1. **Estágio 1 (menos de 50 contratações/ano):** Apenas um ATS ([Workable](/pt-BR/tools/workable/), [Ashby](/pt-BR/tools/ashby/), [Greenhouse](/pt-BR/tools/greenhouse/)). Candidatos sourced são adicionados diretamente à vaga relevante; o outbound é informal.
2. **Estágio 2 (50-200 contratações/ano):** Adicione um recruiting CRM ([Gem](/pt-BR/tools/gem/) é a escolha dominante para essa transição) sobre o ATS. Sourcers trabalham no CRM; recruiters trabalham no ATS; os dados sincronizam.
3. **Estágio 3 (200+ contratações/ano):** Ambas as ferramentas são maduras e integradas; às vezes uma terceira plataforma de talent intelligence (Findem, Eightfold) fica acima para analytics em nível de portfólio.

Algumas plataformas tentam ser as duas coisas. [Bullhorn](/pt-BR/tools/bullhorn/) é ATS+CRM para empresas de staffing (categoria diferente de ATS corporativo). [Gem](/pt-BR/tools/gem/) se posiciona como "substituto do ATS" para alguns segmentos, mas é fundamentalmente um CRM com features leves de ATS. O Talent Cloud do iCIMS empacota ambos, mas é mais pesado do que a maioria das equipes precisa.

## O que um ATS especificamente faz

O ATS é o sistema de registro para o funil de recruiting:

- Criação e aprovação de vagas
- Postagem de vagas no LinkedIn, Indeed, Glassdoor e no site de carreiras da empresa
- Rastreamento de candidaturas — todo candidato em toda vaga
- Workflow de triagem (triagem do recruiter, triagem do hiring manager)
- Agendamento de entrevistas, composição do painel, scorecards
- Gestão e aprovação de ofertas
- Confirmação de contratação e transição para onboarding/HRIS

Quando uma métrica como time-to-hire, source-of-hire ou taxa de aceitação de oferta é reportada, ela vem dos dados do ATS.

## O que um recruiting CRM especificamente faz

O CRM é o sistema de registro para relacionamentos com candidatos:

- Pipelining de candidatos de longo ciclo (o engenheiro sênior com quem a equipe conversou duas vezes nos últimos 18 meses)
- Sequências de e-mail outbound para candidatos passivos
- Comunidades de talentos (inscrições em newsletter, participantes de eventos)
- Re-engajamento de candidatos previamente rejeitados
- Rastreamento de produtividade de sourcers
- Analytics de source-to-application (quais canais de sourcing produzem contratações)

Quando um sourcer diz "tenho 200 candidatos no meu pipeline para a vaga de platform engineer", ele está falando do CRM, não do ATS.

## Como a AI muda o cenário

A divisão tradicional ATS-vs-CRM está sendo desafiada por [ferramentas de sourcing nativas de AI](/pt-BR/learn/ai-sourcing/) como [juicebox](/pt-BR/tools/juicebox/) e cada vez mais o [hireEZ](/pt-BR/tools/hireez/) — eles expandem o que "CRM" significa para incluir descoberta de candidatos aumentada por AI de fontes além do LinkedIn. A linha entre ferramenta de sourcing e CRM está se tornando nebulosa; a linha entre ATS e CRM permanece nítida.

## Armadilhas comuns

- **Comprar CRM cedo demais.** Abaixo de 50 contratações/ano, o CRM resolve um problema que você não tem. O dinheiro é melhor gasto no ATS mais AI sourcing.
- **Tratar o ATS como CRM.** Rastrear "candidatos passivos" dentro do ATS produz dados bagunçados e relatórios quebrados. Use a ferramenta certa para cada trabalho.
- **Dois sistemas, sem integração.** Quando o ATS e o CRM não sincronizam, sourcers e recruiters trabalham em mundos separados. Verifique a profundidade da integração antes da compra.
- **Comprar com base em claims de features de AI.** Ambas as categorias têm features de AI; verifique se elas realmente funcionam para os seus tipos específicos de candidatos antes de se comprometer.
