## 概要

Claude Managed Agents は、長時間動くエージェントのための Anthropic のホスト型ランタイムで、Claude Platform（API）の一部です。**エージェント**（モデル、システムプロンプト、ツール、MCP サーバー、スキル）と**環境**（エージェントが作業するサンドボックス）を定義し、そのエージェントの実行インスタンスである**セッション**を開始します。エージェントのループ、コンテナ、ツール呼び出しは Anthropic が実行し、利用者はユーザーターンを送ってストリームでイベントを受け取ります。2026年4月8日にパブリックベータとして公開され、現在もすべてのエンドポイントでベータヘッダー `managed-agents-2026-04-01` が必要です（SDK が自動で付与します）。アクセスはすべての API アカウントでデフォルトで有効です。

各セッションには新しい Linux コンテナが割り当てられ、主要な言語とパッケージマネージャーがプリインストールされています。組み込みのツールセットは `bash`、ファイルの読み取り・書き込み・編集、`glob`、`grep`、`web_fetch`、`web_search` で、すべてデフォルトで有効です。各ツールには、実行前に承認を待つ権限ポリシーを設定できます。リモートの MCP サーバーは Streamable HTTP で接続します。認証情報は **vault** に保管します。自動更新される MCP サーバー用の OAuth トークン、bearer トークン、そして環境変数です。環境変数はサンドボックス内ではプレースホルダーとしてしか見えず、外向き通信の時点で本物のシークレットに置き換えられます。2026年5月以降、outcomes（エージェントが自分の成果を採点するルーブリック）、マルチエージェントのオーケストレーション、メモリ、webhook がパブリックベータになりました。dreaming と、プライベートサーバーへの MCP トンネルは、より限定的なリサーチプレビューのままです。2026年11月12日には、サービス全体を自社クラウドで動かすセルフホスト版 Managed Agents のプライベートベータが始まりました。

Ops チームにとっての問いはこうです。*ヘッドレスなエージェント（夜間の CRM データ衛生チェック、届いた契約書のトリアージ、候補者ダイジェストを作るエージェント）を Anthropic のランタイムで動かすか、それとも Agent SDK を n8n や自前のワーカーでセルフホストし続けるか。*

## 実際のコスト

課金は2本立てです。トークンは選んだモデルの Claude API 標準料金で課金され、プロンプトキャッシュの倍率も通常どおり適用されます。ランタイムは**セッション時間あたり $0.08** で、ミリ秒単位で計測され、セッションのステータスが `running` の間だけ課金されます。次のメッセージやツール承認を待っている `idle` の時間は課金されず、セッションのランタイムはコード実行用のコンテナ時間課金を置き換えます。セッション内の Web 検索は 1,000 回あたり $10 です。ユーザー単位の料金やプラットフォーム料金はなく、利用額は既存の Anthropic とのコミット契約に算入されます。

Anthropic 自身の試算例では、Opus 5.5 で1時間、入力 50,000 トークン、出力 15,000 トークンのセッションが $0.58（入力 $0.20、出力 $0.30、ランタイム $0.08）です。入力のうち 40,000 トークンがキャッシュから読まれれば $0.428 まで下がります。予算の観点で言えば、ランタイムは小さな項目です。1か月間本当に24時間動き続けるセッションでもランタイムは約 $58、毎晩20分の定期処理なら月 $1 未満です。予測して上限を設けるべきなのはモデルのトークンです。適用されない割引が2つあります。セッションには Batch API 料金がなく、ホスト型ランタイムは Bedrock や Vertex 経由で販売されていないため、パートナークラウド料金もありません。

## 最適な用途

- **エンジニアが1人だけの RevOps または Legal Ops チーム**：サンドボックスで1時間作業し、MCP 経由で CRM や CLM を呼び出して結果を報告するエージェントを、コンテナ群、ジョブキュー、シークレットストアを先に構築せずに動かしたい場合。
- **すでに Claude API のコミット契約があるチーム**：社内ツールや自社プロダクトにエージェントを組み込み、ランタイム料金とコンソールのトレーシングで数週間分のオーケストレーションコードを省きたい場合。Anthropic のローンチ顧客（Notion、Rakuten、Asana、Sentry）は「数か月ではなく数週間」で出荷したと述べていますが、これはベンダーが公表した数字です。

## 代替ツールと選ぶべき場面

- **[Amazon Bedrock](/ja/tools/amazon-bedrock/) と AgentCore**：クラウドのエージェントプラットフォームで市場シェア上位2社の一角です。ID、データ、クラウドのコミット契約が AWS にあり、エージェントを自社アカウント内で動かす必要があるなら、こちらを選んでください。なお、Bedrock 上の Claude には Managed Agents のランタイムがありません。
- **[Microsoft Foundry](/ja/tools/microsoft-foundry/) Agent Service**：もう一方の上位プラットフォームです。Azure テナント、エージェント用の Entra ID、Claude 以外のモデルも必要なら、こちらを選んでください。
- **Claude Agent SDK をセルフホスト**（[n8n](/ja/tools/n8n/) や自前のワーカー上）：ゼロデータリテンション、HIPAA 適格性、セッション時間の確実な保証が今すぐ必要な場合に選んでください。サンドボックス、リトライ、シークレットは自分で管理し、支払いはトークンだけです。
- **[Claude Cowork](/ja/tools/claude-cowork/)**：使うのがサービスではなく、デスクにいる人間である場合に選んでください。Cowork はユーザー単位課金のデスクトップエージェントで、Managed Agents はヘッドレスな作業のための API ランタイムです。
- **[Hermes Agent](/ja/tools/hermes-agent/)**：セルフホスト側で最も急成長している新規参入で、リリースから9か月で GitHub のスター数は約 263,000 です。任意のモデルで Slack や Telegram に常駐するエージェントを1つ、API 連携の作業なしで動かしたいなら選んでください。

## 注意点

- **外向き通信は閉じない限り開いたままです。** ネットワーク設定を指定せずに API で作成した環境は、デフォルトで `unrestricted` になります（コンソールのフォームは Limited から始まります）。**対策：** コードから作成するすべての環境で `networking` を `limited` にし、`allowed_hosts` を明示してください。このリストは `web_search` と `web_fetch` にも適用されます。
- **ZDR と HIPAA の対象外です。** Anthropic のドキュメントによると、ホスト型ランタイムはすべてのサブ機能でゼロデータリテンションと HIPAA の対象外です。**対策：** PHI や ZDR 条項の対象データは、セルフホストした Agent SDK のデプロイに置いてください。あるいは ZDR の対象となる唯一の形態であるセルフホスト版のプライベートベータを待ってください。
- **日付入りヘッダーのベータです。** エンドポイント、イベントの種類、デフォルト値は変わる可能性があり、ドキュメントにはセッションの最大時間も同時実行数の上限も記載されていません。公開されているレート制限は、組織あたり毎分 300 件の作成リクエストと 1,200 件の読み取りリクエストです。**対策：** SDK のバージョンを固定し、エージェントと環境の定義を `ant` CLI で適用するファイルに書いて git で管理し、最初のスケジュール実行の前に組織の支出上限を設定してください。
- **メモリはセッションをまたいで残ります。** メモリストアは実行から実行へ引き継がれるため、エージェントが誤った事実を保存すると、その後の実行にも影響し続けます。**対策：** 本番エージェントごとに専用のメモリストアを割り当て、決まった頻度で API から内容を確認し、検証済みの情報源で裏付けられないエントリは削除してください。
