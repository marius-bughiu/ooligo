## 概要

Tableau は、Salesforce が 2019 年に買収し、現在も単体で販売しているビジュアル分析プラットフォームです。アナリストが Tableau Desktop またはブラウザでワークブックを作成して Tableau Cloud か自社運用の Tableau Server に公開し、ビジネスユーザーが閲覧、フィルター、購読します。[Snowflake](/ja/tools/snowflake/)、[BigQuery](/ja/tools/google-bigquery/)、[Salesforce](/ja/tools/salesforce/) を含む主要なデータウェアハウスと SaaS ソースに接続できます。

2026 年に変わったのはエージェント層です。5 月 5 日の Tableau Conference で、Tableau は Cloud、Server、Desktop、Next にまたがる Agentic Analytics Platform を発表しました。Ops にとって重要なのは、公開済みデータに対する自然言語の質問に答える Tableau Agent、プロアクティブなアラート付きの Pulse メトリクス、Slackbot での回答、そしてメトリクスをきっかけにケース起票などのワークフローを起動できる Agent Actions です。Tableau MCP は [Claude](/ja/tools/claude/)、[ChatGPT](/ja/tools/chatgpt/) などの MCP クライアントを、ガバナンスの効いた Tableau のデータにつなぎます。ユーザーごとの OAuth を使う `mcp.tableau.com` のホスト型か、Apache-2.0 ライセンスの `tableau/tableau-mcp` リポジトリからのセルフホストで動きます。

Tableau Next は別製品です。Salesforce プラットフォームと Data 360 の上に構築され、Tableau Semantics に基づくエージェント型分析レイヤーで、アナリストではなく CRM ユーザー向けです。

## RevOps・CS のスタックに入る理由

- **アナリストがすでに使い慣れています。** 多くの Ops チームは Tableau Server 環境と、それに習熟したチームを引き継いでいます。パイプライン、ブッキング、更新のダッシュボードがすでにそこにあることも少なくありません。
- **Salesforce のデータへの最短経路です。** Tableau Next は別のパイプラインなしに Data 360 経由で CRM データを読み込み、回答は Salesforce と Slack の中に表示されます。
- **ダッシュボードを開かない人にも届きます。** Pulse のダイジェストと Slackbot の回答が、チャーンリスクやカバレッジのメトリクスを、CSM や AE が普段働いている場所に届けます。

## 価格の実態

Tableau Cloud はユーザー単位の月額で、年間請求のみ、月額プランはありません。Standard は Creator が $75、Explorer が $42、Viewer が $15 です。Enterprise は $115、$70、$35 で、Data Management、Advanced Management、最大 10 サイトが加わります。どのデプロイにも Creator が最低 1 人必要です。Tableau Desktop Free Edition なら、ローカルのファイルを対象に無料で作成できます。

エージェント機能はこの 2 つのエディションのどちらにも含まれません。オーサリング、Prep、Pulse での Tableau Agent と Tableau Knowledge には Tableau Cloud+ が必要で、価格は見積もりのみです。Tableau+ Bundle はさらに Tableau Next と Data 360 を加えたもので、こちらも見積もりのみ、Data 360 クレジット 250,000 が含まれます。

2026 年 9 月 30 日のアップデートで、キャパシティベースの価格が追加されました。Creator と Explorer は引き続きユーザー単位で、AI エージェントや MCP トラフィックを含む Viewer のアクセスは共有ブロック単位で購入します。1 つのテナントで、キャパシティブロックとユーザー単位の Viewer ライセンスを混在させることはできません。

私たちの試算では、Creator 3 人、Explorer 10 人、Viewer 60 人の RevOps チームは、定価で Standard なら年 $18,540、Enterprise なら年 $37,740 で、エージェント用の Cloud+ は別です。Vendr のマーケットプレイスデータでは、中央値の購入者は年約 $29,400 で、見積もりからの平均削減率は約 13% です。

**Agentforce を使えば Tableau Next は無料で付いてくるのか？** 一部はそうです。Sales、Service、Industries Clouds の新しい Core、Advanced、Max エディションには Tableau Next プラットフォームが含まれます。Sales、Service、Industries 向けの [Agentforce](/ja/tools/salesforce-agentforce/) アドオンには、Tableau Agent を含むフル機能の Tableau Next Consumer ライセンスが付きます。Free、Starter、Pro Suites が受け取るのは、構築済みアプリ専用の機能限定 Consumer ライセンスです。Consumer はコンテンツを作成できないため、誰かが Creator ライセンスを持つ必要は残ります。Tableau Next 単体はユーザーあたり月額 $40 からです。

## 最適な対象

すでに Tableau を使っている、または新エディションで Salesforce を運用している企業の RevOps・CS Ops リーダーで、少人数のアナリストチームが作ったガバナンス付きのパイプラインとアカウントのメトリクスを 50〜500 人に見せる必要がある人。

クラウドのデータウェアハウスがあり、Tableau のスキルがなく、BI をゼロから始めるなら見送ってください。ウェアハウスネイティブなツールの方が Ops スタッフを早く答えにたどり着かせます。クォータや予測の上書きのように、ユーザーが数値を書き戻す必要がある場合も見送ってください。

## 代替との比較

**Power BI** はインストールベースで BI のトップで、Pro はユーザーあたり月額 $14 です。Microsoft 中心の会社、または Pro がバンドルされている Microsoft 365 E5 をすでに持っているならこちらを選んでください。訓練されたアナリストが本格的なビジュアル探索をする場合や、Salesforce が基幹システムである場合は Tableau を選んでください。

**[Looker](/ja/tools/looker/)** は Google のガバナンス重視の選択肢です。ビジュアルの自由度より、コードで共有されるメトリクス定義が重要な場合、特に BigQuery 上で選んでください。

**Omni** は最も急成長している新興勢力で、2026 年 4 月に評価額 15 億ドルで 1 億 2,000 万ドルのシリーズ C を調達しました。移行すべき既存環境がなく、スプレッドシート風のセルフサービスを備えた Looker 型のセマンティックレイヤーが欲しいなら選んでください。

**[Sigma](/ja/tools/sigma/)** は、Ops スタッフがガバナンスの効いたウェアハウスのデータを編集する必要がある場合に勝ちます。**[Hex](/ja/tools/hex/)** は、仕事がダッシュボードのカタログではなく、エージェントを使った探索的分析である場合に勝ちます。

「パイプライン」の意味について誰も合意していないせいでどれも合わないなら、まずモデルを直してください。[data warehouse vs CDP](/ja/learn/data-warehouse-vs-cdp/) を参照してください。

## 注意点

- **エージェントは見積もりの向こう側にあります。** Standard や Enterprise でのパイロットではダッシュボードと Pulse は確認できますが、オーサリングでの Tableau Agent や Tableau Knowledge は確認できません。*対策:* パイロット前に Cloud+ の価格を Enterprise に対するユーザー単位の差額として書面で受け取り、パイロットは Cloud+ の試用サイトで実施してください。
- **ライセンスの選択はテナント単位で固定されます。** 1 つの Tableau Cloud デプロイでエディションやライセンスモデルを混在させることはできません。例外は Cloud+ と Tableau+ Bundle のユーザーの組み合わせだけです。*対策:* 契約前にユーザー単位とキャパシティのどちらの Viewer にするかを決め、外部向けや組み込み用途のユーザーは初日から別テナントに置いてください。
- **「Agentforce に含まれる」は多くの場合 Consumer ライセンスのことです。** Tableau Next には引き続き Data 360 や Flex のクレジットがかかる可能性があります。*対策:* 各 Salesforce SKU にどの種類の Tableau Next ライセンスが付くかを書面で確認してください。最初の四半期は毎月 Digital Wallet でクレジット消費を確認してください。
- **MCP の到達範囲は Viewer の到達範囲と同じです。** どのライセンスタイプでもホスト型の Tableau MCP を使え、Viewer はデータ全体をダウンロードできます。*対策:* MCP ユーザーには認定済みの公開データソースだけを公開し、そこに行レベルセキュリティを適用し、エージェントがどのソースを照会しているかを監査してください。
