2026 年のショートリストに載せる価値がある ABM プラットフォームは 3 つです。そしてこのカテゴリはもう機能一覧では分かれません。3 つともアカウントを特定し、インテントをスコアリングし、リストを CRM に送り込みます。分かれるのは「どの signal を買うのか」です。モデル化されたサードパーティインテント (6sense)、指名アカウントに対する広告リーチ (Demandbase)、あるいはすでに自社プロダクトに触れている人々のファーストパーティおよび公開アクティビティ (Common Room)。signal を選べば、プラットフォームは決まります。

このページの前回版から 2 つ動きました。3 つとも MCP サーバーを提供するようになったため、「自社のエージェントから照会できるか」は決め手ではなくなりました。そして Common Room はもう独立企業ではありません。Zoom が 2026-07-02 に買収を発表し、同じ月にクローズしています。

## 1. 6sense — モデル化されたインテントが forecast を支えるとき

6sense が勝つのは 1 点です。サードパーティインテントを、forecast が支えられる購買ステージの判断に変換することです。アカウントはステージ (target、awareness、consideration、decision、purchase) でスコアリングされ、6QA — 6sense Qualified Account — という指定が、プラットフォームの残りすべてがぶら下がる中核になります。ooligo スコア: 7.8。

6sense が抜きん出る領域は、まだ誰も手をつけていないアカウントリストです。パイプラインの課題が「12,000 のターゲットアカウントのうち、今四半期に市場に出ている 200 社はどれか」であれば、静的なリストを回す rep よりも多くの signal で答えます。

**何を置き換えるか:** 単体の Bombora フィードと、その上に自作した傾向スコアモデル、そして両者を手作業で突き合わせる作業です。

**エージェントからのアクセス:** 6sense MCP Server は 2026-07-14 にオープンベータへ移行し、一般提供は 2026 年 8 月を予定しています。アカウントインサイト、予測購買ステージ、6QA ステータス、キーワードインテント、広告キャンペーンの実績を MCP 対応クライアントに公開します。まず Revenue Marketing の顧客向けに開放されたため、これを前提に workflow を設計する前に自社のエディションが対象か確認してください。

**どこから始めるか:** ICP セグメントを 1 つ、そのセグメントだけにインテントと予測スコアリング、オーケストレーション済みキャンペーンを 1 本。初月に TAM 全体をスコアリングしても、誰も回さないリストができるだけです。

**注意点:** 購買ステージモデルはあくまでモデルであり、監査できないネットワークで学習されています。ガード: rep が自らの判断で回すアカウントを対照セグメントとして 1 四半期分残し、6QA にテリトリーのカバレッジを決めさせる前にコンバージョンを比較してください。

**[6sense の詳細レビュー →](/ja/tools/6sense/)**

## 2. Demandbase — 広告が主要チャネルのとき

Demandbase はアカウント特定とインテントで同じ領域をカバーし、予算が B2B メディアに向かう場面で勝ちます。広告側のプリミティブがより深く、Demandbase はプラットフォームを 1 つの塊として売ります。自社の価格ページで Demandbase One を個別プロダクトに分割しないと明言しており、プラットフォーム料金にユーザーあたりの定額料金を加える形で課金します。ooligo スコア: 7.4。

抜きん出る領域: 指名アカウントに対して paid を投下していて、キャンペーン ID ではなくアカウントのエンゲージメントに紐づくインプレッション単位のレポーティングが必要な場合です。

**何を置き換えるか:** 広告主導のチームにとっての 6sense と、多くの ABM プログラムが自前で組み合わせている B2B 広告ネットワーク＋アトリビューションツールです。

**エージェントからのアクセス:** Demandbase は 2026 年 4 月に MCP を提供開始しました。アカウント検索、企業リサーチ、コンタクト特定、アカウント単位のインテント、バイインググループのカバレッジ、アカウントブリーフを ChatGPT や Claude から扱えます。

**どこから始めるか:** 6sense との POC は 1 つの問いに絞ってください。どちらのベンダーもコンバージョンを観測していないアカウントのうち、自社の closed-won リストをより正確に言い当てるのはどちらか。この 2 社の機能パリティ比較は 6 週間を燃やして何も決まりません。

**注意点:** Agentbase — キャンペーン成果、アカウントエンゲージメント、インテントをカバーする連携エージェント群 — は個別の明細ではなくプラットフォームに同梱されるため、更新時に価値を切り分けにくくなります。ガード: POC の期間中、エージェントの判断をダッシュボードの要約ではなくログとして記録し、エクスポートできるよう要求してください。

**[Demandbase の詳細レビュー →](/ja/tools/demandbase/)**

## 3. Common Room — signal がアカウントではなく人であるとき

Common Room が勝つのは、アカウントベースのインテントが届かない場所からのコンタクト単位の signal です。Slack コミュニティ、GitHub、Discord、ポッドキャスト、LinkedIn、転職。PLG、開発者向けツール、コミュニティ主導のモーションでは、これが「そのアカウントが温まっている」と「そのアカウントの誰と誰の 4 人が動いている」の差になります。ooligo スコア: 8.3。

抜きん出る領域: 買い手がフォームを埋めるよりも前に、公開の場で自ら名乗っている場合です。従来型の ABM はそのアカウントをゼロと評価します。

**何を置き換えるか:** Slack を監視するスプレッドシート、誰も手が回らない GitHub スターガザーとアカウントの紐づけ、そして実際の signal を取りこぼすサードパーティインテントです。

**エージェントからのアクセス:** Common Room の MCP サーバーは読み取りに加えて書き込みもできます。コンタクト、組織、アクティビティ、セグメントを照会し、AI クライアントからレコードを作成・更新します。このループを閉じているのは 3 つのうち Common Room だけです。

**どこから始めるか:** 主要な 3 ソースを接続し、ICP を定義し、1 週間だけ signal を 1 つの Slack チャンネルに流してください。CRM に何かを配線する前に、既存のインテントフィードと signal の密度を比較します。

**注意点:** 資本関係です。Zoom は 2026 年 7 月に買収をクローズし、Common Room のバイヤーインテリジェンスを Zoom Revenue Accelerator に統合する方針を表明しています。現時点でプロダクトは単体で販売され続けており価格ページも公開中ですが、単体プロダクトとしてのロードマップは自社のレベニュープラットフォームを持つ買い手のものになりました。ガード: 36 か月ではなく 12 か月の契約で交渉し、署名時にデータのエクスポート経路を書面で確保してください。

**[Common Room の詳細レビュー →](/ja/tools/common-room/)**

## 価格の実態

価格を公開しているのは 3 つのうち 1 つだけです。Common Room の Essential は年額請求で $2,500/mo — $30,000/yr — で、5 シート、最大 100k コンタクト、5k の RoomieAI リサーチクレジット、2.5k の Prospector クレジットが含まれます。Advanced (15 シート、250k コンタクト) と Enterprise (30 シート、750k コンタクト) は見積もりのみです。無料プランはありません。

6sense と Demandbase は最初から最後まで見積もり制です。Vendr の取引データでは、6sense の年間契約額の中央値は 381 件の購買で $62,440、レンジは $11,566 から $175,022。Demandbase の中央値は 185 件の購買で $68,591、レンジは $24,000 から $164,265 です。

実務上の比率: エンタープライズ ABM 契約の中央値は **Common Room の公開エントリー価格の約 2×**、どちらのレンジも上限はその 5–6× です。各レンジ内のばらつきは 2 社間の差より大きく、つまりロゴよりも交渉のほうが効きます。レンジ上限に近い見積もりは市場価格ではなくパッケージングの問題だということです。

## このリストに入っていないもの、その理由

- **AdRoll ABM (旧 RollWorks)** — 依然として機能するプロダクトで、広告がプログラムのすべてなら検討に値しますが、いまは独立した ABM プラットフォームではなく AdRoll 内のパッケージです。NextRoll は 2025-08-27 にブランドを統合し、rollworks.com は AdRoll ABM のページにリダイレクトします。[詳細レビュー →](/ja/tools/rollworks/)
- **Terminus** — 独立プラットフォームとしては消滅しました。DemandScience に統合され、terminus.com は demandscience.com へ 301 リダイレクトします。同社が売るのは自社のプロダクトライン (Ionic、Demand、Advertising、Data、VID) であって Terminus ブランドのものではありません。まだ Terminus の契約が残っているなら、更新は DemandScience の評価です。
- **Madison Logic** — コンテンツシンジケーションとインテントで、実際の予算が付いており、上記 3 つより範囲は狭いです。見積もり制で公開価格はありません。シンジケーションがプログラムの中心なら正解、オーケストレーションが要るなら不正解です。
- **Bombora 単体** — インテントデータのみで、このページの複数のプラットフォームの上流に位置します。すでにオーケストレーション層があり生のフィードが欲しいなら直接購入する意味がありますが、そうでなければ同じ signal に二重に払うことになります。
- **Influ2** — アカウントではなく指名した個人に向けた広告です。ABM プラットフォームの補完であって置き換えではありません。[詳細レビュー →](/ja/tools/influ2/)

## 実行可能な最小の選択

本格的な評価を正当化できないなら、既定で **Common Room** を選んでください。営業サイクルなしに予算化できるのはこれだけで、エントリープランはエンタープライズ ABM 契約の中央値のおよそ半分、12 か月の契約なら間違えても取り返せます。モデル化されたサードパーティインテントが手元の signal を上回るという証拠が出てから、6sense か Demandbase に上げれば十分です。

ルーティングルール、優先順に:

1. エンタープライズ B2B、長い商談サイクル、アカウントスコアリングの上に組んだ forecast: **6sense**
2. 広告が主要チャネルで、インプレッション単位のアトリビューションが要件: **Demandbase**
3. PLG、開発者主導、コミュニティ主導で、買い手が公開の場に見えている: **Common Room**
4. 予算の小さい広告のみのプログラム: このリストのプラットフォームではなく **AdRoll ABM**

どれも当てはまらない場合 — 最も多いのはターゲットアカウントリストが数百社を下回るケースです — ABM プラットフォームは買わないでください。その規模なら、データツールと実行ツールの組み合わせが同じ範囲をはるかに低いコストでカバーします。リサーチとエンリッチメントに [Clay](/ja/tools/clay/)、シーケンスに [Outreach](/ja/tools/outreach/) か [Salesloft](/ja/tools/salesloft/) を組み合わせてください。ABM プラットフォームがその価格に見合うのはリストの規模とオーケストレーションの複雑さゆえであり、その閾値を下回ると買っているのはダッシュボードです。

何を選ぶにせよ、rep への引き渡しから設計してください。ABM プログラムが壊れるのは、モデルがアカウントをスコアリングした瞬間ではなく、スコアの付いたアカウントが誰かのタスクになった瞬間です。

## 見直すタイミング

この判断を見直すのは次の 3 つのときです。Zoom が Common Room を Zoom Revenue Accelerator に統合し単体販売をやめたとき、6sense の MCP サーバーが Revenue Marketing だけでなく全エディションで一般提供に達したとき、あるいはエンタープライズ 2 社のいずれかが下限価格の公開を始めたとき。上のルーティングルールを動かすのはこの 3 つです。
