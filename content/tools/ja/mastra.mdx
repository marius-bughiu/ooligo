## 概要

Mastra は、AI エージェントを構築するためのオープンソースの TypeScript フレームワークと、それを実行するホスト型プラットフォームです。Gatsby.js を開発したチームが手がけ、Y Combinator を経て、2026 年 1 月に 1.0 をリリースしました。2026 年 4 月には Spark Capital がリードする 2,200 万ドルのシリーズ A を調達しています（累計 3,500 万ドル）。GitHub リポジトリのスター数は約 30K です。

フレームワークは、ツールを持つエージェント、分岐と suspend/resume を備えたグラフ型ワークフロー、メモリ、RAG、評価、トレーシングを、すべて `@mastra/*` 配下の npm パッケージとして提供します。Mastra Studio はローカルの UI で、エージェントとチャットしたり、ワークフローの実行をステップごとに追ったり、トレースを確認したりできます。エージェントは Vercel、Cloudflare、Netlify など Node.js が動く環境ならどこにでも、あるいは Mastra Platform にデプロイできます。

運用チームにとっての答えはこうです。チームがすでに TypeScript を書いており（CRM 連携を保守する RevOps エンジニアや、受付ポータルを構築した Legal Ops の開発者など）、社内エージェントを Python サービスやプルリクエストでレビューできないノーコードキャンバスではなく、他のコードと同じ言語・同じリポジトリで作りたい場合に向いています。

## 実際に購入するもの

**フレームワークは無料です。** コードの大半は 2025 年 7 月以降 Apache 2.0 です。`ee/` ディレクトリ配下のコードは別のエンタープライズライセンスの対象です。RBAC、きめ細かな認可、Agent Builder、Studio のサードパーティサインインは開発環境では無料ですが、本番環境では有料キーが必要です。

**Mastra Platform** は、サーバー、Studio、オブザーバビリティ、Connect（マネージド連携）をホストします。2026 年 11 月には、組み込みの MCP サーバー（2026-11-17）、1 つのキーで 500 以上のモデルにフェイルオーバー付きでアクセスできる Mastra Gateway（2026-11-19）、オブザーバビリティのアラート、暗号化されたシークレットが追加されました。

**Mastra Factory** は別製品で、2026 年 7 月にローンチされ、2026-11-18 に Show HN として投稿されました。カンバン形式のボード上で、エージェントが GitHub や Linear の issue をトリアージし、PR を書き、レビューを実行します。Mastra によると、自社の PR の 25% 以上を Factory が書いています。参考設計としては有用ですが、ソフトウェアエンジニアリング向けのツールであり、運用向けのツールではありません。

## 料金

mastra.ai/pricing で公開されており、2026-11-27 に確認しました。料金はワークスペースごとの月額です。

- **Free — $0。** エージェント、ユーザー、デプロイは無制限。オブザーバビリティイベント 100K、40 vCPU 時間、メモリ 360 GB 時間、エグレス 10 GB、接続 5 件。サーバーレスプロジェクトのみ（ゼロまでスケール）。
- **Starter — $25。** 常時稼働の Small プロジェクト 1 つ（2 GB、1 vCPU）、イベント 250K、エグレス 25 GB、接続 10 件。2026-11-10 に価格改定され、以前の無料の「Starter」は現在の Free になりました。
- **Team — $250。** Small プロジェクト 1 つと Medium プロジェクト 2 つ、イベント 10M、400 vCPU 時間、接続 50 件、SOC 2 レポート。
- **Enterprise — 個別見積もり。** RBAC、SSO、監査ログ、固定 IP、OIDC。

超過料金：イベント 100K あたり $10、vCPU 時間あたり $0.25、GB 時間あたり $0.25、エグレス 1 GB あたり $0.10、追加接続 1 件あたり $0.50。追加プロジェクトは月額 $25（Small）、$100（Medium）、$200（Large）です。

実際の価格帯：スケジュール実行する社内エージェント 1 つなら、Starter の月額 $25 にモデル利用料を加えた額に収まります。本番エージェント 3 つとステージング環境があれば Team の $250 になります。SSO が必要なら Enterprise が必須で、その価格は公開されていません。フレームワークを自社の Vercel や AWS アカウントでセルフホストする場合、本番で `ee/` の機能が必要でない限りライセンス費用はかかりません。

## 向いているチーム

TypeScript を主軸とする運用エンジニアリングチーム（開発者 1〜5 名）で、2〜10 個の社内エージェントを構築する場合です。たとえば RevOps のリードエンリッチメントエージェント、Legal Ops の NDA 受付トリアージエージェント、Recruiting の候補者スクリーニング要約エージェントなどで、耐久性のある多段階ワークフロー、人による承認ステップ、トレースが必要であり、コードを他のすべてと同じリポジトリでレビューしたいケースに向いています。

## 向いていないチーム

開発者がいないチーム：[Dify](/ja/tools/dify/)、[Sim](/ja/tools/sim/)、[n8n](/ja/tools/n8n/) を使ってください。Python 中心の組織：フレームワークは TypeScript のみです。初日から SSO が必要で、Enterprise の調達プロセスを回せない企業：$250 の Team には SSO が含まれません。

## 代替製品との比較

- **LangGraph と [LangSmith](/ja/tools/langsmith/)** — 最も広く採用されているコードファーストのエージェントフレームワークで、Python と JS に対応しています。明示的なステートマシン制御と最も成熟した評価ツールが必要な場合、またはチームが Python を使う場合に選んでください。
- **[CrewAI](/ja/tools/crewai/)** — Python の、ロールベースのマルチエージェントクルーです。仕事がロール間の受け渡しに対応しており、チームが Python を書く場合に選んでください。
- **Vercel AI SDK** — より軽量な TypeScript の選択肢です。Web アプリ内でストリーミングのモデル呼び出しとツール利用が必要で、耐久性のある処理が不要な場合に選んでください。suspend/resume、メモリ、トレースを備えたワークフローが必要になったら Mastra に移行します。
- **[Claude Managed Agents](/ja/tools/claude-managed-agents/)** — エージェントループとサンドボックスを Anthropic に運用してもらいたく、Claude モデルだけを使う場合に選んでください。

有料プラットフォームに価値はあるでしょうか。エージェントが 1〜2 個なら、$25 の Starter はホスティング、シークレット、トレーシングを自分で組む時間よりも安く済みます。それ以上になる場合は、$250 の Team と、すでに費用を払っているインフラでフレームワークを動かしてトレースを [Langfuse](/ja/tools/langfuse/) に送る構成とを比較してください。

## 注意点

- **2026 年 6 月の npm 侵害。** 2026-06-17、攻撃者が元コントリビューターの npm アカウントを使い、140 以上の `@mastra` パッケージを悪意ある依存関係（`easy-day-js`）付きで再公開しました。この依存関係には認証情報窃取ツールとリモートアクセス型トロイの木馬が含まれていました。Microsoft はこれを北朝鮮のグループ Sapphire Sleet によるものとしています。Mastra はソースコードは改変されていないとしています。対策：コミット済みのロックファイルで正確なバージョンを固定し、`npm ci` でインストールし、可能な場合は CI でインストールスクリプトをブロックし、`@mastra` をアップグレードするたびに依存関係スキャナー（Socket、Snyk）を実行してください。
- **リリースのペースが速い。** Mastra は 2026 年 11 月だけで 15 件以上の製品発表をブログに投稿しており、2026 年 7 月の料金に関する投稿は 4 か月後には古くなっていました。対策：リリースのたびではなく、変更履歴を確認しながら月次スケジュールでアップグレードし、更新のたびにプランの上限を再確認してください。
- **エンタープライズ機能は `ee/` に隠れている。** RBAC や Studio のサインインにライセンスが必要なことに、本番稼働の段階で気づくチームがあります。対策：構築前にセキュリティレビューで必要となるアクセス制御を洗い出し、同じ週のうちに Enterprise の見積もりを取ってください。
- **プラットフォームの信頼性はまだ成熟途上。** Mastra は 2026-10-21 に発生したプラットフォーム障害のインシデントレポートを公開しています。対策：デプロイ先をポータブルに保ち（同じコードが Vercel や Cloudflare で動きます）、売上に直結するエージェントをフォールバックなしで単一のホスト型プロジェクトに載せないでください。
