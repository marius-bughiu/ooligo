Beim CRM-Import verschwindet die führende Null einer Kundennummer. Um die Ursache einzugrenzen, genügen zwei Beispielzeilen im Claude-Chat. Liegt der Fehler im Importskript, kannst du ihn mit Claude Code im gewohnten Terminal oder in deiner IDE verfolgen. Cursor bietet sich an, wenn du die Änderungen direkt in dessen Editor neben dem Quellcode prüfen möchtest.

## Wo die Arbeit stattfindet

- **Claude-Chat.** Füge die Felddefinition und einige fiktive CSV-Zeilen ein. Frage, welche Umwandlung dazu führen könnte, dass zwei verschiedene Konten dieselbe Kennung erhalten. Wer den Import betreut, kann diese Vermutung ohne Zugriff des Chats auf das Repository prüfen. [Tarife und Funktionen von Claude](https://claude.com/pricing)
- **Claude Code.** Öffne das freigegebene Repository im Terminal oder in einer unterstützten IDE. Lass den Agenten den Weg der Kennung vom Einlesen der CSV-Datei bis zur Kontosuche im CRM verfolgen, den Code ändern und die vorhandenen Tests ausführen. Prüfe die Befehle und die Änderungen. [Dokumentation zu Claude Code](https://code.claude.com/docs/en/overview)
- **Cursor.** Öffne dasselbe Repository in Cursor. Betrachte den CSV-Parser und die zugehörigen Tests nebeneinander, während du die Änderungen im Editor prüfst. Der Agent kann Dateien suchen und bearbeiten sowie Befehle ausführen. Welche Modelle du wählen kannst und wie sie abgerechnet werden, hängt vom Tarif ab. [Cursor Agent](https://cursor.com/docs/agent/overview) · [Modelle und Preise](https://cursor.com/docs/models-and-pricing)

## Ein CRM-Import mit zwei Konten

Die fiktiven Zeilen stehen für verschiedene Konten. Der Import muss `external_id` als Text behandeln und führende Nullen erhalten.

```csv
external_id,account
0071,North Mill
71,South Mill
```

Als ganze Zahl hätten beide Kennungen den Wert `71`. Die Kennung muss sowohl beim Einlesen der Datei als auch bei der Suche nach dem passenden Konto erhalten bleiben. Bitte im Chat um eine Feldzuordnung und eine Erklärung, an welcher Stelle die Werte zusammenfallen können. Bitte den Programmieragenten zuerst um einen Test, der mit dem fehlerhaften Code scheitert.

Starte mit einer leeren lokalen Datenbank und deaktiviere Schreibzugriffe auf das CRM. Nach dem ersten Import erwartest du `0071 → North Mill` und `71 → South Mill`. Importiere dieselben Zeilen erneut. Beide Zuordnungen müssen erhalten bleiben und der zweite Lauf darf kein neues Konto anlegen. So kannst du die Korrektur in deinem Projekt prüfen. Ein weiteres Beispiel zum Herunterladen bietet der [Workflow zur Datenanreicherung mit Clay und Claude](/de/workflows/lead-enrichment-clay-claude/).

## Kosten für eine Person

Die folgenden Webpreise für Einzelpersonen gelten in US-Dollar vor Steuern. Stand ist der 2. November 2026. **Claude Free** bietet Chat mit Nutzungslimits. **Pro** umfasst Chat und Claude Code für 20 USD bei monatlicher Zahlung oder 200 USD für ein Jahr. Max kostet 100 USD und Ultra 200 USD im Monat. Melde dich mit dem Abokonto in Claude Code an, um dessen Kontingent zu nutzen. Bei Anmeldung mit einem Anthropic-API-Schlüssel wird die API-Nutzung separat abgerechnet. [Claude-Preise](https://claude.com/pricing) · [Abrechnung von Claude Code](https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-max-or-ultra-plan)

**Cursor Free** bietet ein begrenztes Kontingent. Bei neuen Einzelabos kostet **Plus** 8 USD im Monat und erlaubt keine Modelle anderer Anbieter. Für ein Claude-Modell in Cursor brauchst du mindestens **Premium** für 30 USD monatlich. Der Modellverbrauch wird zusätzlich zum API-Listenpreis vom vorausbezahlten Guthaben abgezogen. Wer den früheren Pro-Tarif für 20 USD behält, nutzt ihn zu dessen bestehenden Bedingungen. [Cursor-Preise](https://cursor.com/pricing) · [Modellkosten](https://cursor.com/docs/models-and-pricing) · [Frühere Tarife](https://cursor.com/docs/account/pricing/legacy-cursor-plans)

Brauchst du nur eine Erklärung zum Importfehler, starte mit dem Chat von [Claude](/de/tools/claude/). Wer Pro schon bezahlt, kann mit Claude Code direkt am Importskript arbeiten. Ein zusätzliches Abo für [Cursor](/de/tools/cursor/) lohnt sich, wenn die Prüfung im Cursor-Editor deinem Team den Abopreis und die Kosten des gewählten Modells wert ist.
