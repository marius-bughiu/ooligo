## 概要

iManage は、大手法律事務所やプロフェッショナルサービス企業の多くが成果物を保管している文書・メール管理システムです。2015年に HP からのマネジメントバイアウトを経て独立を保っており、2023年4月に Bain Capital Tech Opportunities が成長投資として**少数株式**を取得しましたが、共同創業者の Neil Araujo が引き続き CEO を務めています。2026年5月時点で同社は、4,000組織・100万人超の専門職が利用しており、Am Law 100 の79%、Global 100 の83%、Fortune 100 の40%が含まれ、顧客基盤の78%が iManage Cloud に移行済みだと公表しています。

iManage がリーガル AI の検討リストに載る理由は、DMS そのものではありません。iManage がリーガル AI の通り道となる権限境界になったからです。Harvey、[Legora](/ja/tools/legora/)、Litera、Definely、DraftWise はいずれも iManage を置き換えるのではなくインデックスします。つまり「自社の AI は何を見られるのか」という問いは、AI ベンダーの問題ではなく iManage の設定の問題になります。

## Legal Ops スタックに登場する理由

- **MCP Server がリポジトリを AI から呼び出せる記録システムに変えました。** 2026-05-14 に一般提供として発表され、ベンダーごとに増え続ける API 連携を1本の接続に置き換えます。Harvey、Legora、ChatGPT、Claude、Microsoft Copilot、あるいは事務所独自のエージェントが呼び出せます。アクセスは認証され、権限に縛られ、ログが残り、既存の情報遮断壁はそのまま維持され、ベンダーのインデックスへの一括エクスポートも発生しません。Anthropic のパートナーエコシステムと Claude store を通じて提供されます。
- **情報遮断壁が実際に存在する場所が Security Policy Manager です。** クライアント単位・案件単位の need-to-know セキュリティが iManage 内で適用されるため、AI アシスタントは誰が何を読めるかという並行モデルを自前で持つ必要がなく、既存の遮断壁をそのまま継承します。
- **Insight+ は事務所自身のコーパスに対するナレッジ検索レイヤー**であり、MCP Server が公開する対象もこの面です。AI Enrichment が文書分類とデータ抽出を担い、Ask iManage が保管済みの成果物を自然言語で探して操作するアシスタントになります。
- **OAuth 2.0 に対応した iManage Work Universal REST v2 API** が、各リーガル AI ベンダーがコネクタを作る対象です。あるツールが「DMS 連携」をうたう場合、通常はこの API を指しています。
- ConnectLive 2026 で iManage は、コンテンツ・関係性・リアルタイムの活動を横断するアーキテクチャ層として **context fabric** という方向性を示し、同年に90社の新規顧客ロゴを追加したと述べています。

## 料金

iManage は価格を公開していません。製品ページはいずれもデモ申し込みに誘導されるため、目にする数字はすべてベンダーではなくリセラーやコンサルタント発です。

- **報告されているレンジは月額50〜75 USD/ユーザー程度**、最低10ライセンス前後です。2026年8月時点のコンサルタントおよびリセラーの報告に基づきます。英国のチャネルパートナー経由では月額30〜50 GBP/ユーザーに近くなります。
- **導入費は別請求**で、金額も大きめです。10〜25ユーザーで約1万〜1.5万 USD、25〜50ユーザーで1.5万〜2.5万 USD、51ユーザー超で2.5万 USD 以上。15ライセンスの事務所の初年度は、ライセンス費約1.17万 USD に対し、総額でおおむね2.2万〜2.7万 USD が現実的な水準です。
- **DMS の金額はプラットフォームの金額ではありません。** Insight+、Security Policy Manager、Threat Manager、Records Manager はいずれも別ライセンスです。Work だけを含む見積もりでは、AI の話が依存しているガバナンス層はカバーされません。

## こんなチームに向く

- 弁護士がおおむね50人を超える事務所、および記録保存義務や情報遮断壁の要件を持つ社内法務・会計チームで、フォルダではなく案件中心のファイリングが必要な場合。
- iManage が現時点で明確に勝つ具体的なケースは、20年分の蓄積された成果物に Harvey や Legora を向けたいが、そのコーパスをベンダーのインデックスへエクスポートは**したくない**、しかも情報遮断壁はそのまま維持したい事務所です。

## 代替候補

- **NetDocuments** — リーガル DMS 複占のもう一方で、当初からクラウドネイティブです。取引案件向け構成で月額45〜65 USD/ユーザー、AI アドオンの ndMAX がさらに15〜25 USD と報告されています。AI アドオンのユーザー単価が公開されていることを重視し、オンプレミスの負債を抱えていない場合はこちらを選んでください。
- **Microsoft SharePoint / Microsoft 365** — すでに E3 または E5 を支払っており、案件量が少なく、案件単位の need-to-know アクセスの証明を誰からも求められていない場合はこちらです。失うのは法務向けのメタデータモデルと情報遮断壁の強制であり、その2つを自前で作り直すと出来は悪くなります。
- **[DeepJudge](https://www.deepjudge.ai/)** — この領域で最も成長が速い新規参入で、前年比500%超の売上成長、Felicis がリードした4,120万 USD のシリーズ A、評価額は約3億 USD、顧客として Freshfields、Holland & Knight、Cozen O'Connor が挙げられています。DMS を置き換えるものではありません。本当の課題がファイリングではなく、DMS・メール・イントラネット・クライアントポータルを横断する検索である場合に、iManage と併用してください。

## 注意点

- **買い手が最も強く尋ねる AI ガバナンス機能は、出荷済みの製品ではなくロードマップでした。** Security Policy Manager における案件単位の AI 利用制限と、Threat Manager における AI エージェントの挙動監視は、2026年5月の ConnectLive で Insight+ のマルチリージョン検索、ネイティブ OCR、Collaboration Links とともに方向性として示されたものです。*ガード:* 展開計画がこれらのいずれかに依存するなら、ロードマップのスライドを受け入れるのではなく、一般提供日を発注書に明記させてください。
- **デモの前に価格を出すことはできず、2枚目の請求書が想定外になります。** *ガード:* ライセンス、導入、各ガバナンスモジュールを別行で見積もらせ、同じライセンス数の NetDocuments の見積もりと総額で比較してください。ここで使える価格交渉の材料はそれだけです。
- **MCP が与えるのは、そのユーザーがすでに持っている権限そのものであり、これは両方向に効きます。** need-to-know 設定が長年ゆるいままなら、AI が特権情報を誤った弁護士に返す形で表面化します。逆に長年きつすぎるなら、AI が「何も見つけられない」形で表面化します。*ガード:* 苦情が出てからではなく、最初の AI パイロットの前に、対象案件のセキュリティクラスと NRTA 設定を監査してください。
- **78%がクラウドということは、22%はそうではないということです。** オンプレミスおよびハイブリッド環境は、同じ AI の機能面を同じ時期には受け取れません。*ガード:* 検討を始める前に自事務所がどの構成かを確認してください。答えによって実際に使えるものが変わります。
- **境界であることが、粘着性と高コストの両方を生みます。** iManage からの移行は複数四半期のプロジェクトになります。すべてのリーガル AI ツール、アドイン、ワークフローがそこを向いているためです。*ガード:* まだ降りられる余地があるうちに、最初の契約でエクスポート形式とデータポータビリティの条件を交渉してください。
