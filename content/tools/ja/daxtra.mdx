## 何をするツールか

Daxtra は、履歴書（CV）のパース、セマンティック検索、マッチングを手がけるベンダーで、2002年から人材紹介・派遣会社、インハウスの TA チーム、そして ATS を開発するソフトウェア企業に販売してきました。40以上の言語の CV と職務記述書を150以上の構造化フィールドに変換し（XML または JSON、REST または SOAP 経由、ホスト型またはオンプレミス）、その上に採用担当者向けの製品を重ねています。**Daxtra Capture** と **Magnet** は受信箱や求人サイトから CV を取り込み、重複を排除して ATS に登録します。**Search Nexus** は自社データベースとオンラインの人材プールを横断してセマンティック検索とランキングを行います。**Styler** は CV を自社ブランドの書式に整え、匿名化します。**Engage**（2024年4月の PivotCX 買収で獲得）は SMS、音声、ビデオによるアプローチを追加します。2025年3月18日にローンチされた **TalentFlow** は、これらをソーシング、スクリーニング、エンゲージメントをつなぐエージェント型のフローにまとめた製品です。さらに Conversational Search（2025年5月21日）が、Boolean 検索式を自然言語のクエリに置き換えました。2023年6月から Strattam Capital が同社を所有しており、2025年6月に Michael Flannery が CEO に就任しました。Daxtra は顧客数を人材会社と採用チーム合わせて2,500以上と公表しています。

このページが答える問いはこうです。Bullhorn が Textkernel を傘下に収めたいま、パースとマッチングを独立系の専門ベンダーから買うべきか、それとも ATS に標準搭載されている機能で済ませるべきか。

## Recruiting スタックに入る理由

- **エンタープライズ水準で残っている、事実上唯一の独立系パーサー。** Bullhorn は2024年6月18日に Textkernel を買収し、もう1つの老舗専門ベンダーを ATS ベンダーの傘下に取り込みました。Textkernel は上位10社の人材会社のうち8社を含む2,000以上の顧客を抱えています。Bullhorn 以外の ATS を使っている場合、あるいは採用ソフトウェアを自社で開発している場合、どの ATS ベンダーにもロードマップを握られていない実績ある選択肢は Daxtra です。
- **言語カバー率こそが製品。** 40以上の言語に対応し、氏名、住所、日付を国ごとの形式で処理できることは、1つのデスクでポーランド、日本、ブラジルの候補者を紹介する場合に効いてきます。英語で学習したパーサーや汎用的な LLM のプロンプトは、国境を越えて人材を紹介するエージェンシーが利益を生む、まさにその CV で精度が落ちます。
- **エージェンシーがすでに使っている ATS に接続できる。** Daxtra は2010年から [Bullhorn](/ja/tools/bullhorn/) Marketplace のパートナーであり、Bullhorn Automation の Auto Match で選択できる2つの検索・マッチングプロバイダーの1つです。JobAdder では有料アドオンとして提供され、Vincere、PCRecruiter、Mercury、iCIMS、SAP SuccessFactors とも連携します。TalentFlow は [Workday](/ja/tools/workday/) や [Lever](/ja/tools/lever/) を含む40以上の ATS との双方向同期をうたっています。

## 料金

Daxtra は価格を公開しておらず、セルフサービスのプランも無料トライアルもありません。すべて見積もりベースの年間契約です。価格トラッカーによれば、採用担当者向けの製品（Capture、Search Nexus、TalentFlow）はユーザー単位の課金で、パーサー API はドキュメント量に応じて見積もられます。

第三者の推計（ITQlick）では、ユーザー単位の製品は1ユーザーあたり月額およそ $75〜$100 で、席数が増えるほど下がります。これに加えて、小規模なエージェンシーでは $2,000〜$5,000 の初期導入費用が一度だけかかります。ooligo はこれらの数値を実際の請求書で検証できていないため、予算ではなく交渉の出発点として使ってください。

パーサー API については、公開市場の価格が上限の目安になります。Affinda はセルフサービスのパースを1ドキュメントあたり $0.10、66,000ドキュメントで年間 $3,600（1件あたり約 $0.055）と公表しています。Textkernel の Tx Platform はパース1回につき1クレジット、LLM パーサーを使う場合はさらに0.1クレジットを課金します。自社のボリュームで Daxtra のパースのみの見積もりが1ドキュメントあたり $0.10 を大きく上回るなら、その差額は言語の精度に払っていることになります。自社の CV でその精度を証明させてください。

## 最適な用途

3つ以上の言語で採用を行い、使い続ける ATS の上にパース、重複排除、セマンティック検索を載せたい、多国籍の人材会社（採用担当者およそ20〜500人）のオペレーション責任者や TA テクノロジーの責任者。ATS の競合に所有されておらず、組み込み可能でオンプレミスにも対応するパーサーを必要とする HR テックのプロダクトチームにもよく合います。

**向いていないケース:** 英語のみで採用し、CV が月に約5,000件未満であれば不要です。セルフサービスのパーサー API か、JSON スキーマを指定した [Claude](/ja/tools/claude/) の抽出プロンプトで足ります。コストは Affinda の価格表で年間 $3,600、あるいはそれ以下です。また、すでに Bullhorn を使っていて Pro プランに払う意思があるなら、これも向いていません。Bullhorn 自身の AI 検索・マッチングは Pro から利用でき、同じ仕事に2社目のベンダーを使うのは二重の支出です。

## 代替との比較

- **Textkernel（Bullhorn）** — もう1つの老舗専門ベンダーで、2,000以上の顧客、LLM パーサーのオプション、充実した労働市場データを持ちます。Bullhorn を使っている、あるいは今後使う見込みがあるならこちらを選んでください。所有者の問題が効いてくるのは、Bullhorn と競合する場合か、競合する ATS を運営している場合だけです。
- **RChilli** — こちらも40以上の言語に対応し、主に RChilli を組み込む1,600以上の採用プラットフォームに販売されています。Bullhorn の買収以降、Textkernel からの移行専用ページも設けています。採用担当者向けツールを買うエージェンシーではなく、ホワイトラベルの API を買う HR テックベンダーであればこちらを選んでください。
- **Affinda** — 価格が透明な新興ベンダーで、セルフサービスとセルフホストのプランを公開価格表で提供しています。必要なのはパースだけで、営業との商談前に金額を知りたく、検索機能は自社で上に構築できるならこちらを選んでください。
- **LLM による自前の抽出** — 最も急成長している代替手段です。構造化出力のプロンプトは、英語の CV ならほぼゼロの限界コストで十分に処理できます。パイロットや単一言語のデスクならこちらを選んでください。ただし、重複排除、スキルのタクソノミー、ATS への書き戻しは得られません。
- **ソーシングプラットフォーム** — [hireEZ](/ja/tools/hireez/) と [Eightfold](/ja/tools/eightfold/) は、より広いソーシング製品の一部として検索とマッチングを販売しています。仕事の中心が自社データベースの外で新しい候補者を見つけることなら、どちらかを選んでください。すでにコストをかけて構築した自社データベースを掘り起こすことでは、Daxtra のほうが強みがあります。[AI ソーシングツールの比較](/ja/comparisons/best-ai-sourcing-tools/)も参照してください。

## 注意点

- **連携の品質は ATS によってばらつく。** Capterra のレビュー（32件で3.6/5）は重複排除と Bullhorn との相性を評価していますが、顧客のシステムに合わない場合のコネクタの不具合と修正の遅さが繰り返し報告されています。対策: 最初の年間請求の前に、自社の CV 500件を使い、自社の ATS 上でパース精度と書き戻しを検証する名前付きのテストを実施し、稼働時の受け入れ条件として契約に盛り込んでください。
- **精度の主張はベンダー自身のもの。** 「最も正確なパーサー」「95%以上の精度」は Daxtra 自身のベンチマークであり、独立したものではありません。対策: 実際に紹介している言語ごとに分けた同じ200〜500件の CV で、Textkernel または RChilli、そして LLM のベースラインと比較するブラインドテストを実施し、フィールド単位の精度を自社で採点してください。
- **PE 傘下で、製品ラインが急速に拡大している。** 2023年の所有者交代、2024年の PivotCX 買収、そして2025年の新プラットフォームと新 CEO。パッケージ構成は今後も変わり続けます。対策: 更新時の値上げ上限を書面で定めた12か月契約にし、依存する特定のモジュールと API を注文書に明記して、更新時に再バンドルされないようにしてください。
- **パースした CV は大規模な個人データ。** Capture は受信箱や求人サイトから CV を自社データベースに取り込むため、すべてのレコードに GDPR 上の通知義務と保存期間の義務が生じます。また AI によるランキングは、[NYC Local Law 144](/ja/learn/nyc-local-law-144/) の適用範囲に入る可能性があります。対策: ホスト型サービスのデータ所在地と DPA を確認し、ATS で保存期間に基づく自動削除を設定し、誰をスクリーニングするかの判断に Search Nexus のランキングを使う前に、法務顧問にレビューしてもらってください。
