この比較を最初に書いた時点から、ページ上の2つの名前はどちらも変わっています。[Clari](/ja/tools/clari/) は 2025年12月3日に [Salesloft](/ja/tools/salesloft/) と合併し、2026年9月2日に統合後の会社は Salesloft という単一ブランドに移行しました。現在購入するのは **Clari Forecast** で、Salesloft のメニュー上で Cadence、Conversation Intelligence、Deals、Inspect、Rhythm と並ぶ1つのモジュールです。[BoostUp](/ja/tools/boostup/) は 2025年9月9日に **Terret** に社名を変更し、フォーキャスティングの単機能ツールからエージェントプラットフォームへと位置づけを変えました。同社は現在も独立しています。`boostup.ai` は現在 `terret.ai` にリダイレクトされ、アプリのログインは今も `app.boostup.ai` です(いずれも 2026年11月26日に確認)。このサイトでは `boostup` の slug を維持していますが、製品は Terret です。

以前の版では、この選択は「エンタープライズの深さか、ミッドマーケットの価格か」でした。2026年末の問いは別のものです。フォーキャストをエンゲージメントベンダーから得るべきか、それともフォーキャストを主力製品とする独立ベンダーから得るべきか、です。

## Clari Forecast が勝つところ

**取締役会がすでに信頼している監査証跡。** Clari のロールアップ階層はリブランド後も変わっていません。Commit は rep から manager、VP、CRO へと積み上がり、各階層のオーバーライドはすべて記録され、提出されたフォーキャストはすべてスナップショットとして保存されます。四半期が Commit を下回って着地したとき、その差を特定の階層の特定のオーバーライドまでたどれます。Terret も説明可能な機械フォーキャストと取締役会向けのナラティブを出しますが、この深さでオーバーライド単位まで記録されているという公開された裏付けは Clari より少ないです。フォーキャストの未達分析が取締役会の定例議題である場合や、IPO や買収のプロセスでフォーキャストがデューデリジェンスの対象になる場合、Clari に払う対価はまさにこれです。

**エンゲージメント層と1本の契約で済みます。** Salesloft がすでにケイデンスと通話を担っているなら、Clari Forecast は既存契約へのアドオンであり、2社目のベンダーではありません。Cadence のアクティビティと会話シグナルは Salesloft 自身の経路でディール検査に届き、Salesloft は AI Forecast Agent が営業担当者のワークフロー内で次の最適なアクションを直接起動すると説明しています。[Outreach](/ja/tools/outreach/) を使うチームにとっては同じ事実が逆に働きます。フォーキャストのロードマップを、シーケンスツールの直接の競合が決めることになるからです。

**MCP 経由で LLM からフォーキャストデータにアクセスできます。** Salesloft の MCP サーバーは 2026年4月14日に公開され、現在は Cadence と通話インテリジェンスに加えてフォーキャストとディール検査のデータも公開しています。[Claude](/ja/tools/claude/) のコネクタディレクトリに掲載されており、その後 ChatGPT、Microsoft Copilot、Gemini 向けのコネクタも続きました。Terret のデモページには「Slack、お使いの LLM、Salesforce、または Terret アプリから」質問できると書かれていますが、Terret が公開している MCP サーバーは見つかりませんでした(2026年11月26日に確認)。

**より大規模な導入実績。** Vendr のデータは Clari の購入 291件をカバーしており、年間約 $415,000 までの契約が含まれます。複数の事業部門と標準的でないディール構造を持つ多地域チームでは、この規模での導入実績が文書化されている件数は Clari のほうが Terret より多いです。

## Terret (BoostUp) が勝つところ

**契約規模が小さいです。** Vendr による Terret の中央値は年間約 $30,420 で、レンジは $23,327 から $80,868 です。Clari の Vendr 中央値は約 $76,000 です。中央値で比べると Clari は約 2.5倍高くなります。Clari のプロフェッショナルサービス $15,000-$75,000 を加えると、初年度の差はさらに広がります。

**フォーキャスティングがモジュールではなく製品そのものです。** Terret は Nexus、Forecast、Conversation Intelligence の3つを販売しており、Forecast は BoostUp が長年販売してきた製品の直系です。エンゲージメントプラットフォームを抱き合わせで見積もられることはありません。リブランド以降、Salesloft の営業チームは Clari Forecast と一緒に Cadence と Conversations を見積もるため、フォーキャスト単体の見積もりは今では例外です。

**エンゲージメントツールに対して中立です。** Terret は CRM の基盤として [Salesforce](/ja/tools/salesforce/) または [HubSpot](/ja/tools/hubspot/) を、通話には [Gong](/ja/tools/gong/) と [Chorus](/ja/tools/chorus/) を、エンゲージメントには Outreach と [Apollo](/ja/tools/apollo/) を読み込みます。Salesloft を使っていないなら、この中立性はどの単一機能よりも重要です。

**マネージャーが毎日使うワークフロー。** Terret のディール検査はマネージャーによるレビューを中心に作られています。停滞したアクティビティ、不自然なステージの飛び越し、rep の commit と機械の commit の乖離を表示し、各通話の 30分前に通話ブリーフを Slack に送ります。Clari の画面は奥が深い一方、RevOps と CRO 向けに設計されています。ミッドマーケット企業のセールスマネージャーは、RevOps にレポート作成を頼まなくても Terret で自分でレビューを回せる可能性が高いです。

## 価格の実態

どちらのベンダーも価格を公開していません。`salesloft.com/pricing` は「Talk to Sales」フォームで、`terret.ai/pricing` はデモ予約ページです(いずれも 2026年11月26日に確認)。以下の数字はすべて第三者の調達データであり、定価ではありません。

- **Clari Forecast**:291件の購入に基づく Vendr の中央値は年間約 $76,000、レンジは $19,065 から $415,001 です。Docket は 2026年4月時点で、Forecast 単体を年間契約で1ユーザーあたり月額約 $100-$120 と推定しています。導入サービスは約 $15,000-$75,000 です。
- **Terret**:Vendr の中央値は年間約 $30,420、レンジは $23,327 から $80,868 です。ソフトウェアディレクトリにはフォーキャスティングで1ユーザーあたり月額約 $80 と掲載されていますが、ディレクトリ同士で食い違っており、Terret はいずれの数字も認めていません。

これらの数字では、Clari のシート単価は Terret の約 1.25倍から 1.5倍です。契約単位の差はさらに大きく約 2.5倍で、これは Clari の契約にバンドルされたモジュールとサービスが含まれるためです。このページの以前の版では Clari の中央値を $160,000、総コストを1ユーザーあたり $200 超としていました。現在の Vendr データはこれらの数字を裏付けないため、削除しました。サービスや、本来なら買わないバンドルモジュールも含め、契約期間全体の総契約額で比較してください。

## 導入の手間

**Clari Forecast**:25-100人の rep のチームで、信頼できるフォーキャストが出るまで 8週間から 16週間かかり、高度にカスタマイズされた Salesforce ではさらに長くなります。階層、アクティビティ取得、スナップショット頻度のマッピングが全体のペースを決める作業で、本番稼働後は RevOps の誰かが運用します。

**Terret**:自社データでの 48時間の無料 PoC をうたっています。これはシグナルが本物かどうかを確かめるもので、展開にかかる期間を示すものではなく、Terret は導入スケジュールを公開していません。本当の依存関係は [CRM ハイジーン](/ja/learn/crm-hygiene/)です。アクティビティベースのスコアリングは、rep が接続されたメールやカレンダーの外で仕事をしている部分では弱くなります。チームごとの取得カバレッジは、契約後ではなく契約前に確認してください。

## 結論

**Clari Forecast を選ぶべきなのは**、Salesloft がすでにエンゲージメント基盤である、またはその予定があり、取締役会がオーバーライド履歴付きで監査可能な Commit / Best Case / Pipeline のロールアップを求めていて、ベンダーがサポートする MCP サーバー経由でフォーキャストデータを今すぐ Claude や ChatGPT で使いたい場合です。

**Terret を選ぶべきなのは**、rep がおおよそ 25人から 300人で、フォーキャストが購入の目的であり、Outreach や Apollo を使っている、または変える予定のシーケンスツールがない場合です。エージェント群を目当てに購入しないでください。これらのエージェントは 2025年9月に公開されたもので、根拠はベンダーが公表したものしかありません。フォーキャストを買い、Nexus はパイロットで証明すべき上乗せとして扱ってください。

**どちらも選ばないべきなのは**、rep が約 20人未満、または ARR が $10M 未満の場合です。この規模では $30,000 の契約でも GTM 予算の大きな割合を占めます。Salesforce や HubSpot のネイティブなフォーキャスティングに[パイプラインレビュー用プロンプトパック](/ja/workflows/pipeline-review-prompt-pack/)を組み合わせれば、規律の大部分は得られます。Terret よりエンタープライズ向けの深さがある独立系フォーキャスティングベンダーを探しているなら、[Clari vs Aviso](/ja/vs/clari-vs-aviso/) と [Aviso vs BoostUp](/ja/vs/aviso-vs-boostup/) を参照してください。

**決めきれない場合の選択:** デフォルトは Terret です。以前の推奨を維持しますが、理由は異なります。以前の理由は Clari の価格でした。新しい理由は、Clari Forecast が今ではエンゲージメントベンダーによって販売され、ロードマップも決められており、フォーキャストだけを求める買い手はもはやその顧客ではないということです。例外はすでに Salesloft を使っているチームです。その場合は Clari Forecast を選んでください。統合の利点は本物です。選択を誤ると、中央値ベースで年間約 $45,000 の契約額に加え、オーバーライド履歴がリセットされるフォーキャスト移行のコストがかかります。
