# Contributing to ooligo

Thanks for your interest. ooligo is an open project and contributions — code fixes, content corrections, new tool entries, comparison data, workflows, translations — are welcome.

## How to contribute

1. Open an issue first for anything non-trivial, so we can align on direction.
2. Fork the repo, create a branch, and open a pull request against `main`.
3. Keep PRs focused — one logical change per PR.
4. For content contributions, follow the schema and tone of existing entries in the same folder. See [CONTENT_PIPELINE.md](./CONTENT_PIPELINE.md) for how content is structured and refreshed.

3. If your content contribution incorporates third-party material (quotes, screenshots, logos for identification, public datasets, etc.), you have verified that such use is permitted (e.g. fair use, the third party's own license, or trademark fair use) and you have attributed it appropriately in the contribution.
4. You are not submitting confidential information, proprietary data belonging to an employer or client without authorization, or anything that would infringe a third party's rights.

No CLA signature is required — opening the pull request constitutes your agreement to the above.

## What we won't accept

- Marketing copy or thinly-disguised promotion for a tool or vendor.
- Content auto-generated by an LLM that has not been reviewed and verified by you against canonical sources.
- Use of the "ooligo" name, wordmark, or logo in a fork, derivative site, or external project. The brand is reserved — see [README.md](./README.md#license).

## Questions
