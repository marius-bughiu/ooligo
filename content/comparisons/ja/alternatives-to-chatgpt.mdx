## 前回調べたときから変わったこと

2024 年版のこの問いは「どのモデルが賢いか」でした。その問いはもう終わっています。2026 年 7 月時点で、3 つのアシスタントはいずれも MCP を話し、いずれも個人向け上位プランを $200/月 で頭打ちにし、公開されている推論ベンチマークでも数ポイント差に収まっています。残った差は**形**です。何も設定しない状態で、各プロダクトが既定で何をするか、という違いです。

この 1 年で 2 つ動きがあり、答えが具体的に変わりました。Perplexity が $200/月 の Max プランと自社製 MCP サーバーを出したことで、調べに行く先から、他のエージェントが呼び出せる部品に変わりました。そして OpenAI は 2025 年 8 月 31 日に Operator を単独プロダクトとして終了し、ChatGPT のエージェントモードに統合しました。つまり「Operator を失う」はもう留まる理由になりません。

[ChatGPT](/ja/tools/chatgpt/) からの移行を検討しているなら、正直な整理はこうです。多くのチームは乗り換えていません。2 つ目のシートを追加し、仕事の種類で振り分けています。以下では、それぞれがどこで勝つか、分割の費用がいくらか、そして 1 つしか買えないときに既定を決める唯一のルールを示します。

## Claude — 長いコンテキストの作業とエージェント的なツール利用

[Claude](/ja/tools/claude/) が勝つ場面は 2 つに絞れます。1 つ目はドキュメント量の多い統合作業です。300 ページのデューデリジェンス資料、契約書一式、四半期分のサポート文字起こし。非常に長い入力に対する一貫性は 2023 年から変わらない強みで、今もそうです。2 つ目はエージェント的なツール利用です。MCP を作ったのは Anthropic であり、コネクタは開発者向け設定ではなく第一級の画面として用意されています。統合を組むのがエンジニアではなく ops のマネージャーである場合、この差は効きます。

**Claude に切り替えるべきとき：** AI に使う時間のうち価値が高いのが、長い文書を読んでそこから文章を書く作業である場合。あるいは自社システム上でエージェントのワークフローを構築していて、保守する人が技術者でなくても回るようにしたい場合。

**切り替えるべきでないとき：** 画像や動画の生成が必要な場合。Claude にはどちらもありません。Sora の出力が誰かの週次業務に組み込まれているなら、Claude はそのシートを置き換えられません。

価格は、ops チームが実際に買う階層では ChatGPT と同水準です。Pro は $20/月（年間契約で $17）、Team の標準シートは $25/月、年間契約なら $20 です。計画時に押さえる差は 2 つ。Team は最低 5 シート、そして Enterprise はアクセス分が $20/シートで、モデル利用は API 料金で別建て請求になるため、Enterprise で重く使う場合は定額ではなく従量の請求書になります。

## Perplexity — 出典付きの調査、そして呼び出せる存在へ

[Perplexity](/ja/tools/perplexity/) は汎用アシスタントではなく、汎用アシスタントとして買うのが定番の失敗です。これは回答エンジンです。ウェブに接地し、既定で本文中に出典が付き、「X について今どうなっているか」に答えるために作られています。競合調査、規制の確認、候補者やアカウントのデューデリジェンスでは、汎用アシスタント 2 つより優れています。推論が上手いからではなく、出典がその場にあり、1 クリックで検証できるからです。

新しいのは、Perplexity が他のツールから呼び出せるようになった点です。公式パッケージ `@perplexity-ai/mcp-server` は 4 つのツール — `perplexity_search`、`perplexity_ask`、`perplexity_research`、`perplexity_reason` — を stdio 経由で Claude Desktop、Cursor、VS Code、その他の MCP クライアントに公開します。これは購入判断の枠組みを変えます。Perplexity はアシスタントのシートを奪い合うのをやめ、アシスタントが呼び出す検索レイヤーになります。Claude と Perplexity で迷っていたチームは、Claude をフロントエンド、Perplexity を背後の出典付き検索ツールとして併用する形に寄ってきています。

**Perplexity に切り替えるべきとき：** 主な用途が最新情報の調査で、すべての回答に、関係者へそのまま転送できる出典が必要な場合。

**切り替えるべきでないとき：** アシスタントの中で文章を書く、コードを書く、考える場合。そのための道具ではなく、これらの作業を移すのは後退です。

価格の幅は 3 つの中で最も広いです。Pro は $20/月（$200/年）で同水準。Comet ブラウザは無料で、Comet Plus（出版社のプレミアムコンテンツ向けで月 $5 程度）は Pro に含まれます。ただし Max は $200/月（$2,000/年）で、その間に安価な中位プランはありません。企業向けシートは Enterprise Pro が $40/月、Enterprise Max が $325/月 です。この最上位シートは ChatGPT Business や Claude Team のシートの約 16 倍です。Enterprise Max を見積もるのは、必要な利用者を具体的に名指しできる場合だけにしてください。

## ChatGPT に留まるべきとき

- 用途がコーディング、執筆、画像と動画の生成、会話に分散している場合。広さそのものが実際の製品価値であり、単独でこの 4 つを覆う代替はありません。
- OpenAI にしかない画面に依存している場合：Sora、ネイティブの画像生成、エージェントモードの仮想ブラウザ、そして 2026 年 7 月にアプリディレクトリを置き換えたプラグインディレクトリ。
- 入り口の価格が制約になっている場合。$8/月 の Go に相当するものは Anthropic にも Perplexity にもなく、他社で最も安い有料シートは $17 です。
- チームのプロンプトライブラリ、カスタム GPT、コネクタがすでに ChatGPT の挙動を前提に組まれている場合。作り直しは設定変更ではなく、れっきとしたプロジェクトです。
- 訴えが「もっと良い回答がほしい」である場合。その差はモデルのリリースごとに双方向に動き、追いかけることは移行の根拠になりません。

メモに残っているなら訂正しておく価値がある点：ChatGPT は MCP に対応しています。開発者モードは Plus 以上で読み書き両方の MCP クライアント機能をフルに提供し、Responses API はリモートサーバーにネイティブ接続し、Apps SDK がその上に UI を載せます。MCP はもう移行理由になりません。違いは、Claude では既定で有効、ChatGPT では開発者設定の裏にある、という点だけです。

## 分割の実際のコスト

チーム規模で見ると、3 つはマーケティングが示唆するより近い位置にあります。ChatGPT Business と Claude Team はどちらも年間契約で $20/シート/月、Perplexity Enterprise Pro は $40 で 2 倍です。調査担当 1 人に Claude と Perplexity Pro を併用させても、その人の分は $40/月 で、ChatGPT Pro シート 1 つより安く収まります。高くつく失敗は両極にあります。週に 10 件しか問い合わせない人に $200/月 の Max や Pro シートを渡すこと、そしてアナリスト 3 人が必要としただけの Perplexity Enterprise Max を $325/シート で全社展開することです。

## 結論

**アシスタントを 1 つしか運用できないなら、ChatGPT のままにしてください。** 用途が分化していない状態では広さが正しい既定であり、作り込んだプロンプトライブラリの移行コストは現実の負担です。

**既定を Claude に変えるのは**、長文ドキュメントの統合、書き上がる文章の品質、社内システム上のエージェントワークフローのいずれかに当たる、具体的で反復する業務を名指しできる場合です。1 つ名指しできれば十分で、漠然とした品質の好みでは足りません。

**Perplexity は乗り換え先ではなく追加として**、調査をする人に $20/月 で持たせ、その MCP サーバーを残したアシスタントに接続してください。置き換えではなくレイヤーです。

**3 つとも合わないなら**、原因はほぼモデルではありません。その業務が自社データを回路に必要としている、ということです。CRM のレコード、契約書、ATS。その段階で正しい打ち手は、アシスタントとそれらのシステムへの MCP コネクタ、あるいはすでにデータを保有している垂直特化ツールであって、4 つ目の汎用アシスタントではありません。コネクタが整ってから評価をやり直してください。答えは変わります。

AI ベンダーの選択を忠誠心の問題にすることが、これを間違える最後の方法として残っています。2026 年に本気で運用しているチームは 2 つに払い、仕事の種類で振り分けています。
