Una skill de Claude que ingiere las llamadas, emails y actividad en Salesforce de un rep durante los últimos siete días y entrega un reporte de seis bullets con señales: qué se está calentando, qué se está enfriando, dónde está atorado el rep y una sugerencia para la siguiente semana. Diseñado para auto-revisión del viernes, no para vigilancia.

## Lo que vas a necesitar

- Salesforce con Activity History habilitado y acceso API al user record del rep
- Acceso a Gong con la API de transcript de llamadas activada
- Claude.ai o Claude Code
- El framework de calificación de tu equipo, cargado como un doc markdown de referencia

## Setup

1. **Instala la Skill.** `activity-summarizer.skill` expone tres funciones: `pull_week_activity`, `pull_call_signals` y `render_signal_report`.
2. **Autentica Salesforce y Gong.** Dos tokens. Acota Salesforce a solo lectura sobre Activities y Opportunities. Acota Gong para leer las llamadas y transcripts en las que estuvo el rep.
3. **Carga el framework de calificación.** MEDDPICC, BANT o tu variante propia. La Skill lo usa como lente para "dónde está atorado el deal".
4. **Configura el rep ID y el rango de fechas.** La Skill toma por defecto los últimos siete días pero puedes pasar una semana específica.
5. **Agéndalo para el viernes a las cuatro.** La salida va al DM del rep con un follow-up de "enviar al manager" en un solo botón.

## Cómo funciona

La Skill jala tres streams en paralelo. Desde Salesforce: cada Task y Event que el rep registró, más cambios de stage en sus deals abiertos. Desde Gong: resúmenes de llamadas, ratios de talk-listen y cualquier objeción marcada. Después Claude hace join de esto contra la lista de oportunidades abiertas y se hace una pregunta por deal: "¿Qué cambió esta semana, y es bueno?".

La salida es deliberadamente corta. Seis bullets, máximo. La mayoría de las semanas, tres son cuentas calentándose, dos son deals atorados y uno es una sugerencia. Los reps que reciben un dump de cuarenta bullets de actividad no lo leen.

## Cuídate de

- **Postura de privacidad.** Esto es para el rep, no para el manager. La salida debe llegar primero al inbox del rep. Si un manager quiere copia, el rep la reenvía. Nada de auto-cc.
- **Calidad de transcripts en Gong.** Llamadas internacionales y audio malo producen transcripts ruidosos que llevan a señales malas. Filtra llamadas de menos de cinco minutos y marca cualquiera por debajo del umbral de confianza.
- **Drift en la definición de actividad.** Lo que cuenta como un "touch significativo" varía. Usa la taxonomía de tipos de tarea de tu CRM e ignora el ruido: diez entradas de "logged email" sin respuesta no son engagement.
- **Fatiga de sugerencias.** La línea "una sugerencia para la siguiente semana" tiende a lo genérico si el prompt está flojo. Anclarla a un deal real, un stage real y un blocker real.

## Stack

- **Salesforce** — actividad y estado de oportunidad
- **Gong** — capa de señal de llamadas
- **Claude** — extracción y ranking de señales contra el framework de calificación
