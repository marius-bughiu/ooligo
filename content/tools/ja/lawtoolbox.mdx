## 概要

LawToolBox は、裁判所ごとの手続規則に基づいて期限を計算し、docketing（期日管理）を Microsoft 365 の外ではなく内側で行うツールです。公判期日や送達日などの起算となるイベントを入力し、裁判所を選ぶと、規則から導かれる期限を自動で生成します（同社サイトによれば、1つの公判期日から80件以上）。生成した期限は Outlook のカレンダーに同期されます。規則や起算日が変わると、同期済みの期限も更新されます。この計算機を中心に、案件ごとに Teams のチーム、SharePoint サイト、共有メールボックス、OneNote を備えたワークスペースを Microsoft 365 内に構築し、弁護士が普段作業している場所に案件を置きます。

本社は Denver にあります。1998年に創業し、8,000以上の事務所に利用されてきたとしています。2020年8月に InfoTrack が過半数の株式を取得しましたが、Grow 家が引き続き独立した事業部門として運営しています。Carol Lynn Grow が共同 CEO です。

## Legal Ops のスタックに登場する理由

- **専用の docketing システムを別に持たずに docketing ができます。** Aderant の Milana と CompuLaw は、専用アプリケーションで作業する中央の docketing 部門を前提としています。LawToolBox は、弁護士やアシスタントが Outlook から離れないことを前提としています。docketing 担当者のいない訴訟チームにとっては、規則ベースの期日管理とスプレッドシートの違いになります。
- **Microsoft 365 を案件の保管場所に変えます。** 文書、メール、期限、Teams のチャットが、事務所自身のテナント内にある案件ごとのコンテナにまとまります。Microsoft 365 に標準化したものの案件管理システムを導入していない事務所は、移行なしで[案件管理](/ja/learn/matter-management/)を実現できます。
- **MCP サーバーで案件データをあらゆる AI に公開します。** 2026年8月24日、ILTACON の会期中に LawToolBox は70以上のツールを備えた MCP コネクタを発表しました。案件の検索、期限と予定、レポート、SharePoint、Microsoft 365 グループをカバーしています。Claude、Microsoft 365 Copilot、ChatGPT、Harvey、Legora、CoCounsel、Lexis AI が案件コンテナを直接照会でき、倫理的障壁（エシカルウォール）はコンテナ側で適用されます。[Claude](/ja/tools/claude/) に「この案件で今後30日以内に期限が来るものは何か」と答えさせたい事務所は、独自のコネクタを作らずに実現できます。[MCP サーバーとは何か](/ja/learn/mcp-server-explained/)も参照してください。
- **事務所がすでに使っているシステムとつながります。** [iManage](/ja/tools/imanage/)、[NetDocuments](/ja/tools/netdocuments/)、[Filevine](/ja/tools/filevine/)、ECFX、Centerbase との文書連携があります。事務所管理ソフトのコネクタは Actionstep、[MyCase](/ja/tools/mycase/)、PracticePanther、Smokeball、LEAP などに対応し、2025年8月の提携で ProfitSolv の製品群全体にも広がりました。

## 実際の価格

LawToolBox は価格を公開している数少ない docketing ベンダーの1つです。最低契約期間は1年で、利用人数が増えるほど単価が下がります。

- 2–9ユーザー：年払いで $35/ユーザー/月（月払いは $42）
- 10–19ユーザー：$33（$40）
- 20–79ユーザー：$23（$30）
- 80以上のユーザー：$19（$22）

注意すべきは「ユーザー」の定義です。価格ページによると、この単価は期日管理を行う人だけでなく、事務所または法務部門にある Microsoft 365 のライセンス付きメールボックスすべてに適用されます。さらに、iManage、NetDocuments、ECFX、InfoTrack との連携はそれぞれ $4/ユーザーが加算され、AI 機能は別料金、トレーニングも別途請求です。iManage を使う25メールボックスの訴訟ブティックなら、AI とオンボーディングを除いて年間約 $8,100（25 × ($23 + $4) × 12）を見込むべきです。MCP サーバーの価格は公開されていません。

## 最適な利用者

Microsoft 365 を使い、専任の docketing 部門を持たず、アプリケーションを増やさずに裁判所の期限を弁護士の Outlook カレンダーに載せたい、弁護士5〜150人程度の事務所の訴訟マネージャーやプラクティスサポート責任者に向いています。Microsoft 365 で訴訟を管理し、AI ツールを案件データに基づかせたい官公庁や企業の法務チームにも合います。

すでに [Clio](/ja/tools/clio/) を使っているなら見送ってください。Clio の手続規則機能は、Clio が2021年に買収した CalendarRules によるもので、事務所がすでに料金を払っているシステムの中で約2,300の管轄をカバーしています。ECF の通知をすべて照合する中央 docketing チームを持つ大規模事務所も見送るべきです。そこは Aderant の市場です。

## 代替製品との比較

**Aderant Milana と CompuLaw** は大規模事務所向けの定番です。Aderant によれば、規則は資格を持つ弁護士が社内で作成・保守し、2,900以上の管轄をカバーしています。Milana には ECF 照合と裁判所データフィードも加わります。docketing 部門が期限に責任を持ち、弁護士が保守する規則と ECF 照合が必要なら、こちらを選んでください。弁護士が自分で Outlook に期限を登録しており、Aderant の見積額が人員規模に見合わないなら、LawToolBox を選んでください。

**Clio と CalendarRules** は最も成長の速い選択肢です。Clio は2026年5月に ARR 5億ドルを突破し、手続規則機能はユーザー単位のアドオンとして販売されています（$15/ユーザー/月と報じられています）。Clio がすでに事務所管理システムであるなら、こちらを選んでください。案件が Clio ではなく Microsoft 365 と文書管理システムにあるなら、LawToolBox を選んでください。

**事務所管理ソフトに組み込まれた期限機能**（MyCase、Smokeball、Filevine など）は、手続規則の連鎖ではなくリマインダーだけが必要な小規模事務所には十分です。どれも合わない場合の代替策は、計算したすべての期限を別の担当者が必ず再確認する手作業の docketing です。時間はかかりますが、監査可能です。

## 注意点

- **メールボックス単位の課金で請求額が膨らみます。** 公開された条件では、パラリーガル、経理スタッフなど、ライセンス付きメールボックスを持つ人は全員ユーザーとして数えられます。*対策：*デモの前にライセンス付きメールボックスの数を確認し、ライセンスユーザーの定義を注文書に明記させてください。最初に求めるべきは、対象を訴訟チームに限定することです。
- **正確性のリスクは利用者が負います。** 期限計算機の利用条件には、自己責任での利用であること、正確性に関する一切の保証を否認することが明記されています。また、弁護士が保守する Aderant のプロセスとは異なり、LawToolBox は規則の保守方法を公開していません。*対策：*パイロット期間中に、利用の多い5つの裁判所で20件の期限を手計算し、結果を比較してください。管轄の一覧と規則改正時の更新期間を書面で取得してください。Texas の対応範囲や多当事者事件で抜けがあったという利用者の報告もあります。
- **同期は不安定だったことがあります。** Capterra のレビュー（53件で4.2/5）では、同期のために Outlook を開いたままにする必要があること、不要な期限でカレンダーが埋まること、PracticePanther との連携の弱さが挙げられています。大半は2021〜2022年のものです。*対策：*契約前に、デスクトップクライアントを閉じた状態で、新しい Outlook、Outlook on the web、モバイルでの同期をテストしてください。
- **セキュリティの説明は主に Microsoft のものです。** 案件の内容は自社のテナント内に残ります。一方、米国にある LawToolBox の Azure サーバーには案件名、ユーザー名、同社が作成するカレンダーイベントが保存され、セキュリティページは自社の監査ではなく Azure の認証を引用しています。*対策：*LawToolBox 自身の SOC 2 Type 2 レポートを求めてください。米国外で業務を行う場合は、保存されるメタデータのデータ所在地を確認してください。
- **案件データに対して70のツールを持つ AI クライアントには、独自のレビューが必要です。** *対策：*事務所全体に展開する前に、倫理的障壁で隔離された案件を使って MCP サーバーをテストし、除外されたユーザーの Claude や Copilot のセッションからその案件を読めないことを確認してください。MCP の価格と認証方式は書面で取得してください。
