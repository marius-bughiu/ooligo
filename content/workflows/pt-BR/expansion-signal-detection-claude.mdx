Um Claude Skill que escaneia cada call de CSM e picos de uso na sua base de clientes e mostra sinais concretos de expansion: novos use cases mencionados, equipes adicionais fazendo onboarding, perguntas de integração sobre features de tier premium e pedidos de capacidades que mapeiam para seus SKUs de upsell. Solta um digest semanal com uma lista ranqueada por CSM.

## O que você vai precisar

- Acesso ao Gong para calls de CSM (separadas das calls de vendas)
- Gainsight para detecção de anomalias de uso
- Claude Code ou Claude.ai com o Skill instalado
- Uma taxonomia de sinais mapeando menções para SKUs de upsell específicos
- Um destino de Slack ou email para o digest semanal

## Setup

1. **Construa a taxonomia de sinais.** Edite `references/expansion-signals.md` com cada SKU de upsell e as frases gatilho ou padrões de uso que indicam intent. Seja específico: não "mais usuários," mas "perguntou pricing para 50+ seats" ou "mencionou requirements de compliance."
2. **Instale o Skill.** Coloque `expansion-signals.skill` em `~/.claude/skills/`. Defina `GONG_API_KEY` e `GAINSIGHT_TOKEN`.
3. **Rode semanalmente.** `detect_expansion(window_days=7)`. O Skill escaneia cada call de CSM da janela mais cada pico de uso de mais de 30% week-over-week, depois mapeia sinais para SKUs e ranqueia por potencial de tamanho de deal.
4. **Roteie o digest.** A saída vai para um canal `#csm-expansion` no Slack e um email para cada CSM com sua lista personalizada. Top 3 por CSM, não 30.

## Como funciona

Para cada call de CSM, o Skill roda um prompt de extração: "Encontre qualquer menção de equipes adicionais, use cases além do escopo atual, interesse em features premium, ou metas de negócio declaradas que impliquem expansion." Cada match é logado com uma citação e um score de confiança.

Para uso, puxa eventos de uso do Gainsight e encontra contas com picos anômalos — particularmente em features que estão limitadas por tier. Uma conta de tier free batendo num limite de feature enterprise-only é um sinal. Um time que acabou de dobrar usuários ativos é um sinal.

O Claude depois sintetiza por conta: combina sinais de calls com sinais de uso, scora probabilidade de expansion, nomeia o SKU mais provável e sugere uma linha de abertura para o CSM usar na próxima conversa.

## Pontos de atenção

- **Fadiga de sinais.** Não mostre 30 sinais por CSM. Ranqueie para 3. Qualquer coisa além disso é ignorada.
- **Cobertura de calls de CSM.** Se os CSMs não estão logando calls, a metade de conversa do set de sinais está vazia. Audite a cobertura antes de depender disso.
- **Sinais mal classificados.** "Estamos pensando em sair" pode soar como "estamos pensando em expandir" para um prompt descuidado. Construa exemplos negativos no prompt do Skill.

## Stack

- **Gong** — corpus de calls de CSM
- **Gainsight** — fonte de anomalias de uso
- **Claude** — extração de sinais, mapeamento, ranqueamento
