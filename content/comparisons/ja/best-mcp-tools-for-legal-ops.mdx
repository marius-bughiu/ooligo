ooligo が追跡している法務システムのうち、現時点で実際に動く MCP サーバーを公開しているのは 6 つです。iManage、NetDocuments、Everlaw、Relativity、Docusign、そして Thomson Reuters の CoCounsel Legal。これに、無料で商用製品ですらない CourtListener が加わります。このページでは、今この瞬間に MCP が効いてくる場所を基準に順位をつけ、出荷済みのものと発表されただけのものを分けます。今年の Legal Ops の購買判断が狂うのは、まさにこの差のところだからです。

まずマーケティングが消してしまう区別から入ります。**法務における「MCP 対応」は 3 つの異なる意味を持ち、互いに置き換えられません。**

1. **ベンダーが運用するリモートサーバー**。公開されたエンドポイントがあり、任意の MCP クライアントを向けられます。iManage、NetDocuments、Everlaw、Docusign、CourtListener がここに入ります。アシスタントの選択権はあなたに残ります。
2. **ベンダーがあなたのインスタンス内に構成するコネクター**。Relativity がここです。動きますが、立ち上げるのはあなたではなくベンダーです。
3. **1 社のコンテンツを 1 つのアシスタントの中に置く提携**。Thomson Reuters と Claude がここです。価値は本物ですが、可搬性は実証されていません。

Anthropic の Claude for Legal は 2026-05-12 に、20 を超える法務コネクターと 12 の実務分野プラグインを 1 日で投入しました。カテゴリが実態より大きく見えるのはそのためです。あのディレクトリに載っているという事実が示すのは、そのシステムが Claude から到達できるということだけです。ベンダーが、Cursor や Codex や自作エージェントからも到達できるサーバーを運用しているという意味ではありません。

## 1. iManage — DMS サーバーの中で最も可搬性が高い

2026-05-14 に提供開始が発表されました。エンドポイントは `https://cloudimanage.com/mcp/work`、streamable HTTP 上の OAuth で、iManage は Claude Code、Codex、Cursor、VS Code に対して文書化しています。特定の 1 アシスタント向けではありません。アクセスは認証され、権限に縛られ、ログに残り、既存の情報遮断壁を迂回せずそこを通ります。事務所のファイル管理委員会が承認に回るのは、まさにこの点です。

得られるのは、事務所がすでに信頼している成果物に根拠を置いた検索です。案件コンテキストと文書はその場で読まれ、一括エクスポートは発生しません。iManage 自身の発表が、クライアントとして Harvey、Legora、ChatGPT、Claude、Microsoft Copilot を挙げています。このベンダー中立性こそが、このリストの他のすべてに対する本当の差別化要因です。

**注意点:** iManage は、サーバーがどのツールを公開するのか、書き込むものがあるのかを公開していません。担当者から書面で確認が取れるまでは読み取り専用と想定し、文書を書き戻すことに依存するワークフローの規模を見積もらないでください。

**着手点:** 1 つのプラクティスグループを接続し、進行中の案件に対して先例検索をかけます。回答が、依頼した弁護士がもともと開ける文書だけを引用し、それ以外を引かないなら、情報遮断壁の説明は成立しています。

## 2. CourtListener — ライセンス交渉のいらない一次法源

Free Law Project は 2026-05-12 に、CourtListener を `https://mcp.courtlistener.com/` でホストされる MCP サーバーの背後に置きました。判例、PACER の訴訟記録、引用分析、裁判官データ、口頭弁論の書き起こし、検索、アラートが対象です。CourtListener のアカウントには API アクセスが自動で付いてくるため、試すコストはゼロで、通るべき購買プロセスもありません。

2 位に置いたのは、1 ドルあたりの見返りが比較にならないからです。ここにある他のサーバーはすべて、あなたがすでに 5 桁か 6 桁を払っているサブスクリプションの背後にあります。こちらはメールアドレスと 10 分で足ります。

**注意点:** 制約は機能ではなくスループットです。上位のアクセスは Free Law Project のメンバーシップか商用契約を通るので、量を前提にしたリサーチワークフローを組む前に価格を確認してください。

**着手点:** エンドポイントを Claude Code か Cursor に追加し、すでに提出済みの書面に対して引用チェックを 1 回走らせます。公開データで作文ワークフローが賄えるのか、有料の引用チェッカーがまだ要るのかが、すぐに分かります。

## 3. Everlaw — 法務分野で最も文書化されたサーバー

Everlaw は 2026-05-12 に統合を発表し、ここに挙げたベンダーの中で唯一、実用に足る開発者リファレンスを公開しています。エンドポイントは `https://api.everlaw.com/v1/mcp`、RFC 9728 の保護リソースメタデータを備えた OAuth 2.0 で、公開するツールはちょうど 4 つです。`GetProjectBinders`、`PostProjectSearch`、`GetProjectSearchResult`、`DescribeProjectSearchTerm`。すべて読み取り専用です。検索は 20 を超える条件 — Bates 範囲、メタデータ、本文テキスト、コーディング、マスキング、プロダクション — を論理演算子とグルーピングで組み合わせ、結果は文書 ID、Bates 番号、レビュー URL を返します。

すべての操作はサインイン中のユーザーの権限で走ります。そのユーザーが Everlaw の Web UI でできないことは、サーバーにも見えず、実行もできません。レート制限は IP 単位、アクセストークン単位、ユーザー単位、同時ツール呼び出し単位で文書化されており、ツール呼び出し制限では 60 秒後の再試行が明示されています。

**注意点:** サーバーは自身をバージョン 0.1.0 と申告しており、検索結果を最初にページングした後で文書が追加・削除・編集されると結果は陳腐化します。出力が提出物につながる場合は、古い ID をページングせず、検索を新しく走らせてください。

**着手点:** 終結済みの案件に向け、Bates 範囲に対する privilege log の妥当性チェックを依頼します。読み取り専用かつ終結案件という組み合わせは、この検索言語が実際に何を表現できるかを見極める最も安価な方法です。

## 4. NetDocuments — 能力は同等、権利付与が難しい

NetDocuments は `https://web-api.us.netdocuments.app/connect/mcp` にリモート MCP エンドポイントをホストしており、エージェントは認証済みユーザーの代理で文書を検索・取得します。能力は iManage と互角です。権利付与はそうではありません。

ndConnect は 2 つの製品を指します。**Standard** はすべての NetDocuments 顧客に提供され、手動です。人がピッカーで文書を選び、承認済みのパートナーアプリに読み込ませます。**Enterprise** が MCP の階層で、ndMAX Enterprise が必要です。NetDocuments はこの拡張接続を、ndMAX Enterprise 顧客向けに 2026-04-01 からと日付を切りました。2026-07-18 という比較的新しい第三者の導入手順書でも、組織が限定プライベートプレビューへの承認を必要とし、接続する各ユーザーが自分の有効な AI 300 シートを必要とする、と記述されていました。課金単位は AI を使う人数であって、全社員数ではありません。NetDocuments 自身の統合ページは Standard と Enterprise の区分と ndMAX Enterprise 要件を明記していますが、GA なのかプレビューなのかは、どちらの方向にも明記していません。

**注意点:** 「MCP に対応している」と「今四半期に有効化できる」が別の文になる唯一の項目がこれです。これを前提に展開を計画する前に、プレビューの承認状況と、接続ユーザーあたりのシート数を書面で取ってください。

**着手点:** 担当者に 2 つ質問します。当社の組織は承認されているか、そして弁護士 N 人を接続すると AI 300 シートでいくらか。他の判断はすべて、この 2 つの答えから導かれます。

**[NetDocuments の詳細レビュー →](/ja/tools/netdocuments/)**

## 5. Relativity — 書き込むが、対象はワークスペースであって証拠ではない

Relativity の MCP は現時点で利用可能ですが、公開エンドポイントからのセルフサービスではなく、Relativity のサポートがあなたのインスタンスに構成します。やることは管理系です。ワークスペースの立ち上げ、案件データの整理、マターの管理、グループ割り当ての調整、アクセスのレビュー、利用状況のレポート。書き込みます。

機能一覧よりも位置づけのほうが重要です。Relativity は MCP と aiR が仕事を分担すると明言しています。MCP がワークスペースを整えてチームを配置し、aiR がその中の証拠を分析します。「Relativity は MCP に対応している」を「Claude が自分の文書をレビューできる」と読んだ買い手は、頭の中の製品を取り違えており、見積もる対象を間違えます。

**注意点:** 管理系のスコープは、範囲設定を誤ったエージェントが実害を出す場所そのものです。保護命令のかかった案件において、グループ割り当てはアクセス制御の面だからです。進行中のワークスペースにエージェントを向ける前に、書き込み操作を人間の承認の後ろに置いてください。

**着手点:** テスト用ワークスペースを与え、マターを端から端まで立ち上げさせます。ワークスペース、グループ、フォルダ構造まで。それがこの機能の設計目的であり、プロジェクトマネージャーの午前中をまるごと節約する作業です。

**[Relativity の詳細レビュー →](/ja/tools/relativity/)**

## 6. Docusign — 書き込めるが、まだベータ

Docusign は Momentum 2026 で、Agreement Manager API と IAM Toolkit と併せて MCP サーバーを `https://mcp-d.docusign.com/mcp` に出荷しました。到達先は Intelligent Agreement Management プラットフォームです。契約の作成・送信・管理、署名ステータスの確認、契約データの照会、Maestro ワークフローの起動。開発者アカウントと本番アカウントの双方でオープンベータであり、申請フォームも承認ステップもありません。

書き込めて、しかもセルフサービスなのは、このリストでここだけです。同時に、ベンダーがベータと表示し、無保証の「as is」で提供している唯一の項目でもあります。

**注意点:** エンベロープを送るエージェントとは、間違ったエンベロープを間違った相手方に送りうるエージェントです。そしてベータは、不可逆な操作の下に置く状態としては不適切です。表示が外れるまでは読み取りと下書きに留め、送信ステップには人を置いてください。

**着手点:** Agreement Manager API が抽出する条項 — `expiration_date`、`renewal_type`、`renewal_notice_date` — と組み合わせ、更新エクスポージャーのレポートを作ります。読み取り側の価値だけを取り、送信リスクは負いません。

**[Docusign IAM の詳細レビュー →](/ja/tools/docusign-iam/)**

## 7. CoCounsel Legal — 最大のコーパス、最も可搬性の低い接続

Thomson Reuters と Anthropic は 2026-05-12 に MCP 統合を発表し、Westlaw と Practical Law の 19 億件の文書を Claude の手の届くところに置きました。対象は 107 か国の 100 万人超と公称される法務プロフェッショナルです。作り直された CoCounsel Legal は Anthropic の Claude Agent SDK 上で動き、2026 年 6 月に早期アクセスを開始、Thomson Reuters は米国での一般提供を 2026 年 8 月に置き、その後カナダ、英国、オーストラリアと続けるとしています。

Thomson Reuters が、他の MCP クライアントから認証できるサーバーを運用しているという記述は、公開情報のどこにもありません。統合の説明はすべて一方向です。Claude が CoCounsel Legal に接続する、という向きです。Thomson Reuters が別のことを言うまでは、可搬なサーバーではなく Claude 統合として扱ってください。

**注意点:** ここでの順位は可搬性の話であって、品質の話ではありません。コーパスの強さではこのページで最上位です。事務所がすでに Claude に標準化しているなら、これはリスト中で最も価値の高い項目であり、順位に引きずられるべきではありません。

**着手点:** 米国の CoCounsel 顧客なら、作り直された体験への切り替えは製品内にあります。1 つのリサーチ課題を両方の経路で走らせ、文章ではなく引用を比べてください。

**[CoCounsel の詳細レビュー →](/ja/tools/thomson-reuters-cocounsel/)**

## MCP 対応では手に入らないもの

買い手が置きがちな前提のうち、プロトコルが支えてくれない 5 つです。それぞれに歯止めを付けます。

- **AI は手に入りません。** これらのサーバーが供給するのは根拠付きの検索であり、推論は接続したクライアント側のものです。**歯止め:** アシスタントのライセンスは別枠で予算化し、DMS ベンダーの MCP 発表を AI 評価の代わりにしないでください。
- **権限は広がりません。これは両刃です。** Everlaw のサーバーはサインイン中のユーザーのアクセスを超えられず、iManage のものは情報遮断壁を通ります。それがガバナンス上の利得です。同時に、範囲の広すぎるアカウントは範囲の広すぎるエージェントを生むという意味でもあります。**歯止め:** シニアパートナーのものではなく、アクセス権を実際に監査した ID で接続してください。
- **書き込みアクセスを意味しません。** 法務の MCP 面はほとんどが読み取り寄りです。Relativity と Docusign は書き込み、Docusign はベータです。**歯止め:** 提出・送信・再割り当てを行うものを設計する前に、サーバーごとにスコープを確認してください。
- **コンテンツがその場に留まる意味ではありません。** iManage 自身のリリースが、その接続でどのデータが iManage の外に出て、どう扱われるのかをベンダーと確認するよう顧客に求めています。権限に縛られた検索はデータレジデンシーではありません。**歯止め:** 進行中の案件を接続する前に、送信先、保持期間、学習利用の条件を DPA で確定してください。
- **ライセンス費用は消えません。** NetDocuments が最も明確な例です。MCP は ndMAX Enterprise と、接続ユーザーあたりの AI 300 シートの背後にあります。**歯止め:** AI 階層は事務所単位ではなく、接続する人数単位で見積もってください。

## 実用最小限の法務 MCP スタック

3 つから始めるなら、この順です。

1. **自社の DMS** — iManage か NetDocuments のうち、すでに持っているほう。日々の仕事を変えるのはこれです。事務所の本当の答えが置かれている場所だからです。
2. **CourtListener** — 無料で、有料の引用チェッカーが予算行を正当化できるかを判断するあいだ、一次法源の下限を埋めます。
3. **Everlaw か Relativity**。ディスカバリーを内製しているなら。プロジェクトデータに対する読み取り側の検索なら Everlaw、ワークスペースとマターの立ち上げなら Relativity です。

Docusign はベータ表示が外れた日に加えます。CoCounsel Legal は Claude に標準化する日に加えます。それより前ではありません。それまでは、動かせない接続を買うことになるからです。

## このリストに載っていないもの（とその理由）

- **Harvey、Legora、Definely** — Claude for Legal のコネクターディレクトリに載っており、Harvey 自身は iManage のサーバーの名指しのクライアントでもあります。これらは MCP で到達できるアプリケーションであって、記録システムではありません。根拠付けのためではなく、生み出すもののために接続してください。
- **Ironclad、Box、Trellis、Midpage、Consilio、Solve Intelligence** — 本物のコネクターですが、スコープはより狭いものです。上に挙げたシステムが動いた後なら加える価値があります。最初に並べる価値はありません。
- **Clio、MyCase、Filevine** — Clio 向けに存在する MCP サーバーはコミュニティ製の第三者実装であり、ベンダー運用ではありません。これはリスクの質が違います。事務所管理の認証情報を、あなたのベンダーでもなく、契約上何の義務も負わない相手に渡すことになります。ベンダー製サーバーはまず市場のエンタープライズ側に来ており、小規模事務所は待っている状態です。
- **Microsoft Purview eDiscovery** — ベンダー製の MCP サーバーはありません。ディスカバリーのワークフローは Microsoft 自身のツール群の内側に留まります。M365 に住んでいるなら問題ありませんが、可搬な接続が欲しかったのなら行き止まりです。
