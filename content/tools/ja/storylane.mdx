## 概要

Storylane はデモ自動化プラットフォームです。製品を一度キャプチャすれば、Web サイト、メール、ディールルーム、あるいはライブ商談中の見込み客の前で、クリック操作できるデモとして公開できます。スクリーンショット、動画、サンドボックスのように動作する HTML/CSS クローンという3種類のキャプチャ方式を1つの製品でカバーしているため、マーケティングの Web サイト用ツアーも、SE が商談後に残す資料も、同じライブラリから作れます。独立企業で、5,000 以上の顧客チームと 200,000 件以上の作成済みデモを公表しています。2024年12月にプリセールス管理ツールの PreSkale を買収し、それ以降、製品はデモから販売へと広がりました。プレゼンター用デモ、Deal Intelligence、そして Web サイト上で動き、会話の途中でデモを呼び出す対話型 AI SDR の RepX です。

## RevOps のスタックに入る理由

- **3つのチームで1つのデモライブラリを使えます。** プロダクトマーケティングが Web サイト用ツアーを作り、営業がディスカバリー後にパーソナライズしたコピーを送り、プリセールスが商談中にサンドボックスを動かします。パーソナライズトークンが見込み客の名前、ロゴ、データを差し込むため、デモを作り直す必要はありません。
- **デモのエンゲージメントがパイプラインデータになります。** リードフォーム、Account Reveal（匿名訪問者の企業特定）、CRM 同期によって、誰が何を見たかが [HubSpot](/ja/tools/hubspot/) や [Salesforce](/ja/tools/salesforce/) に送られます。HubSpot アプリはデモのエンゲージメントをトリガーにしたワークフローに対応しており、ツアーを最後まで見たコンタクトをシーケンスに登録したり、担当者に通知したりできます。
- **GTM 連携の幅が広いです。** ドキュメント化されたコネクタには HubSpot、Salesforce、Dynamics 365、Freshsales、Marketo、Pardot、[Gong](/ja/tools/gong/)、[Outreach](/ja/tools/outreach/)、[Chili Piper](/ja/tools/chili-piper/)、[Calendly](/ja/tools/calendly/)、[Slack](/ja/tools/slack/)、[Intercom](/ja/tools/intercom/)、Clearbit、[6sense](/ja/tools/6sense/)、[Seismic](/ja/tools/seismic/)、Highspot、Segment、Google Analytics、[Zapier](/ja/tools/zapier/)、Webhook が含まれます。
- **エージェントがデモを作成・送信できます。** Storylane の MCP サーバー（Starter プラン以上、OAuth でサインイン）を使うと、[Claude](/ja/tools/claude/) や [ChatGPT](/ja/tools/chatgpt/) からアプリを開かずにデモの作成、パーソナライズ、共有、レポートができます。ChatGPT では、書き込み操作にまだベータ版の Developer Mode が必要です。

## 料金

Storylane は定価を公開しています。年払いは月払いより 20% 安く、デモの閲覧者数によって料金は上がりません。

- **Free — $0。** 1 シート、同時に公開できるデモは1件、スクリーンショットと動画のデモのみ、閲覧数は無制限です。
- **Starter — 年払いで月 $40**（月払いは $50）、1 シート、追加シートは1つあたり $40。デモ無制限、カスタムブランディング、HubSpot と Zapier、MCP サーバー、月 250 件の Account Reveal が付きます。HTML キャプチャはありません。
- **Growth — 年払いで月 $500**（月払いは $625）、5 シート、追加シートは1つあたり $100。HTML エディター、パーソナライズトークン、A/B テスト、月 2,500 件の Account Reveal、チーム別ワークスペースが加わります。Hubs（ディールルーム）は別料金です。
- **Premium — 年払いで月 $1,200**（月払いは $1,500）、10 シート。サンドボックスデモとプレゼンター用デモ、Hubs、Deal Intelligence、オフラインデモ、多言語対応、SSO、ホワイトラベル URL、Salesforce 連携が加わります。
- **Enterprise — 個別見積もり。** API アクセス、非公開デモリンク、プロフェッショナルサービスが加わります。
- **RepX は別料金です。** Growth は月間 Web サイト訪問者 10,000 人までで月 $2,000 から、Premium は訪問者 40,000 人までで月 $3,000 からで、動画アバターでの会話と複数エージェントに対応します。どちらも Demo Suite のライセンスと 30 日間の無料トライアルが付きます。
- **実際の支払額。** Vendr によると Storylane の契約額の中央値は年 $15,330 で、範囲は $3,000 から $50,000 以上、交渉した契約は定価の 15〜25% 下で決まっています。この中央値は Premium の定価（年 $14,400）をわずかに上回るため、Salesforce やサンドボックスデモが要件に入った時点で Premium を前提に計画してください。

## 最適な利用者

- Web サイト用のクリック操作できるデモと、営業担当が残す資料を同じツールで、HubSpot 程度の予算で用意したい B2B SaaS 企業のプロダクトマーケティングおよびデマンドジェネレーションの責任者
- エンジニアリングが構築したデモ環境なしで、サンドボックスデモとパーソナライズしたフォローアップを実現したい、ミッドマーケットのソフトウェアベンダーのプリセールス・SE チーム
- ライブデータと実際の連携を見せる必要がある製品のチーム（デモ環境や本物のトライアルはどんなキャプチャにも勝ります）や、単発のチュートリアル GIF（無料の画面キャプチャツールで十分です）には向きません

## 代替ツールと選ぶべきケース

- **Navattic** — ほぼすべての直接比較で名前が挙がる競合です。有料プランのキャプチャ方式は HTML のみで、Salesforce と Marketo は $1,200 の上位プランではなく、年払いで月 $500 の Base（5 シート）から使えます。HTML デモがすべてという、Salesforce 上の PLG 製品の Web サイト用デモなら Navattic を選んでください。月 $125 の Startup プランは、従業員 30 人以下で自己資金またはシード段階の企業に限定されています。
- **Arcade** — 無料利用の広がりが最大です（企業プロファイルデータによると 20,000 社以上）。Growth は年払いで月 $42.50、最大 10 シートですが HTML キャプチャはなく、Arcade はそれをネイティブの Salesforce 連携とともに Enterprise に限定しています。デモが営業資産ではなく、ローンチや SNS 投稿用の完成度の高いスクリーンショット・動画ツアーであれば Arcade を選んでください。
- **Supademo** — 最も急成長している新興勢力で、G2 の急成長製品ランキングに入っています。2026年6月には独自の AI Demo Agent をリリースしました。Scale は年払いでクリエイター1人あたり月 $38、HTML デモは5クリエイターで月 $350 の Growth から使えます。Storylane と同等の機能をより低いシート単価で使いたく、連携先が少なくても問題ない場合に選んでください。
- **Walnut** — 営業主導でエンタープライズ価格です。Vendr の 36 件の購入実績で中央値は年 $17,000、無料プランはありません。大規模な営業チーム全体で、データを編集した本格的なサンドボックスデモが SE に必要で、予算が制約にならない場合に Walnut を選んでください。
- **[Qualified](/ja/tools/qualified/)** — RepX が検討の理由なら、専用の AI SDR と比較してください。チャット内で製品を見せることより、Salesforce ネイティブのルーティングとパイプラインのアトリビューションが重要なら Qualified を選んでください。

## 注意点

- **Salesforce は Premium の機能です。** Starter には HubSpot と Zapier が含まれますが、Salesforce 連携は定価で年 $14,400 の Premium で初めて使えます。対策：Salesforce が CRM なら最初から Premium で見積もるか、Growth を購入する前に、Zapier や Webhook による同期でアトリビューション要件を満たせることを書面で確認してください。
- **プランでキャプチャ方式が決まります。** Free と Starter はスクリーンショットと動画のデモのみで、HTML 編集は Growth から、サンドボックスデモは Premium からです。対策：プランを絞り込む前に、買い手にどのキャプチャ方式で見せる必要があるかを決め、トライアル中に製品で最も再現が難しい画面を作ってください。
- **ブランド表現が複雑だとデザインの自由度が足りなくなります。** カスタマイズの深さは、G2 の Storylane レビューで最も多く繰り返される不満です。対策：最もブランド要素の強いページをパイロットデモとして再現し、年間契約の前にデザインチームの承認を得てください。
- **RepX は2つ目の製品であり、2つ目の契約です。** 年 $24,000 からで、すでに運用しているチャットエージェントと競合します。対策：訪問者 1,000 人あたりの商談予約数をベースラインにして 30 日間のトライアルで比較し、同じページで2つの AI エージェントを動かさないでください。
- **エージェントが公開・共有できます。** MCP サーバーは接続したユーザーの権限で書き込みができます。対策：サンドボックス用ワークスペースに限定したクリエイターシートで MCP を接続し、本番 Web サイトへの公開はエディターでの人によるレビューを経るようにしてください。
- **UI が変わるとキャプチャしたデモは古くなります。** HTML キャプチャはキャプチャした日の製品の姿を表示します。対策：公開中のデモごとに担当者を指名し、大きな UI リリースのたびに再キャプチャし、2四半期更新されていないデモは取り下げてください。
