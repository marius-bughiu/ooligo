## 何をするツールか

Metaview は6年間、面接メモを売ってきました。今売っているのはソーシングエージェントであり、それを露呈しているのが価格ページです。metaview.ai/pricing に掲載された数字はすべて Sourcing という単一エージェントの価格で、この会社の名前をつくった Notetaker は見積もり対応のみです。トップページの見出しは「The Agentic Recruiting Platform built for radically efficient hiring, end to end」で、製品は Sourcing、Application Review、Screening、Notetaker、Reports の5つのエージェントで構成されます。構造的に最も近い比較対象はもはや [BrightHire](/ja/tools/brighthire/) ではありません。[hireEZ](/ja/tools/hireez/) です。面接キャプチャを後付けしたソーシングプラットフォームであって、その逆ではありません。

## Recruiting スタックに入る理由

- **ソーシングエージェントが、すでに自社が持つ面接データの上で動く。** このエージェントに対する Metaview 自身の主張は再発見です。オープンな Web だけでなく、ATS とすでに録画済みのスクリーニングを検索します。純粋なソーシングツールには検索対象となる書き起こしコーパスがありません。面接を録画していないからです。ポジション転換があなたに実際にもたらすのはこの一点だけであり、これが効くのは以前から Notetaker の顧客だった場合に限られます。
- **MCP サーバーを備え、Metaview は Claude のコネクタとして掲載されている。** Claude はワークスペースから書き起こし、AI ノート、構造化フィールド、スコアカードを直接読み取ります。1つの求人の候補者を比較する、先週のスクリーニングから懸念シグナルを抽出する、募集中のポジション横断で希望年収を確認する — いずれもエクスポートなしで行えます。面接キャプチャのベンダーとしては今も珍しい機能です。
- **約40件の ATS 連携をセルフサービスで提供。** ヘルプセンターには Greenhouse、Ashby、Lever、Gem、SmartRecruiters、Workday、SAP SuccessFactors、iCIMS、Bullhorn、Workable、Teamtailor、Recruitee、Loxo、JazzHR、Pinpoint ほか約25件が記載され、導入プロジェクトではなく管理パネルから設定できます。

## 料金

公開されている料金体系がカバーするのは **Sourcing のみ**です。課金はユーザー単位の月額で、同時検索数はどのプランでも無制限です。

- **Free** — $0。最初の100プロファイルの sourced 分。
- **Pro** — $100/ユーザー/月。月あたり200プロファイルの sourced 分。
- **Max** — $300/ユーザー/月。sourced プロファイル無制限。
- **Enterprise** — 個別見積もり。カスタム数量、専任サポートとトレーニング、エンタープライズ向けセキュリティ管理。

Notetaker、Application Review、Screening に公開価格はなく、エージェント単位の見積もりです。つまり2つのエージェントを動かすチームは1人あたり2本の請求を払います。Reports はレポート単位の課金がない定額アドオンで、アシスタントへの質問とノートの再生成は追加費用なしで含まれます。

購買判断を決める数字は、消えた方の数字です。$30/ユーザーの旧 Starter プランは廃止され、Metaview の有償シートの入口は $30 から $100 へ移りました。課金単位も、録画した面接数から sourced プロファイル数 — リクルーターの活動量ではなくエージェントの出力 — へ変わっています。月200プロファイルは、稼働中の検索2〜3本と読んでください。募集中の求人を6件抱えるリクルーターはこれを使い切ります。つまりフルタイムでソーシングする人にとっての実質的な価格帯は $100 ではなく $300 です。Max のリクルーター5人で定価年間 $18,000 — BrightHire の中央値契約額（Vendr、57件の取引、2026年2月）と同じ数字を、別の製品に払うことになります。

## 向いているチーム

Greenhouse、Ashby、Lever のいずれかを使い、Metaview に1年分のスクリーニング録画が貯まっていて、それを土台にソーシングをしたい 3〜25人規模の社内 TA チーム。具体的には、直近2四半期のスクリーニングの中で新規オープンした求人に合致する候補者は誰かを Claude に尋ね、その傾向をソーシングエージェントに与えて同種の候補者を探させる TA リードです。

面接インテリジェンスだけが目的なら向きません。Notetaker はもはや価格の付いた製品ではなく、ロードマップはソーシングを向いており、他社の戦略転換の内側で見積もり対応のモジュールを買うのは更新時に弱い立場です。プログラムからの書き込みが必要な場合も向きません。ドキュメント化された REST API も Webhook も存在せず、MCP の読み取りと Zapier が接続面のすべてです。

## 代替候補との比較

- **[hireEZ](/ja/tools/hireez/)** — Solo Recruiter シートが $494/月、Enterprise は見積もり、契約額の中央値は $13,000/年。ソーシングが業務のすべてで、掘り起こす面接コーパスがないなら hireEZ です。あちらは候補者データベースそのものが製品ですが、Metaview ではそれは副産物です。
- **[LinkedIn Recruiter](/ja/tools/linkedin-recruiter/)** — 物量の既存王者。LinkedIn が公開している G-Cloud 価格表では 1〜2ライセンスで1シートあたり年間およそ £8,900、Hiring Assistant はシート単位の別建てです。ランキング品質よりも潜在候補者へのリーチが重要なら選んでください。ただし250シートを下回る範囲では割引カーブがほとんど動かないことは前提にしてください。
- **[Juicebox](/ja/tools/juicebox/)** — 最も成長が速い新規参入。年間契約で $99/シート/月、コンタクトクレジット500件付き、エージェントは1体 $199。LinkedIn の10分の1のコストで自然言語検索を使いたく、初日から ATS への書き戻しが要らないなら Juicebox です。
- **[BrightHire](/ja/tools/brighthire/)** — 2025年12月に Zoom が買収。予算を投じたい課題がソーシングではなく面接の品質であり、はるかに大きなロードマップの中に入った製品の統合リスクを許容できるなら選んでください。

## 注意点

- **公開価格がカバーするのは5つのエージェントのうち1つだけ。** 価格ページを見て1シート $100 で予算を組み、後から Notetaker が別見積もりだと気づくチームが出ます。ガード：動かす予定のエージェントは同じ商談の中ですべて見積もりを取ること。Free プランが「数字は決まった」と誰かに思わせる前に済ませます。
- **請求を動かすのはシート数ではなく sourced プロファイル数。** 求人負荷の高いリクルーター1人が Pro の枠を2週間で使い切ることがあり、次の段は3倍の価格です。ガード：まず Free で2週間動かし、検索1本あたりの返却プロファイル数を数え、求人あたり50件を超えるなら Max を前提にサイジングします。
- **既存顧客の足元でカテゴリーが動いた。** 2024年にスコアカード自動化として買ったエントリが、今はソーシングプラットフォームの1項目です。ガード：更新前に、自社 ATS へのスコアカード書き戻しが現場のハイアリングマネージャーが使うフィールドを今もカバーしているか確認してください。連携先の一覧は広いものの、ATS ごとの深さは記載がなくばらつきます。
- **MCP は面接データに対して読み取り専用。** 質問にはよく答えますが、レコードを修正することはできません。ガード：記録の正本は ATS に置き、Metaview MCP は書き込み経路ではなく分析面として扱います。
- **データは AWS UK に置かれ、保持期間の既定は2年。** 英国や EU の雇用主には妥当な既定ですが、米国の規制業種にとっては未解決の論点です。ガード：保持期間は契約時に明示的に設定し（Metaview は依頼に応じて変更します）、データ所在地の扱いは SOC 2 Type II が担保していると仮定せず、自社のプライバシーレビューで確認してください。
