Cursor es un editor de código con un agente que puede buscar en el repositorio, modificar archivos y ejecutar comandos. Úsalo cuando un cambio en RevOps requiera revisar el código. Por ejemplo, pídele que localice la función que convierte las etapas de venta durante una importación al CRM. Dale una fila ficticia con una etapa desconocida. Antes de aceptar el cambio, exige una prueba que aparte esa fila para revisión sin escribir en el CRM. [Agente de Cursor](https://cursor.com/docs/agent/overview)

## Qué incluye la suscripción

Para nuevas suscripciones individuales, Free ofrece uso limitado del agente. Plus cuesta 8 USD al mes y excluye los modelos de terceros. Premium cuesta 30 USD al mes e incluye agentes en la nube. Si eliges un modelo Claude con Premium, el consumo se cobra aparte al precio de lista de la API y se descuenta del saldo prepago. Son precios web mensuales antes de impuestos, consultados el 2 de noviembre de 2026. [Precios de Cursor](https://cursor.com/pricing) · [Modelos y facturación](https://cursor.com/docs/models-and-pricing)

Los clientes que conservan el antiguo plan Pro de 20 USD pueden seguir usándolo con sus condiciones de consumo. Cursor indica que cambiar a la nueva suscripción es opcional e irreversible. Antes de presupuestar la próxima factura, comprueba el plan que figura en tu cuenta. [Condiciones de los planes anteriores](https://cursor.com/docs/account/pricing/legacy-cursor-plans)

## Para qué sirven la API y MCP

La API Cloud Agents v1 está en beta pública. Desde un programa se puede iniciar un agente en un repositorio conectado con `POST /v1/agents` y consultar su ejecución. Entre los proveedores admitidos están GitHub y GitLab. Hace falta un repositorio autorizado, una cuenta con acceso y una clave de API de usuario o de cuenta de servicio. [API Cloud Agents](https://cursor.com/docs/cloud-agent/api/endpoints)

MCP permite exponer herramientas externas concretas mediante un servidor configurado en Cursor. Si el agente solo necesita la definición de un campo del CRM, usa una conexión de solo lectura. La clave que inicia el agente en la nube no concede por sí sola permiso de escritura en el CRM. [Configuración de MCP](https://cursor.com/docs/mcp)

## Antes de compartir un repositorio

Los usuarios individuales pueden activar Privacy Mode en la configuración. Un administrador también puede configurarlo para su equipo. Cursor explica que, con ese modo activo, excluye los datos del cliente del entrenamiento. Describe excepciones de conservación en investigaciones de abusos y para ciertos modelos. Comprueba el modo, el modelo y los repositorios autorizados en tu cuenta. [Seguridad de Cursor](https://cursor.com/security) · [Uso de datos](https://cursor.com/data-use)

Si ya pagas por Claude, prueba la importación de dos filas de la [comparativa de Claude y Cursor](/es/vs/claude-vs-cursor/) para decidir cuánto te aporta el editor.
