Cursor est un éditeur de code doté d’un agent qui peut explorer le dépôt, modifier des fichiers et exécuter des commandes. Utilisez-le pour les changements RevOps qui exigent une revue de code. Demandez-lui, par exemple, de retrouver la fonction qui associe les étapes de vente lors d’un import CRM. Donnez-lui une ligne fictive qui contient une étape inconnue. Avant de valider la modification, exigez un test qui mette cette ligne de côté pour vérification sans écrire dans le CRM. [Agent de Cursor](https://cursor.com/docs/agent/overview)

## Ce que couvre l’abonnement

Pour un nouvel abonnement individuel, Free propose un usage limité de l’agent. Plus coûte 8 USD par mois et exclut les modèles tiers. Premium coûte 30 USD par mois et comprend les agents dans le cloud. Si vous choisissez un modèle Claude avec Premium, son usage est facturé en supplément au tarif public de l’API et débité d’un crédit prépayé. Ces prix mensuels sur le web sont hors taxes et ont été vérifiés le 2 novembre 2026. [Tarifs de Cursor](https://cursor.com/pricing) · [Modèles et facturation](https://cursor.com/docs/models-and-pricing)

Les clients de l’ancienne offre Pro à 20 USD par mois peuvent la conserver avec ses conditions d’utilisation. Cursor précise que le passage au nouvel abonnement est facultatif et définitif. Vérifiez l’offre active sur votre compte avant d’estimer la prochaine facture. [Conditions des anciennes offres](https://cursor.com/docs/account/pricing/legacy-cursor-plans)

## À quoi servent l’API et MCP ?

L’API Cloud Agents v1 est en bêta publique. Un script peut lancer un agent sur un dépôt connecté avec `POST /v1/agents` et consulter son exécution. Cursor accepte notamment les dépôts GitHub et GitLab. Il faut un dépôt autorisé, un compte ayant accès à la fonction et une clé API d’utilisateur ou de compte de service. [API Cloud Agents](https://cursor.com/docs/cloud-agent/api/endpoints)

Un serveur MCP configuré dans Cursor permet d’exposer certains outils externes à l’agent. Si celui-ci a seulement besoin de la définition d’un champ du CRM, donnez-lui un accès en lecture seule. La clé qui lance un agent dans le cloud ne confère à elle seule aucun droit d’écriture dans le CRM. [Configurer MCP](https://cursor.com/docs/mcp)

## Avant d’autoriser l’accès au dépôt

Un utilisateur individuel peut activer le Privacy Mode dans les réglages, et un administrateur peut le configurer pour son équipe. Cursor précise que ce mode exclut les données du client de l’entraînement. Le fournisseur décrit des exceptions de conservation pour les enquêtes sur les abus et pour certains modèles. Vérifiez le mode actif, le modèle choisi et les dépôts autorisés dans votre espace. [Sécurité de Cursor](https://cursor.com/security) · [Utilisation des données](https://cursor.com/data-use)

Si vous avez déjà un abonnement Claude, essayez l’import de deux lignes du [comparatif entre Claude et Cursor](/fr/vs/claude-vs-cursor/) pour juger de l’intérêt de l’éditeur.
