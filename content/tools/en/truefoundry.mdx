## What it is

TrueFoundry is an enterprise AI gateway that puts model traffic and agent tool traffic behind one control plane. The **AI Gateway** gives every app and agent one OpenAI-compatible endpoint with one gateway key; provider keys are stored once in the gateway, and it handles routing (latency-based, weighted, geo-aware), fallbacks, caching, budgets, rate limits, guardrails and per-request logs. The **MCP Gateway** does the same for MCP servers: a central registry, federated login through Okta or Azure AD, OAuth 2.0 token handling, RBAC per server and per tool, and approval flows for who may use which server. A newer **Agent Gateway** adds an agent registry and step-level tracing on top.

What sets it apart from most gateways is the platform underneath. TrueFoundry started as a Kubernetes platform for deploying and serving models, so the same control plane serves self-hosted models through vLLM, SGLang, KServe and Triton, and it deploys into your VPC, on-prem or air-gapped. On June 24, 2026 it acquired Seldon, the UK-based company behind the open-source Seldon Core model-serving project, and with it Seldon's enterprise customers in banking, insurance and retail. Terms were not disclosed.

The company raised a $19M Series A led by Intel Capital in February 2025, with Eniac Ventures and Peak XV's Surge. It was listed as a Representative Vendor in Gartner's Market Guide for AI Gateways (announced February 2026). Customers named on truefoundry.com include NVIDIA, Siemens Healthineers, ResMed, Automation Anywhere, NetApp, Cox and Mastercard. G2 shows 4.6/5 on about 55 reviews.

## The question it answers

"We need one self-hosted gateway for both LLM traffic and MCP tools, inside our own network — TrueFoundry, LiteLLM, Portkey or Runlayer?" Most teams end up with two products: a model gateway for spend and routing, and a separate MCP gateway for tool access. TrueFoundry's pitch is that one policy layer covers both, so a RevOps agent's call to Claude and its call to a Salesforce MCP server are authenticated against the same identity, counted against the same budget and logged in the same trace.

The vendor reports sub-3ms internal latency, 99.99% uptime and 10B+ requests a month across customers. Those are vendor figures, not independent benchmarks. The compliance list is SOC 2 Type II, HIPAA and GDPR, with support for ITAR and export-controlled deployments.

## Pricing reality

From truefoundry.com/pricing, checked 2026-11-28. LLM requests and MCP tool calls count the same, and TrueFoundry does not mark up model tokens; you pay providers directly.

- **Developer:** free forever, up to 3 users, 10,000 requests and tool calls per user per month, 5 MCP servers, 5 model accounts, 7-day log retention. No SSO, RBAC, audit logs or guardrails.
- **Pro:** $25 per user per month, unlimited users, 20,000 requests and tool calls per user per month pooled across the team, then $20 per extra 100,000. Unlimited MCP servers, built-in guardrails (up to 10 policies), SSO, custom roles, audit logs, 30-day retention. No minimum commitment.
- **Enterprise:** custom, annual commitment. This is the only tier with VPC, on-prem, air-gapped deployment and data residency, plus SCIM, external IdP mapping, MCP tool approvals, custom and third-party guardrails, custom retention and an SLA.

Real-world band: a 10-person ops team on Pro pays $250 a month for a pooled 200,000 requests; at 500,000 requests that becomes $310. The catch is the headline question of this page: **self-hosting is Enterprise-only.** Developer and Pro run as TrueFoundry-hosted SaaS. The pricing calculator flips to custom pricing at about $5,000 a month, so budget a five-figure annual contract for any in-VPC deployment, plus the Kubernetes cluster and the engineer who runs it.

## Best for

The platform or AI-enablement lead at a 500-plus-person company in a regulated industry (finance, healthcare, insurance) whose security review requires the gateway inside its own VPC or air-gapped, and who wants model routing, MCP tool governance and self-hosted model serving from one vendor instead of three. The scoped case where it wins: RevOps, support and legal agents calling several model providers and a dozen MCP servers, with a security team that wants every call tied to an Okta identity and kept on-network.

## Not for

A small team that only needs a model router: [OpenRouter](/en/tools/openrouter/) or TrueFoundry's own Pro SaaS tier is enough, and the platform depth goes unused. Not for a team that wants to self-host for free: that is [LiteLLM](/en/tools/litellm/) or [Obot](/en/tools/obot/), because TrueFoundry's in-VPC deployment requires an Enterprise contract. And not for a team with no Kubernetes skills planning an on-prem install.

## Versus the alternatives

- **[LiteLLM](/en/tools/litellm/)**, the most widely deployed open-source gateway. Pick it when self-hosting must be free and you have an engineer to own upgrades. Read its two 2026 supply-chain compromises first; its MCP gateway is also lighter.
- **[Portkey](/en/tools/portkey/)**, the other top managed gateway, now owned by Palo Alto Networks and sold as Prisma AIRS AI Gateway. Pick it when your security team already buys Palo Alto. New air-gapped deployments are no longer offered there, which is TrueFoundry's opening.
- **[Runlayer](/en/tools/runlayer/)**, the fastest-growing MCP-governance entrant. Pick it when the problem is tools employees already wired to Claude and Cursor and you want ML threat detection and shadow-AI discovery; it does not route model traffic.
- **[Obot](/en/tools/obot/)**, MIT-licensed MCP gateway. Pick it when you want open source with no vendor in the credential path and can run Kubernetes yourself.
- **Kong AI Gateway** or **Cloudflare AI Gateway**. Pick these when that vendor already fronts your APIs.

So is TrueFoundry the one-gateway answer? Yes when the deployment must sit in your VPC or air-gapped and you can sign an Enterprise contract. If you only need hosted SaaS, Pro at $25 per user is competitive, but so is staying on whatever gateway you have and adding a dedicated MCP gateway.

## Watch-outs

- **The self-hosting you are shopping for is not in the self-serve tiers.** Developer and Pro are SaaS only. Guard: before a trial, ask sales for the Enterprise in-VPC price in writing, and run the pilot on the deployment model you will buy, not on hosted Pro.
- **Pooled request counts include tool calls.** An agent that makes 20 MCP calls per task burns at least 21 requests, not one. Guard: meter a week of real agent traffic on the free tier, multiply by tool-call depth, and set budget rules per team before moving to Pro.
- **Vendor-reported numbers vary across its own pages.** The site cites 2,500+, 1,600+ and 250+ models on the same AI Gateway page, and both sub-3ms and about 10ms latency. Guard: benchmark latency on your own traffic and provider mix, and confirm the exact providers you need in the supported-providers docs.
- **Seldon integration is in progress.** The June 2026 acquisition brings a second serving stack and customer base to merge. Guard: if you run Seldon Core today, get the migration path and support term for your version in the contract.
