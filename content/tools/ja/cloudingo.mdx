## 概要

Cloudingo は [Salesforce](/ja/tools/salesforce/) 向けの重複排除・データ管理ツールで、テキサス州ダラスの Symphonic Source Inc. が開発しています（G2 によると 2010 年創業）。[DemandTools](/ja/tools/demandtools/) と違い Web アプリで、Cloudingo のアカウントを作成し、OAuth で org を接続し、AppExchange から小さな Cloudingo エージェントをインストールして使います。フィルター（完全一致からあいまい一致までのマッチングルール）を作成し、各フィルターが見つけた重複グループを確認し、マスターレコードと項目ごとに残す値のルールを決めて、手動、一括、またはスケジュールでマージします。同じアプリで一括更新、一括削除、標準化、リードの取引開始、既存レコードと照合しながらの CSV インポートもできます。Cloudingo は、レコード自体はエクスポートも保存もせず、マッチングに使う項目のインデックスだけを保持すると説明しています。

購入者にとって重要な新しい要素が 2 つあります。全プランに含まれる Cloudingo Intelligence は、org の健全性とセキュリティを監視します。また Cloudingo は現在、HubSpot Marketplace に HubSpot アプリを掲載しており、コンタクト、会社、取引、チケット、カスタムオブジェクトに対応しています。2026-11-24 の確認時点でインストール数は 10 件以上、レビューは 0 件だったため、まだ初期段階の製品と考えてください。Cloudingo は Marketo のデータにも対応しています。G2 の評価は 37 件のレビューで 5 点中 4.4 で、最も評価されているのはサポートです。

これは何でないか：データエンリッチメントの提供元でも、ルーティングエンジンでも、AI 製品でもありません。空の項目をサードパーティのデータベースで埋めることはせず、マッチングアルゴリズム以外に AI 機能をうたっていません。

## このツールが答える問い

**RingLead が ZoomInfo に統合された今、Cloudingo、DemandTools、Insycle のどれを選ぶべきか？** ZoomInfo は 2021 年 9 月に RingLead を買収して ZoomInfo Operations に組み込んだため、Salesforce の重複排除に特化した独立系ベンダーは Cloudingo と DemandTools の 2 社になりました。Salesforce のライセンス数に応じて増えない公開価格で、ブラウザから使えるツールが欲しいなら Cloudingo を選んでください。最も細かいルール設定が必要で、管理者のデスクトップからジョブを実行する運用なら DemandTools です。

典型的な利用例：250 ライセンスの org で、リード、取引先責任者、取引先が合計 450,000 件ある環境の RevOps 管理者が、会社名のあいまい一致フィルターとメールアドレスのフィルターを作成し、グループをプレビューで確認し、週末で 18,000 件の重複取引先責任者をマージします。その後リアルタイムマージを有効にし、新しい重複が次のバッチまで溜まるのではなく作成時点でマージされるようにします。

## 料金

Cloudingo は価格を公開しています。2026-11-24 に cloudingo.com で確認しました。

- **Standard、年額 $2,500**：ユーザー 1 名、標準オブジェクトのみ、一括マージ・変換・更新・削除、スケジュールジョブ、標準インポートウィザード、メールサポート。
- **Professional、年額 $6,000**：ユーザー 3 名、カスタムオブジェクト 3 つまで、リアルタイムマージ、マージの取り消しと復元、高速インポートウィザード、個別オンボーディング。
- **Enterprise、年額 $10,000**：ユーザー 8 名、カスタムオブジェクト無制限、API アクセス（1 日 1,000 コール）、専任のカスタマーサクセスマネージャー、セキュリティ監査、契約内容の調整。
- **レコード数に応じた料金。** 価格はユーザー単位ではなく Salesforce org 単位です。レコード数（リード、取引先責任者、取引先、個人取引先、対象のカスタムオブジェクト）が 300,000 件を超えると、100,000 件ごとに $100 が加算されます。500,000 件の org なら Professional で $6,200、120 万件の org なら $6,900 です。
- **HubSpot**：HubSpot アカウントごとに年額 $500。300,000 件を超えると同じく 100,000 件ごとに $100 が加算されます（Marketplace の価格は 2026-10-28 更新）。
- **契約条件**：年間契約のみで、月額プランはありません。1 ライセンスで本番 org 1 つと Sandbox 1 つをカバーします。住所検証は有料アドオンです。10 日間の無料トライアルでは 25 件の重複グループを処理できます。

Salesforce チームの実際の価格帯は年額 $6,000〜$7,000 です。多くのチームに必要な機能（取り消し、リアルタイムマージ、カスタムオブジェクト）が Professional から始まるためです。

## 最適な利用者

- 100〜1,000 ライセンスの org で、数万〜数十万件の重複が溜まっている Salesforce 管理者や RevOps リーダー。ライセンス数連動の課金ではなく、公開された固定価格のブラウザツールを求める人
- 重複をバッチだけでなく、作成された時点でマージする必要があるチーム
- 実績のあるツールが今すぐ必要な HubSpot 専業のチーム（HubSpot アプリは新しい）や、本当の課題が空の項目やルーティングにあるチームには向きません

## 代替ツールと選ぶべき場面

- **[DemandTools](/ja/tools/demandtools/)**：Salesforce のライセンス単位で課金されるため、Vendr による 200 ライセンスの年額中央値 $16,764 に対し、Cloudingo Professional は 500,000 件で約 $6,200 です。より細かいルール設定と、サードパーティのガイドによると同梱されている DupeBlocker が必要なら DemandTools、ライセンス数が多く Web アプリを使いたいなら Cloudingo を選んでください。
- **[Insycle](/ja/tools/insycle/)**：レコード単位の課金、ユーザー数無制限、HubSpot 中心。Growth プランで 100,000 件なら年額 $1,800 と Cloudingo Standard より安く、500,000 件なら $9,000 と Cloudingo Professional より高くなります。小規模なデータベースや HubSpot 中心の環境なら Insycle です。
- **[ZoomInfo](/ja/tools/zoominfo/) Operations**（旧 RingLead）または **[Openprise](/ja/tools/openprise/)**：重複排除がエンリッチメント、正規化、ルーティングを含むより大きな取り組みの一部で、予算が数万ドル規模ある場合に選んでください。
- **Salesforce 標準の重複ルールと一致ルール**：無料で、溜まっている重複が数千件程度なら十分です。
- **Salesforce API に接続するエージェント**：このカテゴリーで最も急速に広がっているアプローチです。[Salesforce データクリーンアップ スキル](/ja/workflows/salesforce-data-cleanup-skill/) は Claude Code からマッチングルールとマージ計画を作成します。技術に強い管理者による一度きりのクリーンアップならこちら、開発者でなくても運用できるスケジュールマージとリアルタイムマージには Cloudingo を使い続けてください。

## 注意点

- **Standard では取り消しができません。** マージの取り消しと復元は Professional からで、Salesforce 自体もマージを元に戻せません。対策：慎重な管理者 1 名以外がマージするなら Professional を購入するか、Standard では一括マージの前に毎回対象オブジェクトをエクスポートしてください。
- **Standard はカスタムオブジェクトに対応せず、ユーザーも 1 名だけです。** トライアル後に気づくチームが多い点です。対策：プランを選ぶ前に、対象オブジェクトとジョブを実行する人を洗い出してください。カスタムオブジェクトが 3 つ、またはユーザーが 2 人目なら Professional です。
- **レコード料金はインポートに連動します。** 購入リストや買収によって、org が次の 100,000 件の区分に入ることがあります。対策：更新前に不要なリードを削除またはアーカイブし、予定しているインポートの予算に料金を織り込んでください。
- **一括ジョブは Salesforce の API 割り当てを消費します。** Cloudingo は Salesforce API 経由で動作するため、大規模な自動マージは他の連携と API 枠を奪い合います。対策：大きなジョブは夜間にスケジュールし、各自動化を org 全体で実行する前に、フィルターで絞った 50 グループのサンプルで試してください。

重複排除ツールを取り巻く運用モデル（データ衛生の責任者、最初に標準化すべき項目、実行頻度）については [CRM ハイジーン](/ja/learn/crm-hygiene/) を参照してください。
