## 概要

Claude Cowork は、コードを書かない人のための Anthropic のエージェント型ワークスペースです。Claude デスクトップアプリの Chat と Code の隣にあるタブで、プロンプトではなくゴールを渡すと、許可したフォルダ、接続した SaaS アプリ、内蔵ブラウザ、そして Pro と Max では実際の画面を横断して作業します。2026年1月の macOS パブリックベータ、2月の Windows 対応を経て、2026年4月9日に一般提供へ移行しました。現在は macOS、Windows (x64 および arm64)、Linux、ChromeOS で動作し、Web 版は順次展開中、モバイル版は2026年7月7日からベータです。

このカタログで最も近い項目は [Lindy](/ja/tools/lindy/) と [Dust](/ja/tools/dust/) で、いずれもオペレーション部門向けに売られているエージェントプラットフォームです。違いは、Cowork がビルダーではない点にあります。キャンバスもノードグラフもなく、答えを得る前に設定すべきエージェントもありません。成果物を説明し、実行の途中で軌道修正します。

## ops スタックに載る理由

理由は機能より先に流通です。Cowork は有料の Claude プランすべてに追加費用なしで含まれます。エンジニアリング向けにすでに Claude のシートを購入した企業のオペレーション責任者は、新しい購買プロセスも、新しいベンダーセキュリティ審査も、新しい予算項目もなしに、財務アナリストや採用コーディネーターに渡せるエージェント面をすでに持っていることになります。このカテゴリの他のツールは、いずれもまず個別の購入を必要とします。

実際の仕事をしているのは3つの機能です。

- **スケジュール実行はクラウドで動く。** タスク内で `/schedule` と入力するか、サイドバーの Scheduled を使うと、ノートパソコンが開いているかどうかに関係なく Anthropic のサーバー上で実行される定期ジョブを設定できます。Cowork を「速いアシスタント」から「無人で回るスループット」に変えているのは、この部分です。
- **画面スクレイピングではなくコネクタ。** Microsoft 365、Google Drive、[Slack](/ja/tools/slack/)、[Amplitude](/ja/tools/amplitude/) が公式で、Settings のコネクタブラウザから [Notion](/ja/tools/notion/)、Gmail なども追加できます。コネクタ経由のアクセスはコンピュータ操作の経路より速く安定しており、コンピュータ操作と違ってすべてのプランで使えます。
- **Dispatch。** スマートフォンから到達できる、途切れない単一のスレッドです。Claude 自身が依頼を振り分け——エンジニアリング作業は Claude Code へ、ナレッジワークは Cowork へ——完了時や承認が必要なときにプッシュ通知を送ります。

## 価格の実態

Cowork 自体に価格はありません。買うのは Claude のシートで、有料階層はすべて Cowork を含みます。

- **Pro** — 月額20ドル、年払いなら月額17ドル
- **Max** — Pro の5倍の利用量で月額100ドル、20倍で月額200ドル
- **Team** — 1シート月額25ドル、年払いで20ドル、最低2シート。プレミアムシートは5倍の利用量で125/100ドル
- **Enterprise** — 1シート20ドルに従量課金、組織単位の機能制御とモデル制御つき

階層表は実際の数字ではありません。Anthropic はトークンのクォータを公開しておらず、Pro に対する倍率だけを示しています。利用量は二重に計測され、5時間ごとにリセットされるセッション上限と、アカウントごとに固定時刻でリセットされる週次上限があります。この予算は **Claude Code、claude.ai chat、Cowork で共有されます**。Cowork のスケジュールタスクとエンジニアのコーディングセッションは同じ枠から引かれます。実際の業務量で毎日 Cowork を回すチームは、Pro ではなく Max か Team のプレミアムシートに落ち着きます。評価用に20ドルのシート、本番用にヘビーユーザー1人あたり100〜200ドルの帯域を見込んでください。

## 適しているのは

RevOps、Legal Ops、Recruiting、Customer Success のオペレーション責任者で、すでに Claude を契約しており、コードを書かない担当者に、無人で回る定期的なドキュメント・表計算業務を渡したいケースです。たとえば、Drive フォルダ内の CRM エクスポートから作る週次のパイプライン整備レポート、ベンダー契約書フォルダに対する月次の差分抽出、ATS のエクスポートと Slack のスレッドから組み立てる月曜朝の候補者パイプライン要約などです。明確に勝てる範囲は、出力フォーマットが安定した定期的でファイル中心の作業であり、担当者が1人に特定されていて、対象データがすでにその人が閲覧権限を持つフォルダやコネクタにあること、という条件が揃う場合です。

## 適していないのは

Cowork は *あなた自身* として動きます。あなたのシート、あなたのフォルダ許可、あなたのコネクタ権限です。エージェントごとのサービス ID はなく、ローテーションすべきエージェント資格情報もなく、セッションの所有者である人間とは別の監査主体も存在しません。要件が「独自のライフサイクルと独自の監査証跡を持つエージェントのレジストリ」であるなら、これは層が違い、シートを増やしても解決しません。それは Microsoft Agent 365 や Salesforce Agentforce が扱う形の問題です。大量の構造化パイプラインにも向きません。「毎晩5000行を同じ手順で処理する」という仕事であれば、[n8n](/ja/tools/n8n/) のフローか [Claude](/ja/tools/claude/) の API を直接呼ぶほうが安く、1行ずつ推論するエージェントよりはるかに予測可能です。

- **Microsoft 365 Copilot** — オペレーション組織におけるシート数では既存の本命で、2026年4月22日から Word、Excel、PowerPoint でエージェントモードが一般提供されています。作業が SharePoint 上の Office 文書にあるとき、ガバナンスの議論がテナント単位のポリシーであるとき、そしてエージェントを別のデスクトップクライアントではなくチームがすでに開いているアプリの中に置きたいときは、こちらを選んでください。
- **ChatGPT Work** — 2026年7月9日に GPT-5.6 のエージェント上で提供開始。1400を超えるアプリのコネクタディレクトリを備え、Web、モバイル、そして Chat・Work・Codex をまとめた macOS デスクトップアプリで動きます。コネクタの網羅性が制約条件になっているとき、または組織がすでに OpenAI に標準化しているときは、こちらを選んでください。計画してから承認つきで実行するモデルは、このリストの中で Cowork に最も近いものです。
- **Manus** — このセグメントで最も成長が速い新規参入で、ローンチから8か月で ARR 1億ドル、2025年12月時点の年換算売上は1億2500万ドルです。1行のブリーフから完成した成果物を得たい、自由度の高い調査・制作タスクにはこちらを選んでください。既定の選択肢にならない理由は、所有関係が未解決だからです。Meta による20億ドルの買収は2026年4月下旬に中国の規制当局に阻止され、2026年6月には旧来の出資者による買い戻しが報じられました。キャップテーブルが係争中の企業の背後に、定期実行される統制済みのワークフローを置くべきではありません。

## 注意点

- **コンピュータ操作は Pro と Max のみで、Team と Enterprise プランにはありません。** 利用できる環境も macOS と Windows に限られ、Linux ビルドではファイルとコネクタは使えますが画面操作はできません。個人の Pro シートで評価してから Team シートで展開する購買者が、まさにここで足をすくわれます——その時点でデモが動かなくなります。ガード：シートを買う前に、対象ワークフローを画面操作が必要なものとコネクタで届くものに分けてください。移せるものはすべてコネクタに載せ替え、残りについては該当する担当者だけを個別の Max シートに置き、予算を分けて確保します。
- **セッションのサンドボックスが制限しているのはネットワーク到達範囲であり、あなたのデータではありません。** Anthropic 自身のセキュリティドキュメントは明確です。セッションは隔離された一時的なクラウド環境で実行され、自宅ネットワークにも社内ネットワークにも到達できず、セッション終了時に破棄されます。しかしこの隔離は、あなたが許可したフォルダやコネクタを通じて「Claude が何を読み、何をするかを制限するものではない」とされており、コンピュータ操作に至っては Claude と画面上のものとの間にサンドボックスが一切ありません。ガード：許可はそのタスクの入力を含む最も狭いディレクトリに限り、ホームディレクトリや同期ドライブのルートは決して許可しないでください。資格情報、給与、財務記録は許可済みフォルダから外し、Enterprise ではスキルスキャンを有効にし、必要のないグループには Cowork の Web 検索を無効にします。
- **スケジュールタスクは、書いた本人が見なくなった後も動き続けます。** マシンの電源が入っているかどうかに関係なくクラウドで実行され、Anthropic は Web コンテンツをプロンプトインジェクションの主要な経路として挙げています。つまり、公開ページを読むタスクは、あなたの権限で信頼できないテキストを定期的に実行していることになります。「Automatically approve」モードでも各アクションは実行前に安全性が確認されますが、タスクの途中で注入された指示を止めることはできません。ガード：書き込みを伴うものはスケジュールタスクを手動承認のままにし、Web を読む手順と書き込み権限のあるコネクタを同一のスケジュール実行に同居させないでください。出力は決まった頻度で確認し、1か月間誰も読んでいないタスクは停止します。
