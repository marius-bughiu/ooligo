## 概要

Scaled Cognition はモデルの研究開発企業であり、エージェントベンダーがまた1社増えたわけではありません。カスタマーサービス自動化向けの独自モデル APT（Agentic Pretrained Transformer）を学習させ、その上でエージェントを構築・シミュレーション・監視するプラットフォームと一緒に販売しています。主張の核はアーキテクチャです。汎用 LLM はトークン予測のために学習され、ツール利用、ガードレール、ポリシーチェックを後付けされます。これに対し APT は、どの API を呼ぶか、どの業務ルールが適用されるか、どの順序で実行するかというアクション単位の目的に対して学習されるため、ポリシー遵守はモデルを包むプロンプトではなくモデル自体の性質になります。同社は APT を「決して推測しない」モデルとして売り出していますが、これは設計目標として読むべきで、テストを省略してよい保証ではありません。

創業者はこれを一度やり遂げています。CEO の Dan Roth と、UC Berkeley の AI 教授である CTO の Dan Klein は、以前 Semantic Machines を共同創業し、同社は2018年に Microsoft に買収されました。Khosla Ventures が2023年に $21M のシードラウンドを主導し、2026年6月25日には Genesys も参加した $100M のシリーズ A を主導しました。報道されている評価額は約 $750M です（SiliconANGLE、Wall Street Journal を引用）。APT-1 は約20名のチームによって構築され、2025年2月にリサーチプレビューとして公開されました。同社はエージェント系ベンチマークの Tau-Bench と ComplexFuncBench でフロンティアモデルを上回ったとしていますが、ローンチ記事ではタスクごとのスコアを公開していません。シリーズ A の発表では、金融サービス、ヘルスケア、通信、保険の Fortune 500 企業で本番稼働していると主張していますが、社名は明かしていません。

## CX・サポートのスタックに入ってくる理由

- **上に乗るエージェントではなく、下で動くモデルです。** 多くの購買者は Genesys Cloud の中で APT に出会います。Genesys は2025年10月16日に提携を発表して出資し、2026年2月10日に APT-1 を「large action model」として搭載した Genesys Cloud Agentic Virtual Agent を発表しました。一般提供は Genesys の2027会計年度第1四半期（2026年2月〜4月）と予定されていました。初期評価企業として M&T Bank と Banco Pichincha の名前が挙がっています。Genesys は到達可能な顧客基盤を8,000超の組織としています。
- **実務上の差別化要因はシミュレーションのツール群です。** AgentTwin は過去の顧客対応履歴からエージェントとテスト会話を生成し、GenAPI はモック化したバックエンド API を使って数千のシミュレーションシナリオでエージェントを走らせ、Agent Evaluator はローンチ前に繰り返し実行した結果の正確性とポリシー準拠をスコア化します。本番稼働後はモニタリングがドリフトを監視します。50件の会話によるパイロットを通過したのに5万件で破綻したエージェントで痛い目を見たチームは、モデルと同じくらいこの部分を買っています。
- **規制業種の購買者が必要とする場所に展開できます。** APT はオンプレミス、自社の VPC、ホスティングのいずれでも動作し、アクセスはステートレスな REST API で、ノーコード、ローコード、SDK の選択肢があります。推論パートナーの Baseten は最初のトークンまでの時間（TTFT）が 120 ms 未満と報告しています。音声エージェントが会話に感じられるか保留待ちに感じられるかを決める数字です。

## 価格の実態

直接契約向けの公開価格表はなく、営業主導のエンタープライズ契約です。公開されている唯一の課金メーターは Genesys 経由のルートです。Genesys のドキュメントでは Agentic Virtual Agent の1インタラクションを AI Experience トークン1.2個とし、トークンの定価は1個 USD 1.00 です。つまり定価ベースで1インタラクションあたり約 $1.20 となり、エンタープライズ割引の前の金額で、さらに Genesys Cloud CX のシート料金（ティアにより1ユーザー月額 $75〜$240）が別途かかります。数字の上では自動解決1件あたり $1.50 の [Zendesk](/ja/tools/zendesk/) より安く見えますが、課金単位は成果ではなくインタラクションなので、未解決の会話にも課金されます。封じ込め率70%なら、解決1件あたりの実効コストは約 $1.71 となり、Zendesk を上回り、outcome 1件あたり $0.99 の [Intercom](/ja/tools/intercom/) Fin を大きく上回ります。直接導入の場合は、[Sierra](/ja/tools/sierra/) や [Parloa](/ja/tools/parloa/) と同程度の6桁ドル規模のプラットフォーム契約を想定してください。これは購買者像からの推定であり、提示された価格ではありません。

## 最適な対象

規制業種の企業、すなわち銀行、保険会社、通信事業者、医療保険の支払者、およびそれらを支える BPO で、コンタクトセンターや CX プラットフォームを率いるリーダーのうち、AI エージェントのパイロットが会話品質ではなくポリシー遵守でつまずき、すでに Genesys Cloud を運用しているか、自社 VPC 内にモデルをホストする必要がある組織です。具体的なユースケースは、誤ったアクションがコンプライアンス事案になるトランザクション型のフローです。支払プランの変更、アカウント変更前の本人確認、保険金請求の処理ステップなどが該当します。

課題が FAQ のディフレクションであれば対象外です（ヘルプデスク組み込みの AI で十分です）。サポート運用チームがエンジニアリングなしで設定できる完成品のエージェント製品を求める場合や、Genesys を使っておらずモデルプラットフォームの導入に人員を割けない場合も見送ってください。

## 代替製品との比較

この比較は同種のものの比較ではありません。Scaled Cognition が売っているのは、エージェントベンダーが OpenAI、Anthropic、Google から買っているレイヤーです。エージェントレイヤーの主要製品と比べるなら、ベンダーにエンドツーエンドで成果を担ってほしく、成果報酬型の課金を受け入れられる場合は [Sierra](/ja/tools/sierra/) を、ボリュームがチャット中心で運用チームが自然言語で手順を書きたい場合はこのセグメントで最も急成長している [Decagon](/ja/tools/decagon/) を選んでください。分単位課金の音声中心のコンタクトセンターには [Parloa](/ja/tools/parloa/) です。構造的に最も近いのは独自の対話モデル Raven を動かす [PolyAI](/ja/tools/polyai/) で、課題が音声にほぼ限られ、マネージドサービスを求める場合に向いています。導入済みの基盤では、すでに支払っているシステムへの集約がより優れたモデルよりも重要な場合、[Salesforce Agentforce](/ja/tools/salesforce-agentforce/) と [Zendesk](/ja/tools/zendesk/) が勝ちます。Scaled Cognition を選ぶべきなのは、直そうとしている障害がモデルのポリシー逸脱であり、ガードレールをもう1つ足すよりもモデル自体を替えたい場合です。

## 注意点

- **「ハルシネーションなし」はマーケティング上の主張であり、測定された発生率ではありません。** ローンチ記事はタスクごとのスコアなしにベンチマークでの首位を主張しており、カスタマーサービスのワークロードでの独立した評価は公開されていません。対策：AgentTwin と GenAPI で500シナリオのポリシー遵守テストを独自に実施し、現在のベンダーが使っているフロンティアモデルと比較したうえで、測定したエラー率を受け入れ基準として契約に書き込んでください。
- **Genesys 経由で買うのは Genesys の製品であり、Scaled Cognition の製品ではありません。** ロードマップ、価格、サポートは Genesys 側にあり、私たちが確認したドキュメントでは一部のセクションでエージェント型仮想エージェントがまだ「近日提供」と記載されていました。対策：自社のリージョンとテナントでの一般提供を書面で確認し、自社組織でどの APT バージョンが動いているか、モデルのアップグレードがどのように展開され回帰テストされるかを質問してください。
- **インタラクション単位の課金は失敗にも課金されます。** 1インタラクションあたり1.2トークンなので、人間にエスカレーションされた会話もトークンを消費します。対策：解決1件あたりのコストを $1.20 ÷ 封じ込め率で試算し、それを下回ったら導入を見直す封じ込め率の下限を設定してください。
- **顧客実績の根拠は乏しく、匿名です。** Genesys とその初期評価企業以外に、公開されている本番顧客はいません。対策：複数年契約の前に自社業界のリファレンスコールを2件求め、初回の契約期間は12か月に制限してください。
