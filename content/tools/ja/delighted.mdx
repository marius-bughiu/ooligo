## 概要

**Delighted は終了しました。** Qualtrics は 2026年6月30日にこの製品を停止しました。2026-08-31 時点で確認したところ、`delighted.com` と `delighted.com/pricing` はいずれも `qualtrics.com/delighted` へ 301 を返します。そこにあるのは 1 段落だけの告知で、全文は次のとおりです。"Thank you for your interest in Delighted. It's no longer available, but Qualtrics offers the same fast and easy feedback collection plus AI capabilities to help you take action and create customers for life." Delighted 自身の終了 FAQ を掲載していたヘルプセンターの記事は、現在 404 を返します。ログインもトライアルも、読み取り専用のアーカイブもありません。このページは、Delighted が何であったかを記録し、いまも検索している人を適切な移行先へ導くために、元の URL のまま残しています。

Delighted は NPS、CSAT、CES 向けの単一設問アンケートツールで、2018年に Qualtrics が買収しました。やることは 1 つだけでした。メール、Web 埋め込み、共有リンク、SMS で摩擦の少ないアンケートを配信し、その回答をスタックへ流すことです。約 10 年にわたり、voice-of-customer 領域における「午後のうちに設定できる」選択肢でした。Qualtrics 自身や Medallia のような重量級プラットフォームに対する、SurveyMonkey 並みの手軽さです。

終了は公表されたスケジュールどおりに進みました。新規の年間契約は 2025年7月1日に停止。月額サブスクリプションは 2026年5月31日に終了。顧客アクセスはすべて 2026年6月30日に遮断され、Qualtrics はその日以降に顧客データを削除すると表明しました。延長も、終了後のアーカイブもありません。締め切り前にエクスポートしなかったチームは、NPS と CSAT の履歴をもう保持していません。

## Customer Success スタックに入っていた理由

- **午後のうちに稼働。** メール、Web 埋め込み、共有リンク、SMS。導入プロジェクトも、設定を担当する専任 CSM も、設計すべきデータモデルも不要でした。
- **メトリクスの素直なルーティング。** スコアは Slack、Salesforce、HubSpot へ流れ、API と Zapier 経由で warehouse や [Gainsight](/ja/tools/gainsight/)、[Vitally](/ja/tools/vitally/) のヘルススコアへ出ていきました。
- **AI は初めから非搭載。** 2014年代のアンケートエンジンで、テーマ抽出もセンチメント層もエージェントからのアクセスもありませんでした。自由記述は別の場所へ運んで読む必要がありました。Qualtrics が作り直さずに製品を畳んだ理由の大部分は、この欠落にあります。

## 料金（過去の実績）

Delighted は月間回答数でプランを公開していました。Free（25 回答、1 ユーザー）、Starter $19/月（50 回答、2 ユーザー）、Growth $39/月（100 回答）、Advanced $149/月（250 回答）、Premium $249/月（500 回答、Salesforce・HubSpot・Segment 連携付き）です。

この数字こそ、終了が痛い理由です。実用的なリレーショナル NPS プログラムが $19–39/月 から始められました。2026年の市場に、同じ設定時間でこの価格を再現できるものはありません。以下の代替はどれも $49–119/月 から始まり、ベンダーが推奨する移行先はそこから約 2 桁上のレンジで始まります。

## 最適な用途

購入対象としては、該当なしです。製品は購入もアクセスもできません。このページが今も役立つ読者は 2 種類です。

1 つ目は、エクスポート期限を逃した旧顧客です。その履歴をベンダーから復旧する手段はありません。データが着地した先から復元してください。Salesforce や HubSpot のレコード、Slack のアラート履歴、Zapier のフローが書き込んでいた warehouse のテーブルです。代替ツールの開始日を新しいベースラインとして扱い、QBR の資料でもそう明記してください。互換性のない 2 本の系列を 1 本のトレンドラインにつなぐのは避けます。

2 つ目は、購買サイクルの途中で "Delighted pricing" を検索し、最短の正しい答えと、稼働中のツールへの導線を必要としている人です。その導線が、このページの残りです。

## 代替候補との比較

- **[AskNicely](/ja/tools/asknicely/)** — 見積のみで、セルフサーブのプランはありません。スコアを報告することではなく、批判者へ対処することが仕事である場合に選んでください。回答はコーチング用のプロンプトを添えて、アカウントまたは拠点の担当者へルーティングされます。ダッシュボードに数字が出れば十分なら過剰です。
- **Customer Thermometer** — Delighted の形と価格に最も近い候補です。公開プランは Jumper $49/月（200 回答）、Flyer $99（500）、Mach 1 $159（1,000）、Mach 2 $259（5,000）、Mach 3 $400（10,000）、Mach 4 $700（20,000）で、全プランともユーザー数は無制限、未使用の回答枠は月間割当の 2 倍を上限に繰り越し、請求は月単位です。調達プロセスを挟まず、単一メトリクスを低ボリュームで回すなら、これを選んでください。
- **Simplesat** — Standard $119/月（年払い $109、5 ユーザー、1,000 回答）、Pro $249（$229、15 ユーザー、3,000 回答、テーマ自動検出）、Elite $499（$459、30 ユーザー、7,000 回答）。NPS、CSAT、CES に対応し、アンケート数とサポートエージェント数は無制限です。チケットのクローズをトリガーにアンケートを送り、サポート部門がプログラムを保有する場合に選んでください。
- **Retently** — 公開プランは $99/月（2,500 アンケート、3 シート）と $299/月（20,000 アンケート、10 シート）から始まり、年払いで 10% 引きです。B2B 向けのプランは金額を表示しないトグルの内側にあります。Customer Thermometer より高い料金を払う理由は、上位プランに MCP サーバーが付く点です。Claude や ChatGPT が NPS データを直接クエリできます。Delighted が最後まで持たなかった機能です。
- **Qualtrics** — ベンダー自身が示す移行先であり、最も厳しく問いただすべき相手でもあります。ラインナップ全体が見積のみで、CX Foundational、Frontline Digital、Frontline Care、Frontline Locations として販売され、インタラクション数で課金されます。無料プランもセルフサーブのプランもありません（qualtrics.com/pricing、2026-08-31 確認）。Vendr の検証済み契約データによると、Qualtrics の契約額の中央値は 317 件の購入で $30K/年 前後、レンジは概ね $6,880 から $139,920 です。責任者と予算枠を伴う experience management プログラムを買うときに選んでください。終了告知がそこを指しているから、という理由では選ばないでください。
- **すでに使っている CS プラットフォームのアンケート機能** — [ChurnZero](/ja/tools/churnzero/)、[Vitally](/ja/tools/vitally/)、[Gainsight](/ja/tools/gainsight/)、[Totango](/ja/tools/totango/) はいずれも NPS や CSAT をネイティブに収集します。何かを買う前に、まず自社の分を確認してください。すでに算出しているヘルススコアへ値を流すだけの単体アンケートツールは、仕事のないコスト項目です。
- **[Enterpret](/ja/tools/enterpret/) または [Dovetail](/ja/tools/dovetail/)** — 本当の欠落が収集ではなかった場合は、こちらを選んでください。Delighted の自由記述を誰も読んでいなかったのなら、収集側を入れ替えても何も直りません。分析レイヤーを買うべきです。

## 注意点

- **推奨される移行先が、いちばん高い選択肢です。** Qualtrics は Delighted の旧ユーザーを自社プラットフォームへ誘導しますが、そこでの契約額の中央値は Delighted の Premium プラン $249/月 の 10–50 倍です。**ガード:** 営業ミーティングを受ける前に、月間回答数とシート数という実数で代替を見積もってください。Delighted の $19–149 のプラン帯にいたなら、あなたは Customer Thermometer か Simplesat の購入者です。
- **連携は製品と一緒に死にました。** Delighted の API を読んでいた Zapier のフロー、Salesforce のフィールドマッピング、Slack のアラートは、いま静かに失敗し続けるデッドコードです。**ガード:** 自動化の棚卸しリストから Delighted の webhook と API キーを探して削除してください。静かに壊れたフィードバックの配管は、誰かが気づくまでの 1 四半期のあいだ「NPS は横ばい」として読まれます。
- **スコアの系列は移行時点で切れます。** 新しいツールは設問の文言、配信チャネル、送信タイミングを変えます。NPS はその 3 つすべてで動きます。**ガード:** 最初の 2 サイクルは Delighted の設問文をそのまま代替ツールで使い、移行日をすべてのグラフに注記してください。上を 1 本の連続線で貫かないことです。
- **このカテゴリは統合が進み、安価な側から先に切られます。** Delighted は 2018年に買収され、維持するには小さすぎるという理由で 2026年に終了しました。**ガード:** $300/月 未満のアンケートツールは月単位契約のままにし、次のツールへ 8 年分の履歴を投入する前に、CSV と API のエクスポート経路がトライアル中に実際に動くことを確認してください。
