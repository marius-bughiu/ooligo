O stack outbound padrão para um time de RevOps moderno rodando prospecting aumentado por IA em 2026 — construção de lista, enriquecimento, pontuação, disparo de sequências e sync de CRM, com IA em cada camada em vez de parafusada no final.

## Como as peças se encaixam

- **[Clay](/pt-BR/tools/clay/) é o workbench de dados + IA.** Construção de lista ICP a partir de qualquer seed (cargos, technographics, sinais de intenção), colunas de IA para resumos de empresas e personalização de outreach, enriquecimento em cascata em mais de 50 provedores de dados. É no Clay que a lista de prospecting toma forma.
- **[Apollo](/pt-BR/tools/apollo/) fornece os dados de contato e a camada de entregabilidade.** Email finder, mobile finder, infraestrutura de entregabilidade. Mais barato por registro do que o ZoomInfo; sequenciamento integrado para segmentos SMB.
- **[Outreach](/pt-BR/tools/outreach/) é o motor de sequências para o segmento upper-mid-market.** Onde o workflow do AE acontece — orquestração de sequências, A/B testing, analytics de conversão, sync completo com Salesforce. O Apollo cuida do outbound SMB; o Outreach cuida do outbound enterprise.
- **[Claude](/pt-BR/tools/claude/) escreve o opener personalizado.** Cada prospect recebe um e-mail de primeiro contato específico para o contexto gerado a partir dos dados enriquecidos pelo Clay — notícias da empresa, contexto do cargo, raciocínio de fit com o ICP. A [Skill de lead enrichment](/pt-BR/workflows/lead-enrichment-clay-claude/) operacionaliza isso de ponta a ponta.
- **[n8n](/pt-BR/tools/n8n/) conecta as camadas.** Dispara o enriquecimento no Clay quando novos leads entram no HubSpot; envia leads pontuados e enriquecidos para o Outreach; roteia leads quentes para o Slack; sincroniza bidireccionalmente dados de CRM de volta ao Apollo para re-targeting.
- **[HubSpot](/pt-BR/tools/hubspot/) é a fonte da verdade do CRM.** Cada lead enriquecido, cada engajamento de sequência, cada conversão volta ao HubSpot para relatórios de pipeline e forecast.

## Por que essa combinação

Os stacks outbound pré-IA eram Apollo + Outreach + Salesforce — um modelo de sequência e spray que dependia de volume para compensar a baixa personalização. A camada de IA (Clay + Claude) inverte isso: envie menos mensagens, mas cada uma é informada por contexto específico da empresa que levaria um SDR humano uma hora para pesquisar. O resultado é 2 a 3x mais taxas de resposta com um décimo do volume de mensagens, que é o que torna o outbound viável em 2026, quando os compradores aprenderam a ignorar sequências genéricas.

A combinação aceita seis ferramentas (~$50K a $150K anuais para um time de 5 a 10 SDRs) porque cada uma faz uma coisa bem. Tentar fazer isso com uma plataforma all-in-one (suite completa do Apollo, suite completa do Outreach) abre mão da profundidade do AI workbench que o Clay oferece de forma única.

## Variações comuns

- **Enterprise / outbound estratégico.** Substitua o HubSpot pelo [Salesforce](/pt-BR/tools/salesforce/); adicione [Gong](/pt-BR/tools/gong/) para conversation intelligence nas reuniões agendadas.
- **Times liderados por inbound.** Elimine Apollo e Outreach; substitua pelo [Default](/pt-BR/tools/default/) para roteamento inbound AI-native e [Drift](/pt-BR/tools/drift/) ou [Intercom](/pt-BR/tools/intercom/) para chat.
- **Estratégia account-based.** Adicione [6sense](/pt-BR/tools/6sense/) ou [Demandbase](/pt-BR/tools/demandbase/) para sinal de intenção e pontuação de contas; o [stack ABM](/pt-BR/stacks/abm-revenue-stack/) é o ponto de referência certo.
- **Overflow de pipeline / agência como complemento.** Use [Regie AI](/pt-BR/tools/regie-ai/) para agentes SDR totalmente autônomos no segmento de menor prioridade; reserve SDRs humanos para o upper-mid-market.

## O que esse stack NÃO substitui

- A necessidade de um rubric real de ICP — veja [ICP](/pt-BR/learn/icp-ideal-customer-profile/) e [signal-based selling](/pt-BR/learn/signal-based-selling/)
- Uma plataforma de agendamento de reuniões (Calendly, Chili Piper) para converter respostas positivas em tempo agendado
- Uma ferramenta de conversation intelligence ([Gong](/pt-BR/tools/gong/), [Chorus](/pt-BR/tools/chorus/)) para o movimento de vendas pós-agendamento
- Um motor de demand generation — search pago, conteúdo, parcerias — que alimenta os inputs de construção de lista no Clay
