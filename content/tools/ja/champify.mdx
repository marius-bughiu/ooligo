## 何をするツールか

Champify は、企業の Salesforce 組織にすでに存在するコンタクトを監視し、その関係が別の場所でパイプラインに変わった瞬間にイベントを発火させます。中核となるイベントは転職です。自社が販売した相手、失注した相手、サポートしてきた相手が、別の会社で新しい役職に就くという事象です。Champify はこれを Relationship Tracking と呼び、その周りに 4 つの製品を重ねています。通話トランスクリプト、メール、CRM 履歴を読み取ってターゲットアカウント向けのナーチャリング施策を組み立てる Insider AI、すでにカバー中のアカウントでの役員採用を捉える New Executive Hires、会議招待からコンタクトを作成する Calendar Sync、そして古くなったコンタクトレコードを修復する CRM Clean です。

この製品を定義する設計上の判断は、届け方にあります。シグナルは管理パッケージを通じて Salesforce 内のレコードとフィールドとして届き、独自ログインを持つ別コンソールには届きません。[シグナルベースセリング](/ja/learn/signal-based-selling/)の領域で [UserGems](/ja/tools/usergems/) や [Common Room](/ja/tools/common-room/) と並びますが、意図的に 3 つの中で最も範囲を絞った製品です。

## RevOps スタックに入る理由

- **設計段階から Salesforce ネイティブ。** Champify は AppExchange パートナーであり、管理パッケージはすべてのプランでユーザー数無制限です。シグナルはルーティング、フォーキャスト、レポートがすでに読んでいるオブジェクトに書き込まれるため、[LeanData](/ja/tools/leandata/) の割り当てフローや [Clari](/ja/tools/clari/) のフォーキャスト（Clari は現在 Salesloft の一部として事業を行っています）が、中間レイヤーも二重のシート数管理もなしにそれを利用できます。パッケージには Salesforce 内で使える 50 以上の既製レポートと 3 つのダッシュボードが付属します。
- **購入リストではなく自社の関係。** 追跡対象は自社 CRM のコンタクトです。そのため、購入したインテントフィードにはない形でシグナルの正当性を説明でき、[チャンピオン・ビルダー](/ja/learn/champion-builder/)の取り組みを逸話ではなく測定可能なものにします。
- **同じフィードで更新リスクを検知。** チャンピオンが顧客アカウントを離れるのは、見込み客開拓のイベントではなく NRR のイベントです。どちらも Salesforce を通るため、同じサブスクリプションが AE と CSM の両方に役立ちます。

## 価格の実態

Champify は 2026 年後半に価格体系を再編しました。2026-11-13 に確認した公開プランは、いずれも月額の「〜から」表記で、チェックアウトではなくデモ経由で販売されています。

- **Lite：$500/月から** — 追跡コンタクト 5,000 件、アドオンで 40,000 件まで拡張可能。Insider AI、New Executive Hires、CRM Clean はアドオンです。プランカードには同期カレンダー 10 件と記載されている一方、比較表では Calendar Sync がアドオン扱いになっています。どちらが適用されるかは発注書で確定させてください。
- **Pro：$2,500/月から** — コンタクト 40,000 件（アドオンで 200,000 件まで）、Insider AI と New Executive Hires がそれぞれ 2,000 アカウント、Calendar Sync が 50 ユーザー、CRM Clean が 50,000 コンタクト、専任の GTM エンジニアと CSM。
- **Enterprise：$5,000/月から** — コンタクト 150,000 件、Insider AI が 5,000 アカウント、New Executive Hires が 10,000 アカウント、Calendar Sync が 200 ユーザー、Salesforce ガバナンス機能。カードでは CRM Clean が 200,000 コンタクトと書かれていますが、表では 150,000 です。

最低価格で年額換算すると $6,000、$30,000、$60,000 です。旧 Core プラン（$2,000）は廃止され、Pro は $3,000 から、Enterprise は $6,000 から、いずれも約 17% 値下げされました。アドオン価格は公開されておらず、ページには上限値しか載っていません。請求額は人数ではなく、コンタクト数とアカウント数、同期カレンダー数に連動し、Champify は超過料金を課さないと明言しています。価格ページは $500K の ROI 保証を、Lite のカードは 2x の ROI 保証を掲げています。どちらかを当てにする前に、ROI ページで条件を確認してください。

Lite によって採算の計算が変わります。FAQ は今も、Relationship Tracking が最も効果を発揮するのは追跡コンタクト 10,000 件以上からとし、ACV が非常に高い売り手は例外としています。しかし最低 $6,000 であれば、クリーンなコンタクトを 5,000 件持つ企業でも、推測に頼らず安価なパイロットを回せるようになりました。

カテゴリーのリーダーとの差は広がりました。UserGems は Core を年額 $40,000、導入費 $3,000 で公開しています。初年度 $43,000 に対し Champify Pro は $30,000 で約 1.4 倍、Lite は $6,000 です。ただし Lite が追跡するコンタクト数は UserGems Core のカバー範囲よりはるかに少ない点に注意してください。両社の最上位で比べると、Champify Enterprise が $60,000 からであるのに対し、UserGems Elite は $150,000 と導入費 $10,000 で、約 2.7 倍です。

## 最適な対象

Salesforce に標準化した B2B SaaS 企業の RevOps リーダーと営業リーダーで、名前のあるチャンピオンが結果を左右するミッドマーケットやエンタープライズの商談を扱うチーム。Lite は、コンタクトが 5,000〜40,000 件あり、本格導入の前に転職起点のパイプラインが本物かを試したいチームに向きます。Pro は、Insider AI やカレンダー由来のコンタクトが重要になった段階の ARR $20-200M 帯に向きます。最も的を絞ったユースケースは、チャンピオン離脱のアラートを、移動から数日以内に担当 CSM へ届け、受信箱ではなく定義済みの更新リスク対応施策につなげる必要があるカスタマーサクセスチームです。

## 代替候補との比較

- **vs [UserGems](/ja/tools/usergems/)。** UserGems はこのセグメントのリーダーで、全プランで Salesforce と HubSpot に対応し、現在は Advanced と Elite プランで MCP サーバーも提供しています。Champify の FAQ は、HubSpot とのネイティブ連携はないと明言しており、Champify のデータが HubSpot に届くのは Salesforce-HubSpot 同期を経由する場合だけです。HubSpot を使っている企業、またはエージェントからのアクセスと、高い価格に見合う幅広い AI アクションを求める企業は UserGems を選んでください。Salesforce 一本で、同じ中核イベントを初年度コストのごく一部で手に入れたい企業は Champify を選んでください。
- **vs [ZoomInfo](/ja/tools/zoominfo/)。** セグメント最大のデータベンダーは、企業がすでに購入しているコンタクトデータベースに転職フィードを同梱しています。同梱フィードでニーズを満たせ、別の予算項目を正当化できない場合は ZoomInfo を選んでください。転職シグナルを、エクスポート用のリストではなく、担当者と施策が紐づいたルーティング済みの Salesforce レコードとして受け取る必要がある場合は Champify を選んでください。
- **vs [Common Room](/ja/tools/common-room/)。** マルチシグナル型のこの製品は、転職をコミュニティ、プロダクト、Web サイト、ソーシャルのシグナルと並ぶ一つの入力として扱い、全プランに MCP サーバーを備え、年額請求で $2,500/月からです。開発者やコミュニティのシグナルを使うプロダクト主導型の取り組みには Common Room を選んでください。関係の移動だけが重要なシグナルで、スタックがコンタクトとアカウント中心である場合は Champify を選んでください。
- **vs [Sales Navigator](/ja/tools/sales-navigator/) と現状維持。** Sales Navigator は転職を個々の担当者に表示するところで止まります。追跡コンタクトが約 5,000 件未満なら、それでも回ります。それを超えたときに予想される失敗は、誰もチャンピオンの離脱に気づかず、更新の電話で初めて知ることです。

## 注意点

- **実行レイヤーのないシグナル。** 第三者レビューで最も多い批判は、Champify が移動を知らせるだけで、フォローアップをチームに任せきりにする点です。シーケンサーもダイヤラーもなく、今週の移動者のうち誰から対応すべきかの優先順位付けもありません。**対策：** Salesforce のフィールドを成果物ではなくトリガーとして扱ってください。立ち上げ前に [Outreach](/ja/tools/outreach/) のシーケンスと名前付きの施策に接続し、定着度は届いたアラート数ではなく実行された施策数で測ってください。
- **エージェント向けの窓口も API もない。** Champify は MCP サーバーも公開 API も提供しておらず、データは Salesforce と掲載された連携先を通じてのみ外に出ます。UserGems と Common Room はいずれも MCP サーバーを公開済みです。**対策：** AI エージェントにチャンピオンの移動を読ませる必要があるなら、Salesforce から読む前提で設計し、すでに使っている Salesforce の MCP やコネクターが Champify のオブジェクトに届くかを確認してください。
- **安い入口に未公開価格のアドオン。** Lite の $500 でカバーされるのは 5,000 コンタクト程度で、Insider AI、役員採用、CRM Clean は要問い合わせです。**対策：** Pro ではなく Lite を選ぶ前に、アドオンの見積もり全体を書面で取ってください。アドオンを 3 つ付けた Lite は、Pro の $2,500 に近づくことがあります。
- **Salesforce への強い依存。** CRM の移行や HubSpot 優先の事業部門があると、サブスクリプションが宙に浮きます。**対策：** Salesforce への継続利用が Champify の契約期間より長く続くことを確認してください。2 年のロードマップに HubSpot への移行があるなら、後で移行ペナルティを払うのではなく、今のうちに UserGems の見積もりを取ってください。
- **成果は CRM の衛生状態次第。** メールが無効で役職が欠けたコンタクトはマッチを生みませんが、コンタクト数ベースのプランではそれらの追跡にも料金がかかります。**対策：** 契約規模を決める前に除外と重複排除をかけ、有効なコンタクトを基準にプランを購入してください。
- **人物の追跡にはプライバシー上の姿勢が伴う。** 特定個人の転職監視は、EU 居住のコンタクトについて GDPR 上の影響があります。**対策：** 展開前に DPO と範囲を確認してください。一般的な解決策は、追跡対象を地域で絞ることです。
