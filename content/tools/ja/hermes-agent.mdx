## 概要

Hermes Agent は、Nous Research が2026年2月に MIT ライセンスで公開したオープンソースのセルフホスト型 AI エージェントです。ノート PC や小さな VPS にインストールし、モデルプロバイダーを指定すれば、ターミナルからでも、チームが普段使っているチャットアプリからでも指示を出せます。1つの gateway プロセスで Telegram、Discord、[Slack](/ja/tools/slack/)、WhatsApp、Signal、メールに対応し、ドキュメントには [Microsoft Teams](/ja/tools/microsoft-teams/)、Google Chat、Matrix、Mattermost を含む20以上のプラットフォームが記載されています。2026年11月13日に確認した時点で、GitHub リポジトリのスター数は約263,000でした。

Nous が差別化要因として打ち出しているのは学習ループです。エージェントはターンの後に自分のスキルを書いたり修正したりできます。スキルは `~/.hermes/skills/<category>/<name>/SKILL.md` 配下のフォルダで、Claude Skills と同じ agentskills.io 形式です。さらに `MEMORY.md` と `USER.md` という2つの小さなメモリファイルを持ち、毎セッション読み込まれます。3か月目に動いているエージェントは、自分で書いた指示に従っています。それこそが狙いであり、同時に最大のガバナンス上の論点です。

会社の形は2026年10月に変わりました。10月7日、Nous は Nvidia、Samsung、Microsoft の M12、Union Square Ventures、Y Combinator、Menlo Ventures が参加する9,000万ドルの資金調達を発表し、有料のビジネス版を開発するとしています。15億ドルという評価額は Wall Street Journal の報道によるもので、Nous 自身は公表していません。利用規模の数字（2,400万回以上のクローン、世界のトークン使用量の約2.5%）は Nous 自身の推計であり、そのように受け取るべきです。

## 3つの導入方法

- **セルフホスト、0ドル。** Linux、macOS、WSL2 では `curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash`、Windows では PowerShell インストーラーで導入し、`hermes gateway setup` でチャネルを接続します。モデル費用は接続したプロバイダーに直接支払います。Nous Portal、[OpenRouter](/ja/tools/openrouter/)、OpenAI、または自分で設定した任意のエンドポイントが使えます。
- **Hermes Cloud。** Nous が従量制のインスタンスでエージェントをホストし、ポータルのクレジットから日次で請求します。稼働中は計算資源を秒単位で、停止中はストレージのみを課金し、推論と有料ツールは別途です。デプロイには2ドルのクレジットかサブスクリプションが必要です。ポータルのプランは Free（無料モデルのみ）、Plus が月額20ドル（RAM 4 GB、ディスク 25 GB）、Super が月額100ドル、Ultra が月額200ドルで、有料プランにはそれぞれ Cloud エージェントが1つ含まれます。
- **Hermes for Business。** メンバーごとの支出上限付きの共有クレジット残高、管理者が管理するロールと API キー、チームのスキルライブラリ、Discord・Telegram・Slack・WhatsApp 向けのチーム gateway を備え、Nous のインフラ上でチームごとに分離されたテナントで動きます。登録はセルフサービスですが、価格は公開されていません。SSO、SLA、オンプレミスまたはプライベートクラウドでの導入は、営業経由で販売される別の Enterprise 層に含まれます。

## 実際にかかる費用

1人のオペレーターにとって、現実的な月額費用はソフトウェアではなくモデルです。セルフホストではサーバーが追加で必要になり、Nous は最低ハードウェア要件を公開していないためサイズは自分で決めることになります。Hermes Cloud の Plus プラン（20ドル）ならサーバーは不要ですが、推論費用は残り、ターンごと、バックグラウンドでのスキル見直しごとに増えていきます。ビジネス版は外部から金額を知ることができません。価格表がない以上、耳にした金額はすべて書面で確認すべき見積もりとして扱い、モデル費用込みで Claude Team の1ユーザーあたり月額25ドル（年払いなら20ドル）で使える [Claude Cowork](/ja/tools/claude-cowork/) と比較してください。

## 最適な用途

- **技術担当者がいる RevOps、Legal Ops、Recruiting のオペレーター。** Slack や Telegram に常駐し、学んだ手順（週次のパイプライン衛生チェック、受信契約のトリアージ、候補者ダイジェストのスキルなど）を保持しながら、すでに支払っているモデルで動くエージェントが欲しい場合です。
- **Hermes for Business を試す小規模チーム。** 1人ごとの上限付きの共有クレジットプールが、財務責任者が実際に求めている統制である場合に向いています。

## 代替ツールと選ぶべき場面

- **[OpenClaw](/ja/tools/openclaw/)**：最も近い競合で、Claude Cowork と並んで多くのオペレーションチームがすでに候補に挙げているエージェントです。2026年7月からは非営利財団が運営しています。自己記述型のスキルよりもガバナンスの継続性を重視するなら OpenClaw を選んでください。有料版を売るベンダーがいないためアップセルの圧力はありませんが、サポート契約もありません。
- **[QM](/ja/tools/qm/)**：マルチユーザーが要件の場合に選びます。チャネルごとのエージェント、スコープごとの権限、監査ログを自社の AWS または Fly.io アカウント内で運用できます。Hermes のメモリはプロファイル単位で分かれており、Slack チャネル単位ではありません。
- **[Claude Cowork](/ja/tools/claude-cowork/)**：デーモンを管理する人がおらず、会社がすでに Claude に支払っている場合に選びます。ホストも gateway も不要で、スケジュールタスクは Anthropic のクラウドで動き、調達書類もすでに揃っています。
- Hermes 自体がこの分野で最も急成長している新規参入です。2026年2月の公開から9か月で GitHub スター約263,000に達しました。試す理由であると同時に、本番ではインストーラーの最新ビルドを使わずバージョンを固定すべき理由でもあります。
- **[Manus](/ja/tools/manus/)**：非エンジニアが起動する単発のリサーチやブラウジング作業に選びます。手順を蓄積していく常駐エージェントには向きません。

## 注意点

- **自己記述型スキルはレビューなしで挙動を変えます。** デフォルトではエージェントがターン後にスキルを作成・修正し、メモリへの書き込みにも承認は不要です。対策：`skills.write_approval: true`（承認されるまで書き込みは `~/.hermes/pending/skills/` に保留されます）と `memory.write_approval: true` を設定し、`~/.hermes/skills/` を git で管理して、すべての変更に差分が残るようにします。
- **コンテナ型バックエンドでは危険コマンドのチェックが省略されます。** ドキュメントによれば、Docker、Modal などの隔離されたバックエンドでは「コンテナ自体がセキュリティ境界」とされ、コマンドのスクリーニングは無効になります。ローカルバックエンドでも、ファイル書き込みの保護は厳格な境界ではなく多層防御の一部と説明されています。対策：認証情報や共有ドライブをサンドボックスにマウントしないこと、社外のメールやウェブページを読むエージェントでは `approvals.mode` を `manual` に保つことです。
- **デフォルトの承認者リストは全員です。** `approvals.approvers` のデフォルトは `["*"]` で、gateway にアクセスできる人なら誰でも危険なコマンドを承認できます。対策：承認者を明示的に指定し、gateway の allowlist と DM ペアリングを使い、チームで1つのエージェントを共有するのではなく信頼境界ごとに1プロファイルを運用します。
- **メモリは小さく、溢れると明確に失敗します。** `MEMORY.md` の上限は2,200文字、`USER.md` は1,375文字で、満杯になるとエージェントが整理するまで書き込みが失敗します。対策：長期的に参照する資料はコアメモリではなく、スキルか外部メモリプラグイン（Honcho、Mem0 などに対応）に置きます。
- **ビジネス版は新しく、価格が未公開です。** 公開価格はなく、製品ページに監査ログの記載もなく、SSO は Enterprise のみです。対策：規制対象データについては、セルフホスト環境から何かを移す前に、DPA、サブプロセッサー一覧、書面での価格提示を求めてください。
