## 概要

Google Antigravity は、Google のエージェントファーストの開発プラットフォームです。タスクを渡すと、エージェントが作業を計画し、ファイルを編集し、コマンドを実行し、ブラウザを操作して結果を確認したうえで報告します。エージェントを並列で動かすためのデスクトップアプリ、IDE、Antigravity CLI、そして同じエージェントハーネスを自社のコードから使える Python SDK として提供されています。2026年5月19日の Google I/O で発表されたバージョン 2.0 では、スタンドアロンアプリ、CLI、スケジュール実行のバックグラウンドタスク、認証情報のマスキングを伴うサンドボックスが追加されました。macOS、Windows、Linux で動作します。

現在、Google の一般向けコーディングエージェントはこれだけです。Gemini CLI と Gemini Code Assist の IDE 拡張機能は、2026年6月18日に無料ユーザーと AI Pro/Ultra ユーザーへの提供を終了し、Google はこれらのユーザーに Antigravity CLI への移行を案内しました。非同期型コーディングエージェントの Jules は11月11日に読み取り専用となり、2026年12月31日に終了します。チームの誰かがどちらかの上にスクリプトを構築していた場合、Google が移行先として想定しているのが Antigravity です。形態としては [Claude Code](/ja/tools/claude-code/) や [OpenAI Codex](/ja/tools/openai-codex/) に最も近く、1つのエージェントエンジンの上にアプリ、ターミナルツール、SDK が載っています。

## ops スタックに載る理由

- **無料枠が実用的なツールになっています。** $0 の個人プランには、アプリ、CLI、IDE 拡張機能、SDK、並列バックグラウンドエージェント、ブラウザ操作、スケジュールタスクが含まれ、週単位のエージェント割り当て量で利用できます。RevOps アナリストは、発注書なしで CRM のクリーンアップスクリプトやエンリッチメントジョブを試作できます。
- **1つのシートでモデルを選べます。** 有料プランでは Google の Gemini 4 モデルと Anthropic の Claude Sonnet および Opus を実行できます。Gemini Enterprise では、Claude モデルは管理者がオプトインする必要があり、トークン単位で課金されます。
- **長いジョブ向けの `/teamwork`。** 有料プランでは、`/teamwork` はスコープを確認するヒアリングから始まり、その後オーケストレーターがプロジェクトをマイルストーンに分割して explorer エージェントと worker エージェントに割り振ります。critic エージェントと auditor エージェントが各マイルストーンを確認してから作業が続行されます。単発のスクリプトよりも、数日がかりの移行作業に向いています。
- **MCP と SaaS へのエージェントアクセス。** SDK は MCP サーバーに接続でき、エンタープライズ管理者は MCP、サンドボックス、ブラウザのポリシーを設定できます。[Greenhouse](/ja/tools/greenhouse/) はすでに自社の MCP サーバーのクライアントとして Antigravity を挙げています。このパターンの背景は [MCP サーバーとは何か](/ja/learn/mcp-server-explained/) で解説しています。

## 価格の実態

Antigravity 自体には価格がありません。利用権は Google アカウントに紐づくプランから得られます。

- **個人、$0:** 基本のエージェント割り当て量で、毎週リセットされます。
- **Google AI Pro、月額 $19.99:** 割り当て量が5時間ごとにリセットされ、週単位の上限も高くなります。`/teamwork` も含まれます。
- **Google AI Ultra、月額 $100 または $200:** I/O 2026 で最上位プランが $250 から引き下げられて以降、Pro の上限の5倍または20倍です。
- **AI クレジット:** 2026年3月から、割り当て量を超えた利用向けに 2,500 クレジットあたり $25 で販売されています。
- **Google Cloud 経由の法人向け:** Gemini Enterprise Standard または Plus はシートあたり月額 $30 からで、毎月 $10 または $15 のシートクレジットが付きます。シート料金なしで従量課金となる pay-as-you-go プランもあります。エンタープライズでの提供は2026年8月21日に始まり、プール型の割り当て量、支出上限、監査ログが用意されています。

Google の価格ページには割り当て量の具体的な数値が掲載されておらず、プランのドキュメントには上限は「変更される場合があります」と書かれています。2026年3月には、Pro の割り当て量が数日で尽きたとユーザーから報告がありました。Google は5月に Gemini の上限を2度にわたり3倍に引き上げましたが、DeepMind の Varun Mohan は、ヘビーユーザーは「数回の作業セッションの後」に週の上限に達する可能性があるとなお述べています。たまにスクリプトを書く人には AI Pro を、毎日使う人には $100 の Ultra を予算に組んでください。チームの場合、計画上の目安は月額 $30–45 の Gemini Enterprise シートに超過分を加えた額です。

## 適しているのは

すでに Google Cloud を購入している企業で、少数のリポジトリ（CRM から BigQuery への同期、エンリッチメントジョブ、社内 MCP サーバー）を管理している RevOps または GTM エンジニアです。監査ログ付きで統制された Gemini Enterprise シートを使え、CLI では同じエージェントを cron や CI から実行できます。今四半期中にサポートされた代替手段が必要な、元 Gemini CLI ユーザーや元 Jules ユーザーにも適しています。

## 適していないのは

Google Workspace のみを利用していて、ライセンスに含まれると考えているチームです。Antigravity をバンドルしていた Workspace AI Ultra Access アドオンは2026年7月7日をもって提供終了となり、Workspace プランには Antigravity が含まれないため、利用するには Gemini Enterprise を別途購入するか、個人の Google アカウントを使う必要があります。また、注意点で触れるとおり、サブスクリプションのログインを使ってサードパーティのハーネスからエージェントを操作したい人にも向きません。

## 代替候補との比較

- **[GitHub Copilot](/ja/tools/github-copilot/):** シート数で最大のインストールベースを持ち、ユーザーあたり月額で Business が $19、Enterprise が $39 で、プール型のクレジットが付きます。会社が GitHub Enterprise を購入しており、大半の開発者がエディタ内でのインライン支援を求めている場合に選んでください。
- **[Cursor](/ja/tools/cursor/):** 売上でトップのコーディング特化型の競合で、2026年初頭の年換算売上は20億ドルを超えたと報じられています。IDE を主な作業場所とし、すべての編集を視覚的に制御したい人に選んでください。
- **[OpenAI Codex](/ja/tools/openai-codex/):** 最も急成長している新規参入で、2026年6月までに週間ユーザー数が500万人を超え、$20 の ChatGPT Plus から含まれています。会社が ChatGPT Business に標準化している場合に選んでください。
- **[Claude Code](/ja/tools/claude-code/):** Pro は月額 $20 からです。既存のコードベースに対する複数ファイルの変更が中心で、Google が変更できる割り当て量ではなく公開された利用ティアを望む場合に選んでください。

無料枠で実際の業務をこなす必要がある場合、または Google Cloud が調達経路である場合は、この4つすべてよりも Antigravity を選んでください。

## 注意点

- **サードパーティ経由のアクセスはアカウント停止につながります。** Antigravity の利用規約は、「サードパーティのソフトウェア、ツール、またはサービスを使用して本サービスにアクセスすること」を違反としており、その例として Antigravity OAuth を使った OpenClaw を挙げています。2026年2月、Google はこれを行ったユーザーを、有料の Ultra 契約者も含めて利用停止にしました。対策: サードパーティのエージェントは Gemini API キーまたは Gemini Enterprise で実行し、個人の OAuth ログインは決して使わないでください。業務用シートに紐づくアカウントは、実験用とは分けておいてください。
- **個人プランのデータはトレーニングに使われます。** 個人向けの規約では、ユーザーがオプトアウトしない限り、Google はやり取りを自社製品と機械学習の改善に利用でき、人間のレビュアーも関与します。Gemini Enterprise はプロンプトや出力をトレーニングに使わないとしています。対策: 顧客データや候補者データを含むリポジトリに、スタッフが個人アカウントを向けないようにしてください。該当するユーザーは Gemini Enterprise に移すか、オプトアウトが設定されていることを確認してください。
- **割り当て量は予告なく変わります。** 2026年には上限が少なくとも3回変更され、モデルも入れ替わります。Google は2026年11月30日に、古い Claude モデルとオープンモデルを Free と Pro から削除します。対策: スケジュール実行のジョブには、Gemini Enterprise の超過課金またはクレジットで支出上限を設定してください。ジョブはテスト済みのモデルに固定し、ドキュメントが変わったら再テストしてください。
