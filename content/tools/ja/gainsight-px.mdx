## 概要

Gainsight PX は Gainsight のプロダクトエクスペリエンスモジュールです。顧客がログインして使う SaaS 製品に対して、プロダクト分析、アプリ内ガイドとチェックリスト、アプリ内アンケート、埋め込み型のヘルプウィジェット、アダプションスコアリングを提供します。前身は Gainsight が 2019 年に買収した Aptrinsic で、独立したサブスクリプションとして販売されています。[Gainsight](/ja/tools/gainsight/) CS なしで PX だけを使うこともできますが、価値の前提はほぼすべて CS と組み合わせることにあります。

このページは PX のみを扱います。ヘルススコア、更新予測、CSM のプレイブックが論点なら Gainsight CS のページを参照してください。PX が答えるのはもっと狭い問いです。**CS 寄りのアダプションツールで足りるのか、それとも [Pendo](/ja/tools/pendo/) のようなプロダクト分析優先のプラットフォームが必要なのか。**

## Customer Success スタックで採用される理由

- **利用データが CSM の作業場所に届きます。** PX にはネイティブの PX-CS 連携があり、アカウント単位・ユーザー単位の利用状況、アダプションスコア、PX アンケートの回答が、reverse ETL のジョブなしで Gainsight CS のヘルススコアとタイムラインに流れ込みます。多くのチームが、より強力な単体の分析ツールではなく PX を選ぶ最大の理由がこれです。
- **CS チームがエンジニアなしで出せるエンゲージメント。** ガイド、ツールチップ、オンボーディングのチェックリスト、ネイティブのメールキャンペーン、NPS/CSAT/CES アンケートを、1 セッションで 1 人のユーザーに 3 つもポップアップが出ないようにするスロットリング付きで配信できます。ヘルプウィジェットは現在 In-App Hub(旧 KC Bot)という名称で、Zendesk、Salesforce Knowledge、Thought Industries、Coveo などのナレッジソースを検索できます。
- **PX のライブデータに対する MCP サーバー。** Gainsight の MCP ページでは PX の MCP サーバーが一般提供(GA)と記載されています(ただし 2026-10-27 時点で、PX のサポート索引では LLM 接続の記事にまだ「Beta」の表記があります)。2026 年 8 月の PX ニュースレターで公開された Gainsight MCP Prompt Library と組み合わせると、CSM は Claude や ChatGPT に、どのアカウントがある機能で停滞しているかを尋ね、フォローアップの文面を下書きできます。Gainsight が PX in Practice セッションで教えている「見つける、理解する、直す、確認する」のループです。
- **最近深くなった分析機能。** Query Builder には Cohort ビューに加えて Metrics モード(既定のメトリクスとカスタムメトリクス、数式ビルダー)が追加され、Path Analyzer ではステップ間の平均所要時間が表示されるようになりました。Amplitude ほどの深さはまだありませんが、2026 年に差は縮まっています。

## 価格の実態

Gainsight は PX の価格を公開していません。価格ページには「Request Pricing」と無料トライアルがあるだけです。価格は主に、トラッキング対象製品の月間アクティブユーザー(MAU)で決まります。Gainsight のドキュメントには 2 つのパッケージが記載されています。

- **PX Essentials**:1 製品に加えて最大 3 つの追加プロダクトタグ、月 100K 通のメール、アクティブな In-App Hub は 1 つ、基本的な連携。
- **PX Enterprise**:最大 30 のプロダクトタグとタグ横断のトラッキング、月 500K 通のメール、複数の In-App Hub、高度な連携、エンタープライズ向けセキュリティ。

どちらも名目上は MAU 無制限で、1 MAU あたり月 1K イベントの上限、36 か月のデータ保持、1 日 1M 回のパブリック API コールが含まれます。

第三者データ(Userpilot と Oliv.ai のコスト解説。いずれもベンダー寄りの情報源)による実勢価格帯は、単一製品の小規模導入で年間約 $13K–$14K から、契約の中央値は年間約 $50K、複数製品のエンタープライズ契約は $100K を超えます。比較として、当サイトの [Pendo](/ja/tools/pendo/) のページでは、ミッドマーケットの Pendo を年間 $30K–$150K としています。実際に効くのはバンドルです。CS と PX をまとめて購入したチームは、合算スイートで 15–25% の値引きを交渉できたと報告しています(当サイトの Gainsight vs ChurnZero の比較を参照)。

## 最適なケース

- **すでに Gainsight CS を使っている B2B SaaS 企業の CS オペレーション責任者**で、データパイプラインを構築せずにプロダクト利用状況をヘルススコアと CSM のタイムラインに取り込みたい場合。
- **プロダクトではなく CS が運営するオンボーディング・アダプション施策**:チェックリスト、機能告知、アプリ内 NPS をポストセールスのチームが持つ場合。
- **AI アシスタントからアダプションデータを今すぐ照会したいチーム**:エクスポートではなく、ベンダーがサポートする MCP サーバー経由で。

## 代替ツールとの比較

- **[Pendo](/ja/tools/pendo/)**:顧客向けプロダクトアダプション分野のシェアトップで、分析はより深く、ロードマップモジュールがあり、レビュー数も桁違いです(GetApp のレビューは 238 件、PX は 7 件)。プロダクトマネジメントがツールを所有し、CS への引き継ぎより分析の深さが重要なら Pendo を選んでください。CS が所有し、Gainsight CS がシステム・オブ・レコードなら PX を選んでください。
- **[WalkMe](/ja/tools/walkme/)**(SAP)と **[Whatfix](/ja/tools/whatfix/)**:最大手の 2 つのデジタルアダプションプラットフォームで、主に購入したソフトウェアの中で従業員をガイドするために作られています。Salesforce や Workday のような社内アプリが対象ならこちらを選んでください。PX は自社が販売する製品のためのツールです。
- **[Userpilot](/ja/tools/userpilot/)**、**[Appcues](/ja/tools/appcues/)**、**[Chameleon](/ja/tools/chameleon/)**:定価が月額約 $249–$299 からのセルフサーブ型アダプションツールです。Gainsight CS がなく、ガイドと軽い分析を年間 $10K 未満で揃えたいならこれらのいずれかを選んでください。
- **Guidde**:アダプション向けコンテンツ分野で最も急成長している新興企業で、2026 年 2 月に PSG Equity 主導で $50M のシリーズ B を調達しています。本当に必要なのがセグメント別のアプリ内エンゲージメントではなく、すばやく作れるハウツー動画なら Guidde を選んでください。
- **[Amplitude](/ja/tools/amplitude/)** または **[Mixpanel](/ja/tools/mixpanel/)**:必要なのが分析だけならこちらを選んでください。どちらもアプリ内ガイドの代わりにはなりません。

## 注意点

- **Gainsight CS なしの PX は強みの大半を失います。** 分析だけなら Pendo や Amplitude の方が強く、レビューも少数です。**対策:** Gainsight CS を使っておらず、契約期間内に導入する予定もないなら、署名前に Pendo か Userpilot と並行トライアルを行ってください。
- **1 MAU あたり月 1K イベントの上限は、イベントの多い製品で効いてきます。** 利用頻度の高いアプリで自動トラッキングとカスタムイベントを組み合わせると上限に達することがあります。**対策:** 交渉前に、現在の分析ツールからアクティブユーザー 1 人あたりのイベント量を 30 日分抽出し、超過時の条件を発注書に明記させてください。
- **HubSpot と Snowflake のネイティブコネクタがありません。** 連携の索引に載っているのは Salesforce(双方向)、Segment、S3/Google Cloud Storage、Slack、Zendesk です。HubSpot には PX Data Loader か REST API が、Snowflake にはサードパーティの reverse ETL ツールが必要です。**対策:** 契約前に PX のデータを受け取る必要があるシステムをすべて洗い出し、ミドルウェアの費用を総コストに含めてください。
- **MCP のステータスがページによって異なります。** マーケティングページは GA、サポートドキュメントはまだ Beta としています。**対策:** CSM のワークフローを構築する前に、PX の MCP サーバーがサポート SLA の対象であることを書面で確認してください。
- **バンドル割引は更新をひとまとめに縛ります。** CS + PX で 15–25% の割引を受けると、後からどちらかのモジュールを外すコストが高くなります。**対策:** モジュールごとに別々の更新上限を交渉し、CS の価格を見直されることなく PX を外せるようにしてください。
