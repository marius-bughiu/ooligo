[Clio](/ja/tools/clio/) と [MyCase](/ja/tools/mycase/) は、10 年にわたって同じ買い手の最終候補リストで並んできました。表計算ソフトと共有ドライブと請求ソフトを置き換えようとしている、弁護士 1 人から 50 人規模の法律事務所です。従来の判断基準は、エコシステムの広さか、1 席あたりの安さか、というものでした。

その基準は、もはや両社の価格表に触れた瞬間に崩れます。MyCase は 1 ユーザーあたり月額 $50 から、Clio は $49 から始まります。席の安さは誤差の範囲です。2026 年に両者を本当に分けているのは、MyCase が販売するすべてのプランを公開しているのに対し、Clio は下限だけを公開している、という点です。

## 何が変わったか

Clio は vLex を 10 億ドルで買収し、同時に 50 億ドルの評価額でシリーズ G を 5 億ドル調達して、その周りに製品ラインを組み直しました。EasyStart / Essentials / Advanced / Complete という階段はなくなりました。プランは現在 Starter、Core、Signature、Elite の 4 つで、法律リサーチ機能は別製品の Clio Work として登場しました。Clio Work は Clio Library の上で動きます。100 を超える法域から集めた 10 億件以上の法律文書で、Web からのスクレイピングではなく裁判所と出版社を出典とし、Cert という引用チェッカーがその判例が今も有効な法かどうかを確認します。

MyCase が変えたのは親会社のブランドであって、アーキテクチャではありません。AffiniPay は 2025 年 8 月に 8am へ社名を変更し、LawPay、MyCase、CasePeer、Docketwise、CPACharge を 1 つの名前の下にまとめました。事務所管理製品は現在 8am MyCase であり、その AI は 8am IQ として提供されます。Pro には Writing and Document Assistant が、Advanced には Case Assistant と OCR 付きの Discovery Assistant が付きます。

## Clio が勝つところ

- **リサーチと起案が案件の中にあります。** Clio Work は案件の文書と法令を一緒に読み、その両方を引用します。この価格帯の他の事務所管理ベンダーは、リサーチのためにシステムの外に出て、結果を貼り戻すことを求めます。それが vLex への投資が買った機能であり、MyCase にはこれに対する答えがありません。
- **会計が Starter から全プランに含まれます。** 銀行取引の同期、売掛金、預り金口座と運営口座の照合、財務レポートがサブスクリプションに付いてきます。MyCase は同等の機能に 1 ユーザーあたり月額 $39 を請求します。
- **上位プランには集客がバンドルされます。** Elite にはインテークと CRM の製品である Clio Grow が含まれ、別項目として売られません。
- **連携できる範囲が広いです。** Clio は 15 年かけて電子申立て、文書管理、会計への接続を積み上げてきました。MyCase が Pro で掲げているのは 70 以上の連携です。

## MyCase が勝つところ

- **誰とも話さずに見積もれます。** 3 つのプランすべてに数字が付いています。年額払いで Basic が 1 ユーザーあたり月額 $50、Pro が $100、Advanced が $130、月額払いなら $60 / $120 / $150 です。10 席の予算は、商談ではなく 1 分で組めます。
- **AI の価格が分かっています。** 8am IQ Writing and Document Assistant は $100 の Pro に含まれます。Clio 側では AI は Core から始まりますが、その Core には公開価格がまったくありません。
- **ディスカバリー作業に公開された上限があります。** Discovery Assistant は 1 ユーザーあたり月 5,000 ページを処理し、$30 のオプションを追加すると事務所全体でさらに 5,000 ページを使えます。従量課金の AI がこのカテゴリで見積もりの裏に隠れないのは珍しいことです。
- **決済にプラットフォーム手数料がかかりません。** LawPay 連携は月額 $0 で、別途決済手数料がかかるだけです。しかも決済会社が事務所管理製品を保有しているため、預り金会計と照合を 1 つのチームが作っています。

## 価格の実態

公開されている数字は同じものを比べていません。ほとんどの最終候補リストが狂うのはここです。

Clio が公開している価格は 1 つだけです。Starter の 1 ユーザーあたり月額 $49 です。Core、Signature、Elite はいずれも「get pricing」か「book a demo」になっています。Clio 自身の FAQ は AI が Core 以上に含まれると述べています。つまり、自分で価格を確認できる唯一の Clio のプランが、AI の入っていないプランだということです。

したがって、正直な対戦は $49 対 $50 ではありません。見積もりのない Clio Core 対、1 ユーザーあたり月額 $100 の MyCase Pro です。10 席の事務所は、MyCase Pro が年間 $12,000、MyCase Advanced が年間 $15,600 だと分かります。同じ事務所が Clio Core の価格を知るには、商談を経るしかありません。

合計額を動かすのは、プラン選びよりもアドオンです。MyCase Advanced を 10 席で会計モジュール付きにすると年間 $20,280 になり、会計だけで $4,680 が乗ります。Clio は同じ会計を 10 席で年間 $5,880 の Starter サブスクリプションの中に入れています。年額払いは MyCase で最大 16% 節約になります。Clio には月額と年額の切り替え自体がありません。

## 避けるべき落とし穴

$49 と $50 を並べて読み、2 つのプラットフォームは同じ値段だと結論づけることです。同じかもしれませんが、Clio の価格ページにそれを裏づけるものは何もありません。AI が購入理由の一部であれば Clio Starter は候補になりませんし、本当に必要な比較の相手は Clio が印刷しない数字です。評価の初週に、まだトライアルに時間を注ぎ込む前の段階で Clio Core と Signature の見積もりを取り、$49 という見出しではなく MyCase Pro と Advanced に対してぶつけることで身を守ってください。

MyCase 側の鏡像となる落とし穴は、公開価格を請求額の全部だと考えることです。会計は別途 1 ユーザーあたり月額 $39 で、Open API は Advanced に限定されています。コストを抑えようと $100 の Pro を買い、その後 70 以上の連携リストが埋めていない何かと同期するために API アクセスが必要だと気づいた事務所は、結局 $130 のプランを買うことになります。API が必要かどうかは、プランを選んだ後ではなく前に決めてください。

## 結論

- **Clio を選ぶ**のは、自動化しようとしている仕事が案件管理と請求だけでなく法律リサーチと起案を含むとき、会計をアドオンではなくサブスクリプションの中に入れたいとき、あるいは事務所が弁護士 50 人規模に向かっていて、より広い連携範囲が必要になるときです。
- **MyCase を選ぶ**のは、機能の広さよりも公開された読みやすい価格が重要なとき、人身傷害・家事・刑事弁護・移民といったインテーク量の多い消費者向けの業務で、リードの転換率が制約になっているとき、あるいはすでに LawPay を使っていて請求・決済・預り金照合を 1 社から得たいときです。
- **どちらも選ばない**のは、訴訟の比重が高く案件の作り込みそのものが本業であるときです。その形には [Filevine](/ja/tools/filevine/) が作られています。また、法律事務所ではなく企業の法務部門であれば、両者ともカテゴリが違います。これらは時間と預り金会計を中心に据えた事務所側の製品であり、社内側の対応物は案件管理と[インテーク](/ja/learn/legal-intake/)のツールです。

これらの条件を切り分けられないときの既定の選択は MyCase Pro です。1 ユーザーあたり月額 $100 という分かっている金額から、AI 込みで始められますし、より大きなものに踏み込む前に自分の事務所が実際に何を使うのかを確かめられます。その差が[案件管理](/ja/learn/matter-management/)ではなくリサーチと起案にあるとトライアルが示したときに、Clio へ移ってください。その時点で見積もりを取る価値があります。Clio Work は、MyCase が答えようとすらしていない問いに答えているからです。
