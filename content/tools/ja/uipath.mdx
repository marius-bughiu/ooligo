## 概要

UiPath はロボティック・プロセス・オートメーション（RPA）の既存大手で、この 18 か月をかけて、AI エージェント、ソフトウェアロボット、人をまとめて動かすオーケストレーション層へと自らを作り替えてきました。中核は今もロボットです。使える API を持たないシステムの画面、たとえばメインフレームのグリーンスクリーン、Citrix 経由で配信される ERP、保険や銀行のバックオフィスツールをロボットが操作します。多くの大規模な ops チームがすでに UiPath と契約しているのはこのためです。新しいのは、その上に載るすべての部分です。

同社は上場企業（NYSE: PATH）です。2026 年 7 月 31 日までの四半期では、売上高が前年同期比 13% 増の $410 million、ARR が 12% 増の $1.938 billion、ドルベースの売上継続率は 109% でした。同四半期の純新規 ARR は $37 million です。これは大きく、利益を出し、成長の遅いインストールベースの数字であり、以下のすべてを読むうえでの正直な前提です。

## エージェント時代に向けて変わったこと

現在の製品を形づくるのは 3 つの要素です。

- **Maestro** はオーケストレーターです。Temporal の durable execution エンジンの上に構築されているため、長時間にわたるプロセスでも各ステップで状態を保持し、一時停止、再開、端から端までの監査ができます。UiPath のエージェント、ロボット、他社のエージェント、人による承認ステップを 1 つのプロセスモデルで統率します。2027 会計年度第 2 四半期の決算時点で、UiPath は例外処理の多いプロセス向けの Maestro Case を追加しており、さらに 2026 年 8 月 19 日には、コーディングエージェントが書いた自動化を統制された本番環境へ載せる開発者向けキャンバス Maestro Flow を出しました。
- **Agent Builder** はエージェントそのものを構築します。UiPath がホストするモデルでも、自社で管理するモデルでも使えます。UiPath Orchestrator はロボット、エージェント、プロセスを MCP サーバーとして公開できるため、外部のエージェントが統制された UiPath のプロセスをツールとして呼び出せます。
- 2026 年 5 月 12 日に発表された **UiPath for Coding Agents** により、[Claude](/ja/tools/claude/) Code と OpenAI Codex が同じガバナンス層の中で自動化を作成・実行できます。Maestro Flow のオーサリングツールとしては [Cursor](/ja/tools/cursor/)、GitHub Copilot、Gemini にも対応しています。

2 つの動きも同じ方向を向いています。UiPath は 2026 年 2 月 6 日に、金融犯罪コンプライアンス（AML、KYC、制裁スクリーニング）向けのエージェントを持つ WorkFusion を買収しました。さらに 2026 年 5 月 5 日には、セルフホスト版の Automation Suite でエージェント機能の大半を提供開始し、規制業種や公共部門の買い手が自社インフラ上でセルフホストの LLM を使ってエージェントを動かせるようにしました。Gartner は 2026 年 9 月 14 日公開の Business Orchestration and Automation Technologies 部門の Magic Quadrant で、UiPath をリーダーに位置づけています。

## 購入に値するユースケース

システムの半分に API がない、保険金請求や受注例外の処理キューです。エージェントが受信メールと添付ファイルを読み、document understanding で項目を抽出してルーティングを判断します。無人ロボットがその結果をレガシーの保険契約画面や ERP 画面に入力します。しきい値を超えるものは Maestro 上で人の承認者に回り、実行全体が 1 つの監査証跡に残ります。[n8n](/ja/tools/n8n/) や [Workato](/ja/tools/workato/) でも画面操作以外のステップはすべて実現できますが、画面操作こそ省けないステップです。ここが UiPath の守れる領域です。つまり、今年誰も刷新しないシステムに対して、エージェントの判断と UI レベルの実行を、1 人の責任者のもとでまとめて扱えることです。

## 料金

公開されているプランは、Community（無料）、Basic（月額 $25 から、欧州リージョンでホスト、ユーザー数とロボット数に上限あり、Maestro なし）、そして見積もりのみの Standard と Enterprise です。エージェント、ドキュメント抽出、ユーザーとロボットの無制限利用は Standard から始まります。Enterprise では自己修復型の UI 自動化、プロセスシミュレーション、顧客管理の暗号鍵が加わります。

実際の契約額のほうが目安として優れています。Vendr の 2026 年 2 月までのデータでは、42 件の購入の中央値が**年間 $45,338**、範囲は $22,440 から $223,821 です。同社のガイドでは、無人ロボットが定価で 1 台あたり年間約 $8,000〜$10,000、有人ロボットが 1 ユーザーあたり $3,500〜$5,000、ボリュームや複数年のコミットで定価の 20〜35% 引きとされています。

エージェントは別枠で計量されます。Flex ライセンスでは、本番のエージェント実行が LLM 呼び出しごとに Agent Units を消費します。標準モデルは 1 回あたり 1 ユニット、プレミアムモデルは 2、ベーシックモデルは 0.8 で、入力トークン 64k 単位で課金されます。コンテキストが 100k トークンの呼び出しは 2 回分の課金です。自社のモデルを持ち込む場合は、呼び出し回数に関係なく 1 実行あたり 1 ユニットに下がります。クレジット型の商用プランでも、同じ考え方が Platform Units で適用されます。

## 最適な対象

すでに UiPath のロボットを運用している、あるいは使える API のないレガシーシステムをまたいで自動化しなければならない大企業の ops・自動化リーダーで、エージェントを 2 つ目のプラットフォームとしてではなく、同じガバナンス、監査、変更管理のもとに加えたい人です。自動化の Center of Excellence がすでにあり、UiPath で運営されているなら、これが標準の選択肢です。

## 代替製品と、それを選ぶべき場合

- **Microsoft Power Automate**: 多くの企業がすでにライセンスしている Microsoft 環境に含まれており、Premium が 1 ユーザーあたり月額 $15、無人ボットが 1 ボットあたり月額 $150、ホスト型ボットが $215 です。環境が Microsoft 365 と Dynamics で、自動化が部門単位であり、ボット単価が安く収まる程度にロボット数が少ない場合に選んでください。
- **Automation Anywhere**: もう一方の老舗 RPA リーダーで、Gartner の 2026 年 RPA 部門 Magic Quadrant で 8 年目のリーダーに選ばれています。Aisera の買収（2025 年 11 月）で IT、人事、サポート向けのエージェントが加わりました。RPA の更新を競合させて交渉している場合や、同社のクラウドネイティブな control room が自社のデプロイモデルに合う場合に選んでください。
- **[n8n](/ja/tools/n8n/)**: 自動化分野で最も成長の速い新興勢力で、2026 年 5 月に $5.2 billion の評価額を得ています。扱うすべてのシステムに API があり、エンジニアがいて、5 桁ドルの最低ラインなしでエージェントのワークフローを組みたい場合に選んでください。
- **[Workato](/ja/tools/workato/)**: 課題が画面レベルの自動化ではなく、基幹システム間の統合である場合に選んでください。

## 注意点

- **ロボットとエージェントは別の単位で計量されるため、ロボット前提の見積もりにはエージェントの費用が見えません。** 対策: 契約前に、処理量の多いエージェントプロセス上位 3 つを取り上げ、リトライや入力 64k トークンを超えるプロンプトを含めて 1 実行あたりの LLM 呼び出し回数を数え、実際に使うモデル階層で価格を試算してください。Agent Units や Platform Units のプールは、ベンダーのパイロット見積もりではなく、その数字をもとに交渉してください。
- **画面レベルのロボットは、対象アプリケーションが変わると壊れます。** 対策: 本番のロボットはすべて UiPath Test Cloud か同等の回帰テストスイートの管理下に置き、ベンダーの UI リリース予定を Center of Excellence の runbook に書き込んでください。API があるプロセスは、ロボットの保守に二重に払うのではなく API に移してください。
- **Standard と Enterprise は見積もりのみで、両者の機能の境目には実際のコストがかかります。** 対策: Maestro、自己修復、顧客管理の暗号鍵、必要な環境数がどのエディションに含まれるかを、更新時ではなく自動化を構築する前に書面で確認してください。
