[Outreach](/ja/tools/outreach/) と [Salesloft](/ja/tools/salesloft/) は依然としてエンタープライズ販売エンゲージメントの二大既存勢力ですが、もはや同じ種類の会社ではありません。Salesloft は forecasting と実行を組み合わせた統合ベンダーの片側です。Outreach は2026年をエージェント中心の製品面の再構築と、それに合わせた価格再設計に費やしました。かつてこの2社を決めていた2つの事実 —— Salesloft のチャットバンドルと「どちらも金を払う価値のあるエージェントアクセスを持たない」 —— はどちらも失効しています。今、実際に両者を分けているものはこれです。

## 2025年から変わったこと

Clari は Vista Equity Partners から Salesloft を買収し、2025年12月3日にクローズしました。統合後の会社は **Clari + Salesloft** として事業を行い、5,000社以上の顧客に対して ARR 約4億5,000万ドルを報告していますが、2026年8月時点で新社名はまだ発表されていません。統合は一度の再パッケージではなくリリース単位で進んでいます。2026年6月のリリースでは Clari Copilot が単一ログインで Salesloft の内側に入り、録画、文字起こし、AI サマリー、action item が別製品ではなく Salesloft の Activity Feed と Deal Summary Agent に流れ込むようになりました。既存の Conversations 顧客の移行は後になります。別途、Clari + Salesloft は2026年3月に Drift の段階的な sunset を発表し、[1mind](/ja/tools/1mind/) を独占的な後継として指名しました。つまりプラットフォームの Chat Agents は 1mind の製品であり、Salesloft が作っているものではありません。

Outreach は outreach.io から outreach.ai に移り、2026年4月27日に「レベニューチームのためのエージェント型 AI プラットフォーム」として再ローンチしました。新しい製品面は Outreach Omni（Slack とモバイル上の会話型エージェント）、Agent Studio（RevOps がビジュアルキャンバス上で独自のエージェントを構築・スケジュールする場所）、そして名前のついたエージェント群です。Meeting Prep Agent、担当者の承認用に CRM フィールド更新を下書きする Deal Agent、AI Topics Explorer、Kaia のコーチングエージェント。パッケージも一緒に動きました。Amplify のティアはシートの上に AI クレジットを積んで計測します。

両社は4か月差で MCP を出荷し、どちらもアクセスを制限しています。Outreach の MCP サーバーは2026年2月24日に一般提供となり、サーバーとしてもクライアントとしても動作します。外部エージェントが Outreach のコンテキストを読み、Outreach 側から外部を呼び出せます。アクセスには Amplify アドオンを有効化した有効なライセンスシートが必要です。Salesloft のものは2026年4月に出て、6月リリースの時点で Claude のコネクタディレクトリにネイティブ掲載され、2026年8月のリリースで ChatGPT 向け MCP サーバーを追加しました。こちらは Salesloft Agentic アドオンが必要です。

## Salesloft が優れている点

- **forecasting が同じ契約で手に入る。** Clari はこのカテゴリで最も広く導入されている forecasting とディール検査の製品です。2025年のショートリストが2枚の発注書に分かれた Outreach と Clari だったなら、今は1枚で両方の仕事をカバーできます。Outreach の Forecast モジュールは存在しますが、CRO が Clari と比較する対象ではありません。
- **MCP の「有無」ではなく「範囲」。** Salesloft のサーバーは、カデンスとアクティビティの実行データ、Clari Copilot のコールインテリジェンス、forecast とディール検査のデータを1つのコネクタで、書き戻し付きで公開します。Outreach のサーバーが公開するのはエンゲージメントのコンテキストです。実在し、スタックの他のどこにも存在しないデータですが、1層です。「アナリストが Claude からレベニューデータを問い合わせる」という計画なら、今日その問いにより多く答えるのは Salesloft です。
- **最小シート数、これが実際の分岐点。** Salesloft のコミットは通常10〜15シートから始まり、Outreach は25〜50です。20人の担当者のチームにとってこれは好みの問題ではなく、買えるのが2つのうち1つだけという話です。
- **オンボーディングの速さ。** カデンス中心の設計はより意見が強く、担当者の立ち上がりが速いです。ノブが少なく、デフォルトの経路が明確 —— 非常に大きな規模では天井になるのと同じ性質です。

## Outreach が優れている点

- **担当者200人以上での設定柔軟性。** より細かい権限の粒度、エッジケースでのより深い Salesforce の扱い（カスタムオブジェクト、Apex 駆動のバリデーション、監査証跡のマッピング）、そしてテリトリー再編を生き延びる管理モデル。これは積み上がったエッジケースであり、1四半期で出荷できる機能ではありません。
- **自分でエージェントを作れる。** Agent Studio は RevOps が独自のエージェントを組み立ててスケジュールするキャンバスです。Salesloft が持つのは固定の顔ぶれ —— Account Research、Person Research、Ask Salesloft、Deal Summaries、MEDDPICC 抽出、Sales Strategist —— に優先順位付けレイヤーの Rhythm が加わったもので、同等のビルダーはありません。AI の計画にベンダーが想定していない手順が含まれるなら、この差は効きます。
- **Outreach は MCP クライアントでもある。** そのエージェントは Salesforce Agentforce、Microsoft Copilot、SharePoint、Google Drive、Glean へ外向きに手を伸ばせます。Salesloft のサーバーは Salesloft の内側を読み書きします。一方向に対して双方向です。
- **統合後の再パッケージリスクがない。** Salesloft のエンタイトルメントは契約期間の途中で組み替えられており、確定した SKU の地図も社名もありません。Outreach のロードマップは比べれば退屈ですが、退屈さには値段があり、それを払わない代わりに再交渉で払うことになります。

## 反転した論点

このページの2025年版は、Salesloft が Drift をバンドルするので会話インテリジェンスが含まれ、Outreach と [Gong](/ja/tools/gong/) の組み合わせはシートあたり50〜80ドル高いと書いていました。これは再利用しないでください。Drift は sunset に入り、その領域は 1mind が持ち、ウェブサイトのコンバージョンは今や独自の解約経路を持つ別契約です。Salesloft のバンドル論はいま forecasting を通ります。

セキュリティ侵害も同じ段落に属します。この2社で買い手側の非対称性はここだけだからです。2025年8月8日から18日にかけて、UNC6395 として追跡される攻撃クラスタが Drift の OAuth トークンを盗み、それを使って数百の組織から Salesforce のデータ —— アカウント、コンタクト、商談、ケース —— を抜き出しました。Google は潜在的な影響範囲を700社以上と見ています。Salesloft は Drift をオフラインにし、トークンを失効させました。ガード：Salesforce 連携を必要最小限のオブジェクト集合に絞り、署名前に最新の SOC 2 レポートと文書化されたポストモーテムを要求し、OAuth のローテーション計画はベンダーのものを引き継がず自分で持ってください。

## 価格、数字で

どちらも見積もり制で、隠している量が違います。Outreach は料率なしで構造を公開しています。AI クレジットの配分による4つの Amplify ティア —— Essentials が10,000クレジット、Core が25,000、Plus が50,000、Pro が100,000 —— で、シート単位の価格に消費を足すモデル、platform fee なしと明記されています。Salesloft の価格ページは見出しと問い合わせフォームだけです。3つのエディション（Essentials、Advanced、Premier）は存在しますが、それについて公開されているものは何もありません。

50シートの導入では、Outreach は Engage のみで年間約72,000ドル、Meet、Deal、Forecast、Amplify クレジットまで載せた構成は初年度で150,000〜165,000ドルを超え、その手前に導入費が5,000〜25,000ドルかかります。Salesloft の調達実績はもっと低いところを走ります。Vendr の703件の購買における年間契約額の中央値は約30,700ドル、平均割引率18%、レンジは5,200〜145,000ドル。交渉後のシート単価は25〜75ユーザーでおよそ90〜130ドル、ダイアラーはユーザーあたり年間300〜400ドル、Conversation Intelligence はベースに20〜40%を乗せます。

エディションを揃えると、Salesloft はシートあたり Outreach の約10〜25%下に着地し、25シートを下回ると比較はパーセントの話ではなくなります。Outreach にはそこに入口がないからです。両社ともエージェント層と MCP アクセスは別見積もりのアドオンの後ろにあります。まずベースエディションを値付けし、そのアドオンを独立した明細として交渉してください。AI はどちらの platform fee にも入っていません。

## 結論

- **Salesloft を選ぶ**のは、担当者が100人未満の場合、forecasting がショートリストのどこかにある場合、または次のロードマップではなく今四半期に Claude と ChatGPT からレベニューデータに到達したい場合です。
- **Outreach を選ぶ**のは、権限モデルと監査証跡が重みを持つ200人超の規模で運用している場合、AI の計画が有効化するエージェントではなく自分で構築するエージェントを必要とする場合、または統合途中のベンダーを購買部門が承認しない場合です。
- **本当に決められないなら、Salesloft を買ってください。** この2社を比較する中位のチームは担当者25〜100人で、その規模で決め手になる4点のうち3点 —— 最小シート数、シート単価、1契約での forecasting —— が同じ方向を指します。Outreach の優位は本物ですが、200人を超えたところに集中しています。
- **どちらも合わない**のは、担当者が25人未満でコンタクトデータベース付きのシーケンサーが必要だった場合で、それは [Apollo](/ja/tools/apollo/) の話であり [Apollo vs Salesloft](/ja/vs/apollo-vs-salesloft/) と [Apollo vs Outreach](/ja/vs/apollo-vs-outreach/) で扱っています。あるいは担当者の代わりにソフトウェアにアウトバウンドを走らせたい場合で、それは [11x](/ja/tools/11x/) か [RegieOne](/ja/tools/regie-ai/) にあたり、シート単価で比較すべきではない別種の買い物です。

このページが防ぐために存在する間違いは、2025年の評価をもう一度やり直すことです。両者の機能差は依然として小さいままですが、同点を破っていた2つの事実 —— チャットのバンドルとエージェントアクセスの不在 —— はどちらも置き換わりました。今の正しい決め手は、forecasting の範囲、最小シート数、そして MCP 接続のどちら側に立つ必要があるかです。
