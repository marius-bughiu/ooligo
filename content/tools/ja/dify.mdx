## 概要

Dify は LLM アプリケーションを構築するためのプラットフォームです。チャットボット、自社ドキュメントを対象にした検索（RAG）アシスタント、多段の AI ワークフロー、そして 2026 年 7 月以降は自律型エージェントを作れます。ビジュアルキャンバス上で構築し、任意のモデルプロバイダー（OpenAI、Anthropic、Gemini、Ollama や vLLM 経由のオープンウェイトモデル）を接続して、成果物を Web アプリ、埋め込み型チャットウィジェット、REST API、または MCP サーバーとして公開できます。ナレッジベース、プロンプトのバージョン、実行ログ、アノテーションによる回答修正はすべて同じワークスペース内で管理されます。

開発元は LangGenius で、2023 年に創業し、本社は Menlo Park にあります。2026 年 3 月 9 日、同社は HSG 主導で $30M のシリーズ Pre-A を評価額 $180M で調達したと発表し、商用エディションを 280 社を超える企業が利用していること、その中に Maersk と Novartis が含まれることを明らかにしました。GitHub リポジトリのスター数は 158,000 を超えています。リリースはおおむね 2〜4 週間ごとです。現行バージョンの 1.17.1 は 2026 年 9 月 10 日に公開されました。その前の 1.16 では、組み込みサンドボックスとスキルシステムを備えた新しい Agent App がオープンベータになっています。

ライセンスは Apache 2.0 に 2 つの条件を上乗せした「オープンソース」です。書面による許可なしにコードをマルチテナントサービスとして運用すること（1 テナント = 1 ワークスペース）はできず、コンソールや Web アプリから Dify のロゴや著作権表示を削除することもできません。自社製品のバックエンドとしての利用を含め、社内利用は認められています。

## オペレーション系スタックに入る理由

- **RAG は追加機能ではなく中核です。** 契約書、ポリシー、プレイブック、職務記述書のライブラリをアップロードし、チャンク分割の戦略と埋め込みモデルを選ぶと、どのアプリやワークフローノードからでも参照できるナレッジベースができあがります。ヒットテストでどのチャンクが返ってきたかも確認できます。ポリシー Q&A ボットを作る Legal Ops チームや、価格ルールに基づいてディールデスク用アシスタントを動かす RevOps チームにとって、構築作業の大半はこれで済みます。
- **MCP は双方向に使えます。** どの Dify アプリも Access Point タブから MCP サーバーとして公開できるため、[Claude](/ja/tools/claude/) Desktop や [Cursor](/ja/tools/cursor/) からツールとして呼び出せます。Dify 側も HTTP トランスポート経由で外部の MCP サーバーを利用し、そのツールをエージェントやワークフローノードに渡せます。バージョン 1.16 で 2025-06-18 版の MCP 仕様に対応しました。
- **ノードごとにモデルを選べます。** 1 つのワークフローの中で、分類は安価なモデルに、文章作成はフロンティアモデルに振り分けられます。トークン単位で課金される以上、これは重要です。

## 価格の実態

dify.ai/pricing より（2026-10-11 確認）。クラウドプランはシート単位ではなくワークスペース単位の価格です。

- **Sandbox — 無料。** メッセージクレジットは合計 200（月ごとではありません）、メンバー 1 人、アプリ 5 個、ナレッジドキュメント 50 件、ログ保持 30 日。
- **Professional — $59/月**、または年 $590（月あたり約 $49）。月 5,000 メッセージクレジット、メンバー 3 人、アプリ 50 個、ドキュメント 500 件、ナレッジストレージ 5GB。
- **Team — $159/月**、または年 $1,590。月 10,000 クレジット、メンバー 50 人、アプリ 200 個、ドキュメント 1,000 件、20GB。
- **Community Edition — 無料、セルフホスト。** コア機能をすべて備え、ワークスペースは 1 つ。ドキュメント上の最小要件は CPU 2 コア、RAM 4 GiB です。
- **Enterprise — 個別見積もり。** 複数ワークスペース、SSO、商用ライセンス、サポート。公開価格はなく、信頼できる第三者の価格データも見つからなかったため、営業との商談事項と考えてください。

メッセージクレジットで支払えるのは Dify がホストするモデルの利用分だけで、フロンティアモデルではすぐに消費されます。価格ページによれば、1 回の応答あたり Claude Opus 4.7 は 20 クレジット、GPT-5 は 5 クレジット、Gemini 2.5 Flash は 1 クレジットです。つまり Professional の 5,000 クレジットは Opus の応答約 250 回分にすぎません。クレジットは追加購入できません。使い切ったら自社の API キーに切り替え、プロバイダーに直接支払うことになります。実際には、本格的な導入はどれも年 $590–1,590 のプラットフォーム料金に別建てのモデル利用料が加わる形に落ち着きます。1 部門にとって現実的な上限は Team プランです。メンバー 50 人で年 $1,590 は、シート課金のどのエージェントプラットフォームよりもはるかに安価です。

## 最適な利用者

- **最適な利用者：** 従業員 50〜1,000 人の企業で、チーム自身のドキュメントに基づき、IT ではなくチームが所有する社内 AI アプリ（ポリシー Q&A ボット、契約条項の抽出ツール、候補者スクリーニングのアシスタントなど）を 2〜3 個リリースする必要があるオペレーションエンジニアや技術系アナリスト。
- ドキュメントを自社インフラ内に置かなければならない Legal Ops・Recruiting チーム。Community Edition は小型の VM 1 台で動きます。
- **向いていないのは、** 本来の業務が SaaS アプリ間でレコードを定期的に移すことであるチームです。Dify にもトリガーや HTTP ノードはありますが、専用の自動化エンジンと比べるとコネクターのカタログは貧弱です。

## 代替ツールとの比較

- **[n8n](/ja/tools/n8n/)：** 技術系の自動化でシェア首位。1,000 以上のインテグレーションを持ち、実行単位の課金で €20/月から。間に AI ステップを挟んだ CRM → エンリッチメント → Slack という配管作業が中心なら n8n を選んでください。検索の品質、プロンプトの反復改善、チャットのフロントエンドといった AI アプリそのものが中心なら Dify です。n8n から Dify の API を呼び出す形で両方を運用しているチームも多くあります。
- **Microsoft Copilot Studio：** もう 1 つのシェア首位で、25,000 クレジットのパックが月 $200。会社が Microsoft 365 で動いており、IT がそのテナントのガバナンス内でエージェントを管理したい場合に選んでください。
- **[Gumloop](/ja/tools/gumloop/)：** 最も急成長している AI ネイティブのビルダーで、Pro はシート数無制限で $37/月。チームの誰もモデルプロバイダーの設定に触れたがらない場合に選んでください。セルフホストや、チャンク分割と検索の制御が必要なら Dify です。
- **[Sim](/ja/tools/sim/)：** より新しいオープンソースの競合で、Pro は 1 ユーザーあたり月 $25。完全にオープンでエージェント中心のキャンバスを好み、エコシステムが小さいことを許容できるなら選んでください。
- **[Relevance AI](/ja/tools/relevance-ai/)：** 目的がカスタムアプリではなく、自社の GTM ツールの中で働く営業エージェントのチームである場合に選んでください。
- **[Dust](/ja/tools/dust/) または [Langdock](/ja/tools/langdock/)：** 求めているものが、ビルダーが他の人向けに公開するアプリではなく、エージェント付きの全社向けチャットシートである場合に選んでください。
- Flowise（現在は Workday 傘下）と Langflow（DataStax 経由で現在は IBM 傘下）も、オープンソースのキャンバスです。どちらも今では大手ベンダーの一部になっているため、独立性を重視するならその点を考慮する価値があります。

## 注意点

- **ライセンスは素の Apache 2.0 ではありません。** Dify をマルチテナントサービスとして運用する場合や、フロントエンドをホワイトラベル化する場合は商用ライセンスが必要です。**対策：** クライアントごとにワークスペースを割り当てる計画や、Dify の画面を自社ブランドで提供する計画があるなら、構築前に LangGenius から書面で条件を取得してください。自社の UI の裏側で API だけを使うのであれば、フロントエンドに関する条項は適用されません。
- **フロンティアモデルではクレジットがすぐに尽きます。** Opus の応答 1 回で 20 クレジットなので、利用の多い社内ボットなら数日で Professional のクレジットを使い切ります。**対策：** 初日から自社のプロバイダーキーを追加し、各プロバイダーの Usage Priority でそれを最優先に設定してください。こうすればクレジットはあくまでフォールバックとなり、モデルの利用料は自社で管理する請求書に計上されます。
- **アップグレードでセルフホスト環境が壊れます。** 1.17.1 のリリースノートでは同梱の Weaviate ストアについて段階的なアップグレードが求められており、1.16.1 では新たな環境変数が必須になりました。**対策：** バージョンを固定し、アップグレードのたびにリリースノートを読み、本番に手を付ける前にデータボリュームのステージング用コピーでテストしてください。
- **Agent App はまだベータです。** **対策：** Agent がベータを抜けるまでは、成熟したアプリタイプである Workflow アプリと Chatflow アプリで本番のユースケースを運用してください。
