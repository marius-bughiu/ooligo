## 概要

Dynamics 365 Sales は Microsoft の営業向け CRM です。アカウント、取引先担当者、リード、商談、フォーキャスト、シーケンスを Dataverse に保存します。Dataverse は Power Apps、Power Automate、Copilot Studio の土台でもある同じデータプラットフォームです。この共有プラットフォームこそが Dynamics を選ぶ理由のすべてです。自社がすでに Entra ID、Outlook、Teams、SharePoint を運用しているなら、Dynamics はレコード、権限、監査証跡がセキュリティチームの管理下にある既存テナントの中に収まる CRM です。[Salesforce](/ja/tools/salesforce/) に対する主要なエンタープライズ向けの代替であり、Microsoft のエンタープライズ契約の更新時期に調達部門が提示してくるのもこの製品です。

## Sales Agent をどう評価するか

AI をめぐる状況は 2026-07-07 に変わりました。この日 Microsoft は、Sales Agent(旧 Copilot for Sales)と Service Agent を Microsoft 365 Copilot、Outlook、Teams、Dynamics 365 全体で一般提供しました。Sales Agent は Outlook でメールスレッドを要約して返信を下書きし、Teams の営業ミーティングを録音してアクションアイテム付きで要約し、Copilot チャットで「summarize account Fabrikam」のような質問に CRM レコードに基づいて回答します。

実用に足るのか。答えは Yes ですが、購入者が見落としがちな条件が2つあります。1つ目は、Dynamics のシートに加えて、営業担当者全員に Microsoft 365 Copilot ライセンスが必要なことです。エンタープライズプランで $30/ユーザー/月です。Sales Enterprise と Premium のユーザーには自動でインストールされますが、この2つ目のライセンスがなければ誰も回答を得られません。2つ目は、Sales Agent が読み取れるテーブルを CRM 管理者が設定し、アカウント、商談、リードの要約を構成する必要があることです。初期状態では「CRM Knowledge hasn't been set up」と表示されます。スイッチを入れるだけではなく、設定作業を計画に入れてください。また US GCC、GCC High、DoD などのソブリンクラウドでは動作しないため、公共部門向けの多くの営業組織では選択肢から外れます。

比較の計算を変える細部が1つあります。Sales Agent は Salesforce Sales Cloud(Professional 以上)にも接続できます。Dynamics に移行する理由が「Outlook での Copilot 体験」なら、CRM を移行しなくてもその大部分は手に入ります。

## エージェントと MCP のレイヤー

Microsoft は Dynamics 365 Sales MCP サーバーを公開しており、`get_opportunity_health`、`get_opportunity_top_risks`、`get_lead_qualification_assessment`、`draft_outreach_email` などのツールを備えています。加えて Dataverse MCP サーバー経由で Dataverse レコードに対する CRUD 操作もできます。[Claude](/ja/tools/claude/) を含む外部エージェントから呼び出せます。AI のツール呼び出しは、ユーザーが Sales Premium または Microsoft 365 Copilot ライセンスを持っていない限り Copilot Credits を消費します。25,000 クレジットのパックは定価で $200/月です。同じデータ上でカスタムの営業エージェントを構築するなら、使うツールは [Microsoft Copilot Studio](/ja/tools/microsoft-copilot-studio/) です。

Microsoft は年2回のリリースウェーブも廃止しました。2026年9月以降、新機能はロードマップに継続的に公開され、Release Planner は 2026-11-15 に廃止されます。管理者の変更レビューのサイクルは、年2回の日付から毎週の定例確認に切り替える必要があります。

## 価格

ユーザーあたり月額、年間契約。Microsoft の価格ページで 2026-10-04 に確認しました。

- **Sales Professional** — $65。コアのセールスフォースオートメーション、Microsoft 365 連携、ダッシュボード。
- **Sales Enterprise** — $105。カスタマイズ、フォーキャスト、Dynamics 365 の Copilot。現実的なベースラインです。
- **Sales Premium** — $150。Sales Insights と、ユーザーあたり月 1,000 Copilot Credits が加わります。
- **Microsoft Relationship Sales** — 見積もりのみ。Sales Enterprise と LinkedIn Sales Navigator のバンドルで、最低10シートです。

すべてのプランに、既製の Sales Qualification、Opportunity、Research、Close の各エージェントへのアクセスが含まれます。

定価ベースでは、Sales Enterprise は Salesforce Enterprise の60%のコストです($105 対 $175)。Sales Agent に必要な $30 の Microsoft 365 Copilot シートを加えると差は縮まり(合計 $135)、Premium も必要になれば差はなくなります。

実勢レンジ: 導入、データ移行、トレーニングによって1年目はライセンス費の2〜5倍に膨らみ、2年目以降はおよそ1.3倍に落ち着きます(Costbench 2026 TCO guide)。パートナーの導入見積もりは通常ユーザーあたり $500〜2,000 です。Sales Enterprise の100シート組織は定価で年間 $126K、1年目の実額は $250〜630K に着地します。ストレージは誰も予算に入れないコスト項目です。テナントのデフォルトを超えるデータベース容量は、定価で 1 GB あたり月額約 $40 かかります。

## 最適な対象

Microsoft 365 で標準化している中堅・大企業の RevOps および営業オペレーションのリーダー。CRM を Entra ID のガバナンス下に置く必要があり、営業担当者が Outlook と Teams で仕事をしていて、IT 部門がすでに Power Platform のスキルを持っている組織です。

## 注意点

- **Dataverse ストレージの超過。** メールと添付ファイルの同期、監査ログ、活動履歴は、シート数の伸びから想定されるよりも速くデータベース容量を埋めます。ガード: 初日から添付ファイルを SharePoint に振り向け、本番稼働前に監査ログの保持ポリシーを設定し、Power Platform 管理センターの容量レポートを毎月確認してください。
- **パートナー依存の導入。** ほとんどの導入は Microsoft パートナー経由で行われ、パートナーの品質のばらつきは製品のばらつきより大きくなります。ガード: 担当ソリューションアーキテクトを指名したうえで、スコープを固定したフェーズ1(アカウント、取引先担当者、商談、フォーキャスト)を要求し、営業担当者がコア機能を使いこなすまではカスタムプラグインのコードをスコープ外にしてください。
- **AI ライセンスが知らないうちに積み上がる。** Dynamics のシート、Microsoft 365 Copilot のシート、エージェントと MCP 呼び出しのための Copilot Credits。ガード: 更新前に営業担当者1人あたりの AI コスト項目を作り、全員にライセンスを付与する前に1チームで1四半期 Sales Agent を試験運用してください。

## 代替ツールとの比較

[Salesforce](/ja/tools/salesforce/) は市場シェアのトップです。自社のエコシステム(Outreach、Clay、Gong、ZoomInfo)が Salesforce 優先で構成されていて、最も厚いサードパーティ連携カタログが必要なら選んでください。[HubSpot](/ja/tools/hubspot/) はもう一方のトップ2 CRM です。ARR がおおむね 25M ドル未満の場合や、マーケティングと営業が1つのプラットフォームを共有し、管理作業を開発者ではなくオペレーションチームで回したい場合に選んでください。[Attio](/ja/tools/attio/) は最も急成長している新興勢力です。AI ネイティブなデータモデルを求め、エンタープライズのガバナンスよりもスピードを優先する、おおむね50人未満のチームに向いています。全体のランキングは [2026年のベスト CRM](/ja/comparisons/best-crms-2026/) にあります。
