## 何をするツールか

Zowie は、チャット、メール、音声に対応したエンタープライズ向けの AI カスタマーサービスエージェントです。返金、荷物の転送、サブスクリプションの変更、カードの停止など、チケットが何らかのアクションで終わる企業向けに作られています。[Ada](/ja/tools/ada/)、[Decagon](/ja/tools/decagon/)、[Sierra](/ja/tools/sierra/) と同じカテゴリですが、売りはアーキテクチャです。会話は言語モデルが担い、業務ロジックは独立した Decision Engine が実行します。Zowie の説明では、LLM が意図を抽出し、決定論的エンジンがルール（返金の可否、返品期限、本人確認）を適用し、LLM が結果を文章にします。返金を認めるかどうかをモデルが判断することはありません。

現在の製品は複数のモジュールで構成されています。Agent Studio（Knowledge、Flows、Playbooks、そして REST、A2A、SDK で他のエージェントを接続する Agent Connect）、Orchestrator、有人対応への引き継ぎ用の Inbox、QA と CSAT 用の Supervisor、Tester、Traces、そしてどのルールを誰が変更したかを記録する Audit Log（2026-05-12 リリース）です。チャネルはチャット、メール、音声、そしてサイトのナビゲーションを置き換える音声・テキストのレイヤー Hello です。2026-09-15 には リモート MCP サーバー（EU と米国のエンドポイント、OAuth ログイン、変更はデフォルトで staging に反映）を公開し、CX オペレーション担当者が Claude や ChatGPT からエージェントを確認・変更できるようになりました。2026-11-09 には Web、iOS、Android、React Native、Flutter 向けの Conversation SDK も追加されています。

Zowie は 2019 年にポーランドで Maja Schaefer（CEO）と Maciej Ciołek が創業しました。2022 年 1 月に Gradient Ventures と 10xFounders がリードする $5M のシードラウンドを調達し、2022 年 5 月に $14M のシリーズ A を発表しています。年間約 1 億件の会話を処理していると公表し、顧客として InPost、Decathlon、Allianz、Total Wine、KRUK、Empik を挙げています。独立系企業で、2026-11-26 時点で買収や事業終了の報道は見つかりませんでした。

## Customer Success スタックに登場する理由

- **証明できるポリシー運用。** 返金や適格性のルールがプロンプトではなくルールエンジンで動くため、同じ入力には常に同じ判断が返ります。Allianz や KRUK のような規制業種の顧客に合い、エージェントが「60 日間返品可能」のような条件を勝手に作ることもありません。
- **デモではなく本番稼働の音声。** InPost は Zowie の音声エージェントをポーランド、英国、フランスで運用しています。音声設定は 2026 年 5 月に UI へ移り、10 月には音声プロファイルが追加されました。
- **監査証跡と変更管理。** Audit Log、Tester、デフォルトで staging に入る MCP 経由の編集により、コンプライアンス部門は誰がいつどのルールを変えたかを記録として残せます。ミッドマーケット向けエージェントの多くにはまだない機能です。
- **モデルを選べる。** Zowie は Anthropic、OpenAI、Google、Meta、Mistral のモデルと、音声向けに ElevenLabs、Cartesia、Deepgram、Azure Speech を挙げています。サイトには SOC 2、GDPR、HIPAA、DORA のバッジが掲載され、顧客自身のクラウド内での導入にも対応しています。

## 料金

Zowie は料金表を公開しておらず、料金ページはデモ申込フォームです。唯一の公開価格は AWS Marketplace の掲載で、**12 か月 $34,500、自動化された会話 25,000 件込み**、つまり **自動化会話 1 件あたり約 $1.38** です。24 か月契約で最大 3%、36 か月契約で最大 6% の割引があります。課金単位は「解決」ではなく「自動化された会話」なので、エージェントが対応したあとエスカレーションした会話もカウントされる可能性があります。定義は書面で確認してください。

現実的な下限は年 $34,500 と考えてください。年 25,000 会話（月約 2,100 件）の場合、Intercom の Fin は 1 解決あたり約 $0.99 なので全件解決しても約 $24,750、実際にはそれより少なくなります。Zendesk の AI エージェントはコミット済み解決 1 件 $1.50 で約 $37,500 です。この下限を超える規模では、Zowie はエンタープライズ向けエージェントよりかなり安くなります。Ada の報告ベースの中央値は年約 $73,500、Decagon は約 $50,000 のプラットフォーム料金から始まり、Sierra の契約は通常 $150K から $350K 超です。標準エージェントに対する Zowie の上乗せ分が回収できるのは、返金、転送、解約など標準エージェントでは自動化できないアクションを Decision Engine が自動化できる場合に限られます。

## こんなチームに最適

EC、物流、フィンテック、保険の CX またはサポートオペレーション責任者で、自動化可能な会話が月 2,000〜50,000 件程度あり、問い合わせの大半が文書化されたポリシーに基づく取引で終わり、誤った回答が金銭的損失や規制リスクにつながるチームです。月 1,500 件未満のチーム、ヘルプデスク標準のエージェントで足りる単純な FAQ 対応、ポリシー実行よりも技術ドキュメントの推論が必要な B2B ソフトウェアのサポートには向きません。

## 注意点

- **ルールは動かす前に書く必要がある。** 決定論的エンジンは Flows と Playbooks でモデル化したものしか実行しないため、最初の数か月はポリシー文書や例外ケースをロジックに落とし込む作業になります。対策：問い合わせ量の多い上位 3 つの意図だけで開始し、各 Flow を staging で Tester を使ってポリシー責任者に承認してもらい、エスカレーション率が 2 週間安定してから意図を 1 つずつ追加してください。
- **季節変動で固定パッケージが足りなくなる。** 平均的な月を基準にしたパッケージは、繁忙期に件数が急増すると早期に使い切ってしまいます。第三者が引用するレビューでも、季節性に応じてコストが上がると指摘されています。対策：ピーク四半期を基準にパッケージを設計し、Billing ページで使用率 75% のアラートを設定し、超過分の会話単価を契約に明記してください。
- **連携の深さにばらつきがある。** Zowie 自身のページで確認できるネイティブ連携は Shopify、Zendesk、Gladly、Dixa などで、それ以外は Agent Connect か個別の API 開発が必要です。対策：エージェントが書き込む必要のあるシステム（OMS、決済、配送業者）をすべて洗い出し、契約前にそれぞれで書き込みアクションが staging で動くデモを確認してください。
- **公開レビューが少ない。** G2 の評価は 73 件で 4.7/5 です。古いレビューでは翻訳品質のばらつきやベンダーサポートの遅さが指摘されています。対策：パイロット期間中に英語以外のキューを検証し、担当者名と応答時間を明記したサポート窓口を契約に盛り込んでください。

## 代替ツールと選ぶべき場面

[Zendesk](/ja/tools/zendesk/) と [Intercom](/ja/tools/intercom/) の Fin は市場シェアが最も大きく、解決件数課金の標準エージェントを提供しています（約 $1.50 と $0.99）。すでにどちらかのヘルプデスクを使っていて、問い合わせの大半が情報提供型なら、まず標準エージェントを選んでください。[Decagon](/ja/tools/decagon/) は最も急成長しているエンタープライズ向けの新興勢力です。大規模なソフトウェアやフィンテックのサポートで、モデル化したルールよりも自然言語で書く手順のほうがチームに合う場合に選んでください。予算が $150K を超え、成果ベースの課金を重視するなら [Sierra](/ja/tools/sierra/) を選んでください。件数が非常に多く増え続けていて、大規模では会話単価の課金が有利になるなら [Ada](/ja/tools/ada/) を選んでください。Gorgias を使う Shopify ブランドには、[Siena AI](/ja/tools/siena-ai/) や [Yuma AI](/ja/tools/yuma-ai/) がより安く、設定も軽いオーバーレイです。件数が少なくどれも合わない場合は、キューが年 $34,500 の下限に見合う規模になるまで、マクロ、セルフサービスの注文状況ページ、返品ポータルで運用を続けてください。
