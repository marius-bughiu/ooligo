## 概要

Reo.Dev は、エンジニア向けに製品を売る企業のために、開発者の行動をアカウント単位の営業シグナルに変換するツールです。誰かがフォームに記入するより前に、開発者がツールを評価している場所を監視します。GitHub の star、fork、issue、pull request。npm、pip、Docker、Maven をはじめとする 40 以上のパッケージマネージャー。ドキュメントの閲覧とコピーされたコードスニペット。self-hosted デプロイからのオープンソーステレメトリ。GitHub や Gmail による匿名のサインアップ。そして Reddit、Stack Exchange、Hacker News、Slack や Discord のコミュニティでの言及です。これらの行動を開発者とその所属企業にひも付け、アカウントをスコアリングし、CRM、Slack、または MCP クライアントへ送ります。

最新のデータソースは **Agent Intent** です。コーディングエージェントがあなたのドキュメントを読んだり MCP サーバーを呼び出したりすると、Reo.Dev はそのやり取りを購買シグナルとして記録し、背後にいるアカウントを示します。devtool の評価は、ブラウザを操作する人間ではなくエージェント経由で行われる割合が増えています。つまり、多くの競合がまだ捉えていないシグナルです。

同社はベンチャーキャピタルの出資を受けて成長中です。2026 年 7 月に Elevation Capital がリードする $11.3M のシリーズ A を調達し、Heavybit、India Quotient、Foster Ventures も追加出資しました。累計調達額は $15.3M です。サイトでは 200 社以上の devtool 企業が利用しているとしており、NVIDIA、LangChain、n8n、ElevenLabs、Temporal、ClickHouse などのロゴが並びます。

## RevOps スタックに入る理由

- **CRM には見えないシグナルを拾います。** 開発者は営業と話すずっと前に、インストールし、star を付け、self-hosting を始めます。Reo.Dev はこうしたイベントをアカウントにひも付けるので、AE は先週あなたの Docker イメージを 400 回 pull したプラットフォームチームの企業に電話できます。
- **パッケージとテレメトリの深さ。** 汎用的なインテントベンダーが読むのは、Web サイト訪問とサードパーティのコンテンツ閲覧です。Reo.Dev はパッケージのインストールと OSS テレメトリを読みます。開発者の評価が実際に行われているのはそこです。
- **MCP と API。** Reo MCP はアカウントデータを Claude Desktop（5 つのスキルを同梱）、ChatGPT の開発者モード、Cursor に接続します。データ出力 API とプロダクト利用 API はドキュメント化されているため、UI を介さずに [Clay](/ja/tools/clay/) のテーブルやデータウェアハウスへシグナルを流せます。
- **営業スタックへのルーティング。** ドキュメントは [Salesforce](/ja/tools/salesforce/)、[HubSpot](/ja/tools/hubspot/)、[Attio](/ja/tools/attio/)、[Outreach](/ja/tools/outreach/)、[Salesloft](/ja/tools/salesloft/)、[Apollo](/ja/tools/apollo/)、Gong のフロー、[Slack](/ja/tools/slack/) アラート、Webhook をカバーし、Web サイト訪問者の特定には [RB2B](/ja/tools/rb2b/) を使います。

## 実際の価格

Reo.Dev は料金ページを公開しておらず、/pricing の URL は 404 を返します。公開情報として最も確かな目安は AWS Marketplace の掲載情報で、2026-11-23 時点で 12 か月契約が 3 つ表示されています。

- **Startup**：年 $12,000。2 シート、監視対象のコンタクト/アカウント 5,000
- **Pro**：年 $30,000。10 シート、コンタクト/アカウント 25,000
- **Business**：年 $50,000。20 シート、コンタクト/アカウント 50,000

「コンタクト」は開発者個人のプロフィール、「アカウント」はその所属企業を指し、シート数は監視ボリュームと連動します。監視アカウントだけを増やすことはできず、上位プランへの移行が必要です。ベンダー側が契約または SLA に違反しない限り返金はありません。トップページには「Try for Free」のサインアップがありますが、無料プランは公開されていません。G2 では 73 件のレビューで 4.9 の評価で、よく挙がる不満は価格と、月額契約やスタートアップ向けプランがないことです。

月額に直すと、およそ $1,000、$2,500、$4,200 です。Essential プランが年 $30,000 の [Common Room](/ja/tools/common-room/) と比べると、Reo.Dev の Startup プランはその 40% の価格で、Pro プランは Common Room と同価格で 2 倍のシートが付きます。

## 最適な利用者

シードから ARR 約 $50M までのオープンソース企業や開発者向けツール企業で、製品がパッケージマネージャー、コンテナ、CLI 経由でインストールされ、どの企業が無料版を動かしているかを AE が把握する必要がある RevOps・グロースのリーダーです。具体的なユースケースは、「従業員 2,000 人の銀行のプラットフォームチームが当社の Helm chart を pull した」という事実を、1 日以内に担当者名付きでルーティングされたアカウントに変えることです。

**向いていないケース：** 購買者が開発者でない場合です。営業ツール、金融プロダクト、人事プラットフォームではパッケージやリポジトリのシグナルがほとんど発生せず、使わないカバレッジにお金を払うことになります。匿名での self-hosting をコミュニティに約束している場合も向いていません。2 つ目の注意点を参照してください。

## 代替ツールと選ぶべき場面

- **[Common Room](/ja/tools/common-room/)**：既存の定番シグナルプラットフォームで、年 $30,000 から。コミュニティ、ソーシャル、転職のシグナルが開発者の行動と同じくらい重要で、devtool 以外にも販売している場合に選びます。
- **[Clay](/ja/tools/clay/)**：シグナル・エンリッチメント分野で最も急成長している新興ツールで、月 $185 から。独自のシグナルテーブルを組める GTM エンジニアがいる場合に選びます。パッケージマネージャーやテレメトリの独自ソースは持たないため、通常は Reo.Dev のようなフィードの下流に置かれます。
- **[RB2B](/ja/tools/rb2b/)** または **[Warmly](/ja/tools/warmly/)**：Web サイト訪問者の特定で、月 $0〜$159 から。評価がターミナルではなくマーケティングサイト上で行われる場合に選びます。
- **[Sumble](/ja/tools/sumble/)**：テクノグラフィックと採用のシグナルで、1 ユーザーあたり月 $99 から。知りたいのが「誰が自社製品を使っているか」ではなく「どの企業が自社と連携するスタックを使っているか」である場合に選びます。

どれも合わない場合は、まず [インテントデータ](/ja/learn/intent-data/) と [シグナルベースセリング](/ja/learn/signal-based-selling/) を読み、営業担当がどのシグナルから動くかを決めてください。

## 注意点

- **連携ページとドキュメントの記載が食い違っています。** 2026-11-23 時点で、reo.dev/integrations のすべての項目（Salesforce と HubSpot を含む）に「Coming soon」のラベルが付いていた一方、ドキュメントでは同じコネクタが稼働中として説明されています。**対策：** トライアル中に実際のアカウントを 10 件 CRM に送り、契約前にフィールドマッピングを確認してください。CRM 同期は発注書に明記します。
- **開発者の特定はオープンソースの信頼と衝突しうる。** Reo.Dev はテレメトリと利用データをログイン ID と IP アドレスでエンリッチし、無料サインアップを匿名解除します。自分たちのインストールが営業ツールに流れていると知ったコミュニティは、強く反発することがあります。**対策：** OSS とサインアップのソースを有効にする前にテレメトリとプライバシーの告知を更新し、EU のデータはベンダーのバッジに頼らず自社の GDPR レビューにかけてください。
- **アカウント数はプランごとに上限があります。** Startup の監視対象は 5,000 コンタクト/アカウントで、人気のオープンソースプロジェクトなら 1 四半期で超えることがあります。**対策：** プランを選ぶ前に、直近 90 日のパッケージとドキュメントのトラフィックからユニーク企業数を数え、超過料金や上位プランへの移行価格を書面で交渉してください。
- **ルーティングのないシグナルはノイズになります。** 週に数百件の「アカウントがアクティブ」アラートが届くと、営業担当は Slack を無視するようになります。**対策：** シグナルからアクションへのルールは 2〜3 個から始め、それぞれに担当者と SLA を設定し、ルールを追加する前にシグナルの種類ごとの採用アカウント率を測定してください。
