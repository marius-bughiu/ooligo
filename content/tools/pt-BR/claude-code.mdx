## O que é

Claude Code é a ferramenta de programação agêntica da Anthropic: você descreve uma tarefa em linguagem natural e ela lê o repositório, edita arquivos ao longo dele, roda comandos de shell e testes, e faz o commit ou abre um pull request. Ela roda sobre um mesmo motor em várias superfícies — uma CLI de terminal, uma extensão do VS Code (que também instala no Cursor), um plugin para JetBrains, a aba Code do app desktop do Claude, o navegador em claude.ai/code e os apps mobile do Claude —, então o `CLAUDE.md`, as configurações e os servidores MCP de um projeto acompanham você entre elas. Chegou ao público geral em maio de 2025 e, segundo o anúncio de captação da própria Anthropic de fevereiro de 2026, sua receita anualizada (run-rate) já passava de US$ 2,5 bilhões.

Esta é uma página de subproduto. [Claude](/pt-BR/tools/claude/) cobre o assistente e a API; [Claude Cowork](/pt-BR/tools/claude-cowork/) cobre a superfície de agentes para quem não escreve código. Claude Code é para quem, no time de ops, é dono do código.

## Por que aparece nos stacks de ops

GTM engineers e desenvolvedores de RevOps entregam cada vez mais código de integração: scripts de sync do CRM, jobs de enriquecimento, servidores MCP próprios, code nodes do [n8n](/pt-BR/tools/n8n/), modelos do data warehouse. A maior parte disso hoje é construída no Claude Code, por quatro motivos:

- **MCP nos dois sentidos.** Ele se conecta a servidores MCP de [HubSpot](/pt-BR/tools/hubspot/), [Salesforce](/pt-BR/tools/salesforce/), [Linear](/pt-BR/tools/linear/), [Notion](/pt-BR/tools/notion/) e [Slack](/pt-BR/tools/slack/), e é o lugar mais rápido para escrever e testar o seu próprio servidor. Veja [o que é um servidor MCP](/pt-BR/learn/mcp-server-explained/) e [quando uma skill ganha de um servidor](/pt-BR/learn/claude-skill-vs-mcp-server/).
- **Execuções headless.** `claude -p` roda um prompt sem interação, então encaixa em CI, cron jobs e pipelines de GitHub Actions ou GitLab CI/CD. O Agent SDK expõe as mesmas ferramentas para você construir seus próprios agentes.
- **Routines.** Jobs agendados na nuvem, criados com `/schedule`, que continuam rodando com o notebook desligado e podem disparar por uma chamada de API ou um evento do GitHub — o check noturno de qualidade de dados ou a auditoria de dependências de segunda-feira que ninguém precisa lembrar.
- **Instruções de repo compartilhadas.** Desde a versão 2.1.277 (18 de setembro de 2026), o Claude Code lê o `AGENTS.md` quando uma pasta não tem `CLAUDE.md`, então um repositório já configurado para Codex ou outros agentes funciona sem duplicar instruções. Se os dois arquivos existirem, vale o `CLAUDE.md`.

## A realidade do preço

Claude Code não tem preço próprio; ele está incluído em todos os planos pagos do Claude, e não no Free:

- **Pro** — US$ 20/mês, ou US$ 17/mês no plano anual
- **Max** — US$ 100/mês ou US$ 200/mês, com 5× ou 20× o uso do Pro
- **Team** — seat padrão US$ 25/mês (US$ 20 no anual); seat premium US$ 125/mês (US$ 100 no anual), de 2 a 150 seats
- **Enterprise** — US$ 20 por seat mais uso cobrado a preço de API

Você também pode dispensar os seats e usá-lo com uma API key do Anthropic Console, Amazon Bedrock, Google Cloud's Agent Platform ou Microsoft Foundry, pagando por token.

A tabela de planos não é o número real. O uso é compartilhado entre o chat do claude.ai, o app desktop, o Cowork e o Claude Code, e tem dois limites: uma janela móvel de cinco horas e um limite semanal, que a Anthropic ajustou várias vezes ao longo de 2026. Programar o dia inteiro, todo dia, estoura um seat Pro; é para isso que existem o Max e os seats premium. Orce um seat Team padrão para o analista que escreve um script por semana, um seat premium (ou Max para pessoa física) para quem usa a ferramenta como principal, e US$ 100–200 por usuário intensivo por mês como número de planejamento. O Code Review automático no GitHub, disponível em Team e Enterprise como research preview, é cobrado à parte via créditos de uso, com média de US$ 15–25 por revisão.

## Ideal para

GTM engineers, RevOps engineers e tecnólogos de legal ops ou recruiting ops que são donos de um repositório — quem mantém o sync CRM-warehouse, escreve o servidor MCP próprio do deal desk ou constrói o pipeline de exportação do ATS. O caso delimitado em que ele ganha sem discussão: mudanças em vários arquivos de um codebase existente que precisa continuar passando nos testes, seguidas de uma execução agendada ou disparada por CI do mesmo job. Isso responde a pergunta do seat Team premium: sim para as uma ou duas pessoas cujo trabalho é construir esse código, não para o resto.

## Não serve para

Pessoas que não leem diffs. O Claude Code propõe e executa comandos de shell e faz commit de código; se ninguém do lado de quem recebe consegue julgar se uma mudança está certa, dê a essa pessoa o [Claude Cowork](/pt-BR/tools/claude-cowork/) ou um builder no-code. Ele também não substitui uma ferramenta de fluxos em pipelines de alto volume e formato fixo: quando o job vira "mover estes campos a cada hora", o código que o Claude Code escreveu deve rodar no n8n ou no seu orquestrador, não dentro de uma sessão de agente.

## Frente às alternativas

- **[GitHub Copilot](/pt-BR/tools/github-copilot/)** — a maior base instalada em número de seats. Business custa US$ 19 e Enterprise US$ 39 por usuário por mês, e desde 1º de junho de 2026 o uso acima dos AI credits incluídos é medido e cobrado à parte. Escolha quando a organização já compra GitHub Enterprise e a necessidade principal é autocompletar dentro do editor para muitos desenvolvedores, não tarefas de vários passos delegadas.
- **[Cursor](/pt-BR/tools/cursor/)** — o principal rival específico de programação em receita; a Bloomberg reportou que passou de US$ 2 bilhões em receita anualizada em março de 2026. Os planos individuais começam em US$ 20/mês e o Teams em US$ 40 por usuário. Escolha quando a pessoa vive dentro de uma IDE e quer ver e conduzir cada edição visualmente; o trade-off completo está em [Claude vs Cursor](/pt-BR/comparisons/claude-vs-cursor/).
- **OpenAI Codex** — o concorrente que mais cresce: de mais de 2 milhões de usuários semanais em março de 2026 para mais de 5 milhões em junho. Está incluído no ChatGPT Go (US$ 8), Plus (US$ 20) e Business (US$ 20 por usuário no anual, US$ 25 no mensal). Escolha quando a empresa já padronizou no ChatGPT Business, porque o seat de programação vem sem fornecedor novo. A OpenAI parou de vender novos seats Codex-only pay-as-you-go nos planos Business em junho de 2026, então o uso cobrado por token agora passa por uma API key.

## Pontos de atenção

- **Auto mode agora é o modo de permissão inicial.** A partir da versão 2.1.283, sessões interativas de terminal e VS Code começam em auto mode, em que um segundo modelo revisa cada ação no lugar de uma pessoa. A própria documentação da Anthropic diz que ele "não garante segurança". Proteção: no Team e no Enterprise, defina `permissions.defaultMode` ou coloque `permissions.disableAutoMode` em `"disable"` nas configurações gerenciadas para os grupos que mexem em sistemas de produção, adicione regras `ask` para qualquer ferramenta MCP que escreva no CRM e rode sessões sem supervisão em um container ou sandbox.
- **Um pool de uso, muitos consumidores.** Uma routine, a sessão de chat de um colega e a sua sessão de programação consomem o mesmo limite do seat, e esse limite reinicia numa janela de cinco horas que você não controla. Proteção: dê às routines agendadas e aos jobs de CI uma API key própria com teto de gasto, para que um job descontrolado não trave quem precisa do seat às 10 da manhã.
- **O custo do Code Review escala com os pushes.** Configurar um repositório para revisar "after every push" multiplica a média de US$ 15–25 pelo número de pushes por pull request. Proteção: comece os repositórios em "Once after PR creation" ou Manual, e defina um teto de gasto mensal para o serviço Claude Code Review em claude.ai/admin-settings/usage antes de ativá-lo.
