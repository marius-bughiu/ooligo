eDiscovery（電子的証拠開示）とは、訴訟・規制当局の調査・内部調査に対応して電子的に保存された情報（ESI）を識別・保全・収集・処理・レビュー・提出するプロセスです。法律業界で最大かつ最も成熟したデータエンジニアリングの問題です——単一の第2次要請の対応で数千万件のドキュメントを取り込むことがあり、見落とした特権文書1件が過誤訴訟になる可能性があります。

## EDRMモデル

電子証拠開示参照モデル（EDRM）はeDiscoveryワークフローの業界標準の地図です。9つのステージを（ほぼ）順番に実行します。

| ステージ | 何が起きるか |
|---|---|
| 1. 情報ガバナンス | 訴訟前：データ保持ポリシー、ホールド準備 |
| 2. 識別 | どのカストディアンとデータソースが対象か？ |
| 3. 保全 | リーガルホールドを発行、削除を凍結 |
| 4. 収集 | メール・ファイル共有・Slack・モバイル・クラウドアプリからデータを取得 |
| 5. 処理 | 重複排除、メタデータ抽出、OCR、フォーマット正規化 |
| 6. レビュー | 弁護士（またはAI）がドキュメントにタグ付け——応答性、特権、ホット |
| 7. 分析 | レビュー済みドキュメントからケースのストーリーを構築 |
| 8. 提出 | 応答性があり特権のないドキュメントを要請者に提出 |
| 9. プレゼンテーション | 提出されたドキュメントを証言録取またはトライアルで使用 |

ほとんどのeDiscoveryソフトウェア（[Relativity](/ja/tools/relativity/)、[Everlaw](/ja/tools/everlaw/)、[Logikcull](/ja/tools/logikcull/)）はEDRMのステージ4〜8をカバーします。ステージ1〜3はMicrosoft Purview、Google Vault、または専用リーガルホールドソフトウェア内の情報ガバナンスツールで対応することが増えています。

## レビューがコストセンターである理由

レビューはeDiscovery費用の70%以上が集中する場所です。最近まで、レビューとは初回審査の弁護士（コントラクトレビュアーであることが多い）が1時間あたり50〜150ドルで各ドキュメントを確認することを意味していました。100万件のドキュメントのレビューには5,000〜15,000時間の弁護士時間がかかるため、第2次品質管理の前のレビューコストだけで50〜200万ドルになります。

2つの自動化の波がこれに対応しました。

- **テクノロジー支援レビュー（TAR）。** 2010年代初頭からの予測コーディングワークフロー。シニア弁護士がシードセットでモデルをトレーニングし、モデルが残りのドキュメントを応答性でランク付けし、低ランクのドキュメントはより少ない強度でレビューされるかまったくレビューされません。米国のほとんどの管轄区域で裁判所に受け入れられています。
- **LLM支援レビュー。** 2023年以降、生成AIが一般的なカテゴリ（応答性/非応答性、特権、ホット）でジュニアコントラクトレビュアーと競争できる品質基準で初回レビューを処理します。Everlaw、Relativity、DISCOはいずれもLLM機能をリリースし、専門プレイヤー（CasetextのCARA、[Luminance](/ja/tools/luminance/) Discovery）がガチンコで競合しています。

LLM支援レビューはコスト曲線を劇的に変えています——適切に運用されたケースでは初回レビューを過去コストの10〜20%で実施できるようになっています——しかし裁判所と対立する弁護士側は、AI支援の提出が開示と検証の観点から何を必要とするかについてまだ調整中です。

## 企業はいつeDiscoveryソフトウェアを必要とするか？

ほとんどの非訴訟企業にとって：必要ありません。eDiscoveryは社外弁護士を通じて案件ごとに調達され、弁護士がその案件のeDiscoveryベンダーを選択します。企業が直接[Relativity](/ja/tools/relativity/)や[Everlaw](/ja/tools/everlaw/)のライセンスを持つことはありません。

eDiscoveryを社内に取り込む企業には通常2つの共通シグナルがあります。

1. **反復する訴訟または規制量。** 金融サービス会社、医療、大手テック、政府請負業者。案件の頻度が専任チームとツールを正当化します。
2. **外部に出したくない機密データ。** 一部の社内チームは、レビュー済み提出物を社外弁護士に渡す前に収集と処理を内部で処理することを好みます。

社内eDiscoveryはLegal Opsの責任であり、案件管理機能とは区別されます。ツールの意思決定（どのプラットフォーム、どのAIベンダー）はeDiscoveryヘッドまたはLegal Opsヘッドが行います。

## eDiscoveryがLegal Ops全般に重要な理由

社内でeDiscoveryを運用しないLegal Opsチームでも気にすべき理由：

- **eDiscoveryの社外弁護士費用は、訴訟予算の最大の単一項目であることが多い。** [法務費用管理](/ja/learn/legal-spend-management/)ツールが追跡し、AFA構造（ドキュメントレビューの上限付き）がますます適用されるようになっています。
- **Legal Opsが上流で行う情報ガバナンスの選択（保持、コミュニケーションポリシー）が下流のeDiscoveryコストを決定する。** 90日間のSlack保持ポリシーは、次の調査が来たときに数百万ドルの決定になります。
