Um pack de doze prompts testados em batalha pras perguntas que um pipeline review realmente precisa responder. Cole um export de deals, cole um prompt, receba uma resposta estruturada no vocabulário do seu time. Sem agente, sem API, sem integrações. Só os prompts, ordenados por quão frequente você vai usar cada um.

## O que você vai precisar

- Claude.ai (tier Sonnet ou Opus)
- Um CSV ou tabela markdown do seu pipeline aberto com nome do deal, valor, stage, dias em stage, owner e última atividade
- O cheat sheet da sua metodologia de vendas, colado uma vez no topo do projeto

## Setup

1. **Crie um projeto do Claude.** Nomeie "pipeline-review". Carregue o doc de metodologia como project knowledge. Agora cada prompt do pack começa com o contexto certo.
2. **Importe os prompts.** Copie cada um dos doze prompts como saved prompt no projeto. Marque por caso de uso: review semanal, prep de board, deep-dive, escalação.
3. **Cole o pipeline.** A maioria dos prompts espera a tabela inline. Dois esperam o histórico completo de um único deal. O pack documenta quais são quais.
4. **Rode primeiro os três mais usados.** "Encontre os commits at-risk", "ranqueie deals por credibilidade de close date" e "redija o talk-track do manager". Esses três cobrem oitenta por cento do uso semanal.

## Como funciona

Os doze prompts estão organizados em três tiers. Tier um é em nível de portfólio: ranqueamento, segmentação, detecção de slippage. Tier dois é por deal individual: diagnóstico de deal travado, análise de gaps de MEDDPICC, proposta de next step. Tier três é prep de reunião: talk-tracks pra manager, one-pagers pra executivos e o prompt "o que devo perguntar pro rep" que managers amam.

Cada prompt é estruturado igual: papel, contexto, formato de input, formato de output, uma lista explícita de coisas a evitar. A seção "coisas a evitar" é a heroína anônima. Bane o hedge corporativo, impede o Claude de inventar dados que não estão na tabela e força cifras específicas em vez de linguagem vaga.

## Pontos de atenção

- **Garbage in, garbage out.** Se seu export de pipeline não tem datas de última atividade, o prompt at-risk vai chutar. Sempre inclua a coluna de atividade.
- **Mismatch de metodologia.** Um prompt de MEDDPICC rodado num time treinado em BANT produz saída pouco familiar. Troque o doc de metodologia, não edite os prompts.
- **Especificidades alucinadas.** O Claude vai inventar com confiança o nome de um champion se você deixar. Os prompts incluem guards do tipo "se um campo está faltando, diga". Mantenha.
- **Creep de tamanho.** A saída tende a alongar com o tempo conforme você faz follow-ups. Resete a conversa entre deals.

## Stack

- **Claude** — camada de modelo, project knowledge, saved prompts
- **CSV export** — dados de pipeline num formato amigável pro Claude
- **Doc de metodologia** — a lente que torna a saída útil
