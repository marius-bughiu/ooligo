[Personio](/ja/tools/personio/) と [BambooHR](/ja/tools/bamboohr/) は、中小企業の採用チームが応募者管理と従業員レコードを2つではなく1つのシステムにまとめたいと考えたときに行き着く2つの HR プラットフォームです。対象規模は近く、Personio は従業員10〜10,000人の企業に、BambooHR は25〜500人の帯に販売しています。公開されている入口価格も近い水準です。近くないのは、従業員が法的にどこで雇用されているかという点です。Personio はドイツ、英国、アイルランド、オーストリア、スペインでプラットフォーム内にネイティブで給与計算を実行します。一方 BambooHR の給与計算製品は米国の従業員のみを対象とし、それ以外は扱いません。この1点が、誰かが機能比較表を開く前にこの手の評価の大半を決着させます。給与計算は連携でごまかせない唯一のモジュールだからです。

## Personio が勝つ領域

- **ドイツの給与計算をプラットフォーム内で回せる。外部の給与事務所を経由しない。** Personio Payroll は ITSG 認証を取得し、ドイツの社会保険機関と直接やり取りします。これにより、ドイツの中小企業の多くがいまだ Steuerberater（税務顧問）経由で処理している書類作業と手作業の工程がなくなります。Personio はこの運用形態を3種類提供しています。自社で回す、税務顧問と共同で回す、Personio の給与チームに任せる、の3つです。給与計算事業は前年同期比80%成長し、2026年4月時点で1,500社超に達しています。
- **複数法人対応はプランの機能であり、回避策ではない。** Core は法人1社、Core PRO は法人数無制限です。ドイツの GmbH とスペインまたはアイルランドの子会社を並行して運営するグループは、上位プランを買えばそれで完了します。BambooHR の課金は従業員数のみに依存し、階層を分けるのは ATS の同時求人枠と評価機能であって、いくつの法人で雇用しているかではありません。
- **EU の内部通報義務を HRIS の中で満たせる。** EU 指令 2019/1937 は、従業員50人以上の雇用主に内部通報窓口の運用を義務づけています。Personio は Whistleblowing を自社 App として従業員レコードと同じプラットフォーム上で販売しているため、通報窓口とその案件記録は、別ベンダーのシステムではなく HR の他の領域と同じアクセス制御下に置かれます。
- **Recruiting に同時求人数の上限がない。** Personio Recruiting は App であり、Personio の16,000社のうち9,000社が使っています。同時に何件の求人を開けるかをパッケージが制限することはありません。メーターは従業員数であり、それはすでに支払っているものです。
- **ベンダーは欧州企業で、いまや自己資金で回っている。** 本社はミュンヘン、2026年4月22日に初の黒字四半期を報告、16,000社の顧客が欧州で150万人超の従業員をカバーしています。調達部門が米国 CLOUD Act へのエクスポージャーを問うとき、答えはデータ所在地の覚書ではなく企業そのものについての事実になります。

## BambooHR が勝つ領域

- **商談の前に請求額を計算できる。** Core $10、Pro $17、Elite $25（従業員1人あたり月額）がすべて公開されています。Personio が公開している数字は「starts from €7.60 per month/employee」の1つだけで、各 App はその上に個別見積もりとなるため、Personio の総額をベンダー自身のページから導くことはできません。
- **応募者管理が入口プランに含まれる。** BambooHR の Core は $10 で ATS、オファーレターのテンプレート、入社パッケージ、電子署名を含みます。Personio の €7.60 の Core にはそのいずれも含まれず、Recruiting は別途ライセンスされる App です。最低価格帯において、この2つの価格の一方は採用機能を含み、他方は含みません。
- **エージェントアクセスは発表ではなく出荷済み。** BambooHR は2026年7月に Bamboo AI を提供開始し、UI がすでに適用している権限モデルのまま人事データを Claude や ChatGPT に公開する MCP 接続を備えています。Personio は2026年4月にミュンヘンの採用 AI スタートアップ aurio をエージェント型のソーシングとスクリーニングのために買収し、最初の顧客向け提供は2026年内の後半になると述べました。2026年8月20日時点でそれは到着していません。Personio は自社 MCP サーバーを提供しておらず、GitHub にあるものはその API に対するコミュニティ実装です。
- **採用確定レコードの引き渡しが主要 ATS からあらかじめ用意されている。** [Greenhouse](/ja/tools/greenhouse/)、[Lever](/ja/tools/lever/)、[Ashby](/ja/tools/ashby/) はいずれもワンクリックの BambooHR コネクタを提供しており、その背後には150社超の連携パートナーがあります。候補者を「採用」に移すと、氏名、入社日、職務、報酬、上長が入力済みの状態で HRIS に到着します。Personio は200件超の連携と自社マーケットプレイスを掲載していますが、最も強い採用経路はサードパーティ ATS ではなく自社の Recruiting App です。
- **交渉後価格に公開されたベンチマークがある。** Vendr のデータセットは BambooHR の購買114件をカバーし、年間契約額の中央値は $16,197、レンジは $9,490〜$78,783、平均値引き率は9.79%です。Vendr の Personio ガイドは中央値ではなく言葉によるレンジを公開しています。25人チームで年間5桁台前半、給与計算込みの100〜150人規模で5桁台の中〜上位、という具合です。そのため Personio の買い手は、より幅の広い想定で交渉に臨むことになります。

## 価格の実態

公開されている下限は近接しています。従業員1人あたり月額で €7.60 対 $10 です。しかし買える範囲は異なり、2つの通貨は互換ではありません。BambooHR の $10 の Core は ATS を含みますが同時求人を5件に制限します。$17 の Pro は上限を25件に、$25 の Elite は50件に引き上げますが、その階層は枠を必要としたリクルーター1人分ではなく全従業員分を購入することになります。Personio の €7.60 の Core は採用機能を一切含まず、電子署名ワークフローを従業員の8%に制限し、法人は1社のみです。Core PRO はこの3点をすべて解除し、カスタム連携向けの API アクセス、Okta と Microsoft Entra ID、ポジション管理、人員計画を追加します。

100人規模の企業なら BambooHR の数字は算術です。$17 の Pro は月額 $1,700、定価で年額 $20,400 となります。これは米国限定のアドオンである Payroll と Benefits Administration を含まない金額で、第三者の購買レポートはそれらを従業員1人あたり月額 $6〜8 と見ています。Personio の数字は算術になりません。€7.60 の下限で Core 単体でも100人なら年額 €9,120 で、そこに Recruiting、Performance、Surveys、Compensation、Whistleblowing がそれぞれ個別見積もりで乗り、さらに企業規模に応じて変動する初期設定費用が一度だけかかります。年額一括前払いはソフトウェア費用から10%を差し引き、年間契約には12か月の最低契約期間があります。

見出しの単価よりも実際の金額を動かす構造的な要素が2つあります。Personio はアクティブユーザー全員をライセンスとして数えるため、業務委託や休眠アカウントも課金対象です。BambooHR は従業員25人以下の企業に月額 $250 からの定額下限を課しており、ちょうど25人なら1人あたり $10、10人なら1人あたり $25 になります。Core の機能に Elite の金額を払う形です。

## 結論

- **Personio を選ぶべきなのは**、ドイツ、オーストリア、スペイン、アイルランド、英国で人を雇用しており、従業員レコードと同じシステムで給与計算を実行したい場合、法人を複数運営している場合、EU の内部通報窓口がまだ未対応のコンプライアンス項目である場合、あるいは調達部門が米国本社のデータ処理者を、チェックを入れて済む項目ではなく説明を要するリスクとして扱う場合です。
- **BambooHR を選ぶべきなのは**、従業員が米国にいる場合、デモの前に価格が必要な場合、入口プランで ATS が初日から動く必要がある場合、あるいは MCP 経由の HR データへのエージェントアクセスを来年ではなく今四半期に使うつもりがある場合です。
- **どちらも選ばないべきなのは**、本当の問題が ATS である場合です。パネル面接、ルーブリック評価、部門別の採用リードタイム集計を回しているチームなら、[Greenhouse](/ja/tools/greenhouse/)、[Ashby](/ja/tools/ashby/)、[Workable](/ja/tools/workable/) のいずれかを購入し、どちらのプラットフォームをその下の HRIS として置いてください。米国で従業員100人前後を超え、IT のプロビジョニングも範囲に入るなら、[Rippling](/ja/tools/rippling/) が1つの入社トリガーから HR とデバイス管理の両方を回します。数千人規模を超える場合、あるいは欧州と北米の両方の外で事業を展開する場合、これらの買い手が結局行うのは [Workday](/ja/tools/workday/) への移行です。

これらの条件がどれも当てはまらず、1つだけ既定を選べと言われたなら BambooHR です。商談サイクルなしで価格を出し、購入し、運用できるのはこちらであり、ATS が最低価格帯からすでに動いています。Personio への移行は好みの問題ではありません。給与計算をユーロで確定させる必要が生じた瞬間に起きることです。
