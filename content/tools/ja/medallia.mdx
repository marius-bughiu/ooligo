## 概要

Medallia は、顧客のフィードバックを「それに対して行動できる人」に届けることを軸に作られたエンタープライズ向けエクスペリエンス管理スイートです。対象は店長、銀行支店のスタッフ、コンタクトセンターのスーパーバイザー、ホテルの総支配人といった現場の人々です。アンケート、デジタルフィードバック、音声、ソーシャル、動画を収集し、テキスト分析と音声分析をかけ、その結果をロール別レポート、アラート、ケース管理に流します。2001年創業、2019年7月に NYSE へ上場し、2021年10月に Thoma Bravo が64億ドルの全額現金で非公開化しました。最も近い同等製品は [Qualtrics](/ja/tools/qualtrics/) です。

2026年に購入者が問うているのは機能ではありません。2026年4月22日、Thoma Bravo は債務の株式化（デット・エクイティ・スワップ）によって Medallia を債権者に引き渡すことに合意し、約30億ドルの債務に対してスポンサー側の株主資本約51億ドルが消滅しました。翌日に Reuters が報じた時点で、債権者のうち2社はすでにこの融資を1ドルあたり74セントと79セントで評価していました。資本再構成は2026年6月17日に正式発表され、2026年8月3日に完了しています。現在の Medallia は Blackstone、Apollo、FS KKR Capital が率いる投資家グループの所有となり、債務は非公表の額だけ削減され、バランスシートには1億5,000万ドルの新規資本が入りました。会社が消えるわけではありません。ただし、2025年に検討していたときと同じ賭けではなくなっています。

## CX スタックに登場する理由

- **インサイトチームではなく現場のために作られています。** Gartner は2026年の Magic Quadrant for Voice of the Customer Platforms（2026年3月12日発表、評価対象12社）で Medallia を5回連続で Leader に選び、毎週700万人近くが使う Frontline-Ready AI を評価しました。この利用のされ方こそが製品の本質です。本社のダッシュボードを見る十数人のアナリストではなく、自分の拠点のフィードバックを見る数万人の従業員が使うツールです。
- **ユーザー数無制限が価格に含まれています。** Medallia は Experience Data Record（EDR）単位で課金します。EDR とは、顧客または従業員と企業との1回のインタラクションに紐づくすべてのデータのことで、年間ティアで販売されます。料金ページには、ユーザー数無制限、ロール別レポート、アラート、ケース管理が含まれると明記されています。従業員40,000人の小売企業にとって、これは現場が使える仕組みになるか、ライセンス数で配給制になるかの違いです。
- **生成 AI レイヤーは7月に提供開始されました。** 2026年7月14日、Medallia は Smart Topic Builder、Intelligent Summaries、Smart Response、Root Cause Assist を一般提供（GA）とし、主要な AI 機能にフランス語とドイツ語を追加しました。同社によれば、その時点で上位300社のエンタープライズ顧客のうち40%超が生成 AI を有効化しており、このグループのソフトウェア ACV は2億ドルを超えます。
- **自らエージェントになるのではなく、エージェントにインサイトを渡します。** 2026年1月21日に発表された [Ada](/ja/tools/ada/) との提携では、Medallia のオムニチャネルのシグナルを Ada の AI エージェントに流し、苦情のパターンに対してエージェントが行動できるようにしています。2025年9月の Adobe との同様の提携に続くものです。ロードマップ上で AI エージェントを顧客の前に置く計画があるなら、Medallia は「何を直すべきか」をエージェントに伝える傾聴レイヤーという位置づけになります。

## 価格の実態

公開価格はありません。料金ページは EDR モデルを説明したうえで営業窓口に誘導するだけで、定価、最低契約額、無料プランのいずれもありません（2026年9月18日確認）。

Vendr の購入者データでは、Medallia の契約額の中央値は年13,338ドル（32件の購入に基づく）、レンジは6,739ドルから112,044ドル、最終更新は2026年2月です。この数字は慎重に読んでください。同じプラットフォーム上で Qualtrics が317件あるのに対して32件しかないということは、Vendr に見えているのは Medallia の小規模な単一プログラムの契約であり、コンタクトセンターの音声や数十の事業部門にまたがるエンタープライズプログラムではない、ということです。Vendr のレンジは「1チャネル・1ジャーニー」の下限として扱い、現場全体への展開のベンチマークにはしないでください。

請求額を動かすのはメーターです。アンケートのみのプログラムでは EDR 数は控えめですが、コンタクトセンターの音声やデジタル行動データを加えると、ユーザーを1人も増やさずにレコード数が何倍にも膨らみます。チャネルごとの EDR の定義、年間の含有量、超過料金、更新時の値上げ上限を必ず書面で取り付けてください。

## 最適な利用者

拠点数が多く現場の人員規模が大きい企業――ホテルグループ、小売チェーン、リテール銀行、通信事業者、病院グループ――の CX プログラム責任者で、各拠点のフィードバックを数時間以内にその拠点の責任者の目の前に届け、ループを閉じたかどうかを追跡することが仕事である場合です。Medallia によると、ホスピタリティ業界の上位10ブランドのうち6ブランドが、ローンチから12か月以内に同社の生成 AI 機能を利用しています。ここが Medallia の設計が最もよく噛み合うセグメントです。

フィードバックがサポートチケットやプロダクトのチャネルにすでにあり、仕事が「集める」ことではなく「読む」ことであるなら、買わないでください。それは分析レイヤーの購入であり、代金を払うことになる現場向けツールを使う人がいません。従業員がおよそ1,000人未満の企業で単一の NPS プログラムを回すためだけに買うのもやめてください。そして、今四半期中にエージェントから MCP 経由でフィードバックを照会したいなら、買わないでください。自社提供の MCP サーバーはありません。

## 代替製品との比較

**[Qualtrics](/ja/tools/qualtrics/)** は導入ベースでもう一方の既存大手であり、同じ Magic Quadrant で最も高く評価された Leader で、Public API 上に公式の MCP サーバーを持っています。2026年5月18日に Press Ganey Forsta を統合したため、Qualtrics 自身も統合作業の最中です。CX に加えて市場調査と従業員エクスペリエンスまで1つの契約でカバーする必要がある場合や、エージェントからのアクセスが今すぐ必要な場合は Qualtrics を選んでください。数百の拠点で現場を動かすことが仕事なら Medallia です。

**Sprinklr** は残る3社目の Leader です。ソーシャルとカスタマーケアのチャネルがシグナルの中心で、すでにソーシャル用途で Sprinklr を使っているなら、こちらを選んでください。ベンダーが1社、コネクタが1つ減ります。

**[Enterpret](/ja/tools/enterpret/)** は分析レイヤーの予算を奪っている、最も成長の速い AI ネイティブの新興製品です。フィードバックがすでに存在し、それをプロダクトとサポートのために分類することが仕事なら Enterpret を選んでください。レビューやアプリストアがシグナルの中心なら [Chattermill](/ja/tools/chattermill/) が同じ役割を果たし、NPS と現場コーチングだけが要件なら [AskNicely](/ja/tools/asknicely/) がより安価な選択肢です。

どれも合わない場合は、Gartner の2社の Challenger、Alchemer と Pisano を見てください。Alchemer は小規模チーム向けのセルフサーブプランを公開しており、これは既存大手2社のどちらもやっていないことです。どちらかで1ジャーニーだけのパイロットを回せば、エンタープライズプログラムを契約する前に、それが本当に必要かどうかがわかります。

## 注意点

- **オーナーは債権者であり、製品への投資約束はプレスリリースの一文にすぎません。** CEO の Mark Bishof は、Medallia が「今後数年間で」製品とサービスに5億ドル超を投資すると述べています。これは声明であって契約条項ではありません。2026年5月に CMSWire が取材したアナリストは、債権者による支配は研究開発よりもコスト削減を優先しがちだと警告し、Gartner の Maria Marino は Medallia の顧客の間ですでに更新時の問題が表面化していると述べています。**対策：** この発表を根拠に3年契約を結ばないでください。初回契約は1年にするか、3年契約にする場合は、指定したロードマップ項目が所定の期日までに GA にならなければ12か月目に任意解約できる条項を入れてください。回答の生データ、文字起こし、組織階層データを文書化された形式でエクスポートできるデータエクスポート条項も追加してください。
- **発表されたものが提供されているとは限りません。** 2026年2月の Experience '26で披露された自然言語クエリ機能 Insights Assistant は、Smart Topic Builder を含む7月14日の GA リストに入っていませんでした。**対策：** ビジネスケースは7月に GA となった機能だけで組み立て、デモは自社データで実施し、それ以外のものは遅延時の価格調整付きの期日入りマイルストーンとして発注書に明記してください。
- **EDR メーターは成功にペナルティを課します。** プログラムがうまくいった年こそ、音声、チャット、デジタルシグナルを追加する年であり、そのどれもが EDR 量を押し上げます。**対策：** 2年目は1年目の EDR の2倍でモデル化し、超過料金は、まだ交渉の席を立てる最初の接触の段階で交渉してください。
- **エージェントからのアクセスは自前で作る必要があります。** プログラムからのアクセスは GraphQL ベースの Query API と Import API を OAuth 2.0のクライアントクレデンシャルで利用します。存在する MCP サーバーは Zapier のものを含めサードパーティ製のラッパーで、顧客データの経路にもう1社ベンダーが入ることになります。**対策：** Claude や Cursor にフィードバックを読ませたいなら、読み取り専用のデータアクセスロールで Query API の上に薄い社内 MCP サーバーを構築し、文字起こしがモデルに届く前に PII 検出を必ず有効にしておいてください。
- **交渉上の立場は異例なほど強いので、活用してください。** オーナーが替わったばかりで、アナリストが更新リスクを公に指摘しているベンダーは、複数年契約の実績を欲しがっています。**対策：** 継続するつもりでも、同じサイクルで Qualtrics か Sprinklr の見積もりを取り、今後18か月にわたって全額予算が確保されているプロダクトチームはどこかを質問してください。その答え、あるいは答えを拒むという事実は、値引きよりも価値があります。
