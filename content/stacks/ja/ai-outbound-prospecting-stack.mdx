2026 年に AI 拡張のプロスペクティングを回す RevOps チームの標準アウトバウンドスタックです。リスト構築、エンリッチメント、ICP スコアリング、シーケンス配信、CRM 同期を、最後に付け足すのではなく各レイヤーの内側に AI を持たせて回します。前提は、単一のツールが単独で勝つということではありません。5〜15 人の担当者のチームでも、より少なく、より深く調べたメッセージを送りながらパイプラインを満たせるということです。各メッセージに必要な調査が、今や SDR のブラウザのタブの中ではなくソフトウェアの中で走るからです。

## 各ピースの噛み合い方

- **[Clay](/en/tools/clay/) はデータ + AI のワークベンチです。** あらゆるシード(役職、テクノグラフィクス、インテントシグナル)からの ICP リスト構築、100 以上のプロバイダーにまたがるウォーターフォールエンリッチメント、そしてアカウントを要約したり行ごとにオープナーを書いたりする AI カラム。リストが形になるのは Clay の中です。2026 年 3 月の料金改定で課金は 2 つのメーター、Data Credits と Actions に分割され、セルフサーブのチームは Launch($185/月)か Growth($495/月)に着地します。[リードエンリッチメントの Skill](/en/workflows/lead-enrichment-clay-claude/) と [ICP リストビルダー](/en/workflows/icp-account-list-builder-clay/) が、ここに住む 2 つのプレイです。
- **[Apollo](/en/tools/apollo/) は安価なベースデータ、携帯番号、そして SMB 向けのシーケンサーを供給します。** メールと携帯の検索、ダイヤラー、そして $79/シート/月(Professional、年払い)のシーケンス。$10M ARR 未満のチームにとって Apollo はデータの下限であると同時に配信エンジンでもあります。その上に Outreach を重ねることはしません。
- **[Outreach](/en/tools/outreach/) はミッドマーケット以上の配信エンジンです。** 分岐するシーケンスロジック、送信時刻の A/B、[Salesforce](/en/tools/salesforce/) との深い結合、そして 25 人以上の担当者を抱える組織が必要とする監査証跡。価格はカスタムで $130-180/シート/月、25〜50 シートの最低ラインがあります。つまり Apollo のシーケンサーか Outreach のシーケンサーか、セグメントに応じてどちらか一方を回すのであって、両方ではありません。
- **[Claude](/en/tools/claude/) はパーソナライズされたファーストタッチを書きます。** 各見込み客のオープナーは、Clay でエンリッチされた行、つまりアカウントの採用シグナル、資金調達イベント、役職の文脈から生成されるので、配信は差し込みタグではなく実在する何かを参照します。Claude は Clay のカラムとして、あるいは n8n を通じて走ります。
- **[n8n](/en/tools/n8n/) は統合レイヤーです。** HubSpot に新しいリードが入るとウェブフックが発火 → Clay がエンリッチ → スコア済みの行が書き戻され → シーケンサーが登録 → ホットな返信が Slack にルーティングされます。ツール間のすべてのホップは、固定配線のコネクターではなく n8n を通ります。Cloud Starter は $20/月、Pro は $50/月。セルフホスティングは料金を ops の時間と引き換えにします。
- **[HubSpot](/en/tools/hubspot/) は CRM の信頼できる情報源です。** エンリッチされたすべての連絡先、すべてのシーケンスのタッチ、すべての返信は、パイプラインのレポーティングとフォーキャストのために HubSpot のレコードへ戻って着地します。公式の MCP サーバーがあるので、Claude は余分な glue なしでレコードを照会し変更できます。

## これをスタックにするハンドオフ

価値は連鎖であって、6 つのロゴではありません。フォーム入力かリストのインポートが n8n のウェブフックを叩き、それが Clay の実行をトリガーして連絡先をウォーターフォールで処理し、あなたの [ICP ルーブリック](/en/workflows/lead-scoring-icp-rubric-skill/)と照らしてスコアリングし、Claude にオープナーを書かせます。その後 n8n は完成した行を HubSpot に書き込み、スコアのしきい値を超えた行だけを Apollo か Outreach に登録します。見込み客が返信すると、n8n はポジティブな返信を人間のために Slack へルーティングし、そのディスポジションを HubSpot へ同期し戻します。1 つのイベント、4 つのツール、返信までは人間なし。各矢印は次のアクションを発火させるトリガーであり、だからこそスタックは単に共存するのではなく積み上がっていきます。

## なぜこの組み合わせなのか

AI 以前のアウトバウンドは Apollo + Outreach + Salesforce でした。弱いパーソナライゼーションを量でごまかす、シーケンスして撒き散らすモデルです。AI レイヤーはこれを反転させます。Clay と Claude は、かつて SDR の午前中を丸ごと食べていたアカウントごとの調査を、リスト規模で走るテーブルへ移します。だからチームはより少ないメッセージを、それぞれにアカウント固有の文脈を載せて送ります。返信率が見るべき指標です。ベンダーが引用するどんな倍率も、あなた自身の配信がそれを動かすまでは未証明として扱ってください。この組み合わせが 6 つのツールを保つのは、それぞれが 1 つの仕事をうまくこなすからです。1 つのオールインワンのスイート(Apollo のフルスタック、あるいは Outreach のそれ)に畳み込むと、Clay だけが提供するワークベンチの深さを手放すことになります。

## いくらかかるか

スタックはバイモーダルで、選ぶシーケンサーが tier を決めます。

**SMB / Apollo tier($10M ARR 未満、5-15 担当者):** ざっくり **年間 $25K-$45K の総額**を見込んでください。HubSpot が最大の項目です。Sales Hub Professional が $100/シート/月、加えて Operations Hub Pro($800/月)で、8 人の担当者のチームなら年間 ~$19K になります。Apollo Professional はクレジットの超過分を除いてシートで年間 ~$7,600 を、Clay Growth は年間 ~$5,400 を、[Claude](/en/tools/claude/) Team($25/シート/月、最低 5 シート)は年間 ~$2,400 を、そして n8n は数百ドルを足します。

**ミッドマーケット / Outreach tier(25 人以上の担当者):** **年間 $100K-$200K+** を見込んでください。Outreach のシート下限が支配的です。$130-180/シート/月での 25〜50 シートの最低ラインだけで年間 $46K-$108K になり、オンボーディング費用はその前です。同じ人員分の CRM シートと Clay Enterprise 契約(中央値で年間 ~$30K)が、総額を 6 桁の向こうへ押し上げます。

隠れたコストは 3 つのメーターと 1 つの人員項目に潜みます。Clay の 2 つのメーター、Apollo のシートごとの携帯と export のクレジット、Outreach のオンボーディングと管理のオーバーヘッド、そして n8n の glue を所有する ops の時間です。コミットする前に、実際のリストサイズに対して Clay の 2 つのメーターをモデリングしてください。20 行のテストテーブルを作り、実行ごとのクレジットとアクションのコストをログで読み、そこから外挿します。ここがチームを驚かせる項目です。

## このスタックが正しい選択となるとき、そしてそうでないとき

選ぶべきなのは、アウトバウンドが主要チャネルであり、n8n と Clay の構築を所有する人がいて、アカウントごとのパーソナライゼーションが返信率を動かすほど ICP が具体的なときです。それが重心です。spray-and-pray を卒業したものの、アウトバウンドを完全自律のエージェントに渡す準備はまだできていない、$5-50M ARR の B2B SaaS チームです。

3 つのケースでは見送ってください。インバウンド主導なら、この大半は遊休状態になります。Apollo と Outreach を外し、[Default](/en/tools/default/) か [Drift](/en/tools/drift/) や [Intercom](/en/tools/intercom/) のようなチャットレイヤーでルーティングしてください。統合とエンリッチメントの構築を誰も所有しないなら、「各レイヤーに AI」という前提は 6 つのつながらないログインへと崩れ、オールインワンのほうがうまく役立ちます。そして $10M ARR 未満なのにブランド目当てで Outreach に色目を使っているなら、やめてください。そのシート最低ラインは買いすぎを強います。人員が本当に 25 担当者を超えるまでは Apollo のシーケンサーに留まってください。

## よくあるバリエーション

- **アカウントベースのモーション(ABM)。** インテントとアカウントスコアリングのために [6sense](/en/tools/6sense/) か [Demandbase](/en/tools/demandbase/) を加え、それらのシグナルを Clay のリスト構築へ流し込みます。[ABM スタック](/en/stacks/abm-revenue-stack/)が正しい参照先です。マーケティングとセールスが量のアウトバウンドではなく指名アカウントのプレイを回すときに切り替えてください。
- **エンタープライズ / 戦略的アウトバウンド。** HubSpot を [Salesforce](/en/tools/salesforce/) に置き換え、予約済みのミーティングに対するカンバセーションインテリジェンスのために [Gong](/en/tools/gong/) か [Chorus](/en/tools/chorus/) を加えます。ディールの複雑さとコーチングの規模が価格を正当化するときに切り替えてください。それより前ではありません。
- **完全自律の下位 tier。** 最も価値の低いセグメントを [Regie AI](/en/tools/regie-ai/) のような AI SDR に任せ、人間の担当者はアッパーミッドマーケットに残します。[AI SDR スタック](/en/stacks/ai-sdr-stack/)が専用の構築です。Clay からシーケンサーへの流れを手作業でさばける量を超えたときに切り替えてください。
- **AI ネイティブな CRM の土台。** CRM をゼロから始め、HubSpot ではなく API ファーストの基盤が欲しいなら、[AI ネイティブ CRM スタック](/en/stacks/ai-native-crm-stack/)を見てください。同じ Clay + Claude + n8n の背骨で、システムオブレコードが異なります。

## このスタックが置き換えないもの

- 自律に踏み切るべきかどうかの判断。担当者をエージェントに置き換える前に、[AI SDR が実際に何をするか](/en/learn/ai-sdr/)を読んでください。
