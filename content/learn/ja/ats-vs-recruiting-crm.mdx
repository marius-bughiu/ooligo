ATS（応募者追跡システム）と採用CRMは、現代の採用スタックの2つの関連しているが異なるツールです。ATSは*応募した*候補者を採用ファネルを通じて追跡します（応募 → スクリーニング → 面接 → オファー → 採用）。採用CRMは、より広い候補者の関係を管理します（チームがこれまでにソース、コンタクト、話し、不採用にしたすべての人を含み、応募したかどうかに関わらず）。成長段階とエンタープライズのほとんどのチームは両方が必要です。SMBは通常、ATSだけから始めて後でCRMを追加します。

## 実質的な違い

| 機能 | ATS | 採用CRM |
|---|---|---|
| アクティブな応募者を追跡 | ✓ | ✓（場合によって） |
| パッシブな候補者を追跡（ソース済み、未応募） | なし | ✓ |
| 再エンゲージのために不採用候補者を追跡 | 限定的 | ✓ |
| 求人掲載 + マルチボード配信 | ✓ | なし |
| 面接スケジューリングとスコアカード | ✓ | なし |
| オファー管理 | ✓ | なし |
| 候補者へのアウトバウンドメールシーケンス | 限定的 | ✓ |
| タレントパイプライニングとナーチャリング | なし | ✓ |
| ソーサー/採用担当者の日常ワークスペース | なし | ✓ |
| 採用-充足メトリクスのレポート | ✓ | 限定的 |

ATSはファネル追跡システムです。採用CRMは関係追跡システムです。「候補者データベース」では重複しますが、ワークフローでは大きく分岐します。

## 両方が必要なとき

自然な進行：

1. **ステージ1（年間50人未満の採用）：** ATSだけ（[Workable](/ja/tools/workable/)、[Ashby](/ja/tools/ashby/)、[Greenhouse](/ja/tools/greenhouse/)）。ソース候補者は関連する求人に直接追加され、アウトバウンドは非公式です。
2. **ステージ2（年間50〜200人の採用）：** ATSの上に採用CRM（[Gem](/ja/tools/gem/)がこの移行の支配的な選択肢）を重ねます。ソーサーはCRMで作業し、採用担当者はATSで作業し、データは同期します。
3. **ステージ3（年間200人以上の採用）：** 両方のツールが成熟して統合されています。場合によってはポートフォリオレベルの分析のための第3のプラットフォーム（Findem、Eightfold）が上部に位置します。

一部のプラットフォームは両方であろうとします。[Bullhorn](/ja/tools/bullhorn/)はスタッフィング会社のATS+CRM（企業ATSとは異なるカテゴリー）です。[Gem](/ja/tools/gem/)は一部のセグメントの「ATS代替品」としてマーケティングしていますが、基本的には軽いATS機能を持つCRMです。

## ATSが具体的に行うこと

ATSは採用ファネルの記録システムです：

- 求人作成と承認ワークフロー
- LinkedIn、Indeed、Glassdoor、会社のキャリアサイトへの求人掲載
- 応募追跡（すべての求人に対するすべての応募者）
- スクリーニングワークフロー（採用担当者スクリーン、採用マネージャースクリーン）
- 面接スケジューリング、パネル構成、スコアカード
- オファー管理と承認
- 採用確認とオンボーディング/HRISへの移行

time-to-hire、source-of-hire、オファー承諾率などのメトリクスがレポートされるとき、それはATSデータからです。

## 採用CRMが具体的に行うこと

CRMは候補者の関係の記録システムです：

- 長期サイクルの候補者パイプライニング（チームが18ヵ月かけて2回話した上級エンジニア）
- パッシブ候補者へのアウトバウンドメールシーケンス
- タレントコミュニティ（ニュースレター購読者、イベント参加者）
- 以前に不採用にした候補者の再エンゲージ
- ソーサー生産性の追跡
- ソースから応募の分析（どのソーシングチャンネルが採用を生み出すか）

ソーサーが「プラットフォームエンジニアのロールに200人の候補者がパイプラインにいる」と言うとき、彼らはATSではなくCRMについて話しています。

## AIが状況を変える方法

従来のATS対CRMの分割は、[AIネイティブのソーシングツール](/ja/learn/ai-sourcing/)（[juicebox](/ja/tools/juicebox/)やますます[hireEZ](/ja/tools/hireez/)）によって挑戦されています。これらはLinkedIn以外のソースからのAI拡張候補者ディスカバリーを含むように「CRM」の意味を拡大します。ソーシングツールとCRMの境界はぼかされていますが、ATSとCRMの境界は鋭いままです。

## よくある落とし穴

- **CRMを早く購入しすぎる。** 年間50人未満の採用では、CRMはまだ持っていない問題を解決しています。
- **ATSをCRMとして扱う。** 「パッシブ候補者」をATS内で追跡すると、雑然としたデータと壊れたレポートを生成します。
- **2つのシステム、統合なし。** ATSとCRMが同期しない場合、ソーサーと採用担当者は別々の世界で作業します。
- **AI機能の主張に基づいて購入する。** 両カテゴリーともにAI機能を持っています。コミットする前に、特定の候補者タイプで実際に機能するかどうかを確認します。
