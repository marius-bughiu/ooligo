## 概要

Bland は、複雑で大量の電話業務のための音声エージェントプラットフォームです。インバウンドのサポート、アウトバウンドのキャンペーン、受付と本人確認といった用途を対象とし、主にスタック全体を 1 つのベンダーにまとめたいエンタープライズに販売されています。同社の差別化の賭けはインフラです。Bland によれば、音声認識、言語モデル、音声合成はすべて自社のサーバー上で動作し、サードパーティのモデルや音声ベンダーへの受け渡しはありません。これにより、AWS、GCP、Azure 上の VPC デプロイや、最も機密性の高いワークロード向けの完全なオンプレミス導入を提供できます。位置づけは、[Vapi](/ja/tools/vapi/) や [Retell AI](/ja/tools/retell-ai/) の「自分で作る」レイヤーと、[PolyAI](/ja/tools/polyai/) や [Parloa](/ja/tools/parloa/) のマネージドサービスのレイヤーの中間です。セルフサーブの API に加え、Enterprise ではフォワードデプロイドエンジニアが付きます。

San Francisco を拠点とし、共同創業者兼 CEO の Isaiah Granet が率い、Y Combinator の支援を受ける同社は、2026年6月16日に Dell Technologies Capital が主導し HubSpot Ventures が参加する 5,000万ドルのシリーズ C を実施し、累計調達額は 1億ドルを超えました。Fortune は、このラウンドの前に同社が 180 社の投資家から断られていたと報じています。同社は週に 350万件超の通話と 250 社以上のエンタープライズ顧客を報告しており、Samsara、Kin Insurance、CNO Financial Group の名前を挙げています。これらの通話量の数値はベンダーの自己申告です。

## CX・サポートのスタックで採用される理由

- **音声ループ全体を 1 つのベンダーで。** 文字起こし、モデル、音声が 1 つの通話時間レートで請求されます。予測すべき LLM の別料金がなく、これは Vapi でスタックを組み立てる際の主な不満点です。
- **最初のドラフトは Norm が作る。** 2026年3月にリリースされた Norm は、平易な英語の説明を、プロンプト、会話フロー、検証条件、抽出ルールを備えたエージェントに変換し、デプロイ前に合成の発信者を相手にエージェント同士のシミュレーションを実行します。Bland はこれを、フォワードデプロイドエンジニアがかつて手作業で行っていたことをコード化したものと位置づけています。Norm はトークン単位で別途課金され、そのレートは請求ドキュメントで公開されていません。
- **規制業種の購買者にも現実的な道がある。** Bland は監査済みの SOC 2 Type I と Type II のレポート、ISO 27001、HIPAA BAA、GDPR DPA を備え、PCI DSS については自己証明しています。さらに 2026年8月には、音声、SMS、チャットのエージェントについて FedRAMP 20x Class A 認証を発表しました。BAA、SSO、データレジデンシー、オンプレミス/VPC デプロイは Enterprise 限定です。
- **独自の音声。** 2026年8月にリリースされた Bland Speech v3 が現行の音声モデルです。Bland 自身のベンチマークでは、リアルさで人間の録音に次ぐ 2 位とされています。この順位を裏付ける独立したベンチマークはありません。
- **開発者向けの機能。** Calls API、TTS API、CLI、そして Claude などのクライアントからエージェントを作成し通話を発信できる MCP サーバー (`npx bland-cli mcp`) があります。自社の Twilio や任意の SIP トランクの持ち込みにも対応しています。

## 価格の実態

Bland は 2025年12月5日に、以前の一律 $0.09/分のレートをプラン制に置き換えました。Start はプラットフォーム料金がなく、接続 1 分あたり $0.14 で、同時接続 10 通話、1 日 100 通話が上限です。Build は月 $299 に加えて $0.12/分で、同時接続 50 通話、1 日 2,000 通話です。Scale は請求ドキュメントには掲載されていますが公開の価格ページにはなく、月 $499 に加えて $0.11/分、同時接続 100 通話、1 日 5,000 通話です。Enterprise は個別見積もりで、上限なしの通話量、専用のオーケストレーションサーバー、コンプライアンス関連の書類はここで提供されます。

分単価はほぼすべて込みですが、その周りに 3 つのメーターがあります。Bland の電話回線でのアウトバウンドの発信試行には、応答の有無にかかわらず 1 回あたり $0.015 の最低料金がかかります。Bland の番号で人間に転送した後の時間は、プランに応じて $0.03–$0.05/分で課金され、自社の通信事業者を持ち込めば無料です。SMS は 1 通あたり $0.02 です。

月 100,000 分の場合、Build は月約 $12,300、Scale は月約 $11,500 となり、転送と発信試行を除いて年間およそ $140K–$150K です。100,000 件の番号に発信するアウトバウンドキャンペーンでは、発信試行の料金だけで $1,500 が加わります。これは標準的な Retell 構成 (約 $0.15/分) と同じ水準で、Vapi の月 $999 の Pro の最低料金を加える前の標準的な Vapi 構成 (すべて込みで $0.09–$0.14/分) とも重なります。

## こんなチームに向く

規制のある、または大量の電話業務を運用する中堅・大企業の CX-ops、サポート、RevOps のリーダーです。保険の受付、医療の予約、行政サービス、月 100,000 分以上のアウトバウンドでのリード選別などが該当し、音声認識、モデル、音声を 1 つの契約でカバーしたく、VPC、オンプレミス、FedRAMP が「あれば望ましい」ではなく必須要件であるチームに向きます。

チームがエージェントごとに LLM と音声を自分で選びたい場合、月の利用が数千分に満たない場合、あるいは Enterprise 契約なしで HIPAA BAA が必要な場合は見送ってください。

## 代替候補との比較

**[Vapi](/ja/tools/vapi/)** は普及度で見た開発者向けの定番で、処理した通話は 10 億件を超え、2026年5月に 5,000万ドルのシリーズ B を実施しました。エンジニアがあらゆる構成要素を入れ替えたいなら Vapi、その入れ替えこそが問題で 1 つのメーターが欲しいなら Bland を選んでください。**[Retell AI](/ja/tools/retell-ai/)** はもう 1 つの大量通話向けの定番です。小規模なチームが自分で署名できる BAA と全通話への組み込み QA を必要とするなら Retell AI を選んでください。**[ElevenLabs](/ja/tools/elevenlabs/)** は ARR 5億ドル超で最も成長が速い新規参入です。音声品質と言語カバレッジがプロジェクトの決め手なら ElevenLabs です。構築者がエンジニア以外でなければならないなら **[Synthflow](/ja/tools/synthflow/)** を選んでください。エージェントの設計と運用をベンダーに任せたいなら、マネージド型を買ってください。PolyAI、Parloa、[Sierra](/ja/tools/sierra/) です。コンタクトセンターがすでに [Genesys Cloud](/ja/tools/genesys-cloud/)、[NICE CXone](/ja/tools/nice-cxone/)、[Five9](/ja/tools/five9/) で動いているなら、まずそれらのネイティブ AI エージェントを自社の containment 基準で試してください。

どれも合わないなら、通話量が最も多い 1 つのインテントを Bland の無料の Start プランと 1 つの代替候補に 2 週間載せ、定価ではなく、解決した通話 1 件あたりの実測コストを比較してください。

## 注意点

- **2026年11月15日にビルダーの強制移行があります。** Bland のドキュメントによると、本番環境のパスウェイとペルソナはこの日までに新しい Agents アーキテクチャへ移行する必要があり、他のプラットフォームからのワンクリックインポートはありません。ガード: 各パスウェイの JSON を API 経由でエクスポートし、まず本番以外のコピーを移行して、トラフィックを切り替える前にシミュレーションスイートを再実行してください。
- **性能とリアルさの主張は自社発表です。** 200ms の応答時間とリアルさのベンチマークは Bland 自身のサイトによるものです。ガード: パイロットで自社の番号を使ってエンドツーエンドの遅延と発信者の離脱を計測し、遅延の閾値を Enterprise の注文書に明記してください。
- **下位プランはアウトバウンドを制限します。** Start は 1 日 100 通話、Build は 2,000 通話までで、つながらなかった発信にも 1 件 $0.015 がかかります。ガード: プランを選ぶ前にダイヤラーのデータから 1 日の発信試行数とピーク時の同時接続数を見積もり、キャンペーン前にリストから不通の番号を除いてください。
- **コンプライアンスは Enterprise の向こう側にあります。** BAA、SSO、データレジデンシーは Build や Scale では利用できません。ガード: 通話が PHI や EU の個人データに触れるなら、本番に移行できないセルフサーブのプランでパイロットするのではなく、初日から Enterprise の価格で見積もってください。
- **スタック全体を持つことは、その障害も持つことです。** プラットフォーム内でフェイルオーバーできるサードパーティのモデルがないため、Bland のインシデントは全面的な障害になります。ガード: IVR に人間へのフォールバック番号を残し、電話回線は自社の Twilio または SIP トランクで運用して、番号を自社と一緒に移せるようにしてください。
