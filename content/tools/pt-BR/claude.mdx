## O que é

Claude é o assistente de IA de uso geral da Anthropic, disponível como produto de chat, API, agente de coding (Claude Code) e plataforma para rodar Skills personalizadas e integrações de ferramentas baseadas em MCP. Para times de operações, funciona como uma camada horizontal — drafting, sumarização, extração estruturada, pesquisa na web, workflows agênticos — que se integra com qualquer stack vertical que você já roda.

## Por que aparece em todo stack de RevOps

- **Skills + MCP.** Define workflows reutilizáveis uma vez e roda em Claude.ai, Claude Code e qualquer cliente compatível com MCP. Times de RevOps usam isso para enriquecimento de leads, research de contas, pricing de deal desk, prep de QBRs e análise de churn.
- **Contexto longo.** Janelas de 1M de tokens permitem despejar um trimestre de atividade do Salesforce, uma deal room de contratos ou um ano de tickets de suporte em um único prompt sem precisar de scaffolding de retrieval.
- **Tool use que realmente funciona.** Function calling nativo e loops agênticos multi-turno são confiáveis o suficiente para conectar a sistemas em produção via servidores MCP (HubSpot, Salesforce, Snowflake, BigQuery, Slack).

## Pricing

- **Free** — uso diário limitado
- **Pro** — $20/mês, acesso diário completo, contexto maior, projects
- **Max** — $100-200/mês, uso ampliado e acesso prioritário
- **Team / Enterprise** — por assento, inclui controles de admin e SSO
- **API** — pago por token; o pricing do Sonnet torna workflows de conteúdo de alto volume econômicos

## Melhor para

- Qualquer time de RevOps, Legal Ops ou Recruiting padronizando um único assistente para análise, drafting e workflows agênticos
- Times adotando MCP para conectar IA ao seu CRM, data warehouse ou repositório de documentos
- Engineers construindo ferramentas internas que querem um agente de coding que lida com contexto longo

## Pontos de atenção

- A qualidade do output depende fortemente da qualidade do prompt — invista em skills/templates em vez de prompts ad-hoc
- Algumas integrações (por exemplo, com CRMs legacy) precisam de um servidor MCP que você vai escolher de um diretório ou construir você mesmo
