## 概要

Claude Code は Anthropic のエージェント型コーディングツールです。自然言語でタスクを伝えると、リポジトリを読み、複数のファイルを編集し、シェルコマンドやテストを実行し、commit するか pull request を作成します。同じエンジンが複数のサーフェスで動きます。ターミナルの CLI、VS Code 拡張機能（Cursor にもインストール可能）、JetBrains プラグイン、Claude デスクトップアプリの Code タブ、ブラウザの claude.ai/code、そして Claude のモバイルアプリです。そのため、プロジェクトの `CLAUDE.md`、設定、MCP サーバーはどのサーフェスでも引き継がれます。一般公開は 2025 年 5 月で、Anthropic 自身の 2026 年 2 月の資金調達発表によれば、年換算売上（run-rate）はすでに 25 億ドルを超えていました。

これはサブプロダクトのページです。[Claude](/ja/tools/claude/) はアシスタントと API を、[Claude Cowork](/ja/tools/claude-cowork/) はコードを書かない人向けのエージェント環境を扱います。Claude Code は、ops チームの中でコードを担当する人のためのツールです。

## ops スタックに載る理由

GTM エンジニアや RevOps の開発者は、ますます多くの連携コードを出荷しています。CRM 同期スクリプト、エンリッチメントのジョブ、自社製の MCP サーバー、[n8n](/ja/tools/n8n/) のコードノード、データウェアハウスのモデルなどです。現在その大半が Claude Code で作られており、理由は 4 つあります。

- **双方向の MCP。** [HubSpot](/ja/tools/hubspot/)、[Salesforce](/ja/tools/salesforce/)、[Linear](/ja/tools/linear/)、[Notion](/ja/tools/notion/)、[Slack](/ja/tools/slack/) の MCP サーバーに接続でき、自社の MCP サーバーを書いてテストする場所としても最速です。[MCP サーバーとは何か](/ja/learn/mcp-server-explained/)と[スキルがサーバーに勝つ場面](/ja/learn/claude-skill-vs-mcp-server/)も参照してください。
- **ヘッドレス実行。** `claude -p` はプロンプトを非対話で実行するため、CI、cron ジョブ、GitHub Actions や GitLab CI/CD のパイプラインに組み込めます。Agent SDK は同じツール群を公開しており、独自のエージェントを構築できます。
- **Routines。** `/schedule` で作成するクラウド上の定期ジョブで、ノート PC の電源が切れていても動き続け、API 呼び出しや GitHub のイベントをトリガーに起動できます。夜間のデータ品質チェックや、誰も覚えておく必要のない月曜日の依存関係監査がその例です。
- **共有されたリポジトリ指示。** バージョン 2.1.277（2026 年 9 月 18 日）以降、フォルダに `CLAUDE.md` がない場合、Claude Code は `AGENTS.md` を読み込みます。Codex など他のエージェント向けに設定済みのリポジトリも、指示を重複させずにそのまま使えます。両方のファイルがある場合は `CLAUDE.md` が優先されます。

## 価格の実態

Claude Code に単体の価格はありません。Claude のすべての有料プランに含まれ、Free には含まれません。

- **Pro** — 月額 $20、年払いなら月額 $17
- **Max** — 月額 $100 または $200、Pro の 5 倍または 20 倍の利用量
- **Team** — スタンダードシート 月額 $25（年払い $20）、プレミアムシート 月額 $125（年払い $100）、2〜150 シート
- **Enterprise** — 1 シート $20 に加え、API 料金で利用量を課金

シートを使わず、Anthropic Console の API キー、Amazon Bedrock、Google Cloud's Agent Platform、Microsoft Foundry 経由でトークン課金で使うこともできます。

プラン表が実際の数字ではありません。利用量は claude.ai のチャット、デスクトップアプリ、Cowork、Claude Code で共有され、2 段階の上限があります。5 時間のローリングウィンドウと週次の上限で、Anthropic は 2026 年中に週次上限を何度も調整しました。毎日終日コーディングすれば Pro シートは足りなくなります。そのために Max とプレミアムシートがあります。週に 1 本スクリプトを書くアナリストにはスタンダードの Team シート、メインツールとして使う人にはプレミアムシート（個人なら Max）を割り当て、ヘビーユーザー 1 人あたり月 $100〜$200 を計画値としてください。GitHub の自動 Code Review は Team と Enterprise でリサーチプレビューとして提供され、利用クレジットで別途課金されます。平均は 1 レビューあたり $15〜$25 です。

## 適しているのは

リポジトリを担当する GTM エンジニア、RevOps エンジニア、そして legal ops や recruiting ops の技術担当者です。CRM とウェアハウスの同期を保守する人、ディールデスク向けの自社 MCP サーバーを書く人、ATS のエクスポートパイプラインを構築する人が該当します。明確に勝てる場面は、テストを通し続ける必要がある既存コードベースへの複数ファイルにまたがる変更と、その後に同じジョブを定期実行または CI から起動するケースです。これで Team プレミアムシートの問いにも答えが出ます。そのコードを作ることが仕事である 1〜2 人にはイエス、それ以外の人にはノーです。

## 適していないのは

diff を読まない人です。Claude Code はシェルコマンドを提案・実行し、コードを commit します。受け取る側の誰も変更の正しさを判断できないなら、その人には [Claude Cowork](/ja/tools/claude-cowork/) かノーコードのビルダーを渡してください。また、大量かつ形の決まったパイプラインでフローツールの代わりにはなりません。ジョブが「これらのフィールドを毎時移す」になった時点で、Claude Code が書いたコードはエージェントのセッション内ではなく、n8n や自社のオーケストレーターで動かすべきです。

## 代替候補との比較

- **[GitHub Copilot](/ja/tools/github-copilot/)** — シート数で最大のインストールベースです。Business はユーザーあたり月額 $19、Enterprise は $39 で、2026 年 6 月 1 日以降は含まれる AI credits を超えた利用が別途計測・課金されます。組織がすでに GitHub Enterprise を購入しており、主なニーズが委任型の複数ステップのタスクではなく、多数の開発者向けのエディタ内補完である場合に選んでください。
- **[Cursor](/ja/tools/cursor/)** — 売上でトップのコーディング専業ライバルです。Bloomberg は、2026 年 3 月に年換算売上が 20 億ドルを超えたと報じました。個人プランは月額 $20 から、Teams はユーザーあたり $40 からです。IDE の中で作業し、すべての編集を視覚的に確認しながら操作したい人に選んでください。詳細な比較は [Claude vs Cursor](/ja/comparisons/claude-vs-cursor/) にあります。
- **OpenAI Codex** — 最も急成長している競合で、週間ユーザーは 2026 年 3 月の 200 万人超から 6 月には 500 万人超に増えました。ChatGPT Go（$8）、Plus（$20）、Business（年払いでユーザーあたり $20、月払いで $25）に含まれます。会社がすでに ChatGPT Business に標準化しているなら、新しいベンダーなしでコーディング用のシートが手に入るため、こちらを選んでください。OpenAI は 2026 年 6 月に Business プラン向けの新規 pay-as-you-go の Codex 専用シートの販売を終了しており、トークン課金での利用は現在 API キー経由になります。

## 注意点

- **auto mode が初期の権限モードになりました。** バージョン 2.1.283 以降、ターミナルと VS Code の対話セッションは auto mode で始まり、人の代わりに 2 つ目のモデルが各アクションを審査します。Anthropic 自身のドキュメントも「安全を保証するものではない」と述べています。対策：Team と Enterprise では、本番システムに触れるグループ向けに管理設定で `permissions.defaultMode` を指定するか `permissions.disableAutoMode` を `"disable"` にし、CRM に書き込む MCP ツールには `ask` ルールを追加し、無人のセッションはコンテナかサンドボックスで実行してください。
- **1 つの利用プールを多数が消費します。** routine、同僚のチャットセッション、あなたのコーディングセッションは同じシートの上限から消費し、その上限は自分では制御できない 5 時間のウィンドウでリセットされます。対策：定期実行の routine と CI ジョブには支出上限付きの専用 API キーを与え、暴走したジョブが午前 10 時にシートを必要とする人を締め出さないようにしてください。
- **Code Review のコストは push の回数に比例します。** リポジトリを「After every push」でレビューする設定にすると、平均 $15〜$25 に pull request あたりの push 回数が掛け算されます。対策：リポジトリは「Once after PR creation」か Manual から始め、有効化する前に claude.ai/admin-settings/usage で Claude Code Review サービスの月次支出上限を設定してください。
