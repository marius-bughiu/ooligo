A recruiter needs to know which statements in a sourced profile they can verify. This workflow turns approved excerpts into review cards for one job-related criterion. Each card keeps the original record ID, quotation and source together, so a colleague can check the reasoning before using the note.

## Try the three-record example

[Download the bundle](/artifacts/candidate-sourcing-claude-skill.zip) and extract it. From the extracted directory, run `python3 prepare_review.py examples/brief.json`. The sample and its output are in English. The command uses Python 3 and local files. You can inspect the [fictional input](/artifacts/candidate-sourcing-claude-skill/examples/brief.json) and [expected output](/artifacts/candidate-sourcing-claude-skill/examples/expected-review.json) side by side.

The role is a warehouse analytics lead. The recruiter wants evidence of a SQL check for duplicate shipment events. C-01 has an excerpt from work sample W-01 describing how shipment ID and event type were grouped. Its card says `verify_quote`. That excerpt supports a follow-up about false positives. It does not tell the reviewer how the check was validated. C-02 is marked `hold` and contributes only to the held count. C-03 has no excerpt and stays visible as `request_evidence`. The two cards keep their input order.

## Use it on an approved export

1. Write down the work task and agree on evidence the hiring team can recognize. The [structured interviewing guide](/en/learn/structured-interviewing/) can help frame a follow-up question.
2. Have the recruiter check source permissions and contact restrictions. Use pseudonymous IDs and the review or hold marker. A missing or unrecognized marker stops the formatter. The [review checklist](/artifacts/candidate-sourcing-claude-skill/references/2-fairness-checklist.md) describes decisions a person must make.
3. After checking each quote, use the [worksheet format](/artifacts/candidate-sourcing-claude-skill/references/3-shortlist-format.md) to record gaps. If you use [Claude](/en/tools/claude/) for a draft, provide only the cards cleared for that purpose. A recruiter decides the next step and separately approves any outreach.

Profiles from [Juicebox](/en/tools/juicebox/) or another source must already be available through an authorized export or your team's connector. The bundle contains a local formatter and drafting instructions. Retrieval, ATS updates and sending messages require separate tools. The review marker records a human decision and does not establish permission on its own.

## Check the result

The published check covers the fictional records above. For an operator trial, record how many quotes a reviewer can trace, which notes need correction and how long the review takes. No real candidates, vendor account, hiring outcomes or timing benchmark were used.
