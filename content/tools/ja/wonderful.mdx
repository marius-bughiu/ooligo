## 概要

Wonderful はエンタープライズ向けの AI エージェントプラットフォームです。非英語圏の市場で音声、チャット、メールに対応する顧客対応エージェントから始まり、現在は「the Enterprise AI OS」として販売されています。中身はエージェントビルダー、オーケストレーションレイヤー、そしてタスクの複雑さに応じて各リクエストをフロンティアモデルか小型モデルに振り分ける AI Gateway です。モデル非依存で、エージェント間でタスクを受け渡すための Google の A2A プロトコルに対応しています。2025年初頭に Bar Winkler (CEO) と Roey Lalazar (CTO) が創業し、本社はアムステルダム、従業員のおよそ半数はイスラエルにいます。

資金調達のペースはこのカテゴリーで最も急です。$34M のシード、2025年11月に Index Ventures がリードした $100M のシリーズ A、2026年3月12日に Insight Partners がリードした評価額 $2B での $150M のシリーズ B、そして2026年9月2日に再び Insight Partners がリードし、Salesforce が初めて出資した評価額 $5B での $550M のシリーズ C です。Calcalist によるとランレートは約 $70M、従業員は約650名で、シリーズ B 時点で Index Ventures が公表した350名から増えています。

## Customer Success のスタックに入ってくる理由

- **「ローカル設計」こそが製品の本体です。** [Sierra](/ja/tools/sierra/) と [Decagon](/ja/tools/decagon/) がまず米国英語のエンタープライズ量を前提に作られたのに対し、Wonderful は最初にイタリア、ギリシャ、ポーランド、ルーマニア、バルト諸国、UAE に進出し、現在は35か国以上で展開しているとしています。市場ごとに言語チューニング、規制への適合、現地の導入チームが付きます。サポート量がギリシャ語、コロンビアのスペイン語、トルコ語であれば、自社に近いリファレンスを持っているのはこのベンダーです。
- **規制業種での、社名と数値が出ている導入事例があります。** Telefónica 傘下の Movistar コロンビアは音声と WhatsApp で請求対応エージェントを運用しており、Wonderful は対象インタラクションでの封じ込め率を91.5%と公表しています。キックオフから本番稼働まで3週間でした。Banco Caja Social は督促エージェントを19日で本番に乗せ、6週間で43,000件超の架電を行い、接触から支払い約束への転換率を45%から65%に引き上げました。ギリシャの通信会社 OTE は8週間でコールのディフレクションが3倍になったと報告しています。3つの数字はいずれもベンダー公表値で、独立した監査は受けていません。
- **現地常駐のエンジニアが統合作業を担います。** Wonderful はエンジニアを顧客先に常駐させ、レガシーの請求、CRM、IVR システムにエージェントを接続し、構築物を引き渡します。社内 API が20本あり、統合チームに余力のない通信会社にとっては、これがパイロットと本番稼働の分かれ目になります。
- **銀行のセキュリティチームが受け入れられるデプロイ形態です。** AWS Marketplace の掲載情報には、マルチテナント、シングルテナント、自社クラウド持ち込みの各デプロイ形態、SOC 2 と GDPR への準拠、稼働率99.9%の SLA が明記されています。

## 価格の実態

公開料金表、トライアル、セルフサーブのプランはいずれもありません。公開されている唯一の目安は AWS Marketplace の掲載で、12か月のエンタープライズ契約が $2,500,000、単位と範囲はプライベートオファーで決まります。これは複数国かつ複数ユースケースの案件に対する上限寄りの目安であり、入口価格ではありません。1市場1ユースケースの契約はそれより低い金額で交渉されますが、金額を公表した購入者はいません。参考までに、Sierra の契約は年間 $150K–$350K+ 程度とされています。Wonderful の見積もりではなく ooligo の推定として、現地エンジニア付きのデプロイがこの帯を下回ることはないと見ています。自社側に CEO または COO クラスのスポンサーが必要になると考えてください。

## 最適な利用者

通信、銀行、保険、公益事業で英語以外の言語による大量の音声・チャット対応を抱え、請求、督促、保険金請求のプロセスをエンドツーエンドで実行するエージェントを必要とし、統合作業をベンダーに現地で担ってほしいカスタマーオペレーション責任者。

## 代替候補と選ぶ基準

- **[Salesforce Agentforce](/ja/tools/salesforce-agentforce/)**:サービスデスクがすでに Service Cloud 上で動いている場合。エージェントはデータモデルと権限をそのまま引き継ぎ、市場シェアもこの既存大手が握っています。課題が CRM との適合ではなく言語と現地のコンプライアンスにあるなら Wonderful を選んでください。
- **[Sierra](/ja/tools/sierra/)**:対応量の大半が英語で、解決件数に連動した成果報酬型の課金を望む場合。
- **[Decagon](/ja/tools/decagon/)**:サポートオペレーションチームが、ベンダーのエンジニアに頼らず自分たちでエージェントの手順を書いて調整したい場合。
- **[Parloa](/ja/tools/parloa/)**:電話チャネルが中心で、DORA に対応し分単位で課金する欧州の音声ファーストのベンダーを求める場合。
- **[PolyAI](/ja/tools/polyai/)**:音声のみのデプロイで、より長いエンタープライズ実績を重視する場合。

Wonderful 自体がこのセグメントで最も急成長している新規参入企業であり、だからこそ以下の注意点が重要になります。

## 注意点

- **性能の数字はすべてベンダー公表値です。** G2 のレビューも独立したベンチマークもまだありません。対策:自社と同じ言語・業種の顧客とのリファレンスコールを求め、パイロット開始前に封じ込め率の定義と測定方法を契約書に明記してください。
- **急成長はデリバリーを圧迫します。** 従業員数は6か月でほぼ倍増し、売り文句もサポートエージェントからあらゆるワークフロー向けの「AI OS」へと広がりました。対策:担当する常駐エンジニアを名指しで、引き渡し日とあわせて契約し、第1フェーズを1チャネル1プロセスに絞って、デリバリーチームがプラットフォーム全体のロードマップに分散しないようにしてください。
- **引き渡しがスキルの断崖を生みます。** モデルは「一緒に作り、その後引き渡す」です。構築期間中に自社チームが evals やプロンプト変更を回していなければ、エンジニアが去った後に封じ込め率は下がっていきます。対策:初週から自社のオペレーション担当を評価スイートの共同オーナーにし、文書化されたランブックをデリバリーのマイルストーンとして要求してください。
