[Sierra](/ja/tools/sierra/) と [Decagon](/ja/tools/decagon/) は、企業が実際に横並びで比較する、2023年設立の純粋なAIカスタマーサポートエージェント2社です。どちらも会話をエンドツーエンドで解決する自律エージェント（返金、本人確認、サブスクリプション変更など）を展開し、どちらもヘルプセンターから答えるだけでなくバックエンドのアクションを実行します。両者は形と、誰が制御を握るかで分かれます。Sierra はボイスファーストで成果ベース課金の CX プラットフォームで、高ボリュームの消費者向けブランドを対象とし、エージェントが規制対象（PCI スコープ）のワークフロー内でトランザクションを実行し、ベンダーがホワイトグローブの導入を運用します。Decagon は制御重視のデフレクションエンジンで、技術的な SaaS 組織を対象とし、非エンジニアがエージェントの振る舞いを Agent Operating Procedures として定義し、メーターは解決ごとに回ります。ルーティングの問い、つまり、消費者向けブランドのためにベンダーが運用するボイス兼トランザクションのエージェントが欲しいのか、それとも自社の ops チームが定義してチューニングする、参入価格の低い構造化されたデフレクションエージェントが欲しいのか、ということです。

## Sierra が勝つところ

**ボイスが主要チャネルであり、エージェントがトランザクションを完了させます。**Sierra のボイスエージェントは主要な接点として text を上回っており、コンタクトセンターの量が電話中心の場合に効いてきます。多くのサポートエージェントツールはいまだに chat のみだからです。そしてプラットフォームは PCI Level 1 に準拠しているため、エージェントは通話内で支払いを受け取り、返金を処理し、解約を引き止めることを、人間に引き継がずに行えます。これがチケットを回避することと、依頼を解決することの違いです。

**ベンダー運用の導入と、素早いエージェント作成。**Sierra はハイタッチなホワイトグローブモデルを運用しており、その Ghostwriter ツール（2026年3月にローンチ）は、SOP、通話の書き起こし、ホワイトボードのスケッチ、または自然言語の説明から本番対応のエージェントを構築します。エンジニアリングの待ち行列なしに新しいエージェントを立ち上げるチームにとって、これは初期構築を短縮します。

**消費者向け企業のためのブランド、規模、セキュリティ体制。**Sierra は Fortune 50 の約 40%（WeightWatchers、SiriusXM、Sonos、Nordstrom、ADT）と取引していると報告しており、2026年5月に約 200M USD の ARR に対し、15.8B USD のポストマネー評価額で 950M USD のラウンドを完了しました。セキュリティレビューと参照リストが購入を決める規制対象の消費者向けブランドにとって、この実績はロードマップの約束ではなく具体的なものです。

## Decagon が勝つところ

**自社の ops チームが振る舞いを定義します。ベンダーへのチケットではなく AOP です。**Decagon の差別化要因は Agent Operating Procedures です。技術者でない CS およびサポート ops のスタッフが、複数ステップのワークフローを自然言語で定義します。エンジニアリング主導の初期統合を配線し終えれば、カスタマーエクスペリエンスを所有する人々が、あらゆる調整をベンダー経由でルーティングする代わりに、エージェントの振る舞いを直接変更します。最大限の運用制御が欲しいなら、この作成の面が選ぶ理由です。

**高い mid-market ボリュームのための、より低い参入価格。**Decagon の報告されている構造は、おおよそ年間 50K USD のプラットフォーム料金に利用分を加えたもので、Sierra の6桁の下限を大きく下回ります。月に数万件の会話を扱い、消費者向けブランドのボイス導入なしにチケットのデフレクションが欲しい組織にとって、投資回収の計算はより早く始まります。

**プラットフォームに組み込まれた QA と実験。**Watchtower は常時稼働の QA を回し、Experiments はエージェントの振る舞いのライブ A/B テストを行うため、ops チームは書き起こしを別のツールにエクスポートせずに解決品質を監視しチューニングします。エージェント品質を動かすべき指標として扱うデータ駆動のサポート組織にとって、この閉じたループは後付けではなくネイティブです。

## 価格の実態

どちらも公開価格表のないカスタム見積もりなので、ステッカーではなく形と下限で比較してください。Decagon の報告されているモデルは、**年間約 50K USD のプラットフォーム料金に利用分を加えたもの**で、会話ごとか解決ごとか（報告では解決あたり約 0.50 USD）のいずれかで、エンタープライズ契約には会話の最低数が付きます。Sierra は**シート単位の要素がない成果ベース**です。エージェントがインタラクションを解決し、解約を引き止め、またはアップセルを完了したときに支払い、年間契約は **150K〜350K+ USD の帯**に収まります。

分岐点は、下限と成果への整合性の間にあります。Decagon の参入点は Sierra の約3分の1なので、純粋なデフレクションのボリュームではより早く回収し、月に数千件未満の会話ではより安全な賭けです。Sierra の成果ベース課金は、コストを人数ではなく解決された成果に結びつけます。1件の解決が料金よりはるかに価値がある高ボリュームでは魅力的です。ただし「解決」は契約で交渉される定義なので、何が課金対象の成功として数えられるかが、どちらかに署名する前に固めるべき最も重要な条項です。買い手が Decagon で過小に見積もる数字は、会話の最低数と解決ごとの課金が積み重なったときの利用のテールです。Sierra で過小に見積もる数字は、6桁の下限が回収されるのは、ボリュームと成果あたりの価値が本当にエンタープライズ規模の場合のみだ、ということです。

## 導入の労力

どちらもプラグインではありません。Decagon のオンボーディングは署名から本番まで約**6週間**かかり、最初の数週間はエンジニアリング主導です。CX の誰かが AOP を定義できるようになる前に、チームが CRM、helpdesk、データソースへの API 接続を構築します。ライセンス費用だけでなく ops の時間を予算に入れてください。Sierra のものは**ベンダー運用のエンタープライズプロジェクト**です。課金、CRM、PCI スコープの決済フローへの接続はセキュリティレビューを意味するので、まず高ボリュームの単一ジャーニーを絞り込み、現在のツールに対して封じ込めと精度のベースラインを設定し、絞り込んだパイロットでエージェントがそれを上回ってから初めて拡大してください。どちらの場合も、不可逆なアクション（しきい値を超える返金、解約）には厳格な上限と人間のレビューを維持し、エージェントが実行したすべてのトランザクションを初日から照合のために記録してください。

## 結論

**Sierra を選ぶ**のは、高ボリュームの消費者向けブランドであるとき、ボイスが主要チャネルであるとき、エージェントが PCI スコープのワークフロー内でトランザクションを実行しなければならないとき、そしてエンタープライズの参照リストと成果に整合した課金を備えたベンダー運用の導入が欲しいときです。ボイスファーストで、トランザクションを実行する、ホワイトグローブの選択肢です。

**Decagon を選ぶ**のは、自社の ops チームにエージェントの振る舞いを自然言語で定義させたいとき、より低い参入価格がデフレクションの計算をより早く回収させるとき、組み込みの QA と A/B テストが効いてくるとき、そしてビジネスがインターネットネイティブでチケットのデフレクション主導であり、ボイスと決済が重くないときです。制御重視で、下限がより低く、ops が作成する選択肢です。

決めきれない場合は、デフォルトで **Decagon** にしてください。より低いプラットフォームの下限、解決ごとの整合性、そして ops が定義する AOP により、消費者向けブランド規模の契約にコミットする前に、実際のボリュームでデフレクションを証明できます。ボイスが主要チャネルになった瞬間、またはエージェントが規制対象のフロー内で支払いを受け取り返金を処理する必要が生じた瞬間に、Sierra へ切り替えてください。

**どちらも選ばない**のは、サポートのボリュームが十分に低く、5桁または6桁の下限が回収できないとき（既存のヘルプデスク上の、より軽量でシート課金のデフレクターが勝ちます。[Zendesk](/ja/tools/zendesk/) または [Intercom](/ja/tools/intercom/) Fin）、あるいは、ハイタッチの専門ツールを上に足すよりも、すでに使っている CRM 内でエージェントを統合したいとき（[Salesforce](/ja/tools/salesforce/) Agentforce）です。
