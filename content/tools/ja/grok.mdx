## 概要

Grok は xAI が開発した AI アシスタントです。xAI は2026年2月に SpaceX に買収されました。2026年11月時点で x.ai のサイトは SpaceX Super Intelligence のブランドを掲げていますが、製品、grok.com アプリ、x.ai API は Grok の名前を維持しています。多くの人には X に組み込まれたチャットボットとして知られています。ops チームにとって重要なのは、2025年12月末に発表された組織向けの提供形態です。セルフサービスのチームプランである **Grok Business** と、営業経由で導入する **Grok Enterprise** です。2026年5月以降、どちらもコネクタ（Google Workspace、Microsoft 365、Notion、GitHub、Linear、Salesforce など）と、管理者が登録するカスタム MCP サーバーを通じて社内データにアクセスできます。

このページが答える問いは、Grok Business がチームの日常的なアシスタントとして [ChatGPT](/ja/tools/chatgpt/)、[Claude](/ja/tools/claude/)、[Gemini](/ja/tools/gemini/) に並ぶ有力な4つ目の選択肢になるのか、そしてその管理機能が何をカバーするのか、です。

## ops スタックで採用される理由

- **管理者承認制のコネクタ。** Business と Enterprise では、チーム管理者が xAI クラウドコンソール（Grok Business → Connectors）でコネクタを追加するまで、メンバーはそのコネクタを使えません。組み込みのコネクタは Gmail と Google Calendar、Google Drive、OneDrive、Outlook、Microsoft Teams、SharePoint、Salesforce をカバーし、カタログで Box、GitHub、Linear、Notion、Canva、Gamma、Vercel、Meltwater、S&P Global が追加されます。発表記事によると、SharePoint のドキュメント編集は Grok 4.3 で動作します。
- **独自 MCP の持ち込み。** 管理者は URL を指定してカスタム MCP サーバーを登録できます。そのため、MCP で公開した社内ツール（[Greenhouse](/ja/tools/greenhouse/) の MCP スコープやデータウェアハウスのクエリサーバーなど）を同じチャット画面から使えるようになります。
- **デフォルトで学習に使わない契約条件。** xAI の Business の発表では、顧客データを学習に使わないことを約束しています。Enterprise のアドオンである Vault では、専用のデータプレーン、アプリケーションレベルの暗号化、顧客管理の暗号鍵が追加されます。
- **低い API 価格で使える frontier モデル。** チームが API でも開発するなら、grok-4.7 の定価は 200k トークン未満のプロンプトで100万トークンあたり入力 $2.00 / 出力 $6.00（それを超えると2倍）で、コンテキストウィンドウは 500k です。

## 料金

- **Free / X Premium / SuperGrok** — 個人向けプラン。モデルを試すには十分ですが、社内データには向きません。チーム管理者もコネクタのガバナンスもビジネス向けのデータ条件もないためです。
- **Grok Business** — 1ユーザーあたり月額 $30、"Create Team" からセルフサービスで導入できます。各シートには SuperGrok 相当のアクセスが付き、アップグレードしたライセンスには SuperGrok Heavy の上限が適用されます。管理コンソール、チームとシートの管理、一括請求を含みます。xAI は最小シート数も Business の利用量の数値も公開していません。有料プランは週単位の共有利用プールから消費し、追加の利用クレジットは $5 から販売されています。
- **Grok Enterprise** — 個別見積もり。カスタム SSO、SCIM によるディレクトリ同期、高度な監査とセキュリティ管理、カスタムの保持ポリシー、個人ワークスペースを無効にするオプションが追加されます。
- **Vault** — Enterprise のアドオンで、見積もりのみです。

20シートの ops チームでの現実的な目安は、Business で月額 $600 です。SSO が必要になった時点で Enterprise は調達の交渉事項として扱い、Business より割高な予算を見込んでください。

## 最適な用途

- **すでに X や SuperGrok を使っている RevOps または ops チーム**で、既存の個人利用を、学習に使わない条件付きの管理されたチームプランへ移したい場合。
- **モデルの多様性のために2つ目のアシスタントを求めるチーム** — たとえば RevOps のリードが、アカウント調査やフォーキャストの説明を経営陣に上げる前に、別の frontier モデルでクロスチェックする場合です。

セキュリティレビューで初日から SSO と文書化されたコンプライアンス資料が求められる legal ops や recruiting のチームにとっては、第一候補ではありません。その場合は Enterprise と、より長い調達サイクルが必要になります。

## 代替と、代わりに選ぶ基準

- **ChatGPT Business / Enterprise** — 市場シェアの首位。最も幅広いコネクタカタログ、カスタム GPT、最も多くのサードパーティ連携が欲しいなら、これを選びます。
- **Microsoft 365 Copilot** — もう一方の既存大手。ドキュメント、メール、ID がすでに Microsoft 365 と Entra にあるなら、これを選びます。データ境界と権限はテナントにそのまま付いてきます。[Microsoft 365 Copilot](/ja/tools/microsoft-365-copilot/) を参照してください。
- **Claude Team / Enterprise** — ビジネスシートで最も成長の速い新規参入者。長文ドキュメントの推論、契約やポリシーの業務、そして [Claude Code](/ja/tools/claude-code/) と Skills によるエージェント型の業務には、これを選びます。
- **Gemini for Google Workspace** — Google Workspace を中心に使っていて、別途コネクタを設定せずに Docs、Gmail、Drive の中でアシスタントを使いたいなら、これを選びます。
- **[Perplexity](/ja/tools/perplexity/) Enterprise Pro** — 求めているのが汎用アシスタントではなく、出典付きの Web リサーチなら、これを選びます。

ルールはこうです。Grok が勝つのは、チームがすでに Grok を使っていてその上にガバナンスを載せたい場合か、意図的に2つ目のモデルファミリーを求める場合だけです。それ以外では、自社の ID プロバイダーと結びついた既存大手のほうが安く展開できます。

## 注意点

- **ブランドと評判のレビュー。** Grok Business は、Grok の画像生成が性的なディープフェイクを生成したことをめぐる公の論争のさなかにローンチされ、複数の国で規制当局の調査を招きました。対策：展開前にベンダーをセキュリティ部門と広報部門のレビューにかけ、チームの利用をテキストとデータの業務に限定する利用規定を作成してください。
- **SSO と保持設定は Enterprise のみ。** Business にはカスタム SSO も SCIM もカスタムの保持ポリシーもありません。対策：セキュリティポリシーで SSO や保持スケジュールが必須なら、Business で試験導入して後から移行するのではなく、最初から Enterprise の予算を組んでください。
- **コンプライアンスの証拠はローンチページにありません。** Business の発表では SOC 2 や ISO 27001 への言及はなく、サイトには DPA と BAA へのリンクがあります。対策：候補者、契約、顧客のデータを入れる前に、最新の SOC 2 レポートと署名済みの DPA を請求してください。
- **カスタム MCP は公開されている必要があります。** カスタム MCP サーバーはパブリックインターネットから到達可能でなければならず、ローカルサーバーにはトンネルが必要です。対策：社内の MCP サーバーは OAuth と許可リストの背後に置き、Grok が何を呼び出しているかを監査ログで確認できるまでは読み取り専用に絞ってください。
- **シートごとの利用上限は公開されていません。** 週単位の共有プールのため、ヘビーユーザーの消費を予測しにくくなります。対策：シート数を確定する前に、最もヘビーなユーザーで2週間の試験導入を行い、クレジットの消費を追跡してください。
