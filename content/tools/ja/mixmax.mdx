## 概要

Mixmax は Gmail の中で動くセールスエンゲージメントツールです。シーケンス（メール、電話、タスク、LinkedIn のステップ）、開封・クリックのトラッキング、ワンクリックの日程調整、テンプレート、フォローアップのリマインダー、AI による会議メモ、CRM への記録を、別のプラットフォームを開くことなく、Chrome 拡張機能を通じて担当者の受信トレイから実行します。サンフランシスコの独立系企業で、送信インフラのツールでもデータプロバイダーでもありません。コンタクトデータベースは持たず、担当者が誰に送るかをすでに把握していることを前提にしています。

これは、私たちの[セールスエンゲージメントプラットフォーム比較](/ja/vs/best-sales-engagement-platforms-2026/)が Mixmax を「カテゴリー違い」と分類した際に触れなかったトレードオフです。Gmail で仕事をするアカウントエグゼクティブのチームや小規模な営業チームにとって、Mixmax は [Outreach](/ja/tools/outreach/) や [Salesloft](/ja/tools/salesloft/) で実際に使う機能の大半を、数分の一の価格で、ほぼ導入作業なしにカバーします。できないのは、大量送信を行う SDR 部隊の運用です。

## 価格の実態

Mixmax は2026年に4回、料金体系を変更しました。2026年10月から有効な現行版では、旧来の Inbox、Engagement、Suite、Teams の各プランが廃止されています。現在は全機能を含む有料プランが1つだけで、各ユーザーが毎月シーケンスに追加できる人数に応じてユーザー単位で価格が決まります。

- **Free**：月50宛先、機能制限あり、MCP 利用不可
- **$29/ユーザー/月**：月100宛先
- **$89/ユーザー/月**：月1,500宛先（14日間トライアルはこの階層で動きます）
- **$129/ユーザー/月**：月3,000宛先

これらは年払いの価格です。月払いは割高になります。Mixmax によると年払いは階層に応じて15〜25%の割引で、$29の階層は月払いだと$34です。機能表には月最大15,000宛先とありますが、3,000を超える分は営業経由になります。ダイヤラー、カスタムブランディング、高度なワークスペースルール、Salesforce Insights パッケージはそれぞれ追加で$9/メンバー/月（月払いは$12）で、ダイヤラーの通話料は別途請求です。

請求額を決めるのはカウントのルールです。宛先とは、1つのシーケンスに追加された1人を指します。1人への5ステップのシーケンスは1件、シーケンス外で送ったメールはカウントされず、同じコンタクトが2つのシーケンスに入れば2件です。枠はユーザー単位で、暦月ごとにリセットされ、繰り越しもチーム内での共有もできません。

具体例で見ると、毎月約80件ずつ登録する AE 5人は$29の階層に収まり、チームで年$1,740です。毎月1,000件ずつ登録する SDR 5人には$89の階層が必要で、年$5,340です。それでも [Apollo](/ja/tools/apollo/) Basic の$49/ユーザー/月にデータ費用を加えた額より安く、導入費用を除いても約$100〜130/ユーザー/月と報告されている Outreach を大きく下回ります。

## 最適な利用者

- **Google Workspace を使う2〜25人の AE チームや創業者主導の営業チーム**で、既知のコンタクトへのフォローアップが中心となり、作業場所となる2つ目のアプリなしにシーケンス、トラッキング、日程調整を使いたい場合。
- **Salesforce や HubSpot に活動履歴を残したい RevOps 責任者**で、担当者に手入力を求めたくない場合。送信と返信はすべて自動で CRM に記録されます。
- **フォローアップをアシスタントに任せたいチーム。** MCP サーバーを使えば、Claude、ChatGPT、Cursor がシーケンスの成果や会議メモを読み取り、シーケンスを作成し、プロンプトからコンタクトを登録できます。

## MCP サーバー

Mixmax の MCP サーバーは2026年4月13日に Mixmax Labs を通じてベータ版として公開され、有料シートとトライアルで追加費用なしに使えます。API キーではなく OAuth を使い、各ユーザーには自分のデータだけが表示されます。読み取りはデフォルトで有効です。対象はシーケンスとその指標、宛先、テンプレート、会議の要約と文字起こし、タスクです。書き込み操作はそれぞれ個別のスイッチによるオプトインで、シーケンスの作成・編集、宛先の登録とシーケンスの有効化、テンプレートとタスクの作成、実際のメールの送信・予約が含まれます。Mixmax は、一部の機能が将来特定のプランに移る可能性があり、ツール一覧は安定性を保証するものではないとしています。

## 代替ツールとの比較

- **[Outreach](/ja/tools/outreach/) と [Salesloft](/ja/tools/salesloft/)** はセールスエンゲージメントのシェア上位です。ダイヤラー体制、テリトリーとチームの統制、案件の精査、マネージャーによるコーチングを1つの権限管理されたシステムで必要とする30人以上のアウトバウンド担当者を抱えるなら、どちらかを選んでください。担当者が受信トレイで仕事をし、そうした統制機能が使われずに終わるなら Mixmax を選んでください。
- **[Apollo](/ja/tools/apollo/)** はこの領域で最も急成長しているプレイヤーで、コンタクトデータベースとシーケンサーをセットで提供します。ボトルネックが「誰に送るかを見つけること」なら Apollo を、コンタクトがすでに CRM にあり課題がフォロースルーなら Mixmax を選んでください。
- **[HubSpot](/ja/tools/hubspot/) Sales Hub のシーケンス**は、HubSpot を使うチームにとっての現状維持の選択肢です。すでに Sales Hub Professional を契約しているならまずそのシーケンスを使い、担当者が Gmail の外で作業することを拒む場合にだけ Mixmax を追加してください。
- **Yesware** は最も近い受信トレイ型ツールで、担当者が Outlook で仕事をしている場合の標準的な選択肢です。

多数のドメインから大量のコールドメールを送るだけなら、Mixmax は不適切なツールです。[Instantly](/ja/tools/instantly/) か [lemlist](/ja/tools/lemlist/) を使ってください。

## 注意点

- **宛先カウントは重複するシーケンスに不利です。** 同じコンタクトが2つのシーケンスに入ると2件を消費し、ある担当者の未使用枠を別の担当者に回すこともできません。対策：購入前に、各担当者の過去3か月分のシーケンス登録を CRM から抽出し、各担当者の階層を本人のピーク月で見積もり、同じコンタクトを狙うシーケンスを統合してください。
- **Gmail を軸に作られています。** 製品は Gmail 用の Chrome 拡張機能です。Microsoft のマーケットプレイスには Outlook アドインが掲載されていますが、2026年の第三者レビューでは今も実質的に Gmail 専用と評価されています。対策：Outlook を使う担当者がいるなら、14日間トライアルに参加させ、シーケンス、トラッキング、日程調整が機能することを契約前に確認してください。
- **MCP は実際のメールを送信できます。** 「代理でメールを送信」やシーケンスの有効化をオンにすると、まずいプロンプトが実在の見込み客に届きます。対策：送信はオフのままにし、アシスタントには宛先を下書きとして登録させ、シーケンスの有効化は人が行ってください。
- **料金体系が変わり続けています。** 2026年だけで4回の変更があり、7月の旧 Teams プランへの上限設定と10月のモデル全面変更を含みます。対策：宛先の階層と更新時の価格上限を発注書に明記したうえで年契約を結び、更新のたびに料金ページを確認し直してください。
- **データは付いてきません。** Mixmax はコンタクトを探してくれません。対策：Apollo、ZoomInfo のシート、Clay のワークフロー など、データソースを別に予算化し、その合計コストを Apollo 単体と比較してください。
