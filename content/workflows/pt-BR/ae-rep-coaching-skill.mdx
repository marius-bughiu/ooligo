Uma skill do Claude que ingere as últimas dez calls de um AE pelo Gong e entrega uma nota de coaching: três coisas funcionando, duas pra apertar e um exercício específico pra próxima semana. Construída pra managers que querem coaching consistente mas não têm dez horas por semana pra escutar calls.

## O que você vai precisar

- Gong com a API de calls habilitada e transcripts disponíveis
- Claude.ai ou Claude Code
- A rubrica de calls do seu time (discovery, demo, negociação) como project knowledge
- Um canal de entrega semanal acordado com o AE: DM, email ou no próximo um-a-um

## Setup

1. **Instale a Skill.** `ae-coaching.skill` expõe `pull_recent_calls`, `analyze_against_rubric` e `render_coaching_note`.
2. **Autentique o Gong.** API key com acesso de leitura às calls e transcripts do AE. A Skill respeita o modelo de permissões do Gong; se as calls do AE estão restritas, a Skill não enxerga.
3. **Carregue a rubrica de call.** Rubricas distintas pra discovery, demo e negociação. A Skill auto-detecta o tipo de call pelo stage tag do Gong ou pede pro Claude classificar se está sem etiqueta.
4. **Configure o rep ID e o intervalo de datas.** Padrão são as últimas dez calls ou os últimos catorze dias, o que for mais curto.
5. **Decida a cadência de entrega.** Semanal é realista. Diária é demais. Mensal é raro demais. Agende pra sexta à tarde pra que o AE tenha o fim de semana pra absorver.

## Como funciona

A Skill puxa transcripts e metadados de calls, classifica cada uma por tipo de call e roda a rubrica relevante contra o transcript. O Claude pontua cada critério da rubrica, citando momentos específicos da call. Aí agrega pelas dez calls na estrutura três-dois-um: três padrões funcionando, dois padrões pra apertar, um exercício específico.

O exercício é o output mais importante. "Melhore o discovery" é inútil. "Nas suas próximas três calls de discovery, faça a pergunta de orçamento antes do minuto vinte" é acionável. A Skill é prompteada pesado pra deixar o exercício concreto e mensurável.

## Pontos de atenção

- **Calibração de tom.** Notas de coaching que se leem como avaliação de desempenho são ignoradas. A Skill é prompteada pra voz de "peer de confiança". Teste o tom com um dos seus AEs mais fortes antes do rollout.
- **Qualidade de transcript.** Calls com menos de cinco minutos, calls com mais de cinco participantes e calls com áudio ruim produzem análise barulhenta. Filtre agressivamente.
- **Alinhamento da rubrica.** Uma rubrica escrita pra discovery outbound aplicada a calls de demo inbound produz feedback irrelevante. Garanta que a rubrica bata com o tipo de call.
- **Dependência do manager-of-record.** Isso é uma ferramenta pro manager, não um substituto. A saída é um draft. O manager edita, contextualiza e entrega.

## Stack

- **Gong** — fonte de calls, camada de transcript, classificação de tipo
- **Claude** — scoring de rubrica e síntese
- **Doc de rubrica de call** — a lente que torna o feedback específico
