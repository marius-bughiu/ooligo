## 概要

Clarra は、請求台帳ではなく訴訟の docket（期日管理）を中心に設計されたクラウド型の案件管理システムです。案件、イベント、文書、連絡先、タイムエントリーは訴訟のライフサイクルに沿って管理され、案件をサブ案件に紐づけることで、マストート、集団訴訟、仲裁、調停の業務に対応できます。「docketing に送る」ステップを備えたメールログが、受け取った裁判所提出書面を期限の担当者に振り分けます。回収（リカバリー）モジュールは、和解のフェーズ、費用の分担、報酬の分配を当事者ごとに管理します。最も近いのは [Filevine](/ja/tools/filevine/) で、Filevine では重すぎると感じる事務所向けの価格と構成になっています。

本社は San Francisco にあり、2021年に創業しました。共同創業者の Todd Schneider は原告側の集団訴訟事務所 Schneider Wallace Cottrell Konecky のマネージングパートナーで、製品はこの事務所から生まれました。CEO は Keao Caindec です。2023年10月3日に商用提供を開始し、2026年6月2日に SOC 2 Type II の審査（Security 基準）完了を発表しました。

## Legal Ops のスタックに登場する理由

- **120以上のツールを備えたファーストパーティの MCP サーバーを提供しています。** 2026年8月19日、Clarra は250以上の REST API エンドポイントの上に120以上のツールを持つ MCP サーバーをリリースし、同月の ILTACON でデモを行いました。Claude Cowork、ChatGPT、Microsoft Copilot、Cursor から、案件データ、文書、メモ、期限、会計情報を読み取れるだけでなく、案件の更新、タスクの作成、ワークフローの設定といった書き込みもできます。[Clio](/ja/tools/clio/) や Filevine のユーザーは、サードパーティのオープンソースコネクタ経由で [Claude](/ja/tools/claude/) を利用しています（Oktopeak の Clio サーバーは26ツール）。Clarra のサーバーはファーストパーティで、規模は Oktopeak の4倍です。[MCP サーバーとは何か](/ja/learn/mcp-server-explained/)も参照してください。
- **原告側でも被告側でも、docket 中心の事務所向けに作られています。** Filevine の製品の出自は原告側の人身傷害（PI）です。Clarra の docketing、サブ案件の紐づけ、ポートフォリオダッシュボードは、保険防御、外部弁護士の訴訟を管理する企業法務部門、保険会社にも合います。
- **価格が公開されています。** 訴訟プラットフォームの多くはデモを経て見積もりを出します。Clarra は4つのプランのうち3つの価格をサイトに掲載しており、実データで案件モデルを試せる無料プランもあります。
- **文書は今ある場所に置いたままにできます。** Growth は SharePoint、OneDrive、Google Drive に接続します。Enterprise では [iManage](/ja/tools/imanage/) と [NetDocuments](/ja/tools/netdocuments/) に加え、Outlook、Gmail、Twilio のコミュニケーション記録が追加されます。

## 実際の価格

価格ページにはユーザー単位の料金が掲載されており、有料プランではユーザー数に上限はありません。

- **Free：**$0、5ユーザー、オープン案件5件、10 GB。
- **Essentials：**年払いで $59/ユーザー/月（年 $708）、月払いは $69。オープン案件は1,000件、ストレージは1 TB まで。REST API、手続規則、SSO はありません。
- **Growth：**年払いで $79/ユーザー/月（年 $948）、月払いは $89。案件数とストレージは無制限で、一括編集、インテーク、REST API、SSO、CalendarRules との連携が含まれます。
- **Enterprise：**見積もりのみ。会計、コミュニケーション、分析、AI による文書要約とタイムキーピング、文書生成、iManage と NetDocuments が追加されます。

Capterra にはいまだに $47 と表示されていますが、これは Clarra の2023年のローンチ価格で、情報が古くなっています。訴訟事務所にとっての実質的な最低ラインは Growth です。Essentials には手続規則に基づく期限計算がないからです。30ユーザーの事務所が Growth を使うと年間 $28,440 で、期限の連鎖計算には別途 CalendarRules の契約が必要です。iManage を使う事務所や AI 機能を求める事務所は Enterprise になります。MCP サーバーはどのセルフサービスプランにも含まれておらず、Clarra はその価格を公開していません。Growth の $79 は、後述する Litify の推定総コストの下限の約半分です。

## 最適な利用者

弁護士20〜500人程度（Legaltech Hub が Clarra の顧客層として挙げている規模）の訴訟事務所で、原告側・被告側を問わず、数百から数千件程度のオープン案件を抱え、Claude が稼働中の案件データを扱えるファーストパーティの MCP サーバーを求め、予算を立てるために公開価格が必要な訴訟マネージャーやリーガルオペレーション責任者に向いています。支出管理スイートではなく docket を必要とする企業法務チームや、保険の請求訴訟チームにも合います。

医療記録とデマンドレターの自動化に価値がある PI 事務所なら見送ってください。その分野では、Filevine と、その周辺に構築された専門の AI ツール（[EvenUp](/ja/tools/evenup/)、[Supio](/ja/tools/supio/)）のほうが深く対応しています。取引業務中心の事務所や、Enterprise の見積もりなしで会計機能を組み込みで使いたい事務所も見送るべきです。それは Clio のほうが安く実現できます。

## 代替製品との比較

**Filevine** は、原告側とマストートの案件管理でシェア首位の製品です。2025年9月に4億ドルを調達し、評価額は20億〜30億ドルと報じられています。PI やマストートの業務で1,000件以上の定型化された案件を扱い、医療記録とデマンドのワークフローをネイティブで使いたいなら、こちらを選んでください。価格は個別見積もりです（ooligo の [Filevine のページ](/ja/tools/filevine/)では、実質的な単価を $50–150/ユーザー/月としています）。公開価格、ファーストパーティの MCP サーバー、被告側の docket を求めるなら、Clarra を選んでください。

**Clio** は中小規模の事務所向けで利用数が最も多く、成長も最も速い製品です。2026年5月に ARR 5億ドルを突破しました。訴訟機能の深さよりも、請求、信託口座、クライアントのインテークが重要なら、こちらを選んでください。Clarra の期限連鎖が依存する手続規則エンジン CalendarRules も Clio が所有しています。サブ案件の紐づけとポートフォリオ単位の docketing が日常業務なら、Clarra を選んでください。

**Litify** は、大規模な原告側事務所や企業の法務チーム向けの Salesforce ネイティブの選択肢です。サードパーティのレビューでは、Salesforce のライセンスを含めて $150–300+/ユーザー/月、さらに3〜9か月にわたる $50,000–200,000+ の導入費用がかかると推定されています。事務所がすでに Salesforce を運用しており、管理者に余裕があるなら、こちらを選んでください。

どれも合わない場合、つまり法務部門に本当に必要なのが支出管理と電子請求であるなら、案件管理システムではなく [Mitratech](/ja/tools/mitratech/) や [Onit](/ja/tools/onit/) を検討してください。

## 注意点

- **独立したレビューの蓄積がありません。** Capterra のレビューは0件で、公開されている根拠はプレスリリースと LegalTech Breakthrough の2つの受賞（2024年と2025年）だけです。*対策：*自社と同程度の案件数・業務分野の参照顧客を2社紹介してもらい、契約前に無料プランで実際の案件5件を運用してください。
- **手続規則が競合他社の子会社に依存しています。** 期限の連鎖計算には別途 CalendarRules の契約が必要で、CalendarRules は2021年から Clio の傘下にあります。*対策：*CalendarRules の費用と対応管轄の一覧を Clarra と一緒に見積もってもらい、規則フィードの継続性を注文書に明記してください。
- **MCP サーバーは読み取りだけでなく書き込みもできます。** 案件の更新やワークフローの設定を行うツールがあるため、不適切なプロンプトで記録が変更される可能性があります。*対策：*AI クライアントには読み取り専用のロールから始め、案件のアクセス制御が MCP セッションにも適用されることを確認し、パイロット期間中は監査ログを毎週確認してください。
- **SOC 2 の範囲は狭く、取得も最近です。** 2026年6月のレポートは Security 基準のみを対象としており、監査人の名前も明らかにしていません。*対策：*秘匿特権のある資料を保存する前に、レポート全文とブリッジレターを求め、Confidentiality と Availability がロードマップにあるかを確認してください。
- **主要な機能は見積もりのみのプランにあります。** AI、iManage、NetDocuments、会計は Enterprise 限定です。*対策：*最初の打ち合わせで、Essentials ではなく実際に必要なプランの価格を確認してください。
