## 概要

Looker は Google Cloud のエンタープライズ BI プラットフォームで、LookML を中心に構築されています。LookML はコードで定義するセマンティックレイヤーで、データチームが「パイプライン」「net revenue retention」「アクティブアカウント」の意味を一度だけ記述します。以後、すべてのダッシュボード、定期配信レポート、AI の回答が、その定義を通じてデータウェアハウスをライブで照会します。BigQuery、Snowflake、Databricks、Redshift をはじめ大半の SQL データベースで動作し、Looker (original) と、Google Cloud アカウント経由で請求される Looker (Google Cloud core) の2形態があります。Google は Gartner の2026年版アナリティクス・BI プラットフォームの Magic Quadrant で、3年連続でリーダーに選ばれました。

2026年のテーマはエージェントです。2026年4月22日の Google Cloud Next で、Google は Looker BI Agents を発表しました。Conversational Analytics エージェント(すでに GA)は推論強化がプレビューで加わり、dashboard agents は既存のダッシュボード内で質問に答え、指標の異常を監視するスケジュール型のエージェント型ワークフローは10月9日にプレビューに入りました。ユーザー定義ダッシュボードと LookML ダッシュボード向けの data agents は10月8日に一般提供となりました。Looker が管理する MCP サーバーがプレビュー中で、オープンソースの MCP Toolbox にも対応しています。VS Code 向け Looker 拡張機能は9月10日に GA となりました。

Data Studio と混同しないでください。Google は2026年4月に Looker Studio の名称を Data Studio に戻したため、現在「Looker」はセマンティックレイヤーのプラットフォームだけを指します。

## RevOps・CS のスタックに入る理由

- **チーム間で指標の定義が1つになります。** RevOps で繰り返される対立は、財務、営業、CS がそれぞれ異なる ARR を報告することです。Looker では定義がバージョン管理された LookML にあり、すべてのチャート、定期配信、エージェントの回答がそれを継承します。スプレッドシート型の BI ツールではなく Looker を選ぶ最大の理由です。
- **エージェントは生のテーブルではなく、ガバナンスの効いた定義から答えます。** CSM が「今四半期に利用が30%落ちたアカウントは?」と尋ねると、QBR ダッシュボードと同じ LookML メジャーで計算された回答が返ります。データチームは verified queries(8月28日から GA)を設定でき、よくある質問に検証済みの回答を返せます。
- **Gemini Enterprise まで届きます。** Conversational Analytics エージェントは Gemini Enterprise に公開でき、8月5日以降はそのチャットで Looker のチャートが返ります。エンジニアは MCP 経由で [Claude](/ja/tools/claude/) や [Cursor](/ja/tools/cursor/) からセマンティックレイヤーを照会できます。

## 価格の実態

Google は年額料金を公開していません。価格ページには3つのプラットフォームエディションが記載されています。Standard(50ユーザー未満、クエリベースの API 呼び出しが月1,000回)、Enterprise(100,000回)、Embed(500,000回)で、いずれも Standard ユーザー10名と Developer ユーザー2名を含み、1年・2年・3年の契約期間で販売されます。これに Developer、Standard、Viewer の3種類のユーザーライセンスが加わります。2026年10月12日に確認された第三者による Google の SKU リストの読み取りでは、Standard は月約5,000ドル、追加ユーザーは月あたり Viewer 約30ドル、Standard 約60ドル、Developer 約125ドルです。

購入者データ: Vendr によると、Looker の契約額の中央値は418件の購入で年84,602ドル、購入者は最初の見積もりから約18%削減しています。追加ユーザー前の Standard の下限として年60,000ドル、数百人の viewer を抱える Enterprise では85,000〜150,000ドルを見込んでください。ウェアハウスのコンピュートは別請求です。

Conversational Analytics は「data tokens」で計測されます。月あたりの含まれるトークンは、Standard が入力60M・出力1.2M、Enterprise が300M・6M、Embed が1.2B・24M です。超過分は入力1M トークンあたり3ドル、出力1M トークンあたり20ドルですが、課金はまだ適用されていません。Google はクォータなしのプロモーション期間を続けており、課金開始の90日前に通知すると約束しています。

## 最適な対象

従業員200名以上で、モデル化されたウェアハウス(特に BigQuery)と、LookML を担当する analytics engineer が少なくとも1名いる企業の RevOps・CS ops リーダー。主な課題が50名超のレポート利用者の間で食い違う指標定義であり、その利用者がダッシュボードを開く代わりにチャットで質問するようになっている場合です。

チームに LookML を書く人がいないなら見送ってください。最初のモデルで止まるツールにエンタープライズ価格を払うことになります。Microsoft 365 E5 を使っている企業も見送ってください。Power BI Pro がすでにバンドルに含まれています。

## 代替ツールとの比較

**Power BI** はインストールベースで BI のトップで、Pro は1ユーザーあたり月14ドルです。レポーティングがすべての Microsoft 企業なら Power BI を選んでください。コードとしてレビューされ、ツールやエージェント間で共有されるセマンティックレイヤーが必要なら Looker を選んでください。

**Tableau** Cloud Creator の定価は1ユーザーあたり月75ドルです。訓練されたアナリストが高度なビジュアル探索を行うなら Tableau を選んでください。共有定義のガバナンスがビジュアルの自由度より重要なら Looker を選んでください。

**Omni** は最も急成長している新規参入者です。元 Looker 幹部が創業し、2026年4月に評価額15億ドルで1億2,000万ドルのシリーズ C を調達しました。売上は前年比4倍で成長しています。Looker 型のセマンティックレイヤーに、より速いスプレッドシート型のセルフサービスを求め、Google Cloud に縛られていないなら Omni を選んでください。BigQuery との深い統合と Gemini Enterprise への展開を重視するなら Looker を選んでください。

**[Sigma](/ja/tools/sigma/)** は、ビジネスユーザーがウェアハウスに書き戻す必要がある場合に勝ちます。**[Hex](/ja/tools/hex/)** は、SQL と Python のノートブックでの探索的分析が仕事の中心である場合に勝ちます。ソースデータがまだウェアハウスにないためにどれも合わない場合は、[data warehouse vs CDP](/ja/learn/data-warehouse-vs-cdp/) から始めてください。

## 注意点

- **LookML は開発者の仕事です。** セルフサービスの Explores や Expression Assistant は役立ちますが、恒久的な指標はすべて LookML にあります。*対策:* 契約前に analytics engineer を1名 LookML の責任者に指名し、その Developer ライセンスを予算に入れてください。セルフサービスの Explores は、後で LookML に昇格させるプロトタイプとして扱ってください。
- **Conversational Analytics の超過分はいずれ課金されます。** 無料期間は90日前の通知で終了し、Google は一般的な質問1件で消費するトークン数を公開していません。*対策:* トークン使用量の可観測性プレビューを今すぐ有効にし、60日間の利用をベースラインとして計測し、含まれる割り当てと超過料金を更新契約に明記してください。
- **Gemini Enterprise 連携はまだ安定途上です。** 公開済みの data agents は、Gemini Enterprise インスタンスの更新後に再公開が必要です。*対策:* 1チームでパイロットを行い、Gemini Enterprise の変更チェックリストに「Looker エージェントの再公開」を加えてください。
- **2026年の廃止により、使っている機能がなくなる可能性があります。** Looker reports は2026年7月13日に非推奨となり、単体の Spectacles サービスは2026年11月30日から終了し、2026年8月1日以降に作成された Google Cloud core インスタンスでは無償の Data Studio Pro ライセンスが提供されなくなりました。*対策:* レポート形式の出力は paginated reporting(GA)に移し、Spectacles のチェックは11月30日より前に Looker Continuous Integration に移行し、新規契約では Data Studio Pro を別途見積もってください。
- **Looker が照会するのはデータベースで、アプリケーションではありません。** CRM やヘルプデスクへのネイティブコネクタはありません。*対策:* まず [Fivetran](/ja/tools/fivetran/) などで [Salesforce](/ja/tools/salesforce/) と [Zendesk](/ja/tools/zendesk/) のデータをウェアハウスに取り込み、その ELT コストをビジネスケースに含めてください。
