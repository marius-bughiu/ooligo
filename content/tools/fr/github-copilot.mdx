## Ce que c'est

GitHub Copilot est l'assistant de programmation IA de GitHub, et en 2026 ce sont quatre produits sous une seule licence : la complétion inline et les suggestions de prochaine modification dans VS Code, JetBrains, Visual Studio et Xcode ; le chat et le mode agent dans l'éditeur ; un agent de code dans le cloud à qui vous assignez une issue et qui renvoie une pull request ; et Copilot code review sur les pull requests, plus la Copilot CLI. C'est l'acteur installé : Microsoft a annoncé 4,7 millions d'abonnés payants à Copilot en janvier 2026, en hausse de 75 % sur un an, et dans la plupart des organisations d'ingénierie il est déjà acheté avant que quelqu'un des ops ne pose la question.

Ce qu'il faut comprendre avant de lire une comparaison écrite avant juin : Copilot a changé de modèle de facturation. Depuis le 1er juin 2026, chaque offre est mesurée en **GitHub AI Credits** (1 crédit = 0,01 $), facturés selon les tokens d'entrée, de sortie et de cache au tarif API de chaque modèle. Les complétions et les suggestions de prochaine modification restent illimitées sur les offres payantes et ne consomment pas de crédits ; le chat, le mode agent, l'agent cloud, la CLI, Spaces et la code review, si.

## Pourquoi les équipes ops tombent dessus

Les GTM engineers, les RevOps engineers et la seule personne des legal ops ou des recruiting ops qui écrit du Python reçoivent généralement Copilot parce que l'organisation GitHub de l'entreprise l'a déjà. Leur question est celle de la facture de septembre : un siège Business à 19 $ suffit-il encore pour le travail agentique — construire un nœud [n8n](/fr/tools/n8n/), un script de synchronisation Salesforce, un serveur MCP — ou le groupe ops-dev doit-il passer à [Cursor](/fr/tools/cursor/) ou à Claude Code ?

La réponse dépend de la quantité de travail agentique que vous faites, car c'est ce que la baisse des crédits a frappé. En juin, juillet et août, GitHub a accordé un usage inclus promotionnel de 30 $ par siège Business et 70 $ par siège Enterprise. Le 1er septembre, il est retombé au standard de 19 $ (1 900 crédits) et 39 $ (3 900 crédits). Les équipes qui avaient calé leurs habitudes sur l'allocation de l'été ont atteint la limite du pool en septembre.

## La réalité des prix

Prix catalogue, vérifiés aujourd'hui sur la page des offres et dans la documentation de GitHub :

- **Free** — 2 000 complétions et un chat limité par mois.
- **Pro** — 10 $/mois ; 10 $ de crédits de base plus une allocation « flex » variable que GitHub affiche actuellement à 5 $.
- **Pro+** — 39 $/mois ; 70 $ de crédits affichés, flex compris.
- **Max** — 100 $/mois ; 200 $ affichés, flex compris. Ajouté quand les inscriptions individuelles ont rouvert en juin, après une pause commencée le 20 avril.
- **Business** — 19 $/utilisateur/mois, 1 900 crédits mutualisés à l'échelle de l'entité de facturation.
- **Enterprise** — 39 $/utilisateur/mois, 3 900 crédits mutualisés ; ajoute le chat sur GitHub.com avec indexation du code de l'organisation ; nécessite GitHub Enterprise Cloud, qui a son propre tarif par utilisateur.

Trois détails de facturation déterminent le vrai chiffre. Les crédits sont **mutualisés** : 10 sièges Business partagent 19 000 crédits, donc deux gros utilisateurs d'agents peuvent vider le pool de huit utilisateurs qui ne font que de la complétion. **Le dépassement payant est activé par défaut** pour les organisations, sans repli automatique vers un modèle moins cher. Et la Copilot code review sur les dépôts privés consomme aussi des **minutes GitHub Actions** depuis le 1er juin.

Un ordre de grandeur pour un groupe ops-dev de 10 personnes sur Business : 190 $ par mois de sièges. Si le groupe garde son usage de l'été — 30 $ de crédits par personne — il paie 110 $ par mois de dépassement, soit 30 $ effectifs par siège. C'est encore sous Cursor Teams à 40 $ et bien sous un siège premium Claude Team à 100 $ en annuel ; quitter Copilot se justifie rarement par le prix seul. Les nouvelles organisations doivent noter un point de plus : GitHub a suspendu le 22 avril les inscriptions en libre-service à Copilot Business pour les organisations sur les offres Free et Team, en renvoyant les nouveaux acheteurs vers les ventes, et n'avait pas annoncé de réouverture lors de notre vérification.

## Idéal pour

Un RevOps engineer, un GTM engineer ou un développeur proche des ops **dans une entreprise dont le code vit déjà sur GitHub**, qui veut de la complétion toute la journée et l'aide d'un agent quelques fois par semaine, et dont l'équipe sécurité préfère un fournisseur déjà sous contrat. Copilot gagne par sa portée : un siège couvre l'IDE, le terminal, la pull request et le gestionnaire d'issues, avec une politique d'organisation sur les modèles autorisés.

## Pas pour

Un profil ops qui construit surtout via de longues sessions agentiques — « lis ce dépôt, planifie l'intégration, écris-la et teste-la » — tous les jours. C'est l'usage que le modèle à crédits facture le plus durement, et c'est là que Claude Code et Cursor sont conçus pour dépenser des tokens. Pas non plus pour une équipe qui veut une liste de modèles stable : GitHub a retiré six modèles le 1er septembre et en prévoit six autres pour le 19 octobre.

## Face aux alternatives

- **[Cursor](/fr/tools/cursor/)** — le challenger le plus solide dans l'IDE, 20 $ en individuel et 40 $ par utilisateur sur Teams. Choisissez-le quand le travail se fait dans l'éditeur, que vous voulez l'expérience agent la plus capable et que vous acceptez de payer environ le double par siège.
- **Claude Code**, inclus dans les sièges [Claude](/fr/tools/claude/) Team (20 $ standard, 100 $ premium, en annuel) — l'outil à la plus forte croissance du segment. Choisissez-le quand le travail part du terminal : de longues sessions agentiques sur un dépôt entier ou sur des systèmes connectés via MCP.
- **OpenAI Codex**, inclus dans [ChatGPT](/fr/tools/chatgpt/) Business — choisissez-le quand l'entreprise est standardisée sur OpenAI et que vous préférez ne pas ajouter un fournisseur.

Garder Copilot pour la complétion et ajouter Claude Code pour le travail agentique est un partage courant et défendable ; voir [Claude vs Cursor](/fr/comparisons/claude-vs-cursor/) et [les meilleurs assistants de programmation IA](/fr/comparisons/best-ai-coding-assistants/).

## Points de vigilance

- **Le pool se vide en silence, puis la facture arrive.** Le dépassement est activé par défaut, et un utilisateur qui fait tourner l'agent cloud tout l'après-midi dépense les crédits de tout le monde. **Parade :** fixez des budgets par utilisateur pour les gros utilisateurs d'agents et un budget d'organisation dans AI Controls avant le premier mois complet ; si vous voulez un arrêt net, désactivez la politique « AI credits paid usage ».
- **La rotation des modèles casse les workflows figés.** Les retraits tombent toutes les quelques semaines, et un prompt ou un agent personnalisé réglé sur un modèle change de comportement avec son remplaçant. **Parade :** abonnez-vous au changelog de GitHub Copilot, gardez un petit jeu de prompts de régression pour chaque agent dont vous dépendez, et fixez les modèles autorisés via la politique globale de modèles plutôt que par choix individuel.
- **Une revue IA n'est pas une revue de sécurité.** Un rapport de Wiz diffusé en août a montré son Red Agent trouvant une injection de commande dans un workflow GitHub Actions du dépôt public `snowflake-connector-net` de Snowflake, qui exposait des identifiants Jira ; Snowflake l'a corrigée et a renouvelé l'identifiant le jour même. Que Copilot ait écrit la ligne vulnérable est contesté — Wiz a restreint son affirmation au fait que Copilot a relu la pull request sans signaler le problème. **Parade :** gardez CodeQL ou un autre scanner statique et un approbateur humain comme checks obligatoires sur tout fichier de workflow, et traitez une revue Copilot comme un signal, jamais comme la barrière.
