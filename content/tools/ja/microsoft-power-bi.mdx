## 概要

Microsoft Power BI は Microsoft Fabric の BI レイヤーです。Power BI Desktop(Windows 向けの無料のオーサリングアプリ)でセマンティックモデルとレポートを作成し、Power BI サービスがそれらを共有・更新し、質問に答えます。セマンティックモデル(テーブル、リレーションシップ、DAX メジャー)は、「パイプライン」「gross revenue retention」「アクティブアカウント」の意味を一度だけ定義する場所です。Salesforce、Dynamics 365、Snowflake、Databricks、BigQuery をはじめ、ほぼすべてのデータソースに接続できます。Gartner は2026年版アナリティクス・BI プラットフォームの Magic Quadrant で Microsoft をリーダーに選びました。19年連続です。

2026年のテーマは、セマンティックモデルが Power BI の外にあるエージェントに供給されるようになったことです。バルセロナで開催された FabCon Europe(2026年9月28日〜10月1日)で、Microsoft は Microsoft 365 Copilot Chat と Cowork における Fabric IQ を一般提供しました。ユーザーはレポートを開かずに、Power BI のセマンティックモデルに基づく回答を得られます。同じガバナンスの効いた回答をあらゆる MCP クライアントに返す Fabric IQ MCP サーバーと、Copilot Studio における Fabric data agents も GA になりました。Power BI Desktop でのエージェント型アプリ作成(アプリを説明すると、Copilot が信頼できるモデルから構築する機能)は、イベント後に順次展開されるプレビューとして発表されました。Power BI 内では、レポートの Copilot ペインが GA です。全画面のスタンドアロン Power BI エージェントとアプリ内 Copilot はまだプレビューです。Remote MCP サーバー(クエリ用)とオープンソースの Modeling MCP サーバー(モデルの構築・編集用)もどちらもプレビューです。

## RevOps・CS のスタックに入る理由

- **おそらくすでに支払っています。** Power BI Pro は Microsoft 365 E5 と Office 365 E5 に含まれています。E5 の企業にとって問いは「どの BI ツールか」ではなく「その上に何を足すか」です。
- **1つのセマンティックモデルを多くの利用者が使います。** CS リーダーが Copilot Chat に「今四半期に遅れた $50k 超の更新案件は?」と尋ねると、QBR レポートと同じ DAX メジャーで計算された回答が返ります。Copilot Studio で作った data agents も同じモデルの上に構築できます。
- **オペレーションのデータはもともと Microsoft にあります。** Teams、SharePoint、Excel での配信はネイティブで、Dynamics 365 Sales には自社製コネクタがあります。Salesforce はネイティブコネクタで接続できますが、ほとんどのチームはまずデータウェアハウスにロードします。

## 価格の実態

定価(2026年10月28日確認):**Free**(Desktop でのオーサリングのみ、共有不可)、**Pro** はユーザーあたり月額 $14、**Premium Per User** はユーザーあたり月額 $24 で、どちらも年間請求です。2025年4月に $10 と $20 から値上げされました。Pro または E5 をすでに持つユーザーは $14 で PPU を追加できます。

落とし穴は Copilot です。Pro や PPU のライセンスだけでは使えません。Microsoft のドキュメントは、有料の Fabric 容量(F2 以上)または Premium P1 を要件としています。Copilot の利用はその容量のコンピューティングユニット(CU)を消費し、トークン単位で課金されます。Microsoft の掲載価格は従量課金で F2 が月額 $262.80(1時間 $0.36)、F64 が $8,409.60 です。1年間の予約で約40.5%下がり、月額およそ $156 と $5,003 になります。

実際の価格帯:レポート利用者200人の E5 企業なら、レポート機能の追加費用は $0 で、Copilot を試す F2 予約に年間約 $1,900 かかるだけです。E5 のない企業は Pro に年間 200 × $14 × 12 = $33,600 を払います。F64 未満では閲覧者全員に Pro が必要です。F64 以上では無料ユーザーも共有コンテンツを閲覧できるため、F64 予約(年間約 $60,000)は閲覧者がおよそ360人を超えるとユーザー単位の Pro より安くなります。

## 最適な対象

Microsoft 365 を使う企業で、レポート利用者が50〜5,000人、データチームがすでに DAX を書いており、ガバナンスの効いた数字を新たな BI ログインではなく Copilot Chat と Teams に届けたい RevOps リーダーと CS オペレーションのリーダー。

Google Workspace と BigQuery で動いている企業や、業務ユーザーがデータウェアハウスのテーブルを編集・書き戻す必要がある場合は見送ってください。

## 代替との比較

**[Tableau](/ja/tools/tableau/)** はもう一つの長年の Gartner リーダーで、導入規模では Power BI の最大のライバルです。Creator はユーザーあたり月額 $75 です。訓練されたアナリストが本格的なビジュアル探索を行い、会社が Salesforce を使っているなら Tableau を選んでください。コストと Microsoft 365 への到達範囲で選ぶなら Power BI です。

**[Looker](/ja/tools/looker/)** は、コードレビューされた LookML のセマンティックレイヤーが欲しく、Google Cloud を使っている場合に勝ります。レポートの行き先が Teams と Copilot なら Power BI を選んでください。

**Omni** は最も急成長している新興勢力です。元 Looker 幹部が創業し、2026年4月に評価額15億ドルで1億2,000万ドルのシリーズ C を調達しました。Microsoft のスタック外で、Looker 型のセマンティックレイヤーとスプレッドシート並みの速さのセルフサービスが欲しいなら Omni を選んでください。

**[Sigma](/ja/tools/sigma/)** は、業務ユーザーが [Snowflake](/ja/tools/snowflake/) や Databricks に書き戻す必要がある場合に勝ります。**[Hex](/ja/tools/hex/)** は SQL と Python の探索的ノートブックで勝ります。CRM データがまだどこにもモデル化されていないためにどれも合わない場合は、[data warehouse vs CDP](/ja/learn/data-warehouse-vs-cdp/) から始めてください。

## 注意点

- **Pro には Copilot が含まれません。** E5 を買えば Copilot も付いてくると考え、ボタンが見つからないチームがあります。*対策:*パイロット用ワークスペースに F2 容量を1つ予約し、Fabric Capacity Metrics アプリで Copilot の CU を30日間観察してから規模を決めてください。あるいは Copilot の課金を専用の Fabric Copilot Capacity に移し、データ更新を圧迫しないようにします。
- **Q&A は2026年12月末に廃止されます。** 既存の Q&A ビジュアルは動作しなくなり、Microsoft は Copilot への移行を案内しています。*対策:*Q&A を使っているレポートを今すぐ洗い出し、それらの質問を Copilot の検証済み回答として作り直し、切り替え前に Microsoft の「AI 向けにデータを準備する」手順に従ってください。
- **セマンティックモデルへの AI アクセスは既定でオンです。** FabCon で発表された制御についてのコミュニティの解説によると、管理者がアクセスをオフにしない限り、モデルは Copilot Chat、data agents、リモート MCP サーバーに公開されます。*対策:*Copilot で Fabric IQ を有効にする前に、モデル単位の設定で、公式指標を持つ認定済みモデルだけを許可してください。
- **準備されていないモデルは、自信満々に誤った回答を返します。** Microsoft 自身のドキュメントも、名前が不明瞭で説明のないモデルを Copilot が誤解すると警告しています。*対策:*列名を業務用語に変え、メジャーに説明を追加し(下書きは Copilot に任せられます)、展開前に答えのわかっている実際の質問20件でテストしてください。
