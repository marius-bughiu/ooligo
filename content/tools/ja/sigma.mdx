## 概要

Sigma は、スプレッドシートの見た目で、すべてのクリックをクラウドウェアハウス(Snowflake、Databricks、BigQuery、Redshift、Postgres)へのライブクエリとして実行する BI ツールです。データを Sigma 独自のストアに抽出しないため、ウェアハウス側で設定済みの行レベルセキュリティや列マスキングが、作り直すことなくすべてのチャートに適用されます。Tableau や Power BI との違いは書き込み経路です。input tables を使うと、ビジネスユーザーがフォーキャスト、クォータ調整、アカウントメモをグリッドに入力でき、それがウェアハウスの行として保存されます。さらに actions でこれらの編集をフォーム、承認、API 呼び出しにつなげられます。これにより、ダッシュボードが小さなデータアプリになります。2026年4月、Sigma は Sigma Agents を追加しました。workbook 内で作るノーコードのエージェントで、スケジュールまたはイベントで起動し、ガバナンスの効いたウェアハウスデータを読み、書き戻し、Slack への投稿、Salesforce や HubSpot へのデータ送信を、起動したユーザーの権限のもとで行います。Sigma は2026年4月に ARR 2億ドル、前年比100%超の成長、2,000社超の顧客を発表し、2026年5月18日に Princeville Capital 主導で評価額30億ドルの8,000万ドルのシリーズ E を調達しました。Databricks、ServiceNow、Workday の各ベンチャー部門も参加しています。

## RevOps・CS のスタックに入る理由

- **書き戻しが「影のスプレッドシート」を置き換えます。** RevOps で繰り返される課題は、BI ツールが読み取り専用であるために、フォーキャスト会議、テリトリー計画、更新リスクレビューが Google Sheets に置かれていることです。Sigma では、AE のコミットや CSM のリスクフラグが、参照先の CRM データや製品利用データの隣にある input table の行となり、編集ログも残ります。input tables の編集に必要なのは Act ライセンスだけで、ビルダー席は不要です。
- **ガバナンスは再実装ではなく継承されます。** エージェントはユーザー権限をそのまま反映します。ユーザーがテーブルに書き込めなければ、そのエージェントも書き込めません。顧客 PII を含む製品テレメトリを照会する CS チームにとって、これが法務の承認を得られる理由です。
- **すでに使っている AI ツールの中で動きます。** Sigma の MCP サーバーを使うと、[Claude](/ja/tools/claude/)、[ChatGPT](/ja/tools/chatgpt/)、Codex、[Cursor](/ja/tools/cursor/) から OAuth 経由で Sigma のデータモデルを検索、説明、照会できます。2026年8月のパブリックベータでは、Sigma の AI 機能を自社の Anthropic API キーと契約で動かせます。

## 価格の実態

定価は公開されていません。ライセンスは View、Act、Analyze、Build の4段階で、これに利用クレジットと自社ウェアハウスの請求が加わります。クレジットが計上されるのは特定のイベントです。公開済み workbook で変更された input table の行ごとに1(1 action あたり上限100)、action からの API またはストアドプロシージャ呼び出しごとに1、ユニークなエクスポートファイルごとに1、エージェントへのメッセージごとに0.1です。ドラフトでの編集やドラフトへの CSV アップロードは無料です。

購買データ:Vendr によると、154件の購買で中央値は年間64,941ドル、範囲は15,585ドルから145,339ドルで、購入者は初回見積もりから平均24.6%下げて契約しています。帯域は10〜25ユーザーで20,000〜60,000ドル、25〜75ユーザーで60,000〜150,000ドルです。Build 席は View 席のおよそ3〜5倍なので、請求額を左右するのは人数よりライセンス構成です。本格的な RevOps 導入の下限として、ウェアハウスのコンピュート費用とは別に年間25,000ドルを見込んでください。

## 最適な対象

Snowflake または Databricks にモデル化済みのウェアハウスがあり、15〜100人のビジネスユーザーが、セルフサービスのレポートと、いくつかの書き戻しアプリ(フォーキャスト提出、テリトリーとクォータの計画、更新リスクレビュー)の両方を必要としている企業の RevOps・CS ops リードです。社内ツール用の別プラットフォームを立ち上げずに済みます。

クラウドウェアハウスがないなら買わないでください。Sigma には照会する対象がありません。Microsoft 365 E5 を使っている場合も見送りです。Power BI Pro がすでにバンドルされており、BI の追加コストはほぼゼロです。また、アプリの大半が UI と API のつなぎ込みで分析が少ないなら見送ってください。それは Retool の仕事です。

## 代替との比較

**Power BI** はインストールベースで見た既存の最大手で、2025年4月以降 Pro はユーザーあたり月額14ドルです。Microsoft 中心の企業で、レポートがすべてなら Power BI を選んでください。ビジネスユーザーがガバナンス下のデータを編集する必要がある場合や、ウェアハウスが Snowflake か Databricks で、データセットへのリフレッシュではなくすべてのクエリをライブで実行したい場合は Sigma を選んでください。

**Tableau** Cloud Creator の定価はユーザーあたり月額75ドルです。訓練されたアナリストによる高度なビジュアル探索なら Tableau を選んでください。対象がスプレッドシートに慣れた ops 担当者で、答えを書き戻す必要があるなら Sigma です。

**Omni** は最も急成長している新規参入者で、2026年4月に売上の前年比4倍成長を背景に、評価額15億ドルで1億2,000万ドルのシリーズ C を調達しました。Looker 型のガバナンスの効いたセマンティックレイヤーが優先で、書き戻しが不要なら Omni を選んでください。書き戻しとエージェントが目的なら Sigma です。

**[Retool](/ja/tools/retool/)** の契約中央値も同程度です(Vendr によると64,623ドル)。アプリがフォームと API 呼び出しで、分析はサイドパネル程度なら Retool を選んでください。アプリが、人が編集しチャート化するガバナンス下のテーブルなら Sigma です。Sigma で定義したセグメントをスケジュールで CRM に送るなら、フィールドごとに actions を作るのではなく [Hightouch](/ja/tools/hightouch/) と組み合わせてください。

財務、営業、CS の間で「アクティブなアカウント」の定義が一致しないためにどれも合わない場合、それはモデリングの問題です。[データウェアハウスと CDP の違い](/ja/learn/data-warehouse-vs-cdp/)を参照してください。

## 注意点

- **エージェントは2026年11月1日まで無料で、その後は有料になります。** Sigma の課金ドキュメントにそう明記されていますが、料金は公開されていません。*対策:*更新リスクやフォーキャストのエージェントを日常業務に組み込む前に、11月以降のエージェント価格と含まれるメッセージ量を発注書に明記させてください。
- **書き戻しのクレジットはユーザー数ではなく行数に比例します。** 毎晩2,000件のアカウント行を更新するスケジュール action は、1晩で2,000クレジットを消費します。*対策:*署名前に予定している actions からクレジット量を試算し、一括ロードはドラフトで行い(クレジットゼロ)、含まれるクレジットと超過料金を交渉してください。
- **ウェアハウスのコンピュート費用は Sigma の請求書に載りません。** すべての操作がライブクエリであり、レビューでは集計されていない大規模テーブルでの遅さが指摘されています。*対策:*Sigma を auto-suspend と resource monitor を設定した専用の小規模ウェアハウスに向け、重いモデルはマテリアライズし、Sigma に起因する費用を60日間追跡してください。
- **書き戻しのサポートはウェアハウスによって異なります。** BigQuery の input tables はパブリックベータ、Redshift では ra3.4xlarge 以上のノードが推奨され、Sigma Tables(workbook をまたいだ共有書き戻し)はプライベートベータです。*対策:*Sigma のサポート機能一覧ページで自社のウェアハウスを確認し、Sigma Tables が自社プラットフォームで GA になるまでは、単一 workbook の input tables を前提にアプリを設計してください。
- **MCP サーバーは読み取り専用です。** 検索と照会はできますが、現時点では input tables の編集や workbook の作成はできません。*対策:*書き込み操作は、権限と編集ログが適用される Sigma のワークフロー内にとどめ、MCP は分析専用に使ってください。
