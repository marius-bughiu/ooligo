## 概要

MillionVerifier は従量課金のメール検証サービスです。リストをアップロードするか API を呼び出すと、各アドレスが ok、catch-all、unknown、invalid、disposable のいずれかで返ってきます。サブスクリプションはなく、クレジットのパックを購入する方式で、有料クレジットに有効期限はありません。[ZeroBounce](/ja/tools/zerobounce/) や NeverBounce と同じカテゴリですが、機能ではなく価格で勝負しています。スコアリングモデル、インボックス到達テスト、ブラックリスト監視はありません。

2026 年に運営会社が変わりました。2026 年 10 月 19 日に公開された利用規約は、ニュージーランド企業の Southern Vector Limited を提供者としています。Southern Vector は、それまで運営していたハンガリー企業 GBD Software as a Service から MillionVerifier の事業資産を買収しました。規約によると、新しい運営会社は有効な未使用クレジットとクレジット台帳を引き継いでおり、事業譲渡によってクレジットを取り消したり、失効させたり、減らしたりすることはできません。ヘルプセンターのポリシー更新履歴には売却の記載がないため、多くの顧客は規約を読まない限り気づきません。

このページが答える問いは、MillionVerifier は今も Smartlead や Instantly の前に置く安価な一次チェックとして使えるのか、そして運営会社の変更で何か変わるのか、です。私たちの答えは、クレジットについては「使える」です。書面で保護されています。ただし、次の大規模アップロードの前にデータ条件を確認し直す必要があります。

## RevOps スタックで使われる理由

- **本格的な一括検証サービスの中で最も安価です。** 5 万件の検証が $89（1 件あたり $0.00178）、100 万件が $449 です。コールドメールチームは、より高価なツールを動かす前に明らかに無効なアドレスを取り除く一括チェックとして使っています。
- **catch-all は判定できた場合のみ課金されます。** MillionVerifier によると、同社の catch-all エンジンは catch-all アドレスの 30% から 40% を標準クレジット 1 つで有効か無効かに判定します。判定できなかった catch-all と unknown の結果は課金されません。
- **リストの送り先とつながります。** サイトには HubSpot、Pipedrive、Mailchimp、Smartlead（Smartlead の API キーで接続）を含む 40 の連携が掲載されています。単一アドレス用と一括用の REST API があり、各結果タイプを強制的に返すテストキーも用意されています。Zapier、Clay、Instantly は連携リストにないため、これらはアップロード前に CSV か API で検証します。

## 実際の価格

トップページで確認できる価格は 2 つです。5 万クレジットが $89、100 万クレジットが $449 です。パックは 1 万から 5,000 万まであり、それ以上はボリューム価格です。サイトではプランは $39 からとしています。新規アカウントにはカード登録なしで 100 クレジットが無料で付与されます。Auto Top-Up を有効にすると支払いごとに 10% のクレジットが上乗せされ、500 万クレジット購入ごとに 100 万クレジットが無料で付きます。

クレジットに有効期限がないため、定価よりも購入するパックの大きさが効いてきます。毎月 5 万件の新規アドレスを検証するチームが毎月 $89 のパックを買うと、年間 $1,068 になります。100 万パックなら $449 で 20 か月分をまかなえ、年間約 $270 です。同じ量を ZeroBounce の ONE サブスクリプションで処理すると年間約 $4,500 かかります。

## 最適な用途

Apollo、Clay、スクレイピングなどから毎月 2 万件から 100 万件のアドレスを検証する B2B チームのアウトバウンド・RevOps 責任者で、ドメインの大半が catch-all ではなく、無効なアドレスを最小コストで取り除くことが目的のケースに向いています。検証を再販するエージェンシーにも使えます。API ドキュメントで再販が明示的に認められています。

catch-all ドメインがリストの約 15% を超える場合、バウンスですでに送信ドメインを失ったことがある場合、またはセキュリティ審査で SOC 2 レポートが必要な場合は、唯一の検証ツールとして購入しないでください。MillionVerifier が公開している SOC 2 の証明は見つかりませんでした。調達を始める前に提出を求めてください。

## 代替ツールとの比較

**[ZeroBounce](/ja/tools/zerobounce/)** は市場のリーダーです。catch-all を 0 から 10 でスコアリングし、SOC 2 Type 2 を取得し、到達率ツールも販売しています。catch-all がリストの大きな割合を占める場合に選ぶか、MillionVerifier が返した catch-all と unknown の結果だけに対する二次チェックとして使ってください。そうすれば ZeroBounce で処理する量はリストの一部で済みます。

**NeverBounce** は現在 ZoomInfo 傘下にあるもう一つの老舗検証サービスで、1,000 件あたり約 $8、クレジットは 12 か月で失効します。すでにその CRM 同期を使っている場合にのみ選んでください。

**シーケンサー内蔵の検証** は最も伸びている選択肢です。[Instantly](/ja/tools/instantly/) はリード 1 件あたり 0.25 クレジットで検証し、[Smartlead](/ja/tools/smartlead/) はアップロード時のアドオンを販売しています。新規コンタクトが月約 5,000 件未満で、価格よりもベンダーを 1 つ減らすことのほうが重要な場合に選んでください。

どれも合わない場合、問題はリストの取得元にあります。[ウォーターフォール型エンリッチメント](/ja/learn/waterfall-enrichment/)で取得元を改善し、そのうえで[コールドメールのインフラスタック](/ja/stacks/cold-email-infrastructure-stack/)が示す位置に検証ツールを置いてください。

## 注意点

- **データの処理者が変わっている可能性があります。** 2026 年 8 月のプライバシーポリシーと DPA では GBD が管理者兼処理者とされており、準拠法は現在ニュージーランド法です。ニュージーランドには EU の十分性認定がありますが、DPA には現在データを保有している会社が記載されているべきです。*対策：* 次の大規模アップロードの前に、Southern Vector Limited が署名した DPA をサポートに求め、再委託先のページを確認してください。入手するまでは、漏えい通知で開示しても問題ないビジネスアドレスだけをアップロードしてください。
- **catch-all の数値は実証されていません。** 30% から 40% という判定率はベンダー自身の数字です。競合の Prospeo は MillionVerifier が判定できる catch-all は 5% にとどまると報告しており、Instantly の 2026 年ベンチマークも catch-all の検出が弱く Yahoo アドレスに問題があると指摘しています。*対策：* 自社の取得元から 2,000 件のサンプルに送信し、有効と判定された catch-all のハードバウンス率を、同じサンプルを ZeroBounce に通した結果と比較してください。
- **リスクのある結果の無料扱いは保証されていません。** 規約は unknown と catch-all の結果を課金しないルールを、恒久的な機能ではなく裁量によるサービスプログラムと位置づけています。*対策：* すべてのアドレスを正規料金で予算化し、ポリシーが変わってもコストモデルが崩れないようにしてください。
- **返金保証が効き始めるのが遅すぎます。** 返金されるのは直近の支払いのみで、条件は ok と判定されたアドレスの 4% 超がハードバウンスしたこと、7 日以内に送信したこと、ファイルアップロードで検証したことです。メールボックスプロバイダーは約 2% で送信者にフラグを立てます。*対策：* 保証は防御ではなく返金として扱い、新しいリストはまずセカンダリドメインから送信してください。この閾値については[コールドアウトリーチのメール到達率](/ja/learn/email-deliverability-for-cold-outreach/)で解説しています。
