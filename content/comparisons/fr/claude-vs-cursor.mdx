Lors d’un import dans le CRM, un numéro de compte perd son zéro initial. Le chat de Claude permet d’examiner deux lignes d’exemple pour comprendre le problème. Avec Claude Code, vous pouvez chercher la cause dans le dépôt depuis votre terminal ou votre environnement de développement habituel. Cursor convient si vous préférez examiner la correction directement dans son éditeur.

## Quel outil utiliser à chaque étape ?

- **Chat de Claude.** Copiez la définition du champ et quelques lignes fictives du CSV dans une conversation. Demandez quelle conversion pourrait attribuer le même identifiant à deux comptes. La personne responsable de l’import peut vérifier cette hypothèse sans ouvrir l’accès au dépôt. [Offres et fonctions de Claude](https://claude.com/pricing)
- **Claude Code.** Ouvrez le dépôt autorisé dans un terminal ou un environnement de développement compatible. Demandez à l’agent de suivre l’identifiant depuis la lecture du CSV jusqu’à la recherche du compte dans le CRM, de corriger le code et d’exécuter les tests du projet. Examinez les commandes et les modifications proposées. [Documentation de Claude Code](https://code.claude.com/docs/en/overview)
- **Cursor.** Ouvrez le même dépôt dans Cursor. Affichez le code de lecture du CSV à côté de ses tests pour suivre les modifications dans l’éditeur. L’agent peut chercher et modifier des fichiers et exécuter des commandes. Le choix des modèles et leur coût dépendent de l’offre. [Agent de Cursor](https://cursor.com/docs/agent/overview) · [Modèles et tarifs](https://cursor.com/docs/models-and-pricing)

## Mettre l’import à l’épreuve avec deux comptes

Ces lignes fictives désignent deux comptes distincts. L’import doit traiter `external_id` comme du texte et conserver les zéros initiaux.

```csv
external_id,account
0071,North Mill
71,South Mill
```

Une conversion en nombres entiers donnerait `71` dans les deux cas. L’import doit préserver la valeur d’origine à la lecture du CSV puis lors de la recherche du compte. Dans le chat, demandez une correspondance entre les champs et une explication du moment où l’identifiant risque de perdre son zéro. Avec l’un des agents de programmation, demandez d’abord un test qui échoue en reproduisant l’erreur.

Partez d’une base locale vide et désactivez toute écriture dans le CRM. Le premier import doit produire `0071 → North Mill` et `71 → South Mill`. Importez à nouveau les mêmes lignes. Les deux associations doivent rester intactes et le second passage ne doit créer aucun compte. Ce sont les critères à vérifier dans votre projet. Le [workflow d’enrichissement avec Clay et Claude](/fr/workflows/lead-enrichment-clay-claude/) propose un autre exemple à télécharger.

## Quel budget pour une personne ?

Prix des abonnements individuels sur le web, en dollars américains hors taxes, vérifiés le 2 novembre 2026. **Claude Free** permet de discuter avec des limites d’usage. **Pro** comprend le chat et Claude Code pour 20 USD avec facturation mensuelle ou 200 USD pour un an. Max coûte 100 USD par mois et Ultra, 200 USD. Dans Claude Code, connectez-vous au compte abonné pour utiliser son quota. Une authentification par clé API Anthropic entraîne une facturation distincte à l’usage. [Tarifs de Claude](https://claude.com/pricing) · [Facturation de Claude Code](https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-max-or-ultra-plan)

**Cursor Free** prévoit un usage limité. Parmi les nouvelles offres individuelles, **Plus** coûte 8 USD par mois et exclut les modèles tiers. Pour utiliser un modèle Claude dans Cursor, **Premium** démarre à 30 USD par mois. L’usage du modèle est facturé en supplément au tarif public de l’API et débité d’un crédit prépayé. Les titulaires de l’ancienne offre Pro à 20 USD conservent les conditions de ce forfait. [Tarifs de Cursor](https://cursor.com/pricing) · [Facturation par modèle](https://cursor.com/docs/models-and-pricing) · [Anciennes offres](https://cursor.com/docs/account/pricing/legacy-cursor-plans)

Commencez par le chat de [Claude](/fr/tools/claude/) si vous cherchez seulement à comprendre l’erreur. Si vous payez déjà Pro, essayez Claude Code sur l’import. Ajoutez [Cursor](/fr/tools/cursor/) si la revue dans son éditeur justifie pour votre équipe le prix de l’abonnement et le coût du modèle retenu.
