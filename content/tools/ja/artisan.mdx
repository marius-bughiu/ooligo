## 概要

Artisan は Ava という名前の AI 営業エージェントを販売しており、限定的な人間の監督のもとで BDR のアウトバウンド業務をこなします。Ava はあなたの ICP に沿ってプロスペクトを見つけ、各アカウントをリサーチし、コピーを書き、メールと LinkedIn でマルチステップのシーケンスを回し、返信を処理し、ミーティングを予約します。同社はこれを BDR の 1 日の約 80% を自動化すると謳っています（同社自身の数字です）。Ava がしないのは電話をかけることです。電話エージェントを動かす代わりに、コールリストを作成してプロスペクトを人間のレップ向けのキューに入れます。Ava の周囲には Artisan Sales Platform があり、典型的なアウトバウンドのスタックが個別に買う要素 — B2B のコンタクトデータ、メールのシーケンシング、デリバラビリティとインボックスのウォームアップ、レポーティング — を 1 つのエージェントの下にまとめています。直接の比較対象は 11x の Alice で、Artisan が対抗する役割は、ジュニアの BDR にデータのサブスクリプションとシーケンサーを足したものです。

## RevOps スタックで採用される理由

- **データと送信が 1 か所にある。** Artisan は自社の B2B コンタクトデータベースを備えており（あるページでは 300M+ コンタクト、別のページでは 250M+ と記載 — この差に注意）、20 を超えるソースから intent シグナルで補強されているため、データプロバイダーの上にシーケンサー、その上にウォームアップツールを積み重ねずに済みます。小規模チームにとっては、請求が 1 つ、ログインが 1 つというのが魅力です。
- **デリバラビリティは後付けではなく組み込み。** インボックスのウォームアップ、送信者レピュテーションの監視、スパム配置テスト、ドメインローテーションがプラットフォームに付いてきます。慎重なアウトバウンドのオペレーターが本来は別々のツールから組み立てるコントロール群です。
- **すでに使っている CRM に書き戻す。** Salesforce と HubSpot へのネイティブな同期に加え、Gmail/Google Workspace、Slack のアラート、ZoomInfo、LinkedIn により、Ava の活動は並行する記録ではなくあなたのシステム・オブ・レコードに残ります。

## 価格の実態

Artisan は価格を公開しておらず、すべての取引はデモ経由で年単位の見積もり、前払いです。第三者のデータでは、中央値の契約は年間約 $26,000-$30,000（Vendr）で、リードとメールの量に応じておおよそ $17,000 から $81,000 の幅があります。Vendr のティアの読み取りでは、入門の「Accelerate」プランが年間約 $12,000（リード約 12,000、メール約 36,000）、「Blitzscale」が年間約 $65,000 で、他のレビュアーは月額で約 $1,000 から $5,000 を挙げています。席はエージェント（BDR）席と人間（AE）席に分かれ、いずれも非公開です。セルフサーブのティアも公開された月額プランもなく、月額は「リクエストに応じて」です。署名する前に、1 年分をコミット済みとして予算化してください。

## 最適な対象

BDR の控えがなく、データ・送信・デリバラビリティを 1 つのベンダーで揃えたい、BDR の給与とツール費の代わりに年間約 $25-30K のエージェントに予算を割ける、北米市場に売るシードからシリーズ B の GTM チーム（おおよそ $1-10M ARR）。

複雑で高 ACV のアウトバウンドにおいて、生産的な人間の BDR チームの直接の代替として Artisan を買ってはいけません。独立系のレビューは、返信品質を訓練されたレップより下に置いています。主に EMEA や APAC に売る場合は見送ってください。レビュアーは薄く古いコンタクトデータを報告しています。そして電話のモーションが必要なら見送ってください。Ava は電話をキューに入れますが、かけはしません。

## 代替案との比較

[11x](/ja/tools/11x/) は AI SDR の直接のライバルで、よりエンタープライズ寄りの選択肢です。マルチエージェントのスイートに電話エージェントの Julian と SOC 2 Type II が加わり、中央値は高め（年間約 $45K）です。音声とより締まったセキュリティのストーリーが欲しいなら 11x を、メールと LinkedIn のアウトバウンドにデータが組み込まれていることが仕事のすべてで入門価格が効くなら Artisan を選びます。より安い現状維持は [Apollo](/ja/tools/apollo/) に人間の BDR を足す形です。Apollo のデータとシーケンスは席あたり月額 $49-99 付近から始まり、レップは Ava にない判断力をもたらします。回す人がいるなら、それを選びます。シグナルとコピーを自分で制御したい GTM エンジニアには、[Clay](/ja/tools/clay/) に [Regie.ai](/ja/tools/regie-ai/) または Claude を足すと、組み立て時間と引き換えに、より低コストでより高い制御性が得られます。アウトバウンドがコピーだけで失敗しているなら、[Outreach](/ja/tools/outreach/) や [Salesloft](/ja/tools/salesloft/) の上に Regie.ai のようなレイヤーを載せれば、エージェントを借りずに解決します。

## 注意点

- **返信品質が繰り返される不満。** 独立系のレビューや Trustpilot の報告は、AI 臭のする汎用的なコピーと非常に低い返信率を述べています。あるレビュアーは、数千件の送信でミーティングがゼロ、ポジティブ返信率 0.07% を挙げました。Guard：狭い ICP で有料パイロットを回し、自社の BDR の選別基準を通過するミーティングを測定し、満たさなければパイロットのゲートで打ち切ってください。
- **北米以外のデータが薄い。** レビュアーは EMEA/APAC のカバレッジが疎だと報告しています。あるケースでは、3M レコードの検索から使える C レベルのコンタクトが 3-7 件でした。Guard：署名前に、実際の地域での本物のターゲットセグメントを 3 つ Artisan に渡し、リストのサイズではなく使える検証済みのコンタクト数を数えてください。
- **セルフサーブの出口がない年間前払いのロックイン。** 契約は年間で前払い、月額は裁量です。Guard：更新と解約条件はデモではなく販売時に書面で取得し、予算化のときは 1 年分を埋没費用として扱ってください。
- **公開された API も MCP もなく、炎上で築いたブランド。** ドキュメント化された開発者向け API も MCP サポートもないため、深いカスタム統合は選択肢にありません。別途、Artisan の知名度を押し上げた「Stop Hiring Humans」の広告キャンペーンは殺害予告と世間の反発を招き、CTO は 7 か月で去りました。Guard：署名前に、必要な各統合がネイティブにサポートされていることを確認し、マーケティングが意図的に挑発的なベンダーの下でアウトバウンドを回すことのレピュテーション上の適合性を検討してください。
