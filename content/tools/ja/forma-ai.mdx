## 概要

Forma.ai は、インセンティブ報酬、テリトリー、クォータを扱うエンタープライズ向けセールスパフォーマンス管理（SPM）ソフトウェアです。2016 年にトロントで創業し、創業者兼 CEO の Nabeil Alazzam が率いています。2022 年 5 月には ACME Capital が主導する 4,500 万ドルのシリーズ B を調達し、2024 年 5 月にはトロントの活動ベースのインセンティブのスタートアップ SeaMonster を買収しました。シンガポールとインドにもオフィスがあります。公表されている顧客には Autodesk、Stryker、WEX、Hootsuite、B. Braun、Solventum、Trustpilot があります。過去 12 か月に買収や事業終了のニュースは見つかりませんでした。

3 つの製品が 1 つのデータモデルを共有しています。**Operator** はインセンティブ報酬の運用、**Architect** はテリトリーとクォータの計画を担い、**Prophet** は Forma のデータサイエンティストと戦略コンサルタントがお客様のチームと一緒にプランをモデリングするアドバイザリーサービスです。

このページが答える問い：**CaptivateIQ は自社の報酬アナリストにプランを構築させようとし、Xactly は 6 桁ドル規模の導入を求めてきます。プランの運用そのものを引き受けてくれるベンダーはあるのでしょうか。** このカテゴリーで最もそれに近いのが Forma です。ただし条件があります。

## RevOps スタックに入る理由

- **データ連携の実務をベンダーが担います。** Forma のインテグレーションページは、CRM、ERP、HRIS にまたがる 200 以上の既製インテグレーションをうたい、データフィードが正確で自社のデータモデルに合うよう、同社チームが継続的に伴走すると説明しています。競合の多くは、管理者にコネクターとマッピング画面を渡すだけです。Forma ではオンボーディングはセットアップを含む一回限りの料金で、レビューでは稼働後も毎週のサービスミーティングが続くと報告されています。
- **プランのロジックを自然言語で書けます。** Forma の AI Configurator は、自然言語で記述したプランの構成要素を計算ロジックにコンパイルします。必要な設定能力に応じて別項目として課金されます。Forma が「プラン変更は数か月ではなく数時間で済む」と言えるのはこの機能があるからです。
- **エンタープライズ規模での稼働実績があります。** Forma が公開している Autodesk の事例では、2,500 人以上の支給対象者、1,900 社のチャネルパートナー、1 億行を超えるトランザクションを、2 つのレガシープラットフォームと自社開発システムから統合したと報告されています。Forma は累計 250 億ドル超のコミッションを処理したとしています。いずれもベンダー発表の数字です。
- **アナリスト評価はリーダーの一段下です。** Forrester Wave の SPM（インセンティブ報酬）Q1 2025 では、Forma は Strong Performer に位置づけられ、Leaders の Varicent と CaptivateIQ に次ぐ評価でした。2026 年の Gartner Magic Quadrant for SPM については、Forma は評価位置を発表していません。

## 実際の価格

価格は公開されていません。2026-09-22 に確認した forma.ai/pricing には 3 つの構成要素が記載されています。一回限りのオンボーディング・導入費用、選択した機能で決まる CompOps プラットフォーム料金、設定レベルで決まる AI Configurator 料金です。無料トライアルやセルフサービスプランはありません。

独立した取引データは見つかりませんでした。Vendr の「Forma」という掲載は福利厚生プラットフォームという別会社のもので、その数字はここには当てはまりません。CFO Shortlist は、Forma の価格帯を Xactly や Varicent と同水準、一般に年間 6 桁ドルに導入費が加わると推定しています。参考までに、Vendr での Xactly の中央値は約 8 万ドル、CaptivateIQ は約 3.6 万ドルです。支給対象者が数百人規模なら年間 8 万ドル以上を見込み、これは見積もりではなく推定として扱ってください。第三者のガイドは、実務上の下限を支給対象者 100 人前後としています。

## 最適な利用者

支給対象者が数百人から数千人規模で、期中のプラン変更が多く、チャネルやパートナーへの支給があり、社内に comp-ops チームを作るつもりがない企業の、セールス報酬責任者とセールスファイナンス責任者です。本当の制約がソフトウェアの機能ではなくアナリストの人員であり、同じデータ上でテリトリーとクォータの計画も行いたい場合に最も適しています。

**向いていないケース：**支給対象者が 100 人程度未満の場合、プランが固定レートとアクセラレーターだけの場合、または管理者がベンダーを介さずにプランのロジックを完全に管理したい場合です。どの場合でもサービス分の費用は発生します。

## 代替製品との比較

- **[Xactly](/ja/tools/xactly/)** はエンタープライズ領域の既存大手で、2026 年の Gartner Leader です。報酬ベンチマークや ASC 606 に基づくコミッション費用の会計処理を同じシステムで行う必要があり、運用できる管理者チームがいる場合に選んでください。
- **[Varicent](/ja/tools/varicent/)** はもう一つの既存大手で、Forrester と Gartner の両方で Leader です。報酬よりもテリトリー、クォータ、キャパシティの計画が購買の中心で、より深いネイティブ AI を求める場合に選んでください。
- **[CaptivateIQ](/ja/tools/captivateiq/)** はミッドマーケットのリーダーです。報酬アナリストがスプレッドシート型のモデルでロジックを自ら管理したい場合に選んでください。想定コストはおよそ半分です。
- **[Everstage](/ja/tools/everstage/)** は最も急成長している新興ベンダーです。マネージドサービスよりも初回支給までの速さを重視する場合に選んでください。
- **[Performio](/ja/tools/performio/)** は中間の選択肢です。支給対象者が 70 人から数百人で、データが ERP や TMS から来る場合に選んでください。
- **[QuotaPath](/ja/tools/quotapath/)**：支給対象者が 100 人未満で、クォータ達成率ベースのプランならこちらのままで十分です。

どれも合わない場合、問題はツールではなくプランにある可能性が高いです。まず[報酬プラン](/ja/learn/compensation-plans/)から始めてください。

## 注意点

- **変更は Forma 頼みになります。** Capterra のレビューでは管理者が単独でできることに制限があると指摘され、CFO Shortlist もセルフサービスでの管理の弱さを挙げています。*対策：*概念実証の段階で、自社の管理者に AI Configurator を使って新しいプランの構成要素を支援なしで作らせ、プラン変更に関するサービス時間と対応期限を契約に明記してください。
- **データの取り込みは負荷が大きいです。** G2 のレビューでは Forma のデータモデルの習得に時間がかかると指摘され、第三者のレビューでは CSV のみの取り込みで Excel にネイティブ対応していない点が挙げられています。*対策：*契約前に実際のソースファイルで支給期間 1 回分をまるごと渡し、Forma のデータモデルへのマッピングを Forma の責任とすることを statement of work に明記してください。
- **ASC 606 への対応範囲が不明確です。** Forma の製品ページは 606 の自動化に触れていますが、CFO Shortlist はコミッション費用の会計処理のための既製モジュールはないと報告しています。*対策：*自社データを使ったデモで、コントローラーに資産計上と償却の流れを確認してもらうか、別ツールの予算を確保してください。
- **AI クライアントからの接続手段がありません。** MCP サーバーも公開 API ドキュメントも見つかりませんでした。Xactly と Performio は MCP サーバーを提供しています。*対策：*Claude などのエージェントから報酬データを照会する計画があるなら、契約前に API の範囲とロードマップのコミットメントを書面で取り付けてください。
- **ロックインと不透明な価格。** 独自のデータモデルと見積もり制の価格体系により、更新時の交渉力はほとんど残りません。*対策：*更新時の値上げに 3 年間の上限を設けるよう交渉し、解約時にはプラン、計算結果、履歴を文書化された形式で完全にエクスポートできることを条件にしてください。
