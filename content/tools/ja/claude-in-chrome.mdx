## 概要

Claude in Chrome は、[Claude](/ja/tools/claude/) が自分の Google Chrome のタブ上で、すでにログイン済みの状態のままページ移動、クリック、入力、フォーム入力を行えるようにする Anthropic のブラウザ拡張機能です。2026年8月26日に、Claude のすべての有料プラン（Pro、Max、Team、Ultra、Enterprise）で一般提供（GA）が始まりました。Free プランでは使えません。サイドパネルから操作し、Chrome Web Store からインストールします。Anthropic の GA 発表によると、現時点ではほかの Chromium 系ブラウザやモバイルでは動作しません。

Max、Ultra、Team では、サイドパネルが [Claude Cowork](/ja/tools/claude-cowork/) のセッションとして動作するようになり、履歴、スキル、プラグイン、コネクタを利用できます。Enterprise では、管理者がクラウド上で Cowork を有効にした場合に限ってこの形になり、それまでは従来のパネルが使われます。開発者は [Claude Code](/ja/tools/claude-code/) から操作して、開発中のサイトをテストすることもできます。

兄弟にあたる製品もあります。Claude のデスクトップアプリには独自の組み込みブラウザが付属しており、インストールが不要で、Cookie をほかのブラウザと分けて保持します。また Cowork では、認識したパスワード、ワンタイムコード、カード番号、社会保障番号の入力欄を Claude から隠します。ブラウザ操作を新たに使い始めるユーザーには、既定で組み込みブラウザが割り当てられます。Salesforce、Greenhouse、e-billing ポータルにすでにサインインしている Chrome プロファイル上で作業する必要がある場合は、Claude in Chrome を選びます。

## ops スタックに載る理由

ops の管理作業の多くは、呼び出す価値のある API がありません。ベンダーポータル、レガシーな ATS の画面、コネクタが公開していない [HubSpot](/ja/tools/hubspot/) の設定ページなどです。Claude in Chrome は、連携プロジェクトを立ち上げることなく、会社がすでに費用を払っている可能性のあるシートでこうした画面にアクセスできます。

GA リリースで、人が張り付いて見守る必要の度合いが変わりました。モードは 3 つあり、チャット入力欄から選びます。

- **手動承認（Manually approve）**：Claude は各アクションの前に一時停止します。そのサイトで許可する、今回だけ許可する、拒否する、のいずれかを選びます。
- **自動承認（Automatically approve）**：Cowork のサイドパネルでの既定モードです。分類器が、Claude が実行しようとしている各アクションを最初の依頼内容と照らし合わせ、一致しないものをブロックします。これとは別のプローブが、ページやメールの内容にプロンプトインジェクションがないかをスキャンします。ブロックが繰り返されると、Claude は毎ステップで確認を求める動作に戻ります。
- **すべての承認をスキップ（Skip all approvals）**：Claude のアクションを何もチェックしません。

Auto モードを実用的にしているのは、Anthropic が公表している数値です。現行のレッドチーム評価では、モデルに到達した攻撃は、追加の安全策がない状態の Opus 5 に対して 3.8% の確率で成功しました。プローブと分類器を組み合わせると、Sonnet 5 と Opus 5 に対して成功した攻撃はゼロで、Fable 5 に対しては 0.3% でした。一部のアクションはどのモードでも拒否されます。購入や金融取引、アカウントの作成、カードや身分証データの取り扱い、トレード、メールやウェブコンテンツ内の指示に従うことです。

## 価格の実態

個別の料金はありません。Claude のシートを購入します。Pro は $20/月（年額払いなら $17）、Max は $100/月、Ultra は $200/月で、ほかに Team と Enterprise のシートがあります。ブラウザタスクは、プランのほかの用途と同じ 5 時間ごとおよび週ごとの利用上限から消費され、スクリーンショットの多い複数ステップのタスクはチャットよりも速く上限を使い切ります。予算は Cowork ユーザーと同じ考え方で組んでください。試用なら $20 のシートで十分で、毎日ブラウザタスクを実行する人には 1 人あたり $100〜$200 が現実的です。

## 適しているのは

使えるコネクタのない SaaS 画面の中で、反復作業に週に何時間も費やしている RevOps 管理者、Legal Ops マネージャー、採用コーディネーターです。たとえば CRM のリストビューでレコードのタグを付け直す、3 つの外部弁護士事務所のポータルから請求書 PDF を取得する、スケジューリングツールと ATS の間で面接枠をコピーする、といった作業です。実行する本人がすでに適切な権限を持ち、タスクにその本人のサインイン済みセッションが必要な場合に真価を発揮します。

## 適していないのは

構造化データを対象とした、無人で大量に回すジョブです。システムに API や [n8n](/ja/tools/n8n/) のノードがあるなら、そちらを使ってください。スクリーンショットを撮るモデルよりも安く、速く、監査もしやすくなります。エージェントに独自のアイデンティティが必要な場合にも不向きです。Claude in Chrome はユーザーのブラウザ上でユーザーとして動作するため、独自のライフサイクルを持つエージェントが必要なら [Microsoft Agent 365](/ja/tools/microsoft-agent-365/) や [Salesforce Agentforce](/ja/tools/salesforce-agentforce/) を検討してください。

## 代替候補との比較

- **[ChatGPT](/ja/tools/chatgpt/) の Chrome 拡張機能**：最も動きの速い競合です。OpenAI は 2026年8月9日に Atlas ブラウザを終了し、ブラウザエージェントを ChatGPT デスクトップアプリ、クラウドブラウザ、Chrome 拡張機能に移しました。この拡張機能は 2026年10月15日にタブ操作に対応し、Edge、Brave、Opera、Vivaldi でも動作します。会社が ChatGPT に標準化している場合や、社員が Chrome 以外のブラウザを使っている場合に選んでください。
- **[Gemini](/ja/tools/gemini/) in Chrome（auto browse）**：Chrome 自体に組み込まれているため、配布範囲が最も広い選択肢です。auto browse は米国の Google AI Pro および Ultra の契約者に限られ、エージェント型アクションには 1 日あたりの上限があり、業務アカウントで使うには管理者による有効化が必要です。拡張機能の展開を避けたい、Google Workspace を使う米国のチームに向いています。
- **[Perplexity](/ja/tools/perplexity/) Comet**：独立した AI ブラウザです。Comet Enterprise は MDM 経由でサイレントインストールでき、管理者は回答のみ、または承認済みドメインでのアクションのみを許可できます。全員の本番環境ログインを保持しているブラウザとは別のブラウザでエージェントを動かしたい場合に選んでください。

## 注意点

- **組織では既定で有効になっています。** Team では拡張機能が既定で有効で、Enterprise ではオーナーがすでに無効にしていない限り有効です。また、管理者が有効にしてもユーザーには通知されません。例外は HIPAA を有効にした組織で、この場合は無効のままとなり、BAA の対象外です。対策：誰かが告知する前に、オーナーが「組織設定 > Claude in Chrome」（Organization settings > Claude in Chrome）で制限の厳しい許可リストを設定してください。これは Anthropic 自身も推奨しています。同じリストが組み込みブラウザにも適用されます。`forceLoginOrgUUID` の Chrome ポリシーで拡張機能を自社の組織に固定し、社員が個人アカウントから使えないようにしてください。
- **データの取り扱いはエンタープライズ向けの既定水準ではありません。** Cowork と同様に、ゼロデータ保持には対応していません。Claude は作業するすべてのタブのスクリーンショットを撮り、Auto モードのチェックが最新のスクリーンショットのコピーを保持する場合があります。対策：候補者の医療メモ、秘匿特権のある案件ファイル、カード番号全体など、規制対象データを表示するページでは使わないでください。ユーザーが近づかないことに頼るのではなく、そうしたドメインをブロックリストに登録してください。
- **Skip モードとスケジュールタスクでは人が介在しなくなります。** Skip モードでは Claude のアクションを誰もレビューせず、スケジュールタスクはコネクタの「常に確認」（Always ask）プロンプトを経ずに完了することがあります。対策：基幹システムへの書き込みアクションは Manual モードまたは Auto モードでのみ実行するというルールを定め、スケジュールしたブラウザタスクは、読み取り専用ビューか、専用の Chrome プロファイルにある最小権限のサービスログインに対して実行してください。
