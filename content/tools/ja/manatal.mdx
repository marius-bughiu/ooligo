## 概要

Manatal はバンコクで開発された AI 拡張型の ATS 兼リクルーティング CRM で、企業内の採用チームと人材紹介エージェンシーの双方に、同一プラットフォーム上でシートあたり課金として販売されています。欧米の ATS ベンダーはこの 2 種類の買い手を別々の製品に切り分けますが、Manatal はそうしません。クライアント案件と自社の求人を 1 つのシステムで回すエージェンシーが Manatal に行き着くのは、そのためです。構造的に最も近い比較対象は [Workable](/ja/tools/workable/) で、SMB からミッドマーケットまでという ATS の守備範囲は同じですが、入口の価格はその何分の 1 かです。

## Recruiting スタックで採用される理由

- **自社製の MCP サーバーを提供しています。** 2026 年 1 月 19 日提供開始、Manatal のホスティングで、候補者、求人、マッチ、組織、コンタクト、参照データにまたがる 31 のツールを備え、読み取りだけでなく書き込みにも対応します。ドキュメント上の推奨クライアントは Claude で、Gemini CLI と Microsoft Copilot Studio もサポート対象、ChatGPT は実験的位置づけです。エージェントは統合開発をせずに、データベースの検索、ノートの作成、マッチのステータス更新、アウトバウンド文面の作成まで実行できます。1 シート $60 未満の ATS でこれは珍しく、Workable と [Recruitee](/ja/tools/recruitee/) に同等機能はありません。
- **年払いで $15/ユーザー/月という入口価格。** その金額で ATS と CRM の両方が入ることが、コストに敏感なエージェンシーが Manatal をショートリストに載せる理由です。
- **APAC を前提としたデフォルト設定。** サポート時間、ローカライズ、ロードマップの優先順位は、米国ミッドマーケットの前提ではなく、APAC の事業会社およびエージェンシーの採用実務を反映しています。

## 価格

4 階層、ユーザーあたり月額、年払いを先に、月払いを括弧内に示します。

- **Professional** — $15（月払い $19）。求人 15 件、候補者 10,000 名、ハイアリングマネージャー無制限。API なし、SSO なし、LLM 連携なし。
- **Enterprise** — $35（月払い $39）。求人と候補者が無制限になり、ワークフロー自動化が加わります。API、SSO、LLM 連携は依然としてありません。
- **Enterprise Plus** — $55（月払い $59）。Manatal Open API、SSO、カスタム権限とユーザーグループ、Advanced Report Builder、追加料金なしの MCP サーバー、優先サポート。
- **Custom** — 見積もり。専任アカウントマネージャー、電話サポート、個別開発の連携が加わります。

14 日間のトライアルはカード登録なしで利用できます。シンガポールの税務上の居住者には 9% の GST が上乗せされます。AI Interviewer、自社ブランドのゲストポータル、求人媒体への掲載契約はアドオンで価格が公開されていません。予算を組む前に見積もりを取ってください。

契約を左右する数字は $15 ではなく $55 です。スタックを組む側が欲しいもの — API、MCP、SSO — はすべて Enterprise Plus にしかありません。リクルーター 5 名のエージェンシーがエージェントアクセスを求めるなら、年払いで年 $900 ではなく年 $3,300 を払うことになります。1 つ下の階層は正直に評価してください。$35 で買えるのはプログラムからの出口がない ATS であり、計画に Claude、データウェアハウス、あるいは独自の採用サイト構築が少しでも含まれるなら、それは誤った買い物です。月払いは階層全体で 7% から 27% の上乗せになり、上記の数字はすべて年間コミットを前提としています。

## 最適な利用者

シート数 3〜25 の帯にいる人材紹介エージェンシーおよび事業会社の TA チームで、APAC に本社を置くか APAC で採用しており、エンタープライズ契約なしにエージェントアクセス付きの ATS を求めている組織です。具体的には、既存データベースの中で新しい求人に合致する候補者はどれかを Claude に尋ね、その答えを候補者マッチとして書き戻したいエージェンシーの責任者です。

構造化面接のスコアカードとコンプライアンスレポートが ATS を買う主目的なら、Manatal は向きません。レビューで一貫して挙がる不満はレポート機能であり、レポートを解決するために Manatal を買うのは道具の選択を誤っています。ソーシング用のデータベースが同梱されている必要がある場合も向きません。Manatal は手元にある候補者プロフィールを拡充するツールであって、コンタクトデータを販売するツールではありません。

## 代替製品との比較

- **[Workable](/ja/tools/workable/)** — 従業員数に応じて上がる定額制で、Standard が月 $299、Premier が $599、Enterprise が $719 です。米国または EU の事業会社で、採用チームは小さいがハイアリングマネージャーが多いなら Workable を選んでください。定額制なら人を増やすたびに課金されません。シート数が少なく求人数が多い、つまりエージェンシー型なら Manatal です。
- **[Greenhouse](/ja/tools/greenhouse/)** — 見積もりのみで、構造化採用の標準です。インタビューキット、スコアカード、コンプライアンスレポートが ATS を買う理由なら、こちらを選んでください。Greenhouse も MCP サーバーを提供しているため、Manatal のエージェントアクセス上の優位は Greenhouse には通用しません。優位が効くのは 1 シート $15〜$60 の他の製品群に対してです。
- **[Ashby](/ja/tools/ashby/)** — この領域で最も成長が速い新規参入で、月およそ $300 から、分析機能そのものが製品です。Manatal にないレポート機能が欲しく、その数倍を払えるなら Ashby を選んでください。

## 注意点

- **エージェントアクセスは機能ではなく階層です。** 各社は $15 を基準に Manatal の予算を組み、その後で MCP サーバーと Open API が 3 階層上の $55 にあることに気づきます。ガード、初日から Enterprise Plus で PoC の予算を立てるか、Enterprise でトライアルを回すなら、購入予定の製品とは別の製品を評価していると認識してください。
- **MCP サーバーの認証は OAuth ではなく URL です。** 組織ごとのサーバー URL がそのまま認証情報であり、候補者データベースへの管理者権限を伴います。ガード、シークレットマネージャーに保管し、共有プロンプトやリポジトリにコミットされる MCP 設定には決して置かず、リクルーターの退職時にローテーションしてください。
- **レビューで繰り返し指摘されるのはレポート機能です。** G2 で 4.3、Capterra で 4.6 という評価の一方で、レポートと検索の制約が繰り返し指摘されています。ガード、Advanced Report Builder が差を埋めると仮定せず、契約前に 14 日間のトライアルで最もよく使う採用レポート 3 本を再現してください。
- **毎分 100 リクエストという API 制限は共有です。** MCP サーバーは標準の API レート制限をそのまま引き継ぐため、データベースを一括走査するエージェントは自社の既存連携と同じ枠を奪い合います。ガード、エージェントのバッチサイズに上限を設け、一括エクスポートはリクルーターの業務時間外にスケジュールしてください。
