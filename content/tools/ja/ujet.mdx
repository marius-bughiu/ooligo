## 概要

UJET は、顧客が手にしているスマートフォンを起点に設計されたクラウドコンタクトセンター（CCaaS）です。Web SDK と Mobile SDK により、音声、チャット、アプリ内サポートを自社アプリの中に組み込めます。Smart Actions を使うと、エージェントは通話の途中で、会話を離れることなく写真の送信、本人確認、画面共有を相手に依頼できます。プラットフォーム自体は顧客の PII を保存せず、各インタラクションのデータを CRM に書き戻します。UJET は非上場で、Sapphire Ventures が $55M のシリーズ C と $76M のシリーズ D（2024年）の両方をリードしました。同社は 50 席から 5,000 席超のコンタクトセンターを支援しているとしています。

このページが答える問いは、UJET が [Talkdesk](/ja/tools/talkdesk/) や [Five9](/ja/tools/five9/) に代わるミッドマーケットの現実的な選択肢か、そして新しいエージェント層が何を自動化するのか、です。過去 12 か月で 3 つの変化がありました。

- **Spiral（2025年11月）。** UJET は、音声、チャット、メール、アンケート、SNS にまたがって顧客の課題を検出・集計し、それについて自然言語の質問に答える会話分析企業 Spiral を買収しました。Spiral は現在も「Spiral by UJET」として単体で販売されています。
- **AXO（2026年3月11日）。** Agentic Experience Orchestration は、会話とバックオフィスシステムの間に常駐する AI 層です。過去の会話データでバーチャルエージェントを学習させ、高価値または感情的な問い合わせは人に引き継ぎ、その後も CRM のコンテキスト、リアルタイム要約、回答候補、ワンクリックで実行できるワークフローで支援を続けます。最も特徴的なのは LLM ベースのコンピューター操作エージェントで、API のないシステムでも保険金請求の登録や返金処理といったバックオフィス作業を実行します。UJET は、2026年4月から一部顧客のオンボーディングを始め、2026年下半期に一般提供（GA）すると発表しました。
- **Google Cloud CCaaS by UJET（2026年4月）。** UJET は 2022年から Google Cloud の CCaaS の唯一の OEM 提供元であるとしており、Virtual Agent と Agent Assist は Google Cloud AI 上で動きます。4月には、Google の Gemini Enterprise for CX スタックを AVANT のアドバイザー網経由で中小企業とミッドマーケットに届けるマネージドサービスを開始しました。

## サポートのスタックに登場する理由

- **ユーザーは運用しやすいと評価しています。** UJET は Info-Tech の 2026年版ミッドマーケット CCaaS Data Quadrant（2026年7月23日公開）で 11 製品中 1 位となり、UJET の検証済みレビュー 33 件に基づく総合満足度スコアは 8.6/10、導入のしやすさは 94% でした。これはユーザー満足度調査であり、Gartner 型の機能評価ではありません。また UJET は、Gartner の CCaaS Magic Quadrant で Leaders 象限に入る 5 社（Genesys、NICE、AWS、Talkdesk、Five9）には含まれていません。
- **モバイルとアプリ内サポートが後付けではなくネイティブです。** 顧客が自社アプリから問い合わせる場合、SDK はエージェントが挨拶する前に、端末、アカウント、セッションのコンテキストを通話に渡します。
- **周辺ツールとつながります。** [Assembled](/ja/tools/assembled/) のようなワークフォース管理ベンダーや [Level AI](/ja/tools/level-ai/) のような QA ツールはすでに UJET を電話系のデータソースとして挙げており、CRM アダプターは [Salesforce](/ja/tools/salesforce/)、[Zendesk](/ja/tools/zendesk/)、[Kustomer](/ja/tools/kustomer/)、[ServiceNow](/ja/tools/servicenow/) に対応しています。

## 価格の実態

UJET はパッケージページでエージェント単価を公開しています。**Basic** はユーザーあたり月額 $65（PSTN 音声、標準レポート、SSO、CRM アダプター、Web SDK）、**Pro** は $99（エージェントデスクトップ、SMS ブレンディング、Smart Actions、Mobile SDK、API、高度なレポートを追加）、**Enterprise** は $120（チャット、メール、SMS、SNS を追加）、**Digital** は $69 で、アプリ内音声を含むデジタル専用スイートです。Digital では PSTN 音声が $50 のアドオンになります。下位プランのチャネルアドオンは各 $10 です。アウトバウンドダイヤラーは $15、Workforce Management は $30、CoBrowse は $20（Web）または $40（Web とモバイル）です。

Conversational AI の項目はすべて見積もりのみです。対象は Virtual Agent、Agent Assist、Summarization、Insights で、Microsoft Teams 連携も同様です。AXO はページに載ってすらいません。100 席の Enterprise 導入は定価で年額 $144,000、WFM とダイヤラーを加えると $198,000、つまりエージェントあたり月額 $165 になり、ここに AI や通話の従量分はまだ含まれていません。見積もりの AI 費用はこの金額に上乗せして予算を組み、公開価格は値下げ交渉の出発点となる上限として扱ってください。UJET 自身のブログは「バンドル使用量」として AI 込み、トークン超過料金なしと説明していますが、価格ページの内容とは一致しません。営業がこの説明を繰り返したら、その一文を発注書に明記させてください。

## 最適な対象

顧客がモバイルアプリ経由で問い合わせてくる、エージェント 50〜500 名規模のサポート責任者や CX オペレーション責任者で、音声、デジタル、アプリ内チャネルを 1 つのデスクトップにまとめたく、AI を Google のスタック上に構築することに抵抗がないチーム。Google Cloud CCaaS を候補に入れているチームにも合います。どちらを選んでも製品は UJET です。

複雑なルーティングと高度なワークフォースエンゲージメントが決め手になる大規模な複数拠点の運用や、大量の予測型アウトバウンドが中核業務の場合は、メインのプラットフォームとしては見送ってください。

## 代替製品との比較

**[Genesys Cloud](/ja/tools/genesys-cloud/)** と **[NICE CXone](/ja/tools/nice-cxone/)** はエンタープライズ CCaaS で最大のシェアを持ちます。ルーティングの深さと複数 AI ベンダーのオーケストレーションを重視するなら Genesys、WFM と品質管理が決め手なら NICE を選んでください。ミッドマーケットで、機能の幅よりエージェントの使いやすさと立ち上げの速さを重視し、席単価が公開されていることを求めるなら、両社より UJET です。**[Talkdesk](/ja/tools/talkdesk/)** は業界別エディションが自社の事業に合う場合に勝ちます。**[Five9](/ja/tools/five9/)** はアウトバウンドの量で勝ちます。すでに Zoom Phone を使っているなら **[Zoom Contact Center](/ja/tools/zoom-contact-center/)**、エージェントが 50 名未満なら **[Dialpad](/ja/tools/dialpad/)** か **[Aircall](/ja/tools/aircall/)** です。

最も急成長している競合は、どの CCaaS の上にも載る AI エージェントベンダーで、[Sierra](/ja/tools/sierra/)、[Decagon](/ja/tools/decagon/)、[Parloa](/ja/tools/parloa/) などがあります。ルール：上位 5 つの問い合わせ理由で UJET の Virtual Agent をパイロットし、自社の封じ込め率、転送率、CSAT の目標で評価してください。専門ベンダーは、そのベースラインを 2 本目の契約費用をまかなえるほど上回る領域にだけ追加します。

## 注意点

- **AXO の一般提供は、期限がまさに今来ている約束です。** UJET は 2026年3月に AXO を発表し、GA を 2026年下半期としました。名前の挙がった唯一の顧客（Capital on Tap）が語ったのは AXO で「できるようになる」ことで、公開された顧客成果は見つかりませんでした。対策：評価期間中に AXO、特にコンピューター操作エージェントを自社テナントで稼働させるよう求め、動作を確認できたものだけを契約してください。
- **AI の価格が価格表にありません。** Virtual Agent、Agent Assist、Summarization、Insights はすべて「Get a Quote」で、ブログの「AI 込み」という説明はパッケージページと矛盾しています。対策：AI の課金単位（分、会話、席）、コミット量、超過料金、使用量アラートを発注書に明記させてください。
- **AI のロードマップは Google のロードマップです。** Virtual Agent と Agent Assist は Google Cloud AI 上で動きます。すでに Gemini を信頼しているなら利点ですが、データやモデルの方針が別の方向を向いているなら制約になります。対策：どのモデルがデータを処理するのか、どのリージョンか、API 経由で自社の LLM やエージェントベンダーを持ち込めるのかを確認してください。
- **コンピューター操作エージェントは API のないシステムで動作します。** それこそが狙いですが、画面が 1 つ変わるだけで返金フローが気付かれないまま壊れる可能性もあります。対策：まず低額のアクションで承認モードから始め、すべてのステップを記録し、適用範囲を広げる前に失敗率のアラートを設定してください。
- **アナリストの評価は満足度ベースです。** Info-Tech と Aragon Research は UJET を高く評価していますが、Gartner の Leaders 象限には含まれていません。対策：最も難しいルーティングとレポートのシナリオを 3 つデモに組み込み、Genesys か Talkdesk と並べて採点してください。
