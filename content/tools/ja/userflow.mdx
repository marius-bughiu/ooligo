## 概要

Userflow は、ノーコード/ローコードのプロダクトアダプションビルダーです。アプリ内のオンボーディングフロー、チェックリスト、ツールチップ、サーベイ（NPS/CSAT）、リソースセンターのランチャーを、変更のたびにエンジニアリングのチケットを切ることなく、ブラウザのエディターだけで構築できます。Pendo や WalkMe に対して、実装が速く developer フレンドリーな選択肢です。スニペットを 1 つ入れたら、あとは自社プロダクトをクリックして回るだけでフローを組み立てられます。2019 年に Sebastian Seilund と Esben Friis-Jensen が創業した bootstrapped 企業で、2024 年 2 月に 60M USD 超とされる条件で Beamer に買収され、現在は両社が統合されたプロダクトエンゲージメントツールキットとして販売されています。

## Customer Success スタックで採用される理由

- **エンジニアリング不要で CS がオンボーディングを所有。** CSM とプロダクトチームが、アクティベーションのチェックリスト、機能告知のツールチップ、更新リスクのサーベイを自分たちで公開できます。エディターはこのカテゴリーで最も習得が速く、チームは最初のフローを 1 スプリントではなく半日で公開できます。
- **サーベイがヘルススコアを支える。** ネイティブの NPS、CSAT、CES サーベイブロックは、回答をユーザー/company レコードに落とし込み、CRM や warehouse へ流します。サーベイのシグナルが、CS のヘルスモデル内でプロダクト利用シグナルの隣に並びます。
- **クリーンな developer 向けインターフェース。** 本物の REST API、Webhook、型付きの JS SDK があり、バックエンドのイベントでフローを起動したり、属性をプログラムから同期したりできます。ノーコード UI からだけではありません。エンジニアリング比重の高いチームが WalkMe ではなく本ツールを選ぶ理由がここにあります。
- **CRM と CDP の同期。** HubSpot と Salesforce との双方向同期に加え、Segment を source と destination の両方として使い、Flow Started や Checklist Task Completed といったイベントを、CSM が既に見ているシステムへ送ります。

## Pricing

MAU ベースで、tier ごとに定額で課金されます（表示は年間料金で、月払いは約 25% 高くなります）。

- **Startup** — 約 240 USD/月、3,000 MAU、3 シート、基本のフロー/チェックリスト/サーベイ
- **Pro** — 約 680 USD/月、10,000 MAU、シート無制限、HubSpot/Salesforce 同期、Smartflow、FlowAI、company レベルのターゲティング
- **Enterprise** — カスタム。SSO、きめ細かな権限、カスタム契約、コンシェルジュ型オンボーディングを追加
- 追加 MAU は 5,000 単位のバンドルで約 80 USD/月（年間）

14 日間の無料トライアルがあり、カード不要です。Startup tier が実用に耐えるのはこのカテゴリーでは珍しく、アーリーステージの CS チームが選ぶ実際の理由になっています。

## 適しているチーム

10〜150 人規模の PLG またはハイブリッド SaaS の CS・プロダクトチームで、エンジニアリングの待ち行列なしにオンボーディングとアプリ内メッセージングを自分たちで所有したい、かつ深いプロダクトアナリティクスよりも速いエディターとクリーンな API を重視するチームに向きます。最適なのは、Intercom の Product Tours を卒業したが、Pendo のアナリティクス＋ガイドのバンドルは必要ない（あるいは払いたくない）チームです。

## 注意点

- **プロダクトアナリティクスのプラットフォームではありません。** Userflow はフロー単位のイベントを追跡するだけで、Pendo や Amplitude が捕捉するプロダクトイベントの全量ではありません。**Guard:** CS のヘルスモデルに深い機能アダプションのアナリティクスが必要なら、専用のアナリティクスツールを維持し、Userflow はガイドのレイヤーだけに使ってください。
- **AI 機能は後付けで、コアではありません。** FlowAI（Smartflow の自動生成、GPT-4 を使ったアプリ内アシスタント）は便利ですが、AI の波の前に作られたノーコードエディターの上に載っているもので、AI-native なプロダクトではありません。**Guard:** FlowAI はそれ自体の価値で評価し、フロー設計のレビューを省く理由にはしないでください。
- **買収後のロードマップリスク。** Beamer との合併以降、投資はより広いツールキットに分散します。Userflow 単体のロードマップの進み具合を、統合プロダクトの方向性と照らして確認する価値があります。**Guard:** 複数年契約の前に、単体プロダクトへのコミットメントを担当 AE から書面でもらってください。
- **MAU 課金は成功とともにスケールします。** 利用が 3 倍に伸びるプロダクトは請求も伸びます。**Guard:** 年間契約の前に MAU 3 倍のシナリオでコストを試算し、MAU の数え方（ログイン済み か 識別済み か）を確認してください。
