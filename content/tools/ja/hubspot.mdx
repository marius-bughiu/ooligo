## 概要

HubSpot は SMB とミッドマーケットの標準 CRM です。Sales Hub、Marketing Hub、Service Hub、Data Hub が単一のレコードグラフを共有し、企業、コンタクト、ディール、チケット、カスタムオブジェクトが 1 つのスキーマに収まります。Breeze はそのデータの上に載る AI ブランドで、アプリ内の Assistant に加えて、HubSpot が Agent Hub に集約しつつあるエージェント群を指します。多くの ops チームにとっては、[Breeze](/ja/tools/hubspot-breeze/) 単体よりも、HubSpot を業務特化型の AI ツールと組み合わせる方が得られるものは大きいままです（エンリッチメントは [Clay](/ja/tools/clay/)、会話分析は [Gong](/ja/tools/gong/)、オーケストレーションは [Claude](/ja/tools/claude/) と [n8n](/ja/tools/n8n/)）。

古いドキュメントを読む場合は 2025 年の名称変更に注意してください。Operations Hub は Data Hub に、Lists は Segments に、Copilot は Assistant になりました。製品そのものは同じですが、2026 年より前のランブックの用語はもう通用しません。

## あらゆる RevOps スタックに登場する理由

- **単一のレコードグラフ。** ディール、チケット、カスタムオブジェクトが同じスキーマにあり、隣接ツールの大半と双方向同期します。マーケティングとサポートが同じアカウントを見るために、ミドルウェアを挟む必要がありません。
- **公式 MCP サーバーが 2 つ。** `mcp.hubspot.com` のリモート CRM サーバーは 2026-04-13 に GA となり、コンタクト、企業、ディール、チケット、ライン アイテム、商品、エンゲージメントへの書き込みと、キャンペーンおよびページの読み取りに対応します。別系統のローカル開発者向け MCP サーバー（2026-02-19 に GA）は、Claude Code、Cursor、VS Code からアプリと CMS のビルドを動かします。このセグメントでベンダー自身が MCP を保守している CRM はごくわずかです。
- **ワークフローと custom code actions。** ネイティブの自動化が RevOps ロジックの大半をカバーし、Node.js の custom code actions がロングテールを引き受けます。ただし後述の Data Hub の行を確認してください。custom code actions が置かれているのはそちらです。

## 料金の実態

Sales Hub の定価、2026-09-04 時点で確認:

- **Free** — $0、最大 2 ユーザー
- **Starter** — 月次契約で $20/シート/月、年間契約で $7/シート/月。HubSpot Credits 500
- **Professional** — 月次契約で $100/シート/月、年間契約で $90/シート/月。クレジット 3,000。初期費用 $1,500（一回限り、必須）
- **Enterprise** — 年間契約で $150/シート/月。クレジット 5,000。初期費用 $3,500（一回限り、必須）

予算を壊すのは表示上のシート単価よりも、次の 2 つの構造です。1 つ目はシート種別で、上記の単価が買えるのは Sales Seats です。CRM へのアクセスだけが必要なメンバーは Core Seats（Professional は $50/月、Enterprise は $75/月）を使い、閲覧専用シートは無料です。クォータ保持者が 6 人いる 12 人の GTM 組織は、12 × $90 にはなりません。2 つ目は HubSpot Credits が AI のメーターであることです。単価は $0.010、年間購入なら 1,000 クレジットあたり $9 で、毎月リセットされて繰り越しはなく、枠は製品をまたいで合算されません。

Data Hub は別建ての費用で、チームが忘れがちなのはここです。Professional は年間契約で $720/月（月次契約なら $800）、Core Seat 1 席とクレジット 5,000 を含み、webhook トリガーは 100 が上限です。Enterprise は $2,000/月で、webhook トリガーは無制限、クレジットは 10,000 です。プログラマブルな自動化はこの扉の向こうにあり、Sales Hub の中にはありません。

実勢のレンジ: 複数 Hub をまとめた年間契約は、定価より ~20〜35% 低い水準に着地するのが一般的です。これは販売パートナーと価格集約サイトの照合による推定であり、公表レートではありません。初期費用も通常は Solutions Partner 経由で交渉できます。ミッドマーケットの現実的な下限は、Sales Pro と Data Hub Pro の合計で見積もってください。

## 最適なケース

ARR $1M〜50M の B2B SaaS で、営業・マーケティング・CS を 1 つの CRM に標準化する RevOps リーダー。ネイティブ UX の質を重視し、[Salesforce](/ja/tools/salesforce/) 級の設定自由度を手放す代わりに、チームが実際にきれいに保てるシステムを取る判断ができる場合です。

**向かないのは**、少数シートでプログラマブルな自動化を主目的にする場合です。custom code action を 1 本も書かないうちに Data Hub Professional の $720/月 が発生し、月 $99 の n8n インスタンスを HubSpot API に向ければ同じ仕事ができます。深い検証ロジックを持つカスタムオブジェクトや、テリトリー単位の権限モデルが必要な場合も向きません。それは Salesforce の構築案件です。

## 代替候補との比較

- **Salesforce** — 設定自由度とエンタープライズ ガバナンスが time-to-value より重い場合に選びます。実際の検証ルールを持つカスタムオブジェクト、複雑なテリトリー階層、そして組織を専任で見る管理者が前提です。コストはライセンスより実装側にかかります。
- **[Pipedrive](/ja/tools/pipedrive/)** — 営業パイプラインだけが必要な場合に選びます。実用ティアでのシート単価は HubSpot のおよそ 3 分の 1 で、マーケティングやサービスの面は一切ありません。後から下位に移るのは現実的ではないため、マーケティング オートメーションが対象外だと確信できる場合にだけ選んでください。
- **[Attio](/ja/tools/attio/)** — このセグメントで最も伸びている AI ネイティブの新興プレイヤーです。データモデルが特殊（コミュニティ、PLG アカウント、投資パイプライン）で、HubSpot の主張の強いスキーマと衝突しそうな場合に選びます。統合の面は HubSpot の一部にすぎないため、CRM が他の 6 システムのハブになる必要があるなら不適です。

## 注意点

- **クレジットがメーターであり、エージェントはそれを消費します。** Breeze のエージェントは、繰り越しなしで毎月リセットされる同じ枠を消費します。監視型のエージェントは 1 件の監視コンタクトあたり月 ~100 クレジット程度（推定）を使うため、Professional の 3,000 クレジット枠でカバーできるのは 30 件ほどです。*ガード:* ポータル全体で有効化する前に、まず 1 セグメントに限定して 1 請求サイクル分を走らせ、クレジット消費レポートを読むこと。買い足しは都度 $0.010 ではなく、年間購入の 1,000 あたり $9 で確保すること。
- **プログラマブルな自動化は 2 回目の購入です。** custom code actions と webhook トリガーは Sales Hub ではなく Data Hub Professional にあります。*ガード:* Data Hub の費用を初年度予算に明示的に積むか、ロングテールは意図して n8n や Zapier に置き、CRM API 経由で処理して購入しないこと。
- **シート種別のドリフト。** アクセスを申請した担当者が持っていたという理由だけで、チームは既定で Sales Seats を割り当てがちです。*ガード:* 更新のたびに、シート種別を実際の利用状況と突き合わせて棚卸しすること。Core と閲覧専用へのダウングレードは、多くの HubSpot 請求書で最も大きな回収可能項目です。
- **ARR $10M 前後で当たるレポーティングの天井。** ネイティブのレポーティングは、コホートやアトリビューションの問いに答えられなくなります。*ガード:* BI ツール（Looker、Hex、Mode）を不意の追加ではなく CRM 予算の一部として計画し、指標の定義はウェアハウス側に置くこと。
- **Breeze は専用ツールに一歩遅れます。** エンリッチメント、会話分析、分析のいずれも Clay、Gong、Claude より一世代後ろです。*ガード:* Breeze は既に保有しているデータに対する省力化の自動化として扱い、売上数値が依存する処理には専用ツールを残すこと。
