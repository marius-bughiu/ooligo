Wer Profile für eine Stelle sichtet, muss Aussagen auf ihre Quelle zurückführen können. Dieser Workflow erstellt aus freigegebenen Auszügen je eine Prüfkarte für ein tätigkeitsbezogenes Kriterium. Kennung, wörtliches Zitat und Quelle bleiben beieinander.

## Beispiel mit drei Datensätzen

[Laden Sie das Paket herunter](/artifacts/candidate-sourcing-claude-skill.zip), entpacken Sie es und führen Sie im entpackten Verzeichnis `python3 prepare_review.py examples/brief.json` aus. Dafür genügt Python 3. Die Beispieldateien sind auf Englisch. Vergleichen Sie die [fiktive Eingabe](/artifacts/candidate-sourcing-claude-skill/examples/brief.json) mit der [erwarteten Ausgabe](/artifacts/candidate-sourcing-claude-skill/examples/expected-review.json).

Gesucht wird eine Leitung für die Datenanalyse im Lager. Das Kriterium verlangt einen SQL-Abgleich auf doppelte Versandereignisse. C-01 enthält ein Zitat aus Arbeitsprobe W-01 über die Gruppierung nach Sendungskennung und Ereignistyp. Die Karte trägt den Hinweis `verify_quote`. Wie Fehlalarme geprüft wurden, bleibt eine offene Frage. C-02 mit dem Vermerk `hold` erhöht nur die Zahl der zurückgehaltenen Datensätze. Für C-03 fehlt ein Auszug, daher erscheint `request_evidence`. Beide Karten behalten die Eingabereihenfolge bei.

## Einen freigegebenen Export verwenden

1. Beschreiben Sie eine konkrete Aufgabe der Stelle und stimmen Sie mit dem Team ab, welche Arbeitsprobe sie belegen würde. Der [Leitfaden zum strukturierten Interview](/de/learn/structured-interviewing/) hilft bei der Formulierung von Rückfragen.
2. Prüfen Sie Nutzungsrechte und Kontaktsperren. Verwenden Sie pseudonyme Kennungen und kennzeichnen Sie jeden Datensatz ausdrücklich für die Prüfung oder als gesperrt. Fehlt eine gültige Kennzeichnung, bricht das Programm ab. Die [Prüfliste](/artifacts/candidate-sourcing-claude-skill/references/2-fairness-checklist.md) beschreibt die Aufgaben des Recruiting-Teams.
3. Prüfen Sie jedes Zitat anhand der [Kartenvorlage](/artifacts/candidate-sourcing-claude-skill/references/3-shortlist-format.md). Wer mit [Claude](/de/tools/claude/) eine Notiz formuliert, verwendet nur dafür freigegebene Karten. Über den nächsten Schritt und eine Kontaktaufnahme entscheidet eine Person.

Profile aus [Juicebox](/de/tools/juicebox/) oder einer anderen Plattform benötigen einen autorisierten Export oder einen eigenen Konnektor. Das Paket verarbeitet die lokale Datei. Für Abrufe, Änderungen im ATS und den Versand von Nachrichten sind separate Werkzeuge erforderlich.

## Das Ergebnis prüfen

Der veröffentlichte Test verwendete fiktive Daten. Erfassen Sie bei einem Praxistest, welche Zitate sich belegen ließen, welche Notizen korrigiert wurden und wie lange die Prüfung dauerte. Ergebnisse realer Auswahlverfahren und Zeitersparnisse wurden nicht gemessen.
