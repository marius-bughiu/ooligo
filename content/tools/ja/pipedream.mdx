## 概要

Pipedream は、どの製品を買ったかによってまったく異なる答えになります。Workday は 2025年11月19日に買収契約を締結し、取引は 2026年2月に完了しました。2026年、Pipedream は元来の製品である Workflows を、String エージェントビルダーとともにメンテナンスモードに移行しました。両者とも **2027年3月31日** に提供を終了します。存続するのは Pipedream Connect で、ドキュメントには Connect が「今後の注力先」であると記されています。

Connect は、自社アプリや AI エージェントにサードパーティ連携を組み込むための開発者向けツールキットです。担う役割は 3 つです。**マネージド認証**：エンドユーザーが Connect Link またはクライアント SDK を通じて Gmail、[Salesforce](/ja/tools/salesforce/)、[HubSpot](/ja/tools/hubspot/) のアカウントを接続し、Pipedream がトークンを保管・更新します。**ツール**：3,000 以上の API にわたる 10,000 以上の構築済みアクションとトリガーを、自社コードから呼び出せます。**MCP**：同じツールが `remote.mcp.pipedream.net` のリモート MCP サーバーとして公開されるため、サーバーを書かずに [Claude](/ja/tools/claude/)、[Cursor](/ja/tools/cursor/)、あるいは自社のエージェントから呼び出せます。SDK は TypeScript、Python、Java 向けに提供され、REST API もあります。Connect プロキシを使えば、構築済みアクションがカバーしていない任意のエンドポイントに対して、認証済みのリクエストを直接送れます。

Pipedream によれば、API リクエストのペイロードやレスポンスボディは保存せず、すべてのプランで SOC 2 Type 2 と GDPR に対応しています。BAA 付きの HIPAA、SSO、SCIM は Business のみです。

## 解決する分岐点

このページが答える問いは、買収によって生まれたものです。Pipedream はエージェント連携の基盤として今も安全なのか、それとも移行すべきなのか。

答えは製品ごとにはっきり分かれます。**Pipedream Workflows を運用しているなら、移行は避けられません。** 決めるべきは移行先と時期だけです。Workflows は新規登録も新規サブスクリプションも受け付けていません。サブスクリプションは 2027年3月31日に日割り返金付きで解約され、Workflows のデータはすべて 2027年4月30日までに削除されます。Connect は代替品ではありません。自社のランタイムから呼び出す連携レイヤーであり、Node.js や Python のステップを実行するホスト型スケジューラーではありません。

**Connect の上に構築しているなら、製品は稼働中で投資も受けています。** リスクはオーナーです。Workday は HR・財務スイートであり、自社のエージェントプラットフォームを強化するために、同じ時期に Pipedream、Sana、Flowise を買収しました。Flowise は 2026年夏に自らの提供終了を発表し、Workflows がそれに続きました。Connect は Workday のエージェント戦略に合致する部分であり、それが存続を支持する最大の論拠です。同時に、そのロードマップがあなたのニーズより先に Workday のニーズに応える理由でもあります。

## 価格の実際

Connect の価格には 2 つの課金軸があります。**外部ユーザー** と **クレジット** です。

- **Free** — $0、カード不要。すべての機能とチームメンバー無制限が使えますが、外部ユーザーとクレジットは開発用途に限られます。本番トラフィックは流せません。
- **Startup** — 年払いで月 $99。月払いの場合、料金ページの表示は $150 です。外部ユーザー 100 人を含み、超過分は 1 人あたり $2。クレジットは 10,000 を含み、超過分は 1 クレジットあたり $0.012。メールサポート付き。
- **Business** — 個別見積もり、年払い。SSO、SCIM、HIPAA、専用の固定送信元 IP、SLA、専用 Slack チャンネルが加わり、両方の課金軸にボリューム価格が適用されます。

外部ユーザーとは、少なくとも 1 つのアカウントを接続した人を指します。5 つのアプリを接続したユーザー 1 人は 1 人として数えます。アクション、MCP ツール呼び出し、プロキシリクエスト、トリガーイベントは、いずれも 30 秒のコンピュートごとに 1 クレジットを消費します。管理 API の呼び出しは無料です。

典型的な本番エージェントで計算してみます。エンドユーザー 500 人、月 50,000 回のツール呼び出しで、それぞれ 30 秒以内に完了するとします。$99 + 400 × $2 + 40,000 × $0.012 = **月 $1,379** です。請求額の 3 分の 2 は 500 人のユーザーとそのツール呼び出しであり、プラットフォーム料金ではありません。当サイトで扱う競合と比べると、1 回あたり $0.012 は [Composio](/ja/tools/composio/) の $0.0003 の 40 倍、[Arcade](/ja/tools/arcade-dev/) の $0.01 とほぼ同水準、[Merge](/ja/tools/merge/) の Pro プラン（25,000 クレジットで $1,000、1 クレジットあたり約 $0.04）の約 3 分の 1 です。4 社のうち、エンドユーザー単位でも課金するのは Pipedream だけです。

## 最適な相手

自社製品に連携機能を組み込む B2B SaaS 企業のプロダクトエンジニアです。顧客ごとに自分のアカウントを接続し、カタログの幅が商談の決め手になるケースです。具体例：AI アシスタントが、顧客ごとに異なる CRM、ATS、受信トレイ上で動作しなければならない Recruiting または RevOps 製品で、誰も OAuth を自作したくない 200 以上のロングテールのアプリにまたがり、顧客アカウントが数百規模の場合です。

## 向かない相手

自社のオペレーションチームが運用する社内エージェントです。15 人の RevOps アナリストにホワイトラベルの Connect Link もエンドユーザー単位の課金も必要なく、Composio なら 1 回あたりの価格のごく一部でその役割を果たせます。ホスト型のワークフロー実行環境を探している人にも向きません。その製品は終了します。

## 代替候補との比較

- **[Composio](/ja/tools/composio/)** — エージェントのツール呼び出しで 1 回あたりのコストが安い選択肢です。月 $29 から、加えて 1 回あたり $0.0003。SOC 2 と ISO 27001 に対応。1 回あたりのコストが支配的で、顧客ごとのブランド付き認証が不要な社内エージェントや大量処理のエージェントに選んでください。
- **[Merge](/ja/tools/merge/) Agent Handler** — エンタープライズのガバナンス重視の選択肢で、Pro は月 $1,000。セキュリティレビューがツール単位の権限、監査、すべてのエージェント呼び出しに対する DLP を求め、対象 API が主流のエンタープライズ SaaS 群である場合に選んでください。
- **[Arcade](/ja/tools/arcade-dev/)** — 資金調達額で最も急成長している新興企業で、2026年6月に $60M の Series A を調達。Team は月 $25、加えて 1 回あたり $0.01。ツール呼び出しごとのユーザー単位の認可が難所であり、スイート企業に所有されていないベンダーを望む場合に選んでください。
- **Workflows からの移行組には [n8n](/ja/tools/n8n/) または [Activepieces](/ja/tools/activepieces/)。** n8n はコードステップ、トリガー、大規模カタログの点で最も近い同等品で、月約 $23 から、またはセルフホストで使えます。Activepieces は MIT ライセンスの選択肢で、単一のオーナーが再び実行環境を取り上げられない状態を望む場合に向きます。

どれも合わず、連携する API がおよそ 10 個未満なら、OAuth フローは自分で書いてください。10 個の連携はエンジニア 1 人の四半期分の工数です。その上にユーザー単位の課金を重ねるのは、恒久的な税金です。

## 注意点

- **Workflows の削除は、認証情報を伴う厳格な期限です。** 2027年3月31日にすべてが停止し、接続済みアカウントを含む Workflows のデータはすべて 4月30日までに消えます。対策：今すぐ全ワークフローのコードをエクスポートし、受信 Webhook URL とスケジュールをすべて棚卸ししてください。3月より前に上流システムの送り先を移行先のエンドポイントに切り替え、トークンのエクスポートを当てにせず、接続済みアカウントは新しいツールで 1 つずつ再認可してください。
- **エンドユーザーのトークンは Workday 所有の保管庫にあります。** Connect を離れると、すべての顧客がすべてのアカウントを再認可することになります。対策：自社の OAuth クライアントを登録し（Custom OAuth クライアントはすべてのプランで利用可能）、同意画面とアプリ登録を自社のものにしてください。Connect は自社の連携インターフェースの背後に置き、Business では支配権変更時の通知期間とデータエクスポート条項を交渉してください。
- **ユーザー単位の課金は、利用量ではなく顧客基盤に比例して増えます。** 接続ユーザーが 2,000 人になると、Startup のユーザー課金だけで、クレジットを 1 つも使う前に月 $3,800 です。対策：契約前に 12 か月後の予測顧客数で両方の課金軸を試算し、数百ユーザーを超えたら Business のボリューム価格を書面で確保してください。
- **クレジットはコンピュート時間なので、遅い API はコストが 2 倍になります。** 遅い上流 API を 31 秒待つツール呼び出しは 2 クレジットを消費します。対策：すべてのアクションにタイムアウトを設定し、使用状況ダッシュボードでツール呼び出しあたりのクレジットが 1.2 を超えたらアラートを出してください。この比率は上流の劣化を示す初期兆候です。
