## Qué es

Make (antes Integromat) es una plataforma de workflow automation visual — arrastras módulos a un canvas, conectas datos entre ellos, ramificas según condiciones y publicas. Se posiciona como la alternativa más potente y barata a [Zapier](/es/tools/zapier/) para equipos que quieren control real de flow sin escribir código.

## Por qué aparece en stacks de ops

- **Editor de flow visual.** Branching, error handling, iterators y aggregators son first-class — no afterthoughts como en Zapier.
- **Las operaciones son baratas.** El pricing por "operation" de Make tiende a ser más generoso que el modelo por task de Zapier para escenarios de complejidad media.
- **Módulos HTTP y JSON.** Los power users pueden pegarle a cualquier API REST, parsear respuestas y rutear — convirtiéndolo en una plataforma de integración real, no solo una herramienta de pegamento.

## Pricing

- **Free** — 1.000 ops/mes, 2 escenarios activos
- **Core** — $9/mes, 10K ops
- **Pro** — $16/mes, 10K ops + features avanzados
- **Teams** — $29/mes, escenarios compartidos
- **Enterprise** — custom

## Mejor para

- Equipos de ops que superaron el modelo de tasks de Zapier
- Automatizaciones de complejidad media con branching y error handling
- Equipos que prefieren flows visuales sobre el script-heavy de [n8n](/es/tools/n8n/)

## Cosas a vigilar

- El catálogo de integraciones es más chico que el de Zapier — revisa tus apps
- La superficie de IA/agentes va detrás de Zapier y n8n
- El editor visual puede volverse desbordado en escenarios complejos; se requiere disciplina
