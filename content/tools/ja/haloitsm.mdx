## 概要

HaloITSM は Halo Service Solutions の IT サービスマネジメント製品です。同社は非公開で外部資本に頼らずに成長してきた英国のベンダーで、マネージドサービスプロバイダー向けの HaloPSA と HaloCRM も開発しています。2026 年、Halo はこの 3 製品を 1 つのプラットフォームに統合し、usehalo.com で単に **Halo** として販売しています。ESM、ITSM、CSM、CRM、マネージドサービス、AI の各モジュールが 1 つのコードベース上で動作します。パートナー、レビュアー、購入者の多くは今も社内 IT 向け製品を HaloITSM と呼んでいるため、このページでもその名称を使います。

製品は本格的な ITIL デスクです。インシデント、問題、CAB 承認付きの変更、サービスカタログ、SLA、資産検出の連携を備えた CMDB、Virtual Agent チャットボット付きのセルフサービスポータルを備えています。r/sysadmin やレビューサイトでの評判は一貫しています。ほぼすべてが設定可能で、価格は ServiceNow を大きく下回り、設定の負担は自社で負うことになります。

2026 年の 2 つの事実が購入判断を変えます。8 月 13 日、Halo はマルチテナントクラウドについて **Moderate レベルの FedRAMP 20x 認可**を発表しました。これにより、米国の連邦政府機関や請負業者の候補リストに入ります。また PricingSaaS のページキャプチャによると、6 月末ごろに見積もりのみの価格設定をやめ、エージェント単価を公開しました。同社は 2026 年中にグローバル本社を Stowmarket から Ipswich の Willis Building へ移転する予定です。

## 適した用途

- **シンプルなヘルプデスクでは足りなくなった、ITIL 中心の社内 IT デスク。** 本格的な変更管理、問題レコード、チケットと結び付いた CMDB を必要としつつ、ServiceNow のライセンス費用とパートナー費用は避けたいチームに向いています。
- **IT、人事、施設管理、カスタマーサポートを 1 つのプラットフォームで。** ESM と CSM が同じコードベースで動くため、1 つの管理者チームで人事のオンボーディング、施設管理の依頼、外部サポートのキューを、共通のワークフローとレポートで立ち上げられます。
- **米国の公共部門と請負業者。** この価格帯で FedRAMP 20x Moderate を持つ製品は珍しく、中堅市場の競合の多くは取得していません。
- **デスクにアクセスする AI エージェント。** Halo は REST API に加えてプラットフォームに組み込まれたネイティブ MCP サーバーを提供しているとしており、Claude、Microsoft Copilot、Codex がエージェントごとのツール範囲設定のもとでチケットを読み取り、操作できます。組み込みの Virtual Agent はナレッジベースの検索、インシデントの作成、チケットのステータス確認、人間への引き継ぎが可能で、Halo の AI または自社の OpenAI や Azure OpenAI の接続で動作します。

## 実際の料金

Halo の料金ページには、**英国では年間契約でエージェントあたり月額 £66** と記載されており、その他の地域では現地通貨で表示されます。プランやアドオンはありません。すべてのモジュール、連携、AI 機能が単一のライセンスに含まれ、エンドユーザーと依頼者は無料です。指名ライセンスと同時接続ライセンスは同じ価格で、異なる時間帯にログインするエージェントのプールで共有する同時接続ライセンスは、シフト制のデスクにとって主なコスト調整手段です。非営利団体は 15% 割引になります。

エージェント単価の外側に 2 つのコストがあります。**オンボーディングは必須**で、プロジェクトごとに価格が設定されます。PricingSaaS は、2026 年 7 月初旬にすべての購入にオンボーディングが追加された変更を記録しています。また AI 機能で自社のモデルプロバイダーを使う場合、そのトークン費用は Halo ではなくそのプロバイダーから請求されます。

実際の数字です。25 人のエージェントを抱える IT デスクは、オンボーディングを除くライセンス費用として**年間約 £19,800** を支払います。ドルに換算すると、同じチームでの Freshservice の Growth と Pro の中間に収まりますが、変更管理、CMDB、AI はプランで分けられず最初から含まれています。反対側の端では、Halo は年間固定 $1 million でライセンス無制限の Enterprise Package を提供していますが、元が取れるのはおおむね 1,000 人以上のエージェントがいる場合に限られます。Halo は「ARR Milestones」も公開しています。会社の ARR が所定のしきい値を超えるたびに、標準価格の顧客は次回更新時にさらに 5% の割引を受けられます。

米国価格についてはサードパーティのトラッカー間で食い違いがあります（PricingSaaS はプラットフォームでエージェントあたり $80 と表示しています）。予算を組む前に、ドル建ての見積もりを書面で入手してください。

## 最適な対象

従業員 500 人から 10,000 人規模の組織で、15 人から 300 人のエージェントを抱える IT およびサービスデスクのリーダーのうち、ITIL の深さ（変更、問題、CMDB）と ESM を 1 つのライセンスで求め、最初の四半期に設定を担う意欲のある社内管理者がいるケースです。

## 代替製品との比較

最も直接的な比較対象は [Freshservice](/ja/tools/freshservice/) です。導入までのスピードとすっきりしたエージェント UI が深さより重要なら Freshservice を選んでください。数週間で立ち上げやすい一方で、AI はプランで分けられ、追加料金がかかります。基本的なデスクでは足りなくなると見込んでいて、変更管理や資産管理を追加しても上がらない 1 つの定額料金を望むなら Halo を選んでください。

最大手の 2 社は [ServiceNow](/ja/tools/servicenow/) と [Jira Service Management](/ja/tools/jira-service-management/) です。フルフィラーがおおむね 300 人を超える場合、または IT、人事、セキュリティ、カスタマーサービスが 1 つのデータモデルを共有する必要があり、パートナー主導の導入に予算を割ける場合は ServiceNow を選んでください。エンジニアリングがすでに Jira を使っていて、サービスリクエストを同期ツールなしでエンジニアリングの作業項目に紐付ける必要がある場合は Jira Service Management を選んでください。

最も急成長している新規参入者は、[Unthread](/ja/tools/unthread/) のような Slack ネイティブのデスクです。依頼の大半が Slack のスレッドから始まり、チームのエージェントが約 20 人未満で、変更管理や CMDB が不要なら Unthread を選んでください。

## 注意点

- **セットアップはデモの印象より時間がかかります。** G2 と Capterra のレビュアーは、設定項目の多さによる急な学習曲線を指摘しており、導入の遅れを報告する声もあります。対策：オンボーディングパッケージの範囲を、件数の多い上位 5 種類の依頼と変更プロセスに絞り、契約前に作業範囲記述書へ本番稼働の受け入れ基準を書き込んでください。
- **ドキュメントが製品に追いついていません。** レビュアーの不満で最も多いのは、ヘルプ記事やトレーニング動画が新機能より遅れている点です。対策：導入前に少なくとも 2 人分の管理者トレーニング費用を確保し、すべての設定判断を社内ランブックに記録して、知識が 1 人の管理者に偏らないようにしてください。
- **エージェント UI と CMDB の速度は評価が分かれます。** r/sysadmin での Freshservice との比較では、古いインターフェースと、大規模環境での CMDB の遅さが挙げられています。対策：トライアルで現実的な資産数を読み込み、契約前に最も多い 10 種類のチケット操作についてエージェントの所要時間を計測してください。
- **料金ページは新しく、まだ安定していません。** ページには £66 と表示されている一方で、FAQ は今も購入者に金額を問い合わせるよう案内しており、オンボーディング費用は料金計算ツールの公開から 1 週間後に追加されました。対策：エージェント単価、オンボーディング費用、更新条件、通貨を 1 つの書面見積もりで入手し、契約で更新時の値上げに上限を設けてください。
