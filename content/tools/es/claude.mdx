## Qué es

Claude es el asistente de IA de propósito general de Anthropic, disponible como producto de chat, una API, un agente de coding (Claude Code) y una plataforma para ejecutar Skills personalizados e integraciones de herramientas basadas en MCP. Para equipos de operaciones funciona como una capa horizontal — redacción, resúmenes, extracción estructurada, investigación web, workflows agénticos — que se integra con cualquier stack vertical que ya estés usando.

## Por qué aparece en cada stack de RevOps

- **Skills + MCP.** Define workflows reutilizables una vez y ejecútalos en Claude.ai, Claude Code y cualquier cliente compatible con MCP. Los equipos de RevOps los usan para enriquecimiento de leads, research de cuentas, pricing en deal desk, preparación de QBRs y análisis de churn.
- **Contexto largo.** Las ventanas de 1M de tokens permiten cargar un trimestre de actividad de Salesforce, una sala de deals con contratos o un año de tickets de soporte en un solo prompt sin necesidad de scaffolding de retrieval.
- **Tool use que funciona de verdad.** El function calling nativo y los loops agénticos multi-turno son lo suficientemente confiables como para conectarlos a sistemas en producción vía servidores MCP (HubSpot, Salesforce, Snowflake, BigQuery, Slack).

## Pricing

- **Free** — uso diario limitado
- **Pro** — $20/mes, acceso diario completo, contexto más amplio, projects
- **Max** — $100-200/mes, uso ampliado y acceso prioritario
- **Team / Enterprise** — por asiento, incluye controles de admin y SSO
- **API** — pago por token; el pricing de Sonnet hace que los workflows de contenido de alto volumen sean económicos

## Mejor para

- Cualquier equipo de RevOps, Legal Ops o Recruiting que estandarice un único asistente para análisis, redacción y workflows agénticos
- Equipos que adoptan MCP para conectar IA a su CRM, data warehouse o repositorio documental
- Engineers que construyen herramientas internas y quieren un agente de coding que maneje contexto largo

## A tener en cuenta

- La calidad del output depende fuertemente de la calidad del prompt — invierte en skills/templates en lugar de prompts ad-hoc
- Algunas integraciones (por ejemplo, con CRMs legacy) requieren un servidor MCP que tendrás que elegir de un directorio o construir tú mismo
