## Instantly とは

Instantly は、B2B のリードデータベースと軽量な CRM を載せた cold email の送信インフラです。無制限のメールアカウント、無制限の warmup、返信用の Unibox、そして任意の連絡先データベース（SuperSearch）を 1 つのログインで備えます。打ち出しは all-in-one で、リードを見つけ、多数のメールボックスにまたがって送信し、3 つのツールを配線せずに返信を追えます。最も近いカテゴリーリーダーは [Smartlead](/ja/tools/smartlead/) で、パーソナライズに特化した代替は [lemlist](/ja/tools/lemlist/) です。

## なぜ RevOps スタックに登場するのか

- **1 つのログインで all-in-one。** 送信、組み込みのリードデータベース、軽量な deal トラッカーが 1 つの製品に収まり、小さなチームは初期のアウトバウンドのために Smartlead + [Apollo](/ja/tools/apollo/) + CRM をつなぎ合わせずに済みます。
- **すべての tier で無制限のメールアカウントと warmup。** 数十のメールボックスに送信を分散させてメールボックスあたりの量を低く保ち、warmup は Instantly の共有アカウントネットワークを通じてすべてで走ります。Smartlead と同じ定額のスケール設計で、inbox ごとの料金はありません。
- **インフラ優先のツールより短い ramp。** UI と Unibox の master inbox は Smartlead より整っており、だからこそソロの創業者や少人数チームは、API を配線するのではなく今週ローンチしたいときにこれを選びます。

## pricing の実態

送信（Outreach）は 3 つの tier で提供されます。Growth は $47/月（1,000 件の連絡先、5,000 通の送信）、Hypergrowth は $97/月（25,000 件の連絡先、100,000 通の送信、Unibox、A/B testing、API と webhook）、Light Speed は $358/月（100,000 件の連絡先、500,000 通の送信、SISR による専用 IP シャーディング）です。年額請求はおよそ 20% 下がり、月あたり $37.60／$77.60／$286.30 になります。volume と API の両方が欲しいチームの多くは Hypergrowth に落ち着きます。

表示価格は話の半分です。リードデータベースは別のサブスクリプションで、SuperSearch は $37.60/月（Growth）から $177.30/月（Hyper Credits）まで、クレジット課金です。つまり「all-in-one」でも請求は 2 行のままです。さらに、ドメイン（$10-20/年）、Google または Outlook のメールボックス（1 つあたり月 $6 程度）、検証は自己負担です。$47 のプラン価格ではなく、送信 + データ + メールボックスインフラを 1 つの all-in の数字で予算化してください。

## こんなチームに最適

- 送信、データ、軽量な deal トラッカーを 1 つのツールで、同じ週に立ち上がる ramp とともに求めるソロの創業者や少人数のアウトバウンドチーム（1-10 名の rep）。
- 初期のアウトバウンドを回す GTM チームで、ICP がコンバートするか分かる前に別個のデータベンダーを配線するより、同梱のリードデータベースを買いたいチーム。

## 代替との比較

Smartlead はシェアで首位の代替です。多数の white-label のクライアント workspace（$29/クライアント/月）を運用する代理店なら、または Clay や n8n に組み込む API ファーストの送信が欲しいなら Smartlead を選んでください。よりすっきりした UI、同梱データベース、短い ramp が欲しく、代理店向けの white-label が不要なら Instantly を選んでください。

lemlist はパーソナライズとマルチチャネルの観点で最も成長が速い参入企業です。動的画像、email に加えて LinkedIn のステップがあります。マルチチャネルの sequence と rep レベルのパーソナライズが、同梱データや純粋な送信量より重要なときは lemlist を選んでください。

単一ドメインから月 ~1,000 通未満しか送らないなら、3 つともやめておきましょう。Apollo の組み込み sequencer か既存の engagement ツールですでに足り、専用の送信レイヤーは無駄な支出になります。

## 注意点

- **450M リードという主張は、450M の到達可能な連絡先ではありません。** Instantly の pricing ページは「450M+ B2B Leads」と打ち出していますが、独立した照合では検証済みで到達可能な件数ははるかに低く（複数のレビューで ~160M と言及）見積もられています。対策：SuperSearch は初期リスト向けの便宜的なレイヤーとして扱い、送信前に検証し、ICP に重要なアカウントには専用のデータベンダー（ZoomInfo、Apollo）を維持してください。
- **公開価格は実コストではありません。** $47-97 の送信プランは、SuperSearch データベース、メールボックス、ドメイン、検証が上に積み重なれば 3 つの請求のうちの 1 つにすぎません。対策：コミットする前に、実際に走らせるつもりのメールボックスとクレジットの量で月の all-in コストを見積もってください。
- **無制限のメールボックスと warmup だけでは deliverability は直りません。** 共有 warmup プールのレピュテーションは、このカテゴリーのどの vendor でも低下しています。対策：キャンペーンをスケールする前に配信先テストを実行し、メールボックスあたりの量を控えめ（1 日あたり 20-30 程度）に保ち、1 つを強く押すのではなくドメインをローテーションしてください。
- **white-label と代理店のマルチテナンシーは Smartlead より弱いです。** 対策：多数のクライアントアカウントを管理するなら、Instantly にコミットする前に Smartlead のクライアント単位の workspace モデルを見積もってください。
