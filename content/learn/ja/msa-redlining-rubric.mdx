マスターサービス契約（MSA）レッドラインルーブリックとは、注文書、作業明細書、継続的なサービスが掲げる包括的な商業契約である MSA のレッドラインまたはドラフティング時に法務チームが適用する構造化されたルーブリックです。MSA は通常、複数年にわたる数十万〜数百万ドルの商業関係を規律するため、[NDA](/ja/learn/nda-playbook/) や日常的なベンダー契約よりもルーブリックが重要です。

## MSA vs 注文書

ルーブリックを形成する区分：

- **MSA。** 法的条件——責任、IP、保証、期間と解除、準拠法、守秘義務、補償。関係の開始時に1回交渉；めったに見直されません。
- **注文書（または SOW）。** 商業条件——何を購入するか、いくらで、どのくらいの期間、どの成功基準で。関係を通じて繰り返し交渉されます。

うまく設計された MSA はほぼ商業的な詳細を MSA 自体に含めません；取引に特有のものはすべて注文書に記載されます。これが MSA のサイクルタイムが非常に重要な理由です——署名されたら、ディールベロシティは注文書のみに依存します。

## ルーブリック：10条項、それぞれ3つのポジション

| 条項 | 許容（A） | フォールバック（B） | 撤退（C） |
|---|---|---|---|
| 責任上限 | 12ヶ月分の料金、IP /データ/守秘義務違反のカーブアウトあり | 24ヶ月分の料金、より狭いカーブアウト | 無制限の責任または直接損害への上限なし |
| 補償 | 相互；IP 侵害のみ | 一方向（あなたが補償）、IP のみ | あらゆるクレームに対する広範な相互補償 |
| IP 所有権 | 顧客が顧客データを所有；ベンダーがベンダー IP を所有 | 派生物の共同所有 | 顧客がベンダー IP に対する権利を主張 |
| 保証 | 限定的なサービス保証、30日の是正期間 | 文書への適合性、より長い是正期間 | 黙示の保証が免責条項を生き残る |
| 期間と解除 | 1〜3年の初期期間；重大な違反に対する是正期間付きの解除 | 通知が必要な自動更新 | 解除なしの長期ロックイン |
| 準拠法 | デラウェア、NY、または同等の法域 | 相手方の本国法域 | レバレッジのない外国の法域 |
| データ保護 / DPA | 標準 [DPA](/ja/learn/dpa-checklist/) 添付、GDPR 準拠 | 30日以内に別途交渉した DPA | DPA なし；ベンダーが標準データ条件を拒否 |
| 守秘義務 | 解約後 3〜5年のテール | 営業秘密のみ無期限 | すべての秘密情報に無期限 |
| 監査権 | 通知上での合理的な営業時間の監査 | 年1回まで、第三者監査人 | いつでも、顧客または代表者が監査 |
| サービスレベル / クレジット | SLA 定義、サービスクレジットが唯一の救済策 | SLA 定義、クレジット ＋ 慢性的な違反に対する解約権 | MSA に SLA なし、注文書のみ |

最も難しい交渉は常に責任上限、IP 所有権、補償に集中します。この3つが解決されると他のほとんどの条項は迅速に動きます。

## 運用化の方法

1. **テンプレートにルーブリックを事前にマークする。** MSA テンプレートは各条項を A/B/C でマークし、許容/フォールバック/撤退の言語がすでにドラフトされています。弁護士は毎回ドラフティングするのではなくレベルを選択するだけです。
2. **AI で受信した相手方の契約書を自動採点する。** [BlackBoiler](/ja/tools/blackboiler/) または [Spellbook](/ja/tools/spellbook/) が各条項を A/B/C でルーブリックに照らして評価し、自動的に A にレッドラインバックします。弁護士は B/C の逸脱のみをレビューします。
3. **逸脱ごとに承認マトリクスを追跡する。** 各 B ポジションの条項はマネージャーの承認が必要；各 C は GC の承認が必要。逸脱は積み重なります——C なしで3つの B でも GC が必要になる場合があります。
4. **撤退ポジションをキャプチャする。** ディールが相手方の C ポジションへの主張により中断された場合、それを記録します。パターンが C を B に改定すべきかどうかを示します。

## よくある落とし穴

- **撤退ポジションのドキュメントなし。** 明示的な C ポジションがないと、弁護士はディールの圧力の下で譲歩します。ルーブリックはそれらの譲歩を反応的ではなく意図的なものにするために存在します。
- **5万ドル MSA と 500万ドル MSA に同じルーブリック。** ルーブリックをディールサイズで段階化してください；ルーブリックの前面にある1ページの修正マトリクスでこれを処理します。
- **業界特有の要件を無視する。** ヘルスケア MSA は HIPAA に準拠したデータ条件が必要；防衛 MSA は輸出管理言語が必要；金融サービス MSA は追加の規制表明が必要。あらゆるケースに対応しようとするルーブリックではなく、業界固有のテンプレートにこれらを組み込んでください。
- **MSA が商業条件を含む。** 価格、期間の長さ、スコープが MSA に忍び込むと、すべての注文書交渉が MSA の再開となります。商業的な詳細は注文書に押し込んでください。
