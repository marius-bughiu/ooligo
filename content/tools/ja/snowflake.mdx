## 概要

このページで扱うのは Snowflake のウェアハウスではなく、エージェント層です。つまり Snowflake CoWork と、その下にある Cortex Agents プラットフォームです。CoWork は Snowflake Intelligence として登場し、2025年11月4日に一般提供(GA)となり、2026年6月2日の Summit で CoWork に改称されました。その際に Deep Research、保存可能な artifacts、ユーザーメモリ、スケジュール実行の自動化(最後のものはパブリックプレビュー)が追加されています。ビジネスユーザーが自然言語で質問すると、Cortex Agent が手順を計画し、構造化データに関する質問は Cortex Analyst(セマンティックビューに対する text-to-SQL)に、ドキュメントに関する質問は Cortex Search に送り、チャートとそれを生成した SQL を添えて回答を返します。すべての処理が自社の Snowflake アカウント内で実行されるため、行アクセスポリシーと列マスキングが、ユーザーのロールのもとですべての回答に適用されます。CoWork は Snowsight、Slack ボット、iOS アプリから利用できます。MCP コネクタを通じて Snowflake の外部でも操作できます。Snowflake のドキュメントには Atlassian、GitHub、Glean、Linear、Salesforce 向けの構築済みコネクタが掲載されており、いずれも OAuth 専用です。逆方向では、2025年11月4日から GA の Snowflake マネージド MCP サーバーが、Cortex Analyst と Cortex Search を [Claude](/ja/tools/claude/) やその他の MCP クライアントに公開します。

Anthropic の [Claude Cowork](/ja/tools/claude-cowork/) と混同しないでください。こちらは一般的なナレッジワーク向けのデスクトップエージェントです。Snowflake CoWork は Claude モデルで動きますが、推論の対象は自社の Snowflake アカウント内にあるもの、またはそこに接続されたものだけです。

## RevOps・CS のスタックに入る理由

- **データはすでにそこにあります。** [Fivetran](/ja/tools/fivetran/) が CRM、請求、製品利用のデータを Snowflake に取り込んでいれば、CoWork は「週間アクティブユーザーが減少している $50,000 超の更新案件はどれか」に、BI ツールや別の AI アナリストにエクスポートすることなく答えます。
- **ガバナンスは継承されます。** 回答はユーザーの Snowflake ロールのもとで実行され、2026年5月14日から CoWork と Cortex Agents で GA となった Cortex AI Guardrails が、プロンプトインジェクションの試みを検査します。顧客 PII を含むテレメトリを照会する CS チームにとって、通常これがセキュリティ承認を得られる理由です。
- **1つのセマンティックビューが複数の利用先に対応します。** 同じセマンティックビューが CoWork、マネージド MCP サーバー経由の Claude、そして Snowflake Semantic Views をインポートする [Hex](/ja/tools/hex/) などの BI ツールにデータを供給します。

## 価格の実態

席単位の料金はありません。Snowflake は CoWork を AI Credits で請求します。1クレジットあたり、クロスリージョンルーティングを許可した場合は $2.00、ホームリージョンに固定した場合は $2.20 で、エディションを問わず一律です。利用量は100万トークン単位で計量され、エージェントが呼び出すすべてのサービスにわたって積み上がります。2026年9月30日発効の Service Consumption Table によると、Cortex Agents 経由の Claude Sonnet 4.5 は、入力100万トークンあたり1.95 AI Credits、出力100万トークンあたり9.76 AI Credits で、定価では $3.90 と $19.52 です。各回答が実行する SQL は、これとは別に自社ウェアハウスで通常のクレジットとして請求されます(AWS US East ではエディションに応じて1クレジットあたり $2–$4)。また Cortex Search サービスは、誰も照会しなくても、インデックス化した GB ごとに毎月課金されます。

当社の試算では、複数ステップの質問1件あたり入力30,000トークン、出力3,000トークンとすると、AI Credits で質問1件あたり約 $0.18 です。40人の ops チームが営業日ごとに1,000件の質問をすると、ウェアハウスのコンピュート費用を除いて月額 $4,000 近くになり、請求額は利用量に応じて変動します。予算はこの数字ではなく、パイロット後の自社の `SNOWFLAKE_COWORK_USAGE_HISTORY` から立ててください。

## 最適な対象

CRM、請求、製品のデータがすでに Snowflake にモデル化されており、20〜200人のビジネスユーザーが既存のウェアハウスガバナンスのもとで、アカウントやパイプラインに関する質問に自分で答えられるようにしたい企業の RevOps・CS ops リードです。ユーザーごとに2つ目の分析ツールの席を購入する必要はありません。

データが Snowflake にないなら見送ってください。CoWork にはネイティブの Salesforce や HubSpot のデータコネクタがなく、先にデータを取り込む必要があります。ユーザーが数値を編集する必要がある場合も見送りです。フォーキャストの提出やクォータの上書きは書き戻しツールの仕事です。

## 代替との比較

**Microsoft Power BI Copilot** はインストールベースで見た既存の最大手で、F2 以上の有料 Fabric 容量であればどれでも動きます。会社がすでに Microsoft 365 中心で、ダッシュボードが主なアウトプットなら Power BI Copilot を選んでください。データが Snowflake にあり、2つ目のセマンティックモデルを保守したくないなら CoWork を選んでください。

**Databricks Genie** はウェアハウスネイティブの直接の競合です。2026年7月6日以降、ユーザーあたり月150 DBU の無料枠を超えた分が DBU による従量課金になります。レイクハウスが Databricks なら Genie を選んでください。両者は互換ではありません。

**[Hex](/ja/tools/hex/)** Threads は最も動きの速い新規参入者で、席単位の料金(Team はエディターあたり月額 $75)を採用しており、回答をアナリストが監査できるノートブックへと引き継げます。データチームが AI の回答を管理・レビューしたいなら Hex を選んでください。追加の席をゼロにし、Snowflake ネイティブのガバナンスを使いたいなら CoWork です。

**[Sigma](/ja/tools/sigma/)** は、同じ Snowflake データの上に書き戻しアプリを作るのが目的なら勝ります。CoWork で特定したセグメントをスケジュールで CRM に送るなら、[Hightouch](/ja/tools/hightouch/) と組み合わせてください。

「アクティブなアカウント」の定義について誰も合意していないためにどれも合わない場合は、まずモデルを修正してください。[データウェアハウスと CDP の違い](/ja/learn/data-warehouse-vs-cdp/)を参照してください。

## 注意点

- **デフォルトでは厳格な支出上限がありません。** トークン課金は質問の複雑さに応じて増え、Deep Research は並列のサブ調査を最大10分間実行します。*対策:*ユーザーごとの AI クレジット上限を設定し、CoWork が使うウェアハウスに resource monitor を付け、最初の60日間は `SNOWFLAKE_COWORK_USAGE_HISTORY` を毎週確認してください。
- **回答の品質はセマンティックビューの品質で決まります。** あいまいな列名や欠けている指標定義は、自信満々の誤った SQL を生みます。*対策:*主要な20〜30の指標をセマンティックビューで定義し、列数をおおむね100未満に保ち、既知の質問セットを毎月実行してドリフトを検出してください。
- **ロールの設定ミスは、ユーザーが見るデータを気づかないうちに変えてしまいます。** CoWork は各ユーザーのデフォルトロールで起動し、そのロールが付与されていなければ PUBLIC にフォールバックします。また共有された artifacts は閲覧者ごとのロールで再実行されるため、2人が異なる数値を見ることがあります。*対策:*`CORTEX_AGENT_USER` を専用ロールに明示的に付与し、それを CoWork ユーザーのデフォルトロールに設定し、共有前に低権限アカウントで artifacts をテストしてください。
- **MCP コネクタは OAuth 専用、ツール専用で、Snowflake による検証はありません。** Snowflake は外部サーバーを保守しておらず、サーバーへのアクセス権がそのツールの利用権を与えるわけではありません。*対策:*Salesforce のレコード更新のような書き込みツールは、ツールごとに小規模なロールへ付与し、信頼できる監査証跡ができるまで外部アクションは読み取り専用にしてください。
