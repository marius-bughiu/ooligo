## 概要

Wonderlic はシカゴ地域のアセスメント企業で、1930年代から採用の近道として使われてきた「50問・12分」の認知能力テストの開発元です。現在もその考え方を **Wonderlic Select**（旧称 WonScore）として販売しています。候補者は1回のセッションで認知能力、性格、モチベーション（Wonderlic は最後のものを「興味」と呼びます）を受検し、3つの結果は職務ごとのスコアリングプロファイルと照合されて、1つの職務適合スコアにまとめられます。認知能力パートは短い時間制限付きで、通常は約12分です。性格とモチベーションの質問票には時間制限がありません。

2つ目の製品は **Wonderlic Develop** です。入社後に同じ結果を再利用し、マネージャーが部下を育成・定着させるのを支援するモジュールです。2026年6月からは **Ask Wonderlic** が加わりました。Develop に追加料金なしで組み込まれた AI コーチで、各従業員の結果と役割をもとに 1on1 の話題を提案します。

同社は現在も独立した同族経営企業です。創業者 E.F. Wonderlic の孫である Charlie Wonderlic が執行会長、Hogan Assessments の元プロダクト責任者 Becca Callahan が CEO を務めています。過去12か月で買収や事業終了の報道は見つかりませんでした。

Wonderlic は ATS でも、ビデオ面接ツールでも、スキルテストのライブラリでも**ありません**。ファネルの1か所で候補者を採点し、その結果をお使いの ATS に渡すツールです。

## 2026年の変更点

- **Select のリデザイン（2026年6月4日発表、2026年7月27日までに全顧客へ提供）。** 8つの変更があります。求人ダッシュボード、候補者と求人をまとめて探せる検索、スコアリングプロファイル上の AI 生成の職務サマリー（Wonderlic は採点には影響しないと明言）、各結果の冒頭に表示される予測力の高い5つの指標、1つの適合スコアで並ぶ候補者リスト、最終候補者の横並び比較、候補者ごとの受検タイムライン、そして**標準化されたアセスメントバッテリー**です。最後の機能により、ある職務の候補者はメール、Quick Apply リンク、オンサイトのどの経路で来ても同じテストを受けます。
- **AI による不正のシグナル（2026年2月）。** 回答パターンが AI ツールを含む外部の助けを示唆する場合、認知能力の結果に「正確性に関する警告」が表示されるようになりました。オフにはできず、Wonderlic はこれを「判定ではなくシグナル」と説明しています。
- **ATS なしの自動化（2026年8月）。** 外部の候補者 ID を含められる Quick Apply リンクと、メールまたは SFTP で届く日次・週次のデータレポートです。連携のないチーム向けの機能です。

## 価格

- **見積もりのみ。** Wonderlic は価格を公開していません。公式 FAQ によると、価格はパッケージと従業員数で決まり、どのパッケージにも導入、トレーニング、サポートが含まれます。アセスメント単位のクレジットではなくパッケージで販売されるため、応募者全員を受検させられます。
- **実勢レンジ（第三者情報、ベンダー未確認）：** Software Advice と GetApp は Select を **年間約6,000米ドル**からと掲載しています。小規模組織の下限と考えてください。パッケージは従業員数に応じて上がります。
- **更新時のリスクは現実的です。** GetApp のレビュアーは更新時に従来料金の「300%超」になったと報告しており、G2 の中小企業レビュアーは、採用が少ない月には定額料金を正当化しにくいと述べています。
- **比較の目安：** [TestGorilla](/ja/tools/testgorilla/) の2026年 Core プランは、候補者クレジット750件で年間約2,580米ドルです。年間の受検者が数百人に満たない場合、Wonderlic は価格ではなく、妥当性検証と職務適合スコアで勝負する必要があります。

確認時点のレビュー評価：G2 で 4.2/5（189件）、Software Advice で 4.5/5（166件）。

## 最適な用途

時給制、営業、サービス、新卒・若手の職種を継続的に採用する中小企業（従業員約50〜2,000人）の TA・人事責任者で、応募者ごとに短く検証済みのスクリーニングを行い、採用担当マネージャーがトレーニングなしで読める1つの適合スコアを求めているケースに向いています。同じ結果を入社後に Develop で再利用する場合に最も効果を発揮します。

**次の場合は Wonderlic を購入しないでください：** コーディングテストや職種固有のスキルテストが主な目的の場合、同じベンダーで非同期ビデオ面接も使いたい場合、または年間の受検者が約200人未満の場合。

## 代替ツールとの比較

- **[Criteria](/ja/tools/criteria-corp/)**：最も近い競合です。CCAT は同じ形式（50問・15分）で、Criteria はビデオ面接と AI 面接、75社以上の ATS パートナーも備えています。アセスメントと面接を1つの契約にまとめたいなら Criteria を、認知能力・性格・モチベーションを1つの適合スコアに統合し、入社後のコーチング層も欲しいなら Wonderlic を選んでください。
- **[SHL](/ja/tools/shl/)**：エンタープライズ向け心理測定の市場シェア首位です。多くの国で法的な異議申し立てに耐える必要がある、グローバルで重要度の高い選考に選んでください。
- **[HireVue](/ja/tools/hirevue/)**：エンタープライズ向けビデオ面接のシェア首位で、アセスメントも付属します。スクリーニングの中心がテストではなく面接である場合に選んでください。
- **[TestGorilla](/ja/tools/testgorilla/)**：最も急成長している新興勢力で、セルフサービスのプランと大規模なテストライブラリがあります。中小企業の予算、職種別の多数のスキルテスト、月単位の購入に向いています。
- **[Plum](/ja/tools/plum/)** と **[Harver](/ja/tools/harver/)**：社内異動での人材ポテンシャルのマッチングには Plum を、職務シミュレーションで毎月数千人を採用する現場職プログラムには Harver を選んでください。

採用数が少なくどれも合わない場合は、ルーブリックで採点するワークサンプルの後に[構造化面接](/ja/learn/structured-interviewing/)を行うほうが、どの年間パッケージよりも効果的です。大きな流れについては[スキルベース採用](/ja/learn/skills-based-hiring/)をご覧ください。

## 注意点

- **対策教材と AI の助けはどこにでもあります。** 従来型テストはインターネット上で最も練習されている認知能力テストであり、正確性に関する警告はパターンを示すだけで、監視は行いません。*対策：* Wonderlic 自身の推奨どおり、警告の付いた結果は監督下での再受検のきっかけとして扱い、高得点者には同じ思考力を確かめる面接質問で改めて確認してください。[AI による面接不正](/ja/learn/ai-interview-fraud/)もご覧ください。
- **認知能力テストには不利益影響（アドバース・インパクト）のリスクがあります。** 時間制限付きの認知能力スクリーニングは、グループ間のスコア差と最も結び付けられやすいアセスメントの種類です。また統合された適合スコアでは、どの要素が不合格の原因かが見えにくくなります。*対策：* 自社データで四半期ごとにセグメント別の合格率を確認し（[スクリーニングスコア分散監査](/ja/workflows/screening-score-variance-audit-skill/)はこの用途向けです）、すべての不合格判断に人間を関与させ、[NYC Local Law 144](/ja/learn/nyc-local-law-144/) に基づくバイアス監査の義務を確認してください。
- **連携は限られています。** Wonderlic が挙げているのは [Greenhouse](/ja/tools/greenhouse/)、[JazzHR](/ja/tools/jazzhr/)、[iCIMS](/ja/tools/icims/) で、公開 API や MCP サーバーは見つかりませんでした。*対策：* 契約前に、招待、受検完了、スコアの書き戻しを自社の ATS で検証してください。ATS が一覧にない場合は、SFTP レポート経路の予算を確保してください。
- **価格は更新時に動きます。** *対策：* 最初の契約で更新時の上限と従業員数の帯を交渉し、パッケージのテスト量に関する条件を書面で受け取ってください。
