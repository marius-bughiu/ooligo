As ferramentas de IA que um time moderno de RevOps de fato deploya. Não "o maior número de ferramentas de IA" — as ferramentas de IA cujo ROI aparece nas métricas. Cinco picks, ranqueados por leverage, com o que cada uma substitui.

## 1. Claude — a camada horizontal de IA

Claude é o assistente sobre o qual todo time moderno de RevOps padroniza. Contexto longo (1M tokens), tool use confiável, MCP-ready, e um sistema de Skills que deixa você transformar análises ad-hoc em workflows reutilizáveis do time. ooligo score: 9.5.

**O que substitui:** uso ad-hoc do ChatGPT, prompts espalhados em docs compartilhados, o tempo de analyst que costumava ir pra "resume a atividade de deals do Q4".

**Por onde começar:** defina 3-5 Skills de RevOps (lead-research, account-summary, churn-analysis, QBR-prep, forecast-narrative). Distribua via o workspace do Claude.ai do seu time ou um setup de Cursor + Claude Code pro lado técnico.

## 2. Clay — o substrato de orquestração de dados

Clay é a plataforma spreadsheet-native de enriquecimento + orquestração de outbound. Colunas de IA em escala (potencializadas pelo Claude), roteamento por 100+ provedores de dados, lógica condicional, webhooks. ooligo score: 9.2.

**O que substitui:** ZoomInfo + Hunter + Lusha + 20 provedores nicho + a fiação de Make/Zapier entre eles.

**Por onde começar:** uma lista. Escolha um ICP alvo, despeje 1.000 empresas no Clay, rode enriquecimento + scoring de IA, mande os top 50 pro Outreach ou Salesloft. A matemática fica óbvia.

**[Review completo do Clay →](/pt-BR/tools/clay/)**

## 3. n8n — o backbone de automação de workflows

n8n é automação de workflows open-source com nós de agentes de IA de primeira classe e suporte completo a MCP. Self-hosteável, grátis pra rodar em escala. ooligo score: 9.0.

**O que substitui:** Zapier (em escala), scripts custom em Python que ninguém mais entende, o gap entre Salesforce e seu data warehouse.

**Por onde começar:** reconstrua seu workflow mais barulhento do Zapier no n8n. O primeiro é mais rápido como cloud; depois de portar 5+, a matemática self-hosted ganha.

**[Review completo do n8n →](/pt-BR/tools/n8n/)**

## 4. Gong — conversation intelligence

Gong grava, transcreve e estrutura conversas com clientes. Precisão de forecast + escala de coaching + flagging de risco numa plataforma. ooligo score: 8.7.

**O que substitui:** o forecast que o rep submete como única fonte de verdade de pipeline, o coaching driven por manager em 1:1 que não escala, as revisões post-mortem de deals onde ninguém lembra do que foi dito.

**Por onde começar:** ligue o Gong pra organização de AE, ignore os dashboards nos primeiros 30 dias, construa o músculo de revisar 3 chamadas por semana por rep. A camada de forecast paga o orçamento depois disso.

**[Review completo do Gong →](/pt-BR/tools/gong/)**

## 5. Cursor — a camada de leverage técnico

Cursor é o IDE AI-native. Pra GTM engineers e o lado técnico de RevOps, é a diferença entre escrever um servidor MCP por trimestre e escrever um por semana. ooligo score: 9.3.

**O que substitui:** VS Code + Copilot do lado de engineering; scripts shell ad-hoc do lado de ops; os meses que costumava levar pra construir automações internas.

**Por onde começar:** se você tem um GTM engineer ou uma pessoa de RevOps que escreve código, dê Cursor pra ela no dia um. Se não tem, contrate uma e dê Cursor no dia um.

**[Review completo do Cursor →](/pt-BR/tools/cursor/)**

## O que não está nessa lista (e por quê)

- **Outreach, Salesloft, Apollo** — plataformas de sales engagement. Infraestrutura importante, mas não são realmente ferramentas de IA; são camadas de execução adjacentes ao CRM com IA colada em cima.
- **HubSpot, Salesforce** — CRMs. Mesma lógica. Os dois têm IA agora (Breeze, Agentforce) mas nenhum é best-in-class em IA; combine eles com Claude + MCP.
- **Agentforce, Einstein, Breeze** — IA empacotada pelo vendor. Não recomendamos isso como estratégia de IA. Tá ok pra tarefas dentro do CRM; não é a camada na qual seu time deveria padronizar.

## O stack mínimo viável de IA pra RevOps

Se você quer começar com três:

1. Claude (assistente + Skills + MCP)
2. Clay (dados + colunas de IA)
3. n8n (orquestração)

Adicione Gong quando tiver 25+ reps. Adicione Cursor no dia que contratar um GTM engineer.

Custo total pra um time de 25 reps: ~$150/assento/mês pra Claude Pro + Clay + n8n, mais Gong por assento (~$1.500/ano) quando escalar. A curva real de leverage começa no primeiro Skill reutilizável do Claude e compõe a partir daí.
