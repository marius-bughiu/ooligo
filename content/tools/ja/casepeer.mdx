## 概要

CasePeer は、原告側の人身傷害事務所という 1 種類の事務所のためだけに作られた案件管理ソフトです。汎用の案件記録に人身傷害用の項目を後付けするのではなく、案件ファイルが人身傷害の流れに沿って構成されています。インテーク、治療経過の追跡、医療記録と請求書の取り寄せ、時効アラート、案件経費、和解交渉、分配台帳です。2015 年に創業し、2021 年に MyCase に買収され、2022 年に AffiniPay が MyCase を買収した際に一緒に移りました。AffiniPay は 2025 年 8 月に社名を 8am に変更し、製品は現在 8am CasePeer として [MyCase](/ja/tools/mycase/)、Docketwise、LawPay と並んで販売されています。最も近いカテゴリーリーダーは [Filevine](/ja/tools/filevine/) ですが、ウェブサイトに価格が載っているのは CasePeer の方です。

## Legal Ops スタックで採用される理由

- **人身傷害向けの AI ベンダーが接続しています。** CasePeer は、[EvenUp](/ja/tools/evenup/) と [Supio](/ja/tools/supio/) の両方への公開コネクターを持つ数少ない案件管理システムの 1 つです。EvenUp は CasePeer Partner API を通じて案件の詳細、原告の情報、文書を読み込みます。2026 年 3 月に文書化された Supio の連携は、案件データ、医療記録、請求書、法律文書を自動で取り込みます。どちらも CasePeer から AI ツールへの一方向の同期です。Filevine と Clio にはどちらのコネクターもありません。そのため [人身傷害 AI スタック](/ja/stacks/personal-injury-ai-stack/) では、CasePeer を AI の選択肢を開いたままにしておける基盤として扱っています。
- **画面が業務に合っています。** 治療経過の追跡、交渉ログ、案件ステージ、高額案件レポートが標準で備わっているため、人身傷害の事務所は Filevine や Litify より設定作業が少なくて済みます。
- **決済は親会社から提供されます。** LawPay が組み込まれているため、クライアントからの支払いと和解金はサードパーティの同期を介さずに案件に反映されます。

## 料金の実態

casepeer.com/pricing、2026-10-16 確認、ユーザーあたり月額、月払い、長期契約なし、初期費用なし:

- **Basic: $90。** 案件・連絡先・タスク管理、クライアントポータル、時効アラート、和解交渉、治療経過の追跡、経費、預り金の追跡、カレンダー、無制限の文書保管。
- **Pro: $130。** クライアントのインテーク管理、無制限の双方向 SMS、案件ステージ画面、訴訟イベントプラン、50 以上の追加レポート、20 以上の連携、8am IQ の AI 機能が加わります。
- **Advanced: $160。** 予約 SMS、レポート用のデータ同期、複数オフィスのレポート、インテーク調査員ポータル、案件評価、API アクセスが加わります。
- **追加オプション。** 電子署名はアドオンです。ガイド付きの導入支援とデータ移行は任意で、別途見積もりです。

Capterra と CostBench はいまだに $79 / $119 / $149 を掲載しており、CostBench がこの価格を最後に確認したのは 2026-09-12 です。つまり定価は 9 月中旬から 7-14% 上がっています。予算は公式ページで組んでください。インテーク管理と 20 以上の連携は Pro から始まるため、ほとんどの人身傷害事務所には Pro が必要で、複数オフィスを運営する場合や API が欲しい場合は Advanced が必要です。EvenUp と Supio のコネクターにどのプランが必要かは書面で確認してください。5 人の事務所が Pro なら年 $7,800、15 席の事務所が Advanced なら移行費用を除いて年 $28,800 です。

## 最適な用途

- **最適なのは:** おおむね 3-40 ユーザー規模の原告側人身傷害事務所のマネージングパートナーとオペレーション責任者で、人身傷害に合った案件ファイルを公開価格で導入したく、デマンドレターと時系列の作成には EvenUp か Supio を購入する予定の方です。
- **向いていないのは**、人身傷害以外の業務が相当な割合を占める事務所 (家事、刑事、遺産相続の業務は MyCase の方が合います)、定型化された数千件の案件を扱う大規模不法行為 (マス・トート) 専門の事務所、そして今すぐ案件システムの中で AI エージェントや Claude コネクターを使いたい方です。

## 代替との比較

- **vs [Filevine](/ja/tools/filevine/)。** 2025 年 9 月に推定評価額 $3B で $400M を調達し、原告側の案件管理で最も資金力があり、最も急成長しているプラットフォームです。見積もりのみで、設定の自由度が高く、独自の MedChron と DemandsAI を提供しています。マス・トート、大幅なカスタムワークフロー、50 ユーザー以上なら Filevine を、固定価格と外部の AI ベンダーを望むなら CasePeer を選んでください。
- **vs [Litify](/ja/tools/litify/)。** Salesforce 上に構築され、すべて込みでユーザーあたり月額おおよそ $150-300、導入には 3-6 か月かかります。事務所がすでに Salesforce を運用している場合や、エンタープライズ規模のインテーク業務が必要な場合は Litify を選んでください。40 ユーザー未満なら、CasePeer の方が安く、早く稼働できます。
- **vs [MyCase](/ja/tools/mycase/)。** 同じ親会社の製品で、年払いで $50 / $100 / $130 です。MyCase には現在、Advanced プランの Case Assistant と OCR に加え、73 のアクションを備えた Claude MCP コネクターがあります。人身傷害が複数の業務分野の 1 つにすぎないなら MyCase を選んでください。
- **vs [Clio](/ja/tools/clio/)。** 市場全体のリーダーですが、人身傷害は標準の形ではなく、EvenUp も Supio も Clio 向けのコネクターを公開していません。案件の中でリサーチを行いたい複数分野の事務所の場合に限って選んでください。

## 注意点

- **新しい AI は CasePeer ではなく MyCase に行きました。** 2026-09-23 の Kaleidoscope で、8am は Claude 向けの MyCase MCP コネクターを発表し、Firm Agent と IQ Draft も発表しました。LawNext によると、これらの製品は MyCase 内でのみ利用できます。CasePeer の 8am IQ は文章作成と翻訳のアシスタントです。**対策:** CasePeer は案件ファイルのために購入し、AI は EvenUp、Supio、[Eve](/ja/tools/eve-legal/) から購入してください。CasePeer の AI ロードマップを当てにする前に、書面で入手してください。
- **EvenUp が見られるのは CasePeer 内に保存されたファイルだけです。** CasePeer のサポートセンターによると、EvenUp は Partner API を通じて Documents tab を読み込みます。Dropbox や OneDrive を既定の保存先にしているファイルは EvenUp からは見えません。**対策:** 移行前に文書の保存場所を決め、トライアル期間中に AI ベンダーと一緒に終結済みの案件 1 件をエンドツーエンドでテストしてください。
- **価格が変わったばかりです。** Basic の $79 から $90 への値上げについて、私たちが確認した限り公開された告知はありませんでした。**対策:** 契約する日に料金ページのスクリーンショットを撮り、10 席以上を購入する場合は価格の固定を書面で求めてください。
- **レポートとカスタマイズの制限。** G2 のレビュアーは、カスタマイズとレポートの制限に加え、カレンダーと Dropbox の同期の問題を挙げています。**対策:** デモの前に必須のレポートを書き出し、ベンダーにその場で 1 つ作ってもらってください。
