## 概要

Claude Cowork は、コーディング以外のナレッジワーク、つまり調査、分析、ドキュメント作成などの複数ステップのタスクに向けた Anthropic のエージェント型モードです。プロンプトではなくゴールを渡すと、成果物ができあがるまで、あなたのファイル、接続したアプリ、内蔵ブラウザを横断して作業します。もはや独立したタブではありません。2026年9月16日、Anthropic は Cowork とチャットを1つの Claude に統合しました。製品ページには現在「Claude Cowork は、いまや単に Claude です」と書かれています。統合後のアプリは Enterprise で10月23日に、Team で11月12日に一般提供となり、Pro、Max、Ultra には順次展開中です。Cowork という名前はヘルプセンターとプランの説明項目に残っています。中身としては、いまや [Claude](/ja/tools/claude/) のうち、質問に答えるのではなく作業をこなす部分です。

2つ目の変化は、作業がどこで実行されるかです。2026年10月6日以降、Pro、Max、Ultra の新しい Cowork タスクはクラウドで実行され、「Only on your computer」オプションは完全に廃止されました。ローカルファイル、ブラウザ操作、コンピュータ操作には、引き続き macOS または Windows 版の Claude デスクトップアプリを開いて接続しておく必要があります。Anthropic はローカル限定の作業を [Claude Code](/ja/tools/claude-code/) デスクトップアプリに誘導しています。

このカタログで最も近い項目は [Lindy](/ja/tools/lindy/) と [Dust](/ja/tools/dust/) で、いずれもオペレーション担当者向けに販売されているエージェントプラットフォームです。Cowork はビルダーではありません。キャンバスもなく、先に設定すべきエージェントもありません。成果を説明し、実行中に軌道修正します。

## ops スタックに載る理由

理由は機能ではなく流通です。Cowork は有料の Claude プランすべてに含まれています。そのため、エンジニアリング向けにすでに Claude のシートを購入した企業のオペレーション責任者は、新たな購買手続きもベンダー審査もなしに、財務アナリストや採用コーディネーター向けのエージェント面を手にしています。統合によってこの点はさらに強まりました。Claude を開いた人は誰でも、いまやそこにたどり着きます。

実際の仕事をしているのは3つの機能です。

- **スケジュールタスクはリモートで実行される。** すべての有料プランで、`/schedule` またはサイドバーの Scheduled から、毎時、毎日、平日、毎週のジョブを設定できます。コンピュータがスリープ中でも、デスクトップアプリを閉じていても実行されます。例外はローカルのファイルやアプリを必要とするタスクで、これはそのマシン上でのみ実行されます。
- **プラグインはスキル、コネクタ、サブエージェントを** 1回のインストールにまとめ、一度追加したプラグインはチャット、Claude Code、Cowork のすべてで動作します。2026年2月24日以降、Team と Enterprise のオーナーはプライベートなプラグインマーケットプレイスを公開し、プラグインを既定でインストール、必須、ブロックのいずれかに指定できます。
- **画面より先にコネクタ。** Claude はまずコネクタを試し、次にブラウザを使い、画面操作は最後の手段です。[Slack](/ja/tools/slack/)、Microsoft 365、Google Drive、[Notion](/ja/tools/notion/) をはじめとするコネクタディレクトリの各コネクタは、デスクトップ、Web、モバイルで動作します。

## 価格の実態

Cowork 自体に価格はありません。買うのは Claude のシートで、すべての有料プランに含まれています。

- **Pro**：月額$20、年払いなら月額$17
- **Max**：Pro の5×の利用量で月額$100、現在は月額$100分の API クレジット付き
- **Ultra**：Pro の週次利用量の10×で月額$200、認証済みアカウントは5時間上限なし、月額$200分の API クレジット付き
- **Team**：2〜150シート。スタンダードシートは$25、年払いなら$20です。プレミアムシートは5×の利用量で$125、年払いなら$100です。最大月額$500分の API クレジットがチーム全体でプールされます。
- **Enterprise**：年払いで1シート月額$20、最低20シート、加えて API 料金での従量課金

階層表は実際の数字ではありません。Anthropic が公開しているのは倍率であり、トークンのクォータではありません。上限はプランごとに5時間ウィンドウと週次ウィンドウで計測され、Cowork 専用の枠はありません。Anthropic 自身の製品ページも、Cowork は「チャットよりも速く上限を消費します」と注意しています。$20のシートは評価用と考え、本番ではヘビーユーザー1人あたり$100–$200を見込んでください。Enterprise では支出にシート単位の上限がありません。利用量は API 料金で課金されるため、展開前にユーザー単位と組織単位の支出上限を設定してください。

## 適しているのは

すでに Claude を契約している企業の RevOps、Legal Ops、Recruiting、Customer Success のオペレーション責任者で、エンジニアではない担当者に、無人で回る定期的なドキュメント・表計算業務を渡したいケースです。典型的な仕事は、Drive 内の CRM エクスポートから作る週次のパイプライン整備レポート、ベンダー契約書フォルダに対する月次の差分抽出、ATS のエクスポートと Slack のスレッドから組み立てる月曜の候補者ダイジェストなどです。明確に勝てるのは、出力フォーマットが安定した定期的でファイル中心の作業で、担当者が1人に特定されており、その人がすでに閲覧権限を持つデータを扱う場合です。

## 適していないのは

Cowork は *あなた自身* として動きます。あなたのシート、あなたの許可、あなたのコネクタ権限です。エージェントごとのサービス ID はなく、セッションを所有する人間とは別の監査主体もありません。Anthropic は、Cowork イベントの OpenTelemetry ストリームについて「コンプライアンス目的の監査ログを置き換えるものではありません」と述べています。独自のライフサイクルを持つエージェントのレジストリが必要なら、[Microsoft Agent 365](/ja/tools/microsoft-agent-365/) か [Salesforce Agentforce](/ja/tools/salesforce-agentforce/) を検討してください。大量の構造化パイプラインにも向きません。「毎晩5,000行を同じ手順で処理する」という仕事なら、[n8n](/ja/tools/n8n/) のフローか API の直接呼び出しのほうが安く、予測可能です。

## 代替候補との比較

- **[ChatGPT](/ja/tools/chatgpt/) Work**：OpenAI の同等製品で、「1,400を超えるプラグイン」、承認用のステップごとの計画を作成する Plan モード、スケジュールタスクとチームタスクを備えます。デスクトップではすべてのプランで、Web とモバイルでは Plus、Pro、Business、Enterprise、Edu で動作します。コネクタの網羅性が決定的な制約である場合、または組織が OpenAI に標準化している場合はこちらを選んでください。
- **[Microsoft 365 Copilot](/ja/tools/microsoft-365-copilot/)**：オペレーション組織におけるシート数での既存の本命で、Enterprise はユーザーあたり月額$30、Business は$21です。Agent Mode が Word と Excel でドキュメント全体を作成します。作業が SharePoint 上の Office ファイルにあり、ガバナンスがテナントポリシーの議論になる場合はこちらを選んでください。
- **[Manus](/ja/tools/manus/)**：最も成長の速い新規参入です。Manus 2.0（2026年9月28日）で Cloud Computer、イベントトリガー型の Automations、コンピュータ操作が追加されました。1行のブリーフから始める自由度の高い調査・制作タスクにはこちらを選んでください。ただし先に所有関係の経緯を確認してください。Meta による買収は中国の規制当局によって取り消され、現在は Tencent 主導の投資家が同社を支配しています。

## 注意点

- **コンピュータ操作は Pro、Max、Ultra のみです。** ヘルプセンターは「Team プランと Enterprise プランでは、現時点でコンピュータ操作を利用できません」と明言しています。対象プランでもベータで、macOS と Windows に限られ、Linux ベータにはありません。個人の Pro シートで評価して Team シートで展開する購買者は、デモが動かなくなる事態に直面します。ガード：シートを買う前に、対象ワークフローを画面操作が必要なものとコネクタで届くものに分け、移せるものはすべてコネクタに移し、残りは予算を分けた個別シートに置いてください。
- **クラウドが既定になり、データの経路が変わりました。** Pro、Max、Ultra のタスクは、意図したかどうかにかかわらず、いまや Anthropic のサーバー上で実行されます。Team では「Run Cowork in the cloud」が既定でオン、Enterprise では既定でオフです。HIPAA が有効な組織では Cowork は既定でオフで、BAA が対象とするのはローカルモードの構成のみであり、クラウドセッションは利用できません。ガード：展開前に、各ワークフローのデータをどこで処理してよいかを決めてください。Enterprise では、その審査を通過したグループにのみクラウドセッションを許可し、規制対象の作業はローカルモードか Claude Code デスクトップに回します。
- **サンドボックスが制限するのはネットワーク到達範囲であり、あなたのデータではありません。** セッションは「自宅や会社のネットワークに到達できない」隔離環境で実行され、終了時に削除されます。しかし隔離は「あなたが許可したアクセスを通じて Claude が読めるものや実行できることを変えるものではありません」とされており、ネットワークの送信設定は Web フェッチ、Web 検索、MCP には適用されません。公開ページを読むスケジュールタスクは、あなたの権限で信頼できないテキストを定期的に実行していることになります。ガード：許可はそのジョブの入力を含む最も狭いフォルダに限り、Web を読む手順と書き込み可能なコネクタを1つのスケジュールタスクに同居させず、書き込みは手動承認のままにしてください。Enterprise ではスキルスキャンを有効にし、必要のないグループでは Web 検索を無効にします。
