## 概要

TrueFoundry は、モデルへのトラフィックとエージェントのツール呼び出しを1つのコントロールプレーンの背後にまとめるエンタープライズ向け AI ゲートウェイです。**AI Gateway** はすべてのアプリとエージェントに OpenAI 互換のエンドポイントを1つ、ゲートウェイキーを1つだけ渡します。プロバイダーのキーはゲートウェイに一度だけ保存され、ルーティング（レイテンシベース、重み付け、地域別）、フォールバック、キャッシュ、予算、レート制限、ガードレール、リクエスト単位のログをゲートウェイが処理します。**MCP Gateway** は MCP サーバーに対して同じことを行います。中央レジストリ、Okta や Azure AD によるフェデレーションログイン、OAuth 2.0 のトークン管理、サーバー単位・ツール単位の RBAC、そしてどのサーバーを誰が使えるかを決める承認フローを備えています。より新しい **Agent Gateway** は、その上にエージェントのレジストリとステップ単位のトレースを追加します。

多くのゲートウェイとの違いは、その下にあるプラットフォームです。TrueFoundry はモデルのデプロイとサービングのための Kubernetes プラットフォームとして始まりました。そのため同じコントロールプレーンで vLLM、SGLang、KServe、Triton を使ったセルフホストモデルを提供でき、自社の VPC、オンプレミス、エアギャップ環境に導入できます。2026年6月24日には、オープンソースのサービングプロジェクト Seldon Core を手がける英国企業 Seldon を買収し、銀行・保険・小売のエンタープライズ顧客も引き継ぎました。買収条件は公表されていません。

同社は2025年2月に Intel Capital が主導する1,900万ドルのシリーズ A を調達しており、Eniac Ventures と Peak XV の Surge も参加しています。Gartner の Market Guide for AI Gateways では Representative Vendor に挙げられています（2026年2月に発表）。truefoundry.com に掲載されている顧客には NVIDIA、Siemens Healthineers、ResMed、Automation Anywhere、NetApp、Cox、Mastercard が含まれます。G2 の評価は約55件のレビューで 4.6/5 です。

## このツールが答える問い

「LLM トラフィックと MCP ツールの両方を、自社ネットワーク内のセルフホストのゲートウェイ1つで扱いたい。TrueFoundry、LiteLLM、Portkey、Runlayer のどれにすべきか？」多くのチームは結局2つの製品を抱えます。費用管理とルーティングのためのモデルゲートウェイと、ツールアクセスのための別の MCP ゲートウェイです。TrueFoundry の提案は、1つのポリシーレイヤーで両方をカバーすることです。RevOps エージェントによる Claude の呼び出しと Salesforce の MCP サーバーの呼び出しが、同じアイデンティティで認証され、同じ予算から差し引かれ、同じトレースに記録されます。

ベンダーは、内部レイテンシ 3ms 未満、稼働率 99.99%、顧客全体で月間100億件超のリクエストを公表しています。これらはベンダー自身の数字であり、独立したベンチマークではありません。コンプライアンス面では SOC 2 Type II、HIPAA、GDPR に対応し、ITAR や輸出管理対象の導入もサポートしています。

## 実際の価格

truefoundry.com/pricing に基づき、2026-11-28 に確認しました。LLM リクエストと MCP ツール呼び出しは同じ1件として数えられ、TrueFoundry はモデルのトークンに上乗せをしません。プロバイダーへの支払いは直接行います。

- **Developer：** 永久無料。ユーザー3人まで、1ユーザーあたり月10,000件のリクエストとツール呼び出し、MCP サーバー5つ、モデルアカウント5つ、ログ保持7日。SSO、RBAC、監査ログ、ガードレールはありません。
- **Pro：** 1ユーザーあたり月25ドル。ユーザー数無制限、1ユーザーあたり月20,000件のリクエストとツール呼び出しをチームで共有し、超過分は100,000件ごとに20ドル。MCP サーバー無制限、組み込みガードレール（ポリシー10件まで）、SSO、カスタムロール、監査ログ、ログ保持30日。最低契約期間はありません。
- **Enterprise：** 個別見積もり、年間契約。VPC、オンプレミス、エアギャップ環境への導入とデータレジデンシーに対応する唯一のプランで、SCIM、外部 IdP マッピング、MCP ツールの承認、カスタムおよびサードパーティのガードレール、カスタムのログ保持、SLA も含まれます。

実際の価格帯：10人の Ops チームが Pro を使うと、共有の200,000件で月250ドルです。500,000件になると310ドルになります。問題は、まさにこのページの核心となる問いです。**セルフホストは Enterprise 限定です。** Developer と Pro は TrueFoundry がホストする SaaS として動きます。料金計算ツールは月5,000ドル前後で個別見積もりに切り替わるため、自社 VPC への導入には年間で5桁ドルの契約に加え、Kubernetes クラスターとそれを運用するエンジニアの費用を見込んでください。

## 最適な利用者

金融、医療、保険などの規制業種で従業員500人以上の企業に所属し、セキュリティレビューでゲートウェイを自社 VPC 内またはエアギャップ環境に置くことが求められ、モデルのルーティング、MCP ツールのガバナンス、セルフホストモデルのサービングを3社ではなく1社でまとめたいプラットフォーム責任者や AI 推進責任者です。特に強いケースは、RevOps、サポート、法務のエージェントが複数のモデルプロバイダーと十数台の MCP サーバーを呼び出し、セキュリティチームがすべての呼び出しを Okta のアイデンティティに紐づけ、社内ネットワークの外に出したくない場合です。

## 向いていないケース

モデルルーターだけが必要な小規模チームには向きません。[OpenRouter](/ja/tools/openrouter/) か TrueFoundry 自身の Pro SaaS プランで十分で、プラットフォームの機能は使い切れません。無料でセルフホストしたいチームにも向きません。その用途は [LiteLLM](/ja/tools/litellm/) や [Obot](/ja/tools/obot/) です。TrueFoundry を自社 VPC に導入するには Enterprise 契約が必要だからです。また、Kubernetes の経験がないままオンプレミス導入を計画しているチームにも向きません。

## 代替ツールとの比較

- **[LiteLLM](/ja/tools/litellm/)**：最も広く導入されているオープンソースのゲートウェイです。セルフホストを無料で済ませる必要があり、アップグレードを担当するエンジニアがいる場合に選んでください。2026年に2回起きたサプライチェーン侵害について先に確認してください。MCP ゲートウェイもより簡素です。
- **[Portkey](/ja/tools/portkey/)**：もう1つの主要なマネージドゲートウェイで、現在は Palo Alto Networks の傘下にあり、Prisma AIRS AI Gateway として販売されています。セキュリティチームがすでに Palo Alto から購入している場合に選んでください。新規のエアギャップ導入はもう提供されておらず、そこが TrueFoundry にとっての好機です。
- **[Runlayer](/ja/tools/runlayer/)**：MCP ガバナンス分野で最も急成長している新興ベンダーです。従業員がすでに Claude や Cursor に接続したツールが課題で、ML による脅威検知とシャドー AI の検出が必要な場合に選んでください。モデルトラフィックのルーティングは行いません。
- **[Obot](/ja/tools/obot/)**：MIT ライセンスの MCP ゲートウェイです。認証情報の経路にベンダーを一切置かないオープンソースを求め、Kubernetes を自分たちで運用できる場合に選んでください。
- **Kong AI Gateway** または **Cloudflare AI Gateway**：そのベンダーがすでに自社 API の前段にある場合に選んでください。

では、TrueFoundry は「ゲートウェイ1つ」の答えになるのでしょうか。導入先を自社 VPC またはエアギャップ環境にする必要があり、Enterprise 契約を結べるなら、答えはイエスです。ホスト型の SaaS だけで足りるなら、1ユーザー月25ドルの Pro は競争力がありますが、今使っているゲートウェイを維持して専用の MCP ゲートウェイを追加する選択肢も同じくらい有力です。

## 注意点

- **求めているセルフホストはセルフサービスのプランにはありません。** Developer と Pro は SaaS のみです。対策：トライアルの前に、VPC 導入時の Enterprise 価格を営業から書面で受け取り、ホスト型の Pro ではなく実際に購入する導入形態でパイロットを行ってください。
- **共有のリクエスト枠にはツール呼び出しも含まれます。** 1タスクで MCP を20回呼び出すエージェントは、1件ではなく少なくとも21件を消費します。対策：無料プランで実際のエージェントトラフィックを1週間計測し、ツール呼び出しの深さを掛け合わせたうえで、Pro に移行する前にチームごとの予算ルールを設定してください。
- **ベンダーの数字が自社ページ間で一致しません。** 同じ AI Gateway のページで 2,500以上、1,600以上、250以上という3種類のモデル数が示され、レイテンシも 3ms 未満と約 10ms の両方が記載されています。対策：自社のトラフィックとプロバイダー構成でレイテンシを計測し、必要なプロバイダーが対応プロバイダーのドキュメントに含まれているかを確認してください。
- **Seldon の統合はまだ進行中です。** 2026年6月の買収により、2つ目のサービングスタックと別の顧客基盤を統合する必要が生じています。対策：現在 Seldon Core を使っている場合は、ご利用のバージョンの移行パスとサポート期間を契約書に明記してください。
