## Ce que c'est

Cursor est l'IDE AI-native devenu l'environnement de développement par défaut des ingénieurs qui construisent des agents, des serveurs MCP et la partie technique de l'automatisation ops. Forké depuis VS Code, il superpose une intégration AI profonde : autocomplétion à la touche tab, mode agent, contexte sur l'ensemble du codebase et support MCP complet.

## Pourquoi on le retrouve dans les stacks RevOps

Cet outil s'adresse aux GTM engineers et à la partie technique de RevOps — pas à l'organisation AE. Mais chaque équipe RevOps qui construit des workflows sur mesure, des nodes n8n, des serveurs MCP, des applications internes ou du code Salesforce Apex réalise de plus en plus ce travail dans Cursor. Le mode agent combiné au MCP permet de brancher Cursor à Salesforce, HubSpot, Snowflake, votre data warehouse, et de lui faire écrire du code qui opère sur vos données réelles.

- **Mode agent.** Agent de coding multi-étapes qui planifie, édite et exécute du code sous votre supervision. Plus rapide que Claude Code sur la plupart des tâches ; comparable sur les refactors complexes.
- **Contexte codebase.** Indexe l'ensemble de votre repo et l'utilise comme contexte. Pour les mono-repos RevOps avec intégrations custom, scripts et SQL, c'est déterminant.
- **Support des serveurs MCP.** Branchez n'importe quel serveur MCP à Cursor — Salesforce, HubSpot, [Linear](/fr/tools/linear/), votre CRM de prédilection — et l'AI peut lire et écrire des données tout en produisant du code qui les utilise.
- **Cursor rules.** Conventions par projet encodées dans des fichiers `.cursorrules`. Deviennent l'endroit canonique pour documenter « comment on construit les automatisations ici ».

## Tarifs

- **Free** — requêtes AI quotidiennes limitées
- **Pro** — 20 $/utilisateur/mois, usage AI généreux
- **Business** — 40 $/utilisateur/mois, inclut contrôles admin, SSO, privacy mode
- **Enterprise** — sur devis

L'accès API n'est pas exposé ; Cursor se consomme entièrement via l'IDE.

## Idéal pour

- Les GTM engineers, RevOps engineers et profils ops techniques qui écrivent du code sur mesure
- Les équipes qui adoptent MCP — Cursor est l'IDE MCP-aware le plus abouti
- Les solopreneurs et les petites équipes en vibe-coding ; le mode agent prend en charge la plupart des tâches de bout en bout
- Toute personne qui a essayé Copilot, Continue ou Codeium et veut quelque chose de nettement plus rapide et plus intelligent

## Points de vigilance

- Le privacy mode est en opt-in (palier Business et au-delà). Pour les environnements régulés, vérifiez les paramètres par défaut de rétention des données avant le déploiement.
- Plus efficace sur les gros codebases — sur des scripts d'un seul fichier, la surcharge par rapport à Claude Code ou claude.ai est réelle
- L'organisation engineering peut déjà avoir une préférence d'outillage (Copilot, Cody, Continue). Ce n'est pas un combat que RevOps a intérêt à mener.
