## 概要

Runlayer は、マネージド型の MCP ゲートウェイであり、エージェント向けのコントロールプレーンです。Claude、Cursor、ChatGPT、Codex、あるいは社内エージェントから送られるすべての MCP リクエストは、AWS 上のシングルテナントのゲートウェイ（Runlayer がホストするか、自社アカウントにデプロイするかを選べます）を通過します。ゲートウェイは呼び出し元を自社の ID プロバイダーで認証し、ポリシーを確認し、呼び出しをスキャンして監査ログに記録します。このゲートウェイの周囲に、購入担当者が実際に評価する 4 つの要素があります。社員が Okta のアプリランチャーのように選べる審査済み MCP サーバーのカタログ、実行時の脅威検知を担う ToolGuard と AgentGuard、社員が勝手にインストールしたサーバーやプラグインを見つけるシャドー AI 検出、そしてプロンプト・ツール呼び出し・権限判断を記録するセッション録画です。

同社は 2025 年 11 月 17 日にステルスを解除し、Khosla Ventures の Keith Rabois と Felicis が主導する 1,100 万ドルのシードを発表しました。2026 年 6 月 24 日には Felicis 主導、Khosla 参加の 3,000 万ドルのシリーズ A を発表し、調達総額は 4,200 万ドルです。CEO の Andy Berman は以前 Vowel を創業し、2024 年に Zapier へ売却しています。共同創業者の Tal Peretz と Vitor Balocco も Zapier 出身です。MCP の共同開発者である David Soria Parra がエンジェル投資家として参加しています。公表されている顧客には Instacart、Gusto、Opendoor、dbt Labs、AngelList、Decagon、Lemonade が含まれます。

## 答える問い

「チームが各自の判断で Claude や Cursor を MCP サーバーにつないでいる。エージェントがどのツールを呼べるかを誰が管理し、誰が監査するのか？」。Runlayer の答えは、自社で組み立てるインフラではなく、ベンダーが運用するコントロールプレーンです。Okta と Entra のグループは SSO と SCIM で同期されるため、Salesforce や Slack の MCP サーバーへのアクセスは、アプリ本体と同じグループメンバーシップに従います。監査ログは S3 へ継続的にエクスポートされ、Splunk、Sentinel、CrowdStrike に取り込めます。テレメトリは Datadog と Honeycomb に送れます。プラットフォームは SOC 2 Type II と HIPAA の認証を取得しています。

単なるゲートウェイとの違いは検知レイヤーです。ToolGuard は ML モデル群で、ツール定義・呼び出し・出力をスキャンし、ツールポイズニング、プロンプトインジェクション、認証情報、不可視文字を検出します。ベンダー公表の推論時間は 1 回の呼び出しあたり 50-100 ms です。AgentGuard はセッション全体を監視して逸脱を検出します。2026 年 2 月の OpenClaw for Enterprise の発表で、Runlayer は ToolGuard によってプロンプトインジェクションへの耐性がベースラインの 8.7% から 95% に上がったと報告しました。これはベンダー自身のベンチマークであり、独立した検証ではありません。検出は MDM で配布するエンドポイントエージェントで行われ、ノート PC 上の管理外の MCP サーバーを見つけ出します。

## 価格の実態

公開価格はありません。`runlayer.com/pricing` は 404 を返し、すべての商談はデモから始まり、無料プランもセルフサーブの登録もありません。Runlayer はシート単位ではなく、デプロイ規模と機能に応じたプラットフォーム料金で販売しています。1 人あたりの課金で利用拡大を妨げない、というのが同社の説明です。AWS Marketplace の掲載は 12 か月契約で、唯一の課金項目に 5,000,000 ドルの上限と超過 1 単位あたり 20 ドルが設定されています。これは見積もりではなく、プライベートオファー用のプレースホルダーとして扱ってください。実務上の利点は、Marketplace 経由で購入すれば既存の AWS 利用コミットメントに充当できる点です。

比較の目安として、[Obot](/ja/tools/obot/) は Kubernetes を自社で運用すれば MIT ライセンスで無料です。TrueFoundry は MCP サーバー 25 台までをカバーする月額 499 ドルの Pro プランを公開しています。Runlayer はエンタープライズ向けセキュリティソフトウェアの価格帯で、どちらよりも上です。セキュリティプラットフォームの予算項目として計上し、対象となるクライアント数とサーバー数によって見積もりが変動すると想定してください。

## 最適な対象

Claude Code、Cursor、ChatGPT がすでに日常的に使われ、MCP サーバーが誰もレビューしきれない速さで増えている、従業員 500〜5,000 人規模の企業の IT またはセキュリティ責任者です。Runlayer が明確に勝つ具体的なケースは、RevOps とサポートのチームが MCP 経由で Salesforce、Slack、Notion にアクセスし、セキュリティチームがすべてのツール呼び出しを Okta の ID に紐づけて SIEM に送ることを求め、かつセルフホストのゲートウェイを運用できるプラットフォームエンジニアがいない場合です。

## 向いていない対象

おおむね 50 人未満のチーム、あるいは営業との打ち合わせの前に価格を知りたい人には向きません。また、セキュリティレビューでリクエスト経路上のクローズドソースソフトウェアが認められない場合や、AWS を使っていない場合も不適切な選択です。Runlayer のホスト型とセルフホスト型はいずれも AWS ベースで、Runlayer Operator は顧客管理の EKS または GKE クラスターにも対応しています。

## 代替製品との比較

- **[Obot](/ja/tools/obot/)**：MIT ライセンス、セルフホスト、ツール呼び出しとモデル呼び出しを 1 つのポリシーで管理します。Kubernetes の運用スキルがあり、認証情報の経路にベンダーを入れないことが要件なら Obot を選んでください。ML による脅威検知とエンドポイントでの検出は失われます。
- **Docker MCP Gateway**：このカテゴリで最も広く普及しており、Docker Desktop の MCP Toolkit に同梱されています。開発者のマシン上での安全なローカル実行が目的なら選んでください。「全社で見て、どの社員がこの書き込みを許可したのか」には答えられません。
- **Amazon Bedrock AgentCore Gateway**：ハイパースケーラーの選択肢で、AWS 内で API や Lambda 関数を MCP ツールに変換します。エージェントが Bedrock 上に構築されていて、IAM がすでに信頼している ID モデルであれば選んでください。
- **[Rippling](/ja/tools/rippling/) AI Governance**：最も動きの速い新規参入者です。MCP ゲートウェイ、AI ゲートウェイ、エージェント ID、シャドー AI 検出を備え、Runlayer と Rippling が 8 月 19 日に和解なしで相互の訴訟を取り下げた直後の 2026 年 8 月にリリースされました。Rippling がすでに HRIS で、追加のベンダーなしに役職や雇用状態に合わせてアクセスを変えたい場合に選んでください。
- **[Composio](/ja/tools/composio/) または [Arcade](/ja/tools/arcade-dev/)**：大規模な連携カタログを持つマネージド型のツール認証です。社員がすでにつないだツールを統制することではなく、今四半期中にエージェントから数百の SaaS アプリへ書き込めるようにすることが目的なら選んでください。

本当の懸念が MCP トラフィックではなく SaaS のコパイロットにおけるシャドー AI であれば、まず [Zenity](/ja/tools/zenity/) か [WitnessAI](/ja/tools/witnessai/) を検討してください。

## 注意点

- **クローズドソースでベンダーが運用し、すべてのエージェント呼び出しの経路上にあります。** Runlayer の障害や価格変更は、社内のすべてのエージェントに影響します。対策：チームが運用できるなら自社 AWS アカウントへのセルフホスト型を選び、稼働率の SLA とデータエクスポートの条件を書面で取り付け、重要な MCP サーバー向けに文書化されたバイパス手段を用意してください。
- **ドキュメント上にベータ版のコンポーネントがあります。** 人による承認ルールはベータ扱いで、まだ特定のリソースに絞り込めません。LLM ゲートウェイはアーリーアクセスで、セルフホスト版の ToolGuard には GPU が必要です。対策：パイロット前に自社ポリシーが求める制御を正確にリスト化し、それぞれを GA 機能だけで検証してください。
- **カテゴリの勝者はまだ決まっていません。** Rippling は競合するゲートウェイを HR プラットフォームに組み込み、Okta、Microsoft、AWS もエージェント ID の機能を提供しています。対策：契約は 36 か月ではなく 12 か月にし、更新時の値上げに上限を設け、乗り換え後も SIEM に残せる形式で監査ログをエクスポートできることを確認してください。
- **検知性能のベンチマークはベンダー自身のものです。** インジェクション耐性 95% という数字は Runlayer の公表値です。対策：パイロットで自社で用意した汚染済みのツール説明を使って ToolGuard をレッドチームし、ブロックを有効にする前に 2 週間、実トラフィックでの誤検知率を追跡してください。
