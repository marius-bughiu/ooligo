Cursorは、リポジトリの検索、ファイルの編集、コマンド実行ができるエージェントを備えたコードエディタです。RevOps業務の変更にコードレビューが必要なときに使えます。たとえば、CRMへの取り込み時に商談ステージを対応付ける関数を探すよう依頼します。未定義のステージを含む架空の行を渡し、その行が確認待ちとなり、CRMへの書き込みが0件になることをテストで確かめてから修正を承認します。[Cursor Agentの概要](https://cursor.com/docs/agent/overview)

## プランに含まれる機能と追加料金

新規の個人契約では、Freeはエージェントの利用量に制限があります。Plusは月8米ドルで、外部のモデルは選べません。Premiumは月30米ドルで、クラウドエージェントを利用できます。PremiumでClaudeモデルを選ぶと、その利用分は契約料とは別にAPIの公示価格で前払い残高から引かれます。いずれも2026年11月2日に確認した、ウェブ契約の月払い税抜き価格です。[Cursorの料金](https://cursor.com/pricing)・[モデルと課金条件](https://cursor.com/docs/models-and-pricing)

旧Proを契約中なら、月20米ドルで旧プランの利用条件を維持できます。Cursorによると、新プランへの移行は任意で、移行後は元のプランに戻せません。次回の請求額を見積もる際は、まずアカウントに表示されたプランを確認します。[旧プランの条件](https://cursor.com/docs/account/pricing/legacy-cursor-plans)

## APIとMCPが扱う範囲

Cloud Agents API v1はパブリックベータです。スクリプトから `POST /v1/agents` を呼び出すと、接続済みのリポジトリでエージェントを起動できます。実行状況もAPIで確認できます。GitHubやGitLabなどに対応し、利用可能なアカウント、アクセスを許可したリポジトリ、ユーザーまたはサービスアカウントのAPIキーが必要です。[Cloud Agents API](https://cursor.com/docs/cloud-agent/api/endpoints)

MCPサーバーを設定すると、特定の外部ツールをCursorから利用できます。CRMの項目定義を読むだけなら、その情報に限定した読み取り権限を与えます。クラウドエージェントを起動するAPIキーだけでは、CRMへの書き込み権限は得られません。[MCPの設定](https://cursor.com/docs/mcp)

## リポジトリへのアクセスを許可する前に

個人ユーザーは設定でPrivacy Modeを有効にでき、管理者はチーム単位で設定できます。Cursorによると、有効にすれば顧客データは学習に使われません。データ保持には、不正利用の調査や選択したモデルに応じた例外があります。自分のワークスペースで有効なモード、使用モデル、接続を許可するリポジトリを確認してください。[Cursorのセキュリティ](https://cursor.com/security)・[データの取り扱い](https://cursor.com/data-use)

すでに[Claude](/ja/tools/claude/)を契約している場合は、[ClaudeとCursorの比較](/ja/vs/claude-vs-cursor/)にある2行のCRMデータで、エディタを追加する価値を検討できます。
