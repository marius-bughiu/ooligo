## 概要

Spott は、ATS とリクルーティング CRM を1つのワークスペースにまとめた製品で、社外の人材紹介エージェンシー — 正社員紹介、エグゼクティブサーチ、業務委託、派遣 — 専用に作られており、社内の HR チーム向けではないと明言しています。2024年にベルギーの Leuven で創業し、Y Combinator (W25) を経て、2025年後半にコアプラットフォームをローンチしました。2026年9月22日には、Balderton Capital が主導し、Base10、Y Combinator、Fortino が参加する $21M のシリーズ A を発表しています (tech.eu、The Next Web)。これにより累計調達額は $24.2M になりました。同社によれば、プラットフォーム上のエージェンシーは 500+ 社で、売上は2026年初めから10倍以上に伸びています。

売り文句は「システムが勝手に埋まる」ことです。通話、メール、WhatsApp のスレッド、CV が取り込まれ、文字起こしされ、該当する候補者またはクライアントのレコードに紐づけられます。AI はそのレコードを起点に動き、求人に対する候補者のランク付け、アウトリーチ文面や推薦書の下書き、次のタスクの提案を行います。置き換えを狙っている製品は [Bullhorn](/ja/tools/bullhorn/) で、同社自身が掲げる理想の顧客像は、Bullhorn、Loxo、Vincere、JobAdder から移行しようとしている、英国またはベルギーの20ユーザー以上のエージェンシーです。

## エージェンシーのスタックで採用される理由

- **マッチングは2段階で、根拠を説明できる。** まずハードフィルターで候補を絞り込み、残った候補をベクトルモデルが記述された条件に照らしてランク付けします。リクルーターは CV のキーワードだけでなく、メモ、添付ファイル、通話の文字起こしを横断して自然言語で検索できます。本当の差別化要因はこの最後の点です。5年分の通話メモを検索できるデータベースには、より優れたパーサー以上の価値があります。
- **AI の利用料はシート価格に含まれている。** 価格ページには、マッチング、メモ作成、アウトリーチ文面の下書き、レコメンドにかかるトークン費用はすべてのプランに含まれると明記されています。従量課金の追加費用は連絡先データ用のエンリッチメントクレジットだけです。対照的に [Loxo](/ja/tools/loxo/) では、エージェント、アウトリーチ、AI Chat のすべてが繰り越しなしの月間クレジットプールから消費されます。
- **公式の MCP サーバーと公開 REST API。** Spott は自社の MCP を通じた [Claude](/ja/tools/claude/) と [ChatGPT](/ja/tools/chatgpt/) 向けのファーストパーティコネクタを掲載しており、api-docs.spott.io で API ドキュメントも公開しています。リクルーターはミドルウェアを挟まずに、Claude からエージェンシーのデータベースに問い合わせることができます。
- **コミュニケーション機能は後付けではなくネイティブ。** WhatsApp (Business API 経由のテンプレート一斉送信を含む)、Aircall、Ringover、RingCentral、Dialpad、Zoom のすべてが、レコードごとに1本のタイムラインへ同期されます。候補者が WhatsApp 上にいる欧州のデスクでは、この1つの連携だけで評価が決まることも少なくありません。

## 価格の実態

spott.io/pricing に掲載されている2026年10月3日時点の内容です。1ユーザーあたりの月額です。

- **Core — 年間契約で $119 (月額契約は $149)。** ATS/CRM、AI ノートテイカー、AI 検索とマッチング、メール・SMS・WhatsApp を横断する単一の受信箱、CV リフォーマッター、ショートリスト。
- **Pro — 年間契約で $179 (月額契約は $219)。** 自動化、マーケティングスイート、マルチチャネルのシーケンス、データエンリッチメントが加わります。
- **Enterprise — デモを予約。** カスタムの利用規約と DPA、高度なロールと権限、複数拠点の管理、専任の窓口担当者が加わります。見積もりのみとして扱ってください。

年間契約の価格は取り消し線付きの $139 と $199 の下に表示されているため、確定した定価ではなく現時点のオファーとして読むべきです。更新時の価格は契約書に書かせてください。エンリッチメントクレジットは別料金で、ページ上に価格はありません。

定価ベースでは、Pro を年間契約で10シート契約すると年間 $21,480、Core を10シートなら $14,280 です。Loxo の Professional を10シートなら $23,880、Bullhorn を10シートなら、当サイトの Bullhorn エントリーで引用している第三者の TCO 調査によれば初年度 $34,000-$46,100 かかります。Spott は年間料金より約 22-25% 高い月額契約でも販売しており、Loxo は年間前払いのみです。

## 適しているのは

欧州、英国、オーストラリアの、正社員紹介・サーチ・業務委託を扱うおよそ10〜200シート規模のエージェンシーのオーナーや業務責任者で、誰も CRM を入力しないという理由で Bullhorn、Vincere、JobAdder から離れようとしており、その入力を通話の取り込みとマッチングに肩代わりさせたい層です。ベンダーによれば、エンタープライズ顧客は 200+ シートで運用しています。

**事業会社の TA には向きません。** 自社への採用であれば、求人票と面接のワークフローには [Greenhouse](/ja/tools/greenhouse/) や [Ashby](/ja/tools/ashby/) が合います。クライアント・推薦・成約という Spott のモデルとは噛み合わず、抵抗を受け続けることになります。

## 代替製品との比較

- **[Bullhorn](/ja/tools/bullhorn/)** は導入実績のリーダーであり、支払・請求、VMS 連携、350以上のパートナーマーケットプレイスを必要とする大規模な派遣事業にとっては今も第一候補です。課題がバックオフィスのカバー範囲ではなく、定着率とデータ品質にある場合は Spott を選んでください。
- **[Loxo](/ja/tools/loxo/)** はもう一方の AI ネイティブの極です。ボトルネックが、まだ自社で持っていない人材を見つけることであれば Loxo を選んでください。850M+ プロフィールのグラフがシートに含まれています。価値が自社のデータベースと通話履歴の中に眠っているなら Spott を選んでください。
- **[Recruit CRM](/ja/tools/recruit-crm/)** は年間契約 $95 という価格の下限で、勤怠管理を製品内に備えています。予算の厳しい10シート未満の業務委託デスクなら、こちらを選んでください。
- **[Recruiterflow](/ja/tools/recruiterflow/)** は急成長中のチャレンジャーとして Spott と競合しており、一律 $149 でアウトバウンド重視の米国ブティックに対しては勝っています。

## 注意点

- **ベンダーは創業から2年も経っていない。** コアプラットフォームの提供開始は2025年後半で、レビューの母数も少なく、今回の確認時点で G2 に11件、Capterra に2件です。ガード: 現在お使いのシステムから移行した同規模のエージェンシーとのリファレンスコールを必ず要求し、全データのエクスポート (レコード、メモ、文字起こし、添付ファイル) を契約書に明記してください。
- **バックオフィスはパートナー経由で動く。** 支払・請求はネイティブではありません。Spott は成約時に請求書を Xero に同期し、Timesheet Portal に接続します。ガード: 派遣・業務委託のデスクは、移行中ではなく署名前に、勤怠と請求のフローを端から端までスコープしてください。
- **4週間での移行はベンダーの主張にすぎない。** Spott は既存製品の 16+ 週間に対して約4週間とうたっています。ガード: カットオーバー日を確定する前に、データベースの 10% のサンプルでテスト移行を行い、メモと添付ファイルが正しいレコードに入るかを確認してください。
- **データ所在地のデフォルトは EU で、OpenAI がサブプロセッサーとして記載されている。** ガード: クライアントとの契約でデータの所在地条項を持つ米国や APAC のエージェンシーは、リージョンの選択肢とサブプロセッサー一覧を DPA で確認してください。カスタム DPA は Enterprise の機能です。
- **エンリッチメントが未確定の費用項目。** ガード: エンリッチメントクレジットの価格を書面で取得し、デモでの見積もりではなく、自社データベースのうちメールアドレスや電話番号が欠けている割合をもとに規模を見積もってください。
