## 概要

Hunter は、企業ドメインを軸に作られたセルフサーブ型のメールアドレス検索・検証ツールです。ドメインを入力すると、Hunter がそのドメインについてインデックスしている公開の業務用アドレスが、見つかった掲載元とともに返ってきます（Domain Search）。氏名とドメインを入力すると、その人物の最も可能性の高いアドレスが信頼度スコア付きで返ってきます（Email Finder）。リストを貼り付ければ、各アドレスが検証されます（Email Verifier）。この中核機能の周りに、Discover（フィルター付きの企業検索）、人物・企業のエンリッチメント、Chrome/Firefox/Edge 拡張機能、Google Sheets アドオン、そして自社の Gmail または Outlook の受信箱からシーケンスを送る軽量なコールドメール送信機能 Campaigns があります。Hunter は 2015 年に Antoine Finkelstein と François Grante が創業し、完全リモートで運営され、700 万のユーザーアカウントと 8,100 万のインデックス済みウェブサイトを公表しています。

Hunter ではないもの：電話データのソースでも、網羅的なコンタクトデータベースでもありません。API には電話番号のフィールドがありますが、Hunter は携帯番号のカバレッジを商品として販売しておらず、強みはドメインベースのメール発見であって、数百のフィルターを使った人物検索ではありません。また単一ソースです。Hunter にアドレスがない場合、その背後で他のソースが照会されることはありません。

## RevOps のスタックに入る理由

- **全プランでユーザー数無制限。** Hunter が課金するのはクレジットプールであり、ユーザーではありません。10 人のチームが Growth を使っても契約は 1 つで済みますが、[Prospeo](/ja/tools/prospeo/) や [Apollo](/ja/tools/apollo/) のようなユーザー単位課金のツールでは担当者ごとに費用がかかります。そのため、同じ会社のマーケティング、パートナーシップ、採用、営業が「全員にログインを配る」用途のメール検索ツールとして定番になっています。
- **検証が標準搭載で安価。** 検証 1 件は 0.5 クレジットで、失敗した検証や「unknown」の結果は無料、同じアドレスの再検索は請求期間ごとに 1 回しかカウントされません。6 つのステータス（`valid`、`invalid`、`accept_all`、`webmail`、`disposable`、`unknown`）は、CRM のルーティングルールを動かせるほど明確です。
- **アドレスごとに掲載元を表示。** Domain Search は、各メールが掲載されていたページを一覧表示します。担当者が送信前にアドレスを確認する最速の方法であり、Hunter が今も手作業で開かれるツールであり続けている理由です。
- **無料プランを含む全プランで API と MCP。** REST API は Discover、Domain Search、Email Finder、Email Verifier、エンリッチメント、リードをカバーし、レート制限は検索とエンリッチメントで毎秒 15 リクエスト、検証で毎秒 10 リクエストです。公式 MCP サーバー（`https://mcp.hunter.io/mcp`、API キーまたは OAuth）は、同じツールを [Claude](/ja/tools/claude/)、[ChatGPT](/ja/tools/chatgpt/)、[Gemini](/ja/tools/gemini/) に追加料金なしで提供します。ネイティブ連携は [HubSpot](/ja/tools/hubspot/)、[Salesforce](/ja/tools/salesforce/)、[Pipedrive](/ja/tools/pipedrive/)、[Zapier](/ja/tools/zapier/)、[Make](/ja/tools/make/)、[Clay](/ja/tools/clay/)、[Snowflake](/ja/tools/snowflake/) に対応しています。

## 料金

2026-10-18 に hunter.io/pricing で確認しました。価格はユーロ表示でした。すべてのプランで、チームメンバー数は無制限、1 つのクレジットプールを共有します。

- **Free** — 0 ユーロ、月 50 クレジット、接続メールアカウント 1 件、キャンペーンあたり受信者 500 件。
- **Starter** — 月額 49 ユーロ（2,000 クレジット）、または年額 408 ユーロ（月換算 34 ユーロ）で 24,000 クレジットを前払いで一括付与。接続アカウント 3 件、受信者 2,500 件。自動検証、エンリッチメント、Discover の高度なフィルターが加わります。
- **Growth** — 月額 149 ユーロ（10,000 クレジット）、または年額 1,248 ユーロ（月換算 104 ユーロ）で 120,000 クレジット。接続アカウント 10 件、受信者 5,000 件。
- **Scale** — 月額 299 ユーロ（25,000 クレジット）、または年額 2,508 ユーロ（月換算 209 ユーロ）で 300,000 クレジット。接続アカウント 20 件、受信者 15,000 件、アカウントマネージャー付き。
- **Enterprise** — 個別見積もり。別枠の API 専用 Data Platform では、12 か月有効のクレジットをまとめて販売しています。Hunter の例では、検索クレジット 1,000 件と検証クレジット 200,000 件で 6,500 ドルです。
- **1 クレジットで買えるもの。** 見つかったメール 1 件（Domain Search、Email Finder、Bulk Email Finder）は 1 クレジット、Bulk Domain Search は見つかったメール最大 10 件ごとに 1 クレジット、検証 1 件は 0.5 クレジットです。失敗した検索は無料です。
- **実際のコスト。** Starter 月払いでは、見つかったメール 1 件あたり約 0.025 ユーロ、検証 1 件あたり約 0.012 ユーロ（1,000 件で 12.25 ユーロ）です。Growth 年払いでは、それぞれ約 0.010 ユーロと 0.005 ユーロまで下がります。Instantly の 2026 Email Verification Benchmark（2026-01-31）は Hunter を検証 1,000 件あたり約 24.50 ドルとしていますが、これは検証ではなく Starter の「見つかったメール」1 件あたりのコストと一致します。上記のクレジット計算を使ってください。10 人のチームの場合、Growth 年払いの合計 1,248 ユーロに対し、Prospeo Growth を 10 ユーザー分契約すると約 8,880 ドルになります。ただし Prospeo には携帯番号も含まれます。

## 最適な利用者

- ユーザー単位の課金なしで、3〜30 人が共有できるメール検索・検証ツールを必要とする、小規模チームのマーケティング、パートナーシップ、営業の責任者
- HubSpot、Salesforce、Clay、Zapier、または MCP 接続のエージェントから呼び出す、シーケンス前の安価な検証ステップが欲しい RevOps チーム
- Campaigns を使い、自社の受信箱から少量・ドメイン起点のアウトリーチを行う創業者やエージェンシー
- 電話中心のアウトバウンドには不向き（[Lusha](/ja/tools/lusha/) か [Prospeo](/ja/tools/prospeo/) を使ってください）。フィルターを多用する人物検索やインテントには不向き（[Apollo](/ja/tools/apollo/) か [ZoomInfo](/ja/tools/zoominfo/) を使ってください）。多数の受信箱を使う大量のコールドメールには不向き（[Instantly](/ja/tools/instantly/) か [Smartlead](/ja/tools/smartlead/) を使ってください）

## 代替ツールと選び分けのルール

- **[ZoomInfo](/ja/tools/zoominfo/)** — カテゴリのシェア首位。最も深いデータベース、インテントデータ、組織図を、個別の年間契約で提供します。アカウントインテリジェンスと直通番号が目的なら ZoomInfo を選んでください。公開価格で検証済みの業務用メールが目的なら Hunter を選んでください。
- **[Apollo](/ja/tools/apollo/)** — もう一方のシェア首位。コンタクトデータベース、シーケンス、ダイヤラーを年払いで 1 ユーザーあたり月 49 ドルからまとめて提供し、無料プランでも API と MCP が使えます。1 ユーザーで検索、シーケンス、架電までこなす必要があるなら Apollo を選んでください。多くの人がときどきメールを調べる程度で、ユーザー単位課金が無駄になるなら Hunter を選んでください。
- **[Clay](/ja/tools/clay/)** — ここで挙げた中で最も成長の速いプラットフォームです。多数のプロバイダーをウォーターフォールで組み合わせ、Hunter もその 1 つです。プロバイダーの順序とフォールバックを自分で制御したいなら Clay を選んでください。1 つのソースで自社のセグメントをカバーできるなら、Hunter を直接選んでください。
- **[Prospeo](/ja/tools/prospeo/)** — ユーザー単位のクレジット制で、データは 7 日ごとに更新され、携帯番号は 10 クレジットです。メールと電話番号の両方が必要な SDR には Prospeo を選んでください。メール専用の共有プールなら Hunter を選んでください。
- **[FullEnrich](/ja/tools/fullenrich/)** — 20 以上のプロバイダーをまとめたパッケージ型ウォーターフォールで、ヒットした分だけ課金します。Hunter で見つからないコンタクトには FullEnrich を選んでください。単一ソースは、インデックスしていないものは見つけられません。

## 注意点

- **プールは 1 つ、ユーザーは無制限。** ユーザー数が無制限ということは、1 人の一括処理でその月のクレジットが全員分なくなりうるということです。対策：Domain Search と Bulk Email Finder の一括処理は 1 つの管理者アカウントから実行し、自動エンリッチメントは API や Zapier 経由で 1 日の上限を設けて流してください。全ユーザーに一括処理ツールを渡すのは避けます。
- **`accept_all` は `valid` ではありません。** キャッチオールドメインはどんなアドレスも受け付けるため、Hunter はメールボックスの実在を確認できず、レビューでもこの領域の精度は一貫して低いと報告されています。対策：`valid` のアドレスは通常どおり送信し、`accept_all` は [ZeroBounce](/ja/tools/zerobounce/) などの 2 つ目の検証ツールか小規模なテスト送信に回し、バウンスしたものはすべて除外してください。
- **クレジットは失効します。** 月払いのクレジットは毎月、年払いのクレジットは更新時にリセットされ、繰り越しはありません。対策：最初の 2 か月は月払いで運用して実際の消費量を測り、その数字に合わせて年払いプランを選んでください。
- **小規模企業ではカバレッジが薄くなります。** ドメインベースの発見は、企業が公開ウェブ上に存在感を持っているほど効果的です。小規模企業や英語圏以外の市場では、返ってくるアドレスが少なくなります。対策：購入前に、実際のターゲットリストから 200 件のコンタクトを Hunter の無料プランと競合 1 社に通し、ツール自身の信頼度ラベルではなく、ヒット率と初回送信時のバウンス率で比較してください。
- **Campaigns は軽量です。** Scale で接続できる受信箱は 20 件（追加枠は有料アドオン）で、アウトバウンドのエージェンシーが専用のコールドメールプラットフォームでローテーションする受信箱の数には遠く及びません。対策：Campaigns は創業者主導やパートナーシップのアウトリーチに使い、大量のアウトバウンドは Instantly や Smartlead などの専用送信ツールで送り、Hunter はリストの検証だけに使ってください。
