## 概要

G2 Buyer Intent は、G2 が自社のレビューサイトに掲載されているソフトウェアベンダー向けに販売している、売り手側のデータ製品です。購入者が読む無料のレビューとは別物です。ある企業の誰かがあなたの G2 プロフィール、価格ページ、代替製品ページ、あなたを含む比較ページ、あなたのカテゴリ、あるいはカテゴリ内の競合のページを閲覧すると、G2 はそれをその企業のシグナルとして記録します。見えるのは企業です。人物は見えません。

G2 のドキュメントには、Profile、Pricing、Alternatives、Category、Compare、Sponsored content、Licensed content、Reference page、Competitive の9種類のシグナルが挙げられています。2022年6月以降、単一のインテントスコアはありません。代わりに各アカウントには **Buying Stage**（購買段階：Awareness、Consideration、Decision）と **Activity Level**（活動レベル：Low、Medium、High）が付与されます。G2 はこの両方を毎日再計算しています。

このページを作った理由は、2026年の2つの変化です。1つ目に、G2 は2026年1月に Gartner から Capterra、Software Advice、GetApp を買収することで合意し、6月までに取引は完了しました。2026年6月3日、G2 はこの3サイトすべてのリサーチを Buyer Intent に統合し、**既存顧客には追加費用なし** で提供しました。G2 はシグナルが最大2倍、市場にいるアカウントが36%増えたと報告しており、増加幅はカテゴリによって異なるとしています。2つ目に、G2 は Claude、ChatGPT、HubSpot（Breeze Agents 経由）、Gong、Profound、AirOps、のちに Microsoft Copilot 向けの **MCP 連携** をリリースしました。さらに Snowflake、BigQuery、Databricks のコネクタと、シグナルが連携先に届く前に ICP で絞り込むベータ版のオーディエンスビルダー **Intent Studio** も追加しています。

## RevOps スタックに登場する理由

このページが答える問いは次のとおりです。G2 が Capterra を所有するようになった今、G2 Buyer Intent にお金を払う価値はあるのでしょうか。それとも Bombora と 6sense ですでにカバーできているのでしょうか。

**両者は測っているものが違うため、どちらも相手の代わりにはなりません。** Bombora や ABM スイートが教えてくれるのは、ある企業が数千のパブリッシャーサイトにわたって、ある *トピック* について普段以上に読んでいるということです。G2 が教えてくれるのは、ある企業が *あなたのカテゴリのソフトウェア掲載ページ*、つまりあなたのプロフィール、価格、指名された競合との比較を見ているということです。これは購買プロセスのより後の段階で、範囲もずっと狭くなります。「sales engagement」に関する Bombora のサージは、ブログ記事を書いている誰かによって起きることもあります。価格ページの閲覧に続いてあなたと Outreach の比較が見られている場合、それが単なる調べもので終わることはまずありません。

Capterra の買収が重要なのは、G2 の以前の弱点を解消するからです。2026年より前は、SMB 向けソフトウェアのリサーチの大部分が Gartner の3サイトで行われ、G2 の顧客からは見えませんでした。今は1つのサブスクリプションで4サイトすべてが見えます。

## 価格の実態

Buyer Intent は見積もりのみのアドオンです。G2 のプランページには Free、Starter、Professional、Enterprise の4つの販売者向けティアが掲載されています。Buyer Intent がアドオンとして示されているのは Professional と Enterprise だけです。**Starter では購入できません。** Starter は初年度は月額 $299 または年額 $2,999 と掲載されていますが、これが示すのは有料プロフィールの最低ラインであって、インテントの費用ではありません。

- **価格は製品ごとに設定されます。** G2 のドキュメントによると、シグナルを受け取る製品ごとに個別のサブスクリプションが必要です。3つのカテゴリに3製品を掲載している企業は、3つのフィード分を支払います。
- **どのシグナル種類が得られるかはプランで決まります。** G2 のドキュメントには、プランによって受け取れるシグナル種類の数が異なると書かれています。見積もりを受けたティアのシグナル種類リストを書面で求めてください。
- **社外の数値は限られています。** Vendr は G2 の購入全体で中央値を年間約 $27,000 と報告していますが、この数字にはプロフィールパッケージとインテントが混在しています。ある集計サイトは Buyer Intent 単体で年間約 $55,000 としていますが、根拠は購入者レポート4件です。どちらも目安として扱ってください。

試算（あくまで試算です）：Professional で1製品に Buyer Intent アドオンを付けると、**年間で5桁台半ば** になります。これは、シグナルをもとに動くために必要なコンタクトデータを含まない金額です。広告プラットフォーム向けの Custom Audiences は、Buyer Intent を契約すれば含まれます。MCP と Market Intelligence へのアクセスはプランによって異なります。

## 最適なケース

**競争の激しい G2 カテゴリにいる B2B ソフトウェア企業の RevOps またはデマンドジェネレーションのリーダー** で、競合を把握できる後期段階のアカウントシグナルを Salesforce や HubSpot、そして SDR のシーケンスに流したい方です。G2 が文句なしに勝つ限定的なケースは、ターゲットアカウントがあなたの価格ページを閲覧したり、指名された競合とあなたを比較したりしたときに1日以内にアカウントオーナーに通知し、そこから競合対策のプレイを始める場合です。

## 向いていないケース

ソフトウェアを販売していない企業には向きません。G2 が見ているのはソフトウェア掲載ページでのリサーチだけです。また、あなたのカテゴリへの G2 のトラフィックが少ない場合や、プロフィールのレビューが少ない場合も見送ってください。フィードはまばらになり、どのティアでもそれは解決しません。さらに、どの人物がリサーチしているかを知る必要がある場合も見送ってください。データは企業単位なので、コンタクトは ZoomInfo Suggested Contacts や LinkedIn Sales Navigator などのアドオンから取得する必要があります。

## 代替ツールとの比較

- **6sense**：ABM プラットフォームの2大シェアリーダーの一つです。自社のシグナルとライセンスしたフィードをブレンドし、G2 を連携先として掲載しています。すべてのインテントソースにわたる予測ステージとオーケストレーションが欲しいなら 6sense を選んでください。レビューサイトのシグナルを単独で見たい場合に G2 を加えます。[6sense](/ja/tools/6sense/) を参照してください。
- **Demandbase**：もう一つの大手 ABM スイートで、こちらにも G2 連携があります。広告、アカウント識別、インテントを1社のベンダーでまかないたいなら Demandbase を選んでください。[Demandbase](/ja/tools/demandbase/) を参照してください。
- **Bombora**：卸売りのトピックインテントフィードです。アカウントリスト全体にわたる幅広いカテゴリのリサーチが必要なら Bombora を選んでください。掲載ページ単位で競合名が分かるシグナルが必要なら G2 です。両方を使っているチームも多くあります。G2 は自社の Audiences を Bombora のアクティベーション API 経由で配信してさえいます。[Bombora](/ja/tools/bombora/) を参照してください。
- **シグナルスタック型のアプローチ**：最も急成長している代替手段は、トリガーを自分で組み合わせることです。具体的には、[Warmly](/ja/tools/warmly/) や [RB2B](/ja/tools/rb2b/) によるファーストパーティの訪問者識別を、[Unify](/ja/tools/unify/) や [Clay](/ja/tools/clay/) でオーケストレーションします。後期段階のリサーチの大部分が自社サイトで行われているならこちらを選んでください。あなたのカテゴリの購入者が自社サイトを訪れる前にレビューサイトで候補を絞り込んでいるなら G2 です。

## 注意点

- **シグナルの量は、支払うティアではなくカテゴリで決まります。** **対策：** 契約前に、自社製品と上位3社の競合について過去90日間のシグナル件数を、サイト別（G2 と、Capterra、Software Advice、GetApp）に分けて G2 に求めてください。ターゲットセグメントの件数が少なければ、そこで検討をやめてください。
- **企業単位のデータは SDR のところで止まります。** 名前の分かるコンタクトがない「High activity」のアカウントは、リサーチ作業に変わってしまいます。**対策：** アドオンと同時にコンタクト層の予算も確保し、パイロットではダッシュボードではなく、ルーティング済みのコンタクトと商談を成果物として求めてください。
- **製品ごとの価格はいつの間にか膨らみます。** **対策：** カバーしたいすべての製品とカテゴリを洗い出し、最初の更新より前に、それぞれの価格を同じ見積もりに載せてもらってください。
- **Intent Studio はまだベータ版で、変更は翌営業日に反映されます。** **対策：** ICP フィルターのコピーを G2 の外に保管し、フィルターを変更したら1週間は CRM でシグナル件数を確認してください。
- **MCP へのアクセスはサブスクリプションに従います。** Copilot コネクタにはエンタープライズ版の Copilot ライセンスも必要です。**対策：** MCP の上にエージェントを構築する前に、自社のティアで MCP がどのデータを返すかを確認してください。

関連：[インテントデータ](/ja/learn/intent-data/) では、ファーストパーティのインテントと、G2、Bombora、ABM スイートが販売するサードパーティのフィードの違いを解説しています。[シグナルオーケストレーション](/ja/learn/signal-orchestration/) では、それをどうルーティングするかを扱っています。
