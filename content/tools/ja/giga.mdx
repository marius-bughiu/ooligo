## 概要

Giga は、問い合わせを回避させるのではなく AI エージェント自身が対応するエンタープライズ向けサポート製品です。音声を主軸に、チャットとメールも同一のエージェント定義の上で動きます。本社はサンフランシスコ、創業者は Varun Vummadi 氏と Esha Manideep Dinne 氏で、Y Combinator の Summer 2023 バッチには Giga ML として参加し、当時はファインチューニングしたオープンソースモデルをオンプレミスで販売していましたが、その後会社全体をエンタープライズサポートへ再ポジショニングしました。2025年11月5日に Redpoint がリードする 6,100万ドルのシリーズ A を発表し、Y Combinator と Nexus Venture Partners も参加、累計調達額は約 6,500万ドルです。

DoorDash が中核のリファレンスです。Dasher が配達を完了できない場合、Giga は Dasher との通話を保持したまま消費者に電話して住所を確認し、その結果を同一セッション内でポリシーと照合します。その他の公表顧客には Toast、Postman、Capital.com、Shiftsmart、Flex、Afriex、Remedy Meds があります。

## CX とサポートのスタックで検討される理由

- **Browser Agent が統合プロジェクトをクリティカルパスから外す。** Giga のエージェントは、サポート担当者と同じように既存の Web ツールにログインし、画面を操作してワークフローを完了させ、レコードが実際に更新されたことを検証し、すべての操作をログに残します。答えを保持しているシステムに対する API は不要です。返金、住所変更、権限付与のロジックがベンダーの管理コンソールや API のない内製ツールにある組織にとって、これは2週間の導入と2四半期の導入を分ける差であり、チャット起点のプラットフォームがどこも売っていない機能です。
- **実績が積み上がっているのは音声。** Giga は音声応答 400ミリ秒と 99言語対応を掲げ、音声におけるリアルタイムのハルシネーション訂正の技術的成果を公開しています。DoorDash の数値、2025年9月20日から10月20日の期間で配達ワークフローの解決率 90% 超は、ポリシーチェックを伴う複数当事者の調整を含んでおり、単一の発信者に対する FAQ 封じ込めよりも難しい形です。いずれもベンダー自己申告として扱ってください。独立監査を受けたものはありません。
- **構築面はプロンプト入力欄ではなくポリシーのキャンバス。** Agent Canvas はローコード環境で、ポリシー、エスカレーション経路、ツールを定義し、合格・不合格の件数付きでシミュレーションを実行し、リリースを切ります。プラットフォーム内蔵の AI 開発者である Scout は、あなたが指定した KPI に照らして本番の会話と人間の介入を読み、ポリシーやナレッジへの型付きの変更を提案し、まず限定トラフィックで検証します。Giga は12日間のロールアウトの形を公開しています。1日目に既存ドキュメントからベースラインのポリシーを起草、6日目に手動 QA を経てレビュー可能なバージョン、12日目にトラフィックの 1% でカナリアを実施してから 100% へ拡大します。
- **アクションのリスク階層がアーキテクチャに組み込まれている。** Giga 自身のアーキテクチャ解説は、作業を低リスクの読み取り、低リスクの書き込み、顧客確認を伴う書き込み、人間の承認を要するアクション、禁止アクションに分類し、ワークフローを全権限を持つ単一の自動化アカウントに集約してはならないという立場を明示しています。管理ツールの認証情報をエージェントに渡すのであれば、この分類こそがセキュリティレビューで必ず求められるものであり、それが求められる前から用意されています。
- **コンプライアンスの構成はエンタープライズ仕様。** 公開トラストセンターには SOC 2、ISO 27001、PCI DSS、HIPAA、GDPR が掲載されています。

## 価格の実際

公開情報はなく、セルフサーブのプランも価格ページもありません。個別のエンタープライズ契約のみです。2026年の第三者分析は、Giga の契約規模を最低でも年額6桁ドルのレンジに置き、同等の AI サポートベンダーの年額 5万〜10万ドルの帯と対比しています。実用的な適合ラインは月間の受信コンタクト 50,000件超で、月間 10,000件を下回る規模は Giga が売っているセグメントの外です。

より重要な欠落は、Giga が課金単位を公表していないことです。競合は公表しています。[Intercom](/ja/tools/intercom/) Fin は成果あたり 0.99ドル、[Zendesk](/ja/tools/zendesk/) は自動解決あたり 1.50ドル、[Parloa](/ja/tools/parloa/) は分単位です。公表されていないメーターは交渉可能なメーターなので、交渉してください。署名前に4点を書面で取り付けます。課金単位、年間の最低コミット額、それを超えた場合の超過料金、そして何をもって解決済みコンタクトとするかの書面上のテストです。4点目を省くと、四半期ごとの言い争いになります。

## 適しているのは

月間コンタクト数がおおむね 50,000件を超え、音声の比率が高く、最も量の多いワークフローが複数当事者の調整を含むか、統合する価値のある API を持たない管理ツールを経由するエンタープライズのサポート・CX 責任者です。配送と物流、マーケットプレイス、フィンテックのオペレーション、ホスピタリティが該当します。前回の AI エージェント評価での障壁が「対象の処理が Web コンソールの中にあるため、エージェントが実際にはその処理を実行できない」だったのであれば、このリストで最も強い選択肢です。

チャット中心で複雑度の低いボリュームの場合、調達プロセスなしで承認できる公開価格が必要な場合、あるいはコンタクト量が初年度6桁ドルのコミットを回収できない場合は見送ってください。

## 代替製品との比較

導入ベースで見た既存勢は [Zendesk](/ja/tools/zendesk/) と [Intercom](/ja/tools/intercom/) です。ヘルプデスクにすでに付属している AI が封じ込め率の基準を満たすなら、そちらを取ってください。チャット比率の高いオペレーションでは大半がこれが正解であり、常に最も安価な最初の検証です。[Sierra](/ja/tools/sierra/) はこのセグメントで最も成長の速い新規勢で、2026年5月時点の ARR は約2億ドルです。同じトランザクション志向を、はるかに長いエンタープライズ導入実績とともに求めるなら Sierra を選んでください。[Parloa](/ja/tools/parloa/) は、Genesys、Five9、NICE、Avaya といった既存の電話基盤との接続が決め手になる場合、そして事前にモデル化できる分単位のメーターが欲しい場合の選択肢です。[Decagon](/ja/tools/decagon/) は積極的なチャット回避で優ります。4社に対する Giga の主張は狭く、そして実在します。API がないときにあなたの画面を操作する製品であり、そのためのアクションリスク分類を公開している製品だという点です。

## 注意点

- **見出しの数値はすべてベンダー自己申告。** 解決率 90% 超、テクノロジー業種で 98%、応答 400ミリ秒、いずれも Giga 自身の数字で独立監査はなく、「解決」の定義を決めるのは請求する側です。ガード: 署名前に自社のトラフィックで2週間のシャドー運用を要求し、自社の定義で採点してください。クローズ後 7日以内に再問い合わせがない、フローの途中で離脱していない、黙ってエスカレーションされていない、という定義です。これを SOW の努力目標ではなく、契約書の受入テストとして書き込みます。
- **Browser Agent は管理ツールの内側で動く認証情報付きのロボット。** Giga を面白くしている機能は、このページで最大の影響範囲でもあり、ブラウザ自動化はベンダーが予定外の画面変更を出した瞬間に壊れます。ガード: 共有の自動化アカウントではなくワークフローごとにサービス ID を分け、初日は読み取りと顧客確認付き書き込みの階層に限定し、金銭が絡むものは人間承認の階層に通し、アクション失敗率にアラートを設定して、静かな画面変更がバックログではなく指標として表に出るようにします。
- **Scout は本番の挙動を変える。それが狙い。** KPI に照らしてポリシー変更を提案・検証するループは実際の強みであると同時に、監査担当が見たことのない変更管理の面でもあります。ガード: Scout の変更が 1% のカナリアを出る前に、氏名の記録される人間の承認を必須にし、変更ログを毎月自社の記録システムへエクスポートしてください。エージェントに何を指示したかの履歴をベンダーだけが持つ状態にしてはいけません。
- **会社は若く、これは2つ目の製品。** Giga ML はオンプレミスのモデルを売っていました。Giga はサポートエージェントを売っています。転換は最近で、現行製品の公開実績は短く、リファレンスは少数のロゴに集中しています。ガード: 初回の契約期間は1年に留め、ポリシー、通話記録、シミュレーションケースを利用可能な形式で持ち出せる権利を契約に入れ、インシデントの後ではなく署名の前に代替ベンダーを決めておいてください。
- **オムニチャネルは実証より先にマーケティングされている。** Giga は音声、チャット、メール、SMS、WhatsApp を履歴共有で1つのエージェントとして売っていますが、公開されている裏付け、つまり顧客、指標、技術文書はいずれも音声に大きく偏っています。ガード: 非音声チャネルをデモから見積もるのではなく、パイロット期間中に実際のチケットで自社のチャットとメールの評価を実施してください。音声が自社のコンタクト構成の 40% 未満であれば、Decagon や既存ベンダーのネイティブエージェントを並行して評価します。
