## 概要

Merge は 1 つの会社が提供する 2 つの製品です。古いほうは共通データモデルの統合 API で、HRIS、ATS、CRM、会計、チケット管理の各システムを 1 つのスキーマで扱えるようにし、B2B SaaS ベンダーが自社顧客向けの連携機能を出荷するために組み込みます。新しいほう、そしてオペレーション責任者の候補リストに入る理由が **Agent Handler** です。これはホスト型の MCP レイヤーで、[Claude](/ja/tools/claude/)、Claude Code、[ChatGPT](/ja/tools/chatgpt/)、[Cursor](/ja/tools/cursor/)、あるいは社内エージェントが、マネージド認証、範囲を絞った **Tool Packs**、すべてのツール呼び出しの入力と出力に対する DLP スキャン、そしてアクションごとに ID・引数・下流の API 呼び出し・結果を記録する監査ログを通じて社内システムを呼び出せるようにします。

2026 年 6 月 1 日、Merge は Agent Handler for Employees をリリースし、その後 **Merge for Workforce** に改名しました。[Okta](/ja/tools/okta/)、Azure AD、または任意の SCIM プロバイダーから従業員とグループを同期し、ロールを承認済みツールに対応付け、すべてのツール呼び出しを従業員本人の ID で実行します。さらに MDM で配布するデスクトップクライアントが、未承認のモデルと MCP サーバーを端末上でブロックします。2026 年 6 月 2 日のプレスリリースでは、[Microsoft 365 Copilot](/ja/tools/microsoft-365-copilot/) 向けに Microsoft Agent Store 経由で Agent Handler に接続できるようになると発表されました。

Merge は 2020 年創業で、2022 年 10 月に Accel がリードする $55M のシリーズ B を調達し（累計約 $74.5M）、Agent Handler の導入企業ロゴとして OpenAI、Perplexity、Ramp、JetBrains を掲げています。SOC 2 Type II と ISO 27001 を取得していると表明しています。

## 実際に解消する課題

どちらの製品を買うかで、解消する課題は 2 つに分かれます。エージェントを構築するプラットフォームチームにとって、Agent Handler は最も手間のかかるシステムのコネクタ保守を肩代わりします。コネクタの約 30% はベンダーの承認が必要で、Merge は Workday、NetSuite、Greenhouse、DocuSign と契約を締結済みです。統合 API 事業から受け継いだこの資産、つまり自前の OAuth アプリではすぐに得られない HRIS・ATS・ERP へのパートナーアクセスこそ、Composio と Arcade が再現できない唯一の点です。

IT 部門にとって、Merge for Workforce は「従業員はすでに Claude Desktop や ChatGPT を社内データにつないでいる。どう統制するか」という問いに、IdP 主導のアクセス制御と、コネクタ単位・チーム単位・全社単位で設定できる DLP ルールで答えます。

## 実際の価格

- **Free** — $0、月 2,000 クレジット、ユーザー数と Tool Packs は無制限。プロトタイプ専用です。
- **Pro** — 月額 $1,000 で 25,000 クレジット。月 100,000 クレジットまでの大きなブロックもありますが、その価格は非公開です。超過分は月末に請求され、超過クレジットの単価は公開されていません。
- **Enterprise** — 個別見積もり。SIEM へのログストリーミング、オンプレミスおよびマネージド VPC へのデプロイ、カスタムコネクタ、フォワードデプロイドエンジニア、個別 SLA はこのプランに含まれます。
- **Merge for Workforce** — 見積もりのみ。従業員数、コネクタ、デプロイ形態で決まります。

価格ページにはクレジットが「ツール呼び出しのたびに消費される」とありますが、クレジットと呼び出しの換算比率は公開されていません。1 回の呼び出しが 1 クレジットなら、Pro は 1 回あたり $0.04 となり、Arcade の $0.01 の 4 倍、Composio の $0.0003 の約 130 倍です。月 25,000 回の呼び出しでは、Arcade の Team プランは約 $275、Composio Pro は $50 未満に収まりますが、Merge は超過前で $1,000 です。本番導入の現実的な価格帯は最低でも年 $12,000 で、SIEM ストリーミングが必要になった時点で Enterprise になります。そしてほとんどのセキュリティレビューはそれを求めます。

## 最適な利用者

従業員がすでに Claude、ChatGPT、Copilot を使っていて、それらのアシスタントがどの SaaS に触れるかを承認し、すべての呼び出しに監査証跡と DLP を求める、従業員 500 名以上の企業の IT またはセキュリティ責任者です。明確に勝てる場面は、Workday や Greenhouse を読むエージェントを導入したい People Ops や Recruiting 組織です。Merge のパートナー承認済みコネクタによって、ベンダーとの何か月もの交渉を省けます。

## 向かないケース

Gmail、Slack、Linear 上で大量の呼び出しを行うエージェントを試作するスタートアップには向きません。呼び出し単価が合わず、カタログも Composio より小さいためです。イベントトリガーやコードのサンドボックスが必要なチームにも向きません。Merge 自身の比較記事でも、イベント駆動の機能が少ないことを認めています。

## 代替ツールとの比較

- **[Composio](/ja/tools/composio/)** — エージェント向けツール専業として最大のカタログを持ち、呼び出し単価も最安です。エンジニアリングチームが幅と量を必要とし、Composio がトークンを保持することを受け入れられるなら選んでください。2026 年 5 月のインシデントでは約 5,001 件の GitHub 接続と 5,241 件の API キーが流出しました。
- **[Zapier](/ja/tools/zapier/) MCP** — 組織がすでに Zapier に支払っていて、オペレーション担当のジェネラリストが少量のアシスタントを接続する場合に選んでください。
- **[Arcade](/ja/tools/arcade-dev/)** — 最も急成長している新興勢力です。ユーザー単位の OAuth とアクション単位の認可が要件で、HRIS/ERP へのパートナーアクセスがボトルネックでないなら、Merge の 4 分の 1 の呼び出し単価で手に入るこちらを選んでください。
- **[Runlayer](/ja/tools/runlayer/)** または **[Obot](/ja/tools/obot/)** — Merge 独自のコネクタではなく、すでに選定済みの MCP サーバーの前にゲートウェイを置きたい場合に選んでください。Obot は自前で運用すれば無料です。

どれも合わない場合は、ベンダー自身の MCP サーバーの前に MCP ゲートウェイを置き、得られるコネクタ品質を受け入れてください。

## 注意点

- **クレジットの定義が公開されていません。** 価格ページから請求額を試算できません。対策：クレジット換算表と超過単価を発注書に明記させ、Pro に署名する前に実際の Tool Packs で Free プランの 30 日間パイロットを行い、ワークフローごとの消費クレジットを測定してください。
- **Enterprise 未満では、監査と DLP は Merge のコンソール内にとどまります。** SIEM ストリーミングは Enterprise の機能なので、Pro では調査の記録がベンダーの UI の中にしかありません。対策：セキュリティ部門が自社 SIEM へのログ集約を求めるなら、Pro を買って監査の圧力の中でアップグレードするのではなく、最初から Enterprise で見積もってください。
- **デフォルトでは Merge の OAuth アプリが使われます。** 認証情報を一元保管する仕組みは、まさに Composio で破られたものです。対策：書き込み権限を持つコネクタには自社の OAuth クライアントを登録し、DLP ルールを検証するまで Tool Packs は読み取り専用にし、取り消し手順のランブックをローンチ前に書いてください。
- **カタログの数字がページによって異なります。** Merge は場所によって 300 以上のコネクタ、「数百のエンタープライズシステム」、4,000 以上のツールと書いています。対策：エージェントに必要なシステムとアクションを正確に列挙し、調達前に Free プランで 1 つずつ確認してください。
