## 概要

Clari はもはや会社ではありません。現在は [Salesloft](/ja/tools/salesloft/) 内の予測製品である **Clari Forecast** です。両社は2025年12月3日に Steve Cox を CEO として合併し、9か月間「Clari + Salesloft」として事業を行ったのち、2026年9月2日に単一ブランドへの移行を発表しました。会社とプラットフォームは Salesloft となり、Clari の名前を残す製品は Clari Forecast だけです。それ以降、`clari.com` は `salesloft.com` への恒久リダイレクトを返し、`clari.com/pricing` は Salesloft のデモ申し込みページに着地します（いずれも2026年11月13日確認）。

旧 Clari の残りの製品群は Salesloft のラインナップに組み込まれました。Inspect はパイプラインの可視化向けに引き続きその名前で販売されています。Copilot の通話インテリジェンスは現在 Salesloft Conversations の下にあります。Groove はログイン先としてはまだ到達できますが、独立した製品としては販売促進されていません。Capture とアクションハブの Guide は、名前の付いた製品としてはもう表示されていません。2026年後半に「Clari」を評価しているなら、評価しているのは予測モジュールを含む Salesloft の契約です。

予測の手法そのものは変わっていません。Forecast は担当者・マネージャー・経営層の申告値をスナップショットしたパイプラインに対して積み上げ、Inspect は活動がステージと矛盾するディールにフラグを立て、さらに AI Forecast Agent が数字がどこでなぜ動いたかを要約するようになりました。変わったのは、製品の販売、ロードマップ、サポートを担うのがエンゲージメントのベンダーになった点です。

## RevOps スタックに入る理由

- **予測精度は RevOps が評価される指標そのものです。** 取締役会は、四半期の着地が CRO の申告値から数ポイント以内に収まったかを見ます。Clari のディール単位の乖離シグナルは、対処できる早さでズレを表に出します。買う理由はここに尽きます。
- **ステージ基準ではなく活動基準のスコアリング。** メールとカレンダーの活動は自動で取り込まれます。買い手側の活動が14日間ないディールは、担当者が設定したステージに関係なくフラグが立ちます。
- **予測データに LLM から到達できます。** Salesloft の MCP サーバーは2026年4月14日に提供開始され、7月には [Claude](/ja/tools/claude/) のコネクタディレクトリにネイティブ掲載されました。夏の拡張では、Cadence の活動データと通話インテリジェンスに加えて、予測とディール精査のデータが追加されました。[ChatGPT](/ja/tools/chatgpt/)、Microsoft Copilot、Gemini 向けのコネクタも続いています。Aviso と BoostUp には現時点で同等のものがありません。

## 価格の実態

価格は何も公開されていません。`salesloft.com/pricing` は階層も数値もない「Talk to Sales」フォームです（2026年11月13日確認）。以下の数値は第三者による調達データの推定値です。定価ではなく、交渉のための帯域として扱ってください。

- **Clari Forecast**: 年額請求でおよそ 1ユーザーあたり月 $100-$120（Docket、2026年4月）、年換算でおよそ $1,200-$1,500。
- **契約総額**: Vendr の 291件の Clari 購買データでは、年間契約の中央値が約 $76,000、レンジは $19,065-$415,001、平均交渉値引きは 15% 前後です。
- **導入費**: プロフェッショナルサービスでおよそ $15K-$75K、期間は8〜16週間。Salesforce を大幅にカスタマイズしている環境ほど上限側になります。
- 契約は年単位のみです。大きな値引きが出るのは複数年契約です。

リブランド後の現実的な見積もりは Salesloft のバンドルです。Forecast 単体の契約も今も成立しますが、営業チームはエンゲージメントと会話インテリジェンスを抱き合わせた価格を提示してくると考えてください。ARR 約 $10M を下回ると採算が合いません。その規模では RevOps 責任者がパイプラインを頭に入れておけますし、中央値 $76,000 の契約は GTM 予算に対して無視できない比率になります。

## 向いている相手

- ARR $50M-$5B の B2B 企業で、複数地域の営業組織と取締役会に見える四半期予測を持つ RevOps 責任者。
- エンゲージメント基盤としてすでに Salesloft を使っているチーム。この場合 Clari Forecast は、2社目のベンダーではなく既存契約へのアドオンになります。
- 今四半期のうちに、予測とパイプラインのデータを Claude や ChatGPT から照会したいチーム。

**向かないのは**、営業担当が50名未満の場合、予測の問題が実際には CRM の入力品質の問題である場合、またはエンゲージメントに [Outreach](/ja/tools/outreach/) を使っていて、予測をその直接の競合に握られたくない場合です。

## 代替候補と、そちらを選ぶ基準

- **[Gong](/ja/tools/gong/)** — レベニューインテリジェンスの市場シェア首位で、このセグメントで最も成長が速い企業です。2026年5月に ARR $500M を超えました。通話分析が第一要件で、シーケンサーも売っているベンダーではないところから予測を買いたいなら、こちらです。[Gong vs Clari](/ja/vs/gong-vs-clari/) を参照してください。
- **[Aviso](/ja/tools/aviso/)** — 予測の深さで最も近い専業の競合で、過去のパイプライン挙動に対する予測モデルを持ちます。エンゲージメントスタックから独立した予測ベンダーが欲しいなら、こちらです。[Clari vs Aviso](/ja/vs/clari-vs-aviso/) を参照してください。
- **[BoostUp](/ja/tools/boostup/)** — ミッドマーケット向けの価格面の選択肢。買う仕事が予測だけなら、こちらです。[Clari vs BoostUp](/ja/vs/clari-vs-boostup/) を参照してください。
- **[Salesforce](/ja/tools/salesforce/) 標準の予測機能** — Sales Cloud に含まれます。ARR $50M 未満ならこちらです。差分は活動基準のスコアリングで、標準の予測は担当者が自分で操作できるステージ変更に連動して動きます。

## 注意点

- **予測ベンダーが、そのままエンゲージメントベンダーになりました。** Outreach を使っているなら、Clari Forecast のロードマップを決めるのは Outreach の最大の競合であり、商業的な圧力は統合に向かいます。**対策:** 契約期間全体にわたってサポートされる CRM とエンゲージメントの連携について書面での確約を取り、バンドルの話が始まる前に Forecast 単体での更新価格を出させてください。
- **パッケージはまだ再編の途中です。** Groove、Copilot、Capture は1年のうちに名称変更または統合され、Groove と Salesloft Cadence は今も重複しています。**対策:** 正確な SKU と利用権を発注書に明記し、契約期間中にモジュールが再パッケージされた場合に価格と範囲を維持する条項を加えてください。
- **MCP の範囲はテナントごとに異なります。** 第三者レビューの中には今もコネクタを読み取り専用と説明しているものがあり、予測データはエンゲージメントデータより後から追加されました。**対策:** エージェントのワークフローを計画する前に、自社テナントでどの予測オブジェクトとディールオブジェクトが公開されているか、書き込みアクションが有効かを、AE に書面で確認させてください。
- **Salesforce のカスタムオブジェクトに対する統合負債。** 標準オブジェクトはそのままマッピングされますが、作り込んだ環境には個別のスコープ作業が必要です。**対策:** 商談中に出てくる1か月という数字ではなく、8〜16週間をまるごと予算に組んでください。
- **予測精度の演出化。** 見積もりの精度を上げるためではなく、数字を管理するためにツールが使われることがあります。**対策:** 四半期内の収束ではなく、4四半期移動での予測乖離を測ってください。前者は最終週の数字の抑え込みを評価してしまいます。
