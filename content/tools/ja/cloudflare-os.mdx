## 概要

Cloudflare OS は、企業が自社の Cloudflare アカウントにデプロイするオープンソースのエージェント・ワークスペースです。全従業員がブラウザ上のチャットを使えるようになり、そこでは会社のコンテキストと共有スキルを読み込んだエージェントが、調査、ドキュメントやスライドの作成、繰り返し作業の自動化、小さな社内アプリの構築を行います。Cloudflare は 2026 年 5 月に最初のバージョンを全社員に配布し、2026-08-05 に全面的に書き直した v2 を Apache 2.0 でオープンソース化し、2026-10-01 には Cloudflare のダッシュボードから起動するマネージド版のウェイトリストを開設しました。ローンチ記事は Hacker News のトップページで 668 ポイントを獲得し、GitHub リポジトリのスター数は 2026 年 10 月時点で 10,200 を超えています。

名前の「OS」は比喩です。実際の仕事は 3 つの要素が担います。

- **エージェント・ワークスペース。** コード断片を書いて実行することでタスクを完了する Code Mode エージェントです。Cloudflare AI Gateway 経由でルーティングする任意のモデル（Anthropic、OpenAI、Google、Workers AI、セルフホストのモデル）を使えます。
- **Gadgets。** エージェントが作るドキュメントやアプリはすべて、専用のサンドボックスで動くプライベートなインスタンスです。外向きのインターネット通信を無効化した Dynamic Worker と、隔離された iframe で構成されます。Gadget は Google Doc のようにリアルタイムの同時編集つきで共有でき、コードを Blueprint として共有すれば同僚はそれぞれ自分のコピーを持てます。
- **Gatekeepers。** 外部サービスごとに 1 つの Worker です（GitHub、Google、Slack、Notion、Confluence、ZoomInfo、Supabase、メールなどがリポジトリに同梱されています）。Gatekeeper が OAuth の認証情報を保持するためエージェントがそれを目にすることはなく、ユーザーが提示した特定のリソースだけを公開し、すべての読み取りを記録し、副作用のあるアクションは人間の承認待ちキューに入れます。

## 買う価値がある部分：デフォルトでのガバナンス

多くのエージェント・ワークスペースは MCP サーバーを事前に接続するため、どのチャットも接続済みのすべてに常時アクセスできます。Cloudflare OS は、すべてのエージェントと Gadget をアクセス権ゼロで起動します。ユーザーが特定のリポジトリ、ドキュメント、チャンネルを提示し、エージェントは追加を要求でき、ユーザーが承認または拒否します。エージェントが読んだリソースはすべて出力に紐づく観測ログに記録され、このログが後で、エージェントが外部の宛先に書き込めるか、元データへのアクセス権を持たない人に結果を共有できるかを判断します。

承認は非同期です。エージェントが Slack メッセージの送信やドキュメントの編集をしようとすると、Gatekeeper が結果をシミュレートしてエージェントは作業を続け、ユーザーは戻ってきたときにキューのアクションをまとめて承認または却下します。これで、チームがエージェントを自動承認に切り替える最大の理由がなくなります。

## 料金の実態

ソフトウェアは $0 です。インフラは Cloudflare に、トークンはモデルプロバイダーに支払います。以下は 2026-10-01 に Cloudflare の公開料金で確認した数字です。

- **Workers Paid — アカウントあたり月額 $5。** Dynamic Workers に必須です。1,000 万リクエストと 3,000 万 CPU ミリ秒を含み、超過分は 100 万リクエストあたり $0.30、100 万 CPU ミリ秒あたり $0.02 です。
- **Dynamic Workers — ロードされた一意の Worker 1 つにつき 1 日 $0.002**、月 1,000 まで込みです。この機能がベータの間、Cloudflare はこの料金を免除しています。
- **Cloudflare Access（Zero Trust）** — スターターリポジトリのデフォルトのサインイン方式です。50 ユーザーまで無料、それ以降は従量課金でユーザーあたり月額 $7 です。Access を使わない場合、コアはユーザー名とパスワード、または Google、GitHub、Cloudflare の OAuth サインインにも対応します。
- **モデルのトークン** — AI Gateway 経由でプロバイダーが請求し、個人、チーム、ワークスペース単位で予算とレート制限を設定できます。
- **マネージド版** — ウェイトリストのみで、2026-10-01 時点で価格は公開されていません。

Access を使う従業員 200 人の試算：Access が年 $16,800、Workers Paid が $60、これにトークン代が加わります。同じ 200 席を Claude Team にすると、年額プランの $20 で年 $48,000 かかり、これは誰かが利用上限に達する前の金額です。Microsoft Agent 365 は E5 環境に年 $36,000 を上乗せします。インフラ費は小さく、本当のコストは、デプロイし、Gatekeeper ごとに OAuth アプリを作成し、固定したアーリーアクセス版をアップグレードしていくエンジニアです。

## 適した用途

すでに Cloudflare 上で事業を運営し、Workers のデプロイを担当できるプラットフォームエンジニアが 1 人いて、ベンダーに広範な常時アクセスを渡さずに全従業員が GitHub、Google Workspace、Slack 上でエージェントを使えるようにしたい、従業員 50〜2,000 人規模の企業の ops・IT リーダー向けです。ライブデータでパイプラインのダッシュボードを作る RevOps チーム、エージェントが下書き前に何を読んだかの監査証跡が必要な Legal Ops チーム、各自がプロンプトを書く代わりに共有スキルを使いたいリクルーティングチームに合います。

**使うべきでないケース：** 社内でデプロイを担当する人がいない場合、基幹システムが Salesforce、HubSpot、ATS の場合（これらの Gatekeeper は同梱されておらず、自分で書くことになります）、または調達部門が現時点でベンダーの SLA を必要としている場合です。

## 代替候補との比較

- **[Claude Cowork](/ja/tools/claude-cowork/)** — デプロイなしで今四半期中にマネージドのエージェント・ワークスペースを導入したいなら、こちらを選びます。1 席 $20〜25、Anthropic のモデルのみで、コネクターはタスクごとに提示するのではなく事前に設定します。
- **[Microsoft Agent 365](/ja/tools/microsoft-agent-365/)** — 会社が Microsoft 365 で標準化されていて、環境全体のエージェントを統制するのが目的なら、こちらを選びます。対象となるベースライセンスに加えてユーザーあたり月額 $15 です。
- **[Dust](/ja/tools/dust/)** — エンジニア以外のメンバーが Salesforce、HubSpot、Snowflake 上のエージェントを今すぐ作って共有する必要があるなら、こちらを選びます。マネージドで 1 席約 $31、Cloudflare OS にないコネクターがあります。
- **[Onyx](/ja/tools/onyx/)** — 課題がアプリ構築ではなく、社内ナレッジの検索とチャットなら、こちらを選びます。MIT ライセンスで任意のインフラにセルフホストでき、40 以上のコネクターがあります。
- **[OpenClaw](/ja/tools/openclaw/)** — 2026 年に最も急成長したオープンソースのエージェントです。1〜3 人のオペレーター向けの個人用エージェントならこちらを選びます。マルチユーザーの権限モデルはありません。

## 注意点

- **アーリーアクセスのソフトウェアです。** Cloudflare 自身の README が v2 を「early access」リリースで「many rough edges」があると説明しており、リポジトリには 2026-10-01 時点で 128 件のオープンな issue がありました。対策：上流のリリースを固定する `cloudflare-os-starter` リポジトリ経由でデプロイし、各アップグレードは本番前にステージング用のルートでテストしてください。
- **業務システム向けのコネクターが少ないです。** 同梱の Gatekeeper は GitHub、Google、Slack、Notion、Confluence、ZoomInfo をカバーしますが、Salesforce、HubSpot、ATS 向けはありません。対策：パイロット前に主要 5 システムを洗い出し、不足する各システムについて、スターターリポジトリの `packages/custom-gatekeeper` で独自の Gatekeeper を書くエンジニアリング工数を予算に入れてください。
- **実質的に Cloudflare へのロックインです。** オープンソースのランタイム `workerd` 上でのセルフホストは「coming soon」とされており、現時点で本番運用するには Workers、KV、R2、Browser Rendering、Workers AI、AI Gateway を有効にした Cloudflare アカウントが必要です。対策：Cloudflare をプラットフォームとして採用する判断として扱い、アプリだけでなくその依存関係についてもセキュリティチームの承認を得てください。
- **外部からのコントリビューションは受け付けていません。** Cloudflare が受け入れるのは小さく簡単に検証できるプルリクエストだけで、ロードマップは Cloudflare が握っています。対策：自社固有の変更はコアのフォークではなく Gatekeeper とスターターのラッパーに置き、アップグレードを機械的に保ってください。
- **トークン支出にはデフォルトで上限がありません。** ユーザーごとの日次割り当ては、設定しない限りオフです。対策：全社展開の前に、AI Gateway でチームごとの予算とレート制限を設定してください。
