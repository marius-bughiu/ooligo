## 概要

Maven AGI はエンタープライズ向けの CX エージェントプラットフォームです。ヘルプセンターの記事から回答するのではなく、その問い合わせが実際に対象としているシステム内で複数ステップのアクションを実行し、チャット、email、音声、Web にわたって顧客の要求を解決する AI エージェントを提供します。動作形態はオーバーレイです。すでに運用しているヘルプデスクの上に重なり、データ移行を必要としません。したがってチケット管理、ルーティング、レポーティングは Zendesk や Salesforce に残したまま、エージェント層だけが入れ替わります。

同社は 2023 年初頭に、Jonathan Corbin 氏 (HubSpot で Global VP of Customer Success and Strategy を務めた) 、Sami Shalabi 氏 (元 Google、Google News のエンジニアリングを統括、50 件以上の特許を保有) 、Eugene Mann 氏 (元 Stripe、Applied ML チームを率いた) によって設立されました。調達総額は $78M で、そのうち $50M のシリーズ B は 2025 年 6 月 18 日に発表され、Dell Technologies Capital がリードし、Cisco Investments と SE Ventures、さらに既存投資家の Lux Capital、M13、E14 が参加しています。この調達時点で Maven は、前年に企業顧客が 0 社から 40 社になったこと、2024 年の売上が約 $7M であること、更新率が 100% であることを公表しました。同社は独立しており、Tripadvisor、Clio、Rho、ClickUp、Hard Rock Digital、SS&C、Thumbtack を含む 90 社以上を顧客として挙げ、The Agentic List 2026 の CX Agents カテゴリに掲載されました。

製品として名前が付いている構成要素は、AI Agent Designer (エンジニアリングなしで挙動を調整し性能を監視する) 、AI Voice Agent (電話回線に取り付けたチャットボットではなく、音声から音声への処理) 、Graph of Record (エージェントが推論の土台にする顧客データ層) 、そして Data and Insights です。

## CX・サポートスタックで採用される理由

- **買っているのは導入モデルそのものです。** Maven は forward-deployed engineers を配置し、顧客のチームに入り込んで、連携の配線、ポリシーとトーンの実装、実運用で出てくるエッジケースの調整、本番稼働可否の検証まで行います。公表されているオンボーディング期間は具体的です。K1x は 1 週間でゼロから解決率 80% に到達し、Mastermind は 6 週間で 93% に達し、Clio は 6 週間のオンボーディングでチャットの自律解決率 80% 超、従来のチャットボット比で 60% 多いチケット解決を実現しました。これがこの市場におけるアカウント主導型の極であり、セルフサービス型のビルダーに対して Maven が案件を勝ち取る理由です。
- **コンプライアンスの範囲は同カテゴリで最も広いです。** 認証は 9 種類。SOC 2 Type 2、ISO 27001、ISO 27017、ISO 27018、ISO 27701、AI マネジメントシステムの ISO 42001、PCI-DSS 4.0 Level 1 に加え、HIPAA、GDPR、CCPA への準拠があります。ISO 42001 と PCI Level 1 が揃っていることが、軽量なベンダーが止まる規制下の調達審査をエージェントに通過させます。
- **知識検索がバージョンを意識します。** Maven の知識層は、エージェントが古い版のドキュメントから自信を持って回答してしまうという特定の失敗を狙って設計されています。これは CSAT が 1 ポイント下がる類の誤りではなく、ポリシー上の紛争を招く誤りです。
- **すでに運用している基盤に接続します。** ヘルプデスク側は Zendesk、Salesforce、Freshdesk、[Front](/ja/tools/front/)、Genesys、HubSpot、[Intercom](/ja/tools/intercom/)、ServiceNow。ナレッジは Confluence、Notion、Google Drive、GitHub。データは Snowflake、BigQuery、S3 です。

## 価格の実態

公開情報はありません。価格ページはデモ予約フォームであり、プラン区分も課金単位も金額も記載されていません。Vendr のマーケットプレイスのデータでは、Maven AGI の契約中央値は**年間 $100,000**、観測された購入額は **$42,000 から $200,988** の範囲です。Vendr はこの中央値を [Ada](/ja/tools/ada/) の $72,000 より 17.48% 高いと算出しています。交渉はシートではなく、チケット量、チャネル数、連携の複雑さで行われます。$42K を実質的な下限とみなし、導入費用と最低利用量がライセンス費用の上に乗ると想定してください。

## 適しているのは

規制業種または決済を扱う業種のエンタープライズおよびミッドマーケット上位の CX 責任者で、移行するつもりのない既存ヘルプデスクを運用しており、ビルダー UI とサポートポータルではなく、導入期間を通じてベンダーのチームが常駐することを求めている場合です。他のどの選択肢よりも優位に立つ限定された条件は、PCI と ISO 42001 の審査を通す必要があり、実際にバージョン管理されたポリシー文書群を持ち、エージェントを自社で連携させるためのエンジニアを割けないサポート組織です。

年間のサポート量が $42K の下限を回収できない場合、自社でエージェントを設定したくベンダーとの関係を管理したくない場合、あるいは Claude や ChatGPT を自社の CX 分析に接続する必要がある場合は見送ってください。最後の注意点を参照してください。

## 代替との比較

既存勢がインストールベースを握っています。[Zendesk](/ja/tools/zendesk/) と Intercom Fin は、すでに支払っているヘルプデスクに付属するエージェントを提供し、解決単価はそれぞれ $1.50 と $0.99 です。自動化の水準が自社の基準を満たすなら、こちらを選んでください。ベンダーを 1 社増やすのは実際の作業負担だからです。最も成長の速い新規参入は [Decagon](/ja/tools/decagon/) で、2026 年 1 月に評価額 $4.5B でシリーズ D の $250M を調達しています。最も急な自動解決の伸びを求め、成果ベースの課金を受け入れられるならこちらが勝ちます。[Ada](/ja/tools/ada/) は、請求額をエージェントの性能から切り離したい場合の選択肢です。解決単位ではなく会話単位で課金するためです。[Sierra](/ja/tools/sierra/) は取引を実行するエージェントで競合しますが、Maven の PCI-DSS 4.0 Level 1 取得はその差分を埋めています。[Forethought](/ja/tools/forethought/) は、自律解決よりもトリアージとオペレーター支援を重視する場合の安価なマルチエージェント選択肢です。これらすべてに対する Maven の主張は同一です。導入が機能するまで残るエンジニアを投入し、その分の価格を取る、というものです。

## 注意点

- **候補群の中で中央値が最も高く、価格を一切公開していません。** Ada の $72,000 に対して中央値 $100,000、観測された最高契約額は $200K をわずかに超え、基準にできる公開単価がありません。ガード: 最初の価格協議で Vendr のレンジを提示し、課金単位を書面で確定してください。会話単位、解決単位、アクション単位は自動化率が上がったときの挙動が異なります。そのうえで複数年契約に合意する前に、予測量で 3 年分を試算してください。
- **forward-deployed engineering には公開された商業条件がありません。** 常駐エンジニアが契約に含まれるのか、別途請求なのか、時間の上限があるのかを Maven は明示していません。「機能するまで残る」は約束であって SLA ではありません。ガード: FDE の割り当てを、引き継ぎ地点を定めた週数または時間数として発注書に明記し、完了とみなす解決率を定義してください。
- **公表されている数値は、条件の良い導入事例におけるベンダー側の上限値です。** 「最大 93% を自律解決」「1 週間で 80%」は Maven 自身の顧客における Maven 自身の数値であり、そのまま引き継げる基準値ではありません。ガード: 取引量の多い導線を 1 つ選んでパイロットし、現行ツールと比較して封じ込め率と再オープン率を四半期を通して計測し、契約上の量的コミットメントは事例ではなく実測値に基づいて設定してください。
- **Maven は MCP クライアントであり、MCP サーバーではありません。** サードパーティの MCP サーバーの URL を Maven の UI に貼り付けてエージェントに新しいアクションを与えることはでき、これは有用です。できないのは、Claude などの MCP クライアントを Maven に向けて、解決要因や CSAT の推移を対話的に照会することです。Ada はこれを提供していますが、Maven は提供していません。ガード: エージェント側のレポーティングを計画に含めるなら、そのワークフローが存在すると想定する前に、REST API が必要な指標を公開しているか確認してください。
