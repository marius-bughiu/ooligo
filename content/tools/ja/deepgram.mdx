## 概要

Deepgram は、多くの音声サポートのスタックが、購入者に知られないまま土台として使っている音声レイヤーです。speech-to-text(文字起こし向けの Nova-3 ファミリーと、リアルタイム会話向けの Flux)、text-to-speech(Aura-2 と新しい Flux TTS)、そして文字起こし、LLM、音声を1本の WebSocket にまとめて定額の時間単価で提供する Voice Agent API を販売しています。[Vapi](/ja/tools/vapi/) のアシスタントや Genesys のバーチャルエージェントを設定すると、その下で文字起こしを担っているのが Deepgram であることがよくあります。

このページが答える問いは1つです。サポート用の音声エージェントの下にどの音声レイヤーを置くべきか、そして Deepgram を直接購入すべきか、それとも音声プラットフォームにバンドルされているものを使うべきか、です。同社は独立系で、資金も潤沢です。2026年1月13日に AVP 主導、評価額13億ドルで1億3,000万ドルのシリーズ C を調達し、戦略投資家として Twilio、ServiceNow Ventures、SAP、Citi Ventures が加わりました。同じ発表でドライブスルー向け音声 AI 企業の OfOne を買収しており、同社がいまや飲食店向け製品の中核を担っています。

## CX・サポートのスタックに登場する理由

- **Flux は文字起こしではなく、会話のターン交代のために作られています。** 2025年10月にリリースされた Flux は、ASR のストリームに音声区間検出を後付けするのではなく、文字起こしと発話終了の検出を1つのモデルで行います。Deepgram は発話終了の遅延を約260ms としており、ネイティブの割り込み(barge-in)対応と「eager」な発話終了イベントを備えているため、通話者が話し終える前に LLM が応答の作成を始められます。これらはベンダーの数値です。自分で確認できるのはその効果で、エージェントが通話者の話にかぶせて話したり、無音のまま止まったりするケースが減るかどうかです。
- **汎用 STT では崩れる通話のためのドメインモデルがあります。** Nova-3 Medical は2026年10月6日に10言語対応となり、Nova-3 Pharma(2026年9月17日)は薬剤名の認識を対象にしています。キーターム・プロンプティングを使えば、SKU、プラン名、アカウント ID を認識しやすくなるよう調整でき、2026年10月2日からはストリームの途中でキータームを更新できます。
- **コンプライアンスチームが求める場所で稼働します。** EU(`api.eu.deepgram.com`)とインド(2026年9月15日に一般提供開始)の専用エンドポイントがあり、Enterprise の顧客は自社の VPC 内やオンプレミスの NVIDIA GPU 上でモデルをセルフホストできます。ePHI を扱う Enterprise の顧客とは BAA を締結します。
- **大手コンタクトセンターベンダーはすでに採用しています。** Genesys は Agentic Virtual Agent の中で Deepgram の音声認識を使っており、Deepgram はセルフサービスでの自己完結と英数字の認識精度の事例として Five9 を顧客に挙げています。お使いの CCaaS がすでに Deepgram を使っているなら、直接契約すれば同じエンジンを自社のキータームとデータ条件で使えます。

## 価格の実態

従量課金プランは $200 の無料クレジットから始められ、カード登録は不要で、最低利用額もありません。2026年10月19日時点の定価は次のとおりです。

- **Nova-3 ストリーミング：** 単一言語で1分あたり $0.0048(1時間あたり約 $0.29)、多言語で1分あたり $0.0058 です。Deepgram はこれらのストリーミング料金を期間限定のプロモーション価格としているため、値上がりを前提に予算を組んでください。
- **Nova-3 録音済み音声：** 単一言語で1分あたり $0.0043 です。
- **Flux ストリーミング：** 英語で1分あたり $0.0065(1時間あたり約 $0.39)、多言語で1分あたり $0.0078 です。
- **アドオン：** ストリーミングの話者分離と秘匿化はそれぞれ1分あたり $0.0020、キーターム・プロンプティングは1分あたり $0.0013 です。3つすべてを使うストリーミング通話は Nova-3 で1分あたり約 $0.0101 となり、表示価格のおよそ2倍になります。
- **TTS：** Aura-2 は1,000文字あたり $0.030、Flux TTS は $0.045 です。
- **Voice Agent API：** 標準ティアで1時間あたり $4.50(1分あたり $0.075)、自社の LLM と TTS を持ち込む場合は1時間あたり $3.00、アドバンストティアでは1時間あたり $9.75 です。電話回線の料金はキャリアから別途請求されます。

Growth プランは年間 $4,000 の前払いクレジットから始まり、Nova-3 の料金がおよそ12〜17%下がります。Growth での超過分は Growth の料金に10%上乗せして請求されます。実際には、月100,000分のストリーミングを文字起こしするサポートチームの支払いは、アドオン次第で定価ベースで月およそ $480〜$1,010 です。音声エージェントの請求で speech-to-text が高額な項目になることはまれです。LLM と音声のほうがコストがかかります。

## 最適な対象

Vapi、Retell AI、LiveKit、Pipecat 上で音声エージェントを構築または運用し、文字起こしエンジンを自分で選びたいサポートエンジニアリングや CX プラットフォームの責任者です。とくに、通話者がアカウント番号、薬剤名、製品コードを読み上げる場面に向いています。また、コーチングや CRM への書き戻しのために社内で通話の文字起こしを構築し、Gong のシートではなく素の音声レイヤーを求める RevOps チームにも適しています。

チーム内に API に対してコードを書く人がいない場合は見送ってください。Deepgram は部品であり、完成したエージェントではありません。

## 代替製品との比較

speech-to-text の定番は、ハイパースケーラー(Google Cloud Speech-to-Text、Amazon Transcribe、Azure AI Speech)と AssemblyAI です。調達上、既存のクラウド契約の範囲内にとどまる必要があり、遅延が決め手にならないなら、ハイパースケーラーを選んでください。1時間あたりの価格で判断が決まるなら **AssemblyAI** を選んでください。同社の Universal-Streaming モデルの定価は1時間あたり $0.15 で、Nova-3 のストリーミング料金の約半分です。ただし、送信した音声ではなく WebSocket のセッション時間で課金されるため、アイドル状態の接続も課金対象になります。同社の Voice Agent API もすべて込みで1時間あたり $4.50 で、表示価格は Deepgram と同じです。

最も成長が速い新規参入者は [ElevenLabs](/ja/tools/elevenlabs/) で、同社で知られる音声に加えて、いまでは Scribe という speech-to-text も販売しています。分単価よりも、聞き取りと音声の両方を1社にまとめることを重視する場合や、顧客が評価するのが音声品質である場合に選んでください。

会話のターン交代、ドメイン固有の語彙、セルフホスティングがプロジェクトを決める場合は Deepgram を選んでください。こうしたことを一切社内で抱えたくないなら、マネージド型のエージェント([PolyAI](/ja/tools/polyai/)、[Sierra](/ja/tools/sierra/))を購入し、音声スタックの選定はベンダーに任せてください。

## 注意点

- **ストリーミング料金はプロモーション価格です。** 対策：ビジネスケースは現在の Nova-3 と Flux のストリーミング料金の1.5倍で試算し、ボリュームが Growth の契約に見合うなら、注文書で料金を固定してください。
- **精度と遅延の主張は Deepgram 自身のベンチマークによるものです。** 対策：契約前に、自社で録音した通話200〜500件を Nova-3、Flux、競合1社に通し、アカウント番号、製品名、住所といった重要なエンティティについて単語誤り率を評価してください。
- **Flux TTS はリリース時点で英語のみです。** 対策：英語以外の通話者に対応するキューがあるなら、そのキューでは Aura-2 またはサードパーティの音声を使い続け、TTS ベンダーを1社に絞る前に対応言語を書面で確認してください。
- **セルフホスティングには Enterprise 契約と自社の GPU が必要で、2026年10月1日にセルフホスト版エンジンから Whisper が削除されました。** 対策：ライセンスとあわせて GPU の容量と運用人員のコストを見積もり、アップグレード前に Whisper のワークロードを Nova-3 へ移行してください。
