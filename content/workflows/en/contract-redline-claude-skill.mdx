The review copy proposes ten, cites the exercise rule in a comment, and leaves a renewal decision open for counsel. Both files contain the same delivery table.

## Inspect the fictional example

Download the [incoming agreement](/artifacts/contract-redline-claude-skill/examples/incoming.docx) and the [review copy](/artifacts/contract-redline-claude-skill/examples/review-copy.docx), or use the ZIP to get the instructions and verifier as well. The example is in English across all six editions of this guide. You can inspect it locally without a Claude account or customer documents.

1. Keep the incoming file intact. Open the review copy in Word and display all markup and comments. In clause 2, find the deletion of “three” and insertion of “ten”. The adjoining comment cites `REVIEW-01` and asks counsel to check the period against the pilot schedule.
2. Read clause 3. The renewal wording remains in place, including its five-day notice period. The second comment, `HOLD-01`, asks for a decision because the exercise playbook has no renewal position. Clause 1 and the delivery table have no proposed edits.
3. Make two disposable copies of the review file. Reject both revisions in one and confirm the sentence matches the original. Accept both in the other and confirm only the review period changes. Inspect comments separately. Hiding markup does not resolve a revision. [Microsoft’s Word instructions](https://support.microsoft.com/en-us/word/accept-or-reject-tracked-changes-in-word)

## Verify what the file preserves

From the extracted ZIP, run `python3 verify_sample.py`. Python 3 reads the two sample files locally. A passing result begins with `PASS: one replacement, two anchored comments`. The script checks the native insertion and deletion, comment anchors and references, and the document body after projecting each decision. It also checks the table, styles and unrelated package content against the original.

Read `examples/review-notes.md` alongside the documents. Its three entries separate an unchanged clause, a proposed substitution and an unresolved decision. The sample documents were assembled offline, rendered for layout and checked structurally. This verifies the shipped pair. It does not establish that Claude can preserve arbitrary documents or that these terms are appropriate for a real agreement.

## Use the instructions on an approved matter

Choose this workflow when counsel has approved a playbook for the agreement type and a named reviewer can examine every proposed edit. If a live draft contains unresolved revisions, conflicting exhibits, missing definitions or an unfamiliar clause, preserve the original and bring those issues to the reviewer before proposing wording.

`SKILL.md` describes the review steps. The three files in `references/` supply the fictional rule, replacement text and escalation decision. Replace them with your organization's approved rules, exact fallback language, version, owner and escalation criteria before working on an actual NDA or MSA. The exercise's ten-day period is not a default position for other agreements. The [contract review SOP](/en/learn/contract-review-sop/) can help define the handoff.

Confirm that the matter owner permits the chosen account and document handling. The Skill provides written instructions. It cannot enforce account policy, verify privilege, connect to a CLM or transmit a draft. A reviewer using [Claude](/en/tools/claude/) needs an approved editor that can preserve existing Word features. If only plain text is available, return a clause-by-clause note and have the reviewer enter proposals in Word. Preserve previous reviewers' markup, cross-references, exhibits, comments and definitions on a separate version.

## Decide whether to adopt it

Run a pilot on material approved for evaluation. Record missed issues, incorrect substitutions, unsupported proposals, review minutes and any damaged document features. Include editor or model charges and counsel time when comparing with the existing process. No live contract, vendor cost, time saving or legal outcome was measured in this example.

Counsel decides whether each proposal is acceptable and resolves every hold. The matter owner controls release. Before sharing a document, review the final version, comments, metadata and recipients through the organization's normal process.
