# Example review rubric

This local planning rule assigns attention for the next review. Adapt it with the team before using it on an account.

| Evidence | Review priority | Next step |
| --- | --- | --- |
| Renewal terms, measurement dates or adoption denominators are missing or incomparable | Verify inputs | Name an owner to confirm the missing fact before drawing a trend |
| Comparable usage fell and the current sponsor is unconfirmed | Owner review | Assign an adoption check and a sponsor-confirmation task |
| Only one concern is established | Follow up | Assign a check to the person able to resolve that concern |
| Neither concern is established | Routine review | Keep the scheduled review and name its owner |

Apply the first matching row. A priority is a work queue label. Turning it into a probability would require historical renewal outcomes, defined cohorts and an assessment of calibration.
