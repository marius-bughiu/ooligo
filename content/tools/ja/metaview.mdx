## Metaview のどの部分を購入するか

Metaview は複数の採用業務に対応し、購入単位が異なります。[Notetaker](https://www.metaview.ai/interview-notes) は面接を記録し、候補者の要約を作成して、対応する ATS にメモやスコアカードを同期します。[Sourcing](https://www.metaview.ai/sourcing) は職務の要件から候補者を検索します。[Application Review](https://www.metaview.ai/application-review) はチームが編集できる基準に沿って応募者のプロフィールを評価します。1つを購入しても、他のモジュールが必要とは限りません。

面接官が振り返りに使える、発言者を特定できるメモを作れない場合は、Notetaker から評価してください。ソーシングの処理件数は別の問題です。面接メモの評価に、1年分の録画や Sourcing の契約は必要ありません。一般的な顧客会議の要約だけが必要なら、まず [Fathom](/ja/tools/fathom/) を評価してください。営業コーチングや売上レビューが目的なら、[会話分析ツールの比較](/ja/vs/best-conversation-intelligence-tools/)で [Gong](/ja/tools/gong/) と [Chorus](/ja/tools/chorus/) を比較できます。

## 料金はモジュールごとに異なります

以下は2026年11月2日に確認した公開価格です。交渉済みの見積もりや、プラットフォーム全体の共通料金ではありません。

| モジュール | 公開されている無料・有料プラン | 確認する課金単位 |
|---|---|---|
| [Notetaker](https://www.metaview.ai/pricing?product=notes) | Free：月25通話。Pro：月額60 USD／ユーザーで通話無制限。Enterprise：個別見積もり。 | 面接を記録するユーザー |
| [Sourcing](https://www.metaview.ai/pricing) | Free：最初の100プロフィール。Pro：月額100 USD／ユーザーで月200プロフィール。Max：月額300 USD／ユーザーでプロフィール無制限。 | ユーザーと取得プロフィール数。無料枠は月次とは記載されていません |
| [Application Review](https://www.metaview.ai/pricing?product=application-review) | Free：月50応募。表示される Pro の選択値は月500評価で月額150 USD、ユーザー数は無制限。Enterprise：個別見積もり。 | 選択する評価件数。採用担当者ごとの料金ではありません |

計算例として、Notetaker Pro を2席使うと公開単価では**月額120 USD**です。税金や追加製品は含みません。Application Review を加える場合は、その処理件数を別に選びます。すべてのエージェント料金に採用担当者数を掛けると、予算を誤ります。契約前にモジュール、利用枠、請求期間、更新条件をまとめて確認してください。独立に検証した割引率や、顧客の通常支出額はありません。

## 設定と評価の進め方

組織が承認した面接サンプルを使ってください。まず[構造化面接](/ja/learn/structured-interviewing/)の評価基準を定義します。そのうえで、各基準に必要な根拠がメモに残るか、話者を区別できるか、回答を作らず不確実性を残すかを確認します。情報の充足度と修正時間を合わせて測ってください。長い要約が良い記録とは限りません。

最初の試行では ATS と面接形式をそれぞれ1つに絞ります。[連携ドキュメント](https://support.metaview.ai/integrations/integrations-overview)は出発点であり、自社設定のすべての項目が正しく同期する証拠ではありません。承認済みのテストレコードを使い、同期先の候補者、スコアカード項目、アクセス権、重複レコードの扱いを確認してから利用を広げてください。

[面接振り返りテンプレート](/ja/workflows/interview-debrief-summary-skill/)と[面接プロセス設計テンプレート](/ja/workflows/interview-loop-builder-skill/)は、後続業務の構成例を提供します。別個の手順であり、検証済みの Metaview 連携ではありません。[面接インテリジェンスのガイド](/ja/learn/interview-intelligence/)では、この製品に限定せずカテゴリを説明しています。

## 展開前に解決する制約

- **AI の要約は独立した採用判断ではありません。** 重要な記述を面接内容と照合し、判断の責任は採用チームが持ってください。文章の読みやすさだけでなく、省略された根拠や矛盾も確認します。
- **記録と共有には合意した手順が必要です。** 録画前に通知、アクセス、保持期間の設定を組織内で承認してください。機密性のない素材で共有と削除を試します。この評価は法令への適合を証明するものではありません。
- **MCP は読み取り専用ではありません。** [公式 MCP ドキュメント](https://support.metaview.ai/integrations/mcp-integration/mcp-overview)は、ATS の更新や、不採用メールを送信し得る Application Review の判断など、実際に反映される変更を説明しています。アシスタントを接続する前にアカウントの権限と実行可能な操作を確認し、書き込みや候補者へのメッセージ送信には事前確認を求めてください。

確認工数が許容範囲内で、有用な面接記録が改善するなら Notetaker を選んでください。Sourcing と Application Review は、それぞれの業務量で別に評価します。現行手順で必要な根拠が得られ、新しい契約でも改善しないなら、その手順を維持してください。
