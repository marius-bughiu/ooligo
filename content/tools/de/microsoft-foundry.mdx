## Was es ist

Microsoft Foundry ist die Plattform von Azure, um Modelle aufzurufen und Agents innerhalb Ihres eigenen Azure-Abonnements zu bauen. Sie hieß zuerst Azure AI Studio, dann Azure AI Foundry; der Name „Microsoft Foundry“ setzte sich zum Jahreswechsel 2026 durch. Für einen Ops-Käufer zählen zwei Ebenen. **Foundry Models** ist der Katalog: die GPT-5.6-Familie von OpenAI (Sol, Terra und Luna, allgemein verfügbar seit dem 9. Juli 2026), Claude (allgemein verfügbar seit Juni 2026, wobei Anthropic die Inferenz als Auftragsverarbeiter betreibt), Microsofts eigene MAI-Modelle, Grok, Llama, DeepSeek und ein langer Schwanz an Open-Weight-Modellen. **Foundry Agent Service** ist die Agent-Ebene und deckt inzwischen drei Formen ab:

- **Prompt Agents** — deklarative Agents (Modell, Anweisungen, Tools), die Microsoft für Sie betreibt. Allgemein verfügbar seit dem 16. März 2026.
- **Hosted Agents** — Ihr eigener Code (Microsoft Agent Framework, LangGraph oder ein anderes Open-Source-Framework), der in von Foundry verwalteten, isolierten Containern mit Session-State und Dateisystem läuft. Allgemein verfügbar seit dem 9. Juli 2026.
- **Workflows und Routines** — mehrstufige und zeitgesteuerte Agents; Routines sind seit dem 24. September 2026 allgemein verfügbar.

Darum herum gruppieren sich **Toolboxes** (ein gesteuertes Bündel aus Tools, MCP-Servern und Konnektoren, das sich viele Agents teilen; GA, wobei Skills und Tool Search noch in Preview sind), **Foundry IQ** (verwaltete Wissensdatenbanken über SharePoint, OneLake, Azure AI Search und das Web; Wissensdatenbanken GA, der Serverless-Tier in Preview), **Memory** (Session-, Nutzer- und prozedurales Gedächtnis, noch Preview), ein **Browser-Automation**-Tool (GA seit dem 19. Oktober 2026) und **Bring-your-own AI Gateway** (GA, April 2026), mit dem Agents Modelle aufrufen können, die hinter Azure API Management oder einem Gateway eines Drittanbieters liegen. Der neueste Baustein, der **Copilot harness**, ist ein verwalteter Agent-Loop mit Skills und Subagents, der am 28. Oktober 2026 in die Public Preview ging.

## Warum Ops-Teams hier landen

Der Auslöser ist vorhersehbar: Ein Team hat seine ersten Agents in [Copilot Studio](/de/tools/microsoft-copilot-studio/) gebaut, sie haben funktioniert, und jetzt schmerzt die Credit-Rechnung oder die Obergrenze. Ein Agent für die Vertragsaufnahme braucht eigenen Extraktionscode. Ein Agent für Pipeline-Hygiene läuft 3.000-mal im Monat, und die Copilot Credits für jede Aktion summieren sich. Das Recruiting-Team will Claude für Screening-Bewertungsraster, aber der restliche Stack ist Microsoft. Foundry ist der Ort, an den diese Agents umziehen, wenn ein Engineer die Verantwortung übernimmt.

Der Grund, bei Microsoft zu bleiben, statt zu AWS zu wechseln, sind Distribution und Governance. Seit dem **10. Juni 2026** lässt sich ein Foundry-Agent direkt in [Microsoft 365 Copilot](/de/tools/microsoft-365-copilot/) und [Microsoft Teams](/de/tools/microsoft-teams/) veröffentlichen, sodass der Code-first-Agent dort erscheint, wo Mitarbeitende ohnehin arbeiten, unter derselben Entra-Identität. Jeder Agent erhält eine Entra Agent ID und registriert sich in [Microsoft Agent 365](/de/tools/microsoft-agent-365/), was bedeutet, dass die Security den Foundry-Agent mit denselben Conditional-Access-, Purview- und Defender-Werkzeugen prüft, die sie für Copilot-Studio-Agents nutzt. Die Ausgaben werden auf ein bestehendes Microsoft Azure Consumption Commitment (MACC) angerechnet, einschließlich der Claude-Nutzung, und genau das bringt den Einkauf oft durch.

## Die Preisrealität

Es gibt keinen Preis pro Platz. Prompt- und Workflow-Agents verursachen **keine Laufzeitgebühr**; Sie zahlen für Modell-Tokens und für die Tools, die sie aufrufen. Alle folgenden Angaben sind Azure-Listenpreise in US East 2, abgeglichen mit der Azure Retail Prices API am 4. November 2026.

- **GPT-5.6 Terra: $2 pro Million Input-Tokens und $12 pro Million Output-Tokens** auf Global Standard. GPT-5.6 Sol kostet $4/$20; GPT-5.6 Luna $0.20/$1.20. Das sind Tarife für kurzen Kontext; Prompts mit langem Kontext kosten mehr.
- **Data-Zone-Deployments kosten 10 % mehr.** Wer die Inferenz innerhalb der EU- oder US-Datenzone hält, macht aus Terra $2.20/$13.20. Batch kostet 50 % weniger als Global Standard.
- **Claude** wird in Claude Consumption Units auf Ihrer Azure-Rechnung zu den veröffentlichten Token-Tarifen von Anthropic abgerechnet und zählt auf das MACC. Auftragsverarbeiter ist Anthropic, nicht Microsoft.
- **Hosted Agents:** $0.0994 pro vCPU-Stunde und $0.0118 pro GiB-Stunde Container-Compute.
- **Memory:** $0.25 pro 1.000 gespeicherte Kurzzeit-Events, $0.25 pro 1.000 Langzeit-Erinnerungen im Monat, $0.50 pro 1.000 Abrufe.
- **Tools werden separat abgerechnet:** Grounding with Bing, Foundry IQ (als Azure AI Search), Speicher für die Dateisuche, Code-Interpreter-Sessions, Logic-Apps-Konnektoren und Browser-Automation (als Playwright Workspaces) haben jeweils einen eigenen Zähler.
- **Copilot harness:** in der Preview bis zum 1. Dezember 2026 kostenlos, danach dieselben $0.0994 pro vCPU-Stunde und $0.0118 pro GiB-Stunde für seine Sandbox.

Ein durchgerechnetes Beispiel: ein interner RevOps-Agent mit **3.000 Sessions im Monat**, jede mit etwa 20.000 Input- und 1.500 Output-Tokens auf GPT-5.6 Terra, fest an die EU-Datenzone gebunden. Tokens: etwa $132 Input plus $59 Output, rund $191. Ist es ein Prompt Agent, ist das fast die gesamte Rechnung. Ist es ein Hosted Agent, der pro Session fünf Minuten lang eine vCPU und 2 GiB belegt, kommen etwa $31 Compute hinzu. Memory und Grounding bleiben bei diesem Volumen zusammen unter $15. **Gesamt: rund $200 bis $240 im Monat, etwa $2,400 bis $2,900 im Jahr.** Dieselbe Last als autonomer Agent in Copilot Studio mit 6 Aktionen und einer generativen Antwort pro Lauf ergibt etwa 96.000 Credits oder $800 im Monat an Kapazitätspaketen. Die Azure-Rechnung ist die kleine Zahl; der Engineer, der den Agent baut und pflegt, ist die eigentliche Kostenposition.

## Am besten geeignet für

Ein **Plattform- oder RevOps-Engineering-Team in einem Microsoft-365- und Azure-Unternehmen**, das der Low-Code-Obergrenze oder den Credits pro Aktion von Copilot Studio entwachsen ist und Agents braucht, die unter Entra-Identität und Agent-365-Governance in Teams und Microsoft 365 Copilot ausgeliefert werden. Foundry gewinnt klar, wenn die Last hochvolumig und im Backoffice angesiedelt ist (Extraktion, Klassifizierung, Routing, Anreicherung) und das Unternehmen bereits ein Azure-Commitment hat, das abgebaut werden muss.

## Nicht geeignet für

Ein Ops-Team mit 10-50 Personen ohne Engineer, der den Aufbau verantwortet: Bleiben Sie in [Copilot Studio](/de/tools/microsoft-copilot-studio/) oder kaufen Sie [Dust](/de/tools/dust/) oder [Langdock](/de/tools/langdock/). Foundry gibt Ihnen ein Portal und SDKs, keinen Assistenten, den Ihr RevOps-Manager selbst konfigurieren kann. Es ist auch der falsche Kauf für ein Unternehmen, dessen Identität und Daten in AWS oder Google Workspace liegen; Sie würden Entra, Azure-Abonnements und eine zweite Cloud-Rechnung einführen, um zu bekommen, was Ihre bestehende Cloud bereits verkauft.

## Im Vergleich zu den Alternativen

- **[Amazon Bedrock](/de/tools/amazon-bedrock/)** — der andere Marktanteilsführer unter den Agent-Plattformen der Hyperscaler. Wählen Sie Bedrock und AgentCore, wenn Identität, Daten und das Cloud-Commitment in AWS liegen. Wählen Sie Foundry, wenn sie in Entra und Azure liegen oder wenn der Agent in Teams und Microsoft 365 Copilot erscheinen muss. Die Token-Preise liegen nah beieinander; den Ausschlag gibt, wo Ihr Identity Provider und Ihre Daten bereits liegen. Auch die Modelllücke hat sich geschlossen: GPT-5.x läuft auf Bedrock und Claude auf Foundry.
- **Google Clouds Agent Platform** — die dritte Hyperscaler-Option. Wählen Sie sie, wenn das Data Warehouse BigQuery ist, das Unternehmen auf Google Workspace läuft und [Gemini](/de/tools/gemini/) das bevorzugte Modell ist.
- **[Copilot Studio](/de/tools/microsoft-copilot-studio/)** — Microsofts eigene Low-Code-Ebene über Foundry. Behalten Sie Agents dort, solange Maker und nicht Engineers sie verantworten und das Volumen niedrig genug ist, dass die Credits unter ein paar Paketen im Monat bleiben. Wechseln Sie zu Foundry, wenn Sie eigenen Code, ein Modell, das Copilot Studio nicht anbietet, oder Preise pro Token bei hohem Volumen brauchen.
- **Claude Platform und Claude Managed Agents** — der Neueinsteiger, der bei Agent-Funktionen am schnellsten vorankommt. Claude in Foundry fehlen Code-Ausführung, Agent Skills, die Files API und Batches, die Anthropics eigene Plattform bietet. Wählen Sie Anthropic direkt, wenn diese Funktionen das Design bestimmen; wählen Sie Foundry, wenn die Anforderung eine einzige Azure-Rechnung und eine über Entra gesteuerte Distribution ist.

## Worauf Sie achten sollten

- **Claude in Foundry ist nicht die vollständige Claude API, und Microsoft ist nicht der Auftragsverarbeiter.** Anthropic betreibt die Inferenz und ist Auftragsverarbeiter und SLA-Anbieter, und der gehosteten Version fehlen Code-Ausführung, Agent Skills, die Files API und Batches. **Absicherung:** Lassen Sie die Bedingungen von Anthropic als separaten Auftragsverarbeiter von Ihrer Datenschutzberatung prüfen, bevor Sie personenbezogene Daten an Claude leiten, und gleichen Sie jede Claude-Funktion, die Ihr Design braucht, mit Microsofts Liste der Claude-Funktionen ab, bevor Sie sich festlegen.
- **Datenresidenz ist ein Deployment-Typ, keine Voreinstellung.** Global Standard ist am günstigsten und kann eine Anfrage in jede Region leiten. **Absicherung:** Deployen Sie für EU- oder regulierte Daten nur Data-Zone- oder Regional-SKUs, budgetieren Sie den Aufschlag von 10 % und erzwingen Sie das mit einer Azure Policy, die Global-Standard-Deployments in den Abonnements verweigert, in denen diese Agents liegen.
- **GA und Preview sind innerhalb eines Agents gemischt.** Hosted Agents und Toolboxes sind GA, während Memory, Toolbox Skills, Tool Search, das Serverless-Foundry-IQ und der Copilot harness noch Preview sind, ohne GA-Zusagen. **Absicherung:** Führen Sie pro Agent eine Abhängigkeitsliste, die jede Funktion als GA oder Preview kennzeichnet, und halten Sie Preview-Funktionen aus allem heraus, was kundennah oder compliance-relevant ist, bis sie GA sind.
- **Die Rechnung kommt über sechs Zähler.** Tokens, Hosted Compute, Memory, Bing Grounding, AI Search und Playwright werden jeweils separat abgerechnet, sodass keine einzelne Ansicht zeigt, was ein Agent kostet. **Absicherung:** Legen Sie jeden produktiven Agent in eine eigene Ressourcengruppe mit einem Tag für den Agent-Namen und setzen Sie pro Agent einen Budgetalarm in Azure Cost Management bei 120 % der Prognose.
- **Ältere Tutorials lehren abgekündigte APIs.** Die Assistants API wurde am 26. August 2026 eingestellt, und Prompt flow wird am 20. April 2027 abgekündigt. **Absicherung:** Bauen Sie nur auf der Responses API und Foundry Agent Service, und migrieren Sie jede Prompt-flow-Pipeline auf Workflows in Agent Service, bevor Sie ihr Funktionen hinzufügen.
