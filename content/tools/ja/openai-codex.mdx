## 概要

OpenAI Codex は OpenAI のコーディングエージェントです。タスクを説明すると、リポジトリを読み、ファイルを編集し、コマンドとテストを実行して、diff または pull request を返します。動作するサーフェスは6つです。ChatGPT デスクトップアプリ（macOS、Windows、2026年8月からは Linux）、Web 版 ChatGPT、ChatGPT モバイルアプリ、オープンソースの Codex CLI、IDE 拡張機能、そしてノート PC を閉じている間も OpenAI がホストする環境でタスクを進める Codex Cloud です。2026年7月9日、OpenAI は Codex を刷新した ChatGPT デスクトップアプリに統合し、コーディング以外のタスク向けエージェントである ChatGPT Work と並べました。現在は両者が1つの利用枠を共有しています。

普及は急速でした。OpenAI は2026年4月に週間ユーザー300万人超、6月に500万人超を報告し、7月末には Codex と ChatGPT Work を合わせて週間ユーザー約1,000万人と発表しました。両者の内訳は公表していません。

このページはコーディングエージェントを扱います。アシスタント本体は [ChatGPT](/ja/tools/chatgpt/) のページを参照してください。

## ops スタックに載る理由

ほとんどの ops チームはすでに ChatGPT に費用を払っています。会社が ChatGPT Business または Enterprise を使っていれば、GTM エンジニアや RevOps 開発者は同じシートで Codex を使え、新たなベンダー審査は不要です。それ以外にも、次の4つの機能が実用性を高めています。

- **クラウドタスクと GitHub レビュー。** Codex Cloud はローカルにチェックアウトせず、接続済みの GitHub リポジトリに対してタスクを実行します。GitHub コードレビューは一般提供されており、pull request を自動で、または誰かが `@codex review` とコメントしたときにレビューします。GitLab 対応はベータ版です。
- **依頼が届いた場所から作業が始まる。** [Slack](/ja/tools/slack/) と [Linear](/ja/tools/linear/) の連携により、スレッドや issue から Codex にタスクを渡せます。チャンネルに届く「誰かリードのルーティングスクリプトを直してくれませんか」という依頼にちょうど合います。
- **ヘッドレスで組み込み可能。** 非対話モード（`codex exec`）、GitHub Action、Codex SDK によって、同じエージェントを CI や cron ジョブに組み込めます。MCP 対応で CRM、チケット管理、データウェアハウスのサーバーにも接続できます。詳しくは [MCP サーバーとは](/ja/learn/mcp-server-explained/) を参照してください。
- **`AGENTS.md`。** Codex はリポジトリの指示を `AGENTS.md` から読み込みます。これは [Claude Code](/ja/tools/claude-code/) もフォールバック先として読む共通の規約なので、1つのファイルで両方のエージェントに指示できます。

## 価格の実態

Codex には単独の定価がありません。ChatGPT のプランに含まれています。

- **Free と Go（月額 $8）** — デスクトップアプリのみで軽量モデルを利用でき、段階的に展開中です。業務用のツールではありません。
- **Plus** — 月額 $20。Web、CLI、IDE 拡張機能、iOS、クラウド連携。
- **Pro** — 月額 $100、$200、$500 の3段階で、5時間制限はありません。
- **Business** — 1ユーザーあたり月額 $25、年払いなら $20、最低2ユーザー。管理機能と SAML SSO が加わります。
- **Enterprise と Edu** — 個別見積もりで、SCIM、RBAC、Compliance API、データレジデンシーを備えます。
- **API キー** — CLI、SDK、IDE 拡張機能に API 料金を払う方式で、GitHub レビューや Slack などのクラウド機能は使えません。

2026年4月2日以降、プランの利用枠を超えた分はメッセージ単位ではなく、100万トークンあたりのクレジットで課金されます。OpenAI の価格ページによると、中位モデルでの典型的なタスクは2〜15クレジットを消費します。サードパーティの価格ガイドは購入クレジット1つを約 $0.04 としており、タスク1件あたりおよそ8〜60セントになります。Plus と標準の Business シートには5時間と週単位の上限があり、価格ページ自身の見積もりもモデルごとに大きな幅があります。

閉じられた選択肢が1つあります。OpenAI は4月、Business ワークスペースに Codex 専用の従量課金シートを追加できるようにしましたが、2026年6月24日に新規販売を停止しました。既存のシートは引き続き使えます。全員に ChatGPT を配らずに Codex だけ使いたいチームは、現在は標準の Business シートを買うか、プロジェクト予算を設定した API キーで運用することになります。ライトユーザーは1人あたり月 $20〜25、終日 Codex でコードを書く人は月 $100〜200 を見込んでください。

## 適しているのは

ChatGPT Business または Enterprise に標準化した企業の GTM エンジニア、RevOps 開発者、legal ops や recruiting ops の技術担当者です。Codex が明確に勝つ限定的なケースは、失敗している同期ジョブ、フィールドマッピングの変更、新しい webhook ハンドラーといった明確に定義されたタスクを、Slack のスレッドや Linear の issue からクラウドタスクに委ね、開かれた pull request をレビューする使い方です。ops チームがすでに持っている Business シートで、追加の調達なしにこのケースをまかなえます。

## 適していないのは

diff を判断できない人や、git のワークフローがないチームです。Codex が返すのはコードの変更です。誰もレビューしないのであれば、その人には ChatGPT Work やノーコードのビルダーを渡してください。また、大量かつ定型のジョブにも向きません。「このフィールドを毎時同期する」という仕事になった時点で、Codex が書いたコードはトークン課金のエージェントセッションではなく、[n8n](/ja/tools/n8n/) やお使いのオーケストレーターで動かすべきです。

## 代替候補との比較

- **[GitHub Copilot](/ja/tools/github-copilot/)** — シート数で最大の導入基盤です。Business は1ユーザーあたり月額 $19、Enterprise は $39 で、2026年6月1日からは含まれるクレジットを超えた分が従量課金されます。組織がすでに GitHub Enterprise を購入しており、主なニーズが多数の開発者向けのエディター内インライン補完である場合に選んでください。
- **[Cursor](/ja/tools/cursor/)** — 売上で首位のコーディング特化型の競合で、個人向けは月額 $20、Teams は1ユーザーあたり $40 です。IDE に常駐し、すべての編集を視覚的に操りたい人に選んでください。[Cursor の代替候補](/ja/comparisons/alternatives-to-cursor/) も参照してください。
- **[Claude Code](/ja/tools/claude-code/)** — Anthropic のエージェントで、月額 $20 からの Claude プランに含まれ、ヘビーユーザー向けに $100〜200 の Max と $125 の Team プレミアムシートがあります。複数ファイルにわたる長い変更やスケジュール実行が中心の場合、または会社が ChatGPT ではなく Claude を使っている場合に選んでください。Codex 自体がこの分野で最も急成長している新規参入者なので、決め手になるのはたいてい、会社がすでにどのアシスタントに費用を払っているかです。

市場全体のランキングは [AI コーディングアシスタントのベスト](/ja/comparisons/best-ai-coding-assistants/) にまとめています。

## 注意点

- **1つの利用枠を多くの用途が消費する。** Codex は利用枠を ChatGPT Work や音声タスクと共有しているため、同僚の調査レポートがあなたのリファクタリングと同じ上限を消費します。対策：CI と cron のジョブは独自の支出上限を設けた API キーで実行し、クレジット制の Business ワークスペースでは、全員に Work を有効にする前にワークスペースのクレジット上限を設定してください。
- **モデルはあなたが決めないスケジュールで廃止される。** GPT-5.5 は2026年10月14日に全プランの Codex から外れ、古い Codex モデルのバージョンは7月23日に API で停止されました。共有の `config.toml` や CI ジョブに固定したモデル名は動かなくなります。対策：共有設定にバージョン名を固定せず、OpenAI の非推奨ページを毎月確認し、モデルが変わるたびに既知の小さなタスク群を再実行してください。
- **承認モードは見た目以上に権限が広い。** 「Approve for me」は対象となるアクションを人ではなく自動レビューに回し、「Full access」はサンドボックスを完全に外します。対策：OpenAI 自身のドキュメントが推奨するとおり「Ask for approval」から始め、Business と Enterprise では管理された要件で本番環境に触れるリポジトリの Full access をブロックし、CRM に書き込む MCP ツールには必ず人による承認を求めてください。
