## 概要

Agentforce は、すでに運用している CRM の内側にある Salesforce のエージェント層です。Salesforce に向けて外から接続する別製品ではありません。2025年10月の Agentforce 360 リリース以降、Agentforce Builder（自然言語でエージェントを設計する）、Agent Script、Agentforce Voice、エージェントの可観測性を束ねる名称になり、いずれも Data Cloud を改称した Data 360 に接地しています。Salesforce はその後、ポートフォリオの大半をこの名前の下に集約しました。Sales Cloud は Agentforce Sales として販売され、Revenue Cloud は現在 Agentforce Revenue Management です。規模も実在し、しかも直近の数字です。Salesforce は 2026-05-27 に 2027年度第1四半期の Agentforce ARR が $1.2B、前年同期比 205% 増と発表し、Agentforce と Slack を合わせて累計 38億件の「Agentic Work Units」を処理したとしています。買収でも前に出ています。2026-06-15 に、Intercom 改め Fin を約 $3.6B で買収する最終契約を発表し、2027年度第4四半期のクローズを見込んでいます。

## RevOps スタックに登場する理由

- **エージェントはレコードグラフの上で動きます。横ではありません。** 共有ルール、項目レベルセキュリティ、オブジェクト権限が、エージェントの読み書きできる範囲をすでに統制します。事前に別インデックスへコピーする工程がなく、Salesforce に住む RevOps チームがセキュリティレビュー開始時に必ず持ち出す論拠がこれです。
- **ホスト型 MCP サーバーは 2026年4月に GA**、対象は Enterprise Edition 以上の組織です。Agentforce 360 プラットフォーム、Tableau Next、Data 360 SQL 向けの既製サーバーに加え、自社の Flow や Apex アクションを載せたカスタムサーバーも作れます。認証は専用の MCP スコープでの OAuth + PKCE で、このスコープは既存の REST API へのアクセスを与えません。エージェントは呼び出したユーザー本人の権限の範囲内でのみ動作します。中間層を自作せずに [Claude](/ja/tools/claude/) や Cursor を Salesforce につなぐ、正直な理由はここにあります。着手点は sandbox の読み取り専用サーバー `platform/sobject-reads` です。
- **名前のついた GTM エージェントは、ブランドが与える印象より狭い。** SDR Agent から改称した Agentforce Lead Nurturing は、パーソナライズした初回メールを送り、返信がなければフォローアップし、会社が与えたナレッジで質問に答え、関心を検知し、ミーティングを設定し、オプトアウトを処理します。オムニチャネルではなくメールです。前提として Enterprise、Performance、Unlimited のいずれかのエディションと Sales および Einstein for Sales、さらに Sales Engagement、Einstein Activity Capture、Einstein Generative AI、Outlook/Gmail の生産性連携が必要で、Activity 360 Reporting とは併用できません。

## 価格の実態

Salesforce はエージェントの課金メーターを公開しています。これは聞こえるより珍しいことです。価格ページで 2026-08-01 に確認した内容です。

- **Salesforce Foundations** — $0 で開始、ユースケースは問わない
- **Flex Credits** — 100,000 クレジットあたり $500（1クレジット $0.005）。標準的なエージェントアクション1回で 20 クレジット、つまり 1アクション $0.10
- **Conversations** — 顧客向けエージェントで1会話あたり $2。同一組織内で Conversations と Flex Credits を併用することはできない
- **Agentforce User License** — $5/ユーザー/月、Flex Credits が前提、CRM オブジェクトへのアクセスは限定、従量計測 — 全従業員にエージェントを配るための行
- **Agentforce アドオン** — Sales、Service、Field Service 向けが $125/ユーザー/月、Industries が $150。従業員の利用は非計測
- **Agentforce 1 Sales** — $550/ユーザー/月から、アドオン込み、組織あたり年間 250万 Flex Credits

メーターは予算ではありません。Sales Cloud Enterprise は $175/ユーザー/月、Unlimited は $350 で、名前のついたエージェントもホスト型 MCP サーバーも Enterprise 以上を要求します。つまり $100/ユーザー/月 の Pro Suite にいるチームは、エージェントのアクションを1回買う前にエディションのアップグレードを支払います。エディション、エージェントの SKU、Data 360 の消費を1つの数字として見積もってください。

## こんなチームに向く

すでに Salesforce の Enterprise エディション以上で標準化していて、エクスポートした複製ではなく CRM 自身の権限モデルの内側でエージェントを動かすことが決定的な制約になっている企業の RevOps リーダーです。最も強いのはインバウンドリードのフォローアップと、レコードを読み書きする社内従業員向けエージェントです。

Salesforce が system of record でない場合、購入リストへのコールドアウトバウンドが課題の場合（Lead Nurturing はエンゲージメントシグナルに接地するため、スクレイピングした連絡先には何も無い）、あるいは年間5桁ドル未満でエージェントを試したい場合は見送ってください。

## 代替候補との比較

[HubSpot](/ja/tools/hubspot/) Breeze は SMB・ミッドマーケットの極で、2026-04-14 から成果課金です。解決した1会話あたり $0.50、アプローチ推奨リード1件あたり $1。Agentforce の1会話 $2 に対して、同じ単位で 4:1 の比率です。HubSpot を使っている場合、あるいは解決1会話あたりのコストが判断を決める数字である場合は Breeze を選んでください。[Rox](/ja/tools/rox/) と [Day.ai](/ja/tools/day-ai/) は最も伸びている新規参入で、分岐点は1つの問いです。Rox は Salesforce の上にエージェント群を載せ、両方の支払いが続く前提を置きます。Day.ai は system of record 自体を置き換えるべきだと主張します。Salesforce が作り直しなしには提供しないエージェントの挙動が要るなら Rox、2社目のベンダーを管理したくないなら Agentforce です。

どれも合わないなら、ホスト型 MCP サーバーに対する [Claude](/ja/tools/claude/) が退避策です。[Salesforce MCP のワークフロー](/ja/workflows/mcp-server-salesforce-revops/) で扱っています。エージェントの SKU を買わずに、統制された Salesforce データの上でエージェントの挙動が得られます。引き換えに、オーケストレーションの構築・ホスティング・監視は自分たちで行うことになります。

## 注意点

- **価格モデルは組織単位の一方通行です。** Flex Credits と Conversations は共存せず、切り替えは契約のやり直しを意味します。**ガード:** 契約前に30日間アクションを数えてください。大量の顧客向けディフレクションは $2 の Conversations に有利、小さな読み取りと更新を数多く行う社内エージェントは 1アクション $0.10 のクレジットに有利です。デモではなく実測値で決めてください。
- **予算を決めるのは Data 360 であって、エージェントの SKU ではありません。** 非構造化コンテンツにエージェントを接地させると Data 360 を消費し、これは Flex Credits とは別に契約・計測されます。**ガード:** Data 360 のクレジット割当と超過料率を、エージェントの行と同じ見積書に必ず入れさせ、エージェントの SKU だけを先に契約しないでください。
- **パイロットが遅れるのは前提条件リストです。** Lead Nurturing には Sales Engagement、Einstein Activity Capture、Einstein Generative AI、メール生産性連携がすべてライセンス済みかつ有効である必要があり、Activity 360 Reporting とは競合します。**ガード:** パイロットの日程を決める前に自社組織で各前提条件を確認し、Activity 360 の競合を自チームが実際に回しているレポーティングと突き合わせてください。
- **買収の速度が統合の速度を上回っています。** Fin は Agentforce Service と、[Qualified](/ja/tools/qualified/) はインバウンドコンバージョンと重複します。**ガード:** 発表済みの案件と重複する単独契約については、複数年の期間に同意する前に、収束の条件（製品、価格、移行パス）を書面で入手してください。
