[Userpilot](/ja/tools/userpilot/) と [Chameleon](/ja/tools/chameleon/) はどちらもプロダクトアダプションのカテゴリーに属します。CSM の電話からではなく、プロダクトの内側から機能のアダプションを促す no-code レイヤーです。エントリー tier で両者の価格差はわずか $20/月で、まさにこれが多くのチームが両者を混同する理由です。本当の違いは、それぞれが何を中心に作られているかにあります。Userpilot は in-app ガイドとプロダクト analytics (funnel、path、cohort) を1つのツールに束ねているため、離脱を確認してそのまま修正をプラットフォーム内で構築できます。Chameleon はデザイン重視の選択肢です。完全なカスタム CSS、強制される「made with」表記なし、そして本当に自社プロダクトの見た目に馴染む widget です。ルーティングの問いは、あなたのボトルネックが *アダプションがどこで崩れるかを把握すること* (Userpilot) なのか、*ブランドレビューを通過する in-app ガイドを出荷すること* (Chameleon) なのか、です。

## Userpilot が勝つ場面

- **analytics が同じツール内にある。** Userpilot は funnel、path、cohort、トレンド、イベント自動キャプチャをフロービルダーと並べて提供します。アクティベーションの離脱を見つけ、それに対処する tooltip を1つのプロダクト内で構築でき、Amplitude を別のフローツールに縫い合わせる必要がありません。Chameleon の analytics はより薄く、体験のパフォーマンスは計測しますが、プロダクト analytics プラットフォームではないため、深い path 分析を求めるチームは別のものと組み合わせます。
- **透明なエントリー価格。** Userpilot は Starter tier に $299/月を公開しています。Chameleon はプラン一覧ページに定価を掲載するのをやめており、Startup tier の約 $279 という数字は第三者データに由来し、それより上はすべて見積もりのみです。営業電話の前に実際の数字を知りたいチームにとって、Userpilot の方が摩擦の少ない評価になります。
- **アダプションと計測を1つのツールで。** CS とプロダクトが onboarding のオーナーシップを共有し、アクティベーションを計測してそれに対処する場所を1つにしたい場合、Userpilot は2つのコスト項目を1つにまとめます。この統合こそが、Userpilot が product-led な mid-market の stack に登場する理由です。
- **Lia が分析から介入までのループをカバーする。** Userpilot の AI エージェントは cohort がどこで離脱したかを示し、それを修正する in-app の介入を下書きします。analytics とビルダーが同じシステムであるため、診断と処方が1つの動作で行われます。

## Chameleon が勝つ場面

- **デザインの忠実度こそが売りのすべて。** Chameleon が当社の内訳で UX に9点を獲得し、Userpilot が8点なのには理由があります。完全なカスタム CSS、ピクセル単位の制御、そして有料 tier でのベンダー表記なしです。プロダクトとブランドのチームが取って付けたように見えるアダプションツールを却下する場面で、Chameleon はより安価なオーバーレイを葬るレビューを生き延びます。汎用的な見た目の tooltip が社内でブロックされるなら、これが決め手になります。
- **より広い体験のサーフェス。** Tour、Tooltip、Microsurvey、Launcher、Banner、Checklist、そして HelpBar 検索 widget です。特に HelpBar はヘルプコンテンツ全体への in-app 検索であり、Userpilot が並べられないものです。
- **CS ワークフロー向けにより強い統合数。** Chameleon は HubSpot、Salesforce、Intercom に加えてネイティブの Slack を提供します (統合で8点、Userpilot は7点)。survey の回答とアダプションイベントを Slack チャンネルに発火させたい CS チームにとって、これは接着作業が1つ減ることを意味します。
- **ヘルスシグナルとしての第一級の Microsurvey。** in-app の NPS、CSAT、CES survey は実際の利用イベントで発火し、CS プラットフォームに戻されます。Userpilot がサポートするのと同じパターンですが、Chameleon の survey ターゲティングはより細やかです。

## 価格の実態

エントリーはほぼ互角です。Userpilot の Starter は年払いで $299/月 (最大 2,000 MAU)、Chameleon の Startup は年払いで約 $279/月 (最大 2,000 MTU) です。分かれ目は次の tier です。Userpilot の Growth は見積もりのみですが、ほとんどの CS 組織が実際に着地する tier であるため、公開されている $299 は実際の支出を過小評価しています。Chameleon の Growth は Startup 価格のおよそ 3-4倍で、第三者データは年間 Growth 契約を $12k 以上としており、2,000 MTU と単一 Launcher の上限がきついため Startup から Growth への崖は早く訪れます。両者とも利用量で課金し (Userpilot は MAU、Chameleon は MTU)、そのため大きな無料 tier が課金対象数を膨らませても売上を膨らませない、高トラフィックの freemium や PLG プロダクトにはどちらも不利です。どちらにコミットするにせよ、エントリーの誘い文句ではなく Growth tier で12か月のユーザー予測をモデル化してください。Growth や Enterprise の定価はどちらも公開していません。

## 導入の労力

どちらも no-code で立ち上げが速く、CS や product ops がエンジニアリングのチケットなしに体験を構築・ターゲティングできるため、onboarding フローのイテレーションは当日の変更で済みます。Userpilot の軽い負担は analytics が統合されている点です。別の analytics ツールを立ち上げないため、統合が1つ減ります。Chameleon の重い負担はデザイン作業です。カスタム CSS が差別化要因ですが、それを実現するには誰かが体験を自社プロダクトに合わせてスタイリングする必要があり、これは安価な汎用オーバーレイの道なら省ける実際のフロントエンドの工数です。どちらも enterprise の CS プラットフォームのような専任 admin は不要です。どちらでもフロー構築に数日を見込み、Chameleon でピクセルパーフェクトな CSS テーマ設定を行うなら1週間を追加してください。

## 結論

- **Userpilot を選ぶ**のは、CS とプロダクトが onboarding のオーナーシップを共有し、analytics と in-app のアクションを1つのツールに求める場合です。アクティベーションがどこで崩れるかを *把握* して同じ場所で修正しようとしており、透明な $299 のエントリーが見積もりのみの営業サイクルに勝ります。2k-100k MAU の帯域にある product-led な mid-market SaaS に最も強く適合します。
- **Chameleon を選ぶ**のは、デザインの忠実度が決め手となる場合です。ブランドとプロダクトのチームが取って付けたように見えるものをすべて却下する、あるいは HelpBar 検索 widget とネイティブ Slack が必要な場合です。アダプションツールが出荷前にデザインレビューを通過しなければならない、従業員 50-500人の SaaS で最も適しています。
- **どちらも選ばない**のは、ヘルススコアリング、更新の forecasting、CSM のタスク管理が必要な場合です。どちらも CS プラットフォームではありません。[Gainsight](/ja/tools/gainsight/) または [Vitally](/ja/tools/vitally/) を購入し、選んだ in-app ツールをその下に配線してください。そしてアダプション analytics が主たる価値で in-app ガイドが大きく劣後する二番手なら、[Pendo](/ja/tools/pendo/) がどちらよりも強い選択肢です。

上記の条件がなく何もない状態で選ぶなら、Userpilot を選んでください。統合された analytics と透明なエントリー価格がリスクの最も低い default にしており、計測レイヤーが無料で手に入ります。ブランドレビューが汎用的な見た目のガイドをブロックするとき、あるいはデザインの忠実度がフローの出荷を阻む唯一の要因になったとき、Chameleon に切り替えてください。
