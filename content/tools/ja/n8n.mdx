## 概要

n8n は技術チーム向けのワークフロー自動化プラットフォームです。各ステップをノードとして並べるビジュアルキャンバスを持ち、キャンバスで足りない部分は JavaScript や Python のコードステップで補えます。さらに、任意の LLM をツールやメモリにつなぐ AI エージェントノードも備えています。インテグレーションは 1,000 以上あります。n8n のクラウドでも自社インフラでも動かせます。GitHub リポジトリのスター数は 210,000 を超えており、あらゆる自動化プロジェクトの中でも最もスターを集めているものの 1 つです。非技術ユーザーにとって扱いやすい [Zapier](/ja/tools/zapier/) と、はるかに高価な [Workato](/ja/tools/workato/) のようなエンタープライズ iPaaS の中間に位置します。

オープンソースではなく、ソースアベイラブルです。セルフホスト版の Community Edition は n8n の Sustainable Use License の下で無料ですが、このライセンスが認めているのは社内業務での利用と非商用の配布だけです。`.ee` と付いたファイルには、別途 n8n Enterprise License が必要です。

同社は独立系で、資金も潤沢です。2025 年 10 月に Accel 主導で $180M のシリーズ C を調達し、評価額は $2.5B、NVIDIA の NVentures も参加しました。2026 年 5 月には SAP がセカンダリー取引で株式を取得し、その際の評価額は $5.2B でした。あわせて SAP のエージェントビルダー Joule Studio に n8n を組み込む複数年契約も結んでいます。n8n のプレスページによれば、累計調達額は $240M です。

## RevOps・Legal Ops・Recruiting のスタックに入る理由

- **課金単位はステップではなく実行回数です。** 1 回の実行とは、ステップ数に関係なくワークフロー全体を 1 回走らせることです。月 500 回起動する 20 ステップのエンリッチメント兼ルーティングのフローは、n8n では 500 実行、ステップ単位の課金では 10,000 タスクになります。ワークフローが長くなったチームがここへ移ってくるのは、この 1 つの設計判断が理由です。
- **MCP は双方向に、すべての有料プランで使えます。** インスタンスレベルの MCP サーバーにより、Claude Code、Claude.ai、ChatGPT、[Cursor](/ja/tools/cursor/)、Codex、Gemini CLI、VS Code がワークフローを検索し、公開設定したものを実行でき、n8n 2.13 以降はワークフローやデータテーブルの作成・編集もできます。クライアントは OAuth または個人用 API キーで接続します。MCP Server Trigger ノードは 1 つのワークフローを専用の MCP サーバーに変え、MCP Client ノードは n8n のエージェントから外部のサーバーを呼び出せるようにします。n8n の価格ページでは、この 3 つすべてが Starter、Pro、Enterprise に含まれると記載されています。
- **データを自社の境界内に置けます。** セルフホストなら顧客レコードが自社インフラの外に出ることはありません。n8n のクラウドではデータはフランクフルトに保存されるため、候補者や契約のデータを扱う EU 拠点の Legal Ops・Recruiting チームにとってはこれでデータ所在地の問題に答えが出ます。

## 価格の実態

n8n.io/pricing はユーロ建てのみで価格を掲示しています（2026-11-22 確認）。全プランでユーザー数無制限、ワークフロー数無制限、全インテグレーションが含まれます。以下は年間契約時の月額です。ページ上では年払いを「Save 17%」と表示しており、月払いは約 20% 高くなる計算です。

- **Community Edition — 無料、セルフホスト。** 実行回数の上限はありません。SSO、Git によるバージョン管理、環境分離はありません。メールアドレスを登録すると、エディターでフォルダーとデバッグ機能が使えるようになります。
- **Starter — €20/月**（約 $23）。2,500 実行、同時実行 5、共有プロジェクト 1、Assistant クレジット月 1,600、ワークフロー履歴 1 日分。クラウドのみ。
- **Pro — €50/月。** 10,000 実行、同時実行 20（大きい Pro サイズでは 50）。共有プロジェクト 3、管理者ロール、グローバル変数、ワークフロー履歴 5 日分、インサイト 7 日分、プランサイズに応じて Assistant クレジット 4,000 または 9,600。クラウドのみ。
- **Business — €667/月。** 40,000 実行、共有プロジェクト 6、SSO と LDAP、Git によるバージョン管理、複数環境、queue mode、インサイト 30 日分。セルフホストのみで、クラウド版はウェイトリスト受付中です。従業員 100 人未満の企業向けで、サポートはフォーラムのみです。
- **Enterprise — 個別見積もり。** クラウドまたはセルフホスト、同時実行 200 以上、ログストリーミング、監査ログ、外部シークレットストア、インサイト 365 日分、SLA 付きサポート。
- **Start-up Plan — €333/月。** Business の 50% 引きで、従業員 20 人未満かつ累計調達額 €5M 未満の企業が対象です。期間は 1 年間、または条件を満たし続ける限りそれ以上です。

9 月の確認時からの変更点：価格と実行回数の枠は据え置きです。Assistant クレジットは約 30% 減り、Starter では 2,300 から 1,600 に、Pro では最大 13,700 から最大 9,600 になりました。大きい Pro サイズでは同時実行が最大 50 になりました。追加 300,000 実行ごとに €4,000 という公開されていた超過料金はなくなりました。Starter と Pro の超過分は現在「Capped」と記載され、Business の FAQ はアップグレードしない場合に超過料金が「発生する場合がある」と述べるだけです。

5〜50 人の構築者がいるチームの実際の価格帯：クラウドで SSO なしでよければ Pro で年約 €600、Start-up Plan なら年約 €4,000、Business なら年 €8,004 です。高くつくのは Pro から Business への移行です。これで SSO と Git ベースの環境が手に入りますが、同時に n8n のクラウドから自社での n8n 運用への移行も意味します。一般的なクラウドでセルフホストする場合のインフラ費用は、当社の推定で月 $40–80 です（小型 VM 1 台、マネージド Postgres、queue mode 用の Redis）。これにエンジニアの工数が加わります。

## 最適な利用者

- **最適な利用者：** 従業員 20〜200 人の企業で、CRM、エンリッチメント、メッセージングにまたがる多段の自動化を構築し、コードステップとエージェントノードを同じツールで使いたい RevOps・GTM エンジニア。ワークフローが 10 ステップを超えると、実行単位の課金で安く抑えられるため、効果が最もはっきりします。
- 契約や候補者のデータをセルフホストまたは EU 内に置く必要がある Legal Ops・Recruiting チーム。
- Claude、Codex、Cursor に標準化し、それらのアシスタントが MCP 経由で呼び出し・編集できる単一のオーケストレーション層を求めるチーム。
- **向いていないのは、** JSON を読んだり失敗した HTTP ノードをデバッグしたりできる人がいないマーケティング・営業チームです。また、n8n で作った自動化を自社製品として再販する予定の人にも向きません。ライセンス上、別契約なしには禁止されています。

## 代替ツールとの比較

- **[Zapier](/ja/tools/zapier/)** — シェア首位で、コネクターのカタログが最も広く、学習曲線が最もなだらかです。$19.99/月から。構築者が非技術者でフローが短いなら Zapier を選んでください。フローが長くなったら n8n です。Zapier はステップごとにタスクとして課金するためです。
- **Microsoft Power Automate** — もう 1 つのシェア上位で、多くの Microsoft 365 契約に含まれています。会社が Microsoft 365 で動いており、IT がそのテナントのガバナンス内で自動化を管理したい場合に選んでください。
- **[Make](/ja/tools/make/)** — 最も安い有料エントリーで、Core は $9/月、クレジット課金です。複雑な分岐に強いビジュアルビルダーを持ちます。予算が厳しく、セルフホストの必要がない場合に選んでください。
- **[Gumloop](/ja/tools/gumloop/)** — 最も急成長している AI ネイティブの新興勢で、2026 年 3 月に Benchmark 主導で $50M のシリーズ B を調達しました。Pro は $37/月で 20,000 クレジット。エンジニアのいないチームがドキュメントやモデルを多用するエージェントパイプラインを回すなら Gumloop です。コードステップ、セルフホスト、モデル呼び出しを計量しない課金単位が欲しいなら n8n を選んでください。
- **[Activepieces](/ja/tools/activepieces/)** — オープンソースの代替です。コアは MIT、Plus は $16/月。ライセンスが本当にオープンソースである必要がある場合や、販売する製品に自動化を組み込む予定の場合に選んでください。
- **[Workato](/ja/tools/workato/)** — エンタープライズ iPaaS で、Vendr の中央値は年 $64,544 です。エンタープライズ規模で CRM と ERP 間の統制された order-to-cash を回すなら Workato です。フォーラムサポートのみの n8n Business では手薄です。

## 注意点

- **ライセンスはオープンソースではありません。** Sustainable Use License が認めているのは社内業務での利用と非商用の配布だけです。**対策：** n8n で顧客向けのワークフローを動かす、あるいは販売する製品に組み込むのであれば、構築前に n8n の Embed または商用条件を書面で取得してください。初日からそれが計画なら、Activepieces もあわせて評価してください。
- **Pro から Business への移行は、価格の跳ね上がりであり、プラットフォームの移行でもあります。** SSO、Git によるバージョン管理、環境分離は Business の機能で、Business はセルフホストのみです。**対策：** パイロット段階で、セキュリティ部門が 12 か月以内に SSO を要求するかどうかを決めてください。要求するなら、Cloud Pro で構築して後から移行するのではなく、最初から Business（条件を満たせば Start-up Plan）を予算に組み込んでください。
- **超過料金は公開されなくなりました。** Business と Enterprise のワークフローはクォータを超えても動き続けますが、n8n の FAQ には超過料金が発生する場合があると書かれており、Business の年間契約顧客にはクォータの 80% 付近で営業から連絡が来ます。**対策：** 署名前に実行あたりの超過料金を注文書に明記させ、使用状況ページで年間枠の 60% にアラートを設定してください。
- **ポーリング型トリガーは実行回数を消費します。** 5 分ごとに起動するスケジュールは 1 日 288 回動き、月に約 8,640 実行になります。1 つのワークフローだけで Starter の 2,500 の 3 倍以上です。**対策：** 送信元アプリが対応していれば必ず webhook を使い、最初の 2 週間は使用状況ページで実行回数を確認してください。
- **MCP の公開範囲はクライアント単位で制限できません。** ワークフローはオプトイン方式で、1 つずつ、またはプロジェクトやフォルダー単位で有効化します。しかし、接続したすべてのクライアントが、Claude でも ChatGPT でも、有効化したものすべてを参照でき、検索ツールはユーザーが参照できるすべてのワークフローのプレビューを返します。**対策：** 接続されたどのアシスタントが起動しても安全なワークフローだけを公開してください。書き込みの多いものや破壊的なものは MCP から外すか、別インスタンスに置いてください。セルフホストのインスタンスでは、`N8N_DISABLED_MODULES=mcp` でサーバーを完全に無効化できます。
- **セルフホストの有償プランは毎日 n8n と通信します。** Business と Enterprise のライセンスキーは 1 日 1 回、使用量を添えて n8n のライセンスサーバーに ping を送ります。**対策：** ネットワークポリシーでライセンスサーバーへのアウトバウンド通信を許可し、セキュリティレビューが自ら気づく前に伝えておいてください。
