[Claude](/pt-BR/tools/claude/) e [Perplexity](/pt-BR/tools/perplexity/) são comparados entre si porque os dois começam em $20/mês e os dois respondem perguntas digitadas numa caixa de texto. Esse enquadramento venceu em 2026. A Perplexity agora publica um servidor MCP próprio, então a decisão real não é mais qual produto assinar: é se você compra a Perplexity como uma segunda licença ou instala como ferramenta dentro do Claude. Os dois se compõem de um jeito que ChatGPT e Perplexity não fazem, e a conta muda quando você percebe isso.

## O que mudou desde a versão anterior desta página

**A Perplexity passou a ser chamável.** O pacote `@perplexity-ai/mcp-server` expõe quatro ferramentas contra as APIs Search e Agent da Perplexity — `perplexity_search`, `perplexity_ask`, `perplexity_research` e `perplexity_reason`. Claude, Claude Code ou qualquer cliente MCP consegue rodar pesquisa web com citações sem ninguém abrir perplexity.ai. Exige uma API key do `console.perplexity.ai` e é cobrada à parte de qualquer licença Pro.

**A escada da Perplexity esticou nas duas direções.** O Max chegou a $200/mês com Model Council — uma consulta distribuída entre vários modelos de fronteira e as respostas sintetizadas — e o Enterprise Max a $325/licença/mês. Na outra ponta, o navegador Comet derrubou o paywall em março de 2026 e agora roda de graça no Mac, Windows, iOS e Android.

**A história de contexto longo do Claude ficou mais precisa, não maior.** Uma janela de 1M de tokens é o padrão no Claude 4.6 e modelos posteriores, sem header beta e sem sobretaxa de contexto longo: uma requisição de 900k tokens é cobrada na mesma tarifa por token que uma de 9k. Mas isso é uma propriedade da API. O claude.com/pricing lista uma janela de 200k nos planos individuais. A versão anterior desta página dava a entender uma janela de 1M dentro do produto de chat; isso estava errado e fica corrigido aqui.

**O Claude ganhou uma segunda superfície de agente.** O Cowork — um agente no nível do sistema de arquivos que trabalha sobre seus arquivos e apps conectados em vez do seu repositório — saiu no desktop em janeiro de 2026 e chegou à web e ao mobile em julho para assinantes Max.

A assimetria é a página inteira. Perplexity é um servidor. Claude é um cliente. Na comparação com o ChatGPT isso produz um impasse; aqui produz um stack.

## Onde o Claude ganha

- **Documentos que não cabem em nenhum outro lugar.** A janela de 1M de tokens a preço padrão, mais até 600 imagens ou páginas de PDF numa única requisição, cobre um data room de contratos ou um trimestre de transcrições de calls. A Perplexity foi construída para sair até a web, não para segurar o seu corpus.
- **É a peça que orquestra.** Claude Code, Cowork, Skills, um cliente MCP e o Agent SDK são um runtime que você programa. A história agêntica da Perplexity é um navegador e uma API — bons, mas você constrói em volta deles em vez de dentro deles.
- **Entregáveis, não respostas.** Redlines, primeiras versões, código funcionando, extração estruturada para um schema que alguém consome depois. A síntese da Perplexity é afinada para resolver uma pergunta, que é outro output.
- **Consegue chamar o outro.** Não existe configuração em que a Perplexity execute o Claude Code.

## Onde a Perplexity ganha

- **Citações são o formato do produto, não um modo em que ele entra.** Para um memo que vai para o jurídico, para um regulador ou para o conselho, isso decide se o trabalho sobrevive a ser encaminhado.
- **Spaces.** Um projeto de pesquisa com fontes fixadas persiste entre sessões e é passado para um colega. Um Project do Claude chega perto, mas o Space é construído em volta de fontes em vez de instruções.
- **Um navegador grátis com assistente na página.** O Comet não custa nada em quatro plataformas. Nada na linha do Claude ocupa essa superfície.
- **Retrieval que você compra por requisição.** O Sonar vende pesquisa web como capacidade medida. Quando quem consome essa pesquisa é um agente e não uma pessoa, licença é a unidade errada e a Perplexity é quem vende a certa.
- **Internal Knowledge Search.** Nos planos Enterprise os seus próprios documentos ficam ao lado da web ao vivo numa mesma resposta, sob uma garantia de não treinamento.

## A realidade de preço

A entrada é um empate genuíno e as escadas divergem imediatamente.

- **Individual** — Claude Pro $20/mês, ou $17/mês na cobrança anual com $200 adiantados. Perplexity Pro $20/mês, $200/ano. Empate nos dois modos de cobrança.
- **O degrau do meio que falta** — o Claude Max começa em $100/mês por 5× o uso do Pro e chega a $200/mês por 20×. A Perplexity pula direto de $20 para $200 sem nada no meio. Se o seu uso é três vezes uma licença Pro, só um dos dois te vende um plano para isso.
- **Licenças de time** — Claude Team padrão é $25/licença/mês, $20 na cobrança anual; licenças premium são $125/mês, $100 anual. Perplexity Enterprise Pro é $40/licença/mês ($400/licença/ano). Cerca de 2× a favor do Claude no degrau padrão, e o que o prêmio da Perplexity compra é Internal Knowledge Search e a garantia de treinamento.
- **Topo da escada** — Perplexity Enterprise Max é $325/licença/mês ($3,250/licença/ano), um número fixo e grande. Claude Enterprise é $20/licença mais todo o uso de modelo cobrado a tarifas de API: um piso mais baixo e um teto definido por quanto o seu time aperta. São formatos de cobrança diferentes, e comparar por licença não significa nada sem uma estimativa de uso.
- **Medido** — o Sonar custa cerca de $1 por milhão de tokens no nível base, $3 de entrada / $15 de saída por milhão no Sonar Pro, mais aproximadamente $5-12 por 1,000 requisições de recuperação web. A API do Claude está em $5/$25 por milhão para Opus 5 e Opus 4.8, $2/$10 para Sonnet 5 até 31 de agosto de 2026 e $3/$15 depois, e $1/$5 para Haiku 4.5, com busca web a $10 por 1,000 buscas, web fetch grátis além dos tokens, e a Batch API cortando os dois pela metade. Sonar Pro e Sonnet caem no mesmo $3/$15; a diferença é qual lado te cobra pelo retrieval.

Duas licenças individuais dão $40/mês. A configuração mais barata que quase ninguém enxerga é uma licença Claude Pro de $20 mais uma API key medida da Perplexity, que coloca retrieval com citações dentro da ferramenta que já faz o trabalho.

## Esforço de implementação

O Claude como produto de chat não precisa de nada. O Claude como agente — servidores MCP, Skills, contas de serviço, uma revisão do que ele tem permissão de escrever — é um projeto real medido em dias, e a linha que vale projetar é a conta de tokens, não o número de licenças.

A Perplexity como app também não precisa de nada. A Perplexity como servidor MCP dentro do Claude é uma API key e uma entrada de configuração: menos de uma hora, mais uma conta medida que antes não existia. O Internal Knowledge Search no Enterprise é a única peça aqui que é um projeto de conector de verdade.

## Pontos de atenção

- **Pagar duas vezes por um trabalho só.** Rodar o servidor MCP da Perplexity dentro do Claude enquanto mantém licenças Perplexity Pro cobra uma licença e um medidor pela mesma pesquisa. *Proteção:* atribua uma superfície por pessoa e leia o gasto no console de API no fim do primeiro mês antes de renovar licenças.
- **Retrieval medido dentro de um loop.** A taxa de recuperação web é cobrada por chamada, não por sessão, então um agente que tenta de novo gera conta enquanto falha. *Proteção:* coloque um teto de gasto na API key antes que ela chegue a qualquer processo desassistido.
- **Tratar uma janela de 1M como 1M de precisão.** O recall degrada conforme a janela de contexto enche — a própria documentação da Anthropic nomeia isso e recomenda compaction em vez de empilhar. *Proteção:* curadoria do que entra, e passe documentos-fonte em vez de arquivos inteiros.
- **Teatro de citações.** Os dois produtos vão devolver uma lista de fontes que inclui uma página que não sustenta a afirmação colada nela. *Proteção:* clique em cada citação que carrega um número antes de o trabalho sair das suas mãos.

## Veredito

- **Escolha o Claude** se o output é um entregável — uma minuta, um redline, uma extração, um script — ou se o input é mais longo do que alguém quer ler.
- **Escolha a Perplexity** se o output é uma resposta cuja procedência vai ser questionada, ou se um pesquisador não técnico precisa de Spaces e Comet em vez de uma janela de chat.
- **Escolhendo um, com uma única linha de orçamento: Claude Pro a $20/mês, e depois some a Perplexity pelo servidor MCP com uma API key medida.** Compra retrieval com citações dentro da ferramenta que faz o trabalho e pula a segunda licença por completo. Inverta só se a pessoa passa quase o dia todo pesquisando e nada construindo.
- **Duas licenças a $40/mês** quando o pesquisador e quem constrói são pessoas diferentes.
- **Nenhum dos dois**, se as respostas moram nos seus próprios sistemas e não na web aberta — isso é um problema de retrieval corporativo, e a lista curta é [Gemini Enterprise](/pt-BR/tools/gemini/) e [Glean](/pt-BR/tools/glean/). Se busca na web aberta é o trabalho inteiro, [melhores buscadores com IA](/pt-BR/vs/best-ai-search-engines/) é a página certa. Se quem você está de fato deslocando é a OpenAI, leia [ChatGPT vs Perplexity](/pt-BR/vs/chatgpt-vs-perplexity/) no lugar.
