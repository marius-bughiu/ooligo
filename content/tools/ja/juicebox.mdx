## これは何か

Juicebox（PeopleGPT ブランド）は、ブール検索を自然言語クエリに置き換える AI-native なソーシングツールです。LinkedIn、GitHub、カンファレンスの登壇者リスト、特許や論文の著者情報、その他のシグナルなど、数十の公開ソースから構築された 800M 以上のプロフィールのデータベースを対象とします。2023 年にローンチされ、レガシーな検索エンジンに後付けするのではなく LLM のプリミティブを中心に構築された、広く採用された初のリクルーティング製品でした。ベンダーは現在 25,000 チームが利用していると公表しています。

2026 年後半の時点で、これはもはやアウトリーチを後付けした検索ボックスではありません。製品の重心は **Juicebox Agents** です。プロジェクト内に常駐する常時稼働のソーシングエージェントで、ATS、インテーク資料、通話の文字起こしからコンテキストを取り込み、人材市場をマッピングし、shortlist を作成し、接続したメールボックスからアウトリーチを送信します。もう一つの変化は、Juicebox が自身の UI の外からも使えるようになったことです。公式の **MCP サーバー**により、Claude、ChatGPT、Cursor、Gemini CLI からリクルーティング分析を照会し、Agent を作成・キャリブレーション・一時停止・クローズできます。これにより Juicebox は、[Pin](/ja/tools/pin/)、[SeekOut](/ja/tools/seekout/)、[goperfect](/ja/tools/goperfect/) と並ぶ agent-first ソーシングの領域のど真ん中に位置づけられます。

## なぜ Recruiting スタックに登場するのか

- **自然言語でのソーシング。**「オープンソースの ML ライブラリにコントリビュートし、フィンテックのスタートアップで働いた経験のある、ベルリンのシニア Python エンジニア」と入力すると、数秒でランク付けされたリストが返り、各プロフィールが合致した理由を AI spotlight が説明します。シニアソーサーが 30 分かけて組んでいたブール文字列が、一文で済みます。
- **コンテキストを持つ Agent。** Agent は検索の前に、接続されたソース（Google Drive、Notion、Granola、[Metaview](/ja/tools/metaview/) の文字起こし、Business プランでは ATS の過去の採用実績）を読み込み、その後はあなたが承認・却下したプロフィールから学習します。自律度は選べます。完全自動にするか、shortlist またはシーケンスの段階にチェックポイントを置くかです。
- **AI クライアントから操作できる。** リモート MCP サーバー（`https://mcp.juicebox.ai/v1`、ユーザーごとの OAuth）はすべての有料プランで使えます。分析ツールと Agent ツールは全プランで動作し、shortlist、候補者詳細、プロジェクトのツールは Business 限定です。[Claude](/ja/tools/claude/) で作業しているリクルーターは、アプリを開かずに新しい求人の Agent を立ち上げられます。
- **幅広い ATS 対応。** 40 以上の ATS（Greenhouse、Lever、Ashby、Workday、iCIMS、SmartRecruiters など）と 20 以上の CRM に対応し、求人のインポート、ATS へのエクスポート、rediscovery を行えますが、いずれも Business プラン限定です。

## Pricing

フリーミアムのシート課金で、月額または年額です。Juicebox は年額の切り替えを 15% 割引とうたっていますが、実際の割引率はプランで異なります。Starter は 17%、Growth は 10% しか下がりません。2026-11-09 に juicebox.ai/pricing で確認しました。

- **Free**：$0、限定的な検索、1 シート、単発の contact credits 5 件、エクスポート不可
- **Starter**：$119/シート/月、または**年額課金で $99/シート/月**。1 シート、無制限の検索、月 500 contact credits と 500 export credits、1 mailbox
- **Growth**：$199/シート/月、または年額 $179/シート/月。最大 5 シート、いずれも有料。シートあたり月 1,500 contact credits と 1,500 export credits、talent insights、シートあたり 3 mailboxes
- **Business**：個別見積もり、年額のみ。無制限の contact credits、シートあたり月 2,250 件のエクスポート、ATS/CRM 統合、hiring manager シート、network sourcing、利用分析、SSO と SCIM、シートあたり 6 mailboxes
- **Juicebox Agents アドオン**：すべての有料プランで $199/エージェント/月。contact credits と email credits は無制限

**実際のコスト：**「$99」という見出しは、自動化なしの年額 1 シートの価格です。宣伝どおりの使い方（1 シート + 常時稼働の Agent 1 つ）をする一人のリクルーターの支払いは **$298–318/月**（シート $99–119 + エージェント $199）です。請求額を動かす点が二つあります。第一に、Agent はソーシング中、一時停止中、対応待ちの間は有料のエージェント枠を占有します。無料なのはキャリブレーション中とクローズ済みの Agent だけなので、一時停止したまま忘れた Agent も $199 かかり続けます。第二に、比較表では電話番号 1 件が 3 contact credits、メールは 1 件 1 credit なので、電話中心のアウトリーチは Starter の 500 credits を約 3 倍の速さで消費します。ATS 同期と MCP の shortlist ツールはどちらも個別見積もりの Business にあるため、統合に依存するチームは初日からこのプランを予算に入れておくべきです。

## こんなチームに最適

- エンジニア、デザイナー、ML 研究者を採用する成長期のテック企業。キーワードマッチより実績レベルのシグナルが効く職種
- 人員を一人増やす代わりに、通年募集の求人ごとに常時稼働の [AI ソーシング](/ja/learn/ai-sourcing/)エージェントを置きたい少人数の TA チーム（リクルーター 1〜3 人）
- すでに Claude や ChatGPT の中で仕事をしていて、MCP 経由でそのクライアントからソーシングを起動・監視したいチーム

## 注意点

- **ファネルの統合では既存プレイヤーが上。** 多くのチームがすでに使っている [hireEZ](/ja/tools/hireez/) と [Gem](/ja/tools/gem/) は、より深い CRM ワークフローとパイプラインのレポーティングを備えており、Juicebox は ATS 同期を Business に限定しています。*対策：* ATS を system of record として維持し、Juicebox は discovery と初回接触のレイヤーとして扱い、ATS エクスポートを前提にする前に Business の価格を書面で取得してください。
- **シグナルの乏しい職種では精度が落ちる。** 営業、オペレーション、従来型マネジメントの候補者は公開されている足跡が少ないためです。*対策：* Juicebox はオンラインのシグナルが強い職種に絞り、それ以外にはリファラルやエージェンシーのチャネルを残してください。
- **カバレッジは地域によって差がある。** 米国、英国、EU のデータが最も充実しており、APAC や LATAM の一部市場は薄めです。*対策：* 支払う前に Free プランで実際のターゲット地域で 20 人のテスト検索を行い、[Findem](/ja/tools/findem/) や現在のツールと recall を比較してください。
- **Agent はあなたのドメインから実際のメールを送る。** キャリブレーションの悪い auto-email の Agent は送信者レピュテーションを損ないかねません。*対策：* すべての Agent を最初の 1 週間は auto-shortlist モードで動かし、shortlist が自分で選ぶ内容と一致してから auto-email に切り替えてください。
- **MCP セッションは 30 日ごとに失効し**、SSO を強制している組織では SSO 経由で承認されていない接続が拒否されます。*対策：* MCP サーバーに対して自動化を組む人向けに再認証の手順を文書化し、気づかないうちの失効でワークフローが止まらないようにしてください。

## 代替ツール

- **hireEZ / Gem**：ATS ネイティブなシーケンスとパイプラインのレポーティングが検索 UX より重要な場合はこちらを選んでください。彼らは既存プレイヤーであり、Juicebox は自然言語による discovery とエージェントの自律性で勝り、彼らは下流で勝ります。
- **[Pin](/ja/tools/pin/)**：最も速く伸びている agent-first の競合で、こちらも $99 からのフリーミアムです。一つのエージェントにソーシングから日程調整までを一気通貫で任せたい場合に選んでください。[Pin vs Juicebox](/ja/vs/pin-vs-juicebox/) を参照。
- **[SeekOut](/ja/tools/seekout/)**：自分で検索を回すより、ベンダーが提供する shortlist サービスを望む場合に選んでください。
- **[goperfect](/ja/tools/goperfect/)**：多数の ATS をまたいだ継続的なマルチチャネルの autopilot が中核ニーズである場合に検討してください。

[ATS](/ja/learn/ats-vs-recruiting-crm/) の代わりにはなりません。ファネル管理には [Ashby](/ja/tools/ashby/)、[Greenhouse](/ja/tools/greenhouse/)、または他の ATS と組み合わせてください。
