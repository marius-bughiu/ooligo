## 実際に手放すものは何か

[Claude](/ja/tools/claude/) から移行する理由のうち、成立するものが 2 つ、成立しないものが 1 つあります。

成立する理由。Claude がそもそも提供していない機能が必要な場合です。画像生成、動画、コンシューマー向けの音声プロダクト。あるいは組織が AI ベンダーを 1 社に統合しようとしていて、Claude が品質ではなくカバー範囲の広さで負ける場合です。これらは構造的な差であり、今後のリリースで解消されるものではありません。

成立しない理由。ベンチマークが動いた、というものです。公開評価のスコア差はモデルのリリースごとに双方向に振れますし、自社チームが実務で感じる差とはほとんど一致しません。会議室での主張が「もう一方のほうが賢くなったらしい」であれば、それは移行の根拠になりません。

かつてこのページにあった論点が 1 つ消えました。MCP はもはや Claude に留まる理由ではありません。ChatGPT は developer mode 経由で読み書き両方の MCP クライアントアクセスを備えており、Perplexity も自社サーバーを公開しています。Claude のデフォルト挙動は依然として優れています。コネクターが開発者向け設定ではなく第一級の機能面として提供されており、これはエンジニアではなく ops manager が保守する場面で効きます。ただし「MCP を失う」という主張はもう成り立ちません。

## ChatGPT — カバー範囲の広さ、そして画像と動画への唯一の経路

[ChatGPT](/ja/tools/chatgpt/) は範囲の広さで勝ちます。そしてこの広さはマーケティング上の話ではなく、実際のプロダクト判断です。動画の Sora、ネイティブの画像生成、agent mode の仮想ブラウザー、プラグインディレクトリ。この 4 つを同時にカバーする代替は存在しません。Claude は最初の 2 つをまったく持ちません。チームのデザイナー、marketer、recruiter が毎週画像を作っているなら、Claude はそのシートを置き換えられません。設定でこの差は埋まりません。

価格レンジの下限も ChatGPT のほうが低くなっています。ChatGPT Go は $8/月、Claude の最安の有料シートは年額払いで $17/月です。およそ半額であり、Go はこの比較の中で唯一、フル価格を払いたくないライトユーザー向けに設計されたプランです。

**ChatGPT に移行すべき場合。** クリエイティブ制作が週次のワークフローに入っている場合、コード・文章・画像・動画をベンダー 1 社にまとめたい場合、あるいは Microsoft と OpenAI のインフラに標準化していて統合の経路が短い場合です。

**移行すべきでない場合。** 最も価値の高い時間を長文ドキュメントの統合や最終成果物の文章品質に使っている場合です。この 2 つは 2023 年以降 Claude の優位が一貫している領域であり、同じ仕事を ChatGPT でやると担当者には後退として体感されます。

## Perplexity — 出典付きリサーチ、そしてアシスタントから呼び出せる存在へ

[Perplexity](/ja/tools/perplexity/) は汎用アシスタントではなく回答エンジンです。Claude の置き換えとして購入するのが、このページで最も典型的な誤りです。2 つの汎用アシスタントより優れている領域は狭く、そして価値があります。ウェブに根拠を持つ回答にインライン出典が付き、1 クリックで検証してそのまま stakeholder に転送できます。競合リサーチ、規制の確認、アカウントや候補者のデューデリジェンスでは、推論は優れていても出典の痕跡を残さないモデルに勝ちます。

対応すべき変化は、Perplexity が外部から呼び出せるようになったことです。公式パッケージ `@perplexity-ai/mcp-server` は 4 つのツール — `perplexity_search`、`perplexity_ask`、`perplexity_research`、`perplexity_reasoning` — を stdio 経由で任意の MCP クライアントに公開します。Claude も含まれます。これにより判断は「どのシートを買うか」から「どのレイヤーに置くか」に変わります。Claude と Perplexity を比較していたチームは、Claude をフロントエンドとして残し、その背後で Perplexity を出典付き検索ツールとして走らせる構成に移りつつあります。

**Perplexity に移行すべき場合。** 最新情報のリサーチが利用の大半を占め、すべての回答に出典が必要な場合です。

**移行すべきでない場合。** アシスタントの中で文章を書き、コードを書き、思考している場合です。それらを Perplexity に移すのは後退であり、MCP サーバーがある以上、どちらかを選ぶ必要もありません。

## Claude に留まるのが正解である条件

- 最も価値の高い業務が長文コンテキストである。300 ページのデータルーム、契約書スタック一式、四半期分のサポート記録。非常に長い入力に対する一貫性は、維持されてきた優位です。
- 最終的な文章品質そのものが成果物であり、誰かが書き直す下書きではない。
- 自社システム上でエージェントのワークフローを構築していて、保守担当が技術者ではない。デフォルトで有効なコネクターは、開発者フラグの裏にあるコネクターより価値があります。
- チームが Claude Code、スキル、Projects を業務の基盤として使っている。これらには移植先となる直接的な同等物がありません。
- 移行理由が、具体的な業務を伴わない抽象的なモデル品質である。

## 移行の実コスト

シート単価は十分に近く、これで判断すべきではありません。Claude Pro は $20/月、年額払いなら $200 前払いで $17/月です。ChatGPT Plus は $20/月。チーム規模では Claude Team の標準シートが $25/月、年額払いで $20、対する ChatGPT Business は月額払いでユーザーあたり $25/月です。Claude Team は最低 2 名からで、ほぼ誰も排除しない水準です。

コストが漏れるのは高容量プランです。Claude Max は Pro の 5 倍利用で $100/月、20 倍で $200/月、月額払いのみです。ChatGPT Pro も $100 と $200 の 2 段階で同じ構造です。Perplexity は幅が最も広く、Pro が $20/月（$200/年）、Max が $200/月（$2,000/年）で中間の安価なプランはなく、法人シートは Enterprise Pro が $40/月（$400/年）、Enterprise Max が $325/月（$3,250/年）です。この最上位シートは Claude Team 標準シートの 16 倍を超えます。購入するのは名前を挙げられる個人に限り、全社デフォルトにしてはいけません。

見落とされがちなコストが 2 つあります。1 つ目は Claude Enterprise で、アクセス料が $20/シート、モデル利用は API レートで別途課金されます。つまり利用量の多い Enterprise 展開は定額ではなく従量請求になります。ChatGPT Enterprise とはシート単価ではなく想定利用量で比較してください。2 つ目は移行作業そのものです。プロンプトライブラリ、Projects、配線済みの MCP コネクターは設定変更ではなく、週単位で見積もる再構築プロジェクトです。この見積もりを飛ばしたチームが、移行し、行き詰まり、戻ってくることになります。

## 結論

**Claude が現状であり、「移行すべき場合」のリストに該当がなければ、留まってください。** 漠然とした不満は、再構築コストを負担する理由になりません。

**デフォルトを ChatGPT に切り替える**のは、画像または動画生成を必要とする反復業務を名指しできる場合、あるいはベンダー統合が上位で既に決定されている場合です。名指しできる業務が 1 つあれば十分ですが、広さへの一般的な選好では足りません。

**Perplexity は移行先ではなく追加として**、リサーチ担当者に $20/月で持たせ、その MCP サーバーを Claude に接続してください。これはレイヤーであって置き換えではなく、置き換えとして扱うのがこのページで最も多い誤りです。

**3 つとも合わない場合**、問題はほぼモデルではありません。業務が自社データを必要としているということです。CRM、契約リポジトリ、ATS。答えはアシスタント＋それらのシステムへのコネクター、あるいは既にデータを保有する業種特化ツールであって、4 つ目の汎用アシスタントではありません。コネクターが揃った時点で評価をやり直してください。答えが変わります。

最後に残る失敗の形は、AI ベンダーの選定を忠誠心の問題として扱うことです。2026 年に成果を出しているチームは 2 社に払い、業務ごとに使い分けています。
