## Qué es

Cursor es el IDE AI-native que se convirtió en el entorno de coding por default para engineers construyendo agentes, servidores MCP y el lado técnico de la automatización de ops. Forkeado de VS Code, con integración de IA profunda: tab-completion, modo agente, contexto a nivel de codebase y soporte completo para servidores MCP.

## Por qué aparece en stacks de RevOps

Esta es para GTM engineers y el lado técnico de RevOps — no es una herramienta para la organización de AE. Pero cada equipo de RevOps que construye workflows custom, nodos de n8n, servidores MCP, apps internas o código Apex de Salesforce hace ese trabajo cada vez más en Cursor. La combinación modo agente + MCP significa que puedes conectar Cursor a Salesforce, HubSpot, Snowflake, tu data warehouse, y hacer que escriba código que opera sobre tus datos en vivo.

- **Modo agente.** Agente de coding multi-paso que planea, edita y ejecuta código con tu supervisión. Más rápido que Claude Code para la mayoría de las tareas; comparable para refactors complejos.
- **Contexto de codebase.** Indexa tu repo entero y lo usa como contexto. Para mono-repos de RevOps con integraciones custom, scripts y SQL, esto importa.
- **Soporte para servidores MCP.** Conecta cualquier servidor MCP a Cursor — Salesforce, HubSpot, Linear, tu CRM-de-elección — y la IA puede leer/escribir datos mientras escribe código que los usa.
- **Cursor rules.** Convenciones por proyecto codificadas como archivos `.cursorrules`. Se vuelven el lugar canónico para documentar "cómo construimos automatizaciones acá".

## Pricing

- **Free** — requests de IA diarios limitados
- **Pro** — $20/usuario/mes, uso generoso de IA
- **Business** — $40/usuario/mes, incluye controles de admin, SSO, modo privacidad
- **Enterprise** — custom

El acceso a la API no está expuesto; Cursor se consume enteramente vía el IDE.

## Mejor para

- GTM engineers, RevOps engineers y gente técnica de ops escribiendo código custom
- Equipos adoptando MCP — Cursor es el IDE más pulido de los que son MCP-aware
- Solopreneurs y equipos chicos corriendo workflows de vibe-coding; el modo agente maneja la mayoría de las tareas end-to-end
- Cualquiera que haya probado Copilot, Continue o Codeium y quiera algo notablemente más rápido + más inteligente

## A tener en cuenta

- El modo privacidad es opt-in (tier Business y superior). Para entornos regulados, revisa los defaults de retención de datos antes del rollout.
- Mejor en codebases grandes — para scripts de un solo archivo, el overhead vs. Claude Code o claude.ai es real
- La organización de engineering puede ya tener una preferencia de tooling (Copilot, Cody, Continue). No es una pelea que RevOps quiera dar.
