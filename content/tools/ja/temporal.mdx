## 概要

Temporal は Durable Execution（永続実行）のプラットフォームです。Go、Java、TypeScript、Python、.NET の通常のコードとしてワークフローを書くと、Temporal がすべてのステップを記録します。そのため、ワークフローはクラッシュ、デプロイ、レート制限、1週間に及ぶ待機があっても進行状況を失いません。途中で worker が停止しても、別の worker が履歴を再生し、最後に完了したステップから処理を続けます。リトライ、タイムアウト、タイマー、人や他システムからのシグナルはプリミティブとして提供されており、自分で書く必要はありません。

サーバーは MIT ライセンスのオープンソースで、セルフホストできます。Temporal Cloud はマネージドサービスで、同社の収益源です。Temporal は 4,000 社以上の顧客を公表しており、OpenAI、Cursor、Netflix、JPMorgan Chase の名前を挙げています。他のベンダーが基盤として使うインフラでもあり、[UiPath](/ja/tools/uipath/) のエージェントオーケストレーターである Maestro は Temporal のエンジン上で動いています。

ビジュアルな自動化ツールではありません。ドラッグ＆ドロップのキャンバスも、構築済みの SaaS コネクタのライブラリも、業務ユーザー向けのフォームビルダーもありません。すべてのワークフローは、エンジニアが書き、テストし、デプロイするコードです。

## いまオペレーション責任者が Temporal に出会う理由

エージェントのワークフローは本質的に長時間実行です。アカウントを調査し、提案書を下書きし、マネージャーの承認を2日待ってから CRM を更新するエージェントは、LLM のタイムアウト、ツールの障害、人による中断をまたいで状態を保持しなければなりません。Temporal の答えは、エージェントのループをワークフローにし、モデルやツールへの呼び出しを1つずつ activity にすることです。失敗した呼び出しは自動でリトライされ、完了した呼び出しが再実行・再課金されることはありません。OpenAI Agents SDK との連携は一般提供されており、5月の Replay 2026 以降は Serverless Workers を提供しています。AWS Lambda 版は 2026年8月3日からパブリックプレビューで、チームが自前の worker 群を運用する必要がなくなります。

同社は資金が潤沢で、独立しています。2026年2月に 3億ドルのシリーズ D、続いて 2026年9月14日に評価額 125.5億ドルで 5.5億ドルのシリーズ E を調達し、Lightspeed が共同リードしました。2026年10月には認可（authorization）のスタートアップ Oso を買収しており、エージェントの権限管理を次に押さえるレイヤーと見ていることがうかがえます。

## 購入に値するユースケース

年間 50,000 件のベンダー契約を扱う Legal Ops チームの、受領契約パイプラインです。契約ごとにワークフローが起動します。テキストを抽出し、[Claude](/ja/tools/claude/) に条項ごとのリスクを分類させ、低リスクの契約は自動承認へ回し、標準外のものは弁護士の対応を最大5日待つシグナルで保留にします。48時間経過するとタイマーがエスカレーションします。午前3時にモデル提供元がレート制限をかけても、activity はバックオフ付きでリトライし、契約が失われることはありません。チームが分類器の新バージョンをリリースしても、処理中の契約は旧コードのまま完了します。この保証こそが購入する価値です。

## 料金

Temporal Cloud は **Action** 単位で課金します。ワークフローの開始、activity の開始またはリトライ、タイマー、シグナル、query、update がそれぞれ1 Action です。エントリープランは基本料金がなく、100万 Action あたり 50ドルに加え、利用額の 10% のサポート料がかかります。以前の月額 100ドルの Essentials プランは価格表から消えています。**Business** は月額 500ドルと利用額の 10% のうち高いほうで、250万 Action を含み、超過分の単価は段階的に 100万あたり 50ドルから 25ドルまで下がります。**Enterprise** とその上のプレミアム階層は年間契約で、1,000万 Action と 24時間365日のサポートが含まれます。ストレージは GB 時間単位で別途課金されます。新規アカウントには 90日間有効な 150ドル分のクレジットが付与されます。

定価ベース・ストレージ費用を除いた実際の価格帯は次のとおりです。

- **パイロット、月 200万 Action**（1回あたり 40 Action で約 50,000 回の実行）：エントリープランで月額約 110ドル。
- **本番運用チーム、月 2,000万 Action**：Business で月額約 1,275ドル。
- **プラットフォーム規模、月 1億 Action**：Business で月額約 3,850ドル（コミット割引の適用前）。

オープンソースのサーバーをセルフホストすればライセンス料はかかりませんが、データベース、可視化用ストア、アップグレードはすべて自社で運用します。コスト削減につながる前に、少なくともプラットフォームエンジニア1人分の工数を見込んでください。

## 最適な対象

エンジニアリングの支援を受けたオペレーションチーム（RevOps のエンジニアリングポッド、リーガルテックチーム、Recruiting を支えるプラットフォームグループなど）で、エージェントや業務プロセスのワークフローを、リトライ、人による中断、厳密に1回だけ実行される副作用を伴いながら数時間から数週間動かす必要があり、それをバージョン管理されたコードとして持ちたいチームに最適です。

## 代替ツールと、それを選ぶべきとき

- **AWS Step Functions**：AWS を使うチームにとって標準的なマネージドの選択肢で、Standard ワークフローは状態遷移 100万回あたり 25ドルです。すべてがすでに AWS 上にあり、ワークフローがコードではなく JSON で定義して構わない短いステートマシンであれば、こちらを選んでください。
- **Azure Durable Functions**：Azure を使うチームにとっての標準で、永続的なオーケストレーションをコードで書けます。チームが Azure と .NET を使っていて、新しいベンダーを増やしたくない場合に選んでください。
- **Restate**：最も注目度の高い新規参入者で、2026年9月30日に 2,000万ドルのシリーズ A を調達し、Replit Agent を利用者として公表しています。Durable Execution を単一の軽量バイナリとして使いたく、はるかに小規模なベンダーでも構わない場合に選んでください。
- **[Camunda](/ja/tools/camunda/)** または **[Appian](/ja/tools/appian/)**：業務側の関係者がプロセスを図として読み、承認し、編集する必要がある場合や、規制当局が BPMN モデルを求める場合に選んでください。
- **[n8n](/ja/tools/n8n/)**：ワークフローが数分で終わり、構築済みのコネクタが必要で、エンジニアではなくオペレーション担当者1人が管理する場合に選んでください。

## 注意点

- **Action 数は想定を超えがちです。** リトライ、タイマー、シグナル、UI からの query、スケジュール実行1回ごと（3 Action）もすべて課金対象で、不安定な API を囲むリトライループはコストを何倍にもします。対策：プランを決める前にステージングの namespace で1回あたりの Action 数を計測し、有料 API を呼ぶすべての activity にリトライ上限を設定してください。
- **決定性はコーディング上の規律です。** ワークフローのコードは同一に再生できなければならないため、ワークフローのコード内で時刻の取得、乱数の生成、API 呼び出しを直接行うと本番で壊れます。対策：副作用はすべて activity に置き、SDK のリプレイテストを CI に組み込み、実行中のワークフローを変更する前にバージョニング API を使ってください。
- **エンジニアが恒常的に必要です。** オペレーション担当者が自分でワークフローを組める UI はありません。対策：Temporal はエンジニアリングチームがすでに管理しているプロセスの裏側にだけ置き、アプリ間の単純な自動化は n8n や iPaaS に残してください。
- **Serverless Workers はまだプレビュー段階です。** 対策：Temporal が Lambda 版を一般提供と明示するまでは、本番の worker は自社のコンテナで動かしてください。
