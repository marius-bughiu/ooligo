## 概要

Leadfeeder は、自社サイトを訪問している企業を特定し、その企業に働きかけるためのツールを提供します。コンタクトデータ、CRM へのプッシュ、IP ターゲティングのディスプレイ広告です。企業単位のリバース IP 識別であり、[ZoomInfo](/ja/tools/zoominfo/) WebSights や [6sense](/ja/tools/6sense/) のアカウントレイヤーと同じカテゴリーに属します。[RB2B](/ja/tools/rb2b/) や [Warmly](/ja/tools/warmly/) のような個人単位の識別は行いません。

この会社を **Dealfront** として知っているなら、同じ製品です。2012 年にフィンランドで創業した Leadfeeder は、2022 年にドイツのセールスインテリジェンス企業 Echobot と合併し、統合後の会社は 2023 年に Dealfront へブランド名を変更しました。そして 2026-03-24 に、プラットフォーム全体の名称を Leadfeeder に戻しました。契約、価格、データは変わっていません。法人は引き続き Dealfront Group GmbH、Dealfront Germany GmbH、Dealfront Finland Oy なので、請求書や DPA には「Dealfront」と記載されていると考えてください。現在のモジュールは Web Visitors、Companies、Campaigns（旧 Promote）、Lists です。2025 年 10 月には、CRO だった Kevin McIntyre がEchobot の創業者 Bastian Karweg の後任として CEO に就任しました。同社は 2024 年 12 月に AshGrove Capital から €30 million を調達した後、2025 年 3 月に Stuttgart の訪問者インテリジェンスベンダー WiredMinds を買収しました。

このページが答える問いは次のとおりです。これまで使っていた Web サイトシグナルのベンダーが、消滅したか他社に吸収されました。[Koala](/ja/tools/koala/) は 2025-09-30 にサービスを終了し、HubSpot は 2026-06-30 に Warmly の買収で合意し、Zoom は 2026-07-02 に [Common Room](/ja/tools/common-room/) の買収で合意しました。独立を保ち、EU のトラフィックにも安心して使えるベンダーはどこか。答えは Leadfeeder です。同社の 2026 年のニュースは売却ではなく、名称変更でした。

## RevOps のスタックに入る理由

- **EU でホストされ、設計上企業単位です。** Leadfeeder はデータを EU のサーバーに保存し、訪問者本人ではなく訪問企業を特定します。上位プランで得られるメールアドレスや電話番号は、サイト上の個人の匿名性を解除して得たものではなく、別の B2B コンタクトデータベースから取得されます。そのため GDPR の分析は企業単位にとどまり、DPA を結んだうえで正当な利益を根拠にできます。
- **欧州の企業データを持っています。** Echobot 側から、商業登記簿を情報源とする企業レコードが加わります。Leadfeeder は 6,000 万社と 4 億件の検証済みコンタクトをうたっています。
- **価格が公開されており、実用的な無料プランがあります。** このカテゴリーの競合の多くは個別見積もりです。
- **エージェントからアクセスできます。** ベータ版の MCP サーバーが Leadfeeder を Claude、ChatGPT、Microsoft Copilot に接続し、アカウントブリーフ、セグメント、リスト作業に使えます。データを変更する操作は、実行前に確認を求めます。

## 価格の実態

価格はすべてユーロ建てで、全プランでユーザー数は無制限です。**Lite** は無料で、月あたり直近 100 社を 7 日間の履歴付きで表示します。**Discover** は年額請求で月額 €79 から始まり、特定企業 50 社までが対象で、1,000 社では月額 €309 になります。年額請求にすると 30% 安くなり、同じエントリープランを月額請求にすると €113 です。**Activate** は月額 €369 からで、コンタクト情報、インテントフィルター、Campaigns、API と MCP へのアクセスが加わります。**Scale** は月額 €599 からで年額請求のみ、10,000 社と 5,500 クレジットで月額 €2,089 に達します。

クレジットは、エンリッチメント、CRM へのプッシュ、Campaigns に使われます。識別そのものにはクレジットを消費しません。Vendr の購買データでは、年間契約の中央値は $8,628、範囲は $5,144 から $10,588 です。Vendr はこの数字が何件の購買に基づくかを開示していないため、目安として扱ってください。この中央値は月額約 $720 に相当し、Activate の中位の価格帯と一致します。営業担当者がコンタクトと CRM の自動化を求めるようになった段階で必要になるプランです。

## 最適な対象

欧州向けに販売し、月間のサイト訪問が数百ではなく数千ある、従業員 20 から 500 人の B2B 企業の Marketing Ops と RevOps の責任者です。GDPR をめぐって法務と揉めることなく、アカウント単位のシグナルを営業担当者と広告に回したい組織に向いています。

**向いていないケース:** パイプラインの大半が米国で、アウトバウンドの動きに個人名が必要な場合です。その場合は RB2B の米国向け個人単位識別のほうが合います。また、すでに 6sense や Demandbase に費用を払っているなら選ばないでください。それらのアカウント識別がこの用途をカバーしており、2 つ目の IP リゾルバーはシグナルを増やさずにコストだけを増やします。

## 代替製品との比較

- **ZoomInfo** は売上で最大の B2B データベンダーです。米国のコンタクトの厚みが必要で、いずれにしてもデータプラットフォームを購入するなら ZoomInfo を選んでください。Web サイトが主なシグナルで、予算が 6 桁ではなく 5 桁なら Leadfeeder を選んでください。
- **6sense** と **[Demandbase](/ja/tools/demandbase/)** は ABM インテントを牽引するベンダーです。大企業の広い TAM にわたって、複数ソースのインテントとアカウントスコアリングが必要ならこちらを選んでください。ファーストパーティの Web サイト訪問で十分なら Leadfeeder を選んでください。
- **RB2B** は最も急成長している新興ベンダーで、2024 年 3 月にローンチし、2026 年 2 月までに ARR $7.25 million に達したと報じられています。米国の個人単位の識別結果を Slack に届けたいなら RB2B を選んでください。EU のトラフィックと企業単位のコンプライアンスを重視するなら Leadfeeder を選んでください。
- **[Cognism](/ja/tools/cognism/)** は、訪問者トラッキングなしで EU のコンタクトデータと電話番号が必要な場合の選択肢です。

どれも合わない場合は、まず測定してください。無料の Lite プランで表示される月 100 社にターゲットアカウントがほとんど含まれていないなら、有料プランにしても状況は変わりません。識別ツールを買う前に、トラフィックと [インテントデータ](/ja/learn/intent-data/) のソースを改善してください。

## 注意点

- **リバース IP はリモートワーカーを捕捉できません。** 家庭用ブロードバンド、VPN、モバイルネットワークからの訪問者は企業に紐付きません。Leadfeeder は企業からの訪問の「最大 45%」を特定できるとしていますが、G2 のレビュアーの中には 10% 程度だったと報告する人もいます。*対策:* 14 日間のトライアルを自社のトラフィックで実施し、特定された企業の総数ではなく、ICP アカウントからの特定済みセッション数を測定してください。
- **コンタクトは訪問者本人ではありません。** Activate が返すのは、訪問企業に所属しフィルター条件に合う従業員であり、閲覧した本人ではありません。*対策:* 「料金ページをご覧になっていましたね」とは決して書かないでください。アカウントを担当者に回し、役職ベースでアプローチしてください。
- **2023 年以降に 2 度のブランド変更があり、API も 2 つあります。** 旧 Leadfeeder API は現在「Legacy Leadfeeder API」となり、Dealfront API が Leadfeeder API になりました。*対策:* 新しい連携は現行の Leadfeeder API で構築し、旧 API の廃止スケジュールを書面で示すよう求めてください。
- **全ユーザーが 1 つのクレジットプールを共有します。** 無制限のシートと CRM への自動プッシュが重なると、クレジットを急速に消費します。*対策:* CRM には ICP でフィルターしたフィードだけをプッシュし、最初の 1 か月はクレジット使用量を毎週確認してください。
- **更新条件に注意が必要です。** レビュアーは、解約通知期間が 30 日の自動更新を報告しています。*対策:* 署名前に通知期間を確認し、更新の 60 日前にリマインダーを設定してください。
- **MCP サーバーはベータ版で、Activate または Scale が必要です。** *対策:* エージェントからのアクセスをビジネスケースに組み込む前に、トライアル中に実際のアカウントブリーフ用プロンプトを試してください。
