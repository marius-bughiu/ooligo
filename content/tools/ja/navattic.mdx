## 概要

Navattic はノーコードのインタラクティブデモプラットフォームです。Chrome 拡張機能が製品の HTML と CSS をキャプチャし、クリック操作できるアプリのクローンを生成します。見込み客はログインもトライアルアカウントもなしに、Web サイト、メール、共有リンクからそのデモを使えます。キャプチャは HTML のみで、スクリーンショットのスライド形式や動画エクスポートはありません（アップロードしたメディアをデモ内に配置することはできます）。そのため、どのデモも製品の録画ではなく製品そのもののように動作します。Navattic は 1,000 社以上の顧客を公表しており、G2 では約 824 件のレビューで 4.7/5 の評価です。2026 年には、訪問者の質問に答えながらキャプチャ済みデモを操作する AI エージェント「Navattic Agents」と、MCP サーバーを追加しました。

## RevOps のスタックに入る理由

- **製品と同じように動く PLG 向け Web サイトデモ。** 各デモが HTML クローンなので、訪問者は入力欄に文字を入力し、メニューを開き、画面間を移動できます。マーケティングは「Book a demo」の隣に「Take a tour」として配置し、フォームには決して記入しないセルフサーブ型の検討者に届けます。
- **デモのエンゲージメントがルーティングデータになります。** アカウント識別（Base 以上）により、デモを閲覧している企業名が分かります。連携機能はエンゲージメントを [HubSpot](/ja/tools/hubspot/) の Contacts と Companies、[Salesforce](/ja/tools/salesforce/) の Leads、Contacts、Accounts に同期し、新規作成の前に既存アカウントの有無を確認します。ターゲットアカウントが購買意欲の高いフローを完了すると、プレイブックが [Slack](/ja/tools/slack/) またはメールでアラートを送ります。Default の導入事例によると、Navattic 自身もこの方法で [Default](/ja/tools/default/) を使い、プロダクト起点の有望リードをルーティングしています。
- **5 シートのプランで Salesforce が使えます。** Navattic の料金ページでは、月額 $500 の Base に Salesforce、Marketo「ほか 25 以上」の連携が含まれています。[Storylane](/ja/tools/storylane/) は Salesforce を月額 $1,200 の Premium まで、Arcade は Enterprise まで提供しません。
- **月額 $125 のプランから、書き込み権限付きの MCP サーバー。** Navattic の MCP サーバーは Startup 以上で利用できます。[Claude](/ja/tools/claude/) と [ChatGPT](/ja/tools/chatgpt/) は OAuth で接続し、[Cursor](/ja/tools/cursor/) などのクライアントは個人アクセストークンを使います。エージェントは分析データ、訪問者データ、Navattic Agents の会話履歴を読み取れるほか、デモの作成、編集、公開、アーカイブや、1 対 1 の Launchpad 共有リンクの作成もできます。

## 料金

Navattic は 2026 年に料金ページから定価を削除し、現在はプラン内容と見積もりボタンのみを表示しています。以下は、Navattic 自身の 2026 年 6 月のブログと、2026-09-03 付の Supademo による料金分析に基づく、最後に公開された数字です。

- **Starter — $0。** 1 シート、デモ 1 件、Copilot による基本的なデモ生成。
- **Startup — 年払いで月額 $125**（月払いは $150）、1 シート。HTML デモ無制限、HubSpot、Slack、メール、Webhook（各プレイブック 1 件）、MCP サーバー。対象は自己資金またはシード段階で従業員 30 名以下の企業に限られます。
- **Base — 年払いで月額 $500**（月払いは $600）、5 シート。Salesforce、Marketo ほか 25 以上の連携（プレイブック無制限）、アカウント識別、A/B テスト、パイプラインへの影響レポート、専任 CSM が加わります。
- **Growth — 年払いで月額 $1,000**（月払いは $1,200）、10 シート。[Gong](/ja/tools/gong/)、[Salesloft](/ja/tools/salesloft/)、[Outreach](/ja/tools/outreach/)、Gmail、Outlook、[Seismic](/ja/tools/seismic/)、Highspot との連携、購買関係者の発見、AI アバターのクローン作成、カスタムドメイン、SSO が加わります。
- **Enterprise — 個別見積もり。** オフラインデモ、監査ログ、プロフェッショナルサービス、優先サポートが加わります。
- **実際の支払額。** Vendr によると、Navattic の契約額の中央値は 99 件の購入で年間 $8,500、範囲は $5,000〜$18,000 です。年間前払いや複数年契約で定価から 15〜30% の値引きが可能です。この中央値は Base（定価で年間 $6,000）と Growth（$12,000）の間に位置します。CRM が Salesforce なら Base を、セールスエンゲージメントやイネーブルメントとの同期が要件に入った時点で Growth を予算に組み込んでください。

## 最適な利用者

- PLG またはハイブリッド型の B2B SaaS 企業で、HubSpot や Salesforce のルーティングにつながる操作可能な HTML デモを Web サイトに置きたいプロダクトマーケティング・グロースの責任者。シード段階（Startup プラン）から、デモ作成者 5〜10 名のチームまでが対象です
- Salesforce 連携を 10 シートではなく 5 シートの予算（定価で年間 $6,000）で使いたい RevOps・デマンドジェネレーションのチーム
- 向かないケース：ローンチ投稿や SNS 向けに動画や GIF 形式のツアーが欲しいチーム（Navattic は動画をエクスポートしません）、見込み客ごとにデータを編集したサンドボックスが必要な SE を抱えるエンタープライズのプリセールスチーム（Consensus か Walnut を検討してください）、UI が毎週変わる製品（HTML キャプチャは自動では更新されません）

## 代替ツールと選ぶべきケース

- **[Storylane](/ja/tools/storylane/)** — ほぼすべての直接比較で競合となる独立系ベンダーで、顧客チームは 5,000 以上です。スクリーンショット、動画、HTML のキャプチャを 1 つのライブラリで扱い、年払いで月額 $40 から始まり、サンドボックスデモ、プレゼンターデモ、AI SDR（RepX）も備えます。マーケティングがスクリーンショットや動画のツアーを、営業がライブ商談用デモを同じツールで必要とするなら Storylane を選んでください。Web サイトの HTML デモがすべてで、Salesforce を 5 シートのプランで使う必要があるなら Navattic を選んでください。
- **Arcade** — 無料利用の裾野が最も広いツールです（企業プロフィールデータによると 20,000 社以上）。Growth は年払いで月額 $42.50、最大 10 シートですが HTML キャプチャはなく、HTML とネイティブの Salesforce 連携は Enterprise 限定です。デモがパイプライン施策ではなく、ローンチや SNS 投稿用の完成度の高いスクリーンショット・動画ツアーなら Arcade を選んでください。
- **Supademo** — 最も急成長している新興ベンダーで、G2 の急成長製品にも選ばれており、2026 年 6 月から独自の AI Demo Agent を提供しています。HTML デモは Growth プランの月額 $350（作成者 5 名）から利用でき、Navattic Base の 5 シート月額 $500 より安価です。HTML とスクリーンショットのデモを低価格で使いたく、連携先が少なくても構わないなら Supademo を選んでください。
- **Consensus** — プリセールス重視のツールで、動画デモやインタラクティブデモを購買委員会に送り、どの関係者が何を見たかを分析します。2026 年 4 月に対話型デモエージェントの Peel を買収することで合意しました。Starter は年払いで月額 $600（5 ユーザー）でマーケティング系の連携のみ、Salesforce、Gong、Outreach は Pro（月額 $1,250、10 ユーザー）から使えます。買い手がエンタープライズの購買委員会で、ボトルネックが Web サイトのコンバージョンではなく SE のキャパシティなら Consensus を選んでください。
- **Walnut** — 営業主導でエンタープライズ向けの価格帯です。Vendr の中央値は年間 $17,000 で、無料プランはありません。大規模な営業チームの SE がデータを編集したサンドボックスデモを必要とし、予算が制約にならないなら Walnut を選んでください。

## 注意点

- **定価はもう公開されていません。** Navattic は 2026 年に料金ページから定価を削除し、商談ごとに見積もりを出しています。対策：上記の最後に公開された数字と Vendr の中央値 $8,500 を最初の商談に持ち込み、年額を書面で受け取り、Storylane か Supademo からも競合見積もりを取ってください。Vendr によると、年間契約や複数年契約では定価から 15〜30% 引きになっています。
- **キャプチャ形式は 1 つだけで、動画はありません。** Navattic が出力するのは HTML クローンのみです。対策：同じツアーを LinkedIn の動画、ローンチメールの GIF、ヘルプセンターのクリップとしても使う必要があるなら、Navattic に無理をさせず、2 つ目のツール（Arcade か Supademo）を予算に入れてください。
- **UI をリリースするとキャプチャが古くなります。** HTML クローンはキャプチャした日の製品の姿を表示し、再キャプチャは手作業です。対策：公開中のデモすべてに担当者を名指しで割り当て、大きな UI リリースのたびに再キャプチャし、2 四半期更新されていないデモは公開を停止してください。
- **Startup プランはシリーズ A で終わります。** 対象は自己資金またはシード段階で従業員 30 名以下の企業に限られ、Base への移行で請求額は 4 倍（定価で年間 $1,500 から $6,000）になります。対策：契約期間中に資金調達や従業員 30 名超えが見込まれるなら、契約時に Base の価格を交渉しておいてください。
- **Agents はまだ初期段階で、MCP サーバーは公開操作もできます。** Navattic は Navattic Agents の顧客成果を公表しておらず、MCP サーバーは接続ユーザーの権限でデモを公開・アーカイブできます。対策：Agents はまず 1 ページだけで、デモ訪問者 1,000 人あたりの商談獲得数をベースラインに試験運用してください。MCP は、人がエージェントの変更内容を確認できる体制が整うまで、Navattic が書き込み権限を無効にする Viewer ロールのユーザーで接続してください。
