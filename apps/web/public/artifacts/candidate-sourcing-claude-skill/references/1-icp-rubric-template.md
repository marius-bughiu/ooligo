# Role evidence brief

Record the role, the work task, and the specific evidence a reviewer would recognize. Keep the same criterion for every record in this worksheet.

| Field | Fictional example |
| --- | --- |
| Role | Warehouse analytics lead |
| Task | Find duplicate shipment events in a data feed |
| Criterion | Describe a SQL check for duplicate shipment events |
| Source to inspect | A work-sample excerpt cleared for this review, with its source ID |
| Reviewer question | Which event key was checked, and how was the result validated? |

A broad label such as “strong analyst” gives a reviewer little to verify. A quoted statement can justify a question without establishing the person's overall suitability. Treat absent evidence as an open question.
