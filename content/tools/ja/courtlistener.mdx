## 概要

CourtListener は、2013年に設立された非営利団体 Free Law Project が運営する、無料の米国判例・連邦裁判所ドケットのデータベースです。2,000以上の裁判所による900万件を超える判決を収録しており、Free Law Project によれば2023年時点で米国の先例的判例の99.9%超をカバーしています。さらに、数千万件の PACER 提出書類を収めた RECAP Archive、連邦控訴裁判所の口頭弁論録音、連邦判事の資産公開情報も保有しています。誰でもブラウザから無料で検索できます。

リーガル AI にとって重要なのはウェブサイトではありません。2026年5月12日、Free Law Project はプラットフォーム全体を `https://mcp.courtlistener.com/` のホスト型 MCP サーバーとして公開しました。サインインには通常の CourtListener アカウントを OAuth で使用します。[Claude](/ja/tools/claude/) のコネクタディレクトリと [ChatGPT](/ja/tools/chatgpt/) に掲載されており、2026年8月25日からは Google Cloud の Gemini Enterprise for Legal にも、Thomson Reuters、[Harvey](/ja/tools/harvey/)、Everlaw と並んで搭載されています。Claude Code のユーザーは1つのコマンドで追加できます。

```
claude mcp add --transport http courtlistener https://mcp.courtlistener.com/
```

サーバーは検索、引用検証、アラート用の専用ツールを公開しており、REST API のそれ以外の部分には `get_endpoint_schema` と `call_endpoint` という2つの汎用ツールを通じてアクセスします。

## Legal Ops スタックに登場する理由

- **汎用アシスタント向けの無料のグラウンディング層です。** リサーチ用コネクタを持たない Claude や ChatGPT の導入環境は、判例に関する質問にモデルの記憶から回答します。CourtListener を接続すると、ソースへのリンク付きで取得した判決文に基づいて回答できるようになり、ライセンス費用はゼロ、調達手続きも不要です。そのため [Claude for Legal](/ja/tools/claude-for-legal/) はリサーチ用コネクタの1つとしてこれを挙げています。
- **引用照会はハルシネーションによる架空の引用を検出するために設計されています。** 準備書面を貼り付けると、API が Free Law Project の Eyecite パーサーですべての引用を解析し、18,136,506件の引用と照合します。各引用は、発見（200）、形式は有効だがデータベースに存在しない（404）、不明なレポーター（400）、曖昧（300）のいずれかとして返されます。捏造された判例は通常404に分類され、提出前にレポーターを確認すべき合図になります。当サイトの [引用検証用 Claude スキル](/ja/workflows/citation-verification-claude-skill/) は、これを明示的な出典ソースとして使用しています。
- **誰かがすでに支払っていれば、ページ単位の課金なしで PACER を利用できます。** RECAP の文書は、他のユーザーが購入し、RECAP 拡張機能がアップロードしたコピーです。必要な提出書類がすでにあれば、取得費用はかかりません。
- **アラートも同じアカウントで動作します。** ドケットアラートと判決検索アラートにより、エージェントやパラリーガルは Westlaw や Lexis のシートなしで事件や法理を監視できます。

## 価格の実際

**アカウントは無料で、API アクセスも無料ですが、上限は低めです。** 2026年5月7日以降、非会員アカウントの上限は1分あたり5回、1時間あたり50回、1日あたり125回の API 呼び出しです。この変更前は、全ユーザーに1時間あたり5,000回が割り当てられていました。すでに1,000回以上のリクエストを行っていたアカウントは従来のレートを維持しています。MCP サーバーも同じクォータを消費します。

より高い上限は Free Law Project のメンバーシップで得られます。

| ティア | 価格 | 呼び出し回数（1分 / 1時間 / 1日） |
|---|---|---|
| Free | $0 | 5 / 50 / 125 |
| Tier 1 | $10/月 または $100/年 | 10 / 75 / 300 |
| Tier 2 | $25/月 または $250/年 | 15 / 150 / 600 |
| Tier 3 | $50/月 または $500/年 | 20 / 250 / 1,000 |
| Tier 4 | $100/月 または $1,000/年 | 25 / 300 / 1,400 |

グループメンバーシップは月額$30（Tier 1、最大5名）から月額$2,500（Tier 4、最大100名）までです。EDU メンバーシップは .edu アドレスがあれば無料で、2026年6月からは米国の非営利法律扶助団体が Tier 1 の上限で無料のグループメンバーシップを利用できます。Free Law Project は、メンバーシップによる API アクセスの対象を小規模事務所、小規模な公的機関、法律扶助団体、小規模メディア、研究者、収益化前の組織に限定しています。大規模企業や資金調達済みの企業は商用契約へ誘導され、価格は見積もりのみです。

多くの評価を左右する比較は次のとおりです。年額$1,000の Tier 4 メンバーシップは、年額$1,200の [Midpage](/ja/tools/midpage/) 1シートより安く、月額約$428の Westlaw Precision with CoCounsel 1シートのおよそ5分の1です。

## 最適なチーム

すでに Claude や ChatGPT を運用しており、米国の連邦・州の判例を取得し、草稿内のすべての引用が実在することを確認するための、無料で説明責任を果たせる手段を必要としている個人の訴訟弁護士、小規模事務所、法律扶助団体、社内法務チームに適しています。有料のリサーチ契約を締結する前にリーガル MCP を試験導入する Legal Ops チームにとっても、最初に導入すべきコネクタです。

## 代替候補と選び分け

- **[Thomson Reuters CoCounsel](/ja/tools/thomson-reuters-cocounsel/) with Westlaw**：市場シェアのリーダーです。KeyCite による判例評価、二次資料、実務ノートが必要な場合や、裁判所や保険会社が Westlaw を名指しで求める場合に選んでください。
- **[LexisNexis Protégé](/ja/tools/lexisnexis-protege/)**：もう一方の既存大手です。Shepard's と既存の Lexis 企業契約によって AI 層が追加コスト程度で済む場合に選んでください。
- **[Harvey](/ja/tools/harvey/)**：リーガル AI で最も急成長している新興企業です。事務所全体の起案業務やアドバイザリー業務に選んでください。データソースではなくプラットフォームです。
- **[Midpage](/ja/tools/midpage/)**：最も近い有料の類似サービスで、こちらも MCP コネクタとして提供されています。判例評価サイテーター、制定法と規則、1日あたりの呼び出し上限なしが必要な場合に選んでください。
- **[Trellis](/ja/tools/trellis/)**：州の事実審裁判所のドケットや裁判官分析が案件の鍵になる場合に選んでください。CourtListener はこれらを中心に据えていません。

## 注意点

- **サイテーターがありません。** CourtListener は判例が実在することと、それを引用している判例を示しますが、判例が破棄または変更されたことは表示しません。対策：実際に引用するすべての典拠を、提出前に KeyCite、Shepard's、Midpage のいずれかで確認し、CourtListener は取得と実在確認に使ってください。
- **引用照会が確認するのは実在性であり、正確性ではありません。** 引用文言はチェックせず、制定法、ロー・レビューの引用、「id.」や「supra」はスキップします。実在する判例が、その判例が判示していない命題のために引用されていても200として通過します。対策：最終稿のすべての引用文とピンサイトについて、リンク先の判決文を人が開いて確認することを必須にしてください。
- **無料ティアはセッション途中で上限に達します。** 検索し、判決文を読み、引用ネットワークをたどるエージェントは1つの質問で複数回の呼び出しを行うため、1日125回はすぐに尽きます。対策：1週間の試験導入中に CourtListener プロフィールの使用量カウンターを監視し、本格展開の前にピーク日をカバーするティアを購入してください。
- **商用利用はメンバーシップの対象外です。** 資金調達済みの企業が販売する製品に CourtListener を組み込む用途は、月額$100のメンバーシップでカバーされる範囲ではありません。対策：出荷前に Free Law Project にメールで商用契約を依頼し、大量処理にはバルクデータファイルまたはデータベースレプリケーションサービスを使用してください。
- **RECAP には欠落があります。** 収録されているのは、誰かがすでに購入した PACER 文書のみです。対策：提出書類が見つからない場合は「存在しない」ではなく「まだ RECAP にない」と扱い、必ず必要な文書については PACER 手数料を予算に組み込んでください。
