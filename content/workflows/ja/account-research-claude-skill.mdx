企業ドメインを受け取り、構造化されたアカウントブリーフを生成する Claude スキルです。会社の概要、決算説明会や最近のプレスリリースから抽出した戦略的優先事項、テックスタックのシグナル、主要ペルソナとその報告ラインを把握し、製品にマッピングした 3 つの仮説的な課題を提示します。すべてのディスカバリーコールの前に実行してください。

## 必要なもの

- Claude.ai または Web フェッチが有効な Claude Code
- 入力値として企業ドメインまたは LinkedIn URL
- スキルフォルダーに読み込まれた製品ポジショニングドキュメント（1 枚紙）
- オプション：Apollo や BuiltWith などの有料シグナルソース（スタックデータ用）

## セットアップ

1. **スキルを Claude に追加する。** `account-research.skill` ディレクトリを `~/.claude/skills/`（Claude Code の場合）に保存するか、Claude.ai プロジェクトにインポートします。スキルはエントリーポイントとして `research_account(domain)` を公開します。
2. **コンテキストファイルを読み込む。** 1 枚紙、ICP ルーブリック、競合リストをスキルの `references/` サブディレクトリに配置します。スキルは毎回の実行時にこれらを読み込むため、ブリーフは汎用的な AE リサーチではなく、貴社のポジショニングに基づいたものになります。
3. **出力フォーマットを設定する。** デフォルト出力は 5 つのセクションを持つ Markdown ブリーフです。チームが [Notion](/ja/tools/notion/) ブロック、Google Doc、または Slack 向けのサマリーを好む場合は `SKILL.md` を編集してください。
4. **テストアカウントで実行する。** `claude run research_account --domain acme.com` を実行します。ブリーフを確認し、出力が優秀な AE が手作業で書くものと一致するまで `SKILL.md` のプロンプトを調整してください。

## 仕組み

スキルは 4 つのサブタスクを順番に実行します。まず、会社のホームページ、About ページ、採用ページを取得してスナップショットを構築します。次に、過去 90 日間の決算トランスクリプト、プレスリリース、資金調達のアナウンスを検索して戦略的優先事項を抽出します。3 番目に、購買委員会の LinkedIn 公開データ（一般的な RevOps、Marketing Ops、Sales Ops の肩書き）を取得し、在籍期間と過去の会社を確認します。4 番目に、スナップショットとポジショニングドキュメントを照合して課題の仮説を合成します。

出力は意図的に意見を持った内容です。事実を羅列するのではなく、スキルは最も有力な 3 つのエントリーポイントをランク付けし、それぞれに対するディスカバリー質問を提案します。担当者は採用、編集、または却下できますが、常に白紙からではなく仮説から始められます。

## 注意事項

- **公開データの鮮度。** LinkedIn スクレイピングは頻繁に壊れ、決算トランスクリプトは 1 四半期遅れます。鮮度が重要な場合は、[ZoomInfo](/ja/tools/zoominfo/) や Apollo などの有料ソースを上流に組み込んでください。
- **幻覚による組織図。** 強引に求めると Claude は報告ラインを創作します。ペルソナセクションを LinkedIn や会社サイトで実際に確認できる肩書きに限定し、各名前に引用元を求めてください。
- **ポジショニングのドリフト。** 1 枚紙が 6 ヶ月前のものであれば、課題の仮説は古いメッセージングを反映します。マーケティングがポジショニングを更新するたびに references ディレクトリを同期してください。

- **Apollo または BuiltWith**（オプション）— テックスタックと従業員数のシグナル
