## Qué aporta Claude

Claude es el asistente y la API de modelos de Anthropic. En este piloto de enriquecimiento, su tarea útil es concreta: extraer datos candidatos de empresas desde el texto proporcionado y redactar una apertura después de validarlos. No es la fuente de la cantidad de empleados de una empresa. Una respuesta fluida no es evidencia.

Elige Claude para interpretar texto no estructurado con instrucciones explícitas. Usa código convencional para reglas fijas de puntuación, fechas y comparaciones exactas. Si tu CRM ya contiene los datos estructurados necesarios, añadir un modelo para copiarlos introduce otro punto de fallo sin resolver una carencia de información.

## Elige la vía de ejecución

Una [skill de Claude Code](https://code.claude.com/docs/en/skills) reúne instrucciones reutilizables y archivos de apoyo. Una [salida estructurada de API](https://platform.claude.com/docs/en/build-with-claude/structured-outputs) restringe el esquema de la respuesta. Resuelven problemas distintos de configuración; ninguna demuestra que un dato devuelto sea verdadero.

Para una tarea manual, revisa los datos extraídos junto a sus fuentes. Para procesamiento repetido por API, valida el contrato de salida, conserva evidencias y registra la versión del modelo y del prompt. En [Clay](/es/tools/clay/), configura Use AI y la cuenta del modelo por separado. Instalar una skill local no configura una tabla de Clay.

## Costos de suscripción y API

Los [precios de Claude](https://claude.com/pricing) incluyen Pro a **$20/mes o $200/año**, Max a **$100/mes** y Ultra a **$200/mes**, además de Free y planes para equipos. Se aplican límites de uso.

Los planes Max, Ultra y Team elegibles incluyen [créditos mensuales de API](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-ultra-and-team-plans). Para reclamarlos necesitas un plan elegible activo durante 7 días y vincular una organización de Console. Caducan en cada ciclo y no cubren Claude Code interactivo. Confirma la elegibilidad y el saldo vinculado antes de contarlos como presupuesto disponible.

Para la API, estima tokens de entrada sin caché por tarifa de entrada más tokens de salida por tarifa de salida, usando [las tarifas actuales del modelo elegido](https://platform.claude.com/docs/en/about-claude/pricing). Añade los costos aplicables de herramientas, caché y reintentos. Divide el costo real de procesamiento y revisión entre registros aceptados. El precio de una suscripción no basta para calcular una ejecución automatizada.

## Prueba primero el ejemplo descargable

El [workflow de Clay y Claude](/es/workflows/lead-enrichment-clay-claude/) incluye 20 registros sintéticos, prompts de extracción y apertura, un esquema y un validador local. Ejecuta `python3 pipeline.py demo` desde el paquete extraído. Usa ejemplos incluidos y código determinista: no llama a Claude ni a Clay y no genera gasto de API.

Para la vía opcional de Claude Code, conserva los archivos de apoyo bajo `.claude/skills/lead-enrichment-clay-claude/`, con `SKILL.md` en la raíz de ese directorio. Sigue la configuración del workflow antes de ejecutar un modelo real. Para adaptar a API o Clay, mapea la salida a los campos JSONL documentados. No supongas que el directorio de la skill es una integración importable.

## Qué debes seguir comprobando

- **Un esquema válido no garantiza datos verdaderos.** Exige IDs de fuentes y citas exactas. Revisa evidencias ausentes, antiguas o contradictorias antes de puntuar; no pidas al modelo que complete vacíos con estimaciones plausibles.
- **Las instrucciones no sustituyen controles de ejecución.** Mantén la escritura en CRM y la incorporación a secuencias fuera de la extracción. Revisa los borradores antes de usarlos en outreach.
- **Una respuesta correcta no es una evaluación.** Mantén un conjunto fijo de pruebas con entradas incompletas y contradictorias. Compara rechazos, tiempo de corrección y costo antes de cambiar prompts o modelos.

Usa la [guía de evaluación del enriquecimiento](/es/learn/data-enrichment-strategies/) para comparar. [Apollo](/es/tools/apollo/) proporciona datos de prospección y funciones de outreach; su función es distinta a la de un modelo de texto. Lee [Clay vs Apollo](/es/vs/clay-vs-apollo/) para elegir el proceso que los rodea. Mantén tu asistente actual si cumple los mismos controles de evidencia a menor costo medido.

**Estado de la evidencia:** consultamos la documentación oficial el 1 de noviembre de 2026. No ejecutamos una prueba real de extracción con Claude ni comparamos modelos para este perfil. La demo sintética sin conexión prueba las reglas locales, no la precisión del modelo.
