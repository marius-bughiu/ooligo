## 概要

**Drift は提供終了に向かっています。** 2026年3月6日、Clari + Salesloft は 1mind とのパートナーシップを発表し、その中で本製品の終了を明らかにしました。

> Clari + Salesloft は、conversational marketing ソリューションである Drift の段階的な提供終了を発表します。1mind との独占契約に基づき、Clari + Salesloft は既存の Drift 顧客を後継となる 1mind へ紹介し、摩擦のない移行を確保します。

2026-08-31 時点で確認したところ、`drift.com` と `drift.com/pricing` はいずれも `salesloft.com/platform/drift` へ 301 リダイレクトし、その見出しは「We've transitioned from Drift to 1mind」です。Drift は Salesloft のプラットフォーム機能の一覧から外れました。現在挙がっているのは Cadence、Rhythm、Conversation Intelligence、Deals、Analytics、Forecast です。ベンダーのサイトに残っているのは、ナビゲーションの「Log in to Drift」リンクと、`salesloft.com/legal/drift` にある「Drift Legacy Legal Documentation」のページだけです。アプリケーション自体は既存顧客向けに稼働し続けています。提供終了日は公表されておらず、発表には更新に関する案内も移行ツールもありませんでした。

このページは元の URL のまま残します。Drift が何であったかを記録し、いまも検索している人を適切な選択肢へ案内するためです。

Drift は「conversational marketing」というカテゴリーを作りました。B2B サイト上のチャットボットがインバウンドをリアルタイムで選別し、相手がまだページを読んでいる間にターゲットアカウントを AE へ提示し、ウィジェット内で商談を予約する、という仕組みです。[Salesloft](/ja/tools/salesloft/) が2024年に買収し、Salesloft と [Clari](/ja/tools/clari/) の統合は2025年12月3日に完了、その3か月後に提供終了が発表されました。

## RevOps スタックで採用されていた理由

- **購買意欲の高いページでのリアルタイム捕捉。** 料金ページに到達したターゲットアカウントを、同じセッション内で AE に提示できました。フォーム送信と翌日のフォローアップに劣化させずに済んだということです。
- **Salesloft ネイティブのテレメトリ。** 買収後、チャットの活動は中間レイヤーなしで Salesloft のケイデンスと Rhythm のシグナルに流れ込みました。
- **ABM プレイブック。** アカウント単位の挨拶文、ICP セグメントで分岐するボットフロー、担当者を特定したアカウント認識ルーティング。

## 料金（過去の実績）

Drift は価格表を公開したことがなく、すべて見積もりベース、年契約、サイトのトラフィックとシート数に応じたスケールでした。Vendr の検証済み契約データによると、Drift の購入額の中央値は247件の購入で **$35,500/年**、レンジはおよそ **$8,442 から $88,400** です。

この中央値は、このページに残る最も有用な数字です。すべての代替候補の見積もりを突き合わせる基準になるからです。Drift からの移行先はたいていこれより高く、ベンダー推奨の移行先にいたっては価格を一切公開していません。

## こんなチームに向いている

購入対象としては、誰にも向いていません。Drift は購入できず、ベンダー自身が後継製品を指名済みです。それでもこのページが役に立つ読者が2種類います。

1人目は、ボットがまだ動いている既存顧客です。やるべきことは Drift を延命することではなく、更新日や予告なしの停止に選ばされる前に、自分で代替を選ぶことです。終了日が公表されていない提供終了とは、ベンダーが握っていて自社が握っていないスケジュールのことです。

2人目は、評価の途中で「Drift pricing」を検索してここに来た人です。必要なのは最短の正しい答えと、稼働中のツールへの経路です。以降がその案内になります。

## 代替製品との比較

- **[1mind](/ja/tools/1mind/)** — ベンダー自身が示す経路であり、最も厳しく問い直すべき選択肢です。「Superhumans」という AI エージェントを販売し、サイトのインバウンド対応、商談への同席、プロダクト内ガイドを担い、購買シグナルを Salesloft の Predictive Revenue System に流します。価格は公開しておらず（`1mind.com/pricing` は404、2026-08-31 時点で確認）、最初から最後までデモ経由です。Drift を使い続けた本当の理由が Clari + Salesloft との統合そのものであるなら選んでください。そうでなければ、この紹介は移行計画ではなく複数の見積もりのひとつとして扱うべきです。
- **[Qualified](/ja/tools/qualified/)** — Salesforce 中心のエンタープライズ B2B チャットとして最も近い代替であり、Drift の RFP でもともと比較対象になっていたツールです。Premier、Enterprise、Ultimate のいずれも見積もりのみ（2026-08-31 時点で確認）。Vendr は中央値を190件の購入で **$68,430/年**、レンジ **$35,910 から $120,259** としています。Drift の中央値のおよそ2倍です。サイト経由のパイプラインが担当者付きの明確な数値になっているなら選んでください。コスト削減を期待して選ぶ相手ではありません。
- **[Intercom](/ja/tools/intercom/)** — 価格の下限であり、このカテゴリーで最大の導入基盤を持ちます。Essential **$29**、Advanced **$85**、Expert **$132**（シート/月）で、AI エージェントの Fin はどのプランでも **解決1件あたり $0.99** です。ウィジェットの実際の役割がサポートの自己解決促進で、その上に営業への引き継ぎが乗っているだけなら選んでください。Drift の導入例には、担当者が認めるより多くこのパターンが当てはまります。
- **[Warmly](/ja/tools/warmly/)** — 最も成長の速い新規参入で、エンタープライズ規模の価格を公開している唯一の選択肢です。AI Web-Deanonymization **$10,000/年**、Inbound Chat **$20,000/年**、AI Inbound Autopilot **$30,000/年**（四半期払いは **$4,875**、**$6,500**、**$9,750**）、全ティアで 10K クレジット/月、GTM Signals アドオンは **$10,000/年**。Drift のうち実際に使っていたのがチャットの記録ではなく訪問者の匿名解除とアカウント単位のアラートだったなら選んでください。
- **[Chili Piper](/ja/tools/chili-piper/)** — Drift が商談予約のレイヤーだったなら、チャットではなくルーティングを買うべきです。Routing & Scheduling は **$1,250/月**（**$15,000/年**、15シート込み、超過分は **$45**/シート/月、AI クレジット 45,000/年）から。Experiences は **$3,500/月**（**$42,000/年**、30シート、**$50**/シート/月、150,000 クレジット）から。請求は年次のみで、複数年割引は 15%、25%、40% が積み上げ適用されます。ChiliCal 単体は **$12**/ユーザー/月、最低200シートです。[Default](/ja/tools/default/) はエンリッチ→選別→ルーティング→予約という同じ流れをカバーし、こちらは見積もり制です。

## 注意点

- **紹介は移行ではありません。** この発表が Clari + Salesloft に義務づけているのは 1mind を指し示すことであって、何かを移すことではありません。エクスポートツールもデータポータビリティの条項も契約の継続性も発表されていません。**ガード:** ログインが生きているうちに、会話履歴、プレイブックのロジック、ルーティングルールを Drift の API 経由で自分でエクスポートしてください。1mind のデモを受ける前に済ませておけば、エクスポートが交渉材料にされずに済みます。
- **提供終了日がないことは猶予ではなくリスクです。** 日付のない「段階的」は、停止のタイミングをベンダーの都合が決めるという意味です。**ガード:** 自社で日付を決めてください。次の更新日の90日前に代替の意思決定をカレンダーへ入れ、発表がないことを待つ理由ではなく動く合図として扱います。
- **製品は保守モードにあり、それはベンダー自身のサイトが示しています。** Drift はプラットフォームの一覧から消え、規約は「legacy」のアーカイブへ移されました。**ガード:** 依存している範囲を凍結してください。新しいプレイブックの構築をやめ、壊れても誰も修正を出さない前提で、手作業で再現できない挙動を持つボットフローを洗い出します。
- **どの出口も、いま離れようとしているものより高くつきます。** Drift の中央値 $35,500 に対し、Qualified の中央値はおよそ2倍、Warmly の Inbound Chat ティアはアドオン前で $20,000/年、1mind は公開見積もりを出しません。**ガード:** 代替の価格は実際の利用実態で評価してください。購買意欲の高いページのセッション数、予約された商談数、受信箱に触れるシート数です。Drift の契約額を基準にしてはいけません。あの金額は、いまとは違う課金の仕方をしていたカテゴリー向けに設計されたものです。
- **統合は大きな音を立てずに、静かに壊れます。** Salesforce のフィールドマッピング、Marketo のフロー、Slack のアラート、Drift の API を読む Zapier のステップは、止まるその瞬間まで成功を返し続けます。**ガード:** いま Drift のウェブフックと API キーをすべて棚卸しし、下流のオブジェクトに件数アラートを設定してください。死んだチャットの配管は、誰かが配管を点検するまでの丸1四半期のあいだ「今期はインバウンドが弱い」と読まれます。
