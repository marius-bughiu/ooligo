# Review a vendor MSA in two rounds

This English-language pack is a set of eight copyable text prompts. The fictional JH-042 record lets a reviewer trace each recommendation to a clause version and an internal rule. No account is needed to read the example.

| File | Use |
| --- | --- |
| `msa-negotiation-prompt-pack.md` | Copy a common instruction and one of R1, R2, C1, C2, F1, F2, P1 or P2. |
| `examples/case-record.md` | Read the procurement intake, buyer-specific playbook, original vendor language, buyer request and vendor counteroffer. |
| `examples/review-notes.md` | Compare your reading with authored review notes for all eight prompts. Check the final decision log. |

First, use only vendor V1 to flag the notice clause and the gap in its delivery instructions. Draft the buyer's 30-day position. Then read B1 and V2. Explain why V2's 60 days stays open and who may release the 45-day alternative.

For a real matter, supply a permitted version of your own documents, approved playbook and named review owner. Replace the fictional positions and thresholds. Review each proposed sentence and record the human decision. The Markdown files do not apply tracked changes, send a message, calculate a legal deadline or change a CLM record.
